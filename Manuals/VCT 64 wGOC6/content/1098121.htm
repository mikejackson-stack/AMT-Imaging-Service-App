STEP 1: Pre-Delivery Activities

Labor:1 person
Tools:Site Readiness Checklist

  • Confirm Acceptance to lead installation

  • Confirm Installation Details & Monitor dates with PMI

    • Delivery Date

    • Install Start Date

    • Install Complete D

  • Obtain GON and equipment order list

  • Obtain Installation Tools (Refer to Appendix: Installation Tools)

    • Gang Box (JoBox)

    • Alignment Kit

    • Temperature/Humidity meter

    • Electrical Safety Analyzer (Dale 600 Leakage Meter)

    • Nemoto Injector calibration tool

    • Personal Protective Equipment (PPE)

    • Lock-Out Tag-Out devices (LOTO)

    • Digital Level

  • Pre-Delivery Site Visit

    • Review Site Drawings with PMI and Customer

    • Surface Penetration permit signed and posted. Otherwise customer performs drilling.

    • Lay Floor Templates and mark the anchoring locations. If JoBox already on-site, then use the hole saw to make floor cutouts.

    • Assess site readiness.

    • Confirm delivery / location of the system with PMI

    • Evaluate cable runs

    • Review the equipment order with PMI

    • Verify order accuracy for correct cable set

    • Meet with Electrician: Set up time for the PDU hookup, and brief electrician on expectations for cutting holes in ducts and removing covers

    • Create System ID’s. De-install old System ID’s if required

    • Initiate IP address and start Broadband checkout process

  • Obtain or access appropriate forms

    • Form 4879

    • Form 2579: HHS - Installations

    • Power & Grounding audit form

    • Electronic Service Reporting (ESR) form: ESR Portal

    • iCenter form: iCenter Portal

    • Site Log Book

  • Review Safety Risk Assessments for Install

  • Competency Form signed-off by FE and manager

  • Contact delivery person to validate time, materials, and manpower

  • Receive equipment at time of delivery

  • Complete Site Readiness Checklist prior to install start

  • Conduct Safety Assessment

  • Complete Surface Penetration Form

  • Audit the JoBox

  • Follow State Approved Shielding Plan, if required

  • Perform Installation Activities
