3  Procedure

3.1   8-Port Network Switch Removal

  1. Select one of the following methods to Power OFF the Console:

    1. If Applications are up, click on the [Shut Down] button on desktop display and select [Shutdown].

    1. If Applications are down, open a Terminal Window. Type: halt , then press <Enter>.

    (Step Details)

  1. When halt command has finished, power Off the console at the front panel switch.

  1. Apply LOTO for console. For procedures, see Equipment Service - Lockout-Tagout-PPE.

  1. Remove the console’s keyboard tabletop assembly and front console chassis cover.

    (Step Details)

  1. Locate the network switch on the left side bottom of console chassis. The network switch is held in place with Velcro. Lift up on the network switch to detach it from the console base.

    Illustration 2:  Network Switch Removal

    (Step Details)

  1. Disconnect all cables attached to the network switch. Make certain that all cables are properly labeled.

    Illustration 3:  Network Switch Connections

    ItemDescriptionDestination
    1Ethernet Port 1Host Computer (eth3 - System Board)
    2Ethernet Port 2Rear Bulkhead (AW) - J29
    3Ethernet Port 3Rear Bulkhead (EKG) - J30
    4Ethernet Port 4Rear Bulkhead (RPM) - J31
    5Ethernet Port 5Rear Bulkhead (SRV) - Console Front Panel
    6Ethernet Port 6Not Used
    7Ethernet Port 7Not Used
    8Ethernet Port 8Not Used
    9Power InputConsole Power Distribution Box - J12

    (Step Details)

3.2   8-Port Network Switch Install

  1. Reconnect all cables removed earlier from network switch.

    (Step Details)

  1. Reattach the network switch to the base of the console.

  1. Remove LOTO on console. For procedures, see Equipment Service - Lockout-Tagout-PPE.

    (Step Details)

3.3   Functional Checks, Alignments and Setups

  1. Power On console.

  1. Inspect network switch and confirm the Power and Port 1 LEDs are lit.

    (Step Details)

4  Finalization

  1. Install console’s keyboard tabletop assembly and front console chassis cover. Refer to Replacement → Console (GOC6.6) → Console Cover Removal and Installation Procedure.

  1. Perform the Functional Checks → System Scanning Test instructions from the procedure list.
