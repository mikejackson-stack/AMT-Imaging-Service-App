2  Interconnections

2.1  Installation Faceplates

  1. Install the cable 2286150.

  2. Connect the LEMO plugs to the right and left option panels.

  3. Remove the plate on left side of option interface panel.

  4. With outer conical nut removed, insert a LEMO connector through the appropriate hole in the faceplate, with the red dot at top. See Illustration 1.

    Illustration 1:  Orientation of Connectors

  5. Adjust the inside conical nut so enough thread appears through the hole and the external nut can be firmly attached while keeping the connection flush with the faceplate.

  6. Repeat steps 1 - 5 (above) for the right-side option interface panel.

  7. Route the cable as shown in Illustration 2 along gantry base’s near tube. Secure cables with ties as shown.

    Illustration 2:  SmartStep Cable Routing

2.2  Installation Cables

  1. Locate the gantry MSUB (Milwaukee SUBordinate board, which is used to signal routing for the TGP) See Illustration 3.

    Illustration 3:  Gantry MSUB

  2. Locate the J27 connector. See Illustration 4.

    Illustration 4:  Connetor J27

  3. Install the 2355108 cable to the J27 Connector. Ensure that the covers fit around cables. See Illustration 5.
