STEP 19A: Table Cable Connections

Labor:1 person; 0.5 man-hour
Tools:Standard Tool Kit

1. Pass the ground cables from the PDU and Console (Run #55 and #56) through the gantry to the Table Footswitch.

2. Cut the tie-wraps from around the table cables in the gantry base and route the power cables through the Footswitch.

3. Connect the 120VAC table power cable (Run #54) to J1 table power.

4. Connect the table signal cable (Run #104) to J9 on the table control board.

5. Connect the table ground cable to the table ground chassis.

6. Connect all system grounds - Run #55, #56, gantry ground, gantry power pan, table ground, and any Options grounds - to the ground bus bar on the Footswitch.
