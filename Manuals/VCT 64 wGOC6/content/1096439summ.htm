(10MW06.5) GOC6 Series Load From Cold

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

All hardware components of the System must be functional.

-

-

The Operator Console Front Cover will need to be removed to gain access to the Host Computer DVD Drive.

-

-

A valid and current System State Backup is required. System State is already configured for site specific configuration and preferences. If System State Backup media is missing or not current, some or all of the following must be performed: (1.) A manual configuration using information contained on the System Configuration Data Sheet completed at installation time. (2.) Software Options Licences will need to be manually reloaded. (3.) System Calibrations will need to be performed.

-

-

Only trained service personnel should service the GE CT Scanner.

-

-

2  Procedure

2.1   Software Deliverable for GOC6 Series Consoles

  1. CTT Operating System, Version 5.3.11

  1. CT Applications Software

2.2   Pre-LFC Checks and Information Gathering

  1. Confirm that a current System State Backup Media is on site. If unsure of the status of the System State, execute System State Save Restore procedure found in the Software Chapter of this manual. Save a System State Backup to either DVD-RAM or USB Media.

  1. Remove all media from MOD and DVD Peripheral Towers before starting the OS Load of the LFC process.

    (Step Details)

2.3   Operating Software (OS) Load

  1. Unplug the Hospital Network (HSP - J26) cable from rear Console bulkhead.

  1. Label the cable as HSP - J26 (if necessary) and set it aside during LFC.

  1. Remove the Operator Console front cover per the prescribed procedure Console Cover Removal and Installation.

  1. Insert the OS Disk into the Host Computer DVD Drive. See the following illustrations.

    (Step Details)

  1. Shutdown and Power Cycle Operator Console:

    1. Using the toolchest, open a Terminal Window.

      1. Type: {ctuser@hostname}halt

      1. Wait for System Halted message to appear on the monitors.

        (Step Details)

    1. Turn Off Operator Console power. Wait 30 seconds, then turn power On.

  1. As the Host Computer restarts, the boot process messages appear. After the booting process completes the boot: prompt appears.

  1. At the “boot:” prompt, type the following:

    (Step Details)

  1. After the OS is loaded on the Host Computer, the Complete Window appears.

    (Step Details)

  1. Remove the OS Disk from the Host Computer DVD drive when it ejects and close the tray. Press [Enter] to Reboot.

  1. The Host Computer begins to reboot.

    (Step Details)

2.4   Applications Software (APPS) Load

  1. Open the tray on the Host Computer DVD Drive.

  1. Insert the Applications Disk into the DVD Drive and close the tray.

    (Step Details)

  1. Select [Run Command] in the Warning box.

    (Step Details)

  1. Select [Load] in the CT Software Installation window.

    (Step Details)

  1. System State decision for Install INFO decision box will appear.

    (Step Details)

  1. System State (Install INFO) Media Type decision window will appear

    (Step Details)

  1. Insert the System State Backup Media (DVD-RAM or USB).

    (Step Details)

  1. The Install INFO on the System State Backup Media will be read and if a valid System State Backup has been inserted, an LightSpeed/INFO window will become active.

    (Step Details)

  1. The Install INFO on the System State Backup Media will be displayed and a confirmation window will appear.

    (Step Details)

  1. System Install INFO will be now used to create the CT Application load routine. Do not remove the Apps Disk until completed.

  1. When completed, the Operator Console will automatically reboot.

  1. After the Host Computer reboots, a pop-up window will appear

    Illustration 17:  CT Software Auto-Start Disabled Pop-Up Windows

    (Step Details)

2.5   LFC Menu - GOC 6 Series Console Software Load

  1. To launch LFC Menu, open a Terminal Window, and log on as root:

    1. Type: {ctuser@hostname} su -[ENTER]

    1. Type the root password and press [ENTER]

    1. Type: [root@hostname] /usr/g/scripts/LFC/startLfcMenu.sh[ENTER]

      (Step Details)

  1. A window will be displayed showing the LFC Menu.

    (Step Details)

  1. Select Load DIG (Menu Selection # 1)

    (Step Details)

  1. Select Load VeRB (Menu Selection # 2)

    (Step Details)

  1. Select Set Date and Time (Menu Selection # 3)

    (Step Details)

  1. Select Install ClassC (Menu Selection # 4)

    (Step Details)

  1. Select Install ClassM (Menu Selection # 5)

    (Step Details)

  1. Select Restore System State (Menu Selection # 6)

    (Step Details)

  1. Optional Menu Selections

    (Step Details)

  1. Select Quit (Menu Selection # 10)

    (Step Details)

  1. Reboot the System

    (Step Details)

2.6   Tube Install Certification

  1. Perform the Tube Install Certification procedure.

  1. When completed, continue with Flash Download.

    (Step Details)

2.7   Flash Download

  1. Perform the Flash Download Utility found on the Common Service Desktop - Utilities Tab, select [Flash Download].

    (Step Details)

  1. When the Flash Download Window opens,

    (Step Details)

  1. Once the Gantry Hardware Flash Downloads successfully, select [Dismiss].

  1. Close the Common Service Desktop.

  1. Reconnect the Hospital Network cable at the rear of the Operator Console (J26) that was disconnected at the beginning of the LFC.

  1. Select Shutdown icon on the Desktop and restart the system.

    (Step Details)

2.8   Final Save System State

  1. Perform the System State Save and Restore procedure and save a System State Backup to either DVD-RAM or USB Media.

  1. Save the System State Backup media in a safe and secure location for future service activity.

    (Step Details)

3  Finalization

  1. If applicable, install any Service Pack updates related to this release.

    (Step Details)

  1. Refer to System Scanning Tests in the Functional Checks chapter of this manual to confirm proper operation.

  1. Reinstall Console Front Cover.
