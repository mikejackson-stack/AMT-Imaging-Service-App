Table 4:  Tilt Limits When Table Below Scan Plane Lower Limit Tests

TestStepsExpected Results
1

Set the gantry tilt to zero.

Move the cradle (and IMS) to the home position.

Lower the table all the way.

Set the internal landmark.

Cradle position on the display should read 0.0.

Gantry tilt on the display should read 0.0.

Table height should read 585 ± 3 mm. (This value is the offset from 560 mm by the same amount as the upper table limit varies from 25 mm in the Table Elevation Test #2 in Table 1.)

2

Tilt the gantry forward and backward.

Verify the following tilt limits: S0.5 & I30.

Gantry tilt on the display should read S0.5 ± 0.5º.

Gantry tilt on the display should read I30.0 ± 0.5º.

3

Set the gantry tilt to 0.

Using the gantry push-buttons, move the cradle in toward the gantry until it stops.

Gantry tilt on the display should read 0.0.

Cradle should stop at 10.0 mm ± 6 mm from the home position. (This value is not valid if the table/gantry mechanical characterization is not correct as described in the Table Elevation Test #2 in Table 1. Ensure that the front of the table is at least 25 mm from the gantry.)

4

Set the gantry tilt to zero.

Move the cradle to the home position.

Cradle position on the display should read 0.0

Gantry tilt on the display should read 0.0.

5

Raise the table to a height of 386 mm.

Verify the following tilt limits: S11.0 & I30.0.

Table height should read 386 mm.

Gantry tilt on the display should read S11.0 ± 0.5º.

Gantry tilt on the display should read I30.0 ± 0.5º.

6

Set the gantry tilt to 0.

Set the internal landmark.

Using the gantry push-buttons, move the cradle (and IMS) in toward the gantry until it stops.

Gantry tilt on the display should read 0.0.

The cradle should stop at 141 mm ± 6 mm from the home position.

7

Set the gantry tilt to zero.

Move the cradle to the home position.

Cradle position on the display should read 0.0.

Gantry tilt on the display should read 0.0.

8

Raise the table to a height of 242 mm.

Verify the following tilt limits: S24.0 & I30.0.

Table height should read 242 mm.

Gantry tilt on the display should read S24.0 ± 0.5º.

Gantry tilt on the display should read I30.0 ± 0.5º.

9

Set the gantry tilt to 0.

Raise the table to 210 mm.

Using the gantry push-buttons, move the cradle in toward the gantry until it stops.

Gantry tilt on the display should read 0.0.

The cradle should go all the way through the gantry bore to the full-extended position, (approximately 2445 mm for the GT 2000 table).

10

Set the gantry tilt to zero.

Move the cradle (and IMS) to the home position.

Lower the table all the way.

Set the internal landmark.

Cradle position on the display should read 0.0.

Gantry tilt on the display should read 0.0.

Table height should read 586 ± 3 mm. (This value is the offset from 586 mm by the same amount as the upper table limit varies from 25 mm in the Table Elevation Test #2 Table 1.)

11

Tilt the gantry top toward the table to a tilt of 30 degrees

Display should read I30.

12

With the table down all the way, move the cradle in until it stops.

The cradle position should be 378.5 ±3 mm.

13

Move the table to the home position.

Raise the table to a height of 386 mm.

Set the internal landmark.

Move the cradle in until it stops.

Cradle position should be 403 ± 5 mm.

14

Raise the table to a height of 63 mm.

Move the cradle in.

The cradle should go all the way through the gantry bore to the full-extended position, (approximately 2445 mm for the GT 2000 table).
