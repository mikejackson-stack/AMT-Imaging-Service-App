2  Overview

This procedure describes 13HW31.8 Service Pack 1.0 installation procedure.

Last revised:December 17, 2013

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

Only trained service personnel should service the GE CT Scanner.

-

-

4  Procedure

4.1  Check software version currently installed

  1. Open a Unix shell.

  1. Type swhwinfo <ENTER>

    Confirm that the base software version is 13HW31.8.

4.2  Service Pack Installation

  1. Open a Unix shell.

  1. If Application software is up, perform the following command.

    {ctuser@hostname} cleanMon

  1. In the Unix Shell, become root:

    1. {ctuser@hostname} su -

    1. Password: <password>

  1. Insert the Service Pack CD into DVD drive in the host.

  1. Perform the following steps to install the Service Pack CD:

    1. [root@hostname]# patch_install -c

    1. The following message is displayed

      These patches from cdrom will be installed:
13HW31.8_GEHCServicePack1.0
------------------------------------------
I will install update 13HW31.8_GEHCServicePack1.0 from CDROM, is this ok ? [y/n]

    1. Input y to install Service Pack 1.0.

    1. Confirm the “Update 13HW31.8_GEHCServicePack1.0 has been installed successfully” message.

  1. Check Software Version:

    1. Type: [root@hostname]# swhwinfo <ENTER>

    1. System should reply with a response similar to the following:

      13HW31.8_SP1-0-1.<hw info (ex. V40_H_H64_G_GTL) >

  1. Remove the Service Pack CD from Host DVD drive.

  1. Reboot the system:

    [root@hostname]# reboot

4.3  How to uninstall Service Pack

  1. Open a Unix shell.

  1. If Application software is up, perform the following command.

    {ctuser@hostname} cleanMon

  1. In the Unix Shell, become root:

    1. {ctuser@hostname} su -

    1. Password: <password>

  1. Perform the following steps to uninstall the Service Pack CD:

    1. [root@hostname]# patch_install -u

    1. The following message is displayed.

      The following patches are installed on system:
------------------------------------------
13HW31.8_GEHCServicePack1.0
------------------------------------------
I will uninstall update 13HW31.8_GEHCServicePack1.0, is this ok? [y/n]

    1. Input y to uninstall Service Pack 1.0.

  1. Reboot the system:

    [root@hostname]# reboot

5  Finalization

  1. Refer to System Scanning Tests in the Functional Checks chapter of this manual to confirm proper operation.
