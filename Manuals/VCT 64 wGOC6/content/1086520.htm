2  Overview

This document provides the necessary steps to launch the System Troubleshooting Tool. The System Troubleshooting Tool displays system data that can be used to troubleshoot the system while the system is energized.

Last Revised:October 21, 2009

3  Preliminary Requirements

3.1  Safety

CAUTION
Do not service or physically troubleshoot left side of gantry while system is energized.

CAUTION
No personnel or patients should be in the area of the gantry while scanning without adequate radiation safety precautions being utilized.

3.2  Required Conditions

ConditionReferenceEffectivity

Recommend procedure completion by GE Service trained personnel.

4  Procedure

4.1  Launching Tool

  1. Select [DIAGNOSTICS] from Service Desktop.

  1. Select [SYSTEM TROUBLESHOOTING TOOL]

    NOTE:Overview Panel: Describes gantry left-side sub-system troubleshooting and service information.

    NOTE:Sub-systems Panel: Displays data and status information.

  1. Select Sub-system tab. (See Illustration 1)

    NOTE:To display data using System Troubleshooting Tool, system must be operational, and some displays require system scanning to depict changes in data results.

    NOTE:If gantry is powered off while System Troubleshooting Tool is active, a Reset message is displayed. Follow on-screen instructions to recover.

    Illustration 1:  System Troubleshooting Tool

  1. Click [EXIT] to close tool.

4.2  Tool Functionality

  1. When tool is launched, hardware/system conditions are queried in a continuous mode. Display is updated every second and is in Continuously Update mode.

  1. Click [STOP] releases Continuously Update mode.

  1. Click [UPDATE ONCE] causes values to be updated once.

  1. Display Color Definitions

    1. Green: Data in normal expected range.

    1. Yellow: Data exceed upper or lower warning limits.

    1. Red: Data exceed upper or lower specification limits.

    NOTE:Yellow and Red display colors only apply to power supplies.

  1. Click [HELP] to be routed to systems service manual.
