Network Time Protocol (NTP) Setup

(Click Here to Return to Detailed Procedure)

1  Procedure

NOTE:It is best to first discuss with the site's IT Department to determine if there is a specific Service IP Address preferred to connect to (e.g. same IP Address as PACS or other CT systems). If an IP Address is provided, skip to step 2.

  1. Using a PC connected to the site's local network, determine the NTP server available.

    1. On LAN connected PC, select [START] button, then [Run].

    1. Type: eventvwr.msc<ENTER>

    1. Select [System]

    1. Double-click W32Time

      (Step Details)

    1. In the [Event] tab, look in the Description section

      (Step Details)

    1. Record IP Address from Description.

  1. Ping the IP Address on the system.

    1. Open a Unix shell on the scanner.

    1. Type: ping 3.57.52.193 <ENTER>

      (Step Details)

  1. Perform system config to update the scanner to use NTP.

    1. Become root:

      1. Type: su -<ENTER>

      1. Enter root password.

    1. Type: reconfig

    1. Select [CONFIG]

    1. Select NETWORK tab.

    1. Enter the IP Address previously recorded in the NTP section.
