STEP E16: Patient Touch and System Chassis Leakage Tests

Labor:1 person; 1.0 man-hour
Tools:Standard FE Tool Kit
Dale 600 or 601 Leakage Current Meter
Date extended length lead (part of p/n 46-328406G1)
GE LOTO Kit

1. Configure the Dale 600 Meter (or equivalent for the test. Connect the chassis lead to the table ground bus. Set the function switch to External. Touch the external lead to the test point to verify the meter is operational.

2. Patient Touch Leakage: Perform this test with system power ON. Measure the current leakage between table ground bus and all possible touch points within patient reach (including options), and within 6 ft horizontally and 7.5 ft above the table ground bus.

3. The leakage must not exceed the limits specified for the care area. Take into account all patient positions, including table up/down, patient face-up/face-down, patient feet-first/head-first, and table travel.

4. Complete the System Chassis Leakage test if required by local regulations. Perform this test with power ON and in standby. The measured leakage current must not exceed 5 mA in any ground wire.
