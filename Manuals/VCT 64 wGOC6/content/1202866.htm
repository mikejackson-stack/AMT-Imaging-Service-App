2  Overview

This describes the procedure to install and uninstall SP1.1 for 12HW14.6 (Epsilon).

Last revised:September 11, 2013

4  Procedure

4.1  Preparation for Installation

  1. Check the current software version by the following command.

    {ctuser@hostname}swhwinfo

    Example: 12HW14.6_V40_H_HS64_G_GTL

    If the output contains SP1-1-1, SP1.1 is already installed. No need to install it.

    If the output contains SP1-0-1, SP1.0 is installed, need to uninstall it.

    If the output is not equal to 12HW14.6, system software version is different, do not execute the procedure.

  1. Check Exam Split Type. (Skip this step if SP1.0 Installation is done with 12HW14.6 LFC at the same time.)

    Type swokinstall -p

    If Exam Split option is displayed, execute the following

    Type ls -l ~ctuser/ves/.hesMode

    If there is .hesMode file, it’s HES mode.

    If not, It’s VES mode.

    This will be used at reinstall option.

4.2  Service Pack 1.1 Installation

NOTE:For the options to function correctly, it is necessary to uninstall the options listed below before installing SP1.0, then re-installing them after SP1.0 Installation.

  1. Perform Save State.

  1. Uninstall the following options (if installed) using the Install Options menu in the Configuration Tab in Common Service Desktop.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • CTPerfusion4Neuro

    • VolumeViewer

  1. Open a Unix shell.

  1. Shutdown Application (if up). Type cleanMon [ENTER] .

  1. Insert the Service Pack 1.1 CD-ROM into the Host DVD drive.

  1. Delete the old patch file, type the following commands.

    1. su - [ENTER] to be root user.

    1. mount /mnt/cdrom

    1. /mnt/cdrom/scripts/remove_oldrpm

    1. Confirm that the command prompt is displayed.

  1. Type patch_install -c [ENTER]. Follow the instructions displayed on the screen.

    NOTE:It may take 3~4 min., please wait.

  1. Verify “Successful” message is displayed.

  1. When the Host PC is XW8200 with FX1400/FX1500 Graphic card, the following message is displayed. In this case, execute the following steps to update Display Driver. If the message is not displayed, type reboot [ENTER] and skip to step 15.

    Illustration 1:  Message Window

  1. Type init 3 [ENTER] to shut down the [X Window]. The monitor will be changed to a black screen, and will appear with a text of shutdown.

  1. Hold down the [Alt] key and then press the [F6] key once, the login prompt will appear, and login as root. (It takes about 1 min. to log in.)

  1. Type patch_nvdriver [ENTER] .

    After displaying a “Successful” message and a reboot request message, press [Enter] to reboot.

  1. Remove Patch CD-ROM from Host DVD drive.

  1. Open a Unix shell and type swhwinfo [ENTER] .

    The output should contain “SP1.1” and will look similar to this: 12HW14.6SP1-1-1.V40_H_HS64_G_GTL.

  1. Restore State (Reconfig Info only) to reinstall the options previously removed, then restart the system.

  1. Confirm the following options has been reinstalled.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • CTPerfusion4Neuro

    • VolumeViewer

  1. Execute a test scan to confirm system functionality. Perform a minimum of one scout and 20 images helical or axial scans.

4.3  Service Pack 1.1 Uninstallation

  1. Save System State.

  1. Open a Unix shell and check Exam Split type.

    Type swokinstall -p [ENTER]

    If the Exam Split option is installed, execute the following.

    Type ls -l ~ctuser/ves/.hesMode [ENTER]

    If there is .hesMode file, it’s HES mode.

    If not, it’s VES mode.

    This will be used at reinstall option.

  1. Uninstall the following options (if installed) using the Install Options menu in the Configuration Tab in Common Service Desktop.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • CTPerfusion4Neuro

    • VolumeViewer

  1. In a Unix Shell, type cleanMon [ENTER] to shutdown application.

  1. Type su - [ENTER] to be root user and type init 3 [ENTER] to shut down the [X Window]. The monitor will be changed to a black screen, and will appear with a text of shutdown.

  1. Hold down the [Alt] key and then press the [F6] key once, the login prompt will appear, and login as root. (It takes about 1 min. to log in.)

  1. Type patch_nvdriver -u [ENTER] .

    After displaying “NVIDIA driver has been updated” message and a reboot request message, press [Enter] to reboot.

  1. Press [Cancel] button before the application launches.

  1. Open a Unix Shell and type su - [ENTER] to be root user

  1. Type patch_install -u [ENTER] . Follow the instructions displayed on the screen.

    NOTE:It may take 3~4 min., please wait.

  1. Verify “Successful” message is displayed, then type reboot [ENTER] to reboot the system.

  1. Open a Unix shell, and type swhwinfo [ENTER]. Confirm that the output does not contain “SP1.1” and will look similar to this: 12HW14.6.V40_H_HS64_G_GTL.

  1. Perform a Restore System State (Reconfig Info Only) to re-install the options previously removed, then restart the system.

  1. Confirm that the following options has been reinstalled.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • CTPerfusion4Neuro

    • VolumeViewer

  1. Execute a test scan to confirm system functionality. Perform a minimum of one scout and 20 images helical or axial scans.
