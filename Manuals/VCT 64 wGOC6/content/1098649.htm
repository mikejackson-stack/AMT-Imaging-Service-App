STEP 14A: Install Table Footswitch Assembly

Labor:1 person; 0.5 man-hour
Tools:Standard Install Tool Kit
9” Level

1. Remove footswitch assembly cover and pedal covers.

2. Attach the footswitch assembly to the table base.

3. Level the footswitch assembly using the three level adjusters. Use a 9 in. level to check the levelness in all directions.

4. Install the ground bus connector/adapter plate.
