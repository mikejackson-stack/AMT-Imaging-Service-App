Z820 RAID Disk Clear Configuration Procedure

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

Only trained service personnel should service the GE CT Scanner.

-

-

2  Procedure

2.1   Exchange the Hard Disk Drives

NOTE:The disk configuration clearing needs to be performed by RAID control card WebBIOS utility.

  1. Replace the System or Image Hard Disk Drive that you want to clear the configuration with one of the Scan Data Disk.

2.2   Clearing the Disk Configuration Information

  1. Shut down the system and recycle the console power.

  1. Press [F10] when HP logo is displayed.

  1. In Hewlett-Packard Setup Utility, select Advanced → Slot Setting.

    Illustration 4:  Hewlett-Packard Setup Utility

  1. In the Slot Settings menu, change the Slot 4 setting to Enabled. And hit F10 key to accept the change.

    (Step Details)

  1. Select File → Save Changes and Exit to exit Hewlett-Packard Setup Utility.

    Illustration 6:  Menu of Hewlett-Packard Setup Utility

  1. When HP logo is displayed, hit Enter key.

    Illustration 7:  HP Logo

  1. When the following RAID information is displayed, press CTL+H.

    Illustration 8:  RAID Information

  1. Click “Start” in Adapter Selection screen.

    (Step Details)

  1. Click “Clear” in the next screen.

    (Step Details)

  1. Click “Yes” in the next screen.

    (Step Details)

  1. The WebBIOS screen will be displayed as follows.

    Illustration 12:  WebBIOS Screen

  1. Click Configuration Wizard from left side menu.

  1. In the Configuration Wizard menu, select Clear Configuration.

    Illustration 13:  Configuration Wizard

  1. In the next screen select Yes.

    Illustration 14:  Configuration Wizard - Confirm Page

  1. Confirm all Scan Data disk shows Unconfigured Good in Physical View screen.

    Illustration 15:  Physical View

  1. Click “Exit” from the menu and select Yes in the next screen.

    Illustration 16:  Exit Application

  1. Reboot the system by pressing CTL+ALT+DEL keys.

2.3   Replace Hard Disk Drive Back to Original

  1. Replace the disk in Scan Data Disk Slot 4 back to the original location (System or Image Disk slot).

3  Finalization

  1. Restore the Host BIOS setting to default. (Advanced → slot settings → slot 4 option ROM Download : Disabled)

    (Step Details)

  1. Replace the hard disk drives to the original location.
