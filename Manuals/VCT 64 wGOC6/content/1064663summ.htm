2  Procedure

2.1   Recon Data Path Test Procedure

  1. Open the Common Service Desktop (CSD) by clicking the Service ICON on the Desktop

    (Step Details)

  1. Click on the Diagnostics tab of the CSD.

    (Step Details)

  1. Find Recon Data Path Test in left navigation column and start the application by clicking on Recon Data Path in the menu.

    (Step Details)

  1. Select the desired test conditions, Loop Count and Protocols, in the Recon Data Path Window.

  1. Click [Run] in the Recon Data Path Window to execute test.

  1. View test results shown in the Result box upon completion of test. No errors should present
