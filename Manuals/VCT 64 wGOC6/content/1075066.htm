HP xw8200 Lower Level FRU Replacement

2  Overview

This procedure describes and illustrates the steps necessary to replace lower level FRUs in the HP xw8200 Host PC.

Lower Level FRUs Supported:

  • CMOS Battery

  • Memory Modules

  • Optical Drive

  • Hard Disk Drives (HDDs)

NOTE:This procedure only applies to HP xw8200 model computer. Swapping components between an HP xw8000, xw8200, or xw8400 is not allowed.

4  Procedure

4.1  Powering Off (Shutting Down) the Operator Console

  1. Select one of the following methods to Power Off the Operator Console:

    • If Applications are running, click [Shut Down] on the desktop and select the Shutdown option.

    • If Applications are down, open a Unix Shell using the Toolchest and type: {ctuser@hostname} halt [Enter].

      The Operator Console monitor will display a “System Halted” message when it is acceptable to power off the Operator Console.

  1. Power OFF the Operator Console at the front panel switch.

  1. Make sure to follow all Lockout/Tagout requirements while performing this procedure. Refer to Equipment Service - Lockout-Tagout-PPE procedure. For added protection, disconnect the Twist-N-Lock Main Power Cable from rear of console.

4.2  Removing the HP xw8200 Host Computer from Operator Console

  1. Remove the front and rear Operator Console covers.

  1. Remove the cable connections to the HP xw8200 Host Computer chassis.

    NOTE:Verify that all cables are labeled and clearly marked. If necessary, add a label for clarity.

  1. Remove the power cord at the rear of the Host Computer chassis.

  1. Remove the four (4) 5mm socket cap mounting screws from the front of the Host Computer, holding the computer to the Operator Console.

  1. Slide the Host Computer forward (out the front of console) and set aside.

4.3  Access Panel Removal

  1. If necessary, unlock the access panel using the keys located in the rear of the workstation (Item 2 in Illustration 1).

    Illustration 1:  Keys in Rear of Workstation

  1. Once unlocked, pull up on the handle and lift off the access panel cover (see Illustration 2).

    Illustration 2:  Access Panel Cover Removal

4.4  Replacing HP xw8200 Host Computer Lower Level FRUs

4.4.1  CMOS Battery Replacement

  1. Follow the steps in HP xw8000 Series CMOS Battery Replacement for replacing CMOS Battery in the HP xw8000 Host Computer. Return to this procedure when finished.

  1. Continue with Reinstalling the HP xw8200 Host Computer in Operator Console of this document.

4.4.2  Memory Module Replacement

  1. Follow the steps in HP xw8200 Memory Module Replacement for replacing Memory Modules in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. Continue with Reinstalling the HP xw8200 Host Computer in Operator Console of this document.

4.4.3  DVD Optical Drive Replacement

  1. Follow the steps in HP xw8200 Optical Drive Replacement for replacing DVD Optical Drive in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. Continue with Reinstalling the HP xw8200 Host Computer in Operator Console of this document.

4.4.4  Hard Disk Drive (HDD) Replacement

  1. Follow the steps in HP xw8200 Hard Drive Replacement for replacing Hard Disk Drive in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. If the OS Disk HDD was replaced, it will be necessary to perform a Load From Cold (LFC) to reinstall Host OS and Application Software. Follow appropriate LFC procedure for the system on which this HDD is installed.

    NOTE:The LFC procedure will erase and recreate the Image Database located on the Image HDDs.

  1. If one of the Image Disk HDDs was replaced, it is necessary to perform the following Image Database Reset procedure to format, partition, and create the logical disk:

    1. If Applications are running, click [Shutdown] on the desktop and select the Reboot option.

      OR

      Open a Terminal Window using the Toolchest and type: {ctuser@hostname} reboot [Enter]

    1. Just after the Operating System finishes loading and before Applications start, click [Cancel] in the Application Startup window to stop Applications from loading.

      NOTE:Applications cannot be running when performing this procedure.

    1. Open a Terminal Window using the Toolchest and type: {ctuser@hostname} su - [Enter]

    1. Type the root password and press [Enter]

    1. Launch the Host Computer Image Database Reset utility, type: [root@hostname] resetImageDB_Linux [Enter].

      NOTE:The Terminal Window updates, warning the User that all images stored in the Image Database on the Host Computer will be deleted. It then asks the User to either type “YES” to continue with the reset of database; or, to abort the script, to close the Terminal Window or press [Enter].

    1. Continue with the Image Database Reset procedure by typing: [root@hostname] YES [Enter].

      NOTE:Must be all capital letters.

    1. The script deletes any images found, partitions the Image Disks, recreates the CT Image Database, and for PET/CT systems it also recreates the PET Image Database.

    1. Add restart applications by typing: [root@hostname] st [Enter].

  1. Continue with Reinstalling the HP xw8200 Host Computer in Operator Console of this document.

4.5  Reinstalling the HP xw8200 Host Computer in Operator Console

  1. Slide the HP xw8200 Host Computer into the Operator Console from the front.

  1. Replace the four (4) 5mm socket cap mounting screws to secure the Host Computer chassis to the Operator Console right side compartment. Torque to 4.6 N-m.

  1. Mount the power cord to the rear of the Host Computer chassis and verify that its power switch on the Host Computer’s Power Supply is turned to the ON position.

  1. Replace the rear cable connections.

4.6  Powering-On the Operator Console

  1. Reconnect the Twist-N-Lock Main Power Cable from rear of console and remove Lockout Tagout protection applied earlier.

  1. Power ON the Operator Console at the console’s front panel switch.

  1. Visually verify that the Host Computer front panel Power LED is illuminated. If not, press the Host Computer front panel power switch to apply power to the Host Computer.

5  Finalization

  1. Take some scans and verify that the image(s) reconstruct and are displayed.

  1. Check that all customer functions are operational. (Auto voice, filming, network, archive).

  1. Reinstall Console Front and Rear Covers.
