2  Overview

This procedure outlines the process required to install and set up the AW Server Client software on Optima CT660 and VCT system.

3  Preliminary Requirements

3.1  Pre-requisite

  1. AW Server should be installed at your site.

  2. Your site should have purchased the "Basic Front End - 3rd Party integration" option. The license key will be used later steps.

3.2  Required Conditions

Only trained service personnel should service the GE CT Scanner.--

4.1  Install AWE Connection Software Option

  1. Install the supplied “AWE connection” software key according to the Install Software Options procedure.

  2. -

4.2  Install AWS Client Software

  1. Record the IP address of AWS Server and the User Name and Password for configuration on CT console in later steps.

    NOTE:The User Name and Password are one of the accounts configured on AW server.

    Consult with the site IT admin for which one assigned to this use.

  2. Open a Unix shell and login as root.

    Type: su-[ENTER]

    Type the root password and press [ENTER].

  3. Type the following:

    launchCTWebBrowserAWS http://xxx.xxx.xxx.xxx

    NOTE:“xxx.xxx.xxx.xxx” is AW server's IP address.

  4. The AW Server Download screen appears.

    Illustration 1:  AW Server Download Screen

  5. Click the “Linux Client” Download button.

  6. Select “Save File”.

    Illustration 2:  Opening AWE - solo-install.rpm

  7. Confirm that “root” is selected as Save in folder and click the “Save” button.

    Illustration 3:  File Name Entering

  8. When download is completed, the following window appears. Close this window.

    Illustration 4:  Download completed window

  9. Close the AW Server Download screen.

  10. Open a Unix shell and login as root.

    Type: su-[ENTER]

    Type the root password and press [ENTER]

  11. Type the following:

    /usr/g/scripts/InstallAWSClientOnConsole

  12. After the Client software installation, the "Configure AW Server Client" window appears automatically.

  13. Input the AW Server IP Address, User Name and Password and click Accept.

    Illustration 5:  Configure AW Server Client

  14. Confirm that “AWS client software installation is finished” message appears in Unix shell.

  15. Reboot the System. Select [Shutdown] on the Desktop and select [Restart], then [OK] on the Attention Window.

  16. Declare AWS on the CT System.

    On CT Console, select [ImageWorks] ->[Network] ->[Remote Hosts], enter the required Parameters and select save.

4.3  Enable Integration

  1. On AW Server, enter service tool, select [Initial configuration] -> [Integration], select Basic front end integration (3rdPartyIntegration) as Integration enabler. Input License key and Click [Apply]. refer to Illustration 6.

    Illustration 6:  Initial configuration

  2. Declare CT on AW Server,

    The CT system must be declared in AW server as a DICOM host. Refer to AW server installation manual for the detailed configuration procedure.

5  Finalization

  1. Open ImageWorks desktop Browser.

    NOTE:Before launching the AW server application, the selected exam and series in the console exam list needs to be transferred to AW server.

  2. Confirm that "Applications" button exists on Image works browser and can launch the AW server from CT Console by clicking the “Application” button.

    Illustration 7:  Desktop Browser

  3. Execute the System State Save to save the AWS Configuration.

6  Appendix

6.1  AWS Client Software Update Procedure

NOTE:The following procedure is required when AW Server is upgraded and new AWS client software needs to be re-installed.

  1. Open a Unix shell.

  2. Login as root and enter the proper password.

    Type: su-[ENTER]

    Type the root password and press [ENTER]

  3. In the Unix shell, type the following:

    /usr/g/scripts/UninstallAWSClientOnConsole

  4. Download and install the new AWS Client software according to Section 4.2.

  5. Shutdown and restart the system.

6.2  How to disable Security Connection Setting

This Connection is Untrusted” window may appear when accessing the Service Tools Launch button in the AW Server Utilities menu for the first time after AW Server Client installation. Disable the security setting according to the follow procedure.

  1. Open AW Server client from Applications menu in the ImageWorks.

  2. On the client, select “Tools” tab to show tools menu.

  3. Click “Launch” to open web browser to access administrative and service tools.

    Illustration 8:  AW Server Utilities

  4. “This Connection is Untrusted” page appears in Mozilla Firefox web browser. Click “I Understand the Risks” link.

    Illustration 9:  Untrusted Connection

  5. On the web browser click “Add Exception...” button.

    Illustration 10:  Untrusted Connection - Add Exception

  6. “Add Security Exception” pop-up window appears. Click the “Confirm Security Exception” button.

    Illustration 11:  Security Exception

The pop up closed and “This Connection is Untrusted” page will not appear from next time.
