3.4  Safety

NOTICE
TO PREVENT DAMAGE TO COMPONENTS WITHIN THE Z820, OBSERVE THE FOLLOWING ESD PRECAUTIONS:

  • WORK ON A STATIC-FREE MAT.

  • WEAR A STATIC STRAP TO ENSURE THAT ANY ACCUMULATED ELECTROSTATIC CHARGE IS DISCHARGED FROM YOUR BODY TO GROUND.

  • CREATE A COMMON GROUND FOR THE EQUIPMENT YOU ARE WORKING ON BY CONNECTING THE STATIC-FREE MAT, STATIC STRAP AND PERIPHERAL UNITS TO THAT PIECE OF EQUIPMENT.

FOR FURTHER INFORMATION REGARDING ESD PROTECTION, REFER TO THE SAFETY CHAPTER IN THIS PUBLICATION.

 

NOTICE
IN ORDER TO MEET EMC REQUIREMENTS, THE CHASSIS MODULES MUST BE PROPERLY INSTALLED AFTER SERVICING. CHECK THAT THE MODULES ARE MOUNTED FIRMLY IN PLACE AND LOCKED DOWN WHERE APPLICABLE.
 

NOTICE
FOLLOW ALL REQUIRED SAFETY AND PPE PROCEDURES CUSTOMARY FOR YOUR ORGANIZATION WHEN WORKING ON THIS PRODUCT.

4  Procedure

4.1  Z820 Computer Removal

  1. Shutdown system. Select one of the following methods to Power OFF the Console:

    • If Applications are up, click on the [Shut Down] button on desktop display and select [Shutdown].

    • If Applications are down, open a Terminal Window. Type: halt , then press [ENTER].

    • When halt command has finished, power Off the console at the front panel switch.

  1. Apply LOTO. See Equipment Service - Lockout-Tagout-PPE procedure.

  1. Remove Keyboard Tabletop, Front and Rear covers from GOC6.6 console.

    Refer to Replacement → Console (GOC6.6) → Console Cover Removal and Installation.

  1. Remove the Z820 computer from the GOC6.6 console chassis.

    Refer to Replacement → Console (GOC6.6) → GOC6.6 VCT Host Computer (Z820) Replacement

4.2  Scan Data HDD Removal

  1. Locate the Scan Data HDD referencing the Illustrations below.

    Illustration 1:  Scan Data Disk Physical Layout

  1. Release the Scan Data HDD Tray by pressing the Tray Removal Lever Release button in the Icy Dock® Bay.

    Illustration 2:  Scan Data Disk Removal

  1. Remove the Scan Data HDD with Tray assembly from Icy Dock® bay using the Tray Removal Lever.

  1. Remove the Scan Data HDD with Tray assembly out the front of the Z820 computer and set aside.

4.3  Scan Data HDD FRU Preparation

  1. The replacement Scan Data HDD does not come with the Icy Dock® Tray. Remove the Scan Data HDD from the original Scan Data HDD with Tray assembly.

  1. Mount the replacement Scan Data HDD onto the original Icy Dock® Tray, reusing the mounting hardware.

    Illustration 3:  Scan Data HDD Mounting in Tray Assembly

4.4  Scan Data HDD Install

  1. Slide the replacement Scan Data HDD with Tray assembly into the Icy Dock® bay in the Z820 computer.

  1. Fully seat the Scan Data HDD in the Icy Dock® bay by closing and latching the Tray Removal Lever.

5  Finalization

  1. Power ON the operator console. Start up sequence stops before application start up.

  1. Run “Reconfig” ,and select “Recreate Scan Disk Array” (2 or more HDD replacement) or “Rebuild Scan Disk Array” (only one HDD replacement), and press “Accept”. Refer to System Configuration for the details.

    NOTE:Rebuild Scan Disk Array takes approximately 20 minutes.

  1. System reboots automatically and stops before application.

  1. Open shell window and type st to start up application.

  1. Perform the Functional Checks → System Scanning Test instructions from the procedure list.

  1. Install console front cover.

    Refer to Replacement → Console (GOC6.6) → Console Cover Removal and Installation Procedure.
