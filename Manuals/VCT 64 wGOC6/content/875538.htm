Telnet T/S Note

If the telnet connection fails:

  • Load the SOL CD, if available, for current version of Software into the VDARC Node and press the VDARC Node reset switch (or re-power VDARC Node if necessary). SOL CD will auto-eject when completed.

  • Verify the VDARC Node is running on the Host Computer using the ifconfig command.

  • Verify the Ethernet cabling between the Host Computer (port C) and VDARC Node.
