Table 8:  Java “raidcmd2” Tool Commands

show diskThe show disk command displays information about the disk drives in the enclosure.
show ldThe show ld command displays information for the logical drive.
show mapThe show map command displays information on all partitions/LDs mapped to specific host channels.
show event The show event command displays the event log.
show enclosureThe show enclosure command displays HSDA enclosure/chassis hardware information, voltages, and fans status.
