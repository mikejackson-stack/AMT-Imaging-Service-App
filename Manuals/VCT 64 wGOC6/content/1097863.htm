2  Overview

This procedure describes and illustrates the steps necessary to replace the Data Acquisition & Image Generation Computer (DIG2).

NOTE:Hardware Configuration control is critical for proper system operation. Mixing of different generations of Recon Computers may result in image quality issues! Example: DIG and VeRB Computers utilize NVidia GPU's. DIG2 and VeRB2 Computers utilize AMD GPU's. Like type GPU's (NVidia or AMD) must be installed in both the DIG and VeRB Computers in the same console. Mixing of first and second generations DIGs and VeRBs is not permitted.

4  Procedure

4.1  Power-Off (Shut Down) the Console

  1. Select one of the following methods to power off the Operator Console:

    • If applications are running, click the Shut Down icon and select Shut Down.

    • If applications are down, open a Unix Shell using the Toolchest. Type: {ctuser@hostname} halt. Press <Enter>.

    The Operator Console monitor will display a System Halted message when it is acceptable to power off the Operator Console.

  1. Power OFF the Operator Console at the front panel switch (Illustration 2).

    Illustration 2:  Console Power Switch

  1. Perform prescribed Lockout/Tagout procedure. For added protection, disconnect the Twist-N-Lock Main Power Cable from the rear of the console.

4.2  Remove DIG2 Computer

  1. Remove the front and rear Operator Console Covers per prescribed cover removal procedure.

  1. Remove the cable connections at the rear of the DIG2 Computer chassis being replaced.

    NOTE:Verify that all cables are labeled and clearly marked. If necessary, add a label for clarity

  1. Remove the power cord at the rear of the DIG2 Computer chassis.

  1. Remove the four (4) 5mm socket cap screws and washers from the front of the DIG2 Computer chassis, holding the chassis to the Operator Console rack.

    Illustration 3:  DIG2 Computer Mounting

  1. Slide the DIG2 Computer chassis forward (out the front of console) and set aside.

    Refer to Equipment Service - Console.

4.3  Install Replacement DIG2 Computer

  1. Slide the replacement DIG2 Computer into the Operator Console from the front.

  1. Replace the four (4) 5mm socket cap screws and washers to secure the DIG2 Computer chassis to the Operator Console rack. Torque to 4.6 N-m.

  1. Mount the power cord to the rear of the DIG2 Computer chassis and verify that its power supply switch is turned to the ON position.

  1. Replace the rear cable connection(s).

    Illustration 4:  VDIG2 Cable Connections & Destination

    For cabling details, refer to the appropriate interconnect located in the System Diagrams folder of this service methods publication.

4.4  Power-On the Operator Console

  1. Reconnect the Twist-N-Lock Main Power Cable from rear of console and remove Lockout Tagout protection applied earlier.

  1. Power ON the Operator Console at the console front panel switch.

  1. Do not allow Applications to start. During boot-up, cancel Application Startup when the CT Software Auto-start pop-up window appears.

4.5  Verify Replacement DIG2 Computer Operation

  1. Verify that the DIG2 Computer has powered up and is not displaying or sounding any POST Errors.

    NOTE:See DIG2 Troubleshooting procedure if any errors appear.

  1. In order to assure proper operation of the DIG2 computer perform the System Configuration procedure located in the applicable Align, Setup, Cals → Console folder of this service methods publication.

    1. Do not allow Applications to start. During boot-up, cancel Application Startup when the CT Software Auto-start pop-up window appears.

    1. Open a Terminal window and log on as Root.

    1. Type: reconfig[Enter]

    1. Click [Accept] Tab to start the reconfig process.

    NOTE:No changes are required in the System, Preferences, Hardware, or Network settings. The utility needs to be executed in order for the automated scripts to run. During the reconfig process the DHCP Server running on the Host Computer is reconfigured to support the new DIG2 Computer Ethernet MAC addresses.

    NOTE:Until the System Configuration procedure is performed, the Linux OS bootup text will display an error message when the DIG2 computer attempts to mount its NFS on the Host Computer. Ignore the error message.

5  Finalization

  1. After completing the System Configuration procedure, perform a complete shutdown of the Operator Console and restart the system.

  1. Refer to System Scanning Tests in the Functional Checks chapter of this manual to confirm proper operation.

  1. Reinstall Console Front and Rear Covers.
