GSCB Replacement

3  Procedure

3.1   GSCB Removal

  1. Select one of the following methods to Power OFF the Console:

    1. If Applications are up, click on the [Shut Down] button on desktop display and select [Shutdown].

    1. If Applications are down, open a Terminal Window. Type: halt , then press <Enter>.

    (Step Details)

  1. When halt command has finished, power Off the console at the front panel switch.

  1. Apply LOTO for console. For procedures, see Equipment Service - Lockout-Tagout-PPE.

  1. Remove the console rear chassis cover.

    (Step Details)

  1. Disconnect the GSCB cable assembly from the host computer, GSCB Power Module and the TGP Gantry Communication cable located at the rear of the console.

    Illustration 2:  GSCB Cable Connection Locations

  1. Remove the Keyboard from the GSCB Keyboard Mounting Plate and set aside.

    (Step Details)

3.2   Replacement GSCB Preparation

  1. Transfer Keyboard Mounting Plate to new GSCB.

    Illustration 3:  GSCB Keyboard Mounting Plate

    (Step Details)

  1. Remove the four (4) Flathead Phillips screws to remove the Keyboard Mounting Plate from the original GSCB Assembly and transfer the mounting plate to the replacement GSCB using the same four (4) screws removed from the original assembly.

  1. Open Service Access Panel on the rear of the GSCB and set configuration switches as necessary. See GSCB Configuration in the GSCB Configuration and Intercom Setup procedure for necessary configuration settings.

    (Step Details)

3.3   GSCB Install

  1. Mount the Keyboard to the replacement GSCB Keyboard Mounting Plate removed earlier.

  1. Place the replacement GSCB assembly on the console top and route the GSCB Cable to the rear of the console.

  1. Reconnect all cables removed earlier.

    Illustration 4:  GSCB Cable Connections

    ItemDescriptionDestination
    1GSCB - Black DB-9 (Female) ConnectorGSCB Power Module
    2GSCB - Gray DB-9 (Female) ConnectorHost Computer Serial Port (System Board)
    3GSCB - Green Audio ConnectorHost Computer Audio Out (Green)
    4GSCB - Blue Audio ConnectorHost Computer Audio In (Blue)
    5GSCB - USB ConnectorNOT Used
    6GSCB - Black DB-9 (Male) ConnectorDIP Serial Port
    7GSCB - Black DB-25 (Male) ConnectorTGP Gantry Cable

    (Step Details)

  1. Remove LOTO on console. For procedures, see Equipment Service - Lockout-Tagout-PPE.

    (Step Details)

3.4   Functional Checks, Alignments and Setups

  1. Power On console.

  1. Perform GSCB Intercom Setup procedure. See GSCB Configuration and Intercom Setup procedure for System Intercom setup.

4  Finalization

  1. Perform the Functional Checks → GSCB and ICOM Functional Checks instructions from the procedure list.

  1. Install console rear cover. Refer to Replacement → Console (GOC6.6) → Console Cover Removal and Installation Procedure.

  1. Perform the Functional Checks → System Scanning Test instructions from the procedure list.
