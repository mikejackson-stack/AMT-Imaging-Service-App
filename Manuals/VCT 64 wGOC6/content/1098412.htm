STEP 3B: Unload Console and Control Room Lean Cart

Labor:1 person; 0.25 man-hour
Tools:

  1. Supervise the delivery team to unload the console and move it to the control room.

  2. Unpack the console.

  3. Unload the lean cart that contains the console peripherals and move it to the control room. If the system is not lean packed, then unload all boxes containing console components.

  4. Visually inspect the system components for damages.
