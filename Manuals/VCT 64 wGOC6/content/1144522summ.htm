2  Procedure

2.1   Check software version currently installed

  1. Open a Unix shell.

  1. Type swhwinfo[ENTER]

    (Step Details)

2.2   Service Pack 1.0 Installation

  1. Uninstall “Denta Scan” Option if it is installed.

  1. Open a Unix shell.

  1. If Application software is up, perform the following command.

    (Step Details)

  1. In the Unix Shell, become root:

    1. {ctuser@hostname} su -

    1. Password: <password>

  1. Insert the Service Pack CD into DVD drive in the host.

  1. Perform the following steps to install the Service Pack CD:

    1. [root@hostname]# patch_install -c

    1. Input y to install Service Pack.

    1. Confirm the “Update ******* has been installed successfully” message.

  1. Check Software Version:

    1. Type: [root@hostname]# swhwinfo[ENTER]

    1. System should reply with a response similar to the following:

      (Step Details)

  1. Remove the Service Pack CD from Host DVD drive.

  1. Perform the following post install steps:

    (Step Details)

  1. After the application is up, install “Denta Scan” Option if it was installed.

2.3   How to uninstall Service Pack 1.0

  1. Uninstall “Denta Scan” Option if it is installed.

  1. Open a Unix shell.

  1. If Application software is up, perform the following command.

    (Step Details)

  1. In the Unix Shell, become root:

    1. {ctuser@hostname} su -

    1. Password: <password>

  1. Perform the following steps to uninstall the Service Pack CD:

    1. [root@hostname]# patch_install -u

    1. Input y to uninstall Service Pack.

  1. Perform the following post uninstall steps:

    (Step Details)

  1. After the application is up, install “Denta Scan” Option if it was installed.
