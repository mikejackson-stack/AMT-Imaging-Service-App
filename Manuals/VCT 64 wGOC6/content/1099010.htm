STEP E13: Install and Verify Customer Imaging Options

Labor:1 person; 2 hours
Tools:

  1. Verify network physical requirements.

  2. Gather network identity information to declare the CT system on the hospital network, IP Addresses, Port Number, etc.

  3. From the Install Utility Window, click the [Config] button to enter the CT Software Configuration routine.

  4. Press the [Network] button and configure the network settings.

  5. Initiate a system reconfiguration.

  6. Declare remote hosts on the CT system.

  7. Declare the scanner on any remote systems as needed.

  8. Complete DICOM HIS/RIS setup, as appropriate.

  9. Load and configure the ConnectPRO software option on the CT system, if not already done.
