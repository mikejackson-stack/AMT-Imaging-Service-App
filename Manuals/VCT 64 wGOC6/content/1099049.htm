STEP E15: Administrator Account Configuration in EA3 and Save System State

STEP E15-1 Administrator Account Configuration in EA3

Labor:1 person; 0.5 man-hour
Tools:

NOTICE
This is a mandatory step. If skipped, the customer will not be able to set-up the Dose Check Administrator and Alert Value Exceeding Roles in the Dose Check feature. The customer will be mandated to set-up the Dose Check Administrator role to set Notification Values, Alert Values, User Accounts, etc. Otherwise, they may not be able to perform scans that exceed factory pre-set Alert Value. The customer is required to designate a person for this role so the step can be completed. Keep in mind that the FE should set up ONLY the Administrator role, and should NOT setup the Dose Check Administrator or any other accounts.
 

1. Initial Setup of EA3 Administrator Account using EA3 Admin Browser.

STEP E15-2 Save System State

Labor:1 person; 0.25 man-hour
Tools:

  1. Insert a DVD into the DVD drive.

  2. Select [UTILITIES] and [SAVE SYSTEM STATE] from the Service Desktop.

  3. [Save] System State - [ALL] parameters, to [FILE].

  4. Remove the DVD from the hard drive.
