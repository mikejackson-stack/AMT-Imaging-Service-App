4  Procedure

NOTICE
For Non-Generator Replacement Service Procedures, perform Save Generator Runtime Parameters. (See Save Restore Generator Runtime Parameters)
 

  1. Select [DIAGNOSTICS] from Service Desktop.

  1. Select [GENERATOR TOOL - JEDI], or [X-RAY GENERATION], [GENERATOR TOOL - JEDI].

  1. Click [INITIALIZE DATABASE].

  1. Click [OK] in Attention window.

  1. Click [OK] in Initialize Database window.

5  Finalization

  1. Restore Generator Runtime Parameters (See Save Restore Generator Runtime Parameters)

    NOTE:If Save Generator Runtime Parameters failed, perform Reset TnT, Filament Calibration.

  1. Click [DISMISS] in Generator Tool - JEDI window.

  1. Save System State.
