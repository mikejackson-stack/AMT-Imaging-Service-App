ethtool T/S Note

For an Ethernet cabling connection issue, use the command ‘ethtool  -p  eth#’ (where # represents the Ethernet address) as root on the VDARC Node or VIG Node to determine if the Ethernet cable is correctly connected from the VDARC Node to the VIG Node. The port will blink or flash when activated and <Ctrl+C> will stop the test. This command can be used on the Host, VDARC Node and the VIG Node(s).

Example for VDARC (Jarrell and Westville) Ethernet cable:

[root@darc]  ethtool  -p  eth2   (<Ctrl+C> to stop flashing Jarrell Ethernet port LED)

[root@darc]  ethtool  -p  eth4   (<Ctrl+C> to stop flashing Westville Ethernet port LED)

Example for VIG Node Ethernet cable:

[root@ig1]  ethtool  -p  eth0   (<Ctrl+C> to stop the flashing Ethernet port LED)

[root@ig2]  ethtool  -p  eth0   (<Ctrl+C> to stop the flashing Ethernet port LED)

[root@ig3]  ethtool  -p  eth0   (<Ctrl+C> to stop the flashing Ethernet port LED)
