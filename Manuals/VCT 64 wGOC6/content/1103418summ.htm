System Configuration - RIO

1  Required Conditions

ConditionReferenceEffectivity

The CT System hardware must be in good working order.

-

-

Only trained service personnel should service the GE CT Scanner.

-

-

2  Procedure

  1. Shut down Applications from the Common Service Desktop, Utilities Tab.

  1. Open a Terminal Window, and log on as root:

    1. Type: {ctuser@hostname} su -[ENTER]

    1. Type the root password and press [ENTER]

  1. Launch the Configuration utility:

    (Step Details)

  1. The CT Software Install Utility Window will appear.

    (Step Details)

  1. Click [CONFIG].

    (Step Details)

  1. Configure System Settings

    1. Hospital Name (Illustration 2, item a) - Configures the name that will show up on images produced by this scanner. Example: ST MARY'S HOSPITAL

    1. Service ID (Illustration 2, item b) - Issued by the Service organization. Example: 262785CT2 (no spaces, 14 character limitation)

    1. Select the Time Zone for the site.

    1. Next Patient Exam Number - Customer selected. At initial system installation, Type: 1.

    1. Next Diagnostic Exam # - Configures the next Exam number the scan user interface will use. Customer Selected. At initial system installation, Type: 1.

    1. Mobile System - Select to tell the software if this CT is in a mobile environment or not.

    1. Recreate Scan Disk Array - Determines whether the Scan Array will be recreated during reconfiguration. Used only after Scom Disk replacement or multiple Hard Disk Drive failures. Destructive ! Recreates logical disk of the array.

    1. Energy Saving - Select to tell the software if Energy Saving feature is available.

  1. Click [PREFERENCES] to display the Preferences Configuration window. (See Illustration 3.)

    (Step Details)

  1. Configure Preferences Settings.

    1. Doctors Title - Enter the title for the Doctor (e.g., radiologist.)

    1. Units for Patient Weight - Tells the software whether pounds or kilograms are being used.

    1. Language - Configures the language to be displayed on the Application screens.

    1. AutoVoice Language - Configures the language heard in the scan room.

    1. Keyboard Selection - Configures the language specific keyboard character set.

    1. Date Format - Configures the format in which the date will be displayed on the images.

    1. Time Format - Configures the format in which the time will be displayed on the images.

    1. Modified In Room Start - Be sure "Off" is selected, unless the site is in Japan, in which case, this feature should be "On".

    1. HIPAA Present - Be sure “Off” is selected unless told differently.

    1. Select the site preferred Dose Information Display option for the site to use in monitoring calculated Patient Dose. Use the default selection unless told differently. (This setting is available at software version 10HW10.2.)

      (Step Details)

    1. Dose Record - Configures support for DICOM Dose SR Record option for saving dose information with study. Default is “OFF”. The dose information is saved in a DICOM structured report. The DICOM standard defines a new DICOM X-Ray Radiation SR SOP class which the other systems must support. The Dose SR feature saves an exam's dose information in this format.

      (Step Details)

    1. Preferred Fast Cal KV - Configures the preferred kV that the Fast Cal Routine will calibrate (80, 100, 120, 140 in the Selected Preferred Fast Cal KV field). The default selections are 80, 100, 120, and 140. All defaulted ON for VCT systems. All defaulted On for CT750 HD systems.

    1. Target Noise Index Table - Be sure Table 2 is selected.

    1. Gantry Layout - Configures the preference for Patient loading. Choose correct orientation depending on site specific Gantry layout.

    1. Flip and Rotate - Configures the preference for allowing the Flip and Rotate feature to be turn on in the User Interface on the (Left) SCAN Monitor. This preference allows the Customer to apply custom orientation changes based on Exam Type and Reconstruction methods on DICOM images that will be transferred to PACS and related systems.

      (Step Details)

    1. Emergency Patient Mode - Select ON if customer prefers this feature.

  1. Click [HARDWARE] to display the HD Hardware Settings Screen. (See Illustration 4.)

    (Step Details)

  1. Configure Hardware Settings.

    1. Gantry Type - Indicates the type of Gantry that is installed.

    1. Tube Type - Indicates the type of X-Ray Tube that is installed.

    1. DAS Type - Indicates the type of DAS that is installed.

    1. Detector Type - Indicates the type of detector that is installed.

    1. Table Type - Select the table type: VT1700V, VT2000 or NP Lite. The type of table shipped can be determined by reviewing the order information.

    1. PDU Type - Indicates the type of PDU that is installed.

    1. Scan Recon Hardware - Indicates console type.

    1. Number of IGs - Indicates the number of IGs installed.

  1. Click [NETWORK] to display the Network Settings Screen. (See Illustration 5.)

    (Step Details)

  1. Configure Network Settings.

    1. Enter the Suite Name. The Suite name must start with a letter, followed by three (3) alpha-numeric characters. Total must be four characters long. The name of the OC interface will be <Suite Name> _OC, within the scanner subnet. Typically, you should use su01 or ct01 (“su” and “ct” must be lowercase), unless the customer prefers a different suite name.

    1. Enter the hospital provided Station Name.

      (Step Details)

    1. Enter the hospital provided Host Name. The Host Name identifies the network hostname and AE Title of the CT system to the hospital’s network. The Host Name:

      (Step Details)

    1. Enter the hospital provided IP Address for the system

    1. Enter the hospital provided Net Mask Address for the system.

    1. Enter the hospital provided Broadcast Address for the system.

    1. Enter the hospital provided Default Gateway Address for the system.

    1. Enable TCP Segmentation Offload - Default YES. If network transfers to certain PACS systems are slow, this can be set to No and may increase the transfer speed.

    1. Enable AW DirectConnect if option provided with system. Reviewing the order information to see if option is included.

      (Step Details)

    1. Enter the hospital provided NIS Domain Name and IP Address for the system, if NIS is utilized on site.

    1. Enable Network Time Protocol, if so instructed by hospital. Hospital must have an NTP Server available and the scanner should be synchronized with the Hospital’s time.

    1. Enable Change DARC Subnet, if so instructed by hospital.

      (Step Details)

  1. Review all screens to be sure the information entered is correct before proceeding to the next step.

  1. Click [ACCEPT] to accept the changes made. (See Illustration 6.)

    (Step Details)

  1. When the configuration changes are complete, the system displays a prompt to reboot.

  1. Click [YES]. (See Illustration 8.)

    (Step Details)

  1. The system will automatically log in as ctuser after the reboot. Select [OK] on the Autostart Disabled popup message.

  1. Open a Terminal Window. Type: {ctuser@hostname} st[ENTER]

  1. Remember, if necessary perform System State Save Restore whenever the “reconfig” script is executed.
