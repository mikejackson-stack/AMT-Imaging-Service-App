2  Overview

This describes the procedure to install and uninstall SP1.0 for 12HW14.6 (Epsilon).

Last revised:May 17, 2013

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

4  Procedure

4.1  Preparation for Inatallation

  1. Check the current software version by the following command.

    {ctuser@hostname}swhwinfo

    Example: 12HW14.6_V40_H_HS64_G_GTL

    If the output contains SP1-0-1, SP1.0 is already installed. No need to install it.

    If the output is not equal to 12HW14.6, system software version is different, do not execute the procedure.

  1. Check Exam Split Type. (Skip this step if SP1.0 Installation is done with 12HW14.6 LFC at the same time.)

    Type swokinstall -p

    If Exam Split option is displayed, execute the following

    Type ls -l ~ctuser/ves/.hesMode

    If there is .hesMode file, it’s HES mode.

    If not, It’s VES mode.

    This will be used at reinstall option.

4.2  Service Pack 1.0 Installation

NOTE:For the options to function correctly, it is necessary to uninstall the options listed below before installing SP1.0, then re-installing them after SP1.0 Installation.

  1. Perform Save System State.

  1. Uninstall the following options (if installed) using the Install Options Menu in the Configuration Tab in Common Service Desktop.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • VolumeViewer

  1. Insert the Service Pack 1.0 CD-ROM into the Host DVD drive.

  1. Open a Unix Shell.

  1. Shutdown Application (if up). Type cleanMon [ENTER] .

  1. Install SP1. Type su - [ENTER] to be root and type patch_install -c [ENTER] . Follow the instructions displayed on the screen.

  1. Verify successful installation. Type swhwinfo[ENTER].

    Output should contain “SP1” and will look similar to this: 12HW14.6SP1-0-1.V40_H_HS64_G_GTL

  1. Start Application. Option another Unix Shell and type st [ENTER] .

  1. Perform Restore System State (Reconfig Info Only) to re-install the options previously removed, then restart the system.

  1. Confirm that the following options has been reinstalled.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • VolumeViewer

  1. Execute a test scan to confirm system functionality. Perform a minimum of one scout and 20 images helical or axial scans.

4.3  Service Pack 1.0 Uninstallation

NOTE:For the options to function correctly, it is necessary to uninstall the options listed below before un-installing SP1.0, then re-installing them after SP1.0 Un-installation.

  1. Perform Save System State.

  1. Check Exam Split Type.

    Type swokinstall -p

    If Exam Split option is displayed, execute the following

    Type ls -l ~ctuser/ves/.hesMode

    If there is .hesMode file, it’s HES mode.

    If not, It’s VES mode.

    This will be used at reinstall option.

  1. Uninstall the following options (if installed) using the Install Options Menu in the Configuration Tab in Common Service Desktop.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • VolumeViewer

  1. Insert Service Pack 1.0 CD-ROM into the Host DVD drive.

  1. Open a Unix Shell.

  1. Shutdown Application (if up). Type cleanMon [ENTER]

  1. Install SP1. Type su - [ENTER] to be root and type patch_install -u [ENTER]. Follow the instructions displayed on the screen.

  1. Verify successful installation. Type swhwinfo [ENTER] .

    Output should not contain “SP1” and will look similar to this: 12HW14.6_V40_H_HS64_G_GTL

  1. Start Application. Option another Unix Shell and type st [ENTER] .

  1. Perform a Restore System State (Reconfig Info Only) to re-install the options previously removed, then restart the system.

  1. Confirm that the following options has been reinstalled.

    • AdvVesselAnalysis

    • AutoBone

    • CardEP

    • CardIQPlus

    • CTColonoPro

    • CTPerfusion4

    • VolumeViewer

  1. Execute a test scan to confirm system functionality. Perform a minimum of one scout and 20 images helical or axial scans.
