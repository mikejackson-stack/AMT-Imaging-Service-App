3  Procedure

3.1   Power-Off (Shut Down) the Console

  1. Select one of the following methods to power off the Operator Console:

    (Step Details)

  1. Power OFF the Operator Console at the front panel switch. (See Illustration 2.)

    (Step Details)

3.2   Removing Defective USB Connector on Upper Bulkhead Panel

  1. Remove Console Rear Cover and set aside.

  1. Disconnect cables connected to the defective USB Connector on the Upper Bulkhead Panel.

    (Step Details)

  1. Uninstall USB Connector from the Upper Bulkhead Panel by removing the two (2) 3mm socket cap mounting screws holding the connector to the panel.

    (Step Details)

  1. Remove the USB Connector from the Upper Bulkhead Panel.

3.3   Install New USB Connector in Upper Bulkhead Panel

  1. Install the USB Connector on the Upper Bulkhead Panel using the two (2) 3mm socket cap mounting screws removed earlier. Torque to 0.5 N-m.

  1. Reconnect the USB Cables to the Upper Bulkhead Panel.

    (Step Details)

3.4   Verify Replacement Connector

  1. Apply power to the console using the operator console power switch.

  1. Test the replacement Upper Bulkhead Panel connector by verifying that communications and signal paths have been restored. Verify that the system boots properly and that Keyboard, Mouse, Trackball and Bar Code Reader (if so equipped) function properly.

    (Step Details)
