STEP 5A: Install Operator Console, Peripherals, Hard Drives, etc.

Labor:1 person; 1 man-hour
Tools:Socket Set
Allen Wrench Set

1. Unpack the console.

2. Remove the console covers.

3. Adjust table top height and position the console.

4. Attach keyboard table top.

5. Position the monitors, media tower, keyboard, mouse, SCIM, hard drives, and other console peripherals.

6. Make all cable connections between console components.
