3.1   Replacement of Scan Data Disk Array (JBOD) Chassis (without Hard Disk Drives)

The following procedures are specifically created for the original JBOD Chassis (5114536-20), the procedural step for replacing the JBOD Chassis using the alternative (5114536-30) is the same except for small changes noted in the procedures below. Note: if upgrading from a 5114536–20 to a 5114536–30 JBOD chassis, disk drive locations will be different. See Section 4.6 for details.

3.1.1  Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, select the Shut Down icon and then select [Shutdown].

    NOTICE
    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.x) have corrected this issue.
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      (Step Details)

  1. The Operator Console monitor will display a System halted message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch. (Refer to Illustration 1.)

    (Step Details)

3.1.2  Remove the Old Scan Data Disk Array (JBOD) Chassis

  1. Remove the front and rear Operator Console cover.

  1. Remove all rear cable connection to the Disk Array (JBOD) Chassis. Verify each cable is present and clearly marked, if necessary add a label for clarity.

  1. Remove the front cover of the Disk Array (JBOD) Chassis.

    (Step Details)

  1. Remove and retain the four (4) front mounting screws.

NOTICE
Failure to return the disks to their proper location will result in potential lost patient raw data.
 

  1. Remove each disk from the JBOD Chassis individually, and clearly mark them so that they can be returned to the same slot location in the new replacement JBOD.

    1. Remove each disk or empty sled as shown in Illustration 3.

    1. Label each disk as shown in Illustration 4.

      (Step Details)

  1. Slide out the Disk Array (JBOD) Chassis.

3.1.3  Install the New Disk Array (JBOD) Chassis

Install the replacement Disk Array (JBOD) Chassis in the Operator Console.

  1. Slide the Disk Array (JBOD) Chassis into the Operator Console.

NOTICE
Failure to return the disks to their proper location will result in potential lost patient raw data.
 

  1. Return each Disk or empty sled to its proper position inside the Disk Array (JBOD) chassis.

  1. Replace the four (4) front mounting screws on the front of the Disk Array (JBOD) Chassis.

  1. Replace the front cover screen to the Disk Array (JBOD) Chassis.

    (Step Details)

  1. Replace all rear cable connections to the Disk Array (JBOD) Chassis.

    (Step Details)

3.1.4  Test the Disk Array

  1. Perform all Disk Array RAID Tests per Disk Array RAID Testing

  1. Continue with Sections 4.4, 4.5 and Finalization.

    (Step Details)

3.2.4  Power ON the Console

  1. Power ON the Operator Console at the front switch.

  1. At the VDARC Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3-10 seconds) to apply power to the VDARC Node.

  1. At the VIG Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3-10 seconds) to apply power to the VIG Node.

  1. At the Disk Array (JBOD) verify two green LEDs at rear panel is on. If not, press the two power switches at rear panel to apply power to the Disk Array (JBOD).

  1. Stop Applications from auto-starting at the 5 second Warning Message.

  1. Continue with Sections 4.4, 4.5 and Finalization.

3.4   Start Applications

  1. {ctuser@hostname}  st

  1. If Application software fails with a halt due tot the Disk Array:

    1. Turn Off power at the front switch on the Operator Console.

    1. Wait one minute for the Disk Array to settle.

    1. Turn On power at the front switch on the Operator Console.

    1. Do Not allow CT Application Software to start-up.

    1. View the gesyslog. Locate the startup time of Application software that just halted. Look for a message related to gre-raid. If the Disk Array is the problem, a message will be present identifying a failure with the gre-raid (Disk Array).

    (Step Details)

3.6   Upgrade of JBOD Assembly (5114536 to 5114536-40, Entire JBOD Assembly with Hard Disk Drive Swap)

Due to part obsolescence, the JBOD Assembly (5114536 - Scan Data Disk Array) is no longer manufactured. A new supplier has been identified and a new JBOD Assembly has been cut into forward production for the GOC5 Operator Consoles. The new JBOD Assembly (5114536-40) functions the same as the original JBOD, using the same Hard Disk Drives, but has significant hardware changes. In the event the original JBOD Chassis FRU (5114536-20) is not longer available, the JBOD Assembly will need to be upgraded to the alternative version.
