How to Setup Low Signal correction for SmartPrep

(Click Here for Summary Version)

Required PersonsPreliminary ReqsProcedureFinalization

2  Overview

On LightSpeed VCT with 11HW12.5, 12HW14.6, 13HW31.8 and Optima CT660 with 12HW28.8, there is a possibility to have streak artifact on monitoring phase images of the SmartPrep in case of DAS count/signal is low.

This procedure describes how to set up low signal correction for the SmartPrep monitoring phase images.

4  Procedure

4.1  For LightSpeed VCT with 11HW12.5 and 12HW14.6

Application software should be in shutdown.

  1. Open a Unix shell, and type the following.

    1. cd/usr/g/config <ENTER>

    1. cp prep_flags.cfg.vct prep_flags.cfg.vct.org <ENTER>

    1. chmod +w prep_flags.cfg.vct <ENTER>

    1. nedit prep_flags.cfg.vct <ENTER>

  1. Change the value of the following line to 1.

    (das_underange_corr_on=0 → das_underange_corr_on=1)

    Illustration 2:  nedit Window

  1. Click [File], and click [SAVE], then select [Exit] to close the window.

4.2  For LightSpeed VCT with 13HW31.8 and Optima CT660 with 12HW28.8

Application software should be in shutdown.

NOTE:In case of Optima CT660 with 12Hw28.8, the file name is prep_flags.cfg.cj64.

  1. Open a Unix shell, and type the following.

    1. cd/usr/g/config <ENTER>

    1. cp prep_flags.cfg.vct prep_flags.cfg.org <ENTER>

    1. chmod +w prep_flags.cfg.vct <ENTER>

    1. xedit prep_flags.cfg.vct <ENTER>

  1. Change the value of the following line to 1.

    (das_underange_corr_on=0 → das_underange_corr_on=1)

    Illustration 3:  xedit Window

  1. Click [SAVE], and select [Quit] to close the window.
