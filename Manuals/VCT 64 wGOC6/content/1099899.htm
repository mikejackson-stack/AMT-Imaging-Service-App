Introduction and How To Use This Manual

1  Overview

The format of this installation manual contains features that provide workflow guidance and improved usability. These enhancement features enable the manual to be a highly effective instruction for the installer, regardless of knowledge or experience level. A description of these features and how to use them are described in this introduction section.

To experience the full functionality of this manual, it is best used in its electronic form. This allows the installer to take advantage of quick navigation between “web-like” instruction pages, direct links to external web pages where applicable, and videos that expand on the instructions or show techniques. Most of the features can still be experienced in the printed form, however it requires the installer to navigate between pages of the manual.

2  Manual Structure - Level of Detail

This manual is structured in three major sections, with increasing level of detail through each section. This allows the installer to use the correct level of instruction that matches his/her knowledge, experience, and expertise.

2.1  Level 1 - Installation Work Flow

This level has two pages, a Mechanical Work Flow and an Electrical Work Flow, that serve several purposes. It highlights the major process steps with the least amount of instructional detail, it provides the standard work to complete an installation in the most efficient manner, and it functions as the starting point or “home page” to navigate to the rest of the manual. Expert installers (more than 20 installs) will find this section useful as a high-level guide, a visual management tool, and to quickly find needed information.

2.1.1  Major Process Steps:

The Installation Work Flow is a two-page summary of the entire manual. The mechanical installation is highlighted in 32 major process steps, while the electrical installation is highlighted in 21 major process steps.

2.1.2  Standard Work:

The Work Flow illustrates the best-known method to complete the installation. This includes the standard time that each task should be started under normal conditions (no install delays or defects), it shows the order in which to complete the installation steps, and it illustrates how the installers should work - either in parallel on separate steps, or together on the same step when required.

2.1.3  Navigation:

In the electronic form, the Work Flow functions as the access point for the rest of the installation manual. From this page, the installer can quickly navigate to the Level 2 detail for each process step. The Mechanical Work Flow is the “home page”, while the Electrical Work Flow is accessed from the bottom of the Mechanical Work Flow page.

2.2  Level 2 - Installation Summary For Experienced Installers

This section of the manual provides a level of detail that is suitable for experienced installers (more than 5 installs). For each major process step, the key tasks are stated but without amplifying instructions. This section is designed to highlight important specifications and information, while eliminating extraneous details that can cause clutter and confusion.

The section is designed to be easy-to-read, with each page constructed the same way:

  • Title of the major process step

  • Manpower requirements and Tools & Supplies

  • Simplified instructions with corresponding pictures

  • Links to further information

“Show Me”

“Tell Me More”

“Show Me” - When applicable, there are direct links to brief videos that show amplifying instructions, best practice methods or techniques, and pitfalls to watch out for. NOTE: Videos are not available for every step.

“Tell Me More” - For every process step, this is a direct link to the corresponding process step in the Level 3 detail.

2.3  Level 3 - Full Detail and Instructional Content

This section of the manual contains the entire content of instructions. It includes step-by-step tasks, with amplifying instructions, all warnings, extraneous details, all photos, all specifications, and the appendices.

This section is suitable for inexperienced installers. Occasionally, experienced installers will need to reference this section to locate a description for how to perform a task that they forgot. That information will be easy to locate using the navigational features of the manual.
