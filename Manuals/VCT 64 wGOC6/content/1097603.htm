4  Procedure

4.1  Power Off (Shutdown) GOC6.5 Console

  1. Select one of the following methods to power off the Operator Console:

    1. If Applications are running, click on the [Shut Down] icon and select [Shutdown].

    1. If Applications are down, open a Unix Shell using the Toolchest. Type:

      {ctuser@hostname} halt[ENTER]

      The Operator Console monitor will display a System Halted message when it is acceptable to power off the Operator Console.

  1. Power OFF the Operator Console at the front panel switch (Illustration 1).

    Illustration 1:  Console Power Switch

  1. Perform Lockout / Tagout as described in Safety - Equipment Service - Lockout / Tagout / PPE on the Safety menu of the service publication. For added protection, disconnect the Twist-N-Lock Main Power Cable from rear of console.

4.2  Remove GOC6.5 Console Covers

  1. Move the console away from the wall to allow clear access around the console.

  1. Remove console’s front and rear covers and set aside.

    NOTE:Refer to Console Cover Removal and Installation procedure located on the Replacement > Console menu of the service publication for more details.

  1. Remove the console’s Keyboard Tabletop and set aside. This will allow better access to the console’s computer rack.

4.3  SCSI Card Option Installation (Host Computer - HP Z400)

  1. Remove the Host Computer from the GOC6.5 console.

    1. Unplug the power cord to the rear of the Host Computer chassis.

    1. Remove the cable connections to the HP Z400 Host Computer chassis.

      NOTE:Verify that all cables are labeled and clearly marked. If necessary, add a label for clarity.

    1. Loosen the two (2) cap screws on the retaining bracket at the lower right front of the Host Computer chassis, which holds the Host Computer in place in the Operator Console right side compartment.

      Illustration 2:  HP Z400 Console Mounting

    1. Slide the Host Computer forward (out the front of console) and set aside.

  1. Install SCSI Controller Card in Host Computer (HP Z400)

    1. Remove the Host Computer's access panel.

      Illustration 3:  Access Panel Cover Removal

    1. Lay the Host Computer on its side with the system board facing up.

    1. Unlatch the Retention Clamp that holds the Expansion Cards in place.

      Illustration 4:  Expansion Card Retention Clamp Removal

    1. Insert the SCSI Controller Card in Slot 1 of the Host Computer. Make certain the SCSI Card is fully seated in the motherboard.

      Illustration 5:  SCSI Controller Card Location

    1. Latch the Retention Clamp that holds the Expansion Cards in place.

  1. Reinstall Host Computer (HP Z400) in GOC6.5 Console.

    1. Slide the HP Z400 Host Computer into the Operator Console from the front.

    1. Hand tighten the two (2) cap screws on the retaining bracket to secure the Host Computer chassis to the Operator Console right side compartment.

    1. Replace the rear cable connections.

      Illustration 6:  HP Z400 Cable Connections

      ConnectionDescription - GOC6.5 HP Z400 Host Computer

      2Motherboard PS/2 - Mouse *
      3Motherboard USB - USB Keyboard
      4Motherboard USB - USB Mouse
      5Motherboard USB - USB Trackball
      6Motherboard USB - External Hard Drive
      7Motherboard USB - USB Peripheral Tower DVD-RW
      8Motherboard USB - USB Peripheral Tower DVD-RAM
      9Motherboard GbE Ethernert - CNS Port 9 (eth4)
      10Not Used
      11Audio Out - ICOM
      12Audio In - ICOM

      21Expansion Bulkhead USB - Service Key
      22SCSI 1 - MOD Drive (Optional)
      23SCSI 2 - DASM (Optional)
      * GOC6.5 Consoles may use PS/2 Mouse

    1. Mount the power cord to the rear of the Host Computer chassis.

4.4  MOD Archive Peripheral Tower Option Installation

  1. Set the MOD Peripheral Tower on top of the existing DVD Peripheral Tower on the console table top. The Towers are made to be nested together.

  1. Connect the supplied SCSI Communication Cable between the MOD Peripheral Tower and the Host Computer SCSI 1 Port. Route the cable as shown in the following illustration.

    Illustration 7:  MOD Archive Peripheral Tower Connections

    CableDescription
    1SCSI Communication Cable
    2Power Cable

    Illustration 8:  GOC6.5 Host Computer (HP Z400) Optional SCSI Card Ports

    ConnectionDescription
    1MOD (Port 1)
    2DASM Support (Port 2)

  1. Connect the MOD Archive Peripheral Tower Power Cable between the MOD and DVD Peripheral Towers. See Cable # 2 in illustration above. The MOD Archive Peripheral Tower receives its power from the DVD peripheral Tower.

4.5  Console Power Up Checks

  1. Reconnect the Twist-N-Lock Main Power Cable at rear of console and remove the Lockout / Tagout protection applied earlier.

  1. Power on the Operator Console at the console’s front panel switch.

  1. Do not allow Applications to start. During boot-up, cancel Application Startup when the CT Software Auto-start pop-up window appears.

  1. Verify that the Host Computer has powered up and is not displaying or sounding any POST Errors.

4.6  System Configuration (“reconfig”)

In order to ensure proper operation of the SCSI Controller Card and the MOD Archive Peripheral Tower, it is necessary to perform the following System Configuration process.

  1. Open a Terminal window and log on as Root.

    Type: {ctuser@hostname} su - [ENTER]

    Type the root password and press [ENTER]

  1. Launch the System Configuration utility:

    Type: [root@hostname] reconfig[ENTER]

  1. The System Configuration Utility launches.

    NOTE:No changes are required in the System, Preferences, Hardware, or Network Tab settings. The utility needs to be executed in order for the automated scripts to run. During the reconfig process the Host Computer is configured to support the new SCSI Controller Card and MOD Archive Peripheral Tower.

  1. Click [Accept] Tab to start the reconfig process.

  1. When the configuration changes are complete, the system displays a prompt to reboot. Click [YES].

    Illustration 9:  Configuration Complete Window

  1. After Rebooting, the system will automatically log in as ctuser.

  1. If the Autostart Disabled popup message appears, select [OK] and open a Terminal Window.

    Type: {ctuser@hostname} st[ENTER]

4.7  Functional Checks

  1. Perform the MOD Archive Drive tests in Peripheral Tower Functional Tests located on the Functional Checks > Console menu of the service publication to confirm proper MOD Archive Option operation.

  1. Perform the tests in System Scanning Tests located on the Functional Checks > System Level menu of the service publication to confirm proper system operation.

4.8  Console Cover Installation

  1. Reinstall Console Front and Rear Covers.

    NOTE:Refer to Console Cover Removal and Installation procedure located on the Replacement > Console menu of the service publication for more details.

  1. Reinstall Console Keyboard tabletop.

5  Finalization

Refer to System State Save & Restore procedure on the Software menu of the service publication and save a new System State.
