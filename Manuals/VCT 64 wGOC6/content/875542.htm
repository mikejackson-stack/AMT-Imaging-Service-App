VDARC Port Communication T/S Note

Last Revised28 April 2008

For a Ethernet cabling connection issues, use the ethtool command (ethtool -p eth# where # represents the Ethernet address) as root on the Host Computer, VDARC Node or VIG Node to determine if the Ethernet cable is correctly connected. The port will blink or flash when activated and <Ctrl+C> will stop the test. This command must be performed as root.

Open a Unix Shell and type the following:

  • Host Computer (xw8000 or xw8200) example Ethernet cable check:

    (For xw8000) {ctuser@hostname}  ethtool -p eth2

    (For xw8000) (<Ctrl+C> to stop flashing xw8000 Ethernet port C LED)

    (For xw8200/xw8400) {ctuser@hostname}  ethtool -p eth0

    (For xw8200/xw8400) (<Ctrl+C> to stop flashing xw8200 Ethernet port C LED)

  • Remote Shell to the VDARC Node:

    {ctuser@hostname}  rsh  darc

  • VDARC Node (Jarrell and Westville) example Ethernet cable check:

    (For Jarrell DARC) {ctuser@darc}  ethtool -p eth2

    (For Jarrell DARC) (<Ctrl+C> to stop flashing Jarrell Ethernet port LED)

    (For Westville DARC) {ctuser@darc}  ethtool -p eth4

    (For Westville DARC) (<Ctrl+C> to stop flashing Westville Ethernet port LED)
