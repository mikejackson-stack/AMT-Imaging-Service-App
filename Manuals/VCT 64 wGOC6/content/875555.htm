VIG Port Communcation T/S Note

For a Ethernet cabling connection issues, use the ethtool command (ethtool -p eth# where # represents the Ethernet address) as root on the Host Computer, VDARC Node or VIG Node to determine if the Ethernet cable is correctly connected. The port will blink or flash when activated and <Ctrl+C> will stop the test. This command must be performed as root.

  • IG1

    [root@darc]  ethtool -p eth1

    (<Ctrl+C> to stop flashing Ethernet port LED)

    [root@ig1]  ethtool -p eth0

    (<Ctrl+C> to stop the flashing Ethernet port LED)

  • IG2

    [root@darc]  ethtool -p eth0

    (<Ctrl+C> to stop flashing Ethernet port LED)

    [root@ig2]  ethtool -p eth0

    (<Ctrl+C> to stop the flashing Ethernet port LED)

  • IG3

    [root@darc]  ethtool -p eth3

    (<Ctrl+C> to stop flashing Ethernet port LED)

    [root@ig3]  ethtool -p eth0

    (<Ctrl+C> to stop the flashing Ethernet port LED)
