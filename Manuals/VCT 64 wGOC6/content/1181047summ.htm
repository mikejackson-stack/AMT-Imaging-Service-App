2  Procedure

2.1   Series 997 generation

  1. Ask customer and confirm that the other hospital systems (PACS) supports the following SOP classes. (confirm PACS DICOM Conformance Statement)

    (Step Details)

  1. Application shutdown, open command window, becomes root user and type “reconfig” to show the reconfig screen.

  1. Set Dose record setting (Full or On) depends on the result of supported SOP class.

    (Step Details)

  1. Press Accept button and reboot the system.

  1. Execute an axial scan to create Series 997.

    (Step Details)

2.2   Test

The following steps will demonstrate the capability of the PACS equipment to support a specific DICOM SOP class. The system has been already set to use “DICOM X-ray Radiation Dose SR SOP” class (Full) or “DICOM Enhanced SR SOP” class (On).

  1. Send the generated series 997 image to the remote destination.

  1. Examine the scanner’s GEsyslog.

  1. Confirm that the entry containing “.88.67” or “.88.22” does not exist in the GEsyslog. See Illustration 2 for example.

    (Step Details)
