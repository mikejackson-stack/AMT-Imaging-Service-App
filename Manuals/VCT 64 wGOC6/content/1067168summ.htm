Save Restore Generator Runtime Parameters

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

For VCT type X-ray Generation Systems.

-

-

Recommend procedure completion by GE Service trained personnel.

-

-

2  Procedure

2.1   Save Generator Runtime Parameters

  1. Select [DIAGNOSTICS] from Service Desktop.

  1. Select [GENERATOR TOOL - JEDI], or [X-RAY GENERATION], [GENERATOR TOOL - JEDI].

  1. Click [SAVE RUNTIME PARAMETERS].

  1. Click [OK] in Attention window.

  1. Click [OK] in Save Runtime Parameters window.

  1. Click [DISMISS] in Generator Tool - JEDI window.

  1. Save System State.

2.2   Restore Generator Runtime Parameters

  1. Select [DIAGNOSTICS] from Service Desktop.

  1. Select [GENERATOR TOOL - JEDI], or [X-RAY GENERATION], [GENERATOR TOOL - JEDI].

  1. Select [RESTORE RUNTIME PARAMETERS].

  1. Click [OK] in Attention window.

  1. Click [OK] in Restore Runtime Parameters window.

  1. Click [DISMISS] in Generator Tool - JEDI window.
