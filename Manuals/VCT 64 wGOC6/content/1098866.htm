STEP E2: System and Console Configuration

Labor:1 person; 1.5 man-hours
Tools:

  1. Determine system configuration (site and system identification, preferred file/patient format, network information, etc).

  2. Launch the Install Utility from the service desktop.

  3. Configure the System settings to the site-specific information.

  4. Configure the Preference settings to the customer-desired parameters.

  5. Configure the Hardware settings to the system-specific information.

  6. Configure the Network settings to the site-specific information.

  7. Set the time and date.
