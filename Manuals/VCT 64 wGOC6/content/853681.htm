VDARC Stand-Alone OS Load

Last Revised:16 May 2007

This stand-alone procedure eliminates any external sources causing an issue but does not rule out media issues or internal VDARC Node. In this procedure the user will load the OS software directly into the VDARC Node DVD-ROM. The Operator Console keyboard will be disconnected from the Host Computer and reconnected to the rear of the VDARC Node. The T/S VDARC video monitor cable will be connected between the VDARC Node rear panel and the Display Monitor.

NOTE:Jarrell VDARC and Jarrell IG Nodes require software release 06MW29.x or later.

NOTE:If VDARC Node OS Load Work-around with Disk Array (JBOD) OFF failed, perform the VDARC Stand-alone OS Load. Do Not perform this section if the VDARC Node has loaded the OS successfully.

  1. Remove the front and rear covers from the Operator Console.

  2. See Illustration 1 (Westville or Jarrell VDARC Node versions) for keyboard and T/S VDARC video monitor connections. The T/S VDARC video monitor connection is located on the left side and is blue. The keyboard connection is color coded the standard purple.

  3. Connect the T/S VDARC video monitor cable between the VDARC Node and the right Display Monitor.

  4. Verify the Right Display Monitor front panel is properly set to display the VDARC Node input.

  5. Reposition the existing Host Computer keyboard connection:

    • Remove the keyboard cable at the rear of the Host Computer

    • Reconnect the keyboard cable at the rear of the VDARC Node

    NOTE:Jarrell VDARC and Jarrell IG Nodes require software release 06MW29.x or later.

  6. Insert (and verify the software is properly clicked into place) the OS software directly into the front panel DVD-ROM on the VDARC Node.

  7. Close the VDARC Node DVD-ROM tray.

  8. Press the VDARC Node front panel Power Switch to turn off power. See Illustration 2.

    Illustration 2:  Front Panel of Westville (Top Picture) and Jarrell (Bottom Picture) VDARC Nodes

  9. Wait 30 seconds and reapply power to the VDARC Node at the front panel switch.

  10. The OS is a bootable software DVD. At the boot: prompt, type ONLY the following command (several commands are listed on the monitor display):

    CTDARC

    NOTE:The Console Operating System load takes approximately 20 minutes. If the boot: prompt does not appear, then either the DVD is bad or the Console Operating System Media is not installed in the drive correctly. Typing any other command not listed in this procedure will result in a reload.

  11. After the OS is loaded on the VDARC Node, the OS DVD should automatically eject from the VDARC Node DVD-ROM Drive. If the DVD does not auto-eject after 30 minutes, press the VDARC Node Reset button. This will reboot the VDARC Node.

  12. Remove the OS DVD.

  13. Manually close the VDARC Node DVD-ROM tray.

  14. The VDARC Node should reboot. If the VDARC does not reboot, cycle power to the VDARC Node.

  15. After approximately 4 to 5 minutes the VDARC T/S Video Monitor should display the message: See you on the darc side of the moon.

    NOTE:If the OS failed to load the VDARC Node, retry the stand-alone procedure with all interconnect cables disconnected from the VDARC Node. If it continues to fail the stand-alone procedure then replace the VDARC Node.

  16. Disconnect the T/S VDARC video monitor cable from the right Display Monitor.

  17. Reconnect the Host Computer keyboard connection:

    • Remove the keyboard cable at the rear of the VDARC Node

    • Reconnect the keyboard cable at the rear of the Host Computer

  18. At the Disk Array (JBOD) verify two green LEDs at rear panel are illuminated. If not, press two power switches at rear panel, to apply power to the Disk Array. See Illustration 3.
