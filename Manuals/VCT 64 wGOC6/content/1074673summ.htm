Tube Install Certification

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

For Performix Pro VCT 100 X-ray Tube.

-

-

Procedure to be completed by trained GE Service personnel.

-

-

Class M Service key (only available to GE Healthcare service personnel) is required to effectively record Tube type during 1) Tube Replacement and 2) Load From Cold Software Install.

-

-

2  Procedure

2.1   Non-GE Service Personnel

  1. Record X-ray Tube Insert Model Number on X-ray tube rating plate.

  1. Select [CONFIGURATION] from Service Desktop.

  1. Select [TUBE INSTALL CERTIFICATION]. A screen, as depicted in Illustration 1, is displayed.

    (Step Details)

  1. If X-ray tube rating plate Tube Insert Model Base Number is 2291563, click [GE MEDICAL SYSTEMS TUBE] from Tube Install Certification Tool Change Tube Identity pane.

    (Step Details)

  1. Click [CONFIRM]. A Confirmation screen, as depicted in Illustration 2 or Illustration 3, is displayed.

    (Step Details)

  1. Click [ACCEPT]. Tube Install Certification Tool top pane is updated as depicted in Illustration 4 or Illustration 5.

    (Step Details)

  1. Click [DISMISS].

  1. If an Attention window is displayed, read and click [OK].

  1. Restart system.

  1. If Tube Install Certification is configured for a GE Medical Systems Tube and Trial Period has not expired, contact GE Call Center and create a dispatch for a Field Service Engineer to finalize Tube Installed Certification on-site.

2.2   GE Service Personnel

Perform the following steps when originally setting Tube Install Certification or verifying a GE Medical Systems Tube installation, within trial period, with an active GE Class M service USB key.

  1. Insert and activate Class M Service key.

  1. Record X-ray Tube Insert Model Number on X-ray tube rating plate.

  1. Select [CONFIGURATION] from Service Desktop.

  1. Select [TUBE INSTALL CERTIFICATION]. A screen, as depicted in Illustration 6 or Illustration 7, is displayed.

    (Step Details)

  1. If X-ray tube rating plate Tube Insert Model Base Number is 2291563, click [GE MEDICAL SYSTEMS TUBE] from Tube Install Certification Tool Change Tube Identity pane.

    (Step Details)

  1. Click [CONFIRM]. A Confirmation screen, as depicted in Illustration 8 or Illustration 9, is displayed.

    (Step Details)

  1. Click [ACCEPT]. Tube Install Certification Tool top pane is updated as depicted in Illustration 10 or Illustration 11.

    (Step Details)

  1. Click [DISMISS].

  1. Restart system.

  1. Deactivate and remove Class M Service key.
