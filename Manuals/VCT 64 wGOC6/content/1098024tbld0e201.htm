Table 2:  Position Tilt, Move Table to Interference Limit Tests

TestStepsExpected Results
1

Move cradle (and IMS) to home position and set internal landmark

Cradle position on the display should read 0.0.

2

Raise table height to maximum height.

Set the internal landmark.

Move the IMS into gantry 400 mm, as displayed on gantry.

Set the internal landmark a second time.

Move cradle into gantry 1 m.

Table elevation on the display should read 25.0 ± 3mm. (This value is the same as in the Table Elevation Test #2 in Table 1.)

Cradle position on display should read 1000.0 mm.

3

Tilt the gantry to I30.0.

Lower the table until motion stops.

Table elevation on display should read 65 ± 3mm.

Tilt display should read I30.

4

Tilt the gantry to I23.

Lower the table until motion stops.

Table elevation on the display should read 124 ± 3mm.

Tilt display should read I23.

5

Tilt the gantry to I20.0.

Lower the table until motion stops.

Table elevation on the display should read 140 ± 3mm.

Tilt display should read I20.

6

Raise the table elevation to maximum height.

Table elevation on the display should read 25.0 ± 3mm. (This value is the same as in Table Elevation Test #2 in Table 1.)

7

Tilt the gantry to S30.0, then lower table until motion stops.

Table elevation on display should read 147 ± 3mm. Tilt display should read S30.

8

Tilt the gantry to S23.0.

Lower the table until motion stops.

Table elevation on display should read 175 ± 3mm. Tilt display should read S23.

9

Tilt the gantry to S20.0.

Lower the table until motion stops.

Table elevation on display should read 185 ± 3mm. Tilt display should read S20.

10

Raise the table to 145 mm.

Table elevation on display should read 145 mm. Tilt display should read S20.

11

Tilt the gantry to S30.

Verify that the table height can be adjusted from 145 mm to 25 mm. (This value is the same as in the Table Elevation Test #2 Table 1.)

Tilt display should read S30.

The table lower limit should be 145 ± 3mm. Upper table limit should be 25 ± 3 mm. (This value is the same as in the Table Elevation Test #2 Table 1.)

12

Set the table height to 63 mm.

Table elevation on display should read 63 mm.

13

Tilt the gantry to I30.

Verify that the table height can be adjusted from 63 mm to 25 mm. (This value is the same as in Table Elevation Test #2 Table 1.)

Tilt display should read I30.

The table lower limit should be 63 ± 3 mm.

The upper table limit should be 25 ± 3 mm. (This value is the same as in Table Elevation Test #2 Table 1.)
