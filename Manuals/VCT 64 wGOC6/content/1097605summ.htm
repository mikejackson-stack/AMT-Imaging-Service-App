2  Procedure

2.1   BIOS Settings Preparation

  1. Shut down Applications from the Common Service Desktop, Utilities Tab.

  1. Open a Terminal Window, and log on as root:

    1. Type: {ctuser@hostname} su- [ENTER]

    1. Type the root password and press [ENTER]

  1. Launch the Mozilla WEB browser:

    1. Type:{root@hostname} mozilla [ENTER]

    1. Select [default profile].

    1. Select [Start Mozilla].

      (Step Details)

  1. Follow instruction listed in the following section for setting the VeRB2 Computer Motherboard BIOS Settings.

2.2   VeRB2 Motherboard BIOS Settings

  1. In the WEB Browser URL Address Bar:

    (Step Details)

  1. The WEB Browser will update and display the Login page for the VeRB2 RMM.

    (Step Details)

  1. The WEB Browser will update and display the Home page for the VeRB2 RMM.

    (Step Details)

  1. Click on Console icon or [Click to Open] in the Remote Console Preview window on the RMM Home Page to open a Remote Console.

    (Step Details)

  1. Reset the VeRB2 Computer by pressing the RESET button on the VeRB2 Computer front panel. This will cause the VeRB2 Computer to reboot, but does not reset the RMM. Shortly there after, the Boot Screen of the VeRB2 Computer should be displayed in the Remote Console window.

  1. Press <F2> on the keyboard when instructed, to enter the VeRB2 Computer’s Motherboard BIOS setting routine. See Illustration 4.

    (Step Details)

  1. Press <F9> and click YES to load Optimized Defaults (BIOS Default Settings).

  1. Select the [Main] tab.

  1. Use +/- keys to change defaults, see on-screen menu keys for additional help.

  1. Set Post Error Pause setting to [DISABLED].

  1. Hit <Esc> to return to the top level of BIOS Setup.

  1. Navigate to the [Advanced] tab.

  1. Set System Acoustic and Performance Configuration > Throttling Mode to [CLOSED LOOP].

  1. Hit <Esc> to return to the top level of the [Advanced] tab.

  1. Set PCI Configuration > Dual Monitor Video to [ENABLED].

  1. Hit <Esc> to return to the top level of the [Advanced] tab.

  1. Set PCI Configuration > OnBoard NIC2 ROM to [DISABLED].

  1. Hit <Esc> to return to the top level of the [Advanced] tab.

  1. FOR E0 STEPPING CPU's, BIOS REV. S5000.86B.11.00.0096.101720071530 ONLY. Set Processor Configuration > Deep C-State Support to [OFF].

    (Step Details)

  1. Hit <Esc> to return to the top level of BIOS Setup.

  1. Navigate to the [BOOT OPTIONS] tab.

  1. Set the boot order settings as follows:

    (Step Details)

  1. Press the <F10> and [YES] to save settings and exit.

  1. The VeRB2 Computer will reboot.

2.3   Verify VeRB2 Computer Operation After BIOS Settings

  1. After completing the BIOS Settings Procedure, the VeRB2 Computer will reboot. Verify that the VeRB2 Computer has powered up and is not displaying or sounding any POST Errors.

    (Step Details)

  1. Close Mozilla Browser and reboot the system by typing:

    (Step Details)

  1. In order to assure proper operation of the VeRB2 computer, perform the System Configuration procedure located in the applicable Align, Setup, Cals → Console folder of this service methods publication.

    (Step Details)
