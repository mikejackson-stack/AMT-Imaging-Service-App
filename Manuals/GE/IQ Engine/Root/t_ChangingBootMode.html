Changing Boot mode

Change the Boot mode from Legacy to UEFI when reloading the USB host system software.

Prerequisites

Required conditions
  1. Disconnect the cable connecting to port 1 slot 2 of T5820.
  2. Disconnect the cable connecting to port 1 slot 4 of T5820, and then connect it to port 1 slot 2 of T5820.
  3. Power on T5820, and then start to set up the BIOS.

Procedure

Visually inspect the top of the Preparing One-Time Boot or Please select boot device menu.
  1. Locate the phrase Boot mode is set to:.
    1. If the Boot mode is set to Legacy, use the up and down arrows on the keyboard to select BIOS Setup, listed under OTHER OPTIONS.
    2. Press Enter.
    3. Under Settings in the left side of the window, select General > Boot Sequence.
    4. Under Boot List Option in the right side of the window, select UEFI.
    5. Click Apply and then Exit.

Finalization

  1. Power off the T5820.
  2. Recover the cable connections.
  3. Power on T5820.
