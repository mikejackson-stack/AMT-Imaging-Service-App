Pre-configuration

Note Make sure the service pack has been installed before install IQE software, otherwise the IQE icon will not be displayed after the software is installed.
  1. Open C-shell and change to root account.
    1. Type su - and press Enter.
    2. Type the root password and press Enter.
  2. Insert Configure USB to Host scanner.
  3. Type in command window, mount /dev/disk/by-label/IQEPREINST /mnt/usb
  4. Type in command window, /mnt/usb/start_pre_install
  5. The Pre-install configure window shows:
    • Language: default set English. There is two languages, it is English or Chinese.
    • Type in option Key info, click Add an Option Key.
      Note For IQE software reloading, if option key has been updated successfully into the configure USB, option key information will be automatically captured and displayed in the window. If option key is not displayed, please manually add option key again.
    • IQE Sever IP: Automatically show after fill in above info.
    • Hospital Name: Automatically show after fill in above info.
  6. Click Configure button and close the UI.
    Note Makesure above window is closed, and then the USB can only be unplugged. Otherwise, the USB will be damaged and a pop-up window will not appear.
  7. Wait for 1 - 2 minutes, a pop up window shows up, click OK.
    Note If the window fails to pop up, please follow below steps to repeat the pre-config.
    1. Insert Configure USB to Host scanner.
    2. Type in command window, mount /dev/disk/by-label/IQEPREINST /mnt/usb
    3. Type in command window, /mnt/usb/start_pre_install
    4. Type option key info and click confirm and close the window.
  8. Then, the window should be able to pop up, you can Unplug the configure USB from host scanner.
  9. Continue to IQE software installation and configuration.
