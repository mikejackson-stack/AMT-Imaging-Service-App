IQE software reloading

Note If IQE option key has been changed in Config tab of IQE window, remember to export the latest information to configure USB Export system configuration tool.
  1. Uninstall service pack, see Software uninstall.
  2. Install service pack, see Service pack installation.
  3. Insert Configure USB into scanner host.
  4. Redo IQE pre-configuration and IQE software installation and configuration, see Pre-configuration and IQE software installation and configuration.
