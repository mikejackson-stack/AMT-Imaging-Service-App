Generating software options on eLicense

This procedure describes how to use eLicenses to generate and install software options on MR scanners.

About this task

The eLicense allows the field to generate license keys for MR scanners and removes the need to send out physical media for all options on the order. The first step in creating option keys is to go to the eLicense website and register the scanner. To access the eLicense website, you must have a computer with connectivity, as well as a single sign-on (SSO) account. The eLicense website can be accessed at http://elicense.gehealthcare.com.

The MR system must be tied to the Global Order Number (GON) through the Host ID and System ID of the scanner. After the site information is entered, the keys can be generated and distributed by e-mail, saving, or printing. This option key info can be installed on the system through manually type it under the IQE configure window 1 or preconfiguration step 5.

The following tasks are included in this procedure:

  • Recording the host ID
  • Modifying system information

For additional information on how to generate and obtain these keys from the eLicense server, see the eLicense User Guide under the HELP tab of the eLicense website.

  • Recording the host ID
    To generate new licenses, you must have order number(s) that list the options ordered, as well as the host ID and system ID of the system.
