IQE Theory

About IQE

As an intelligent and optimized processing software for magnetic resonance images, IQ Engine is a medical software package to be purchased as a complete solution, including off-the-shelf business level server hardware. This software system shall be used with the GE HealthCare MR system, connected to the GE HealthCare MR system through LAN and can enhance the DICOM images generated by it.

IQE workflow concept

IQ Engine is deployed in an independent Host PC and connected to the original scanner through a LAN switch, enhancing the image data generated by the scanner through AI algorithms. Transfer the generated images to the main scanner image management system with preset software.
