Accessing the DICOM Network Configuration user interface

Accessing the DICOM Network Configuration user interface.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-
Note Class M Key is required.

Procedure

  1. Click the Image Management icon in the upper left corner of the MR OS window.
  2. In the bottom right corner, select Tools > Network Configuration.
  3. Click IQE icon to open IQE UI, click Config.
  4. Type iqe in Host Name and press enter. And DICOM Server info will show in the Network configuration window, and the content from IQE Config tab.
  5. Click OK.
  6. Check IQE DICOM server is not set as auto transfer target.
    1. Click System Preference.
    2. Type password and click Apply.
    3. Auto Transfer by Exam: Click On and Click ....
