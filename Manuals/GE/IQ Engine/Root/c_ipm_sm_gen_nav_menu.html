Navigate data in the IPM menu panel

Learn how to navigate data in the IPM menu panel.

On the left of the IPM window, the user can use the menu panel to select different menus that determineg the data that will display in the content area. The user can expand and contract the menu panel to suit their viewing needs.

To navigate using the menu panel, select the desired option:
CT


  • Transaction Status: Allows user to view all the transactions that have occurred in the specific organization. User can filter transactions via Device or Library.
  • Protocol Libraries: Lists all the user's Protocol Libraries. The standard library will always be listed at the top and in bold.
  • Devices: List of all the CT devices.
  • Workspaces: A temporary location where users can edit and modify protocols using an Editor.
  • Network Settings: Users can copy auto transfer settings and remap network hosts.
MR


  • Transactions Status: Allows user to view all the transactions that have occurred in the specific organization. User can filter transactions via Device or Library.
  • Protocol Libraries: Lists all the user's Protocol Libraries. The standard library will always be listed at the top and in bold.
  • Devices: List of all the MR devices.
  • Workspaces: A temporary location where users can edit and modify protocols using an Editor.
Settings


  • Devices: Lists of all the devices that are connected to this organization. The user can filter based on type of connection (i.e Directly Connected Devices or Insite Connected Devices). Then the user can filter even further down by modality, site, and model.
  • InSite User Registration: Allows user to register insite users.
  • Libraries: Users can edit and remove Libraries. This is where users can change what standard library they are using.
  • Preferences: User can change languages.
Apps
User can access the Protocol Sharing application. Refer IPM User Manual DOC2775906 for more information.
