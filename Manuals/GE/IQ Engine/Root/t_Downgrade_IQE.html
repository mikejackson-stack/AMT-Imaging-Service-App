About this task

This is to remove IQE from scanner system by uninstalling the service pack Procedure.
Note If need reinstall IQE software, need reinstall Service Pack and IQE software, see Service pack installation and IQE software reloading.
Topic ID: id_SL1771011-1046438

Accessing Guided Install Interface

Procedure

  1. Access Guided install.
  2. Expand Utilities and click on Patches.
Topic ID: id_SL1771020-1046438

Removing Service pack

Procedure

  1. In the Installed Patches section, click Uninstall in reverse order (from bottom to top) to remove the service pack.
    Note

    Sometimes an update cannot be uninstalled and an uninstall error displays. It may be necessary to remove another update to resolve the conflict.

  2. Open c-shell and log in as a root user.
    1. Type su and press Enter.
    2. Type the root password and press Enter.
    3. Remove patches under the directory at /var/opt/gehc/mr/riasdata.

      cd /var/opt/gehc/mr/riasdata/staging and press Enter.

      If patch_MR30.1_R01_ServicePack01 is shown, type rm -rf patch_MR30.1_R01_ServicePack01 and press Enter.

      cd /var/opt/gehc/mr/riasdata/tmp/import and press Enter.

      If patch_MR30.1_R01_ServicePack01 is shown, type rm -rf patch_MR30.1_R01_ServicePack01 and press Enter.

      cd /var/opt/gehc/mr/riasdata/history and press Enter

      If patch_MR30.1_R01_ServicePack01 is shown, type rm -rf patch_MR30.1_R01_ServicePack01 and press Enter.

      Please ensure the directory at /var/opt/gehc/mr/riasdata has no patch_MR30.1_R01_ServicePack01 information

      Note

      If don't perform this step, will cause IQE servic pack uninstallation failed.

  3. IQE icon disappears from the window after successful uninstall IQE.

Finalization

Complete a Goodbye scan (Check Scan) to verify that the system is functioning properly.
