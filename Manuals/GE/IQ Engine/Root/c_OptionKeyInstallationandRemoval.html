Option Key Installation and Removal

About this task: IQE Option key will only be installed on IQE server. Guided Install will not show IQE option key information.

There is two ways to do Option Key installation.
  1. In IQE Software Install: The option key can be installed through the IQE preinstallation window during the pre-configuration process, see Pre-configuration.
  2. After IQE Software Install: Open the IQE window, go to the config tab and install option key in computer. The detailed procedures are described as below.
    Note If need to reinstall IQE software afterwards, please export the option keys to configure USB firstly. See Export system configuration tool. Otherwise, option keys cannnot be reconfigured back automatically during software reloading.
    Note Class M service key is required.
  1. Add option key:
    1. Type option key string, click Add an option key.
    2. Click Configure.
    3. Under Home tab, click Reset button and then click Confirm.
  2. Remove option key:
    1. Select option key to be removed.
    2. Click remove the option key.
    3. Click configure.
    4. Under Home tab, click Reset button and then click Confirm.
