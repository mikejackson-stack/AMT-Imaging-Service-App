Signa 1.5T and 1.0T System PHANTOMs CONTAIN NICKEL, A SUSPECT CARCINOGEN.

Poison Hazard!

1  Procedure

1.1   Scan Preparation

  1. Remove front panel from Systems Cabinet.

  1. Disable the RF Output by setting the RF Output mode toggle switch (located on the front panel of the Master Exciter) to the RF Out “Disable” position. (See Illustration 1.)

    (Step Details)

  1. Install tuning ring in older 1.5T head coils, as shown in Illustration 2.

    (Step Details)

  1. Install the head coil and holder. (See Illustration 3.)

    (Step Details)

  1. Place the Head TLT Sphere in the Head Loader and landmark per Illustration 4. At the front of the magnet enclosure, press [LANDMARK], then [MOVE TO SCAN].

    (Step Details)

  1. At the operator workspace, prepare the system for a Correlated Noise (256 matrix) scan:

    1. Click on [New Pt], and press <Enter>.

    1. ID: Type geservice.

    1. Name: Type corr noise.

    1. Weight (Lbs): Type 111.

    1. Set Patient Protocols to Service.

    1. Select Correlated Noise, Series 1, then click on [Accept].

    1. Select [Save Series], then [Download].

    1. Right click on Research Operations, select [Setup Params], enter settings: R1 =11, R2 =15, TG =0, and select [Done].

  1. Right click on Research Operations, and select [Download].

  1. Select [Manual Prescan], record current system frequency, and set system frequency as follows:

    (Step Details)

  1. Click on [Done], then [Scan].

  1. After scan is complete, click on [Manual Prescan], and increment the system frequency by +25,000 Hz using AX.

    (Step Details)

  1. Click on [Done], then [Scan]. Repeat this step eight times, incrementing the system frequency by +25,000 Hz each time.

    (Step Details)

  1. After completing the ninth scan, proceed to the next step.

  1. Click on the Active series from the Rx Manager list, and right click to select Copy and Paste, then click on [View Edit]. Click on [Save Series].

  1. Right click on [Research Options], select [Setup Params], set R1 = 7, and select [Done].

  1. Click on [Manual Prescan], then set system frequency back to:

    (Step Details)

  1. Click on [Done], then [Scan].

  1. After the scan is complete, click [Manual Prescan], and increment the system frequency by +25,000 Hz. Select [Done], then [Scan]. Repeat this step eight times, incrementing the system frequency by +25,000 Hz each time (all at R1 = 7).

    (Step Details)

  1. At the operator workspace, prepare the system for a Correlated Noise (512 matrix) scan.

    1. Click on [New Series].

    1. ID: Type geservice.

    1. Name: Type corr noise.

    1. Weight (Lbs): Type 111.

    1. Set Patient Protocols to Service.

    1. Select the scan protocol by clicking on Other, select the Correlated Noise protocol and Series 2 from the menu, then click [Accept] to load the Correlated Noise (512 matrix) protocol.

    1. [Save Series], then [Download].

  1. Right click on Research Operations, select [Setup Params] and set R1 = 11, then select [Done].

  1. Click on [Manual Prescan], set system frequency to magnet frequency (recorded in Step 8). Select [Done], then [Scan].

  1. After the scan is complete, right click on Research Operations, select [Setup Params], and set R1 = 7. Click on [Done], then [Scan]. After this second scan at magnet frequency is completed, continue to Correlated Noise Data Analysis.

1.2   Correlated Noise Data Analysis

NOTE:Images must be viewed in an unmagnified format. Ensure that zoom factor is set to 2. Otherwise, the images may look different between manual and auto paging modes since different interpolation methods are used for each mode. Zoom Factor is found on the center of the Image Display page near the center.

  1. Using the Image Browser, measure and record the Mean and Standard Deviation for the first R1 = 11 image and the first R1 = 7 image of each image set (both 256 matrix and 512 matrix scans) per the steps that follow. If desired, record Mean and Standard Deviation values for the other images.

    1. Position a circular cursor from [Measure] so that it is in the center of the image area. Using the size/shape handle, set the circular size for an area of approximately 1200 mm2. (See Illustration 5.)

      (Step Details)

    1. Ensure that zipper and/or bright pixels do not fall within the circle.

    1. Record mean value and Standard Deviation (SD) value displayed on the screen in the Data Sheet.

    1. Calculate pixel acceptance spec value: (Pi) limit = +8 (SD) for first R1 =11 and R1 =7, 256 matrix scans and for both 512 matrix scans. Record these four values in the Acceptance Specifications - Pixels (Pi) column in the Data Sheet.

  1. Review all images for any bright spots. View all 20 images.

    1. Adjust window width to 1 and level to the pixel acceptance spec value recorded in the Data Sheet from Step 1.

    1. The image will be flat black; any "hot" pixel clusters will appear white. If the bright spot is a single pixel (temporarily increase the window level a bit to determine this), then it is a random noise value that can be ignored. If the bright spot is part of a "hot" pixel cluster:

      (Step Details)

  1. View all 20 images on the screen. Adjust window level (start at level setting of 60) so that any zippers display, but normal noise does not display. Review all images for zippers, and if any are detected:

    (Step Details)

  1. Zipper Peak Pixel - Perform if zipper is present in image:

    1. Set window width to 1.

    1. Increase window level until the brightest pixel (PZ) in zipper of interest turns black. Record window level value (PZ) in the Data Sheet.

    1. Calculate using measured and (SD) data from the appropriate Data Sheet: + 6 (SD). Record result in the appropriate Data Sheet in the Acceptance Spec, PZ column. Verify that measured Zipper Peak Pixel (PZ) is ≦ calculated spec.

    1. Calculate using measured and (SD) data from the appropriate Data Sheet:

      (Step Details)

  1. Zipper Mean - Perform if zipper is present in image:

    1. Position a rectangular box from [Measure] so that it covers only the area (and not beyond) of a zipper, or section of a segmented zipper.

    1. Record mean value (Z) of zipper in data sheet.

    1. Calculate using measured data from appropriate data sheet: + 3. Record in the Data Sheet in the Acceptance Spec, Z column. Verify that Zipper Mean (Z) is < calculated spec.

    (Step Details)

2  Finalization

  1. Set the system frequency back to the nominal value recorded in Scan Preparation , Step 8.

  1. Reset the RF Output mode switch (located on the Master Exciter front panel) to the ON position. (SeeIllustration 1.)

  1. Install the front panel on the System Cabinet.
