VRF Status Display

1  Diagnostic Link

Diagnostics → System Function → Recon → VRF Status Display

Diagnostics → Hardware Location → PGR Cabinet → Recon → VRF Status Display

Illustration 1:  VRF Status Display for Software Revisions Pre-22.x

Illustration 2:  VRF Status Display for Software Revisions 22.x and higher

2  Purpose

The purpose of the VRF Status Display diagnostic is to display the internal status of the VRF. This diagnostic can be used for further debugging if the VRF hardware or communication diagnostics fail.

3  Components Tested

  • VRF serial number

  • FPGA firmware version and temperatures

  • Status of the VRF clock input, Flash memory, and VRF fiber links

4  Requirements

No special requirements.

5  Test Sequence

NOTE:Observe the following:

  • (For 32-channel 4100 systems) Use the ICN Identification tool from the Common Service Desktop (Utilities → Toolbox → VRE → ICN Identification) to help distinguish ICN1 from ICN2.

    (For 32-channel 4170 systems) Open the HART Log → Current Status. Look for the item “vrf” in the BoardType column. Check the Board Location for this board (icn1 VRF1 or icn1 VRF2). The slot number indicates the physical Location of the VRF. Slot 19 is located to the side of the ICN. Slot 13 is located at the center of the ICN.

  • To distinguish between VRF and VRF2, open the HART Log → Current Status. Look for the item "vrf" in the BoardType column. Check the Firmware revision for this board. If the FPGA Rev is <1000, the ICN has VRF. If it is >1000, the ICN has VRF2.

  1. Select the VRF Status Display diagnostic.

  2. Select the ICN/VRF you would like to conduct the test. You can only select one option.

    Your test options are:

    1. ICN1 VRF1

    2. ICN1 VRF2

    3. ICN2 VRF1

    4. ICN2 VRF2

    Each execution will check the following status of the selected VRF.

    • VRF Serial Number

    • VRF FPGA Revision

    • VRF Clock Status

    • VRF Link Status

    • VRF Temperature

  3. Click [Run].

  4. Ensure that the VRF passes the diagnostic by reviewing the status in the Test Results section.

6  Expected Results

This diagnostic has either a pass or fail status.

  • If the selected test passes, the Test Results table displays the requested information.

  • If the test fails, review the error log and corresponding extended error messages for subsequent actions.
