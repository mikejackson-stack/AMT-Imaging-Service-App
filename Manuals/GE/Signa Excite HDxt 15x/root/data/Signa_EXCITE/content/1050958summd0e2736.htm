NOTE:This step corresponds to the diamond-shaped decision box labelled Passive Shim Change < 5 Positions? in Illustration 2, Shimming Flowchart.

  • If the specifications in Table 7 are not met (either Net Mass Change is ≥5 or Changed Number of Shim Positions is ≥5):

    1. Install the passive shims called for by ShimTool in conformance with Passive Shimming.

    2. Once the passive shims are installed, apply the S/C Shim Currents called for by the ShimTool in conformance with Superconducting Shimming.

    3. Return to Field Map Acquisition to take a new map and run the ShimTool for both Passive and S/C Shimming.

    4. Repeat Step 6.

  • If the specifications in Table 7are met (both Net Mass Change is <5 and Changed Number of Shim Positions is <5):

    1. Return to Acquiring a Shim File to run ShimTool for S/C Shimming only.

    2. Apply the S/C Shim Currents called for by the ShimTool in conformance with Superconducting Shimming.

    3. Return to Field Map Acquisition to take a new map, and run the ShimTool for superconducting shimming only.
