• The .cur / .shm text file is automatically saved by ShimTool. It can be printed from NotePad, WordPad or a word processor for pages similar to Illustration 33 and Illustration 34. ShimTool can also open previously saved files for on-screen viewing by selecting Show the output SHM file from the Shim menu.

  • To obtain a multi-page paper version of the ShimTool results similar to Illustration 35 through Illustration 39:

    1. Choose Print Lists... from the File menu,

    2. Set the page orientation to Landscape, and

    3. Click the [OK] button. (The multi-page paper version is generally easier to use while placing shims in the shim trays.)
