NOTE:In DDR2 mode, dual-rank DIMMs are placed farther from the Memory Controller Hub (MCH) than single-rank DIMMs.

The BIOS generates warnings/errors on invalid memory configurations.

  • If unable to obtain a valid memory configuration by disabling some of the plugged-in memory, the BIOS will halt with a diagnostics 2004 code for memory error (four beeps/blinks).

  • If the BIOS finds a valid memory configuration by disabling some of the plugged-in memory, it does so and reports a warning during Post, 215-mismatched memory.

    NOTE:The system can still be booted in this condition.
