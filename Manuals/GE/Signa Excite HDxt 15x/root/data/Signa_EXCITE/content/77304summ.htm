Configuring Mouse for Permanent Left Handed Use

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. If Signa is up and running, you must first log out and bring the system up to the Login screen. Otherwise, turn the system on and proceed to the Login screen.

  1. Log in as root. The system default password is operator. Select [No] for Guided Install option.

  1. In the lower left section of the display, click on the [foot] option then [Programs]-> [Settings]-> [Peripherals]-> [Mouse].

  1. Push the [Left Handed] button under Mouse Mapping, then push the [Apply] Button to accept the changes.

  1. Select [Logout] and restart Signa.
