UPM MNS Functional Checks

(Click Here to Return to Detailed Procedure)

1  Safety

DANGER
FATAL ELECTRIC SHOCK.
HAZARDOUS VOLTAGES PRESENT THROUGHOUT THE RF CABINET WHEN ENERGIZED.
DISABLE RF AMPLIFIER WHEN CONFIGURING THE CALIBRATION TOOLS.

2  Required Conditions

ConditionReferenceEffectivity

Properly calibrated RF Head, Body and MNS

-

-

3  Procedure

3.1   1.5T MNS UPM Functional Check

  1. Inhibit TR faults. Disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet), see Illustration 1. Move switch 2 to the TR Disable position.

    (Step Details)

  1. Remove the MNS Heliax cable. Connect the RF dummy load to the MNS Amplifier.

    (Step Details)

3.2   Setting up Software Tool for UPM MNS

Connect the 31P MNS TR coil to the system.

  1. Start a [New Exam].

  1. Enter the following parameters:

    1. Patient ID: geservice

    1. Weight: 111

  1. Press the [Align] button on, (Land Mark).

  1. Move the cradle to the Home position and then drive it into the bore.

  1. Press [Align on].

  1. Move the cradle to place the Laser alignment light near the Head Coil Area.

  1. Press [Landmark].

  1. Press [Advance to Scan].

  1. From the Common Service Desktop:

    1. For the Class M service tool, select [Calibration Wizard] from the calibration menu and select [Click here to start this tool] . Once the Calibration Wizard starts, select [UPM Calibration(Head and Body)] from the menu, review and okay the pre & post-dependencies, and finally select [Click here to start this tool]. Or start the tool under Class A/C mode shown next.

    1. Illustration 3 shows an example of the UPM tool.

    (Step Details)

  1. Select the Nuclei [31P].

  1. The RF Chain will then default to MNS.

  1. Select: [Func Chk] Button

    (Step Details)

  1. Select the [Start] button.

    (Step Details)

  1. After that, the tool takes full control and runs the 3 functional tests for whatever setup is currently active. The result of each test is compared against a Specification File on the system. Status should indicate Pass/Fail.

    (Step Details)

  1. To proceed:

    1. If any one of the tests fail, refer to Universal Power Monitor (UPM) Troubleshooting.

    1. If all 3 tests pass, proceed to Finalization, Step 1.

4  Finalization

  1. Remove the cables and measurement equipment.

  1. Reattach MNS Heliax cable.

  1. Re-enable TR Driver fault detection.

  1. Complete a TPS reset and do a test scan.

  1. Any failure will require a re-calibration of the UPM system.
