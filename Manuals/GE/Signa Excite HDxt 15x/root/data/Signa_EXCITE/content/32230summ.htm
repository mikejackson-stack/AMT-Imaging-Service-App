Gradient Configuration file

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. On the Config File Manager screen, select [MR Config File]. See Illustration 1.

    (Step Details)

  1. The Gradient Config File screen is displayed. See Illustration 2. For the TwinSpeed, each Gradient Mode, Whole-Body (WHOLE) and Zoom (ZOOM), has a separate button.

    (Step Details)

  1. 3. Either click in the fields or tab through the fields to enter values. Use the [Delete] key to edit text. The [Backspace] key works from the end of the field instead of from where the cursor is located.

  1. 4. To apply changes made to the Gradient Config File, exit the Config File Manager. Make sure to click the [Save] button when the Save dialog box appears. Then, shut down Signa and reboot the computer. (Refer to Exiting the Config File Manager.)

  1. You can view information in the Gradient Configuration file here.
