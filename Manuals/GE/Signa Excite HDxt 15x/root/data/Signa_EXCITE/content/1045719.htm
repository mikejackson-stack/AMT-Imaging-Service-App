3.2  Safety

DANGER
FATAL ELECTRIC SHOCK HAZARD!
Dangerous voltages throughout the cabinet.
TO PREVENT FATAL ELECTRIC SHOCK, MAKE SURE THE RF AMPLIFIER IS DISABLED WHEN CONFIGURING THE CALIBRATION TOOLS.

4  Procedure

4.1  Head Mode

4.1.1  Head Forward Power Calibration

  1. Inhibit the Transmit/Receive (TR) faults. Disable the Driver Module TR and DD fault detection in the PEN cabinet. (See Illustration 1.) Move Switches SW2 and SW3 to the TR DISABLE and DD Disable positions respectively.

    Illustration 1:  Driver Module Front Switches

  1. Move the RF ENB switch on the front of DTX1 Exciter in top of the Penetration Cabinet to the DISABLE (DOWN) position as shown in Illustration 2.

    Illustration 2:  RF ENB Switch

4.1.2  Setting Up Software Tool to Calibrate UPM - Head Forward Power

NOTICE
This tool must have the head coil installed in order to enable Coil ID.
 
 

  1. Enable the RF ENB switch on the front of DTX1 Exciter in top of the Penetration Cabinet by moving it to the ENABLE (UP) position.

  1. With head coil attached to the LPCA, landmark on the head coil and advance to scan.

  1. Start the Common Service Desktop (CSD) , then click the Calibration browser tab.

  1. Start the UPM Calibration Tool.

    • To start non-proprietary service tools:

      1. From the CSD, select the Calibration tab.

      2. From the Calibration menu, select [UPM Tool]

      3. To start the procedure, click the link: Click here to start the tool. (See Illustration 3.) Illustration 4 shows an example of the user interface of the UPM tool.

    Illustration 3:  Common Service Desktop

    Illustration 4:  Universal Power Monitor Tool User Interface

    NOTE:The first time running the UPM Calibration tool after a Load from Cold, if the following error message displays, The spectroRFampType and upm.config do not match!, click File -> Edit Config. When the window opens, click [Restore Defaults] , [Save], and close the window. The tool should now have the correct information so that this pop-up does not display again during future UPM calibrations.

  1. For Nuclei, select [1H].

  1. For RF Chain, select [Head].

  1. For monitor Power Type, select [Forward].

  1. Select [Calibrate].

  1. Select [Start] and validate the hardware setup, then select [Yes].

  1. Verify that the status indicates a PASS or FAIL within about 2.5 minutes. The tool should notify user of current step in progress. (See Illustration 5.) If failure occurs, refer to Universal Power Monitor (UPM) Troubleshooting .

    Illustration 5:  Head Calibration, PASS Status

4.2  Body Mode

4.2.1  Body Forward Power Calibration

  1. Inhibit the TR faults, and disable the Driver Module TR and DD fault detection. (See Illustration 6.) Ensure switches SW2 and SW3 are in the TR DISABLE and DD DISABLE positions respectively.

    Illustration 6:  Driver Module Switches

  1. Disable the RF ENB switch by moving it to the DOWN position as shown in Illustration 2.

4.2.2  Setting Up Software Tool to Calibrate UPM - Body Forward Power

This tool must see a Landmark only. It is not necessary to have a Body Phantom in place or any other scan parameter entered other than what is described below. Simply Landmark on the cradle where the Body Phantom would be.

NOTE:Remove the Head coil, and ensure it is not connected.

5  Finalization

  1. Disable the RF ENB switch by moving it to the DOWN position as shown in Illustration 2.

  1. Remove the cables and power measurement equipment.

  1. Enable the RF ENB switch by moving it to the UP position.

  1. Confirm that switch SW2 is set to TR ENABLE and switch SW3 is set to DD ENABLE for TR drive fault detection. (See Illustration 1.)

  1. Upon completion of any UPM calibration, click [Reset TPS]. The system cannot scan until this step is complete.
