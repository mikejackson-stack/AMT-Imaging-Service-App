2  Overview

Tests in this section allow the service engineer to selectively force head mode peak power, pulse width, and duty cycle beyond allowable limits.

3.2  Safety

CAUTION
PERSONAL INJURY!
POSSIBLE RF BURNS.
PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RFI or SRFD2 BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE.

3.3  Required Conditions

ConditionReferenceEffectivity

Perform the prerequisite calibration procedures in the sequence listed. 1a:Dummy Load & Cables Calibration (Do if NOT using the RF Power Measurement Kit)-- Calibration required whenever using the dummy load and cables. This value will be frequency specific and can change over time.

4  Procedure

CAUTION
PERSONAL INJURY!
POSSIBLE RF BURNS.
PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RFI or SRFD2 BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE.

NOTICE
If the SSM has switch cover (5120058) installed, remove the cover before performing the procedure outlined below. The cover may prevent the power monitor switches from functioning properly.
 
 

NOTICE
Property Damage! Prevent Coil And Associated Switch Damage, By Removing All Phantoms And Hardware (I.E., Head Coil, Surface Coil...) From The Magnet Bore.
 
 

  1. Verify that the system is not scanning and that all coils have been removed from the magnet bore. See the messages above.

  1. If using the RF Power Measurement Kit, refer to the RF Power Measurement Kit laminated card set.

    1. Look in the upper, right corner of each card and find the card labeled 63 (1.5T Head Output).

      NOTE:The head RF output connection is no longer to the non-existent EFB unit, as the reference cards in some of the older kits show, but instead to the J3 output on the rear of the RFI.

    2. Configure the system as shown in the illustration on the card.

    3. Confirm that the rotary attenuator is set to the correct position indicated on the card.

  1. If using the wattmeter or scope (NOT the RF Power Measurement Kit) to measure power, refer to ALTERNATE EQUIPMENT SETUPS & NON-SERVICE PROTOCOLS for the proper system head configuration.

  1. At operator workspace, select the scan desktop ICON in the desktop control panel, if you have not already done so.

  1. At the operator workspace, prepare the system for a Head Power Monitor scan using the "Service Protocols" procedure in Table 1 below.

  1. If using the RF Power Measurement Kit then refer to card 63 (1.5T Head Output) and note the Attenuation value listed on the calibration sticker affixed to the bottom, right of the card.
