MR Coil Log Viewer

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Starting Coil Data Viewer

  1. From Common Service Desktop (CSD) select [Utilities], Coil Data Viewer and Click here to start this tool. The Coil Log Viewer will open as shown in Illustration 1.

    (Step Details)

  1. Select the Coil Configuration, Serial Number, and Connector from the corresponding drop-down fields. See Illustration 1.

    1. If the site only has one coil of a specific configuration, there should be only one Serial Number listed.

    1. For Coils without coil ID, there will be a None option in the Serial Number drop-down field.

    1. All LPCA Ports, which the specific coil has been plugged into and scanned with, will be listed as a choice in the Connector drop-down field. A specific connector can be selected, or All can be chosen to review data from all connectors used.

  1. Detailed information will appear in the Coil Information window to the right of the GUI. See Illustration 2.

    (Step Details)

  1. The default tab in the Coil Information window is the Coil Info tab. This gives all the coil property values for the particular coil selected. The second tab, Voltage, gives the voltage specifications, per channel for the selected coil. The final tab, Circuit Limits, lists the Open and Short current limits in milliamps (mA) per channel for the selected coil.

1.2   Displaying Current Data

  1. To display the data for the selected coil, the user must select one of the following choices in the Circuit: (located under the Coil Information Tabs):

    1. Open Circuit

    1. Short Circuit

  1. Determine if all data should be displayed, and if not, select Show data from the last____ days entering the desired time frame.

  1. To display the data in table format, and determine if there are any faults, select the [Show Table] button. This will display the data as determined by Step 1 and Step 2. Any measurement that violates the threshold will be highlighted in red, see Illustration 3.

    (Step Details)

  1. Graphing the data over time will show any trends in the circuit data by channel.

    1. [Graph All Channels] will give the user a graph of the data based on the information given in Step 1 and Step 2. Each channel will be represented by a different color line, and a Legend will be given to identify each. See Illustration 4.

      (Step Details)

    1. [Graph Channel #] can be selected to narrow down the data graphed to only one Channel of interest. See Illustration 5.

      (Step Details)

1.3   Additional Information

  1. All Logs can be found in the /usr/g/service/log/paramdata/CD_*.xml.

  1. Error information will be displayed along the bottom of the GUI when the data files are corrupted, or contain questionable data (voltage changes, # of channels change, data is missing, etc). The error log information can also be found in /usr/g/service/log/CoilViewer.log. This log is not viewable from any of the log viewers, it must be accessed directly through the command prompt window.

  1. In the upper right corner of the GUI, [Refresh Data], can be selected to dynamically refresh the data.
