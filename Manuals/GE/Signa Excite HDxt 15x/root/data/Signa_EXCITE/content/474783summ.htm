2  Procedure

2.1   Introduction

The effectiveness of high order shimming on the 3T VH/i scanner has a great impact on the image quality (IQ), such as functional imaging and spectroscopy. On the 3T/94 magnet, it has been found that the Z2 component of the high order shimming process contains eddy currents that produce undesired magnetic fields negatively effecting IQ. These undesired magnetic fields need to be measured and compensated for to improve IQ. The Z2 calibration tool uses a specially designed flat rectangular Copper Sulfate phantom. The tool uses an 8-channel High Order Shim Supply to provide the necessary compensation to both a B0 coil that is wound around the CRM coil, and to the Z2 coil. Two channels of the shim supply are allocated for Z2 compensation (for the Z2 component and B0 induced Z2 component). The Z2 ECC tool provides a pre-emphasis compensation for Z2 in a similar fashion to which Grafidy3 provides gradient eddy current compensation for the X, Y and Z gradients. It consists of four parts: graphical user interface (GUI), data acquisition (PSD), and real-time communication using SVAT and data analysis using minilab.The creation of the Z2ECC calibration requires the user to run a localizer scan on a phantom and to adjust its position to within 5 mm as prescribed by the procedure. After the phantom is positioned the user will run the B0 Coil and Z2ECC Functional Check. If the functional check indicates Z2ECC must be run, user will run an automatic script. After selecting Automatic Mode, the tool will automatically characterized the B0 coil running several iterations. It is expected that this process will take 5 to 6 hours to complete.

2.2   Z2 ECC Characterization

The following contains the steps in which the system will configure the Z2 hardware.

2.2.1  Localizer Scan and Phantom Position

NOTICE
Centering of the Z2 ECC phantom is critical to the success of the tool. Center the tool in all three planes to +, - 3mm.
 
 

  1. Put the rectangular phantom on the top of the phantom positioner at the center of the head coil (remove the lower flat holder in the head coil so the sponge can sit lower).

  1. Landmark at the center of the phantom using the Alignment Lights.

  1. At the keypad on the magnet enclosure, press [Landmark], then [Advance to Scan].

  1. Setup and Run Localizer Scan. Refer to Table 1 for Localizer Scan Protocol.

    (Step Details)

  1. After the scan is complete select the image series from the Image Browser, enable the grid.

  1. Illustration 2 shows the axial, sagittal and coronal images of the phantom. The image should be at the center of the FOV. In the sagittal view, the phantom ends should be located at 1=150 (+/-3) and S=150 (+/-3). If the ends of the phantom do not fall into this range, reposition phantom and return to step 4. If the ends of the phantom fall into this range, continue on to the next step.

    (Step Details)

2.2.2  Running Z2 Eddy Current Calibration Tool

  1. In the Service Browser, click the Calibration tab and then click Z2 Eddy Current Compensation.

  1. In the tool's window, click [Click here to start the tool].

  1. Once the tool loads, initialize all the cal values by:

    1. Clicking on [Zero Out] tab (default)

    1. Clicking on [Select All]

    1. Clicking on [Zero Out Cal Values], [Message], [Remove text files failed]

      (Step Details)

  1. Click on [Auto Mode] tab (See Illustration 3.)

    (Step Details)

  1. Select [Z Direction] by clicking on it.

  1. Click on [Scan].

    (Step Details)

  1. Wait for the tool to finished auto mode.

    (Step Details)

2.2.3  Selecting Earlier Iteration Results

This will make sure that the best Z2ECC results will be used to create the calibration file. This section must be performed before you exit the tool.

  1. Switch to the [Manual Mode] tab.

  1. Click on the cell with the best performance data (the cell that has the lowest 3 values). This cell will be highlighted.

  1. Then move the cursor to Set Cal and click on it. The best fit result will not be saved and downloaded to the system. See Illustration 4.

    (Step Details)

  1. To confirm that the correct values were saved, double click on the same cell selected in Step 3. A plot of data should appear.

  1. Select [More] at the bottom of the plot and a separate window will open with a list of “previous params.”

  1. Open a C Shell window. Type the following: cd /usr/g/caldir<Enter>, more resistive_shim_comp.txt. <Enter>

  1. Check if the corresponding cal values (z2 or B0) are the same as the one displayed in the text as the ones listed after previous params in Step 3. See Illustration 5.

    (Step Details)

  1. If the values match, then the correct calibration file was loaded, go to Step  to rerun the CF check. If the values do not match, you can attempt to reload the same calibration file again or proceed to Step  Calibration File Backup after exiting the tool.

2.3   Z2 ECC Troubleshooting

If Z2 ECC does not converge, the following steps can be performed to assist with troubleshooting:

2.3.1  Enable Z2 HO Shim Supply

  1. Open a C-Shell.

  1. type z2download -install <Enter> (It will download the executable image to the Shim Supply and then reboot the shim supply).

2.3.2  BO Coil Check

This section makes sure that the BO Coil is connected correctly and shim supply responds correctly.

  1. Keep the phantom setup and series the same as Localizer Scan and Phantom Position, Step 4. Go to the Scan Page and click on [auto prescan], and record the center frequency.

    (Step Details)

  1. Place 0.15 amps into the BO coil by going to service desktop and opening a c-shell. Type the following: z2download -seterrchan 0.15 <Enter>

  1. Going to the scan page and click on [auto prescan] again, record the center frequency.

    (Step Details)

  1. CF1 should be 20-30 Hz less than CFO

    (Step Details)

  1. Set BO current to 0 by going to the service desktop and opening a c-shell. Type the following: z2download -seterrchan 0<Enter>

2.3.3   Center Frequency (CF) Stability Check

This section determines the system response to resistive shim Z2 current inputs. It should be run before and after running Z2 Eddy Current Calibration tool. This check confirms that the Z2 power supply, cables/filters, coil and calibration are correctly working to significantly reduce the time that the center frequency changes when Z2 coil is activated.

  1. Use the same phantom setup from Localizer Scan and Phantom Position.

  1. Setup protocol that is listed in Table 1; however, turn off autoshim.

  1. Select [Save Series] and then [Auto Prescan].

  1. On the SCAN page, right click on [Research Operation], and then select [Setup Params].

  1. Under window 1, set frame to 1,0 and click <Done>.

  1. Start [Manual Prescan] and select [Center Freq Fine (CFH)]

  1. In the Manual Prescan window, from the [Windows] menu select [Two Windows]. Set the first window type to [1 Channel] and the second window type to [P.Spect]. Both windows should be on Rec 1.

  1. Open a command window. To do this, move the mouse over on the desktop frames, press <Alt - F7> to move the window off-screen and expose the desktop, right click, select [Service Tools], and [Command Window].

  1. Type the following: setcurrent z2 1<Enter>

  1. The center frequency will shift off the center as in Illustration 6. Wait a couple of seconds for it to stabilize.

    (Step Details)

  1. In the command window, type the following and begin taking a time measurement (in seconds) once you hit enter: setcurrent z2 0<Enter>

  1. Stop the time measurement once the CF has stabilized. See Illustration 7. This can take up to 5-10 minutes.

    (Step Details)

  1. If the time measurement is less than 30 seconds, the system has correct Z2 eddy current compensation. No further action is required. If the time measurement is greater than 30 seconds, then proceed to Running Z2 Eddy Current Calibration Tool, Step 1. Click [Done], to exit out of manual prescan, and end the exam. (Took about 1 minute).
