1  Safety

CAUTION
System board or component damage could result.
The cooling fan is off only when the workstation is turned off or the power cable has been disconnected. The cooling fan is always on when the workstation is in “On” or “Standby” mode.
You must disconnect the power cord from the power source before opening the workstation.

CAUTION
Memory module damage could result during removal or installation.
If you do not unplug the power cord while installing memory, your memory modules might be damaged and the system will not recognize the memory changes.
Power off the workstation and unplug the power cord from the AC power outlet. Wait until the LED on the back of the power supply turns off before removing memory.

NOTICE
Turn off the workstation before disconnecting any cables.
 
 

NOTICE
TO PREVENT DAMAGE TO COMPONENTS WITHIN THE HSDA, OBSERVE THE FOLLOWING ESD PRECAUTIONS:

  • WORK ON A STATIC-FREE MAT.

  • WEAR A STATIC STRAP TO ENSURE THAT ANY ACCUMULATED ELECTROSTATIC CHARGE IS DISCHARGED FROM YOUR BODY TO GROUND.

  • CREATE A COMMON GROUND FOR THE EQUIPMENT YOU ARE WORKING ON BY CONNECTING THE STATIC-FREE MAT, STATIC STRAP AND PERIPHERAL UNITS TO THAT PIECE OF EQUIPMENT.

FOR FURTHER INFORMATION REGARDING ESD PROTECTION, REFER TO THE SAFETY CHAPTER IN THIS PUBLICATION

3  Procedure

3.1   Workstation Service Preparation

Perform the following steps before servicing the workstation.

  1. Remove/disengage any security devices that prohibit opening the workstation.

  1. Disconnect all peripheral device cables from the workstation.

  1. Perform the Lockout / Tagout Global Operator Console / Operator Workspace procedure before beginning the replacement.

  1. Remove the four screws in the rear that secure the left side panel. (See Illustration 1).

    (Step Details)

  1. Remove the left side panel by sliding it back.

  1. Remove the left panel of the PC by lifting up on the latch (Illustration 2).

    (Step Details)

3.2   Memory Module Removal

  1. Lay the workstation on its side with the system board facing up.

  1. Gently push out and down on the socket levers of the slot that contains the suspected faulty memory module. (See Illustration 3, Illustration 4, and Illustration 5 for slot locations.)

    Illustration 3:  DIMM Pair Locations for CPU 1

    Illustration 4:  DIMM Pair Locations for CPU 2

    Illustration 5:  System Board

  1. Lift the DIMM straight up and remove it from the unit (Illustration 6).

    (Step Details)

  1. Ensure that the socket levers are still out and away from the memory socket.

  1. Place the new memory module into the slot and push down firmly into the socket until the memory socket latches snap into place.

    (Step Details)

  1. Ensure that the module is fully inserted and properly seated in the socket.

3.3   Memory Module Installation Considerations

When installing a memory module, be aware of the following considerations:

  • Memory modules must be loaded in valid configurations.

  • DDR SDRAM is loaded as matched pairs. (For example, if you place a memory module of 1 GB in slot 1, you must also insert a 1-GB module in slot 2.)

  • Memory modules are always installed in the blue sockets (1A/1B or 2A/2B) before being installed in the black sockets (3A/3B or 4A/4B).

  • The first matched DIMM pair is installed in socket set 1A and 1B for CPU1 or in socket set 2A and 2B for CPU2.

  • Subsequent matched DIMM pairs are installed in sets 3A and 3B for CPU1 or in socket set 4A and 4B for CPU2.

  • Memory modules are loaded in pairs in order of size, from smallest to largest, beginning with memory module pair 1A. For example, if you have 6 GB of memory for CPU 1, composed of two 1-GB modules, and two 2-GB modules, load the 1-GB modules in memory module pair 1A and 1B, and the 2-GB modules in memory module pair 3A and 3B.

  • The DIMM is installed in socket 1A or 2A if only installing one DIMM.

    NOTE:The BIOS generates warnings/errors on invalid memory configurations.

  • In DDR2 mode, dual-rank DIMMs are placed farther from the Memory Controller Hub (MCH) than single-rank DIMMs.

  • If there is no way to obtain a valid memory configuration by disabling some of the plugged-in memory, the BIOS will halt with a diagnostics 2004 code for memory error (4 beeps/blinks).

  • If the BIOS can find a valid memory configuration by disabling some of the plugged-in memory, it will do so and will report a warning during POST (“215-mismatched memory”). The system can still be booted in this condition.

4  Finalization

  1. Replace and secure all cables and covers.

  1. Perform the Lockout / Tagout Global Operator Console / Operator Workspace procedure to restore power to the GOC and Operator Workspace.

  1. Run HP Linux PC Service Diagnostics using the HP Diagnostics Tool.

  1. Reboot, and ensure that no memory BIOS errors are observed during the boot process.

  1. Perform a scan to ensure that the system is operating properly.
