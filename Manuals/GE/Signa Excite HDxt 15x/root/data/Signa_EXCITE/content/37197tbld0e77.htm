{unix prompt} ..................................cd /usr/g/w/config<Enter>
{unix prompt} ..................................Verify the file exists ls -al Shim*.*<Enter> ShimConfig.cfg is part of Load From Cold software.
If ShimConfig exists, the following is displayed:
-rw-rw-rw-   1 sdcbin  informix  7973 Sep20 18:25 
ShimConfig.cfg

vi ShimConfig.cfg to edit the file. 
1. Move cursor to appropriate coil set.
2. Position on the line of the power supply to be turned off.
3. Move cursor to 2nd column of line and change the 1 to 0.
4. Exit vi saving changes.
The power supply with 0 in the 2nd column has been eliminated from the coil matrix.
