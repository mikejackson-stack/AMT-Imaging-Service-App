4  Procedure

4.1  Introduction

The effectiveness of high order shimming on the 3T VH/i scanner has a great impact on the image quality (IQ), such as functional imaging and spectroscopy. On the 3T/94 magnet, it has been found that the Z2 component of the high order shimming process contains eddy currents that produce undesired magnetic fields negatively effecting IQ. These undesired magnetic fields need to be measured and compensated for to improve IQ. The Z2 calibration tool uses a specially designed flat rectangular Copper Sulfate phantom. The tool uses an 8-channel High Order Shim Supply to provide the necessary compensation to both a B0 coil that is wound around the CRM coil, and to the Z2 coil. Two channels of the shim supply are allocated for Z2 compensation (for the Z2 component and B0 induced Z2 component). The Z2 ECC tool provides a pre-emphasis compensation for Z2 in a similar fashion to which Grafidy3 provides gradient eddy current compensation for the X, Y and Z gradients. It consists of four parts: graphical user interface (GUI), data acquisition (PSD), and real-time communication using SVAT and data analysis using minilab.The creation of the Z2ECC calibration requires the user to run a localizer scan on a phantom and to adjust its position to within 5 mm as prescribed by the procedure. After the phantom is positioned the user will run the B0 Coil and Z2ECC Functional Check. If the functional check indicates Z2ECC must be run, user will run an automatic script. After selecting Automatic Mode, the tool will automatically characterized the B0 coil running several iterations. It is expected that this process will take 5 to 6 hours to complete.

4.2.2  Enable Z2 HO Shim Supply

  1. Open a C-Shell

  1. type z2download -install <Enter> (It will download the executable image to the Shim Supply and then reboot the shim supply).

4.2.3  BO Coil Check

This section makes sure that the BO Coil is connected correctly and shim supply responds correctly.

  1. Keep the phantom setup and series the same as Introduction. Go to the Scan Page and click on [auto prescan], and record the center frequency.

    CFO = ________________ (Example: CFO = _127738007_)

  1. Place 0.15 amps into the BO coil by going to service desktop and opening a c-shell. Type the following: z2download -seterrchan 0.15 <Enter>

  1. Going to the scan page and click on [auto prescan] again, record the center frequency.

    CF1 = __________________ (Example: CF1 = _127727976_)

  1. CF1 should be 20-30 Hz less than CFO

    1. If the center of the frequency does not change, there is a BO coil connection or shim supply problem.

    2. If the CFO-CF1 <0, then the BO coil is polarity is wrong, switch the polarity by exchanging the pins in the cable for Z2. See Illustration 1. IMPORTANT: Be sure to remember to put the pins back into the same two holes that they were removed from! Test again.

    3. If the O<CFO-CF1 <30 Hz, then proceed to Step 5

  1. Set BO current to 0 by going to the service desktop and opening a c-shell. Type the following: z2download -seterrchan 0<Enter>

4.2.4   Center Frequency (CF) Stability Check

This section determines the system response to resistive shim Z2 current inputs. It should be run before and after running Z2 Eddy Current Calibration tool. This check confirms that the Z2 power supply, cables/filters, coil and calibration are correctly working to significantly reduce the time that the center frequency changes when Z2 coil is activated.

  1. Use the same phantom setup from Introduction

  1. Setup protocol that is listed in Table 1; however, turn off autoshim (under protocol, deselected the autoshim button).

  1. select [Save Series] and then [Auto Prescan]

  1. On the SCAN page, right click on [Research Operation], and then select [Setup Params].

  1. Under window 1, set frame to 1,0 and click <Done>.

  1. Start [Manual Prescan] and select [Center Freq Fine (CFH)]

  1. In the Manual Prescan window, from the [Windows] menu select [Two Windows]. Set the first window type to [1 Channel] and the second window type to [P.Spect]. Both windows should be on Rec 1.

  1. Open a command window. To do this, move the mouse over on the desktop frames, press <Alt - F7> to move the window off-screen and expose the desktop, right click, select [Service Tools], and [Command Window].

  1. Type the following: setcurrent z2 1<Enter>

  1. The center frequency will shift off the center as in Illustration 3. Wait a couple of seconds for it to stabilize.

    Illustration 3:  CF When Z2 Current is Set to 1 Amp

  1. In the command window, type the following and begin taking a time measurement (in seconds) once you hit enter: setcurrent z2 0<Enter>

  1. Stop the time measurement once the CF has stabilized. See Illustration 4. This can take up to 5-10 minutes.

    Illustration 4:  CF When Z2 Current is set to 0 Amps

  1. If the time measurement is less than 30 seconds, the system has correct Z2 eddy current compensation. No further action is required. If the time measurement is greater than 30 seconds, then proceed to Running Z2 Eddy Current Calibration Tool. Click [Done], to exit out of manual prescan, and end the exam. (Took about 1 minute).

4.2.5  Running Z2 Eddy Current Calibration Tool

  1. Open a C-Shell and type the following commands to run the script: cd /usr/g/bin/z2ecc<Enter>, runz2ecc&<Enter>

  1. When the software loads, initialize all the cal values by:

    1. Click on [Zero Out] tab (default)

    1. Click on [Select All]

    1. Click on [Zero Out Cal Values], [Message], [Remove text files failed]

      NOTE:You may see the following text appear “No b0_coil_params.txt file, need to do B0 Characterization”. This means that the B0 characterization has not been run. Select [OK].

  1. Click on [Auto Mode] tab (See Illustration 5)

    Illustration 5:  Z2 Eddy Current Compensation GUI

  1. Select [Z Direction] by clicking on it

  1. Click on [Scan]

    This will start the Z2 ECC tool. The Scan button will be disabled through the process. The performance number will be displayed in each iteration. The process will stop in the maximum number of iterations is reached (default to 10), or both B0 and Z2 term reached the target values. B0 spec = 1Hz, target = 0.5Hz, Z2 spec = 1Hz, target = 0.5Hz. When the performance is under spec, the performance number will be displayed as black. If the performance is under target, the performance number will be displayed as green, and not more iterations are needed when it is green.

    NOTE:The first iteration is for B0 coil characterization, there is no Z2 fit. Please no not click in the performance data under it. (Clicking generates a non-harmful Java error.) First iteration takes about 45 minutes.

    You can view each iteration fit and measurement curve only after that iteration is finished.

    The total process takes about 5:30-6:00 hours (for default 10 iterations). It could finish earlier when both Z2 and B0 meet target early. If the “Scan” button lights up, that means the process is done.

  1. Wait for the tool to finished auto mode.

    If all terms come within spec and the optimal calibration is shown on the last iteration, click the Exit button. All the performance data and cal values will be saved to a log in the /usr/g/bin/z2ecc/log directory. The calibration is complete!

    If all terms are not in spec, refer to Running Z2 Eddy Current Calibration Tool Manual Mode to run the tool in manual mode.

    If the last iteration does not show the best fit possible, refer to Selecting Earlier Iteration Results to select an earlier iteration. The best-fit possible has the smallest number.

4.2.6  Selecting Earlier Iteration Results

This will make sure that the best Z2ECC results will be used to create the calibration file. This section must be performed before you exit the tool.

  1. Switch to the [Manual Mode] tab.

  1. Click on the cell with the best performance data (the cell that has the lowest 3 values). This cell will be highlighted.

  1. Then move the cursor to Set Cal and click on it. The best fit result will not be saved and downloaded to the system. SeeIllustration 6.

    Illustration 6:  Setting Calibration File

  1. To confirm that the correct values were saved, double click on the same cell selected in Step 2. A plot of data should appear.

  1. Select [More] at the bottom of the plot and a separate window will open with a list of “previous params.”

  1. Open a C Shell window. Type the following: cd /usr/g/caldir<Enter>, more resistive_shim_comp.txt. <Enter>

  1. Check if the corresponding cal values (z2 or B0) are the same as the one displayed in the text as the ones listed after previous params in Step 4. See Illustration 7.

    Illustration 7:  Resitive_Shim_Comp.txt File Showing Previous Params

  1. If the values match, then the correct calibration file was loaded, go to Center Frequency (CF) Stability Check to rerun the CF check. If the values do not match, you can attempt to reload the same calibration file again or proceed to Calibration File Backup after Exiting Z2 ECC Tool Calibration File Backup after exiting the tool.

  1. Open a C-Shell Window and type the following: cd /usr/g/bin/z2ecc<Enter>, runz2ecc&<Enter>

  1. Click [Manual Mode] tab in the GUI. See Illustration 8.

    Illustration 8:  E2 ECC GUI with Manual Mode Selected

  1. Click [Select Z Direction] button in GUI.

4.3.2  B0 Coil Characterization

Test for B0 Coil Characterization. This also provides the user with information on what to expect with regards to B0 fluctuation given Z2 inputs in the resistive shim coil.

  1. Check [B0coil Characterization] box in the GUI.

  1. Click [Scan] button. This will start the B0 coil characterization scan and the iteration will take about 45 minutes. The [Scan] button will be disabled after the system begins scanning. The Z2 linear performance data should be printed in green text. DO NOT CLICK ON THIS DATA. The B0 performance data should be printed in red text. It should give results between 2.0 and 3.0. The output should look similar to Illustration 9.

  1. Wait until the iteration is complete. (The Scan button will re-enable).

  1. The B0 scale factors range by:

    1. Opening a C-Shell Window and typing the following: cd /usr/g/bin/z2ecc<Enter>, ls -l b0_coil_params.txt<Enter> (I = the letter L in lower case), more b0_coil_params.txt<Enter>

    1. The last line of the file b0_coil_params should be between 0.020 and 0.025

    1. If the values are not in this range, run the B0 Coil Check in BO Coil Check

      Illustration 9:  B0 Coil Characterization in Manual Mode

4.3.3  Drift Fit

Drift will perform the Z2 Eddy Current Compensation. It will only begin after the 3rd iteration is complete in the data set in the Z2 ECC GUI.

  1. Run Running Z2 Eddy Current Calibration Tool Manual Mode prior to beginning the Drift Fit. Do not exit the tool.

  1. Click [Scan] button again to start the second iteration. It will take about 32 minutes

  1. Click on [Accept] for the both Z2 and B0 plots when they appear.

  1. Click [Scan] button again after completing the 2nd iteration to begin the 3rd iteration.

  1. Click on [Cancel] for both Z2 and B0 plots when they appear

  1. Select [Drift Fit] in the Z2 ECC GUI before the 4th iteration

  1. Click [Scan] button to start the 4th iteration.

  1. Click on [Accept] for both Z2 and B0 plots when they appear.

  1. Click on the [More...] button to view the results. If the measurement value meets the spec/target click ok and exit the tool. If not, run another iteration. See illustration 9.

    Illustration 10:  Drift Fit Results Comparing Measured versus Target Values

4.3.4  Calibration File Backup after Exiting Z2 ECC Tool

This allows the user to use previous data recalibrate the Z2 eddy current compensation.

  1. Open a C-Shell and type the following commands to run the script: cd /usr/g/bin/z2ecc<Enter>, runz2ecc&<Enter>

  1. Click on the [GE Service] and then [View Log File...]

  1. A log window will be displayed, as in illustration 10

    Illustration 11:  List of Log Files from Z2 ECC Tool

  1. Click on the log file that you want to load. (Log file name “mwwdxxhymzz.z2ecc” translates to the log file create on month xx (0-12), day yy (1-31), hour yy (0-34), minute zz (0-59).

  1. Move the cursor to OK, click on it. The log file will be loaded.

  1. After loading the log file, follow Running Z2 Eddy Current Calibration Tool to allow the Cal file to be backed up.
