NOTE:Many of the Worklist DICOM fields are required only if the PPS Key is installed. Without the PPS Key, only 3 DICOM fields are absolutely required.

  • If there are problems with the Worklist/RIS integration, uninstall the PPS Key and make sure the scanner/RIS is talking in this mode first.

  • Once working, reinstall the PPS Key, move to the next level and make sure that is working with the additional PPS required fields (3 DICOM fields). (This may help a site having serious problems.)
