3  Procedure

  1. Check that green LED is lit. (see Illustration 1).

  1. Set the Control Box STEADY/PULSE Switch to PULSE.

  1. Depress the Squeeze Bulb slowly until fully collapsed.

  1. Check that Control Box red LED is lit and the audible alarm is emitting a pulsating tone.

  1. Set the Control Box STEADY/PULSE Switch to STEADY.

  1. Check that Control Box red LED remains lit and audible alarm is emitting a steady tone.

  1. Depress the Control Box <RESET> Button.

  1. Check that Control Box red LED and audible alarm have turned off, but green LED remains lit.
