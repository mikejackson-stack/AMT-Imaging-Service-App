NEC 2010 Gamma Configuration Setting Gamma For 10.X systems

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

For ALL 10.x Software versions, the Gamma value/LUT is automatically installed during the Software Load Process. A “Pull Down Menu” under “Display Type” under the “System Configure” tab in Guided Install, presents a menu listing all the current monitor types. Once a monitor is selected, the correct gamma value/LUT is installed automatically. If the Monitor “Type” is not listed in the Drop Down list on the Install GUI, Use the “10.x (Excite) (GENERIC) LCD Monitor Calibration & Gamma Setup” Procedure found on the 10.X Service Methods CDROM.

2  Procedure

  1. To set gamma:

    (Step Details)

  1. Open Guided Install and select System Configure tab. Refer to Illustration 1.

    (Step Details)

  1. If “CRT/Custom” is displayed in the Field:

    1. Click on the “Display Type” Field.

    1. Drag your mouse over LCD

    1. c. A Popup Display message will appear, Select [OK] (See Illustration 2)

      (Step Details)

    1. The Field should change to LCD.

    1. Select [LCD] again. The menu shown in Illustration 3will appear:

      (Step Details)

    1. Scroll to the correct Display option (2010 or 2010X) and release the mouse button. The display selected will appear in the box to the right.

    1. Click on the [Configure] Button on the Install GUI to save the changes. You may see a slight change in the screen intensity when “Configure” is complete.

    1. A Popup message box will appear, Select [OK].

    1. Select [File] and [Exit] from the Install/Reconfigure GUI Window.

    1. Reboot the System. A reboot is required to activate the changes. This completes the Gamma Calibration process.

    1. Proceed to Section 5- LCD Monitor Adjustment Process
