3  Procedure

3.1   Hardware Set-Up

  1. Unfold the 6-channel grafidy fixture and lock the arms into place (90o from center plate).

  1. Connect Hypertronics cable to T/R board and use screws to secure. Place the fixture at the front (Head coil end) of the MR table with the connection box toward the bore.

  1. Plug the Hypertronics connector into the Port A. See Illustration 1 . (The Green Coil ID light will come on.)

    (Step Details)

  1. Center the laser cross hairs on top of the fixture (As shown in Illustration 3) . Landmark the system and press Advance to Scan.

    (Step Details)

3.2   Running Grafidy 3

  1. Start the Grafidy 3 tool.

    (Step Details)

  1. For Twin Systems, the tool will ask you to select a gradient mode, (see Illustration 4) . Both modes need to be calibrated, and you may start with either one.

    (Step Details)

  1. If you receive the message shown in Illustration 5 about “Short TC Cal Values”, click [Yes].

    (Step Details)

  1. Click on the [Auto Mode] tab. See Illustration 6. All three-coil axes will be selected. Click the [Scan] button to start the calibration. (When the scan is active, you can stop it by pressing the [Abort] button and the “STOP” button on keyboard.)

    (Step Details)

  1. If you did the tests for WHOLE / ZOOM already, proceed to Step 9. Else continue to Step 6.

  1. For the Whole and Zoom Procedure, select the “Whole and Zoom” option and press the “OK” button (As shown in illustration 4) and the scan takes place automatically. It will scan first in the WHOLE mode and then the ZOOM mode .It will then give a pop-up as shown in the Step 9.

  1. If you receive the message shown in Illustration 7 about “Short TC Cal Values”, click [Yes]. See Illustration 7.

    (Step Details)

  1. The Tool will perform the tests in both the WHOLE and ZOOM mode and give pop-up as shown in illustration 8.

    (Step Details)

  1. The Grafidy 3 software runs multiple scans to bring each term into specification. It iterates up to the maximum specified (default is 5 iterations). The WHOLE or ZOOM mode usually takes about 2 hours.

    (Step Details)

  1. Review the numeric output values from the auto mode scan. Verify that the results of final iteration for each component are below specs (green). See Illustration 9 for help in reading output values.

    (Step Details)

  1. If a component is not in spec after the maximum number of iterations you may need to use manual mode to calibrate that component. See Manual Mode.

NOTE:Systems with S5 magnets should have Very Long Eddy Currents rechecked in manual mode after 10 minutes, as it is possible for calibration to drift and require additional adjustment. See Grafidy 3 Troubleshooting, Section 4.7 for more information.

  1. If system type is TRM, and if you have already done Whole or Zoom mode, repeat the calibration procedure for the other gradient mode. When you are finished, quit the tool by pressing the [EXIT] button. Note that this step is not required for the “WHOLE and ZOOM” mode

3.3   Manual Mode

Use Manual Mode when Auto Mode fails to bring one or more of the terms into specification. Manual Mode lets you iterate through the process yourself, and decide when to stop.

  1. Select the [Manual Mode] tab. Illustration 10 shows this.

    (Step Details)

  1. Select the desired terms, and then press [Scan].

  1. If the “Prompt To Accept” mode is active, after the scan is complete, a graph of the results will pop up (see Illustration 11). In order to learn about “Prompt To Accept” refer to Grafidy 3 Tools, section 7, manual mode.

    (Step Details)

  1. If a “good fit” is shown, click the [Accept] button. The calibration values will be saved to disk, and these values will be used in the next scan. Repeat this process by going back to Step 2.

  1. If a “bad fit” is shown, click [Cancel]. This will leave the last accepted values in the calibration files. Do not expect any improvement on future scans when the fit doesn’t match the data even if you accept the cal parameters.

  1. The last iteration for any component must be a check only, and you should not accept the fit parameters. You will not be allowed to exit immediately after updating the cal parameters.

  1. In order to know more about Grafidy, refer to Grafidy 3 Tools. or if problems are encountered, see Grafidy 3 Troubleshooting.

4  Finalization

  1. Remove Fixture from the system.

  1. Exit the Software Tool.
