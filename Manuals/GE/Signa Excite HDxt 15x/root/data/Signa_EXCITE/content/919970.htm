4.1  Instructions for Software Release 20.x or 21.x

4.1.1  Loading Host Operating System Software

NOTICE
The software load can be corrupted if the following conditions are not met:

  • Check SaveInfo script executed.

  • System Monitor turned On.

 
 

  1. Insert the Linux OS Software DVD into the DVD-ROM drive of the host computer.

  1. Reboot the host computer.

  1. At the boot prompt, type the appropriate code for the keyboard in use, then press <Enter>:

    Keyboard LanguageCode
    EnglishGEHCMR
    FrenchGEHC?R
    PortugueseGEHCMR
    ItalianGEHCMR
    SpanishGEHCMR
    GermanGEHCMR
    SwedishGEHCMR

  1. The OS software load takes about 13 minutes.

    NOTE:As the install begins, it queries all physical drives in the system and builds/partitions all available devices. If the disk is not what the system expected, a warning indicating a bad disk may display. Software will fix during the install. Click [Ignore] to proceed with the install.

    After about 90 seconds, a progress message displays, indicating that the install image is being transferred. (Shown below.)

    Illustration 1:  Transferring Install Image to Hard Drive

    Two minutes later, an additional message displays indicating that the install process has begun. (Shown below.)

    Illustration 2:  Starting Install Process

  1. Once the installation is complete, ensure the disk is removed from the drive. Do not insert the Applications DVD at this time!

  1. When the OS software is loaded, a Complete and Reboot screen (shown below) displays indicating that the system needs to be rebooted. Press <Enter> to reboot the PC.

    Illustration 3:  Complete and Reboot

  1. When a terminal window displays after a couple of minutes, the OS software load is complete. Continue to the next section.

4.1.2  Loading MR Applications Software

  1. Insert the MR Applications DVD into the DVD drive of the Host computer.

  1. When the Warning window (shown below) displays, click [Run Command] to confirm the run.

    Illustration 4:  Confirmation Window

    The system begins partitioning the hard drives. A progress window displays. (Shown below.)

    Illustration 5:  Disk Partitioning Screen

    The system reboots automatically when the partitioning is complete. Do not interact with the system.

  1. When the Locale Selection window (shown below) displays, select the proper locale and language, then click [OK].

    Illustration 6:  Select Location

  1. The Guided Install screen will display. When the Message screen (shown below) displays indicating the improvements made from the previous software version, click [OK] to continue.

    Illustration 7:  Guided Install Upgrade Screen

  1. When the Guided Install Configuration Media Dialog window displays, confirm the type of media to use to restore the Guided Install Configuration. (Shown below.)

    Illustration 8:  Install Configuration Media Window

NOTICE
The last installed GUI configuration can only be installed if it was previously saved using Save GI Configuration.
 
 

NOTE:If you have a host computer with a single DVD drive, complete the following steps to perform a Save Info:

  • Eject the MRApps DVD by right clicking on the desktop and choosing "Eject Media" from the menu.

  • Insert the Save Info DVD. Proceed with the Guided Install Load (See Step 6 to Step 10).

  • When the Guided Install Load is complete, eject the Save Info DVD and reinsert the MrApps DVD. Continue with the MR Applications load (See Step 11).

  1. Insert the Save Info DVD. Verify that the correct values are restored by checking each tab in the next step. Click [OK] to reinstall the last GUI installation configuration values.

    • The SaveInfo files are not restored at this point in the software load, but will be restored later.

    • If the GUI configuration was not saved, or the load is being performed for the first time, click [Cancel] to continue manually with the installation.

  1. Select Basic Configuration tab shown in Illustration 9. Verify that all values under this tab are configured properly, including Time/Date.

    • If failures are noted, click on the failure, then click [Go to Tab].

    • If any parameter does not match the expected criteria, the values in the left column will be red. If everything is acceptable, all values remain black. A changed value is indicated in blue.

    Illustration 9:  Guided Install - Configuration Screen

  1. If the Guided Install configuration was successfully restored from the DVD, it is not necessary to change any of the parameters.

    1. Check the parameters on the Verification tab, and confirm there are no failures. If there are failures, make the necessary changes.

    1. Make sure all required configuration tabs are filled out (not in any specific order) before continuing. The Verification tab lists any formatting errors as well as current settings.

  1. Set the Scan Range to proper value by selecting the System Configure option under the Basic Configuration option. If the length of the Magnet Room is less than 21.5 ft. (6.5 m), select [Short]. If the length is greater than 21.5 ft. (6.5 m) select [Long]. (See the following illustration.)

    Illustration 10:  Guided Install - Configuration Screen

NOTICE
If loading software for the first time on a Host PC, the initial boot up will fail. Manually enter the Term Server information (found on the front of the terminal server in the PGR cabinet) on the Network Info screen shown in Illustration 9.

Example format: 20:2D:90:22:44. Use colons between two digits; letters are case sensitive.

 
 

  1. Proceed to the Verification tab shown in Illustration 11.

    1. Look for any items with a Fail status. Go to the tab with the error and correct it.

    1. Click [Install] to open the Verification tab again.

      NOTE:Failed entries are due to missing or incorrectly formatted entries. The [Install Software] button is inactive if there are failures.

      Illustration 11:  Guided Install - Verification

  1. If all entries pass verification at this point, click [Install Software] to begin the MR Applications load. If the time and time zone are correct, click [Confirm] to proceed. (Shown below.)

    Illustration 12:  Confirming Local Time

    NOTE:A Software Installation in Progress message will display. The MR Applications load will take 5-10 minutes, depending on the host PC.

  1. Once the MR Applications load is complete, a confirmation message (shown below) displays. Click [OK] to close the window.

    Illustration 13:  Guided Install - Software Installation Completed

    NOTE:If the Run Warning message (shown in Illustration 4) displays, click [Cancel] to exit the auto run.

  1. The GUI returns to the Guided Install window. Under the Utilities tab in the left navigation, select Save/Restore to open the Save/Restore screen shown in Illustration 14.

    1. If the DVD with the saved configurations is not available, go to each tab in the Install GUI and complete all system information manually. A [Help] button that provides information on the required data and its format is available on each tab.

      Illustration 14:  Save/Restore Screen

    1. If the DVD with saved configurations is available, click [Restore Information], and select the proper medium from the dialog box. (See Illustration 8.)

    1. When the Restore Info Dialog box (shown below) displays, click [Restore all files automatically], then click [Continue].

      Illustration 15:  Restore Option Window

      NOTE:If restoration fails, the DVD automatically ejects the disc. Exit the Guided Install and allow the system to reboot. When the system restarts, return to the Guided Install and attempt to Restore Info again.

  1. A RestoreInfo in Progress window scrolls filenames as they are restored.

    • When the restoration is completed, an Update Utility message (shown below) displays.

      Illustration 16:  Guided Install - Update Utility Message

    • Click [OK] to open the Restore Manager dialog window shown below.

      Illustration 17:  Guided Install - Restore Utility

  1. Select All to restore all items, and click [Update]. When the update is finished, click [Quit].

  1. Click [Yes] when the Quit Tool message (shown below) displays.

    Illustration 18:  Quitting Restore Manager

    • The message shown in Illustration 19) confirms that a log file was created. Click [OK] to finish.

    • The MR Applications software load is now complete.

    Illustration 19:  Log File

  1. Reboot the system, by selecting [Desktop] on the left corner of the monitor, then [Logout], then [Restart the computer], and then [OK].

  1. Log in to the system as [root] (password is [operator])

  1. Click [Yes] to start Guided Install.

  1. Remove the MR Applications DVD.

  1. Proceed to the next section.

4.1.3  Loading and Configuring VRE Software

  1. From the Guided Install interface left navigation menu, select VRE Configuration.

    1. When the VRE Configuration screen (shown below) displays, verify VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.

      Illustration 20:  VRE Configuration Screen

    1. Click [Configure VRE Blades] shown in Illustration 20.

  1. When the Information window (shown in Illustration 21) displays, click [Continue] to confirm that the VRE Gigabit Switch Ethernet and Host Ethernet connections (Illustration 22) are complete and correct.

    Illustration 21:  Confirm VRE Installation

    Illustration 22:  VRE Gigabit Switch and Host Ethernet Connections

  1. When the VRE window asks for the number of connected VRE Blades, select the proper number of Image Compute Nodes (ICNs) (based on the number of ICNs found in the PGR cabinet): 1 or 2, and click [OK].

    The system needs to be configured for 1 or 2 ICNs. This procedure will take between 15-20 minutes depending on the number of ICNs (blades) in the system.

  1. A VRE Configuration Progress Details window shown below will display.

    Illustration 23:  VRE Configuration Progress Details

    NOTE:If you see an error in detecting the ICNs (VRE Configuration failed) during VRE configuration, complete the following steps:

    • Power Down the ICN.

    • Disconnect the power cable from the back of the ICN, wait for 30 seconds, and reconnect it. The SUN ICN has 2 power sources. Both should be connected almost simultaneously (at most within 5 seconds of each other).

    • Restart VRE Configuration from Guided Install.

  1. When VRE configuration is complete, a configuration Success message is displayed. Click [OK] to continue.

  1. If the site has IRM (In Room Monitor), in the Guided Install window select IRM Installation and then select the [Install IRM Software] button. (Shown below.)

    Illustration 24:  IRM Installation Screen

  1. If this is the first or initial software load, perform a Term Server Reset by executing the following steps. Otherwise, proceed to Step 8.

    1. Remove the power connector from the Term Server. (Shown below.)

      Illustration 25:  Reset Term Server

    1. Press and hold the small square Reset button (next to the power jack), and connect power to the Term Server while continuing to depress this button.

    1. Continue depressing the Reset button for 20 seconds.

    1. Verify communication between the Host PC and Term Server:

      1. Open a C-shell terminal.

      2. Ping the ts1 address by typing: ping hostname-ts1 (where hostname is the hospital name) and press <Enter>.

        • Proper communication should display as shown below.

          Illustration 26:  Ping ts1

        • If an improper response of Host Unreachable (shown below) displays, repeat the Term Server Reset procedure in Step 7.

      Illustration 27:  Communications Error Message

    1. To stop the test, press <Ctrl-c>.

  1. When the Information window confirms that the configuration is complete, click [OK].

  1. Load Service Software: See Loading or Deleting Proprietary Software.

4.2.3  Loading and Configuring VRE Software

  1. From the Guided Installation interface left navigation menu, select VRE Configuration.

    1. When the VRE Configuration screen displays, verify VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.

      Illustration 49:  VRE Configuration Screen

    1. Click [Configure VRE Blades].

  1. When the Information window displays, click [Continue] to confirm that the VRE Gigabit Switch Ethernet and Host Ethernet connections are complete and correct.

    Illustration 50:  Confirm VRE Installation

    Illustration 51:  VRE Gigabit Switch and Host Ethernet Connections

  1. When the VRE window asks for the number of connected VRE Blades, select the proper number of Image Compute Nodes (ICNs) (based on the number of ICNs found in the PGR cabinet): 1 or 2, and click [OK].

    The system needs to be configured for 1 or 2 ICNs. This procedure will take between 15-20 minutes, depending on the number of ICNs (blades) in the system.

  1. IMPORTANT: A pop-up message will prompt the user to insert the VRE OS disk for copying the ICN OS contents onto the hard drive. Insert the Linux OS Software DVD into the DVD-ROM drive of the host computer and click [OK]. VRE configuration progress details will display while ICN OS contents are being copied.

    Illustration 52:  Insert Linux OS Disk Pop-Up

    Illustration 53:  VRE Configuration Progress Details

  1. If the site has In-Room Monitor (IRM) , in the Guided Install window, select IRM Installation and then click the [Install IRM Software] button.

    Illustration 54:  IRM Installation Screen

  1. If this is the first or initial software load, perform a Term Server Reset by executing the following steps. Otherwise, proceed to Step 9.

    1. Remove the power connector from the Term Server.

    1. Press and hold the small square Reset button (next to the power jack), and connect power to the Term Server while continuing to press this button.

    1. Verify communication between the Host PC and Term Server:

      1. Open a C-shell terminal.

      1. Ping the ts1 address by typing: ping hostname-ts1 (where hostname is the hospital name). Press <Enter>.

      • Proper communication should display as shown below.

        Illustration 56:  Ping ts1

      • If an improper response of Host Unreachable displays, repeat the Term Server Reset procedure.

        Illustration 57:  Communications Error Message

    1. To stop the test, press <Ctrl-c>.

  1. When the Information window confirms that the configuration is complete, click [OK].

  1. Load Service Software. Refer to Loading or Deleting Proprietary Software.
