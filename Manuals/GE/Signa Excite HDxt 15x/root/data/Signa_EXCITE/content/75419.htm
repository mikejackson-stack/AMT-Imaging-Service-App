CPD Board Setup and Calibration

This procedure describes the setup and calibration of the Communications Pin Driver (CPD) Board in the System Support Module (SSM)

NOTE:This procedure is not applicable for systems with PHPS (Patient Handling Power Supply) on the Pen Panel.

The SSM Cal Switch procedure must be completed. The remaining procedures below maybe optional. Descriptions are given for each.

  • SSM CAL Switch.

  • POWER MONITOR TYPE CONFIGURATION. This procedure is required only after CPD Board replacement.

  • MULTI-COIL OPTION. This procedure is used for troubleshooting only.

  • PAC VOLTAGE CONFIGURATION. Required only for sites without a fiber optic repeater.

  • T/R VOLTAGE ADJUSTMENT WITH PULSE TRAIN. Troubleshooting only, Not part of the standard calibration procedure.
