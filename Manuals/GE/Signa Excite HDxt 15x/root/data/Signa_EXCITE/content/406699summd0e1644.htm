NOTE:When all 24 slices are taken, the finished map displays on the field map screen shown in Illustration 15. ShimTool automatically assigns a sequential alphabetic name to both the displayed map and the .map file it creates. The file name consists of:

  • The magnet series and number information entered on the Register Magnet Type screen shown in Illustration 6, Field Camera Set-Up Using ShimTool (W0 + 0009 becomes W00009; WB + 0002 becomes WB0002.)

  • A sequential alphabetic character (A, B, ... C becomes 0000A, 0000B, ... 0000C.)

  • The test cell entered on the Register Magnet Type screen shown in Illustration 6, Field Camera Set-Up Using ShimTool. Always use test cell “W” when shimming at a customer site.

  • Plus the .map file extension.
