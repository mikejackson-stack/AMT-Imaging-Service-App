LX (SGI-based) System Software shutdown

  1. Toggle mouse control to the PC monitor using the hard key on the top left side of the keyboard housing.

  2. From the PC monitor, use the mouse to select Start → Shutdown → Shut down. Bring the Signa software down.

  3. Toggle mouse control back to the Signa monitor using the hard key on the top left side of the keyboard.

  4. Click [Toolbelt].

  5. Click [System Shutdown] on the Service Desktop Manager.

  6. Click [OK] to confirm the shutdown.

  7. Wait for the system to indicate on the monitor that it is safe to power off the computer before proceeding. This usually takes about 90 seconds.

Horizon (Genesis console) System Software shutdown

  1. Touch [Utilities].

  2. Touch [System Shutdown].

  3. Select [OK] to confirm the shutdown.

  4. Wait for Boot Prompt (this indicates it is safe to proceed).
