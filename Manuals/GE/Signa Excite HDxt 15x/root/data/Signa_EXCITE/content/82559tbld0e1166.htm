Table 11:  RRF-DIF BOARD DIAGNOSTICS

TEST NAMETEST DESCRIPTION
IO StatusVerifies various RRF values, states: RF Out switch state, 20Mhz clock, Rx Signal detect, Tx Ready, Link Ready, GB State, 3.3V present, 5.0V present, Feeder Diag state, Loopback DIag state, and FPGA reset state.
Reset FPGAThis tests that the FPGA can be reset.
Feeder TestMult-Coil Voltage test done in Driver Module.
Loop Back TestThis places the RRF-DIF Link FPGA into loopback mode. No data is transferred and nothing else is tested. This mechanism, in the future, will be used by another diagnostic to perform a loopback test.
Query A2D ValuesVerifies the RRF-DIF Analog to Digital 3.3V and 5.0V levels.
