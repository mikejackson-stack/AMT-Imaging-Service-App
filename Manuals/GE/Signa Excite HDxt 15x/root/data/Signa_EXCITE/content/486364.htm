Signa HDxt Service Methods
Module Version  2.0,  Version Date  6/18/09

System Power On

  1. Confirm PDU main disconnect locks and tags are in place.

  2. Refer to 5113474 Teal PDU in HFD Cabinet

    • Input voltage selection terminal block for each of the three phases.

    • Overload and short circuit trip settings for the main input circuit breaker.

  3. Notify field service and other installation personnel that are working at the installation site that the PDU main disconnect locks and tags will be removed so that PDU power can be turned on.

  4. Restore power to the PDU from the main disconnect.

  5. Switch on the PDU’s main input circuit breaker.

  6. Press EMO RESET button on the PDU front control panel.

  7. Except for Gradient Cabinet power modules, switch all cabinet circuit breaker to ON. The Gradient Cabinet Power Module circuit breakers should remain OFF until room humidity stabilizes under 60%.
