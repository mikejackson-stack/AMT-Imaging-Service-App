15.x MR APPS Software Load

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

All media must be removed during applications load, disk partitioning, and application software load. This includes additional DVDs, MODs, and USB devices (e.g., Service Keys). Failure to remove can cause software load failure.

-

2  Procedure

2.1   Instructions for Software Release pre-15.0_M4B

  1. Insert Applications disk.

    1. For HP9300 PC, insert Applications CD into the Host CD drive in the GOC. Do not use the CD drive on the SCSI tower.

    1. For HP8400 PC, insert CD into top DVD drive on computer.

  1. The following confirmation window opens.

    (Step Details)

  1. Click [Run Command].

  1. A message box opens warning to turn off power to the DASM if installed. See Illustration below.

    (Step Details)

  1. Continue with the software load. The system is now partitioning the hard drives. See illustrations below. No action is required.

    (Step Details)

  1. A window opens indicating that the system will automatically reboot after two minutes.

  1. The Locale Selection window opens prompting you to select the proper locale. Select the language, and click [OK]. See illustration below.

    (Step Details)

  1. The Guided Install page opens.

  1. Another window opens indicating improvements made from the previous software version. Click [OK].

    (Step Details)

  1. Insert the SaveInfo MOD or CD/DVD if a GI configuration has been saved. Click [OK] to reinstall your last GI installation's configuration values.

    (Step Details)

  1. A message box indicates ‘Restoring the Guided Install GUI configuration’. A Select media message box appears. See illustration below.

    (Step Details)

  1. Select the media for the Guided Install, either MOD or CD/DVD. (The normal SaveInfo files are not restored at this point in the software load. They will be restored later.) Click each tab to check each section to verify that the correct values are restored.

  1. If any parameters do not match the expected criteria, the left column will be red. If everything is acceptable, all values will be black. If the value is changed, it will be noted in blue. See illustration below.

    (Step Details)

  1. Go to System Configure under Basic Configuration.

  1. Verify that the correct Video Card and Display Type (LCD Monitor) for your system are selected.

    (Step Details)

  1. To determine the Video Card model, open a command window and login as root.

  1. Type the command: cat /proc/driver/nvidia/cards/*

  1. If the correct Video Card and LCD Monitor model are selected, then skip to Step 20.

  1. In the Video Card box, select the correct video card model using the drop-down menu. In the Display Type box, select the correct LCD monitor model using the drop-down menu.

  1. Proceed to the Verification tab on the left menu (see illustration below). Once in the verifications tab look for any pass or fail status, the [Install Software] button will not be active if there are any failures. Failed entries will be due to missing entries, or entries not in the correct format.

  1. Go to the tab with the error and correct it, and then click [Install] to re-open the Verification tab.

  1. If all entries pass verification, click [Install Software] again to begin the MR Apps load (see Illustration below). A message window prompts you to verify Time and Zone. Click [Confirm] to continue or [Abort] to return to the Time/Date. The verification window opens.

    (Step Details)

  1. Once the MR Apps load is completed the following confirmation window opens. Click [OK].

    (Step Details)

  1. There may be a message window prompting: “Do you want to run media/cdrom/autorun?” Click [NO] or [Ignore]. Do not click [Yes].

  1. The GUI will change from the Install phase.

  1. Important: you must remove the Apps CD from PC.

  1. If a SaveInfo info MOD or CD/DVD is not available, go to each tab in the Install GUI and fill in or update all system information manually. A help button is available on each tab, which will open a pop up box with information on the required data and its format for that page.

    (Step Details)

  1. To restore info, follow these steps:

    1. Select [Save/Restore], then [Restore Information].

    1. The Save/Restore window prompts you to restore all files or selected files. See Illustration below. Select [Restore Information], then select the proper media, either MOD or CD/DVD. Click [Restore all files automatically].

      (Step Details)

    1. The RestoreINFO in Progress window will scroll filenames as they are being restored

    1. When the RestoreINFO is finished a window opens prompting you to run the update utility. See Illustration below.

      (Step Details)

    1. Click [OK] . The Restore Manager menu opens. See Illustration below.

      (Step Details)

    1. Select the All box so that all items are restored. Click [Update]. When update is finished click [Quit] and then [yes].

    1. In the confirmation window, click [OK]. If the update is successful, click [Quit].

      (Step Details)

    1. Click [OK].

      (Step Details)

    1. Reboot the system by entering reboot in a C-shell.

    1. Log into system as root, username is root, password is operator.

    1. When prompted, click [Yes] to start Guided Install.

  1. Proceed to VRE Configuration for Software Releases Pre-15.0_M4B.

2.2   Instructions for Software Release 15.0_M4B and Higher

  1. Insert the MR Applications DVD into the DVD drive of the Host computer.

    1. For HP9300 PC, insert Applications CD into the Host CD drive in the GOC. Do not use the CD drive on the SCSI tower.

    1. For HP8400 PC, insert CD into top DVD drive on computer.

    1. For HP Z400 PC, insert CD into sole DVD drive on computer.

  1. After inserting the MR Applications DVD, an alert box displays, indicating that the MR Applications Software Installation is in progress. If you do not see this alert, right-click on the desktop and choose Install MRApps from the menu to begin installation.

    (Step Details)

  1. When the Locale Selection window displays, select the proper locale and language, then click [OK].

    (Step Details)

  1. The Guided Install screen displays. When the Message screen shown below displays, indicating the improvements made from the previous system version, click [OK] to continue.

    (Step Details)

  1. Remove the MRApps DVD from the drive.

  1. When the Guided Install Configuration Media Dialog window displays, select the type of media you will use to restore the Guided Install Configuration.

    (Step Details)

  1. Insert the Save Info DVD or MOD. Proceed with the Guided Install Load. (See Step 8 through Step 17.)

NOTICE
The last installed GUI configuration can only be installed if it was previously saved using Save GI Configuration.
 
 

  1. Verify that the correct values are restored by checking each tab in the next step. Click [OK] to reinstall the last GUI installation configuration values.

    (Step Details)

  1. Select Basic Configuration tab shown below. Verify that all values under this tab are configured properly, including Time/Date.

    (Step Details)

  1. If the Guided Install configuration was successfully restored from the DVD, it is not necessary to change any of the parameters.

    1. Check the parameters on the Verification tab and confirm there are no failures. If there are failures, make the necessary changes.

    1. Make sure all required configuration tabs are filled out (not in any specific order) before continuing. The Verification tab lists any formatting errors as well as current settings.

NOTICE
If loading software for the first time on a Host PC, the initial boot-up will fail. Manually enter the Term Server information on the Network Info screen shown in Illustration 21.

Example format: 20:2D:90:22:44. Use colons between two characters; letters are case sensitive.

 
 

  1. Go to System Configure under Basic Configuration.

  1. Verify that the correct Video Card and Display Type (LCD Monitor) for your system are selected.

    (Step Details)

  1. To determine the video card model, open a command window and login as root.

  1. Type the command: cat /proc/driver/nvidia/cards/*.

  1. If the correct video card and LCD monitor are selected, then skip to Step 17.

  1. In the Video Card box, select the correct video card model using the drop-down menu. In the Display Type box, select the correct LCD monitor model using the drop-down menu.

  1. Proceed to the Verification tab (shown below).

    1. Look for any items with a Fail status. Go to the tab with the error and correct it.

    1. Click [Install] to open the Verification tab again.

    (Step Details)

  1. If all entries pass verification at this point, click [Install Software] to begin the MR Applications load. If the time and time zone are correct, click [Confirm] to proceed.

    (Step Details)

  1. A pop-up message will display (shown below). Remove the SaveInfo disc from the DVD drive and insert the MRApps DVD.

    (Step Details)

  1. Once the MR Applications load is complete, a confirmation message displays. Click [OK] to close the window.

    (Step Details)

  1. The GUI returns to the Guided Install window. Under the Utilities tab in the left navigation, select Save/Restore to open the Save/Restore screen.

    (Step Details)

  1. A RestoreInfo in Progress window scrolls file names as they are restored.

    (Step Details)

  1. Click [Yes] when the Quit Tool message displays.

    (Step Details)

  1. Reboot the system by right-clicking on the desktop.

  1. Log in to the system as root. (Password is operator)

  1. Click [Yes] to start Guided Install.

  1. Remove the SaveInfo disc.

  1. Proceed to VRE Configuration for Software Release 15.0_M4B and Higher.

2.3   VRE Configuration for Software Releases Pre-15.0_M4B

Load VRE software by doing the following:

  1. Go into Guided Install and Select “Configure VRE”. (Shown below.)

    (Step Details)

  1. Verify that the VRE Blades are properly installed and all hardware connections are in place including Ethernet connections.

    (Step Details)

  1. Click on [Configure VRE Blades].

  1. Select the proper number of ICNs of 1, 2 or 4.

    (Step Details)

  1. This procedure will take between 15-20 minutes to complete depending on the number of ICNs blades in the system.

2.4   VRE Configuration for Software Release 15.0_M4B and Higher

Load VRE software by doing the following:

  1. Go into Guided Install and Select “VRE Configuration”. (Shown below.)

    (Step Details)

  1. Verify that the VRE Blades are properly installed and all hardware connections are in place including Ethernet connections.

    (Step Details)

  1. Click on [Configure VRE Blades].

  1. Select the proper number of ICNs of 1, 2 or 4.

    (Step Details)

  1. Insert the VRE OS DVD into the host computer.

  1. This procedure will take between 15-30 minutes to complete depending on the number of ICNs blades in the system.

2.5   Term Server Reset - All Software Releases

  1. If this is the first or initial software load, perform the Term Server Reset Procedure by executing the following steps:

    1. Remove power connector from Term Server.

    1. Press and hold the small square button, labeled 'reset' next to power jack.

    1. Connect power to term server, while continuing to hold in reset button.

    1. Continue to hold reset button for 20 seconds.

      (Step Details)

NOTICE
If the system will not properly boot on the first attempt, the Term Server may need to be reset. Perform the Term Server reset procedure in Step 1.
 
 

  1. Exit the Guided Install screen by selecting File, then Quit.

2.6   Loading Restricted Service Software - All Software Releases

NOTE:For installing the software using the e-licensing , refer to 2397845 Signa Software Option Install with eLicense.

NOTE:It is necessary to shut down the software before attempting to load the Restricted Service or Advanced Service CDs. These should not be loaded with Applications software running.

  1. Reboot the system by selecting [Desktop] on top left corner of monitor, then [Logout] then [restart the computer] then [OK]

  1. Log into the system as root, password is operator and load Restricted or Advanced Software if applicable.

  1. If applicable, reconnect the DASM.

  1. Click [yes] to start the Guided Install GUI.

  1. Remove the APPS CD and insert the Service Software CD and click the Service SW/InSite option, located near the bottom of the Guided Install menu. Then select the Load Restricted Software option. The system will respond with a window as shown below. Read the proprietary statement and continue by sequentially clicking the “1,2,3” buttons and then click [OK].

    (Step Details)

  1. Insert your normal SaveInfo MOD/CD/DVD or a new MOD/CD/DVD into the drive if not already in the drive.

  1. At the top left of the Install GUI, select [File] then [Save GI Configuration to MOD]. This will save the information that has been entered in all the edit fields in the GUI.

  1. Remove restricted CD from the system.

2.7   Loading Service Methods - All Software Releases

NOTE: The Service Methods CD can be loaded onto the software platform. The load will take approximately 12 minutes to complete.

  1. Insert the Service Methods CD into the CD-ROM drive in the PC. Click on [Install Service Documentation]. (Shown below.)

    (Step Details)

  1. A window as shown below will be displayed – click as appropriate.

    (Step Details)

  1. After the installation of the CD contents, remove the CD from the system by going to the Service Desktop – home – bottom left “Unmount CD”.

  1. Right Click on the mouse, and select “Logout”. You can now boot applications by selecting username of sdc and password of adw2.0.

  1. Finally, as a part of Software Setup, load the Operator Manual DVD in the local language.

    (Step Details)
