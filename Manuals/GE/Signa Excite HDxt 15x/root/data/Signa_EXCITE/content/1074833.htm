Universal Power Monitor - MNS Setup and Calibration

(Click Here for Summary Version)

Required PersonsPreliminary ReqsProcedureFinalization

2  Overview

This procedure sets up the Universal Power Monitor (UPM) in MNS Mode by using the system and the Power Measurement Kit.

4  Procedure

4.1  MNS Forward Power Calibration

  1. Inhibit TR faults. Disable the Driver Module TR fault detection in the RFS (RF in the system cabinet). See Illustration 1. Move Switch SW2 to the TR Disable position.

    Illustration 1:  Driver Module Front Switches

  1. Remove the MNS Heliax cable from the back of the MNS Amplifier and connect the RF dummy load as indicated in Illustration 2.

    Illustration 2:  Setup for MNS Output Measurement

4.2  Setting up Software Tool to Calibrate UPM – Head Forward Power

NOTE:This tool must have the head coil installed in order to enable Coil ID.

  1. To establish a Landmark, Start a [New Pt].

  1. Enter the following parameters:

    1. Patient ID: geservice

    1. Weight: 111

  1. Install the head coil.

  1. Align the head coil to the alignment light.

  1. Press [Landmark] to drive the coil into the bore.

  1. Start the UPM Calibration Tool.

    • Restricted Service tools available to GE Field Service. Make sure your service key is installed. Select [Calibration Wizard] from the Calibration menu and then select [Click here to start this tool]. Once the Calibration Wizard starts, select [UPM Calibration (Head and Body)] from the menu, review and validate the pre- and post-dependencies. Select [Click here to start this tool] to start the procedure. If you are unable to start the Restricted Service tools, use the non-proprietary method described in the next bullet.

    • To start non-proprietary service tools: From the Common Service Desktop, select [Calibration], [UPM Tool] from the Calibration Menu, then select [Click here to start this tool] to start the procedure.

    Illustration 3 shows an example of the UPM tool's user interface.

    Illustration 3:  UPM Monitor Tool User Interface

  1. Select Nuclei [31P].

  1. The RF Chain will then default to MNS.

  1. Select [Forward] for the Power Monitor type.

  1. Select [Calibrate.]

  1. Select [Start ] and validate your hardware setup, then select [Yes].

    NOTE:Advisory message indicating head coil not present can be ignored.

  1. Verify that the status indicates a Pass or Fail within five minutes (tool should notify user of current step in progress). If failure occurs, see Universal Power Monitor (UPM) Troubleshooting.

  1. Proceed to the UPM MNS Functional Check procedure before moving to Finalization, Step 1

5  Finalization

  1. Remove the cables and power measurement equipment.

  1. Re-attach the MNS Heliax cable.

  1. Re-enable TR Drive fault detection. See Illustration 1.

  1. Upon completion of any UPM calibration, [Reset TPS]. The system will not scan until this step is complete.
