Installing Codonics Printer for BrainWave or SAGE

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

Signa Software is installed and configured.

-

-

2  Procedure

  1. If Signa applications are up and running, restart the computer by right-mouse clicking on [Service Tools], then [System Restart].

  1. From the Signa log in screen, type root for the user name and operator for the password. (Do not access Guided Install.)

  1. Right-mouse click to display the Printer configuration screen shown in Illustration 1.

    (Step Details)

  1. Click on the New icon shown in Illustration 1.

  1. Click [Forward].

  1. Enter the Name of the Codonics Printer as GENNavprntr (case sensitive), shown in Illustration 2. (This exact name must be used for Brainwave. For the SAGE option, the name is not important.)

    (Step Details)

  1. Enter the Queue type as Networked UNIX (LPD), then select [Forward].

  1. Enter the Host Name or IP Address for the server. (Example IP Address: 10.1.11.11.)

  1. Enter the Queue name as 2.a-cvp, then select [Forward].

  1. For the Printer Model, select Postscript printer, then [Forward].

  1. Click [Apply]. The printer test page should print successfully at this time.

3  Finalization

  1. To verify SAGE is printing:

    1. Open the SAGE option.

    1. Select File, then Print. A GUI will display.

  1. In the Printer text field, remove the default printer and enter the name of the printer that was used in Step 6.
