Coil Configuration File

1  Procedure

1.1   Adding Coils

  1. In the Config File Manager screen, select [Coil Config File].

  1. Select the coil(s) to be added to the site’s configuration by clicking on the desired coil name(s) in the Available Coils list. See Illustration 1

  1. Click the [>>ADD>>] button to add the selected coil(s) to the Site Coils list. You must reboot Signa for scan to recognize that a coil has been added to the list.

1.2   Adding Coils For LX to Excite Upgrades

  1. On the Config File Manager screen, select [Coil Config File].

  1. From the Available Coils list, select these coil names

    (Step Details)

  1. Click the [>>ADD>>] button to add the selected coil(s) to the Site Coils list.

  1. Exit and save your changes by clicking [Quit], [Yes], and then [Save].

  1. Reboot Signa for the coil changes to take effect.

    (Step Details)

1.3   Deleting A Surface Coil

For new Excite installs for 4.x/5x upgrades, be sure to leave the 8 TRPA test, TRPA1234, and TRPA5678 coil names in the “Site Coils” list when removing non-site coil names. They must be in the list in order for the MCR tool to run.

  1. On the Config File Manager screen, select [Coil Config File]. See Illustration 2.

    (Step Details)

  1. Select the coil(s) to delete in the Site Coils list by clicking on the coil name(s). See Illustration 1.

  1. Click the [Remove] button to delete the selected coil(s) from the Site Coils list. You must reboot Signa for scan to recognize that a coil has been deleted from the list.

1.4   Editing Coil Values

  1. On the Config File Manager screen, select [Coil Config File]. See Illustration 2.

  1. Select the appropriate coil(s) (you can select more than one coil) in the Site Coils list by clicking on the coil name(s) and then clicking the [Edit Coil] button. See Illustration 3.

    (Step Details)

  1. The Coil Edit screen displays the present values of the selected coils. See Illustration 4. To change a value, click in the field to enter text or tab through fields and make the necessary changes.

    (Step Details)

  1. Click [OK] to close the screen.

  1. You must exit the tool and reboot Signa for scan to recognize the coil configuration changes.

1.5   Adding New Coils to Config File Manager

  1. On the Config File Manager screen, select [Coil Config File]. See Illustration 2.

  1. [Click the Add new Coil] button. See Illustration 3.

  1. The Add a New Coil screen displays the coil value fields for a new coil. See Illustration 5. Values for new coils are in the service manual provided with the coil. For the new “Multi Coil Recon Enable” field, enter 0 as the default unless instructed otherwise. Either click in the fields or tab through the fields to enter values.

    (Step Details)
