1  Required Conditions

ConditionReferenceEffectivity

If this is not a new install, perform a SaveInfo of all system settings before beginning the Software Install.

-

-

If planning to install a second monitor, do not install it until after the software installation is complete, or the software will not install properly.

-

2  Procedure

2.1   Instructions for Software Release Pre-15.0_M4B

NOTICE
The software load can be corrupted if the following tasks are not done:

  • Check Info Script executed.

  • DASM powered off.

  • System Monitor turned on.

  • SCSI tower on.

  • All USB devices (including Service Keys) are removed.

  • Any non-OS media are remove.

 
 

  1. Insert the MR PC Linux CD (current revision) into the CD drive of the PC.

  1. Reboot the computer.

NOTICE
The proper OS Load command must be entered for detection of the mouse and a foreign keyboard. At the boot prompt, type one of the following commands based on your keyboard type:

  • English Keyboard: GEHC-MR<Enter> (GEHC dash MR, no spaces).

  • French Keyboard: GEHC-?R<Enter> (GEHC dash question mark R, no spaces).

  • Portuguese Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces)

  • Italian Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).

  • Spanish Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).

  • German Keyboard: GEHCβMR<Enter> (GEHC Beta symbol MR, no spaces).

  • Swedish Keyboard: GEHC+MR<Enter> (GEHC plus sign MR, no spaces).

 
 

  1. At the boot: prompt, type: GEHC-MR and press the <Enter> key. (The OS software load takes about 13 minutes.)

    (Step Details)

  1. Remove the CD from the drive after the drawer opens. (Do not insert the MR Applications disk at this time.)

  1. When the OS software is properly loaded and the following message displays, press <Enter> to continue.

    (Step Details)

  1. The OS software load is now complete, so proceed to 15.x MR Applications Software Load.

2.2   Instructions for Software Release 15.0_M4B and Higher

NOTICE
The software load can be corrupted if the following tasks are not done:

  • Check Info Script executed.

  • DASM powered off.

  • System Monitor turned on.

  • SCSI tower on.

  • All USB devices (including Service Keys) are removed.

  • Any non-OS media are remove.

 
 

  1. Insert the MR PC Linux CD (current revision) into the CD drive of the PC.

  1. Reboot the computer.

NOTICE
The proper OS Load command must be entered for detection of the mouse and a foreign keyboard. At the boot prompt, type one of the following commands based on your keyboard type:

  • English Keyboard: GEHCMR<Enter>

  • French Keyboard: GEHC?R<Enter> (GEHC question mark R, no spaces).

  • Portuguese Keyboard: GEHCMR<Enter>

  • Italian Keyboard: GEHCMR<Enter>

  • Spanish Keyboard: GEHCMR<Enter>

  • German Keyboard: GEHCMR<Enter>

  • Swedish Keyboard: GEHCMR<Enter>

 
 

  1. At the boot: prompt, type: GEHCMR and press <Enter> .

    (Step Details)

  1. You will see a series of progress bars. The OS software load takes about 20 minutes.

    (Step Details)

  1. Once the installation is complete, the system reboots to a graphical user login prompt. Login as root. Password is operator.

    (Step Details)

  1. The OS disc will eject automatically. Remove it.

  1. The OS software load is now complete. Proceed to 15.x MR Applications Software Load.
