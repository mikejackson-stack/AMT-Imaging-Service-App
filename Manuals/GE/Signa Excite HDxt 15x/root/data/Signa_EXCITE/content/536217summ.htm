Configuring Laptop for Gradient Switch Communication

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

Disable any software running in the background on the laptop, such as Personal Digital Assistant (PDA) syncing or “Hotlink” programs, that take exclusive control of the COM1 port and will prevent HyperTerminal from using this port. Failure to do this will result in COM1 port availability errors when attempting to configure the port from HyperTerminal.

-

-

2  Procedure

  1. On the Taskbar, click [Start], [Programs], [Accessories], [Communications], and then [HyperTerminal].

    (Step Details)

  1. (For Laptop using Windows 98 or earlier) If HyperTerminal is not found, then it must be installed. Do the following:

    1. To open [Add/Remove Programs], click[Start], then [Settings], then [Control Panel], and then double-click [Add/Remove Programs].

    1. Select [Windows Setup].

    1. Scroll down the menu from the left scroll bar and select Communications.

    1. Scroll down the menu from the left scroll bar and click on the check mark box to the left of HyperTerminal. A check mark will appear in the left box when it has been selected. Click on [OK].

    1. On the Add/Remove Programs Properties window, click on [OK]. The system will indicate that it is attempting to load this program.

    1. Windows 95 users will, at this point, be asked to reboot. Click [Yes]. After the reboot, repeat Step .

    1. Windows 98 users will notice that the installation ends, but will not see any special prompt.

    1. Once HyperTerminal is installed, proceed to Step 3.

  1. In the Connection Description window, enter GradSwitch in the Name box.

  1. Select the GE logo as the icon and then click [OK].

  1. In the Connect To window, click on the arrow in the Connect Using box. Select [COM1] and then click [OK].

  1. Refer to Table 1 and configure the COM1 Properties windows as shown.

    (Step Details)

  1. Select and click on [OK] when done.

  1. From the File menu, select [Save]. This saves this configuration for future use as an entry labeled GradSwitch.ht.
