2  Procedure

2.1   Preparing for New Service Pack Installation

Any previously installed service pack must be removed prior to installing a new service pack.

  1. Back up your system by performing a SaveInfo.

NOTICE
For safety reasons, a service pack must be installed on the system at all times. Do not remove any service pack unless an alternate service pack is available for installation.
 
 

NOTE:If installing a service pack as part of Load From Cold (LFC), complete the LFC and the VRE configuration as described in the service manual, then install the service pack disk. (It is preferable to install the service pack disk after a test scan.)

  1. Restart the system and log in as root at the login prompt.

  1. When asked to invoke Guided Install, click [Yes]. (See Illustration 1.)

    (Step Details)

  1. Open Guided Install and select Patches in left navigation pane, and select the Patches tab.

    (Step Details)

  1. Under Installed Patches, uninstall the Service Pack for the system first, and then uninstall all the other patches by selecting each patch and clicking [Uninstall].

    (Step Details)

  1. After uninstalling the patches, restart the system by typing: reboot in a C-shell.

  1. To verify the patches are uninstalled, open a C-shell and type: getver. None of the patches should be listed. (This step is not actually required to uninstall, but is just for verification.)

2.2   Installing a Service Patch

The installation process is the same whether installing service packs from a disk that was sent to you from GE Healthcare or one that you burned.

  1. Log in as root at the login prompt.

  1. Insert the disk with the patches into the Host PC disk drive.

  1. In the Guided Install window, select Patches in the left navigation pane, and select the Patches tab.

  1. Select CDROM as the patch medium. The patches contained on the disk will be listed.

    (Step Details)

NOTE:The order of installation is important as there may be dependencies on other application patches that are required prior to installing a patch. Normally, install patches first and the Service Pack last. The Guided Install will not proceed until all required application patches are loaded, so the system cannot be damaged by attempting to install a patch before all its dependencies are met. If a message displays indicating that a dependent patch was not installed, simply install the required patch before proceeding.

  1. Select each patch and click [Install].

    (Step Details)

  1. After installing all the patches, restart the system by typing: reboot in a C-shell.

  1. To verify that all the patches are installed, open a C-shell and type: getver. Verify that the service pack just installed is listed. (This step is not actually required to complete installation, but is just for verification.)

  1. Perform a good-bye scan to ensure proper scanner operation.
