Unknown Coils Configuration Procedure

(Click Here to Return to Detailed Procedure)

1  Procedure

NOTICE
Read the following for information when upgrading your system.

  • If upgrading from 8.x, 9.x and 10.x only, the [Use parameters] selection criteria can be used. After confirming all fields in the lower portion of the window are filled, only [Add to CoilConfig] will be enabled.

  • If upgrading from 11.x, all options in selection criteria can be used. [Add to CoilConfig] is activated only when one of the options is selected in selection criteria.

 
 

  1. Launch the Common Service Desktop shown in Illustration 1.

    (Step Details)

  1. Click [CoilConfig] on the left side of Config File Manager (shown in Illustration 2), and click [Manage Unknown Coils] .

    (Step Details)

  1. Click the Unknown Coil pull-down shown in Illustration 3. The system will display the list of unknown coils as shown in Illustration 4.

    (Step Details)

  1. Select the coil to be configured from the pull-down shown in Illustration 4.

  1. Select or Insert the ID from the coil manufacturer in the Mapping criteria section of theManaging Unknown Coils window. (See Illustration 3.)

    (Step Details)

  1. If this is an unknown coil to GE that does not show up in the list, select [Use Parameters] shown in Illustration 2. (The coil manufacturer will need to provide the necessary information for each data field, which should be provided in the documentation provided by the coil manufacturer.)

    (Step Details)

  1. When finished, click [Add to CoilConfig] shown in Illustration 4.

  1. When a message box displays with, Do you want to add this coil to Coil Config NOW?, click [Yes], (see Illustration 5).

    (Step Details)

  1. Repeat Step 3 through Step 6 for all coils in the list of unknown coils.

  1. When finished adding coils, click [Quit] in the bottom right corner of the Manage Unknown Coils page, (see Illustration 4).

  1. Click [Save Changes] in the bottom right corner of the CoilConfigmain page, (see Illustration 2).

  1. Click [Quit] in the bottom right corner of the CoilConfig main page shown in Illustration 2.

  1. Reboot the software by right-clicking the mouse in a background window, and select Service Tools ⇒ System Restart, and click [Yes].

  1. Log back in when prompted with: Username: sdc Password: adw2.0.

  1. To verify the system recognizes the coil, perform a quick scan for all unknown coils without using geservice as the Patient ID.

2  Finalization

  1. Refer to the Functional Checks in the documentation supplied with the coil.

  1. Ensure it is working correctly.
