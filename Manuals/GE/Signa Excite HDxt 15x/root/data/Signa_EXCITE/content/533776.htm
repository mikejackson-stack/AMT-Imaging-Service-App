2  Terminal Server Diagnostics

2.1  Communications

The purpose of the Terminal Server Communications Functional Diagnostic is to verify the Terminal Server’s related configuration files, processes, and communications.

You can access full details about this test including theory, instructions, and troubleshooting directly from the test's Service Browser interface by clicking hyperlinked text or by clicking here to go directly to this diagnostic's the online help.

2.2  Loopback

The purpose of the Terminal Server Loopback diagnostic is to verify the Terminal Server hardware is functioning properly. In addition, test results identify port connections and whether they are attached properly.

You can access full details about this test including theory, instructions, and troubleshooting directly from the test's Service Browser interface by clicking hyperlinked text or by clicking here to go directly to this diagnostic's the online help.
