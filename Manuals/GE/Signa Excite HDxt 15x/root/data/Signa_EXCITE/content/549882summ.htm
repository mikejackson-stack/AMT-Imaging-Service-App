Keyboard Functional Tests

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. On the Scan Desktop, end any patient exams that may be running at the time.

  1. Go to the Service Desktop and on the Common Service Desktop, go to the Diagnostics Tab and select [Keyboard Diags].

    (Step Details)

  1. To show the name of the button in the display area, select [Run] and then press one of the 5 hard key buttons. To remove the name from the display, release the hard key.

  1. Click the <Start Scan>, <Stop Scan>, <Move to Scan>, <Pause>, <Stop Move>, and <PC> buttons one at a time. Each should have a response in the display window.

  1. If there is no response from the system when pressing a particular keyboard key, check the cabling to the keyboard. If the cabling is OK, then replace that part of the keyboard.
