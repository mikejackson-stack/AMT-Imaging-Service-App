About this task

Follow this process to prepare for the automated SNR Test using the 1.5T 8-Channel Neurovascular Array Coil by Invivo (M3335M).

Note

Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.

Topic ID: id_SL2927057-585033

Unified Phantom Procedure

Procedure

  1. Place the base of the NV array coil on the patient table and latch it to the table as shown in NV Array Coil on Patient Table.
  2. Place the phantom positioner in the coil as shown in Phantom Positioner in the Coi.
  3. Place the phantoms in the positioner as shown in Phantoms in the Positioner.
  4. Carefully align the connector pins on the base of the coil with the top part of the coil and then latch both the coil sections into place as in Connector Pins Aligned on Base of Coil. (The scanner will not operate if the coil sections are not latched correctly).
  5. Connect the coil to Port A of the system LPCA. Landmark the coil at the cross mark as shown in Landmark the Coil and advance to scan.
  6. Run the Multi-Coil Quality Assurance (MCQA) Tool with the Unified Phantom Set.
