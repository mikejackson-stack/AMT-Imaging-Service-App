Setting up the Bird TT800V wattmeter

This procedure describes how to configure the Bird TT800V wattmeter to measure maximum forward power.

Procedure

  1. Press the power button on the top right section of the Bird TT800V wattmeter unit to turn on the wattmeter.
  2. Plug the M5014G sensor into the USB port located on the right side of the wattmeter.

    Result

    The application should automatically open after plugging in the sensor and show a list of available sensors.
  3. Select the M5014G sensor.
  4. Click the ellipsis on the top right corner of the screen and select Sensor Mode.
  5. Select 43 Peak.
  6. Click the menu bar on the top left corner of the screen and select Configuration.
  7. Select Smoothing(0,8,16,32,64,128).
  8. Select a smoothing level value.
  9. Locate the Element Offset Factors card in the kit and find the offset for the procedure being run.
    This output is used to make sure of an accurate measurement.
  10. Click the menu bar on the top left corner of the screen and select Configuration.
  11. Select Input Offset and enter the value found on the Element Offset Factors card.
  12. Select Forward Scale and enter 50000 for body channel or 5000 for head channel to set the range.
  13. Click the menu bar on the top left corner of the screen and select Readings.

Results

The meter is now ready to calibrate the RF amplifier output power.
Note The units will automatically update when power is being measured.
