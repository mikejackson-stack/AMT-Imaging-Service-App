Staged or SFIed GOC will bear a yellow color label and the staged GOC will come with a factory Save Info DVD. Prerequisites

  • Request customer to back up image data.

  • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.

  • Record the service license ID. Refer to “Access Service License ID 16-Digit Code)” in Service Licensing for specific information.

  • If the host PC, its components, or language change, then SSA licenses must be updated. On-site Internet connectivity is required. See Service Licensing for more information.

  • Check disk size for HP 8400 PC.

    1. In a C-shell, type su and press Enter. Enter password operator. Type fdisk -l | grep Disk and press Enter

    2. In the output, observe the sizes of /dev/sda, /dev/sdb, and /dev/sdc.

  • Request customer to back up image data.

  • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.

  • Record the service license ID. Refer to “Access Service License ID 16-Digit Code)” in Service Licensing for specific information.

  • Once HIPAA/Security setting is configured, the choice cannot be changed without reinstalling the software. See Security Levels for more information.

  • If the host PC, its components, or language change, then SSA licenses must be updated. On-site Internet connectivity is required. See Service Licensing for more information.

  • Request customer to back up image data.

  • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.

(For China only) : The software collector for China may contain multiple applications DVDs for a single DV release. (For example: The software collector for DV24 contains applications DVDs for DV22, DV23, and DV24, but each DVD contains only DV24 software. In this example, the getver command would show only DV24 software.) During installation, record the intended software release on the maintenance label, and install the software using the DVD whose label matches that release. See About MR Scanner for instructions on viewing the software installed at a given site.

Verify that the latest service pack is loaded at the end of the system load procedure. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library. See Installing Service Packs for more information on loading service packs.
