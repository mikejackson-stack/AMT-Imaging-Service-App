Load Linux OS Software (for software version DV24 and earlier)

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-25 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Linux OS Software DVD1--

Procedure

  1. Insert the Linux OS software DVD into the appropriate DVD drive of the host computer.
  2. Reboot the host computer.
  3. At the boot prompt, type the appropriate code for the keyboard in use and press Enter:

    The codes are all uppercase. Turn on the Caps Lock when entering the code.

    Keyboard Language Code
    English GEHCMR
    French GEHC?R
    Portuguese GEHCMR
    Italian GEHCMR
    Spanish GEHCMR
    German GEHCMR
    Swedish GEHCMR

    A series of progress bars appear. The OS software load takes about 20 minutes.

    If you see graphic card or memory errors, STOP this installation. Shut down the host computer and restart the Linux OS load.

  4. When the installation is complete, the system reboots to a GUI login prompt. Log in using the following parameters:

    • User ID: root

    • Password: operator

      Note

      It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  5. The OS DVD automatically ejects. Remove it.

Finalization

Return to DV24 and DV25 (DVD load only).
