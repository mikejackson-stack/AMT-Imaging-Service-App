About this task

Overview

This procedure provides instruction to replace the HP Z420 host computer with another HP Z420.

Topic ID: id_SL12053591-1203186

Prepare Workstation for Host Computer Removal

Procedure

  1. Ask the customer to archive all images to an external storage device such as a PACS or DVDs.
  2. Perform a Save Info.
  3. Shut down the host computer.

    The GOC supports an optional UPS. Confirm your site’s configuration.

  4. Perform LOTO on the GOC/operator workspace. See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace. For added protection, disconnect the twist-n-lock main power cable from the rear of the console.
Topic ID: id_SL12053592-1203186

Remove Host Computer from GOC

Procedure

  1. Remove the two screws that secure the left side panel of the GOC.
    Note

    The side panel has a short ground lead connecting it to the main chassis. When removing the side panel, do not strain this ground lead.

  2. Disconnect the short ground lead that connects the side panel to the GOC main chassis at the center of the lead.
  3. Remove the left side panel and set it is a safe place.
  4. Remove all the cables connected to the host computer.

    Confirm that the cables are properly labeled. Note their locations for reattachment.

  5. Loosen the strap and remove the hook.
  6. Remove the host computer from the GOC.
  7. Carefully remove the computer using the back and bottom brackets.
  8. Perform a disk wipe on all applicable hard drives in the old PC. See the latest revision of the Disk Management Tool Service Manual, PN 5500610-1EN available from the online documentation library.
Topic ID: id_SL12053594-1203186

Install New Host Computer

About this task

The replacement computer may have two Torx/slot screws (not Phillips) that must be removed before attaching the back bracket. Remove the screws using a slot screwdriver. Install the Torx/slot screws into the defective computer before returning it for repair.

Procedure

  1. Position the computer in the GOC as shown below.
  2. To secure the computer:
  3. Tighten the strap as follows:
    1. Hook the bracket to the slot of the bottom plate.
    2. Pull and tighten the strap to secure the computer.
  4. Restore all cables to the computer.
  5. Remove the dust filter from the old computer. Remove the Velcro strips from the inside of the front cover of the old machine and the dust filter. Attach them to the inside of the new machine’s cover. Attach the Velcro strips to the dust filter. Install the dust filter. If the old filter is not reusable, install a new one.
  6. Retrieve the GOC left side panel and reconnect the ground lead to the left side panel.
  7. Attach the GOC left side panel with the two screws.
Topic ID: id_15218707

Finalization

Procedure

  1. Remove LOTO from the GOC to return power. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace. If needed, reconnect the twist-n-lock main power cable to the rear of the console.
  2. Power up host computer.
  3. Verify that the host computer front panel power LED is illuminated as a steady blue signal.
  4. Load software and applications onto the operating system.

    See Loading Host System Software (Quick Start).

    Note

    The HP Z420 host computer only supports DV25.

    Load from cold (LFC) procedure must be performed to properly transfer customer options.

  5. Update the eLicense with the new host ID. See Software Option Installation with eLicense Generated Keys.
  6. Perform Check Scan to confirm the system and applications are working properly.
  7. Confirm that all customer functions are operational (auto voice, filming, network, archive).
  8. Repackage the defective PC for return.
