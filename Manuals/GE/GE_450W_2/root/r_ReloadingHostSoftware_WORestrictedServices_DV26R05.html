Reinstalling DV26 R05 (DVD load only) without restricted software for DoD secure sites

Reinstall the host system software without restricted services.

Important This DoD procedure does not apply to software version 30 and later.
Loading DV26.0 R05 software procedure for enabling the SIGNA™ Security Advanced feature
StepProcedure for DV26 R05
Prerequisites

Record the service license ID. See Managing SSA service licenses. Refer to Access Service License ID 16-Digit Code) in Service licensing for specific information.

Record the IIP configuration information, as it may not be saved during SaveInfo. See Device Connection Tab in InSite/IIP for more information.

After the HIPAA/Security setting is configured, the choice cannot be changed without reinstalling the software. See Security levels for software versions prior to 29.0 for more information.

If the host PC, its components, or language change, then SSA licenses must be updated. On-site Internet connectivity is required. See Service licensing.

Request customer to backup image data.

If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.

Required media
  • MR host PC Linux Base Load OS DVD
  • MR Applications Software DVD
  • MR Service Software DVD
  • MR VRE Linux OS DVD
  • Operator Manual DVD
  • BrainWave Applications DVD if the host PC is a Dell T5810
  • Blank DVD (quantity as needed for save info)
Make sure the SIGNA™ Secure Advanced option key is installedSIGNA™ Secure Advanced option key must be installed to enable the option of the Highest Security Settings. If the SIGNA™ Secure Advanced option key is not installed, check eLicense server and update, or contact GE HealthCare Services.
Note In Guided Install, click the Option Key tab to check the option keys status (toward the bottom of the option key listing).
Uninstall Restricted Services (secureSystem)Open a command window and run the getver command, if cclass package is installed, this is an indication that Restrictive Service Software has been installed and must be removed. If Restrictive Service Software is installed, use the following command to remove the software: /export/home/signa/bin/secureSystem.

Run the getver command again. The cclass package should not be listed; this is an indication that the Restrictive Service Software has been properly removed.

Do SaveInfoSaving information.
If you have applications installed, do a Checksum for the MR Application CD now. If you do not have applications installed, do the check scan after the Load Linux OS step.
Note Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.
(For DV26_R05 Application DV26.0_R05_1921.a CD)

Insert DV26_R05 Application CD 5758543 Rev 9 into DVD drive, open a command window, login as root with Signa default root password and run the following two commands. If the checksum does not match with the output in the MR Service Pack Software Matrix (DOC1667089), STOP the installation process and contact GE HealthCare Services for support. Note that the output of the dd command x.x MB/s (data transfer rate) below may vary, because this specific parameter does not have to match up with the number as shown below. Due to the data size of the application CD, the dd command may take up to 15 minutes to complete.

Note The sector count and sector size displayed in the isosize command should be used in the dd command.
# isosize -x /dev/sr0
    sector count: XXXXXXX, sector size: ZZZZ

# dd if=/dev/sr0 bs=ZZZZ count=XXXXXXX conv=notrunc,noerror | sha256sum
    1995763+0 records in
    1995763+0 records out
    4087322624 bytes (4.1 GB) copied, 535.142 s, 7.6 MB/s
    751cce6450ed619b65f19480eb46043746f17bb5004ac9ebb94d31b9b8acb2cb  -
RebootReboot and follow the LFC steps below.
Note You must do a complete reinstallation of the host system software to remove all of the contents from the prior Restrictive Service Software load.
Load Linux OSInstalling Linux host OS software.

Do RestoreInfoRestoring information.
Configure training PC (ONLY if installing)
Note The training PC is an optional standalone PC used for training on systems other than MR.
Configuring a training PC.
Install SSAGather 16-digit code and generate the site SSA licenses. If the 16-digit code is different from the one recorded before, then contact OLE to update this in SSA back office. See Service Licensing.
Configure ICN (VRE) OSConfiguring the SIP, ICN, or VRE.
Install IRMInstalling IRM software.
Reset term server (first-time loads only)Reset Term Server (CAM configuration only).
Install options/option keysFor the purchasable option keys, see Option key catalog matrix.
Note SIGNA™ Secure Advanced option: If the customer purchased this license, configure the security setting in Guided Install to SIGNA™ Secure Advanced. Guided Install may need to be restarted to enable security configuration.
Install latest service pack (if required)Loading software updates from the repository or CD/DVD.
Install third-party software and/or devices (for example, BrainWave, FUS, MRE, and so on) as applicable.Load the BrainWave software DVD on the Dell host. See Installing BrainWave software. Refer to the online documentation library for vendor-specific installation manuals.
Configure About MR ScannerIf not completed during previous steps, run the About MR Scanner tool. See Running the About MR Scanner tool.
Complete Apps Load and Restore InfoUse the RestoreInfo CD made after the secureSystem has been completed. See Restoring information.
Set the Highest Security Level
  1. Exit Guided Install.
  2. Right-click and logout.
  3. Log back in as root without rebooting. This will restart Guided Install to activate the HIPAA/Security tab.
  4. Navigate to the HIPAA/Security tab and select SIGNA™ Security Advanced.
  5. Select Enable features using role-based policies option and click Configure. A dialog window displays asking for the password change.
    The new password must conform to the Complex Password requirement as follows:
    • must have at least 15 characters
    • must contain at least: 1 number, 1 uppercase character, 1 lowercase character, and 1 special character
    • must contain less than 3 consecutive repeating characters

    Record and secure the new password for future reference

RebootReboot and log in to applications (also applies to training PC).
Note The system may reboot once additionally on its own.
Install latest service pack (if required)Loading software updates from the repository or CD/DVD.

Install SSA KeysThe SSA license is restored during the RestoreInfo process. This step is not necessary for reinstallation unless the service license ID has been modified. If the service license ID has been modified, or if this is a new install, record the service license ID and contact OLE to generate a new license for the site.

See Managing SSA service licenses for information on how to record the service license ID.
