Finalizing DVD drive replacement on the host computer

Follow this procedure to finalize a DVD drive replacement.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1--30 minutes

Procedure

  1. Start up the host computer/system. See Starting up the host computer.
  2. Make sure that the host computer front panel power LED is illuminated as a steady blue signal.
  3. Do a check scan to make sure the system and applications are working correctly. See Doing a check scan.
  4. Make sure that the DVD drive can read and write images.
  5. Make sure all customer functions are operational (auto voice, filming, network, archive).
  6. If you have replaced the computer or a component, repackage it for return.
