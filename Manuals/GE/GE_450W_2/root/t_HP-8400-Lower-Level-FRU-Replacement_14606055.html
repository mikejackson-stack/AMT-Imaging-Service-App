About this task

Overview

Use this procedure to replace the following lower level FRUs in a HP 8400 host PC:

  • Memory modules

  • CMOS battery

  • SCSI card

  • Hard disk drive

  • DVD drive

Topic ID: id_SL2313943-1087622

Workstation Service Preparation

Procedure

  1. Close any PC applications, and power down the GOC.
  2. Perform LOTO on the GOC/operator workspace. See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  3. Remove the two screws on the left side panel of the GOC.
  4. Notice
    When removing the side panel, avoid straining the ground lead.
    Remove the left side panel of the GOC by lifting it up.
  5. Disconnect the short ground lead that connects the side panel to the GOC main chassis at the center of the lead.
  6. Notice
    Potential component damage
    Electrostatic discharge (ESD) can cause permanent damage to electronic components.
    Observe the following ESD precautions:
    • Work on a static-free mat.
    • Wear a static strap to make sure that any accumulated electrostatic charge is discharged from your body to the ground.
    • Create a common ground for the equipment being worked on by connecting the static-free mat, static strap, and peripheral units to that piece of equipment.
    • For more information on ESD protection, see MR Service Safety Manual (5452735).
    Notice
    For further information regarding ESD Protection, refer to the MR Service Safety Manual, PN 5452735, available from the online documentation library.
    Remove all the cables connected to the computer, ensure they are properly labeled, and note their locations for reattachment.
  7. Remove the HP 8400 from the GOC.
    1. Remove the two screws securing the back bracket.
    2. Loosen the two screws on the back slide plate, and slide the plate backward.
    3. Loosen the two screws on the side slide plate, and slide the plate in the direction of the arrow.
    4. CAUTION
      PERSONAL INJURY!
      THE HOST COMPUTER CHASSIS CAN WEIGH IN EXCESS OF 40 POUNDS.
      DEPENDING ON YOUR HEIGHT AND ACCESS TO EQUIPMENT FOR REMOVAL AND INSTALLATION, LIFTING ASSISTANCE MAY BE REQUIRED. USE YOUR JUDGMENT TO DETERMINE IF LIFT ASSISTANCE OR A SECOND PERSON IS REQUIRED TO ASSIST IN REMOVAL AND INSTALLATION.
      Carefully remove the computer using the back and bottom brackets from the GOC.
  8. Notice
    Potential component damage
    Electrostatic discharge (ESD) can cause permanent damage to electronic components.
    Observe the following ESD precautions:
    • Work on a static-free mat.
    • Wear a static strap to make sure that any accumulated electrostatic charge is discharged from your body to the ground.
    • Create a common ground for the equipment being worked on by connecting the static-free mat, static strap, and peripheral units to that piece of equipment.
    • For more information on ESD protection, see MR Service Safety Manual (5452735).
    Notice
    For further information regarding ESD Protection, refer to the MR Service Safety Manual, PN 5452735, available from the online documentation library.
    Remove the two screws that secure the left side panel to the rear of the PC.
  9. Remove the left side panel of the PC by pulling the latch out, and sliding the cover back. Set the cover aside in a safe location.
  10. Lay the workstation on its side with the system board facing up.

Replacing Memory Module

About this task

The fan assembly must be removed only when replacing the memory modules.

Topic ID: id_SL14077304-1087622

Removing Fan Assembly

Procedure

  1. Press down on the green release latch at the bottom of the system/memory fan assembly, and rotate the memory fan holder up until it snaps into a vertical position.
  2. Disconnect the system and memory fan cables from the system board.
  3. Press down on the top of the system/memory fan assembly to release the retaining latch.
  4. Rotate the assembly inward until the hinge tabs on the bottom of the assembly are released.
  5. Lift and remove the system/memory fan assembly from the chassis.
Topic ID: id_SL14077305-1087622

Removing Memory Module

Procedure

  1. Gently push out and down on the socket levers on each side of the slot that contains the suspected faulty memory module.
  2. Lift the memory module straight up and remove it from the unit.
Topic ID: id_SL14077306-1087622

Installing Memory Module

About this task

When installing a memory module, be aware that memory modules must be loaded in valid configurations. Refer to the FRU manual for valid configurations.

Procedure

  1. Ensure that the socket levers are still out and away from the memory slot.
  2. Notice
    Memory modules and their sockets are keyed for proper installation. Be sure these guides line up before pushing down in the step below.
    Place the new memory module into the slot, and push down firmly until the memory socket levers snap into place.
  3. Ensure that the module is fully inserted and properly seated in the slot.
Topic ID: id_SL14077307-1087622

Installing Fan Assembly

Procedure

  1. Insert the hinge tabs on the bottom of the system/memory fan assembly into the slot on the chassis.
  2. Rotate the top of the assembly up until the retaining latch snaps into the slot on the chassis.
  3. Reconnect the system and memory fan cables to the system board.
  4. Rotate the system/memory fan assembly holder down until it snaps into a horizontal position.
  5. Proceed to Reinstalling Host Computer in GOC.
Topic ID: id_SL13774015-1087622

Replacing CMOS Battery

Procedure

  1. Remove the video card as follows:
    1. Press on the green arrows on the securing block for the video board and remove the securing block.
    2. Press on the green tab of the video card and gently pull out the video card.
  2. Locate the CMOS battery on the HP computer system board.
  3. Remove the old CMOS battery. Release the CMOS battery from its holder by pulling back on the spring clip.
  4. Let the computer sit for at least 3 minutes to allow the CMOS memory to clear.
  5. Install the new battery. Make sure the spring clip snaps over the battery, holding it in place. The battery’s positive (+) side should be facing upward.
  6. Reinstall the video card and the video board securing block.
  7. Make sure to perform Step 3.
Topic ID: id_SL14033041-1087622

Replacing SCSI Card

Procedure

  1. Locate the two black tabs on the top and bottom of the spring-loaded card retainer.
  2. While depressing both tabs, remove the retainer.
  3. Depress the two green tabs on the inside of the PC to release the locking mechanism holding the boards in place.
  4. Remove the SCSI card from the fifth slot from the top.
  5. Install the new SCSI card firmly into the fifth slot from the top.
  6. Restore the locking mechanism holding the boards in place by pulling back the two green tabs on the inside of the PC.
  7. Restore the spring-loaded card retainer.
  8. Connect the SCSI tower cable to the left port of the SCSI card, and route the other end of the cable to the back of the SCSI tower.
  9. Proceed to Reinstalling Host Computer in GOC.
Topic ID: id_SL14034047-1087622

Replacing Hard Disk Drive

About this task

Because of the way the hard disk drives are partitioned, if one of the hard disk drives becomes corrupted and has no read/write capabilities, information saved on the system (since the most recent archive) will be lost. Use the HP Diagnostics Tool CD to identify the defective hard drive.

Procedure

  1. Remove the power cable and the data cable from the defective hard disk drive.
  2. Remove the defective drive by pinching the green restraining tabs together, then slowly pulling the drive out.
  3. Confirm that the data cables from all three drives are connected to the correct SAS device locations.
    Table 4. Hard Disk Drive Connections
    Drive Slot Drive ID SAS ID
    TopHDD2SAS2
    MiddleHDD1SAS1
    BottomHDD0SAS0
  4. Install the replacement hard drive by reversing the previous steps.
  5. Perform disk wipe procedure. See the Disk Management Tool Service Manual, PN 5500610-1EN, available from the online documentation library.
  6. Reinstall the left side panel and proceed to Reinstalling Host Computer in GOC.
Topic ID: id_SL14034056-1087622

Replacing DVD Drive

Procedure

  1. Notice
    Never remove a cable by pulling on the wires. Use the housing connector instead.
    Disconnect the power, drive, and audio cables from the drive.
  2. Lift the green drive release lever and slide the drive out of the chassis.
  3. Install the new DVD drive by pulling out on the plastic lock while sliding the new drive into place in the open slot.
  4. Connect the power and data cables to the new DVD drive as shown in either Location of Power and Data Cables (EIDE DVD Drive) or Location of Power and Data Cabes (SATA DVD Drive) based on the DVD drive connection type.
  5. Proceed to Reinstalling Host Computer in GOC.
Topic ID: id_SL13774022-1087622

Reinstalling Host Computer in GOC

Procedure

  1. Replace the left side panel of the PC and secure it with the two screws removed earlier.
  2. Return the HP 8400 host computer to the GOC and replace and secure all cables and covers.
  3. (For CMOS battery replacement) Obtain the GE Equipment Maintenance sticker and write the date on the sticker and place the sticker on the GOC for future reference.
    Note

    Place the sticker on either side of the GOC, where it can be easily viewed.

Powering on Operator Console

Procedure

  1. Remove LOTO from the GOC/operator workspace. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  2. Power ON the GOC at the rear of the GOC and then power up the host PC.
  3. If the CMOS battery was replaced:
    1. If the CMOS battery was replaced, and the PC will not turn on, press and hold the CMOS Reset button for five seconds.
    2. At the language prompt, leave the setting on English or use the arrows to select the language. Press Enter to confirm.
    3. Set the time and date. Use the Tab key and the up/down arrow keys to move the cursor and use the left and right arrow keys to change values. Press F10 to save the changes.
    4. Restore customized BIOS settings. Use the up/down and left/right arrow keys to navigate the menus. Leave all HP defaults except the following:
      Table 5. HP 8400 BIOS Changes
      LocationParameterValue
      Storage / Storage OptionsSATA EmulationSeparate IDE Controller, then F10
      Security / Network Service BootNetwork Service BootDisable, then F10
      Power / OS Power managementACPI S3 SupportDisable, then F10
      Advanced / Power On optionsAfter Power LossON, then F10
      Advanced / Device OptionsS5 Wake On LANDisable, then F10
      Advanced / Device OptionsNIC PXE Option ROMDisable, then F10
      Advanced / Slot 1 – PCISlot 1 Option ROM DownloadDisable, then F10
      Advanced / Slot 2 PCIeSlot 2 Option ROM DownloadDisable, then F10
      Advanced / Slot 3 – PCIeSlot 3 Option ROM DownloadDisable, then F10
      Advanced / Slot 4 – PCIeSlot 4 Option ROM DownloadDisable, then F10
      Advanced / Slot 5 – PCI-xSlot 5 Option ROM DownloadDisable, then F10
      Advanced / Slot 6 – PCI-xSlot 6 Option ROM DownloadDisable, then F10
      Advanced / Slot 7 – PCI-xSlot 7 Option ROM DownloadDisable, then F10
    5. At the File menu, use the down arrow to highlight Save Changes and Exit and press Enter.
    6. Press F10 to save the settings.
  4. If the DVD drive was replaced: You must set up the software configuration at either the root or system level after power up. To set up the software configuration at the system level, proceed to Step 5. To set up the software configuration at the root level, proceed as follows:
    1. After powering up, log in as root with the password operator.
      Note

      It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    2. Proceed to Guided Install.
    3. Open a command window and run the command scsistat.
    4. Select Setup Devices.
    5. When this process is completed, exit Guided Install and log out of root.
    6. Log in to the system and proceed to Step 5.
  5. If the DVD drive was replaced: To set up the DVD drive software configuration at the system level (if you opted not to set this up at the root level in Step 4), proceed as follows:
    1. After power up, log in as sdc with the password adw2.0.
      Note

      It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    2. Open a command window.
    3. Run the command scsistat.

      The information below will display. If the information does not display, recheck the power connection, cable connections, and jumper settings, then rerun the scsistat command.

    4. Launch the MR Service Desktop.
    5. On the Configuration tab, expand Guided Install, select FE mode and Click here to start the tool.
    6. When the login screen displays, log in as root with the password operator.
      Note

      It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    7. From the Utilities heading in the left navigation tree, select Display MOD/CD-ROM.
    8. Select Setup Devices.
    9. Proceed to Step 5.
Topic ID: id_15217742

Finalization

Procedure

  1. Reboot and ensure that no memory BIOS errors are observed during this process.
  2. Verify that all customer functions are operational (auto voice, filming, network, archive).
  3. (For SCSI card replacement, hard disk replacement) Perform the applicable Loading Host System Software procedure to load software and applications onto the operating system.
  4. Perform a check scan to ensure that the system is operating properly.
  5. (For DVD drive replacement) Insert media into the new DVD drive and verify proper operation of the drive.
  6. (For DV25 software or later) Computer hardware replacement may cause a change in the 16-character service license ID code. Renew any site license softkeys that were affected by the hardware replacement.
