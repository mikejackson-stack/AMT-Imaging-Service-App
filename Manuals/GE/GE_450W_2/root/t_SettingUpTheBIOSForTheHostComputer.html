Setting up the BIOS for the host computer

Restore the BIOS configuration on the host computer.

About this task

This procedure describes how to set up the BIOS on the host computer for the Dell T5810 and HP Z4 G5. Follow the steps for the type of host computer installed.

Procedure

  1. (For Dell T5810) Disconnect the cable that connects to port 1, slot 2.
  2. (For Dell T5810) Disconnect the cable that connects to port 1, slot 4. Connect the cable to port 1, slot 2.
  3. Power on the host computer, and then start to set up the BIOS.
  4. (For Dell T5810) During the host computer startup, press F2 when the Dell circle shows on the screen.
  5. (For Dell T5810) If a message indicates that the time of day is not set, press F2.
    1. Select General > Date/Time and set the correct time.
    2. Use the Tab key to move the cursor, and then use the left and right arrow keys to change the values.

    Result

    After you set the time and date, the BIOS settings open. Go to Step 9.
  6. (For HP Z4 G5) During the host computer startup, press F10 to open the BIOS Setup menu when the HP startup logo shows on the screen.

    The screen shows Entering Startup Menu . . . in the lower left corner.

    Note Alternatively, press Esc to open the Startup Menu. Then select the BIOS Setup (F10) menu.
    Note If a screen with UEFI Firmware Settings opens instead of the Startup Menu, click UEFI Firmware Settings and press Enter.

    The Main menu opens.

  7. (For HP Z4 G5) Under the Main Menu, select Change Date and Time.
  8. Set the correct time and date.

    Result

    After you set the time and date, the BIOS settings open. Go to Step 9.
  9. Restore the customized BIOS settings. Change only the values specified below.
    • (For Dell T5810) See Dell T5810 Customized BIOS settings.
    • (For HP Z4 G5) See HP Z4 G5 Customized BIOS settings.

    The system restarts. The BIOS configuration is complete.

Finalization

  1. Power off the host computer.
  2. (For Dell T5810) Disconnect the cable that was previously connected to port 1, slot 2.
  3. (For Dell T5810) Reconnect the cables.
    • Reconnect the IRD cable to port 1, slot 2.
    • Reconnect the host LCD monitor cable to port 1, slot 4.
  4. Power on the host computer (see Starting up the host computer), and make sure that the LCD is on.
