Reset Term Server

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable10 minutesNot Applicable
Table 2. Required conditions
ConditionReferenceEffectivity

This procedure is only for new software loads.

--

Procedure

  1. Exit Guided Install by selecting File > Quit.
  2. Restart the system and log in.

    • User ID: root

    • Password: operator

      Note

      It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. Remove the power connector from the term server.
  4. Press and hold the small square Reset button (next to the power jack), and connect power to the term server while continuing to press this button.
  5. Continue pressing the Reset button for 20 seconds, or until the LED flashes 1–5–1.
  6. Verify communication between the host PC and term server as follows:
    1. Open a C shell.
    2. To ping the ts1 address, type ping hostname-ts1 (where hostname is the hospital name). Press Enter.

      If an improper response of Host Unreachable appears, repeat this procedure.

  7. To stop the test, press Ctrl-c.

Finalization

Proceed to the appropriate MR service software loading procedure. See Loading Host System Software (Quick Start).
