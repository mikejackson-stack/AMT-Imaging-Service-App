About this task

Follow this process to change the system cable for coils that have a cable available as a spare part. This process will be the same whether replacing the coil or the cable.
Topic ID: id_SL2341993-679779

HNS Rev. 2

Procedure

  1. Notice
    Please refer to the cable FRU list above in Replacement Parts.
    If the cable FRU is with the Coil ID Board, then the Coil ID Board has to be removed as well.
    If the cable FRU is without the Coil ID Board, then do not remove the Coil ID Board.
    Notice
    Observe anti-static precautions: Use wrist strap and ESD workstation (ESD mat connected to ground and place to connect ESD wrist strap).
    Put an ESD wrist strap on and ground.
  2. Unscrew the bottom cover and remove from coil. Retain the original screws used.
  3. Unscrew the cable clamp from the coil as shown. Retain the original screws used.
  4. Identify and remove RF connectors (CH in Head Neck Unit (HNU), J in Thoracic Lumbar Unit (TLU)) from interface Board. Pliers may be necessary for removal of the MMCX connectors, as they may be difficult to unplug. This will help prevent accidental breakage of the cables.
  5. Identify and remove DC connectors (DC) from Interface Board and Coil ID PCB.
  6. Remove the system cable (with or without the coil id).
  7. Refer to the Replacement Parts section, if the cable FRU is with the coil id; remove the coil ID PCB from Interface Board (proceed to the next step). If the cable FRU exists without the Coil ID Board, then remove only the cable.
  8. Identify the Interface Board Assembly and the coil ID PCB located on the Interface Board (Head Neck Unit (HNU) Only). Carefully remove the Coil ID assembly.
  9. Install the new system cable.
  10. Align the cable clamp of the cable into the notch of former slot. Screw down cable clamp using original screws.
  11. If applicable from Step 7: Mount the new coil ID PCB assembly in the open slot on the Interface Board (HNU Only).
  12. Connect RF connectors to Interface Board. Verify that all labels on the connectors match those on the Interface Board.
  13. Connect DC connectors to Interface Boards and coil ID PCB (Coil ID PCB for HNU Only). DC connector “S1” connects to J55 on the coil ID PCB. DC connector “S2” connects to J56 on the coil ID PCB. Verify that all labels on the connectors match those on the Interface Board.
  14. Replace cover. Use original screws to fasten cover.
Topic ID: id_SL2341996-679779

HNS Rev. 3

Procedure

  1. Notice
    Please refer to the cable FRU list above in Replacement Parts.
    If the cable FRU is with the Coil ID Board, then the Coil ID Board has to be removed as well.
    If the cable FRU is without the Coil ID Board, then do not remove the Coil ID Board.
    Notice
    Observe anti-static precautions: Use wrist strap and ESD workstation (ESD mat connected to ground and place to connect ESD wrist strap).
    Put an ESD wrist strap on and ground.
  2. Unscrew the bottom cover and remove from coil. Retain the original screws used.
  3. Unscrew the cable clamp from the coil as shown. Retain the original screws used.
    Note When re-installing components, tighten all screws snugly, but do not over-tighten. The recommended torque is 10 in-lbs for M4 screws and 15 in-lbs for M5 screws.
  4. Identify and remove ganged RF connectors from interface Board.
  5. Identify and remove DC connectors (DC) from Interface Board and Coil ID PCB.
  6. Identify and remove GND connectors from interface board. Pliers may be necessary for removal of the PCX connectors, as they may be difficult to unplug. This will help prevent accidental breakage of the cables.
  7. Unscrew the Kevlar™ termination ring. Retain original screw used.
  8. Remove the system cable (with or without the coil id).
  9. Refer to the Replacement Parts section, if the cable FRU is with the coil id; remove the coil ID PCB from Interface Board (proceed to the next step). If the cable FRU exists without the Coil ID Board, then remove only the cable.
  10. Identify the Interface Board Assembly and the coil ID PCB located on the Interface Board (Head Neck Unit (HNU) Only). Carefully remove the Coil ID assembly.
  11. Install the new system cable.
  12. If applicable from Step 4, mount the new coil ID PCB assembly in the open slot on the Interface Board (HNU Only).
  13. Align the cable clamp of the cable into the notch of former slot. Screw down cable clamp using original screws. (Cable clamp screws are 12 mm in length for the TLU and 10 mm in length for the HNU).
  14. Connect RF connectors to Interface Board. Verify that all labels on the connectors match those on the Interface Board.
  15. Connect DC connectors to Interface Boards and coil ID PCB (Coil ID PCB for HNU Only). DC connector “S2” connects J12 located on the 11 channel feed-board to J56 located on the coil ID PCB. DC connector “S1” connects J70 located on the Interface Board to J55 located on the coil ID PCB. Verify that all labels on the connectors match those on the Interface Board.
  16. Connect GND connectors to the Interface Board. Verify that all labels on the connectors match those on the Interface Board.
  17. Screw down Kevlar™ termination ring using original screw. (Kevlar™ termination screws are 10mm in length for both the TLU and HNU).
  18. For forward production coils, ensure that jumpers (red suitcase) J5, J40, J41, J55, J28, J8, and J39 are removed from cable interface (MUX) board before scanning.
  19. Replace cover. Use original screws to fasten cover.
Topic ID: id_14925784

Finalization

Procedure

Perform a good bye scan with this coil to confirm that the repaired coil operates properly.
