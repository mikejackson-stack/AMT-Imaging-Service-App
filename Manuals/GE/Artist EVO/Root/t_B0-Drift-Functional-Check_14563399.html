Using B0 Drift Tool

Procedure

  1. (For flat table) Place the TLT phantom and sphere on the flat table. Position the phantom in the center of the cradle and center it on the PA coil. To achieve the best test measurement, the phantom must be located in the center (long direction) of the cradle (landmark the center of phantom at 1080 mm from Home Position).
    Note: This image is a representative example. Actual systems may vary.
  2. Start the B0 Drift tool:
    1. (For non-proprietary service tools) From the Common Service Desktop, select Calibration > B0 Drift Calibration. Select Click here to start this tool.

    The B0 Drift window appears.

  3. Select the axis that is being validated. To select a second axis, press Shift and click another axis.
  4. Select Check Only.

    The total time required to run B0 Drift Check Only mode is 63 minutes.

  5. Select Scan.

    When the test is complete, it displays the compensated drift rate for the selected axis. Green values indicate pass, and red values indicate fail.

    If one axis fails, run B0 Drift Calibration for only the failed axis.

Additional Functions of B0 Drift Tool

About this task

The B0 Drift tool has additional features. To view a plot, highlight the specific axis, then click Show. The generated plot appears for the selected axis. Four options can be executed by selecting More Actions on the B0 Drift tool window.

  • Zero Out Cal Parameters: Zero out the calibration file. It can be executed for one axis or all three axes.

  • Re-Analysis Only: Re-analyze or view a previously executed pass (existing data).

  • Re-Calculate Time and Scaling Constants: Use existing data to put back into the calibration file of the system. If you want to use existing data:

    • First, run Re-Analysis Only.

    • Select Re-Calculate Time and Scaling Constants.

    • In the new dialog window, select the axis that you want to change.

    • Select Re-Calculate Time and Scaling Constants and click Apply.

  • Add Scan and Wait Time for x/y/z axis: Do not use.
