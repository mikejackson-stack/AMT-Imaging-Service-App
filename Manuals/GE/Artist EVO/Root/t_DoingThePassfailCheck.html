      • Adjusting the patient handling system with the laser leveling tool

        The proper alignment of the entire patient handling system is important for good image quality output from the GE MR scanners.

        • Tools overview

          The patient handling alignment procedure is to be completed using the patient handling and magnet leveling tool kit (5897979) and the MR Patient Handling Alignment Macro Tool (DOC2372458).

        • Aligning the bridge and rear pedestal (z-dir and x-dir)

          Align the front endbell-bridge longitudinal (z-dir) offset and the bridge in the lateral (x-dir) direction (left to right of the magnet bore).

        • Adjusting the dock hook tension

          Adjust the dock hook tension when the force required to engage the dock pedal is minimal or too much (indicating the hook is either too loose or too tight).

        • Aligning the patient table angle (rotation about y-axis) and offset (x-dir)

          Measure the distance between the table top and bridge top, measure the angle and offset of the table with the horizontal rulers, and adjust the table accordingly.

        • Measuring the bridge and rear pedestal heights

          Measure the height of the rear pedestal, bridge, and bridge in the body coil, and record the measurements in the macro tool.

        • Aligning the bridge and rear pedestal (y-dir)

          If necessary, adjust the height of the rear pedestal or bridge, and record new height measurements in the macro tool.

        • Measuring the patient table height

          Measure the height of the dock bosses and patient table, make adjustments to the dock boss height if necessary, and note the measurements for entry in the macro tool.

        • Adjusting the patient table height (y-dir)

          If necessary, adjust the height of the patient table and table casters, and record new height measurements in the macro tool.

      • Patient handling sensor, switch and LPCA adjustment

        Align the patient handling system, which is important for good image quality output from the GE MR scanners.

      • Checking the longitudinal drive belt tension

        Make sure that the cradle belt tension is set correctly.

      • Adjusting the cradle guide rail latch

        This procedure describes how to adjust the cradle guide rail latch so that the cradle does not move when the table is undocked.

      • Adjusting the cradle home table down interlock

        This procedure describes how to adjust the mechanical interlock, which prevents the patient table from being undocked or lowered while the cradle is in the magnet bore.

      • Doing a check of the cradle release from the LPCA

        Do a check of the LPCA mechanism that lets the cradle be released from the LPCA by twisting the handle located on the rear of the cradle.

      • Aligning dual tables

        Align two tables dedicated to one MR suite.

      • Checking and filling hydraulic fluid

        Checks and adjusts the hydraulic fluid level for the dockable patient table.

      • Bleeding the patient table hydraulics

        Bleeds the hydraulic lines for the dockable patient table.

      • Verifying patient table movement

        Make sure the patient table controls operate correctly.
