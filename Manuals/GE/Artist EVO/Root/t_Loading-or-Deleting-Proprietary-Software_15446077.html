About this task

This procedure explains how to install and uninstall proprietary and advanced service software. An installation GUI accessed from the Common Services Desktop directs the installation or removal of this software.

Note:

If loading service software, an Advanced or Restricted service software CD-ROM is required as well as the following:

  • In-House Service Key to load Advanced service software

  • General Electric FE Service Key to load Restricted service software

(For DV25.1 and later) The MR Service Software DVD combines the Restricted Software CD and the Advanced Software CD into a single DVD and can be used to install either the Restricted Software or the Advanced Software, based on SSA licensing.

Loading Proprietary Software (DV25.0 and earlier)

About this task

Shut down all applications before loading the Restricted service or Advanced service media. This media should not be loaded with applications software running.

Procedure

  1. Restart the system and log in as root with the password: operator.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    Note:

    If continuing from Host Software Load, it is not necessary to reboot at this time.

  2. Open the Guided Install and select FE Mode and the link: Click here to start this tool.
    Note:

    Restricted service software is only available for GE use; Advanced service software is only available to sites with a valid Advanced Service Package Limited License. GE Healthcare Restricted service software permits configuration of InSite Interactive.

  3. Insert the Service Software media and from the left navigation menu, select Service SW/InSite and click Load Restricted Software or Load Advanced Software.
  4. When the Configure Insite Menu displays, read the proprietary statement and click Accept three times to continue.
  5. When the message displays: Please Insert CD-ROM to Install Restricted Service, click OK. The Restricted software load in progress window displays.

    This load will take about three (3) minutes. The media is automatically ejected when the load is complete and the InSite Interactive screen displays.

Loading Proprietary Software (DV25.1 and later)

About this task

Shut down all applications before loading the Restricted service or Advanced service media. This media should not be loaded with applications software running.

Procedure

  1. Restart the system and log in as root with the password: operator.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    Note:

    If continuing from Host Software Load, it is not necessary to reboot at this time.

  2. Open the Guided Install and select FE Mode and the link: Click here to start this tool.
    Note:

    Restricted service software is only available for GE use; Advanced service software is only available to sites with a valid Advanced Service Package Limited License. GE Healthcare Restricted service software permits configuration of InSite Interactive. Whether Restricted Software or Advanced Software installs is based on SSA licensing.

  3. Download and install the customer SSA soft licenses. This licensing mechanism is required to continue the Service Software Load.
  4. Insert the MR Service Software DVD and from the left navigation menu, select Service SW/InSite and click on the Load Service Software button. The MR Service Software DVD was shipped together with the MR Application Software Collector.
  5. If and when the Configure Insite Menu displays, read the proprietary statement and click Accept three times to continue.

    This load will take about five (5) minutes. The media is automatically ejected when the load is complete and the InSite Interactive screen displays.

Checking Restricted Software Load Results (DV26 and later)

About this task

The restricted software load procedure will either succeed or fail. To verify, perform the getver command.

Procedure

  1. Open a command prompt and type /usr/g/bin/getver.
  2. Search for Service_Software_Install_Incomplete.

    If this text appears, then the installation procedure failed. Delete the proprietary software and perform the installation again.

Topic ID: id_SL3402918-1050857

Deleting Proprietary Software

About this task

To delete proprietary software, proceed as follows:

Procedure

  1. Open Guided Install and select FE Mode and the link: Click here to start this tool.
  2. From the left navigation menu of the Guided Install, select Service SW/InSite.
  3. Click Secure System to delete proprietary software.
