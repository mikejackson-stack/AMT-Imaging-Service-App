2  Purpose

This test verifies the proper operation of the Operator Control Panel buttons on the front of the magnet enclosure.

NOTE:Possible equipment shutdown. Do not press the [Emergency Stop] buttons on the Display Panel during this test. The [Emergency Stop] buttons are not disabled during the test, and will shut down all cabinets that provide power to the magnet room.

3  Components Tested

  • Magnet Enclosure Operator Control Buttons Codes

  • In-Room Monitor Operator Control Buttons Codes

4  Requirements

None

5  Test Sequence

CAUTION
Possible Equipment Shutdown
Do not press Emergency Stop buttons on the Display Panel during this test.
The Emergency Stop buttons are not disabled during the test. Pressing the top, outer Emergency Stop buttons (Illustration 3) will shut down all cabinets that provide power to the magnet room.

5.1  Version without In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button (as shown in Illustration 2) and verify the code displayed on the Longitudinal Position (right) display corresponds to the button numbers shown in Table 1. The Scan Time Remaining (left) display increments as you press each button. Table 1 lists the button display codes.

6  Expected Results

6.1  Version without In-Room Display

When this test is performed, the alternate functions replace those that are normally executed when the buttons are pressed. Instead, each button has a corresponding number assigned to it. The corresponding number is displayed on the Longitudinal Position (right) display when the button is pressed.

The Scan Time Remaining (left) display increments as buttons are press, providing a means of verifying operation of the switch debounce function. Proper operation of a switch debounce function is indicated when the Scan Time Remaining display increments one count each time the button is pressed and released.

There are two failure modes for the button test:

  • Open Switch failure - displays no code when the button is pressed.

  • Shorted Switch failure - displays an incorrect code when the button is pressed. The displayed code indicates which switch is shorted. For example, if you press [Start Scan] and the displayed code is 1002, the [Lights On] switch is shorted.

6.2  Version with In-Room Display

When this test is performed, each button's description displays on the Host PC within the Service Browser.

NOTE:Possible equipment shutdown. Do not press the Emergency Stop buttons on the Display Panel during this test. The Emergency Stop buttons are not disabled during the test and will shut down all cabinets that provide power to the magnet room.
