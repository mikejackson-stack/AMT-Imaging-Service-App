Optima MR450w 1.5T Service Methods
Module Version  1.0,  Version Date  5/29/08

Analog Data

1  Diagnostic Link

Diagnostics >> Hardware Location >> Pen Panel Cabinet >> Shim Supply Diagnostics, or

Diagnostics >> System Function >> Magnet >> Shim Supply Diagnostics

2  Purpose

Provide read back of the present power supply and board temperature sensor values.

This diagnostic is part of the Shim Supply Diagnostics that comprise the series of tests that verify & display various Shim Supply values by communicating from the SCP to the Shim Supply via the CAN link.

3  Components Tested

  • Shim Supply

  • Coil Channels

  • RTD Channels

4  Requirements

Software Configuration

  • Standard Software

  • CAN communications NOT emulated

Hardware Configuration

  • MGD Chassis: SCP and AGP Processor boards. Bridge board

  • Shim Supply, cabling, etc

5  Block Diagram

Illustration 1:  Shim Supply Block Diagram

6  Test Sequence

  1. Set the Test Duration to the number of seconds desired.

  2. The Operator selects the Analog Data radio button, then presses the [Run] button.

  3. The Diagnostic issues a command that instructs the Shim Supply to return the present power supply and board temperature sensor values.

  4. The Diagnostic displays the results.
