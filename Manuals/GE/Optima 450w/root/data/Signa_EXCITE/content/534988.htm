Reset RF-DIF FPGA

1  Diagnostic Link

Diagnostics >> RRF Chassis >> RF-DIF CAN

2  Purpose

This sends a reset command to the selected RF-DIF in the RRF chassis over the CAN cable. This can be used to recover a RRF that has stopped communicating over its fiber cable.
