Magnet Enclosure Display Test

1  Diagnostic Link

Diagnostics >> System Function >> Patient Handling >> SRI Functional Tests

Diagnostics >> Hardware Location >> Magnet Room >> SRI Functional Tests

Illustration 1:  SRI Functional Diagnostics

2  Purpose

This test provides a quick method of testing the control panel display.

3  Components Tested

  • Magnet Enclosure Operator Control Pushbuttons

  • In-Room Monitor Operator Control Pushbuttons

4  Requirements

None

5  Test Sequence

  1. Select [Magnet Enclosure Display Test].

  2. Click [Run].

6  Expected Results

  1. Verify all LEDs turn on and that no LED remains on throughout the entirety of the test (see Illustration 2).

    Illustration 2:  Display Test Indicators

  2. If using In-Room Display version (see Illustration 3), the lights should blink on for one second then off for one second until test is stopped.

    Illustration 3:  In-Room Display Operator Panel

  3. When test is complete, click [Stop] to end the test.
