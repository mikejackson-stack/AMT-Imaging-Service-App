1  Prerequisite Information for Proprietary (GE Contracted) Operation

To configure the Magmon3 for modem or network connectivity, the user must obtain information from the customer’s network system administrator. This section details the type of information required based on connectivity type and system type. Make sure to start this information-gathering process at least 3 weeks in advance of the physical installation.

1.1  Modem

1.1.1  For Non-HFO Systems

  • Dial-Out Prefix: Obtain from customer (needed for InSite2 dial-out).

  • Site Modem Phone Number: Obtain from customer (used only for phone line testing).

  • Proxy IP Address: Pre-assigned and in Service Docs (reference link).

  • Proxy Port Number: Pre-assigned and in Service Docs (reference link).

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other

  • Compressor Type (Required): Leybold or Sumitomo.

1.1.2  For HFO Systems

  • Dial-Out Prefix: Obtain from customer (needed for InSite2 dial-out).

  • Site Modem Phone Number: Obtain from customer (used only for phone line testing).

  • Proxy IP Address: Pre-assigned and in Service Docs (reference link).

  • Proxy Port Number: Pre-assigned and in Service Docs (reference link).

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Type (Required): HFO.

  • Compressor Type (Required): Sumitomo.

Network cable connection from Magmon3 J5 to OW – Host LAN Hub J7 and network configuration required for communication to host for coldhead switching.

Must use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer IT person.

  • Subnet Address: Obtain from customer IT person.

  • Gateway Address: Obtain from customer IT person.

  • Domain Name Server (DNS): Obtain from customer IT person.

1.2  Broadband

1.2.1  For Non-HFO Systems

  • Network cable connection from Magmon3 J5 to Customer's network drop.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

Use Dynamic Host Configuration Protocol (DHCP) if available. Obtain from customer IT person. If DHCP not available, use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer IT person.

  • Subnet Address: Obtain from customer IT person.

  • Gateway Address: Obtain from customer IT person.

  • Domain Name Server (DNS): Obtain from customer IT person.

If required by the customer, use Hypertext Transfer Protocol (HTTP) Proxy:

  • Proxy Name or IP Address: Obtain from customer IT person.

  • Proxy Port Number: Obtain from customer IT person.

  • Account User Name: Obtain from customer IT person.

  • Account Password: Obtain from customer IT person.

1.2.2  For HFO Systems

  • Network cable connection from Magmon3 J5 to Customer's network drop.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Type (Required): HFO.

  • Compressor Type (Required): Sumitomo.

DHCP is not used because of the coldhead cycling hardware and communication requirement with the host. Must use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer IT person.

  • Subnet Address: Obtain from customer IT person.

  • Gateway Address: Obtain from customer IT person.

  • Domain Name Server (DNS): Obtain from customer IT person.

If required by the customer, use Hypertext Transfer Protocol (HTTP) Proxy:

  • Proxy Name or IP Address: Obtain from customer IT person.

  • Proxy Port Number: Obtain from customer IT person.

  • Account User Name: Obtain from customer IT person.

  • Account Password: Obtain from customer IT person.

1.3  Satellite Modem (Mobiles and Fixed Sites in Outlying Areas)

  • Network cable connection from Magmon3 J5 to Customer's network drop.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

Use Dynamic Host Configuration Protocol (DHCP). Obtain from customer IT person.

NOTE:HFO Systems are not supported with this configuration at this time.

2  Laptop Port Driver Issue

Problem: Service laptop fails to communicate with magnet monitoring devices when using the Serial Null Modem Method. There is an incompatibility issue between the laptop communication port drivers and the laptop hardware. Two versions of laptop core load software have Com port drivers that are incompatible with the Dell D600 and D610 Laptops.

EFFECTIVITY: All Dell D600 and D610 GE-Issued Service Laptops.

2.1  Check Laptop Software Load Version

  • Right-click [My Computer] on the desktop.

  • Select [Properties] from the menu.

  • The System Properties window will open up, defaulted to the General tab. Near the bottom of the tab is the version of laptop release software on the laptop (for example, Windows XP X-image 2005Q1). If your laptop version is either (1) Windows XP X-image 2005Q1 or (2) Windows XP X-image 2005Q2, proceed to the Dell website to update your chipset drivers.

2.2  Dell Website Steps to Download/Update Chipset Drivers

  • Open an Internet Explorer window and type http://www.dell.com in the Address line.

  • Place your cursor over the [Notebooks] icon in the middle left of the page, a menu will come up; click Medium & Large Business.

  • Select the [Support] tab.

  • In the Choose a Support Option area, click [Drivers and Downloads] under Option 1: Most Popular Selections.

  • Choose Option 2: Select a Product. Use the Laptop Typedrop-down menu to select [Latitude], The Model Type is either [D600] or [D610]. Click [Go].

  • Choose your Operating System on this page. Use the drop-down menu to select [Microsoft Windows XP]. Click [Find Downloads].

  • In the Choose a Device for Download area, click [Chipset]. Click [Intel Mobile Chipset].

  • Click [Download Now] and download the R114079.EXE file to your laptop. Run the R114079.EXE file on your laptop, follow the directions, reboot your laptop and your COM1 port should be fully functional for use with any of the GE Magnet Monitoring devices for Serial Link Null modem connections.

NOTE:While installing R114079.EXE should fix the communication problem, it will not update the laptop version shown at the bottom of the General tab in the System Properties window. If necessary for future reference you will need to note that you’ve installed the new driver.
