2  Overview

The Excite 3.0T MNS kit includes a broadband exciter, amplifier, cabling, T/R switch, and service coil for 31P spectroscopy.

For MNS installation, complete all sections of this document in sequential order.

For a MNS upgrade, complete:

  • System Power Shutdown - System Power Shutdown

  • Select the appropriate section for the area being upgraded

  • Restoring System Power - Restoring System Power

  • Configuration - Configuration

  • Verifying Configuration Settings - Verifying Configuration Settings

Other MNS nuclei are supported by the kit although separate T/R switches, coils, and phantoms will be necessary. An 8kW amplifier (AMT/Herley) is supported.

4  Procedure

4.1  System Power Shutdown

DANGER
FATAL ELECTRIC SHOCK HAZARD!
LETHAL VOLTAGES ARE PRESENT WITHIN THE PDU EVEN IF ALL PDU BREAKERS ARE OFF.
Disconnect and Lockout and tagout power from the system at the facilities Main Disconnect.

NOTICE
Prior to powering down the entire Systems Cabinet, perform a system shutdown of the system software. The Volume Recon Engine (VRE) System which resides in the Systems Cabinet can become corrupted if it loses power while applications software is active.
 
 

  1. To prevent fatal electric shock, disconnect the power from the PDU before performing the following procedures.

  1. Notify ALL personnel that are working on the system that the system is being shut down.

  1. Shut down the system software before removing power.

  1. For PDU (in PGR Cabinet, with plastic safety cover):

    1. Open the front left door of the PGR cabinet.

    1. Open the plastic cover and flip the operator's workspace host circuit breakers to the OFF position. This allows control upon power up, when this procedure is completed.

    1. Rotate the larger main breaker labeled INPUT counter-clockwise to the green OFF (O) position.

    1. Perform the LOTO for the PGR PDU/Gradient Subsystem which will disconnect the INPUT circuit breaker.

4.6  Installing the LPCA Cover (5183855-2)

NOTE:The MNS T/R module should be removed from the system when spectroscopy is not in use. The presence of the module during a non-MNS scan may cause image quality degradation.

  1. With the LPCA cover off, place the two LPCA rails (p/n 5267384) on the top of the MNS LPCA cover so that the notches are facing up. When viewing from the patient-end, the right LPCA rail should have the notch farthest away and the left rail closest to.

  1. Attach the rails to the cover by screwing the screws in from the underside (screwheads should be hidden underneath the cover).

  1. Install the LPCA cover onto the system and secure with four screws.

4.9  Restoring System Power

  1. Notify all personnel that are working on the system that the system is being powered-up.

  1. Remove the LOTO for XRFD Amplifier and PEN Cabinet (Magnet Room Electronics).

NOTICE
Whenever the PEN cabinet LOTO is removed, the Exciter board requires 20 minutes of power-up time before scanning.
 
 

  1. Remove the LOTO for the PGR PDU/Gradient Subsystem.

  1. Open the plastic door over the front of the PDU breakers and switch ON the appropriate sub-system breakers.

  1. Place any individual circuit breakers turned off to the ON position.

4.10  Installing Spectroscopy Software

  1. From the Common Service Desktop, click [Configuration], [Guided Install], and [FE mode](see Illustration 22).

    Illustration 22:  Common Service Desktop Path

  1. Start the Guided Install using the operator login.

  1. After the Guided Install window opens select [Option Key] tab.

  1. Install the MNS option key using eLicense (refer to Software Option Install with eLicense Generated Keys).

  1. Place rating plate on the rear of the GOC (if applicable).

  1. Reboot the computer. The installation is now complete.

4.11  Configuration

NOTE:The MNSpectro Option Key delivered with the Hydrogen Only Spectroscopy Option (PROBE/SV) must be previously installed.

  1. At the Common Service Desktop Manager, click on the [Configuration] tab.

  1. Select Guided Install, then FE Mode from the navigation sidebar to launch the Guided Install GUI (see Illustration 23).

  1. At the hardware configuration page, select AMT for Spectro RF Amp Type(see Illustration 23).

    Illustration 23:  Hardware Configuration Page of Guided Install

  1. Ensure all other 3.0T settings are correct for the system.

  1. Modify and save all changes. A reboot is required.

4.12  Verifying Configuration Settings

  1. At the Common Service Desktop Manager, click on the [Utilities] tab.

  1. Select the Config File Manager. Ensure the following parameters match the definitions set below (see Illustration 24):

    1. Spectroscopy RF Amplifier= yes to configure the Multi-Nuclear Spectro RF Amplifier (amp to ready).

    1. Broadband Transceiver = yes to configure the MNS BroadBand Transceiver (frequency change).

    1. Power Monitor Type = 4.

    1. 3T Spectro RF AMP Type = 0.

      Illustration 24:  MR Configuration File

  1. Click [Save Changes] before exiting.

  1. Click [Quit] to exit the Config File Manager.

  1. Reboot host to save file changes.

  1. Perform Verification of SaveInfo Data.

5  Finalization

  1. Perform the TR DD System Path Check. This will ensure that the cables are connected properly and not accidentally swapped, primarily with the TX switch cables.

  1. Perform the 8kW 3.0T MNS Amplifier Calibration.

  1. Perform the Universal Power Monitor – MNS Setup and Calibration.

  1. Perform the UPM - MNS Functional Check.

  1. Perform the Multi Nuclear Spectroscopy (MNS) Functional Checks.
