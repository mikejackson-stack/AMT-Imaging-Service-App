Illustration 1:  SRI Motion Test

2  Overview

The SRI Motion test moves the cradle to home and through the end of travel switch location using different speeds and accelerations to ensure operation of the cradle.

The cradle will perform the following series of moves:

  1. The cradle moves to home (in case home isn't known, it sets the home position by moving to home).

  2. The cradle moves past the configured end of travel location. This verifies that the configuration for scan range is set to the same value as the position where the physical end of travel switch block is installed.

  3. The cradle moves 1 meter from the home switch location using a faster speed (300 mm/s) and faster acceleration and deceleration (300 mm/s/s).

  4. The cradle moves 0.5 meters further into the bore using the faster speed and acceleration.

6  Preliminary Requirements

For this test, the table needs to be docked and up.

6.1  Configuration

This diagnostic is available from the Common Service Desktop when required system components are available.

A complete system is required. No special hardware or configurations are necessary.

No additional equipment is required.

This diagnostic presents no human or equipment safety concerns.

6.5  Required Conditions

FE must be on-site. The test cannot be executed remotely.

7  Test Sequence

NOTE:This test may not be run remotely as it causes table motion.

  1. Select the Motion Test .

  2. Click [Run].

  3. Ensure that the diagnostic passes by reviewing the status in the Test Results table.
