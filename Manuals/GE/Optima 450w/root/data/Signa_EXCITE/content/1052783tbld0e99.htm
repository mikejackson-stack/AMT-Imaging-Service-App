Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities >> Toolbox >> VRE >> ICN Identification).
  2. Ensure that the Host-ICN Remote Shell diagnostic runs successfully.
    1. If that diagnostic fails, follow steps described in the help page for that diagnostic.
    2. If that diagnostic succeeds, re-run the ICN CPU Stress diagnostic.
  3. If the diagnostic fails after a second attempt, reboot the ICN. Please wait until the ICN is fully enabled. Once the ICN is enabled, re-run the diagnostic.
  4. If the diagnostic fails after the ICN reboot, check the ICN. Go to ICN Identification to identify the defective ICN (Utilities >> Toolbox >> VRE >> ICN Identification).
NOTE:If the ICN Ethernet port/cables are bad then all of the test for that ICN may fail. This does not apply to the IPMI test which has a separate Ethernet cable.

NOTE:The current product configuration has a redundant motherboard Ethernet connection for each ICN.
