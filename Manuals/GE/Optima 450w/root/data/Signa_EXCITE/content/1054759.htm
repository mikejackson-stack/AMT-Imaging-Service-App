Gradient Manual

1  Diagnostic Link

Diagnostics >> System Function >> Gradient >> Gradient Diagnostics

Diagnostics >> Hardware Location >> PGR Cabinet >> Gradient >> Gradient Diagnostics

2  Purpose

This diagnostic is available when no service key is present.

3  Components Tested

None

4  Requirements

None

5  Test Sequence

  1. Use a volt meter to obtain a volt reading from an XGA Assembly.

  2. Stop the diagnostic to return gradient amplifiers to a zero-current state.

6  Expected Results

The diagnostic returns nothing. There is no pass/fail result. The diagnostic is strictly manual. The expected voltage is displayed on the service browser.

Many FRUs are involved. No FRUs are identified in error messages because there are no error messages.
