Analog Data

1  Diagnostic Link

Diagnostics >> Peripherals >> Shim Supply Diagnostics

2  Purpose

Provide read back of the present power supply and board temperature sensor values.

This diagnostic is part of the Shim Supply Diagnostics that comprise the series of tests that verify & display various Shim Supply values by communicating from the SCP to the Shim Supply via the CAN link.

3  Components Tested

  • Shim Supply

  • Coil Channels

  • RTD Channels

4  Requirements

Software Configuration

  • Standard Software

  • CAN communications NOT emulated

Hardware Configuration

  • MGD Chassis: SCP, AGP, and APS Processor boards. Bridge board

  • Shim Supply, cabling, etc

6  Test Sequence

  1. Set the Test Duration to the number of seconds desired.

  2. The Operator selects the Analog Data radio button, then presses the [Run] button.

  3. The Diag issues a command that instructs the Shim Supply to return the present power supply and board temperature sensor values.

  4. The Diag displays the results.
