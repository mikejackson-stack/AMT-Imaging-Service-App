SPT Stability Viewer

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. From Common Service Desktop (CSD) select Image quality, then SPT Stability viewer, (see Illustration 1).

    (Step Details)

  1. Select the SPT pass that you want to analyze, then select open, (see Illustration 2). The most recent SPT file is at the bottom of the list.

    (Step Details)

  1. If the selected SPT file has Stability results, then the viewer will display it. The plots for Head FSE, Head GRE, Body FSE, and Body GRE are displayed in separate windows.(see Illustration 3).
