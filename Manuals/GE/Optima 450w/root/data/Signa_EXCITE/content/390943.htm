2  Overview

Follow this process to install the 1.5T HD Vibrant Bilateral Breast Array by GE/USAI (M3087JG).

3  Procedure

  1. Go to the Service Desktop and start the Service Desktop Browser if it's not already running.

  1. Follow the steps shown in Illustration 1.

    Illustration 1:  Starting the Config. File Manager

  1. Click the [CoilConfig] button on the left. The following screen will appear, see Illustration 2.

    Illustration 2:  CoilConfig Screen

  1. For HDx, HDxt, and HDe, add the following coil name(s) to the list of site coils:

    • HDBreast

    • HDBreastRight

    • HDBreastLeft

    • HDBreastServ

    • HDBreastRtServ

    • HDBreastLtServ

  1. Once the coils have been added click the [Save Changes] button to save changes made.

  1. Restart the system.

  1. Add coil part number into the GIB (Product Locator).

4  Finalization

No finalization steps.
