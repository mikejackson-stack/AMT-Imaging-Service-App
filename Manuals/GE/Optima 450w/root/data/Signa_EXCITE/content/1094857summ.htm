Cradle Guide Rail Replacement

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Removal of Guide Rail

NOTE:The guide rails (LH and RH) are used to guide the cradle when moving the cradle forward and backward on the table top. There are fives screws that secure each guide rail to the table top. A nut bar is provided for the screws to secure a guide rail to the table top. The nut bar is NOT secured to the table top. Installation of two screws during guide rail removal will prevent nut bar from dropping into the table top. Therefore, follow each step in this procedure to make sure bar nut does not drop into the table top during removal or installation. If nut bar drops into table top, the table top will need to be disassemble to retrieve nut bar.

  1. To obtain access to the guide rail, move the cradle back (into the magnet). (See Illustration 1.)

    (Step Details)

NOTE:Two screws in the narrow part of the guide rail should remain installed.

  1. Using a 7/64” Allen wrench, loosen each of the three screws and then remove them from the wide part of the guide rail. (See Illustration 2.)

    (Step Details)

NOTE:The nut bar is NOT secured to the table top. Installation of screw will prevent nut bar from dropping into the table top. If nut bar drops into table top, the table top will need to be disassemble to retrieve nut bar.

  1. Lift up guide rail and install screw (approximately 3 or 4 turns) into the first screw hole of the nut bar. (See Illustration 3.)

    (Step Details)

  1. Remove fourth screw from the narrow part of the guide rail. (See Illustration 4.)

    (Step Details)

  1. Loosen fifth screw until approximately 1/4-inch of thread is exposed.

NOTE:The nut bar is NOT secured to the table top. Installation of screw will prevent nut bar from dropping into the table top. If nut bar drops into table top, the table top will need to be disassemble to retrieve nut bar.

  1. Lift up guide rail and install screw (approximately 3 or 4 turns) into the fourth screw hole of the nut bar. (See Illustration 5.)

    (Step Details)

  1. Remove fifth screw from the guide rail and guide rail from the table top.

    (Step Details)

  1. If other guide rail requires replacement, repeat Step 2through Step 7.

1.2   Installation of Guide Rail

NOTE:The guide rails (LH and RH) are used to guide the cradle when moving the cradle forward and backward on the table top. There are fives screws that secure reach guide rail to the table top. A nut bar is provided for the screws to secure a guide rail to the table top. The nut bar is NOT secured to the table top. Installation of two screws during guide rail removal will prevent nut bar from dropping into the table top. Therefore, follow each step in this procedure to make sure bar nut does not drop into the table top during removal or installation. If nut bar drops into table top, the table top will need to be disassemble to retrieve nut bar.

  1. Install screw, with guide rail (narrow end), into fifth hole of the nut bar. Do not tighten screw at this time.

    (Step Details)

  1. Remove screw from fourth hole of the nut bar. (See Illustration 7.)

    (Step Details)

  1. Aligning the fourth of the guide rail with the fourth of the nut bar, install screw through the guide rail and into the nut bar. Do not tighten the screw at this time.

    (Step Details)

  1. Install a screw through the third hole of the guide rail (wide end) and into the nut bar. Do not tighten the screw at this time.

  1. Install a screw through the second hole of the guide rail (wide end) and into the nut bar. Do not tighten the screw at this time.

  1. Remove screw from the first hole of the nut bar.

  1. Install a screw through the first hole of the guide rail (wide end) and into the nut bar.

  1. Using a 7/64” Allen wrench, tighten the five screws. (See Step .)

    (Step Details)

  1. If other guide rail requires replacement, repeat Step 1through Step 8

  1. Adjust cradle guide rails. (See Cradle Guide Rail Adjustment.)
