ICN Hard Disk Health

1  Diagnostic Link

2  Purpose

The purpose of this diagnostic is to verify the SMART health status for both hard disks on an ICN. SMART refers to the Self-Monitoring Analysis and Reporting Technology system present on the ICN hard drives. SMART contains information about hard drive parameters, which can be used to predict failures.

3  Components Tested

ICN Hard Disks (Hard drives are not replaceable in Dedicated ICNs.)

4  Requirements

The ICN is turned on and has at least one network connection for the ICN motherboard Ethernet port to the Host.

5  Block Diagrams

Illustration 1:  System Cabinet and GOC Diagram

6  Test Sequence

  1. The screen is titled VRE Communications and Hardware Diagnostics.

  2. Click [Run].

    NOTE:Once [Run] is clicked, do not click anywhere else in the Common Service Desktop until the test is complete. To abort the test prior to its completion, [Stop] must be clicked.

  3. Ensure that the ICN passes the diagnostic by reviewing the status in the Test Results table.

7  Expected Results

This diagnostic has either a “passed” or “failed” status. If the diagnostic has failed, review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in Table 1.

This diagnostic has either a “passed” or “failed” status. If the diagnostic has failed, review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in Table 2.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
  2. Ensure that the Ethernet switch is turned on.
  3. Ensure that Host ICN Remote Shell diagnostic runs successfully.
    1. If that diagnostic fails, follow the steps described on the Help page for that diagnostic.
    2. If the diagnostic succeeds, rerun the ICN Hard Disk Health diagnostic.
  4. If the diagnostic fails again and the cabinet contains a silver SUN ICN, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. See Step . The hard drive is replaced by:
    • Pressing the lock lever to release
    • Pulling out the old drive
    • Sliding in the new drive
    • Pressing the lock lever to lock in place
    If the cabinet contains a black Dedicated Computing ICN, the entire ICN must be replaced. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
    NOTE:If the ICN Ethernet port/cables are bad, all the tests for that ICN may fail. This does not apply to the IPMI test, which has a separate Ethernet cable.

    The current product configuration has a redundant motherboard Ethernet connection for each ICN.

Table 2:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
  2. Ensure that the Ethernet switch is turned on.
  3. Ensure that the Host-ICN Remote Shell diagnostic runs successfully.
    1. If that diagnostic fails, follow the steps described on the Help page for that diagnostic.
    2. If the diagnostic succeeds, rerun the ICN Hard Disk Health diagnostic.
  4. If the diagnostic fails after a second attempt, run the ICN Hard Disk Stress diagnostic (Diagnostics => System Function => Recon => VRE Hardware Diagnostics).
    1. If the diagnostic fails, check the hard disk. Look at the System Error Log for the corresponding error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
    2. If the diagnostic succeeds, rerun the ICN Hard Disk Health diagnostic.
  5. If the diagnostic fails after a third attempt, run the ICN Hard Disk Integrity diagnostic (Diagnostics => System Function => Recon => VRE Hardware Diagnostics).
    NOTE:The ICN Hard Disk Integrity diagnostic takes about 85 minutes to complete.

    1. If the ICN Hard Disk Integrity diagnostic fails, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
    2. If the diagnostic succeeds, rerun the ICN Hard Disk Health diagnostic.
  6. If the diagnostic fails again, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
    NOTE:If the ICN Ethernet port/cables are bad, all the tests for that ICN may fail. This does not apply to the IPMI test, which has a separate Ethernet cable.

    The current product configuration has redundant motherboard Ethernet connection for each ICN.
