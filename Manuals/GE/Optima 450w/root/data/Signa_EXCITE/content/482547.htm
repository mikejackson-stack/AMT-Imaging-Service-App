2  Overview

This procedure sets up the Universal Power Monitor (UPM) in Body mode by using the system and the Power Measurement Kit.

    4  Procedure

    4.1  Body Forward Power Calibration

    1. To inhibit TR faults, disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet). Move the SW2 switch to the TR DISABLE position. (See Illustration 1.)

      Illustration 1:  Driver Module Front Switches

    4.2  Setting Up Software Tool to Calibrate UPM - Body Forward Power

    This tool must see a Landmark. It is not necessary to have a Body Phantom in place, or any other scan parameter entered other than what is described below.

    1. Press the [Align] button.

    1. Move the cradle into the bore.

    1. Press the [Landmark] button when the alignment light is approximately where the center of the Body Phantom would be.

    1. Start the UPM Calibration Tool.

      • For Restricted Service tools available to GE Field Service:

        1. Make sure Service Key is installed. Select [Calibration Wizard] from the Calibration menu, then Click here to start this tool.

        2. Once the Calibration Wizard starts, select [UPM Calibration, Head and Body] from the menu; review and confirm the pre and post dependencies.

        3. Select Click here to start this tool to start the procedure.

        4. If unable to start the Restricted Service tools, use the non-proprietary method described next.

      • To start Non-Proprietary Service Tools: From the Common Service Desktop, select [Calibration] => [UPM Tool] from the Calibration menu, and Click here to start this tool to start the procedure.

      NOTE:The first time the UPM Calibration tool is run after a Load from Cold, this error message may display: The spectroRFampType and upm.config do not match! Click [File] -> “Edit Config”. When the window opens, click [Restore Defaults] and close the window. (The tool should now have the correct information so this pop-up will not display during future UPM calibrations.)

      Illustration 2 shows an example of the user interface for the UPM tool.

      Illustration 2:  UPM Tool User Interface

    1. Select [1H] for Nuclei.

    1. Select [Body] for the RF Chain to be calibrated.

    1. Select [Forward] for the Power (monitor) Type.

    1. Select [Calibrate] for the Test.

    1. Select [Start], and validate the hardware setup, then select [Yes].

    1. Verify the status indicates a Pass or Fail within five minutes. (Tool should notify user of the current step in progress.) If failure occurs, see UPM Troubleshooting.

      NOTE: Step  only applies to 3.0T systems. For 1.5T systems, perform UPM - Body and Head Functional Check before proceeding to Finalization, Step 1.

    5  Finalization

    1. Remove the cables and power measurement equipment.

    1. Reconnect the Body Heliax Cable to the amplifier.

    1. Re-enable T/R Drive fault detection. (See Illustration 1.)

    1. Upon completion of UPM calibration, select [Reset TPS]. The system will not scan until this is done.
