VRF Status Display

1  Diagnostic Link

Diagnostics >> System Function >> Recon >> VRF Status Display

Diagnostics >> Hardware Location >> PGR Cabinet >> Recon >> VRF Status Display

Illustration 1:  VRF Status Display

2  Purpose

The purpose of the VRF Status Display diagnostic is to display the internal status of the VRF. This is not a test. This diagnostic can be used for further debugging if the VRF hardware or communication diagnostics fail.

3  Components Tested

  • VRF serial number

  • FPGA firmware version and temperatures

  • Status of the VRF clock input, Flash memory, and VRF fiber links

4  Requirements

No special requirements.

5  Test Sequence

NOTE:If this is a 32-channel system, use the ICN Identification tool from the Common Service Desktop (Utilities >> Toolbox >> VRE >> ICN Identification) to help distinguish ICN1 from ICN2.

NOTE:To distinguish between VRF and VRF2, open the HART Log > Current Status. Look for the item "vrf" in the BoardType column. Check the Firmware revision for this board. If the FPGA Rev is <1000, the ICN has VRF. If it is >1000, the ICN has VRF2.

  1. Select the VRF Status Display diagnostic.

  2. Select the test you would like to conduct. You can only select one test at a time. This test is executed on all connected VRFs.

    Your test options are:

    1. VRF Serial Number

    2. VRF FPGA Revision

    3. VRF Clock Status

    4. VRF Link Status

    5. VRF Temperature

    6. VRF Flash Memory Status

  3. Click [Run].

  4. Ensure that the VRF passes the diagnostic by reviewing the status in the Test Results section.

6  Expected Results

This diagnostic has either a pass or fail status. If the test you selected passes, the Test Results table displays the requested information. If the test fails, please review the error log and corresponding extended error messages for subsequent actions.
