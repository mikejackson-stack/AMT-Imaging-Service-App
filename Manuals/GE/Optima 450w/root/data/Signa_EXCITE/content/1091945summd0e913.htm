NOTE:Check that the Teslameter does not decrease as the Voltage Adjust Control is turned to zero. Only the last two digits on the Teslameter should change. If magnetic field strength decreases as the Voltage Adjust Control is turned, the Main Coil Switch is not persistent; slowly adjust the Voltage Control to return to parking field. The magnetic field will drop approximately 1 KHz when the power supply is being dialed down to zero Amps.
