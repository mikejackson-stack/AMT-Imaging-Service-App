Loading Host System Software

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

If this is not a new installation, perform a SaveInfo of all system settings before beginning the software installation.

-

-

When conducting a software reinstallation, write down all the IIP configuration data to speed up the InSite process. (It is not saved as part of the SaveInfo procedure.) The data can be accessed from the Common Service Desktop → Configuration → Guided Install → FE Mode → Service SW → InSite → Config InSite IIP. Click on each IIP Configuration tab, and record the data. This data can be manually entered after the software application load.

-

-

2  Procedure

2.1   Loading Host Operating System Software

NOTICE
The software load can be corrupted if the following conditions are not met:

  • Check SaveInfo script executed.

  • System Monitor turned On.

 
 

  1. Insert the HDv Linux OS Software DVD into the DVD-ROM drive of the host computer.

  1. Reboot the host computer.

  1. At the boot prompt, type GEHCMR

    (Step Details)

  1. Once the installation is complete, ensure the disk is removed from the drive. Do not insert the Applications DVD at this time!

  1. When the OS software is loaded, a Complete and Reboot screen (shown in Illustration 3) displays indicating that the system needs to be rebooted. Press <Enter> to reboot the PC.

    Illustration 3:  Complete and Reboot

  1. When a terminal window displays after a couple of minutes, the OS software load is complete. Continue to the next section.

2.2   Loading MR Applications Software

  1. Insert the MR Applications DVD into the DVD drive of the Host computer.

  1. When the Warning window (shown in Illustration 4) displays, click [Run Command] to confirm the run.

    (Step Details)

  1. When the Locale Selection window (shown in Illustration 6) displays, select the proper locale and language, then click [OK].

    (Step Details)

  1. The Guided Install screen will display. When the Message screen (shown in Illustration 7) displays indicating the improvements made from the previous software version, click [OK] to continue.

    (Step Details)

  1. When the Guided Install Configuration Media Dialog window displays, confirm the type of media to use to restore the Guided Install Configuration. (See Illustration 8.)

    (Step Details)

NOTICE
The last installed GUI configuration can only be installed if it was previously saved using [Save GI Configuration].
 
 

  1. Insert the Save Info DVD. Verify that the correct values are restored by checking each tab in the next step. Click [OK] to reinstall the last GUI installation configuration values.

    (Step Details)

  1. Select Basic Configuration tab shown in Illustration 9. Verify that all values under this tab are configured properly, including Time/Date.

    (Step Details)

  1. If the Guided Install configuration was successfully restored from the DVD, it is not necessary to change any of the parameters.

    1. Check the parameters on the Verification tab, and confirm there are no failures. If there are failures, make the necessary changes.

    1. Make sure all required configuration tabs are filled out (not in any specific order) before continuing. The Verification tab lists any formatting errors as well as current settings.

  1. Set Scan Range to proper value by selecting the System Configure option under the Basic Configuration option. If the length of the Magnet Room is less than 21.5 ft. (6.5 m), select [Short]. If the length is greater than 21.5 ft. (6.5 m), select [Long]. (See Illustration 10.)

    (Step Details)

NOTICE
If loading software for the first time on a Host PC, the initial boot up will fail. Manually enter the Term Server information on the Network Info screen shown in Illustration 9.

Example format: 20:2D:90:22:44. Use colons between two digits; letters are case sensitive.

 
 

  1. Proceed to the Verification tab shown in Illustration 11.

    1. Look for any items with a Fail status. Go to the tab with the error and correct it.

    1. Click [Install] to open the Verification tab again.

      (Step Details)

  1. If all entries pass verification at this point, click [Install Software] to begin the MR Applications load. If the time and time zone are correct, click [Confirm] to proceed. (See Illustration 12.)

    (Step Details)

  1. Once the MR Applications load is complete, a confirmation message (shown in Illustration 13) displays. Click [OK] to close the window.

    (Step Details)

  1. The GUI returns to the Guided Install window. Under the Utilities tab in the left navigation, select Save/Restore to open the Save/Restore screen shown in Illustration 14.

    1. If the DVD with the saved configurations is not available, go to each tab in the Install GUI and complete all system information manually. A [Help] button that provides information on the required data and its format is available on each tab.

      (Step Details)

    1. If the DVD with saved configurations is available, click [Restore Information], and select the proper media from the dialog box. (See Illustration 8.)

    1. When the Restore Info Dialog box (shown in Illustration 15) displays, click [Restore all files automatically], then click [Continue].

      (Step Details)

  1. A RestoreInfo in Progress window scrolls filenames as they are restored.

    (Step Details)

  1. Select All to restore all items, and click [Update]. When the update is finished, click [Quit].

  1. Click [Yes] when the Quit Tool message (shown in Illustration 18) displays.

    (Step Details)

  1. Reboot the system, by selecting [Desktop] on the left corner of the monitor, then [Logout], then [Restart the computer], and then [OK].

  1. Log in to the system as [root] (password is [operator])

  1. Click [Yes] to start Guided Install.

  1. Remove the MR Applications DVD.

  1. Proceed to Loading and Configuring VRE Software.

2.3   Loading and Configuring VRE Software

  1. From the Guided Install interface left navigation menu, select VRE Configuration.

    1. When the VRE Configuration screen (shown in Illustration 20) displays, verify VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.

      (Step Details)

    1. Click [Configure VRE Blades] shown in Illustration 20.

  1. When the Information window (shown in Illustration 21) displays, click [Continue] to confirm that the VRE Gigabit Switch Ethernet and Host Ethernet connections (Illustration 22) are complete and correct.

    (Step Details)

  1. When the VRE window asks for the number of connected VRE Blades, select the proper number of Image Compute Nodes (ICNs): 1 or 2, and click [OK].

    (Step Details)

  1. If the site has IRM (In Room Monitor), in the Guided Install window select IRM Installation and then select the [Install IRM Software] button. SeeIllustration 24.

    (Step Details)

  1. If this is the first or initial software load, perform a Term Server Reset by executing the following steps. Otherwise, proceed to Step 6.

    1. Remove the power connector from the Term Server. (See Illustration 25.)

      (Step Details)

    1. Press and hold the small square Reset button (next to the power jack), and connect power to the Term Server while continuing to depress this button.

    1. Continue depressing the Reset button for 20 seconds.

    1. Verify communication between the Host PC and Term Server:

      (Step Details)

    1. To stop the test, press <Ctrl-c>.

  1. Select Quit from the File menu to exit the Guided Install interface.

  1. When the Information window confirms that the configuration is complete, click [OK].

    (Step Details)

  1. Remove the MR Applications DVD from the host computer, and then reboot the computer.

    (Step Details)

3  Finalization

  1. Load Service Software: Loading or Deleting Proprietary Software

  1. Load Service Methods documentation: Installing Service Methods CD onto System

  1. Load all applicable options.
