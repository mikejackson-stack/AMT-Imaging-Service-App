2  Overview

This document details the “check scan” used at the conclusion of many procedures. This functional check assures the unit is in good clinical working order.

Last Update27 November 2007

3  Procedure

3.1  Steps

  1. Create a New Worklist item.

    1. Click [New Worklist] . See Illustration 1.

    1. Enter for Patient ID: geservice. See Illustration 2.

    1. Enter for Weight: 111. See Illustration 2.

    1. Select [Show All Protocols...]. See Illustration 2.

    1. When the Protocol Selector menu opens:

      1. Select for the Protocol Library: [GE]. See Illustration 3.

      1. Select [Adult]. See Illustration 3.

      1. Select the [Template] tab. See Illustration 3.

      1. In the [Template] tab select 30.11 - 3 - Plane 2D Localizer. See Illustration 4.

      1. In the [Template] tab select the right arrow to move to the box on the right. See Illustration 4.

      1. Click on [Accept]. See Illustration 4.

    1. Click on [Save].

    1. Select [Start Exam].

  1. Enter the following Patient parameters:

    1. Patient Position: Supine

    1. Patient Entry: Head First

    1. Coil: Body

  1. Enter the following Image parameters (refer to Illustration 5):

    1. Edit the frequency field of view (FOV) (Freq. FOV): 30.0

    1. Edit the Phase FOV: 1.00

    1. Edit the Slice Thickness: 5.0

    1. Click [Save RX].

    1. Click [Scan].
