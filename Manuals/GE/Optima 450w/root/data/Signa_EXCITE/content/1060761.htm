2  Overview

Logging into the ICNs displays the ICN output, especially for the OS load. The login function is also useful for viewing the ICN boot process and installation without connecting to an external monitor. This functional check is usually generated when there is a problem with the ICN, such as the ICN fail during a boot-up.
