Echo Planar Test (EPT)

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Startup

  1. Install a service filler panel under each of the two cradle top panels. (See Illustration 1.)

    Illustration 1:  Install Service Filler Panels

  1. Place a 100 mm sphere phantom, an EPI foam phantom holder and a phantom loader in the head coil, as shown in Illustration 2. Establish landmark on the center line of the Head Loader.

    (Step Details)

  1. Place an EPI Grafidy Foam Positioner and a second 100-mm sphere in the positioner, as shown in Illustration 4. Move the table into the bore to 1100 mm from landmark. Slide the Grafidy base plate so the center of the 100-mm sphere is at the axial alignment light, and then press the MOVE TO SCAN button.

    (Step Details)

  1. Start the Echo Planar Test Calibration Tool.

    (Step Details)

  1. Click [Start]. The Echo Planar Test Window appears.

  1. For calibration, set the Select All Tests? option to [Yes].

    (Step Details)

  1. There are four option buttons on the screen that must be set to the desired state before starting EPT:

    1. Selecting the Multi Passes button and entering an integer in the text box can perform more than one pass of the tests.

    1. One or more of the selected tests can automatically update the config files with new calibration data if the new data is within specs. Select Config Update before starting EPT.

    1. The TNS should be disabled during the EPI white pixel test for troubleshooting purposes by clicking the TNS Disable button. EPT posts a message if the TNS is not connected. Run EPT with the TNS disabled.

    1. The baseline Noise Check should be enabled during the EPI white pixel test. This check is done by comparing the mean and standard deviation to set limits. If they are outside the limits, a pop-up will appear, indicating the failure. Click [OK] to continue, which aborts the test. This will prevent false results if the receive chain is disconnected or not functioning properly.

  1. Select a Test Purpose from the pull-down menu.

  1. Two lines of Comments: can be entered, if desired. If no comments are entered, the text NO COMMENT is entered into the results file.

CAUTION
Equipment Movement!
The test you are about to initiate will move the cradle.
Please take appropriate precautions to ensure that no one will be in its path.

  1. Select [Start EPT]. Running all the tests takes about one-half hour and thoroughly tests the EPI performance of your system. This is the recommended mode for baseline, PM, and initial problem-finding. The single test mode is meant to be used while troubleshooting. If possible, run the full set of tests at the end of your troubleshooting to verify system performance. While EPT is running, each test will be displayed in the message window indicating the amount of time the test requires to run.

    (Step Details)

1.2   Image-based Short Cross Term Eddy Current Tool

If the B-zero Image fails, quit EPT and run the Image-based Short Cross Term Eddy Current tool. This tool may reduce EPI ghosting and is designed to specifically work in conjunction with the EPT. If you passed B-zero Image, you should proceed to Test Termination Procedure.

NOTE:Consider running this test even if the B-zero image passed. Based upon past experience, this may improve image quality.

  1. To quit EPT, select Quit EPT and confirm.

  1. Open the C-shell (click on the [C Shell...] button in the Service Desktop Manager) and type /usr/g/bin/runsct

    (Step Details)

  1. Click [Apply and Scan].

    (Step Details)

  1. If the system determines that correcting the short cross term values may fix the ghosting problem, compensation is applied and the B-zero Image scan starts with the new values. Data collection takes 10-15 minutes and the resulting ghosting level is measured and displayed.

    (Step Details)

  1. If the B-zero Image passes the procedure is complete and the results are displayed. Click [Exit] and re-run the EPT tool (see Illustration 5). When running the tool, go to the Body section of the test options page and click Off next to the B-zero Image (see Illustration 5). This saves time by not rerunning this part of the EPT.

  1. If the B-zero Image results are not within specification, the cross-term compensation is removed. Click [Exit] and troubleshoot the system for other ghosting sources (see Troubleshooting EPI Ghosting Problems).

  1. Once EPI ghosting problems have been brought into specification, rerun the EPT and continue to Test Termination Procedure.

1.3   Test Termination Procedure

  1. When the tests are complete, one of four messages shown below appears:

    1. Your tests completed successfully, or

    1. A minor system problem has been detected. This problem is NOT expected to affect image quality, or

    1. A serious system problem has been detected. This problem IS expected to impact image quality, or

    1. EPT was unable to determine PASS/FAIL status of the tests.

  1. Select [Quit EPT] and confirm.

    (Step Details)

1.4   EPT Report

To view the EPT data and plots, refer to the report manager tool procedure by opening the Common Service Desktop. Then select [Utilities], then [Report Manager Tool]. Enter the password: mrgo1. See Illustration 6 for file naming convention and EPT report file identification explanation.

Illustration 6:  Data File Naming Convention

2  Finalization

  1. Remove service filler panel from under each of the two cradle top panels.

  1. Perform a Check Scan to ensure the scanner is working properly before customer turn over.
