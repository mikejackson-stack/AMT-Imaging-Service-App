Secondary Cradle Latch Actuating Cable Replacement

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Undock Patient Table and move it from magnet room.

  1. Remove Upper and Lower Base Covers. For more information, see the Patient Table Upper and Lower Base Cover Removal procedure.

  1. Remove Front Base Cover.

    (Step Details)

  1. Manually slide cradle forward and prop up cradle to expose pin housing and push rod. Refer to the Removing Cradle Assembly procedure.

    (Step Details)

  1. Loosen set screw at end of push rod and cable feed lock nut to unfasten cable end.

    (Step Details)

  1. Pull cable out of pin housing.

    (Step Details)

  1. Insert new cable through cable casing.

  1. Route cable through cable casing.

  1. Loop cable twice through hole in push rod and secure with set screw. Tighten securely to prevent cable from slipping.

  1. Adjust cable so that when push rod button is pushed in 9.6 mm, pin stop is flush with pin housing. Use threaded cable adjuster for fine adjustment. Tighten lock nut after adjustment is complete, then cut off excess length of cable.

    (Step Details)

  1. Replace cradle, Front Base Cover, Upper and Lower Base Covers,

  1. Return table to magnet room and dock the Patient Table.

  1. Verify that release pin is flush to 1/16 inch (1.6 mm) below flush when table is docked.
