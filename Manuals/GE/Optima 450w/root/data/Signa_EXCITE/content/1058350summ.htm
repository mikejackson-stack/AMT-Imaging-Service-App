RF Output Power Check

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Run SPT according to IBIS/PM Assist requirements. See SPT Check and Troubleshooting For XRMB/XRMw.

  1. Verify that the SPT SNR Test (Head and Body) is within specifications (tests pass).

  1. If the SNR Test is within specification, the RF Output Power is OK. If it is out of specification, determine if the TG value is causing the failure. If the TG value is causing the failure, schedule time to adjust the RF Output Power.

2  Finalization

  1. If TG Passes, none.

  1. If TG Fails Head, adjust the Head Max Output Power. See Body and Head Maximum Power Setup and Calibration.

  1. If TG Fails Body, adjust the Body Max Output Power. See Body and Head Maximum Power Setup and Calibration.
