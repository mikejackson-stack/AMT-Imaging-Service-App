"The phantom appears to be rotated 16 degrees about the physical Z axis."
  1. See Note in the first row of this table.
  2. Visually inspect phantom in the head coil. Verify that the phantom is not rotated. A positive rotation value indicates that the phantom is rotated counter-clockwise around the Z axis. The phantom needs to be rotated clockwise to correct the situation. Be careful so you do not incorrectly align phantom when repositioning.
  3. If a positive value is noted for phantom rotation about the physical Z axis, rotate the phantom clockwise in the XY plane when viewing from the front of the magnet. Be careful so you do not incorrectly align phantom when repositioning. See Illustration 9.
"The phantom center appears to be offset 20 mm along physical X."

"The phantom center appears to be offset 20 mm along physical Y."

"Z gradient polarity appears to be inverted."
  1. See Note in the first row of this table.
  2. Review the most recent DQA exam via the image browser.Take action based on the following:CONDITION/SOLUTION:
    • If the latest exam has its image labeled Coronal, then check to see if that image looks "like" (regarding the shapes & positions of phantom features) the Coronal sample image shown in Troubleshooting.
    • If your image looks "like" the CORONAL example in the doc (even if degraded via low SNR, ghosting, distortion, etc.) then suboptimal image quality may have confused the DQA II tool and the IQ related issues must be resolved before running DQA II calibration.
    • If your acquired CORONAL image DOES NOT look "like" the CORONAL image example in the document, then you probably DO have a gradient wiring/setup problem and should proceed to the next step to track that down.
    • If the latest exam has its image(s) labeled Axial, then the tool has made an early detection of a Z gradient polarity problem, from the set of multi-slice images. Check to see if the central "bar" feature (see arrow label in AXIAL image of Section 2) moves TOWARD the resolution comb feature as the slice location moves from Inferior to Superior.If it DOES then the Z gradient is most likely polarity flipped and you should proceed to the next step to track that down. If the "bar" moves AWAY from the resolution comb feature then suboptimal image quality may have confused the DQA II tool and the IQ related issues must be resolved before running DQA II calibration.
