Connecting a Laptop to the Magmon3

1  Connecting Via The Building Network

This procedure is used to log into Magmon from the Service Browser on the customer's scanner, or from a laptop attached to the customer's network.

1.1  Prerequisites

  • The Magmon3 was previously configured for network operation using a direct connection between this device and a laptop.

  • The Magmon3 has been successfully communicating over the building network.

1.2  Precondition

Magmon3 is connected to the building network via Magmon3 – J5 port.

1.3  Procedure

  1. Find the IP address assigned to the Magmon3 by pressing Data, and then press Up repeatedly until the IP address is displayed.

  2. Write down the IP address for use in Step 6.

  3. Press Service Mode repeatedly until the display shows Start Web Mode? (Yes/No) Same IP. Press Yes to activate Web Mode.

  4. Connect the laptop to the building network using a CAT5-type network cable.

  5. Open a web browser session on the laptop.

  6. Type the Magmon3's IP address, recorded earlier in Step 2, into the laptop browser's address bar. Click (Go). The browser should display the Magmon3 Service Login screen.

2  Direct Network Cable Connection to Laptop and Magmon3

Use this procedure for these conditions:

  • First-time setup of the Magmon3.

  • Magmon3 is using a modem for InSite communication.

  • No building network connection is available.

  • Use in place of the building network connection for installing patch software (See Loading Patches in Utilities.

2.1  Precondition

Laptop connected directly to Magmon3 – J5 port using a crossover-type CAT5 network cable.

2.2  Procedure

  1. Right-click on (My Network Places) on the laptop's desktop.

  2. Select Properties from the menu. The Network Connections window (Illustration 1) will open.

    Illustration 1:  Network Connections Window

  3. Disable the wireless network connection (if enabled). Right-click on Wireless Network Connection. Select [Disable].

  4. Double-click Local Area Connection. The Local Area Connection Status window (Illustration 2) will open.

    Illustration 2:  Local Area Connection Status Window

    NOTE:Depending on the laptop's configuration, you may see the Local Area Connection Properties window (Illustration 3). In this case, skip to Step 6.

  5. Click [Properties] to open the Local Area Connection Properties window (see Illustration 3).

  6. As in Illustration 3, select Internet Protocol (TCP/IP). Click [Properties]. The Internet Protocol Properties window (Illustration 4) will open.

    Illustration 3:  Local Area Connection Properties Window

  7. Click Use the following IP address. See Illustration 4.

    Illustration 4:  Internet Protocol (TCP/IP) Properties Window

  8. Enter the following addresses, as in Illustration 4.

    • Type 192.168.0.2 in the IP address box.

    • Type 255.255.0.0 in the Subnet mask box.

  9. Click [OK] to save settings and exit.

  10. Click [OK] or [Close] to save the new Local Area Connection Properties (see Illustration 5). This may take a moment. You may also close the Local Area Connection Status window.

    Illustration 5:  Local Area Connection Properties Window

  11. Launch Internet Explorer from the laptop's desktop.

  12. In Internet Explorer, select Tools → Internet Options(see Illustration 6).

    Illustration 6:  Internet Explorer Menu Selections

  13. In the Internet Options window (Illustration 7), click the Connections tab.

    Illustration 7:  Internet Options Window

  14. Click [LAN Settings], as in Illustration 8.

    Illustration 8:  IE Connections Tab Window

  15. The Local Area Network (LAN) Settings window will open. Make sure the Automatically detect settings and Use automatic configuration script boxes are not selected (see Illustration 9).

    Illustration 9:  Local Area Network (LAN) Settings Window

  16. Click [OK] to save the LAN Settings. Click [OK] to save all settings and close the Internet Options window (see Illustration 10).

    Illustration 10:  Closing the Internet Options Window

  17. Still on the laptop, open a Command Prompt window. In Windows XP, click the icon in the taskbar. You can also go to Start → Programs → Accessories → Command Prompt.

  18. Type ping 192.168.0.1<Enter>. If the Magmon3 unit responds, as in Illustration 11, close the Command Prompt window and proceed to the next step. If not, recheck your settings.

    Illustration 11:  Command Prompt Window

  19. Return to Internet Explorer and enter the Magmon3's IP address (192.168.0.1) in the address field. Click (Go). The browser should display the Magmon3 Service Login screen (see Illustration 12).

    Illustration 12:  Magmon3 Service Login Screen

  20. Go to Login Modes for further instructions.

3  Connecting to Magmon3 From Laptop Using a Null Modem Serial Cable

If it is not possible or convenient to connect the laptop to the Magmon3 unit with a network cable, then the laptop can be connected with a serial port cable to Magmon3 - J2 and a “PC to PC” interface established. The process for setting up a new connection configuration on the laptop is different between Windows 2000 (Section 3.2) and Windows XP (Section 3.1). Make sure to follow the appropriate setup procedure for your operating system.

3.1  Windows XP Setup Procedure

  1. Use a 9-pin null-modem serial cable to connect the laptop serial port to the Magmon3 J2: Laptop jack.

  2. On the laptop, go to the desktop and right-click on (My Network Places).

  3. Click [Properties]. The Network Connections window (Illustration 13) will open.

  4. Click [Create a New Connection], as in Illustration 13.

    Illustration 13:  Network Connections Window

  5. The New Connection Wizard (Illustration 14) will open. Click [Next].

    Illustration 14:  New Connection Wizard Window

  6. In the Network Connection Type window (Illustration 15), select Set up an advanced connection and click [Next].

    Illustration 15:  Network Connection Type Window

  7. In the Advanced Connection Options window (Illustration 16), select Connect directly to another computer and click [Next].

    Illustration 16:  Advanced Connection Options Window

  8. In the Host or Guest? window (Illustration 17), select Guest and click [Next].

    Illustration 17:  Host or Guest? Window

  9. In the Connection Name window (Illustration 18), type Magmon3 in the Computer Name field and click [Next].

    Illustration 18:  Connection Name Window

  10. In the Select a Device window (Illustration 19), select Communications cable between two computers (COM1) from the menu and click [Next].

    Illustration 19:  Select a Device Window

  11. In the Connection Availability window (Illustration 20), select Anyone's use and click [Next].

    Illustration 20:  Connection Availability Window

  12. In the Completing the New Connection Wizard window (Illustration 21), confirm that the connection has been named Magmon3 and click [Finish].

    Illustration 21:  Completing the New Connection Wizard Window

  13. The Connect Magmon3 window (Illustration 22) will open. Click [Cancel].

    Illustration 22:  Connect Magmon3 Window

  14. If the Network Connections window (Illustration 23) is not open, repeat Steps 2 and 3 of Section 3.1 to open it.

    Illustration 23:  Network Connections Window

  15. In the Network Connections window, right-click on the Magmon3 connection (see Illustration 23) and select Properties from the menu. The Magmon3 Properties window (Illustration 24) will open.

    Illustration 24:  Magmon3 Properties Window

  16. In the Magmon3 Properties window, verify that Communications cable between two computers (COM1) is selected in the General tab (select this device from the menu if necessary). Click [Configure].

  17. The Modem Configuration window (Illustration 25) will open. Verify that the Maximum speed (bps) is set at 115200, and that none of the boxes are selected. Make any necessary changes, and click [OK] to return to the Magmon3 Properties window.

    Illustration 25:  Modem Configuration Window

  18. Click the Options tab (Illustration 26) and verify these settings:

    • Boxes for Display progress while connecting and Prompt for name and password, certificate, etc. are selected.

    • Redial attempts is set at 3.

    • Time between redial attempts is set at 1 minute.

    • Idle time before hanging up is set at never.

    • Redial if line is dropped box is not selected.

    When all settings are correct, click [OK] to confirm and save your settings.

    Illustration 26:  Magmon3 Options Properties Tab

  19. Click the Security tab (Illustration 27), and verify these settings:

    • Typical (recommended settings) is selected.

    • Allow unsecured password is selected under Validate my identity as follows.

    When all settings are correct, click [OK] to confirm and save your settings.

    Illustration 27:  Magmon3 Security Properties Tab

  20. Click the Networking tab (Illustration 28) and verify these settings:

    • Type of dial-up server I am calling is set to PPP:Windows95/98/NT4/2000, Internet.

    • Internet Protocol (TCP/IP) is the only item selected in the section marked This connection uses the following items.

    When you have confirmed these settings, click [Settings] to further configure your dial-up connection.

    Illustration 28:  Magmon3 Networking Properties Tab

  21. In the PPP Settings window (Illustration 29), confirm that Enable LCP extensions is the only box selected. Make any necessary changes, and click [OK].

    Illustration 29:  Magmon3 PPP Settings Window

  22. Still on the Networking tab, click [Properties]. The Internet Protocol (TCP/IP) Properties window (Illustration 30) opens.

  23. Verify that the following items are selected:

    • Obtain an IP address automatically

    • Obtain DNS server address automatically

    When all settings are correct, click [OK].

    Illustration 30:  Magmon3 TCP/IP Properties Window

  24. Click the Advanced tab (Illustration 31). Verify that no boxes in this tab are selected.

    Illustration 31:  Magmon3 Advanced Properties Tab

  25. When you have completed reviewing the Magmon3 Properties settings, click [OK] to save (see Illustration 31). You may have to click [Cancel] to close the window.

  26. If the Network Connections window (Illustration 32) is not open, repeat Steps 2 and 3 of Section 3.1 to open it.

    Illustration 32:  Network Connections Window

  27. In the Network Connections window, double-click [MAGMON3] to open the Connect window (Illustration 33).

    Illustration 33:  Magmon3 Connect Window

  28. Enter the following information in this settings window:

    1. User name: pppuser

    2. Password: insite

    3. Select the Save this user name and password for the following users box.

  29. When all settings in this box are correct, click [Connect]. A popup window will show the connection status.

  30. When you are connected to the Magmon3, open Internet Explorer on the laptop. Type 10.0.0.5 in the address window and click (Go).

  31. The Magmon3 Service Login screen (Illustration 34) will appear.

    Illustration 34:  Magmon3 Service Login Screen

  32. Go to Login Modes for further instructions.

    When you have confirmed these settings, click [Settings] to further configure your dial-up connection.

    Illustration 48:  Magmon3 Networking Properties Windows

  18. In the PPP Settings window (Illustration 48), confirm that Enable LCP extensions is the only box selected. Make any necessary changes, and click [OK].

  19. Still on the Networking tab, click [Properties]. The Internet Protocol (TCP/IP) Properties window (Illustration 49) opens.

    Illustration 49:  Magmon3 TCP/IP Properties Window

  20. Verify that the following items are selected:

    • Obtain an IP address automatically

    • Obtain DNS server address automatically

    When all settings are correct, click [OK].

  21. Click the Sharing tab (Illustration 50). Verify that no boxes in this tab are selected.

    Illustration 50:  Magmon3 Sharing Properties Tab

  22. When you have completed reviewing the Magmon3 Properties settings, click [OK] to save changes and close the window.

  23. In the Network and Dial-Up Connections window (Illustration 51), double-click [MAGMON3] to open the Connect window.

    Illustration 51:  Network and Dial-Up Connections Window

    2. Password: insite

  25. When all settings in this box are correct, click [Connect]. A popup window will show the connection status.

  26. When you are connected to the Magmon3, open Internet Explorer on the laptop. Type 10.0.0.5 in the address field and click (Go).

  27. The Magmon3 Service Login screen (Illustration 53) will appear.

    Illustration 53:  Magmon3 Service Login Screen
