Keyboard Operation / Description of IPA and PA Stages

Illustration 1:  RF Setup Keypad

Button Definitions: Refer to the Amplifiers’ Vender Manual for complete documentation.

Local (Allows for Local or External amplifier keypad control. This button has no significance in the Field or for Service. It is only used at the factory. When the green LED is OFF, the amplifier control is in local mode. NORMAL operation: Green LED is ON, indicating that there is external (Computer) control.)

Down Arrow and Up arrow (These two buttons are used to increase or decrease the gain/Attenuation of the amplifier, and also are used to increase or decrease the “Step size” of the “ATTN Setup” and “VVA Setup” Function.)

Enter Button (Used to lock in the value of “ATTN Setup” or VVA setup”. It is pushed at the end of each setup mode.)

Operate (Same as Stby. Returns amplifier to normal operation. Upon completion of “ATTN Setup” and/or “VVA Setup”, this button is pushed. Wait at least 30 seconds to download the setup values to the solid state ROM. )

Stby (Same as Operate. Returns amplifier to normal operation. In this state the RF amp can once again be controlled by the system to go into operate mode when Scan requires. Upon completion of “ATTN Setup” and/or “VVA Setup”, this button is pushed. Wait at least 30 seconds to download the setup values to the solid state ROM.)

Mode (Changes output of Solid State Amplifier between Head and Body Modes of operation.)

Menu Button (Used to switch menues or to exit a calibration menu.)

Solid State Pre-amplifier: (This Solid State pre-amplifier stage feeds both the Head and Body Amplifier stages. )

  • When Head mode is selected in the Protocol or UPM tool the solid State board switches its drive output to the Head (IPA) Amplifier.

  • When Body mode is selected in the Protocol or UPM tool the solid State board switches its drive output to the Body (PA) Amplifier.

The Solid State Pre-amplifier gain is adjusted by using the “Gain Adjust” or VVA “Setup”. This adjustment has a very large affect on overall amplifier output.

Body (PA) stage (The PA stage (Body) is a fixed gain tube type amplifier and must be set to 35KW at TG of 200 in the 3.0T Excite system.)
