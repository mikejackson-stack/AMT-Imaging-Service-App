1.2   FE Cockpit Top-level Page

The FE Cockpit top-level page consists of three sections: the Header, Functional Grid, and Planned Maintenance.

  1. Header

    1. Contains all general system information. The Host Computer and System Info boxes contain information specific to the scanner.

    1. The Time Filter area allows you to filter the displayed information based on time criteria. The Help link opens a short help summary page.

    1. Host Computer and System Info

      1. The Host Computer section contains system information including the Host name, Host ID (used for eLicense), IP address, and Software and OS versions.

      1. The System Info link displays details of the hospital, system ID, and system type. See Illustration 3.

        (Step Details)

    1. Time Filter

      1. The Functional Grid area displays events that occurred since the last TPS reset. The data can be filtered by TPS Reset, 1 Day, 1 Week, 1 Month, or All. To change the time filter, select the radial button of the selection and click [Refresh].

      1. Click [IIS Update] to update the Install in Spec data in the FE cockpit. The IIS script will run and update the cockpit with all new information. The [Refresh] button only updates data from the error and HART log files.

      1. Data can also be filtered by a specified range of dates. Enter the starting date in the DD/MM/YYYY H:M format. Enter the ending date, using the same format, and click[Refresh].

  1. Functional Grid

    1. Most of the system data is displayed in the functional grid. This area consists of nine main functional blocks. Log data that can be traced to a specific functional area is listed in the columns to the right of the functional blocks.

    1. Functional areas are: Acquisition/Pulse Generation, Gradient, Magnet, Global Operator Console, Patient Handling, RF, Surface Coils, Power/Support Systems, and Software/ Firmware /Config.

    1. Each of the main functional areas can be broken down into mid-level and/or FRU-level pages (See Illustration 4). These mid-level pages present the log information in more specific categories or specific to FRUs. If Calibration or Performance Data is available for that functional area, the details are listed on the mid-level page.

      (Step Details)

  1. Planned Maintenance

    1. On the lower right side of the FE cockpit top-level page, is the Planned Maintenance status box.

    1. The status displays in one of the following color-coded text indicators:

      1. Green: PM is due in > than 14 days

      1. Black: PM is due in < than 14 days

      1. Red: PM is overdue (past due date), or PM data files are not present.

      (Step Details)

    1. Patch status is also listed in the Planned Maintenance window. If the patch configuration file is loaded on the scanner, any required patches are listed.

1.4   E-Reporting Page

The E-Reporting Tool is a web-based application that allows customers to read service reports created by Field Engineers or Online Engineers. With the E-Reporting Tool, an engineer can generate a report that documents the service performed on an MR System at a customer site. The report appears in the Unread list when a service engineer has created and saved the report. The report is then moved to the Read list once the customer has opened the report. In addition to viewing reports, customers can export these reports to media, such as DVD, CD, or a USB drive. Each service report includes the hospital name, system ID, system name, and the date it was generated. Service reports for the last three years are maintained on the system. Reports older than three years are automatically deleted.

  1. To access the E-Reporting Tool, click the E-Reporting link on the FE Cockpit Home Page (see Illustration 14). The E-Reporting View Service Reports page is displayed (see Illustration 15).

    (Step Details)

  1. To view a report, click the View link for that report (see Illustration 15).

    (Step Details)
