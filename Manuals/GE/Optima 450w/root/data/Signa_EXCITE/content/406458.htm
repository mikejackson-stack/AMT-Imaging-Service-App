2  Overview

Follow this process to prepare for the automated SNR test using the 3.0T HD NV Array by GE/USAI (M1385AT).

NOTE:Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.

4  Procedure

4.1  Legacy Phantom Setup

  1. Insert phantom on posterior section of coil. Position anterior component over phantom and secure with latches on either side.

  1. Locate and release button on chest piece and slide chest piece up into the coil. Move chest piece down onto the phantom using handle. See Illustration 1.

    Illustration 1:  Location of Release Button And Chest Piece

  1. Secure phantom in the coil with Velcro straps. See Illustration 2.

    Illustration 2:  Securing Phantom

  1. Landmark coil using positioning mark. See Illustration 3.
