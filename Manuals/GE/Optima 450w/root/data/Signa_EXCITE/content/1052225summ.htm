3  Procedure

3.1   Field Map Creation

NOTICE
After loading, landmarking, and selecting [Advance To Scan], allow the Phantom to settle for 15 minutes prior to scanning.
 
 

  1. At the Operator Workstation, select Service Desktop and prepare the system by performing a [TPS Reset].

  1. Load and landmark the LVShim phantom. (See Illustration 1 for the loading/landmarking steps.)

    (Step Details)

  1. At the Operator Workstation, select the scan icon from the desktop control panel and set up the High Order Shim calibration scan as follows.

    (Step Details)

  1. Under Patient Protocols, select Service, and click [Other].

    1. Find and select the LVShim protocol, and click [1] for Series.

    1. Click [Accept] to download the series.

    1. Click [Save].

  1. To execute the scan, select in order: [Start Exam] > [Save Rx] > <Scan>.

  1. When the image displays in the Autoview window, select the Series Data tab. Select [Exam] > [Series] > [Image], and click [Viewer].

  1. Verify that the phantom is centered in the Z axis:

    1. Click [User Prefs].

    1. In the User Preferences pop-up window, find Grid Prefs and click [Customize…].

    1. Change Grid Spacing (mm) to 150, click [OK], then[Apply].

    1. Select the [Grid Symbol] button to turn on the grid. (See Illustration 2 for an example of an image with the alignment grid.)

      (Step Details)

    1. Adjust the W (Window) and L (Level) settings until the edges of the phantom image can be clearly seen.

    1. Verify that the inner phantom sphere is centered within the 150 mm grid in the S/I direction as shown in Illustration 2.

      1. If the phantom is not centered, move the phantom in or out of the bore and right to left as necessary, based on the grid markings.

      1. Landmark again and re-scan

3.2   Running Makereference Script

The Makereferemce Script takes 45 minutes to complete.

  1. Start the HOShim Reference Map tool.

    1. On the service Desktop, open the Service Browser if it is not already running.

    1. Select the Calibration tab.

    1. If a service key is present, refer to Illustration 3 to run the Install and Calibration Wizard.

      (Step Details)

    1. Once the Wizard starts, select HOShim Procedure from the menu if available.

      (Step Details)

    1. Select Ho Shim Reference Map from the Calibration menu and Click here to start the tool.

  1. Once the HOShim Reference Map is started, the Graphic User Interface (GUI) shown in Illustration 5 displays.

    (Step Details)

  1. Select [Start Scan]. When the message, Scanning. Please wait Until Scan Done!. displays, click [OK].

  1. The system prescans first, then scans. There are multiple scans in this sequence with no user interaction at this time.

  1. After the scan is done, the lower portion of the screen indicates, Reference Map Creation in Progress.

  1. Verify that the system created the HOShim reference maps correctly. (Refer to Calibration Verification.)

3.3   Calibration Verification

  1. After the HO Shim Reference Map is created, click [Analyze Ref Map] to verify that the calibration was successful. (Click [Quit] once the scan is complete to exit the screen.)

  1. When the HOSM Ref Map Analyzer screen shown in Illustration 6 displays, select Ref file... and the Shim reference map to be analyzed by double clicking on the proper file. (Select the files that do not have a suffix of .mask or .params.)

    (Step Details)

  1. When the proper file is selected, click [CALCULATE] on the HOSM Ref Map Analyzer screen. Data for the selected map displays.

  1. Scroll down and view the table entitled, Normalized Results Mat. Review the x, x - y, y - z, z files. Refer to Illustration 6. The values circled in blue should be between 0.90 and 1.0. This indicates that the HO Shim Reference Map was successfully created.

4  Finalization

  1. Perform a [SaveInfo] to back up the calibration files. To verify the saved calibration files, see Verifying Save Restore Media.

  1. If completed, store all phantoms and tools.
