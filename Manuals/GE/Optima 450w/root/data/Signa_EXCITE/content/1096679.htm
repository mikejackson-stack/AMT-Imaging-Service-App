2.3  Safety

DANGER
Ferrous Material Present!
The Active Driver module installed in the MRE option contains ferrous material and presents a hazard if it is moved into a magnet room.
Do not move the Active Driver module into a magnet room.

DANGER
Electric Shock Hazard!
Cleaning components of the MRE option while the Active Driver MODULE is connected to electric power may result in electric shock.
Disconnect the MRE components from electric power before attempting to clean them. Wait for all components to dry completely before reconnecting power.

3.2  Configuring MRE Communication

To configure the system to communicate with the Active Driver module:

  1. Connect the 288 inch main tube to the Active Driver module. See Illustration 1.

  1. Connect the BNC cable to PEN cabinet, Exciter Module J6.

  1. Connect the Ethernet Cable to the Ethernet hub in the PGR cabinet.

  1. Connect the AC power cable to the facility-provided AC power socket.

  1. Pull the 288 inch main tube through the facility-provided waveguide.

  1. Turn on the Active Driver module.

  1. On the MR Console, find the IP address for the MR system:

    1. At the MR Console, start a c-shell window.

    1. In the c-shell window, type the following command:

      cat etc/hosts <Enter>

    1. This displays the hosts file for the MR Console. Locate and write down the agp address shown in the hosts file (this is the IP address of the console).

  1. The default address of the MRE Active Driver module is 10.0.1.30. The first three numbers of the address need to match the address of the MR system. If the IP address of the MR system is not of the form 10.0.1.x (where x is a number between 0 and 255), you will need to modify the IP address of the MRE Active Driver module:

    1. Disable wireless Ethernet communication on the laptop computer.

    NOTE:Write down the Ethernet communication settings for the laptop computer before changing them. This will make restoring the settings easier.

    1. Set the IP address of the laptop computer to a fixed address.

      1. Click Start > Settings > Network Connections.

      1. Right-click the Local Area Connection icon, and then click Properties. The system displays the Local Area Connection Properties window.

      1. From the This connection uses the following items list, select Internet Protocol (TCP/IP), and then click [Properties]. The system displays the Internet Protocol (TCP/IP) Properties window.

        Illustration 3:  Laptop IP Connections Setup

      1. Select the Use the following IP address button.

      1. In the IP address field, type an address for the computer. Make sure the address is of the same form as the address of the MR system, but unique. For example, if the MR system has the address 10.0.6.0, set the IP address of the laptop computer to 10.0.6.31.

      1. In the Subnet mask field, enter 255.255.255.0.

      1. Click [OK] to close the Internet Protocol (TCP/IP) Properties window.

      1. Click [OK] to close the Local Area Connection Properties window.

    1. Using an Ethernet cable, connect the laptop computer to the same side of the PGR cabinet Ethernet hub where the MRE Active Driver Module is connected.

    1. Insert the IP Setup Disc provided with the MRE Option into the laptop computer.

    1. Run IPsetup.exe from the IP Setup Disc.

    1. The IP Setup screen appears. The MRE Active Driver module should appear in the Select a Unit window.

    1. Change the IP address for the Active Driver module to match the first three numbers in the IP address of the MR system. For example, if the MR system has the address 10.0.6.0, change the IP address of the Active Driver module to 10.0.6.30.

      Illustration 4:  MRE IP Setup

    1. Highlight the Active Driver module, and then click [Set -- >].

    1. Click [Launch Webpage].

    1. A web page displays. Write down the IP address and MAC address displayed under System Parameters.

      Illustration 5:  Active Driver System Parameters Web Page

    NOTICE
    Recording the IP address of the MRE Active Driver module is critical. The address needs to be available for future servicing of the system.
     
     

    1. Record the IP address of the MRE Active Driver module for future reference.

    1. Close the web page and the IP Setup screen.

    1. Reset the laptop back to its normal IP addressing, and disconnect the Ethernet cable from the laptop and the Ethernet hub in the PGR cabinet.

    1. If you disabled wireless Ethernet communication on the laptop, re-enable it.

    1. At the MR Console, use gedit to edit the /w/config/mre_comm.cfg file, and replace the IP address in the file with the address you set in Step 8.g.

  1. Make sure the touch2d option key is installed on the system. If it is not, install the key using the procedures in Software Option Install with eLicense Generated Keys.

3.3  Cleaning MRE Components

DANGER
Electric Shock Hazard!
Cleaning components of the MRE option while the Active Driver is connected to electric power may result in electric shock.
Disconnect the MRE components from electric power before attempting to clean them. Wait for all components to dry completely before reconnecting power.

NOTE:Do not rub decals on MRE equipment during cleaning. Over time, the decals will rub off.

Do not use solvent-based or alcohol-based cleaning solutions for cleaning the Active Driver module.

  1. Clean MRE components with a damp cloth moistened with a solution of bleach diluted with water or a 5% hydrogen peroxide solution. The cloth used for cleaning must not have excess fluid (no fluid may drip from the cloth).

  1. Wipe components dry with a clean, dry cloth.

  1. Allow all components to air dry completely before reconnecting power.
