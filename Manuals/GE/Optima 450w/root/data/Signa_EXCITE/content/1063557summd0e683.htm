In Auto mode, the tool automatically does the following:

  • Sets up the protocol and collects image data.

  • Calculates the harmonics and compares it with the specification.

  • Calculates dc offsets for X, Y and Z.

  • Completes multiple iterations (maximum = 5) until harmonics meets the specification.

  • Lists the last iteration reanalyzed at 45 DSV in Test mode (customer acceptance specs) in the final column.

After the scan is complete (with the service key still inserted), the tool compares all of the harmonics to spec in the Test mode.

  • Green cell = Passed specification

  • Red cell = Failed specification

NOTE:If ANY of the cell(s) are still red after five iterations, refer to the LVShim Troubleshooting manual for more information on corrective action to be taken.
