SRI Button Loop Back Test

1  Diagnostic Link

Diagnostics >> Periperals >> SRI Functional Tests

2  Purpose

This test is useful for troubleshooting intermittent keypad button problems. It displays which key on the enclosure's control panel is being pressed. Once the operator presses the Done button, the SCP will reset the SRI to end the test.

3  Components Tested

4  Requirements

5  Block Diagram

6  Test Sequence

  1. Select the test.

  2. Click [Run].

  3. Once complete, click [Stop] and the SCP will reset the SRI to end the test.

7  Expected Results

As buttons on either contol panel are pressed they will be identified in the Test Results field.
