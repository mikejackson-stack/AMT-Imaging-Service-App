Magnet Monitor Installation

The Magnet Monitor, supplied with the magnet, monitors the cryogen level inside the magnet and controls the internal helium vessel pressure. Install Magnet Monitor 2219400 in conformance with Direction 2230681, LCC Magnet Monitor Hardware (SHEM) Installation. Install Magnet Monitor 2394952 in conformance with the magnet's Service Methods CD or with Direction 5124576, Magnet Monitor 3 Operation & Hardware Installation.

The Magnet Monitor's connection to magnet is shown in Magnet Monitor Interface. Cable schematics are shown in Magnet Monitor Cables.
