About this task

This procedure describes coherent noise check using System Performance Test (SPT)

For SPT Body Full procedure, refer to SPT Body Check.

Topic ID: id_SL3887770-1277339

TDI HNU setup

Procedure

  1. Properly position TDI HNU on the cradle and Insert connector.
  2. Landmark on the center line of the TDI HNU.
    Note

    No phantom is needed for SPT Coherent Noise Check.

  3. Press Advance to Scan.
Topic ID: id_SL1713717-1277339

Invoking SPT Full Test Mode

Procedure

  1. To start the SPT Full Test tool from the Service Browser, select the Image Quality tab and follow the steps shown in the illustration below.
  2. An SPT Test menu window displays on the desktop.
    1. Click No next to all tests fields.
    2. Select “Coherent Noise” to ”On”. Select rest of the test to “Off”.
    3. To select a reason for the test, choose an option from the Test Purpose list. If desired, enter text in the Comments field.
    4. To select multiple passes of the test(s), click Multi Passes and then enter a number in the field.
    5. Click Start SPT to begin.

      As the tests run, status messages display in the text box below the menu. Use the scroll bar on the right to move up or down through the messages.

    Note

    This screen displays until you quit SPT.

    As each test is running, a message displays in the window indicating which data is being collected or processed. Start time and estimated completion times also display. Although the estimated time may expire, the test is not complete until you see a successful or failure message.

    Note

    The total image number used for coherent noise check will be about 400 according to the following formula.

  3. To exit SPT, click Quit SPT.
  4. To view SPT results, select the Utilities tab on the Service Browser, then click Report Manager.
  5. Enter the report manager password (mrgo1) and press Enter .
Topic ID: id_15003591

Finalization

Procedure

  1. Complete a TPS reset, which takes a few minutes, after completing SPT.
  2. If for any reason an SPT scan is aborted, check the error log to determine why, and then determine next steps.
  3. Remove service equipment from the system.
