Loading Operator Documentation

About this task

All operator manuals are distributed electronically. These instructions describe how to load the operator manuals onto the system’s host computer so customers can have access to the manuals any time they are using the system.

Procedure

  1. The DVD Media for Operator Manual is available in multiple languages. Select the DVD that contains the language for the documentation that is to be installed on the system. Each DVD label has the list of languages contained on the DVD. If the Operator Manual was downloaded through IRIS on systems running software version 30 or later, there is no need for a DVD.
  2. Launch Guided Install. The login ID is root and the password is operator.
    Note

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. In the content window on the left side, select Service SW/Insite.
  4. Click the Install Online Help button.
  5. When prompted to insert the media containing online documentation, insert the DVD containing the selected language (DVD/USB Media for Operator Manual) into the host computer's DVD drive and then click OK.
    Note If the Operator Manual is already downloaded through the IRIS Remote Software Download functionality, there is no need for DVD media.
    Note The DVD/USB Media for Operator Manual is available in multiple languages. Make sure the selected DVD contains the language to be installed at the site.
  6. A pop-up menu appears. Select the language that is to be used for the online help and press Install.

    If the language you want is not on the menu, try another operator manual DVD.

  7. After the installation is complete, a message appears indicating that the installation was successful.
  8. (For software version 30 and later) The Operator Manual language can be changed dynamically after the installation from the drop-down menu in the upper right corner of the screen:
  9. Remove the DVD from the drive, if applicable.
  10. To make sure the Online Help opens, click the book icon in the lower right corner of the monitor and view the documents.
