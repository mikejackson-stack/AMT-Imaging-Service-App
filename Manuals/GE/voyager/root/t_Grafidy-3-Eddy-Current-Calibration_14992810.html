About this task

Use the Grafidy 3 procedure to perform eddy current compensation. Grafidy 3 adjusts and compensates long and very long time constant eddy currents for both linear and B0 terms.

Note Do not attempt to change the short values manually. Serious damage may occur to the system.

Grafidy 3 uses a dedicated pulse sequence (PSD), 6-channel fixture, and Grafidy 3 software. The Grafidy 3 fixture plugs into the P port for transmit/receive. No additional fixtures or cables are needed.

This tool simplifies setting up the calibration and collects data from all 6 coils simultaneously. The basic steps required in Grafidy 3 are:

  • Set up the 6-channel Grafidy fixture.

  • Start Grafidy 3, and run the tool in Auto mode.

Review the detailed description for using the Grafidy 3 tools. For more information, see Grafidy 3 Tools and Grafidy 3 Troubleshooting.

Topic ID: id_SL1775951-1178718

Hardware Setup

Procedure

  1. Unfold the 6-channel Grafidy fixture and lock the arms into place (90° from center plate).
    Note Confirm that 6-channel Grafidy fixture is firmly pushed into the slit of Foam Support without any gap.
  2. Connect the P-port cable to the T/R board and secure with screws. Place the fixture at the front of the table with the connection box toward the bore.
  3. Connect P-Port Connector to P2 Port.
  4. Center the laser crosshairs on top of the fixture. Landmark the system and press Advance to Scan.
Topic ID: id_SL1775958-1178718

Running Grafidy 3

Procedure

  1. Start the Grafidy 3 tool:
    1. (For non-proprietary service tools) From the Common Service Desktop, select Calibration > Grafidy3. Select Click here to start this tool.

    The Grafidy3 window appears.

  2. Click the Auto Mode tab.

    All three coil axes are selected automatically.

  3. Click the Scan button to start the calibration.

    • When the scan is active, it can be stopped by pressing the Abort button and the STOP button on the keyboard.

    • Highlight the desired axis and select Show to display the result graphs.

    In Auto and Manual modes, a number of signal checks are performed to ensure the proper state of the Grafidy fixture. The following signals are examined from every channel, and an error is reported if a problem is found.

    • Position

    • SNR

    • Signal saturation

    The Grafidy 3 software runs multiple scans to bring each term into specification. It iterates up to the maximum specified (default is 5 iterations). When each component finishes a scan/analysis iteration, the residual of the eddy current of the measurement displays in the results table. The results are color-coded.

    Text Color Definition
    RedValues above spec
    GreenWithin spec
  4. Review the numeric output values from the Auto mode scan. Verify that the results of the final iteration for each component are within specification (green).
  5. If a component is not within specification after the maximum number of iterations, you can restart after Zero-Out or use Manual mode to calibrate that component.
Topic ID: id_SL1775967-1178718

Manual Mode

About this task

Manual mode allows you to iterate through the process and decide when to stop.

Procedure

  1. Select the Manual Mode tab.
  2. Select the desired terms, and press Scan.
  3. If the Prompt To Accept mode is active, a graph of the results displays after the scan is completed.
  4. If a good fit is displayed (fit line aligned with data line), click Accept. The calibration values are saved to disk, and used in the next scan. Repeat this process by returning to Step 2.
  5. If a bad fit is displayed, click Cancel.
    Note This leaves the last accepted values in the calibration files. Do not expect any improvement on future scans when the fit does not match the data, even if the Cal parameters are accepted.
  6. The last iteration for any component must be a check only. Do not accept the fit parameters. You will not be allowed to exit immediately after updating the Cal parameters.
Topic ID: id_14962082

Finalization

Procedure

  1. Exit the software tool, saving the eddy current data.
  2. Remove the Grafidy fixture from the system.
