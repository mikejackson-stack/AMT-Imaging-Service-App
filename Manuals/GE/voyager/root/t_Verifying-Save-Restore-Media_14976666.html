Verifying Save Restore Media

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-
Required conditions
SIGNA Software is running.

About this task

Verify SaveInfo Data is used to verify content of SaveInfo media to the original data on the system disk drive. The program firsts checks that all files are present on the SaveInfo media and then if check sums match.

Procedure

  1. Insert your already created SaveInfo DVD into the appropriate drive if it's not already there.
  2. At the host computer, go to the Service Desktop and open the Service Browser if it's not already running and start the Guided Install tool in FE Mode, Starting Guided Install From The Service Browser.
  3. The tool will then begin the verification of the data on the media with that on the system hard drive. See Verification Wait Screen.

    Result

    • If no media is present, the user will receive a error message at this time. See Error Message.
    • While the media is being checked, the pop-up shown in Verification Wait Screen.will be displayed on the screen. The run will take about 2 minutes.
  4. Once verification is complete, the system will ask "Do you want to review the CheckInfo log?" Click the Yes button.
  5. A log will be shown that will list content found and it . See SaveInfo Verification Log. If any errors are reported, it his highly suggested that a new SaveInfo be created.

Finalization

  1. Store Save/Restore media in a safe place.
  2. Do a test scan before customer turnover to ensure proper operation.
