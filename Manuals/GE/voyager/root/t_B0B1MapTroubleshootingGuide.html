B0 B1 Map Troubleshooting Guide

When you find shadings in the image, please follow the procedure below and setup B0 map and B1 map protocols.

About this task

Image uniformity issue may manifest in the clinical images (e.g. shading), which is resulted from hardware-related or patient-specific issue.
Note B0 map and B1 map protocols can be used on patients.
  • Loading B0 map for software version earlier than MR30
  • Loading B1 map for software version earlier than MR30
  • Load B0 and B1 map for software version MR30 and later
Topic ID: task_lfc_p4n_wwb

Loading B0 map for software version earlier than MR30

Procedure

  1. Reproduce the bad scan. Keep the same scan parameters as the clinical scan. Parameters includes protocols, scan settings, coils, patient position, localizer position and so on.
  2. Make a new scan by clicking Duplicate & Setup button.
  3. Follow 3.1 - 3.4 to set 21 items of copied protocol as values listed in Values to be set.
    Table 1. Values to be set
    SettingParameterValuePositionAttention
    1PlaneSame as Clinical scanImaging Options -> More
    2Mode2DImaging Options -> More
    3FamilyGradient EchoImaging Options -> More
    4PulseGREImaging Options -> More
    5PSD NameB0rfImaging Options -> MoreNeed click Enter after typing in.
    6TRSame as Clinical scanExam Page
    7CoilSame as Clinical scanExam Page
    8FOVSame as Clinical scanExam Page
    9Phase FOVSame as Clinical scanExam Page
    10Slice ThicknessSame as Clinical scanExam Page
    11SpacingSame as Clinical scanExam Page
    12Freq.DirSame as Clinical scanExam Page
    13Loc Before Pause0Exam PageIf have.
    14TEMin FullExam Page
    15FA20Exam Page
    16Frequency128Exam Page
    17Phase128Exam Page
    18NEX1Exam Page
    19Bandwidth31.25Exam Page
    20Scan Modes0: If scan phantom; 1: If scan a real patientExam Page_AdvancedNeed click Enter after typing in.
    21B0 Field Mapping Rang in Hz220Exam Page_AdvancedNeed click Enter after typing in.
    1. Open Imaging Option Page by clicking Imaging Options button. Then click More button.
    2. Set item 2 to item 5.
      • Set Mode, GradientEcho and GRE.
      • Type B0rf in PSD Name then press Enter .
      • Click Accept to save and quit this page.
        Note A warning window may pop up showing “GRx will be lost. Please prescribe GRx again.” Click Ok to close the window
    3. Click Copy Rx Button in the Graphic Rx Toolbar and select the bad scan
      Note If a 3D bad protocol is copied, select All in ModeFilter tab
    4. Set item 6 and item 14 – 19.
      Note Item 6 could be the same as clinical scan or set as 250
    5. Click Advanced tab and set item 20 and 21 then Press Enter.
      Note Pay attention to type in correct scan mode (0: scan phantom; 1: scan patient).
  4. Save settings by click Save Rx button.
  5. Rename the copied protocol.
    Note It’s better to add a suffix “B0 Map” in the copied protocol name
  6. On Scan button, click Manual Prescan to make sure the prescan parameters are the same as the bad scan.
  7. Click Scan to start scan.
  8. Check the result.
  9. Export the whole exam and send to engineer team if no other test needed.

Load B0 and B1 map for software version MR30 and later

Procedure

  1. Select the active scan session tab.
  2. From Scan/Task panel, click Add Task > Add Sequence.
  3. From the Protocol screen, select Service protocol library.
  4. Click the protocol folder (B0map_RF_Test, b1map_tool).
  5. Click B0map_RF_Test,and then click the to send the protocol to the Multi Protocol Basket.
  6. Click B1 map,and then click the to send the protocol to the Multi Protocol Basket.
  7. Click Accept.
  8. Copy the graphic prescriptions from original series to B0/B1map series.
    1. Click the icon to open the Graphic Rx toolbar.
    2. From Graphic Rx toolbar, Click the icon to open the Copy Rx screen
    3. Select Mode Filter, select All.
    4. Click the desired series (B0map_RF_Test or B1 map) from the Series List window.
    5. Click Original Loc.
    6. Click Accept.
      • Regardless of the viewport active or the images displayed in the viewports, the system displays the original localizer in the original active viewport and posts the graphic lines.
  9. Edit the B0map_RF_Test scan parameters.
    1. Click the to show the details and advanced tab.
    2. On details tab, review and edit the parameter as below:
