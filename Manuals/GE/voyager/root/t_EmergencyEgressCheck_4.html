Checking the emergency egress function

Checks the patient table emergency egress system for correct operation.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-

About this task

The emergency egress functions are different depending on the type of table. Please select the appropriate table type for checking the emergency egress system:
  • Dockable table
  • Fixed table
Topic ID: task_cbw_5lh_53b

Dockable table

About this task

The dockable table has a powered egress mechanism. This option is only applicable when the power is on. If the power is off, move the cradle manually.

Procedure

  1. Press the cradle in button on the control panel and position the cradle approximately 500 mm (20 inches) into the bore.
  2. Pull up the cradle release handle and release it. The cradle will move back to the home position.
    Note While in egress, the handle must be continuously activated for the cradle to move. If the cradle is positioned between 0 mm and 750 mm, releasing the egress handle will cause the cradle to decelerate and move slowly to the home position. If the cradle is positioned beyond 750 mm, releasing the egress handle will cause the cradle to decelerate and stop.
  3. Make sure the cradle is locked in place at the home position.
  4. Press the cradle in button on the control panel and position the cradle approximately 2500 mm (100 inches) into the bore.
  5. Pull up the cradle release handle and hold it. The table will start to move automatically. Continue to hold the handle and walk with the table until it reaches the home position.
  6. Make sure the cradle is locked in place at the home position.
Topic ID: task_p1k_4lh_53b

Fixed table

Procedure

  1. Press the cradle in button on the control panel and position the cradle approximately 500 mm (20 inches) into the bore.
  2. Pull up the cradle release handle and pull the cradle out to the home position.
  3. Make sure the cradle is locked in place at the home position.
  4. Pull up the cradle release handle and push the cradle back to the rigibelt drive to re-engage the cradle.
  5. Press the cradle in button on the control panel and position the cradle approximately 2500 mm (100 inches) into the bore.
  6. Pull up the cradle release handle and pull the cradle out to the home position.
    Note Make sure the rigibelt drive is not pulled with the cradle during this egress release check.
  7. Make sure the cradle is locked in place at the home position.
  8. Pull up the cradle release handle and push the cradle back to the rigibelt drive to re-engage the cradle.
