About this task

IMPORTANT: Make sure that the latest Service Pack is loaded. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library.

If more information is needed for how to load Service Packs, refer to Installing Software Updates.

For a new installation, you will need to know several system-specific options. The tables in Guided Install Site Configuration Options lists the information you will need to know about the site and the site’s hardware.

During the software load procedure, you will install the site’s service license (SSA) softkey. The license must be created in advance. See Service Licensing for information about creating the license.

Prepare for Software Load

Procedure

  1. Confirm that all the correct DVDs are available and ready to use.
  2. If you are installing on a new system, use the tables in Guided Install Site Configuration Options to identify the information you will need to have about the site and the site’s hardware.
  3. If you are installing or reinstalling on an existing system, write down all the IIP configuration data to speed up the InSite process. (It is not saved as part of the SaveInfo procedure.)

    The data can be accessed from the Common Service Desktop, by selecting Configuration > Guided Install > FE Mode > Service SW/InSite > Config InSite IIP. Click each IIP Configuration tab, and record the data. This data can be entered manually after the software application load.

  4. When the instructions say to insert a DVD, insert the DVD into the only DVD drive on the host computer.

Save Client Information (Existing System)

Procedure

  1. Notice
    During the installation of the new software, ALL prior files and images will be lost. Use these steps to backup and archive all images and files.
    Notice
    Installing this new software may result in the loss of use of any research software and hardware installed on the system. Contact GEHC Research Support for backup and restore instructions for research software and hardware.
    Insert a blank DVD.
  2. Perform a SaveInfo.

Load Linux Host OS Software

Procedure

  1. Insert the PC Linux Base Load DVD into the appropriate DVD drive of the host computer.
  2. Restart the host computer. The system boots from the DVD.
  3. From the HELiOS- or SUSE-based GEHCMR Operating System (MR OS) Install screen, select 1. GEHCMR – MR Auto Install and press Enter.

    The Welcome to HELiOS/SUSE for 86_64 screen displays.

    Note During the beginning of this process (checking dependencies, formatting disk drive, etc.), there are two active buttons in the lower right: ←Back and →Next . Do not select these buttons. Later in the process, these buttons are greyed out (inactive).

    The software load proceeds through some checks and then begins the OS load. No responses are required.

    A progress bar shows the percentage complete. This process takes about 15 or 20 minutes.

  4. When the software load is complete, a message appears stating that installation has completed successfully.

    The DVD drive automatically ejects. Remove the DVD.

  5. Select Reboot from the lower right of the screen.

    A progress bar displays during the reboot sequence.

Topic ID: id_SL12229843-1178755

Load MR Application Software

Procedure

  1. Click on Install
  2. After the system successfully reboots, the Welcome to MRHost screen displays. Log in using these parameters:

    • User ID: root

    • Password: operator

  3. At the prompt, insert the MR Application Software DVD into the appropriate DVD drive. Click OK.

    From the list called Select your locale, select the language used for the site. Click OK.

    A series of messages and a progress bar report the progress of the installation.

    The Guided Install screen appears.

  4. The prompt Do you want to load GI Configuration from DVD? appears.

    • (For existing systems) Select YES.

      Proceed to Load GI Configuration Information from SaveInfo DVD and Complete MR Application Software Load (Existing Systems).

    • (For new systems) Select NO.

      Proceed to Enter GI Configuration Information (New Systems).

Topic ID: id_SL12229859-1178755

Load GI Configuration Information from SaveInfo DVD and Complete MR Application Software Load (Existing Systems)

Procedure

  1. Remove the MR Applications DVD.
  2. Insert the SaveInfo DVD that you made in Save Client Information (Existing System). Click OK.

    When the data is loaded, the SaveInfo DVD is automatically ejected. Insert the MR Applications DVD, and click OK.

  3. From the Set Time/Date screen, select the local Time Zone. Set the local time by selecting Current Date/Time/Zone. Select the day of the week and month from the pull-down menu. Click Set Time/Date.
  4. After the configuration information is loaded, go to the Verification Tab to confirm that the data loaded correctly.
  5. If all entries pass verification, in Verification tab, click Install Software to begin the MR applications load.

    A prompt appears reminding you to configure the NTP server (if present) through the Network Info tab. It also reminds you to verify that the current time and time zone are configured properly on the Set Time/Date tab.

    If both are correct, select Confirm. If not, select Abort and configure the NTP server (if present) and the current time and time zone.

    A message appears at the bottom of the screen saying the application software load is in progress. The MR application load takes about 20–25 minutes.

    Note Work with the customer site to confirm that the NTP server time is correct. If the NTP server time is not correct, the SSA license becomes invalid.
  6. The Service License screen appears, where you install the site’s service license key (created previously). See Service Licensing.
    Note The Service License screen is displayed continuously when the user logs on as root.
  7. The Save/Restore screen appears.
  8. Remove the MRApps DVD from the drive. Insert the SaveInfo DVD.
  9. Select Restore Information and ALL (All is the default).

    A progress bar displays. This process takes about 10 minutes.

  10. Proceed to Load ICN Configuration.
Topic ID: id_SL12229864-1178755

Enter GI Configuration Information (New Systems)

Procedure

  1. Use the information that you collected in Guided Install Site Configuration Options to complete this section.
  2. Go to Preferences > HIPAA/Security and select the security option appropriate for the site per the customer. For more information about security options, refer to Security Levels.
    Note The HIPPA security screen is mandatory for PX26.0 and later systems. For PX26.0 and previous systems, the HIPPA screen is optional.
    Note “Typical Security Settings” is the recommended security level, unless the customer has system networked options such as FUS, BrainWave, CADStream, or other third party devices. In that case, select the option “Security settings for systems networked to certain optional devices”.
    Note For the DoD sites, SIGNATM Secure Advanced is the default selection. For the DoD sites or sites that choose the high security setting, the FE must change to a complex password for the root login. We also recommend that the customer changes their user password.
  3. Configure all tabs, and go to the Verification Tab to ensure that the data loaded correctly.
  4. Insert the MR Applications Software DVD.

    (For XW8400 PC) Insert the MRApps DVD in the top DVD drive.

    A progress bar shows the percentage complete. This process takes about 15 or 20 minutes.

    When the MR Application software is loaded, the DVD ejects.

  5. Proceed to Load ICN Configuration.
Topic ID: id_SL12230011-1178755

Load ICN Configuration

Procedure

  1. Insert the MR VRE Linux OS DVD.

    From the Guided Install interface left navigation menu, select ICN Configuration, click Configure ICN, and click OK.

    The VRE software load procedure takes about 20 minutes.

  2. When the ICN OS software load is complete, the DVD ejects.

    The ICN configuration starts and takes about 20 minutes to complete.

  3. Click OK in response to the prompt VRE Configured Successfully.
  4. Click OK in response to the prompt ICN Configured Successfully.

Install IRM Software

Procedure

  1. If the site has an In-Room Monitor (IRM), select IRM Installation and then click Install IRM Software.
  2. When the Information window confirms that the configuration is complete, click OK.

Load MR Operator Documentation

Procedure

  1. Load the operator manual. See Loading Operator Documentation.
  2. Click Accept in response to license agreement.

    A progress bar shows the percentage complete. This process takes about 5 minutes.

  3. Proceed to Finalization.
Topic ID: id_14975731

Finalization

Procedure

  1. IMPORTANT: Make sure that the latest Service Pack is loaded. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library. If more information is needed for how to load Service Packs, refer to Installing Software Updates.
  2. To install software using eLicensing, see Software Option Installation with eLicense Generated Keys.
  3. Right-click on the screen background and select Reboot. Restart the system and boot to applications as sdc.
    Note The initial boot on a new system can take up to 30 minutes.
  4. Load all applicable options. As part of the option load, go to Guided Install > Option Key screen, and click the Install Scantool button in the Scantool Optionkey Installation section.
  5. Do a check of the cyber security compliance. See Doing a check of the cyber security compliance.
  6. (For Software Upgrade) At the Common Service Desktop, select Calibrations > Installation and Calibration Wizard, ICW opens in upgrade mode.
    1. The left pane lists all tasks required to complete the upgrade.
    2. After the task is completed, click Check Status in the right pane. Completed tasks turn blue; failed tasks turn red.
