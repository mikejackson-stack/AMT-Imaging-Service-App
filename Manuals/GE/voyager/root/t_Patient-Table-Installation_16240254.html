Removal of Shipping Lock

Procedure

  1. Notice
    If Table is positioned without removing the Shipping Lock, you may scratch the bridge cover or bridge. There is a service tool box in the patient table package. The ‘Table gap check tool’ and ‘Relief value opening tool’ are in the box when initial delivered. The ‘Caster wheels’, ‘Support block of Caster wheels (4x)’ and ‘Screw Rod’ will be put in the box after table installation. Please safely keep it in customer site after installation.
    Remove the Shipping Lock just before the Table positioning.
  2. Restore two screws for the cover after the Shipping Lock removal.
    Note After removal of shipping lock, keep the cradle at Home position (backward limit) and do not push it forward until it’s finally installed. Otherwise, it may cause a problem of Table Up movement because Home sensor becomes unlatched.
  3. Remove the Cable Protection Plate just before the Table positioning per following steps.
    1. Cut two tie wraps which are fixing the cables on the protective plate.
    2. Remove two screws and remove cable protective plate.
      Note Keep the two screws which were on the lower base. These two screws will be used to connect the dock and table.
      Note It’s recommended to store the Cable Protection Plate at site for future use to protect the cables during Table Transportation.

Patient Table Installation

Procedure

  1. Warning
    FERROUS MATERIAL HAZARD!
    Table Control Box contains ferrous material A Little.
    HOLDING THIS ASSEMBLY TOO CLOSE TO THE MAGNET BORE WILL FORCIBLY ATTRACT IT TO THE MAGNET.
    Remove Table Control Box with bracket per following steps to install cables at Table down limit.
    1. Remove 5 screws shown in illustration below.
    2. Remove Table Control Box with bracket.
  2. Perform the following steps.
    1. Move the Table next to the dock structure.
    2. Check that the Table frame is attached and centered to the Dock Frame.

      For mobile site install:

    3. Loosen the six leveling pad locknuts.
    4. Rotate the leveling pad studs using 16mm spanner to raise the table base frame.
    5. Confirm that the height from the floor to the top of the weldment, just under the locking nut, is within 81+/-20 mm.
    6. Adjust the leveling pads until the tabletop is leveled (note the table will be in the lowered position, not the raised position).
    7. After leveling the patient table, confirm again that the height from the floor to the top of the weldment, just under the locking nut, is within 81+/-20 mm for all leveling feet.
    8. Lock the leveling pad lock nuts.
    9. Confirm that the table is parallel with the table bridge in the magnet bore. Use a laser sight line or other suitable device. Move the end of the table right or left until parallel.
    10. Install two anchor brackets 5756523 at the locations where the front caster brackets were installed (patient feet end of the table). Secure the patient table anchors to the floor using the same method for the dock frame described in Chapter 2 (M8 bolts/screws and washers).

      For fixed site install:

  3. Route coil cables (M1356~M1365) under the Magnet to DPP and connect cables.
  4. Connect coil cables (M1356~M1365) to DPP
    1. Loosen 8 captive screws.
    2. Flip the DPP RRx to access the bottom.
    3. Connect cables.
    4. Once all cables are connected, restore DPP RRx position.
  5. For LCC RD Magnet: Route and connect the 5 cables (M3341, M3386, M3387, M3345, and M3346) from Patient Table to PAC/SRI per following steps.
    1. Remove three rubber stoppers of Front LH Lower Cover.
    2. Remove three screws and washers to remove the Front LH Lower Cover.
    1. Route the following five cables as illustration below and connect them to SRI4 and PAC.

      • M3341: Touch and Go cable (To SRI4 J20)

      • M3386: PPG cable (To PAC J5/J6)

      • M3387: ECG Cable (To PAC I/O ECG)

      • M3345: Mic Cable Front (To SRI J31)

      • M3346: Mic Cable Rear (To SRI J32)

  6. For the IPM Magnet: Route and connect the 5 cables (M3341, M3386, M3387, M3345, and M3346) from Patient Table to PAC/SRI see below figure.
  7. From Step 7 to Step 12 is only for Mobile site installation Connect the following extension cables, apply Velcro wrap 2236130 to each connection, and route underneath the magnet towards the rear of the trailer:
    1. 5759635 connect to run M1357, and route to “DPP” 1-J1
    2. 5759635-2 connect to run M1358, and route to “DPP” 1-J2
    3. 5759635-3 connect to run M1360, and route to “DPP” 2-J1
    4. 5759635-4 connect to run M1361, and route to “DPP” 2-J2
    5. 5759635-5 connect to run M1364, and route to “DPP” 3-J1
    6. 5759635-6 connect to run M1365, and route to “DPP” 3-J2
    7. 5759638 connect to run M1356, and route to “DPP” 1-J3
    8. 5759638-2 connect to run M1359, and route to “DPP” 2-J3
    9. 5759638-3 connect to run M1362, and route to “DPP” 2-J4
    10. 5759638-4 connect to run M1363, and route to “DPP” 3-J3
  8. Connect cable run M3504 (5495369-2) to table IO control box J9 and route underneath the magnet towards the rear of the trailer.
  9. Install DPP holders 5495702 and 5495702-2 on DPP mounting plate 5755611, which will be installed in the trailer according to the trailer design, using supplied M6 screws. Note that there are left and right holders – hooks go towards the inside.
  10. Install RxDist using four supplied M6 screws.
  11. Install DPPs as shown in Figure 16.
  12. Perform the following connections:
    1. Extension cables to DPPs per mobile block diagram
    2. RxDist cables per block diagram
    3. Cables 5476777, 5476777-2 and 5476777-9 between RxDist and DPPs
    4. GE logo jumper cable 5759628 to run M3379 J60
    5. Run M3504 to RxDist J57
    6. Run M1335 RxDist J13 to DST preamp J11
    7. Run M1315 to RxDist J11
    8. BNC adapter 46-208990P1 and UTNS antenna 2355200-2 to run M1315 (coil up behind the magnet at the heat exchanger)
  13. Install the cables at Table IO, and then install the cables at Table Control Box shown below.

    Note
    Need confirm J11 and J12 are connected before 2018 Q3 installation. See J11 and J12 Connector. There is no J11 and J12 in table control box after Q3 of 2018.
  14. Restore Table Control Box with bracket with 5 screws.
  15. Remove the screw rod.
    Note

    The screw rod is a service component, it is NOT for lifting table during installation.

  16. Connect one of the Up/Down foot pedal cable to the connector to J1 of Table Control Box.
  17. Remove the caution labels from both side of Patient Table.
