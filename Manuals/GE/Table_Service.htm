🛏️ GE MRI Patient Table Service Guide
AMT Imaging Solutions — Field Service Quick Reference

Applies to: GE Signa Excite, HDxt, Discovery MR450/750, Optima 450w/750w patient table (patient positioning system). Covers error E112, TABLE-DOCK fault, table drive and docking issues.

Error E112 — Patient Table Fault

CheckAction
Table Position / DockingVerify table is fully docked to magnet bore interface. TABLE-DOCK fault indicates the table is not seated properly. Re-dock table: retract fully, then re-dock until positive engagement is felt/heard.
Table Limit SwitchesCheck table limit switches at docked and home positions. Run Table Diagnostics in MR Service Desktop → Diagnostics → System Function → Table → Table Position Test.
Table Drive MotorListen for motor operation when commanding table movement. No movement with motor sound = mechanical obstruction. No motor sound = electrical fault (motor, driver, or control board).
Table Power SupplyCheck DC power to table drive controller. Verify fuses on table control board. Check for tripped motor protection relay.
Table Cables and ConnectorsInspect table cable routing. On systems with in-bore cable chains, check for pinched or worn cables. Reseat all connectors at table junction box and system electronics cabinet.
Weight Limit / OverloadIf table fault occurs under heavy patient load, check weight limit setting. GE tables are typically rated 300–500 lbs (model specific). Verify patient weight does not exceed limit.

TABLE-DOCK Fault — Troubleshooting

SymptomLikely CauseFix
TABLE-DOCK fault, table will not dockDocking latch misaligned; dock sensor not activated; latch mechanism wornInspect dock latch alignment. Manually guide table into dock. Check dock sensor (proximity switch). Lubricate dock mechanism per PM schedule.
TABLE-DOCK fault after table locksDock sensor failed or misadjustedAdjust dock sensor position. Test sensor continuity. Replace sensor if faulty.
Table docks but won't go into boreTable drive fault after docking; in-bore position sensor issueRun in-bore drive diagnostics. Check in-bore motor and cable chain. Inspect position encoder.
Table moves but makes grinding/squealing noiseWorn drive belt, misaligned drive track, insufficient lubricationInspect table drive belt for wear or damage. Lubricate drive rail per PM. Replace belt if worn.
Table vertical motion failed (height adjustment)Vertical drive motor fault; hydraulic leak (hydraulic tables); vertical position sensorCheck vertical motor/drive. On hydraulic models, inspect for hydraulic fluid leak. Check vertical limit switches.
E112 recurring, table works mechanicallyIntermittent connection in table position feedback cableFlex table cable manually while monitoring table position in service desktop. Replace cable if intermittent fault identified.

Table Safety Systems

Always maintain control of patient table motion when a patient is on the table. Never leave a patient unattended during table movement. Verify all safety stops and limit switches are functional during PM.
Safety FeatureFunctionTest Method
Emergency StopHalts all table motion immediatelyCommand table movement; press emergency stop; verify table halts. Reset and confirm normal operation.
Weight Limit / Overload CutoffPrevents table movement if patient weight exceeds limitCheck weight limit setting in system configuration. Verify error is generated when simulated overload present.
In-Bore Limit SwitchPrevents table from going too far into bore and contacting gradient coilCommand table to maximum in-bore position. Verify table stops at correct limit. Do not override limit switches.
Out-of-Bore Limit SwitchPrevents table from retracting too far and falling off the endCommand table to full retract. Verify table stops at correct home position limit.
Dock SensorPrevents table from entering bore unless properly dockedAttempt to move table into bore without docking. System should refuse movement with TABLE-DOCK error.
Anti-Pinch / Obstruction SensorHalts movement if obstruction detected (model dependent)Place obstruction in table path during slow movement. Verify table stops and fault is generated.

Table PM Checklist

TaskIntervalNotes
Lubricate table drive rails and bearingsSemi-Annual / AnnualUse OEM-approved lubricant only. Non-magnetic lubricant is required for any parts near the bore opening.
Inspect drive belt tension and conditionAnnualCheck for cracking, fraying, or wear. Measure belt tension per service manual specification.
Test all limit switchesAnnualIn-bore, out-of-bore, dock sensor, vertical limit switches. Verify correct stopping at each limit.
Test emergency stop functionAnnualVerify stop button halts motion immediately on all axes
Inspect table cable chainAnnualCheck for worn or broken links, pinched cables. Flex through full travel range.
Clean and inspect dock mechanismAnnualClean dock latch. Inspect for wear. Lubricate per OEM spec.
Verify weight limit calibrationAnnualApply known weight and verify table operates or faults per spec
Inspect table top surface and padSemi-AnnualCheck for cracks or wear that could create patient safety risk. Replace worn pad.
Electrical safety testAnnualLeakage current test per IEC 60601 / facility requirements
Tip: The most common cause of TABLE-DOCK errors is a dock latch that needs lubrication or minor alignment adjustment. Before suspecting electronics, manually inspect the mechanical dock engagement — this fixes the majority of TABLE-DOCK calls without part replacement.
Tip: Use MR Service Desktop → Diagnostics → Table → Table Position to monitor table position in real time. This helps confirm whether the fault is mechanical (position reads wrong during motion) or electrical (position doesn't change at all).
