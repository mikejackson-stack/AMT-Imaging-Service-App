2  Overview

This procedure is needed after ICN Replacements. It may also be used when troubleshooting issues with the VRE system. Refer to the VRE Troubleshooting flowchart.

3  Preliminary Requirements

3.1  Safety

WARNING
ELECTROCUTION HAZARD!
DANGEROUS VOLTAGES ARE PRESENT THROUGH OUT THE SYSTEM CABINET WHEN POWER IS APPLIED.
REFER TO OSHA LOCKOUT TAGOUT REQUIREMENTS.

3.2  Required Conditions

ConditionReferenceEffectivity

A system restart is required after configuration for changes to take affect.

-

-

4  Procedure

NOTE:Reconfigure the ICN's only if absolutely necessary! If troubleshooting, run diagnostics. Do not reconfigure ICN's with failing ICN.

  1. Restart the system by right-clicking on the mouse and selecting [System Restart].

  1. When Login screen appears, login as root password operator. This should not be done with applications up. Select [Yes] to invoke Guided Install.

  1. Select [VRE Configuration] in the left-hand navigation sidebar. (See Illustration 1.)

    Illustration 1:  Guided Install - VRE Configuration

  1. Click [View VRE configuration file] to view the current output status of ICN's.

    Illustration 2:  View VRE Configuration File

  1. Click [Configure VRE Blades]. An information window automatically displays (see Illustration 3) requesting that you check that the hardware connections are secure. This is to ensure that the operating system (OS) will be properly installed onto the ICN's.

    1. Click [Continue] if connections are complete.

    1. Click [Abort] if the connections are not complete. Ensure that all hardware connections are secure to continue.

    Illustration 3:  Information Window

  1. A window displays asking the number of VRE blades to configure (see Illustration 4). Select the number of blades installed in the cabinet (1, 2, or 4). Click [Ok].

    Illustration 4:  VRE Blades Window

  1. The VRE configuration runs and progress details appear in a separate window. Review the window once the configuration is complete to see if the ICN passes or fails (see Illustration 5). If the ICN Reconfiguration fails, please review extended error messages for subsequent actions.

    Illustration 5:  VRE Progress Details

  1. Select [Ok] in the Information window (see Illustration 6) to reboot the system after a successful VRE configuration.

    Illustration 6:  Information Window

  1. Right click on desktop background and select [Service Tools] then [System Restart].

  1. Select [Yes] to confirm system restart. Computer will reboot.

  1. Login with:

    • Username: sdc

    • Password: adw2.0

5  Finalization

Perform a test scan to ensure the system is working properly.
