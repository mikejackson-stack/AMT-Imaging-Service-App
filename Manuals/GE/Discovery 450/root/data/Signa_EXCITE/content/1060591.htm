2  Overview

This procedure documents the set up and calibration of the system to a clinical hospital information system (HIS) or a radiology information system (RIS) .

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

Acquire HIS/RIS, filming network information from the customer administrator.

-

4  Procedure

4.1  Setup

  1. From the Common Service Desktop, select the [Configure] button, select the [Guided Install] button, and in FE Mode login as root (password is operator).

  1. Under [Connectivity], select [HIS/RIS].

    Illustration 1:  HIS/RIS Screen

  1. Enter applicable information in all fields (as provided by site) and click the [Configure] button.

  1. Under [MWL Configuration], select [MWL Config Details].

    Illustration 2:  MWL Config Details Screen

    Illustration 3:  MWL Config Details Screen (Continued)

  1. If any of fields, other than the defaults, are desired to appear in the Modality Worklist, select or deselect appropriately and click the [Configure] button.

  1. Under [MWL Configuration], select [Return Tag Configure].

    Illustration 4:  Return Tag Configuration Screen

  1. If any fields, other than the defaults, are desired by the site to be refreshed in the Modality Worklist, select or deselect appropriately and click the[Configure] button.

  1. Under [MWL Configuration], select [SCP Configure].

    Illustration 5:  SCP Configure Screen

  1. Click the [New] button to setup a new item.

  1. Enter applicable information in all fields (as provided by site) and click the [Configure] button.

  1. To verify network connectivity, click the [Ping] button.

  1. Under [MWL Configuration], select [Table Column Selection Configure].

    Illustration 6:  Table Column Selection Configuration Screen

  1. Select or deselect any fields desired to be displayed in the patient record table (located at the top of the scan window) and click the [Configure] button.

  1. Under [MWL Configuration], select [PPS Configure].

    NOTE:At release of this document, PPS Configure is available with 1.5T systems only. PPS Configure will be available for 3.0T at a later time.

    Illustration 7:  PPS Configure Screen

  1. Click the [New] button to setup a new setup.

  1. Enter applicable information in all fields (as provided by site) and click the [Configure] button.

4.2  Functional Check

  1. Click the [Work List] icon for the scan screen (see Illustration 8).

    Illustration 8:  Work List Icon

  1. To confirm the connectivity of the system to the RIS system, go into the scan desktop and select the [New Patient] icon (see Illustration 9).

    Illustration 9:  New Patient Icon

  1. On the scan screen enter the following:

    1. Patient ID:geservice

    1. Weight:111

  1. Click the [Save] button.

  1. In the Search/Refresh box, click the [Search Data] button (see Illustration 10).

    Illustration 10:  Search Button

    The Search Data window displays as shown in Illustration 11.

    Illustration 11:  Search Data Window

    From this page select how you want to pull information from the RIS system. The Get Patient List options are:

    1. Enter a patient Name, Patient ID, Accession Number, or Procedure ID to define the search.

    2. Selecting This System, which pulls the patient lists entered for this system.

    3. Selecting This Modality pulls the patient list for all MR systems at this facility.

    4. Selecting All Modalities pulls the patient list for all systems associated with this facility. Using this option may cause the scanner to hang if the facility has too large of Work List for all scanners at the site.

    5. Selecting Date Range pulls patient lists for any set day or date range.

  1. After entering the proper Search Data, click the [Search] button (see Illustration 12).

    Illustration 12:  Search Details Selected

  1. The results appear in the list above the patient information (see Illustration 13).

    Illustration 13:  Full Work List

4.3  Troubleshooting

  1. From the Common Service Desktop, select the [Guided Install] button, and in FE Mode login as root (see Illustration 14).

    Illustration 14:  Accessing HIS/RIS Setup

  1. Under [Connectivity] select [HIS/RIS] (see Illustration 15).

    Illustration 15:  HIS/RIS Setup Screen and Tabs

  1. Ensure that the Hospital Name, Suite ID, Host ID, and Local AE Title are correct for the MR system. The Local Port Number (Host Port) should be set to 4000 (same as the DICOM (Digital Imaging and Communications in Medicine) networking port number for MR systems). These are the parameters that the hospital RIS system uses to identify our system (see Illustration 15).

  1. Under [MWL Configuration], select [SCP Configuration] (see Illustration 16).

    Illustration 16:  SCP Configure Screen

    Ensure the following information with the site network administrator:

    • Host Name is the site name.

    • AE Title is the Modality Work List (MWL) Application Entity (AE) title of the RIS system of the site.

    • IP Address is the internet protocol (IP) address of the RIS server.

    • Port Number is the port number of the RIS system of the site.

  1. Under [Home], select [Verification] (see Illustration 17.

    Illustration 17:  Verification Screen

  1. Select [Configure] and confirm no errors.

  1. Select File>Quit.
