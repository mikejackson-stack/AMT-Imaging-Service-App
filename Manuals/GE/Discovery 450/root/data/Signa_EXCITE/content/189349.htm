2  Overview

The Excite 3.0T Multi Nuclear Spectroscopy (MNS) Kit includes a broadband Exciter, amplifier, cabling, TR switch, and service coil for 31P spectroscopy. Other MNS nuclei are supported by the kit, although separate TR switches, coils and phantoms will be necessary. Two broadband amplifiers are supported, a 4kW amplifier (CPC) and a floor-standing 8kW amplifier (AMT/Hurley). For each type of MNS installation or upgrade, this section includes the required steps for a successful installation/upgrade. 4  Procedure

4.1  System Power Shutdown

DANGER
FATAL ELECTRIC SHOCK HAZARD!
LETHAL VOLTAGES ARE PRESENT WITHIN THE PDU EVEN IF ALL PDU BREAKERS ARE OFF.
Disconnect and LOTO power from the system at the Main Disconnect for the facility.

NOTICE
Prior to powering down the entire Systems Cabinet, boot the Applications software down to the root level. The VRE System that resides in the Systems Cabinet can become corrupted if it loses power when the Applications software is active.

  • Right mouse click, select Service Tools, then System Restart.

  • Power down the Systems Cabinet when the login GUI displays.

 
 

  1. Ensure that power is disconnected from the PDU before proceeding.

  1. Notify all personnel working on the system that the system will be shut down.

  1. Shut down the system software before removing power.

  1. For a Phoenix PDU (in ACGD Cabinet with the plastic safety cover):

    1. Remove the cover from the front of the ACGD Cabinet.

    1. Open the plastic cover, and flip the Operator Workspace PC and Operator Workspace Host circuit breakers to their OFF position. (This allows control of their power up when this procedure is completed.)

    1. Rotate the larger main breaker labeled INPUT counterclockwise to the green, OFF (O) position.

    1. Apply LOTO to the PDU INPUT circuit breaker.

    1. Using a meter, test the input voltage between test inputs A-B, A-C and B-C; confirm the voltage between each is zero (0) VAC. Each test input is scaled down to 100:1 of the corresponding AC phase.

4.4  Installation of RF Detector Boards (ASC/MGD Chassis)

For upgrading from 4kW to 8kW, no additional boards need to be added. For both the 4kW and 8kW MNS installation, the following supplemental circuit boards need to be installed:

  • Two RF Detector Boards

  • One BB Amp I/F Board

  • One Exciter Board

  1. Ensure that all LOTO procedures were followed. Double check that the Accessories Cabinet breakers are OFF.

  1. Remove the RF Detector Boards (5250034 or equivalent) and BB Amp I/F Board from their packing material.

  1. At the front of the Accessories Cabinet, locate Slots 10 and 13 of the UPM Chassis.

    1. Insert one RF Detector Board into each slot. (See Illustration 7.)

    1. Locate Slot 6 in the UPM Chassis, and insert the BB Amp I/F Board. (See Illustration 7.)

    Illustration 7:  RF Detector and BB Amp I/F Boards in Accessories Cabinet

  1. Locate the cables labeled: Slot 10 Jx and Slot 13 Jx (where x = 1-5). Attach them to their respective connections on the two RF Detector Boards, and run them to the IO Panel J102-105 connections.

  1. Add the 50-ohm Terminators (2329754 or equivalent) to all empty J numbers on the RF Detector Boards. (See Illustration 7.

  1. Locate Cable 5113183-4 labeled: BB Amp I/F Board J3 and attach to Driver Module J13.

  1. Locate Cable 5115644 labeled: BB Amp I/F Board J5 and attach to IO Panel J123.

  1. Turn ON the Accessories Cabinet breaker.

4.8  MNS T/R Switch Installation on LPCA

NOTE:The MNS T/R Module should be removed from the system when Spectroscopy scanning is completed. The presence of the module may cause IQ degradation.

  1. The LPCA and all cables should have been installed and connected at the time the system was installed. Refer to the Mechanical Installation Manual, Section 6-3-9-E to ensure this was done properly.

  1. Move the LPCA to a position where it can be easily accessed, either the front or rear of the magnet.

  1. Remove the MNS TR Switch from its packing material.

  1. Position the MNS TR Switch so that the square opening and two cables are facing the front of the magnet.

  1. Slide the MNS TR Switch onto the two brackets on top of the LPCA as shown in Illustration 10.

    Illustration 10:  Carriage Assembly Run to Rear of Magnet

  1. Attach the cables of the MNS TR Switch to the LPCA. (See Illustration 10.)

4.9  Restoring System Power

  1. Notify all personnel working on the system that the system will be powered up.

  1. Remove the cover from the front of the Gradient Cabinet.

  1. Remove LOTO.

  1. Open the plastic door over the front of the PDU breakers, and switch ON the appropriate subsystem breakers.

  1. Flip any individual circuit breakers that are turned off to the ON position.

4.10  Spectroscopy Software Installation

  1. From the Common Service Desktop, click [Configuration] => [Guided Install] => [FE mode], and start Guided Install.

  1. Type: root with the default Password: operator.

  1. After the Guided Install window opens, select the Option Key tab.

  1. If the option key is not downloaded from eLicense, insert the option key into the floppy or CD drive (depending on the media being used).

  1. Select the matching Floppy, eFloppy or eCD box in the Install Option Key portion of the window, then select Install.

  1. When the installation process is complete, either load the next floppy or when all options are loaded, select File => Quit to exit the Guided Install tool.

    NOTE:Most options are now loaded via eLicense. The MNS keys can be downloaded directly from the eLicense web page or loaded onto a floppy or CD from this site. In this case, only one floppy/CD is used, not multiple media as Step 6 above states.

  1. Remove the front panel of the computer, and place the MNS Option Rating Plate on the inside panel of the Computer Duplex front panel.

  1. Reboot the computer. The installation is now complete.

4.11  Configuration

NOTE:The MNS Option Key delivered with the Hydrogen-Only Spectroscopy Option (PROBE/SV) must be previously installed.

  1. At the Common Service Desktop Manager, click [Config] => [Guided Install] => [FE Mode] to launch the Guided Install GUI.

  1. On the Hardware Configuration screen (shown in Illustration 11), select AMT for the 8kW amplifier and CPC for the 4 kW amplifier.

    Illustration 11:  Hardware Configuration Screen

  1. Verify other 3.0T settings are correct for the system.

  1. Modify and save if necessary.

4.12  Verify Configuration Settings

  1. At the Common Service Desktop, select [Tools] => [Utilities].

  1. Select [Start] to display the MR Config File Manager shown in Illustration 12. Locate and change the following parameters:

    1. Spectroscopy RF Amplifier = yes to configure the MNS RF Amplifier to ready.

      Illustration 12:  MR Configuration File

    1. Broadband Transceiver = yes to configure the MNS Broadband Transceiver (frequency change).

    1. Power Monitor Type = 4 to configure a 3.0T 12.x site with MNS.

    1. 3.0T Spectro RF AMP AMT Type = 0 and CPC =1.

    1. Click [Save Changes] to store all changes. ([Discard Changes] can be clicked to abort the changes.)

  1. Select [Quit] to close the Configuration File Manager.

  1. Reboot the system to save the file changes.

5  Finalization

  1. Perform the Universal Power Monitor - MNS setup and calibration.

  1. Perform 2kW 1.5T, 4kW and 8kW 3.0T MNS Amplifier Calibration, a must for 4kW (CPC) and the 8kW (AMT) amplifiers.

  1. Perform Multi Nuclear Spectroscopy (MNS) Functional Checks.
