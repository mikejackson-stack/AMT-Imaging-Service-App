Fidelity Test

1  Diagnostic Link

Diagnostics >> Peripherals >> Gradient Diagnostics

2  Purpose

The Gradient Fidelity Tests are designed to verify the accuracy, stability, and symmetry of the gradient amplifier outputs. Performing this test isolates any failures to the gradient subsystem.

In TwinSpeed systems, the user can run this test with the GP connected to the Whole body coils, the Zoom coils, or on both coils sequentially. Only the gradient cabinet and gradient coil are used in the test.

3  Components Tested

This test exercises only the gradient subsystem. This includes all of the gradient hardware inside the gradient cabinet. It also includes the gradient coil and everything in the transmission circuit between the gradient cabinet and the gradient coil.

The gradient fiber optic cables (X, Y, Z, CLK) are not used or tested.

The system uses the CAN Link to initiate the Gradient Processor Module to start the test. The Gradient Processor Module (GP) then uses data stored in onboard read-only memory to generate the test waveforms. These are sent to the gradient amplifiers to pulse the gradient coil through the transmission circuit.

On TwinSpeed systems, the user can run this test with the gradient electronics connected to the Whole body coils or Zoom coils, or on both coils sequentially.

4  Requirements

CAN Link must be functional. To verify CAN Link see CAN Link Diagnostic.

5  Block Diagram

6  Test Sequence

NOTE:The GP checks for corrupted clock before running this test. The test gets aborted if it finds a corrupted clock and logs an error message.

A ramp-sampled EPI readout waveform is generated on each axis, separately, for 100 shots with 64 views in each shot. Data is acquired, and the following tests are performed.

  1. Accuracy - Across all 100 shots, the largest point of inaccuracy is recorded, in units of microampere-seconds.

  2. Shot to Shot Stability - Each of the 100 shots is compared to the others. The largest difference between any two shots is recorded, in units of microampere-seconds.

  3. View to View Stability - Each of the 100 x 64 views is compared to the others. The largest difference between any two views is recorded, in units of microampere-seconds.

  4. EPI Plus/minus Symmetry - Each view represented by a positive half-cycle is compared to the subsequent view represented by a negative half-cycle.

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.
