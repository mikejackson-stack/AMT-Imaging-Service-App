Magnet Enclosure Button Test

1  Diagnostic Link

Diagnostics >> System Function >> Patient Handling >> SRI Functional Tests

Diagnostics >> Hardware Location >> Magnet Room >> SRI Functional Tests

Illustration 1:  SRI Functional Tests Screen

2  Purpose

This test verifies the proper operation of the Operator Control Panel buttons on the front of the magnet enclosure.

NOTE:Possible equipment shutdown. Do not press the [Emergency Stop] buttons on the Display Panel during this test. The [Emergency Stop] buttons are not disabled during the test, and will shut down all cabinets that provide power to the magnet room.

3  Components Tested

  • Magnet Enclosure Operator Control Buttons Codes

  • In-Room Monitor Operator Control Buttons Codes

4  Requirements

None

5  Test Sequence

CAUTION
Possible Equipment Shutdown
Do not press Emergency Stop buttons on the Display Panel during this test.
The Emergency Stop buttons are not disabled during the test. Pressing the top, outer Emergency Stop buttons (Illustration 2 and Illustration 4) will shut down all cabinets that provide power to the magnet room.

5.1  Version without In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button and verify the code displayed on the Longitudinal Position (right) display corresponds to the button numbers shown in Illustration 2. The Scan Time Remaining (left) display increments as you press each button.

    Illustration 2:  Buttons/Display Codes without In-Room Monitor

    NOTE:[Landmark] and [Align On] button codes are different. The [Landmark] and [Align On] buttons on the Left Operator Control are on a different circuit than the corresponding buttons on the Right Operator Control. The Longitudinal Position display shows a different number code, depending on whether the button is on the left or right.

5.2  Version with In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button and verify that the display on the Host Computer within the Service Browser corresponds to the button descriptions (see Illustration 3).

    NOTE:The three long buttons surrounding the elliptical operator do not display a response on the host computer when pressed.

6  Expected Results

6.1  Version without In-Room Display

When this test is performed, the alternate functions replace those that are normally executed when the buttons are pressed. Instead, each button has a corresponding number assigned to it. The corresponding number is displayed on the Longitudinal Position (right) display when the button is pressed.

NOTE:[Landmark] and [Align On] button codes are different. The [Landmark] and [Align On] buttons on the Left Operator Control are on a different circuit than the corresponding buttons on the Right Operator Control. The Longitudinal Position display shows a different number code, depending on whether the button is on the left or right.

The Scan Time Remaining (left) display increments as buttons are press, providing a means of verifying operation of the switch debounce function. Proper operation of a switch debounce function is indicated when the Scan Time Remaining display increments one count each time the button is pressed and released.

There are two failure modes for the button test:

  • Open Switch failure - displays no code when the button is pressed.

  • Shorted Switch failure - displays an incorrect code when the button is pressed. The displayed code indicates which switch is shorted. For example, if you press [Start Scan] and the displayed code is 02, the [Lights On] switch is shorted.

6.2  Version with In-Room Display

When this test is performed, each button's description displays on the Host PC within the Service Browser.

NOTE:Possible equipment shutdown. Do not press the Emergency Stop buttons on the Display Panel during this test. The Emergency Stop buttons are not disabled during the test and will shut down all cabinets that provide power to the magnet room.
