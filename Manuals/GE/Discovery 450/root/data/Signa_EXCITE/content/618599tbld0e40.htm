Table 1:  VRE Diagnostics Summary

DiagnosticPurposeWhen to Use
Host-ICN Ethernet Path DiagnosticConfirms that the host can contact each ICN via Ethernet.After installing new ICNs or anytime ICN failure seems to be causing TPS reset failure.
Host-ICN Ethernet Stress DiagnosticPerforms a large data transfer from host to each ICN and confirms data integrity. If an intermittent ethernet issue between the host and ICNs is suspected.
Host-ICN IPMI Ethernet DiagnosticConfirms ICNs can be remotely controlled from the host.If an ICN does not power on/off correctly.
ICN CPU Stress DiagnosticPerforms a one-minute stress test on the CPU.If an ICN is intermittently locking up.
ICN Process Verification DiagnosticConfirms all key processes are running on each ICN.If a software issue is suspected.
ICN Remote Shell TestConfirms OS is running on each ICN.When software/OS load issue is suspected, but Ethernet is working.
ICN Time Sync DiagnosticConfirms time is properly synchronized between ICN and system.
  • Errors in the log relating to scan
  • Command arriving before stop command
  • Not being able to scan
ICN Reconstruction DiagnosticFunctionally tests each ICN’s capability of performing image reconstruction. In doing so, each ICN will have its components tested, i.e. memory, processors, hard disk, software, etc.This test takes a set of raw data previously collected, and reconstructs the whole set several times, verifying image integrity by performing Checksums on the images and validating them against saved Checksum values.
ICN Hard Disk Health DiagnosticVerifies the Self-Monitoring Analysis and Reporting Technology (SMART) health status for both hard disks on an ICN. SMART refers to the system present on the ICN hard drives, and contains information about hard drive parameters, which can be used to predict failures.Anytime ICN failure seems to be causing TPS reset failure or If an ICN is intermittently locking up.
ICN Memory Stress DiagnosticStresses the memory on the ICN. While designed to stress the memory, this diagnostic also makes heavy use of the DMA, main disk drive, and motherboard of the respective ICN.Anytime ICN failure seems to be causing TPS reset failure or If an ICN is intermittently locking up.
