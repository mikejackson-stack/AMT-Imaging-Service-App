Capturing Screen Shots Using GIMP

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. To start GIMP, open a C-shell, type gimp at the prompt and press <Enter>. If GIMP is not configured on the Host PC, follow the screen prompts to configure.

    (Step Details)

  1. To capture a screen shot, move the GIMP windows if they are blocking any portion of the proposed shot.

  1. (For  Pre DV Apps) (For DV Apps) From The GIMP File menu, select Acquireor create, then Screen Shot. (Both screens are shown below.)

    Illustration 4:  GIMP File Menu for Pre DV Apps

    Illustration 5:  GIMP File Menu for DV Apps

  1. When the Screen Shot dialog box displays, select desired preference and click [OK].

    Illustration 6:  GIMP Screen Shot Window for Pre DV Apps

    Illustration 7:  GIMP Screenshot Window for DV Apps

  1. Click on the screen or window to capture. The screen shot displays in a new GIMP window.

  1. To save the file, select Save As from the File menu.

  1. In the Save Image window, name the file, select a file extension, then the directory where the file should be saved.
