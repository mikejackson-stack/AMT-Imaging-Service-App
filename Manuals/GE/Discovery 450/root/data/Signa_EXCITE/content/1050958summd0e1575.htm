After taking all 24 slices, the finished map displays on the field map screen. (See Illustration 15.) ShimTool automatically assigns a sequential alphabetic name to both the displayed map and the .map file it creates. The filename consists of:

  • Magnet series and number information entered on the Register Magnet Type screen shown in Illustration 6: W0 + 0009 becomes W00009; WB + 0002 becomes WB0002.

  • A sequential alphabetic character: A, B, ... C becomes 0000A, 0000B, ... 0000C.

  • Test cell entered on the Register Magnet Type screen: Always use test cell W when shimming at a customer site.
