HP9300 Computer Replacement

(Click Here to Return to Detailed Procedure)

  Safety

WARNING
Electrocution Hazard!
Hazardous voltages exist in the goc when energized.
before beginning any work, shut down software if still running. Lockout/Tagout power to the GOC before Continuing.

NOTICE
The system options are keyed to the Host ID on the Ethernet card. A Load-from-Cold is required to transfer the options to the new Host computer. Update eLicense with the new Host ID.
 
 

1  Procedure

  1. Shutdown system applications if still running. Lockout/Tagout power to the GOC before continuing.

  1. Remove the four screws in the rear that secure the left side panel, and the three screws that secure the right side panel. See Illustration 1.

    (Step Details)

  1. Remove the left and right side panel by sliding it back.

  1. Loosen the four screws that secure the back panel. These screws do not need to be removed to take off the rear panel.

  1. Remove all of the cables that are connected to the computer. Verify that they are properly labeled.

    (Step Details)

  1. Remove the 2 blue straps that secure the PC to the GOC. See Illustration 3.

    (Step Details)

  1. Remove the Hard Disk drives from the defective PC and install in the new PC (Hard Drive Replacement Procedure). Take the hard drive from the new PC and install it in defective PC.

NOTICE
The system options are keyed to the Host ID on the Ethernet card. A Load-from-Cold is required to transfer the options to the new Host computer. Update, eLicense with the new Host ID.
 
 

NOTICE
The computer weighs 50 pounds. Two persons must be used when moving the PC Cabinet.
 
 

  1. Carefully remove the PC from the GOC.

  1. Install the new PC by performing the steps above in reverse order.

  1. Perform a complete load-from-cold on the operating system and application software.

2  Finalization

  1. Restore power to the GOC. Boot software and ensure proper system operation.

  1. Repackage defective PC for return.
