1  Prerequisite Information for Proprietary (GE Contracted) Operation

To configure the Magmon3 for modem or network connectivity, the user must obtain information from the customer’s Network System Administrator. This section details the type of information required based on connectivity type and system type. Make sure to start this information-gathering process at least three weeks in advance of the physical installation.

1.1  Modem

1.1.1  For Non-HFO Systems

Non-HFO systems require the following:

  • Dial-Out Prefix: Obtain from customer (required for InSite2 dial-out).

  • Site Modem Phone Number: Obtain from customer (used only for phone line testing).

  • Proxy IP Address: Preassigned and in Service Docs (reference link).

  • Proxy Port Number: Preassigned and in Service Docs (reference link).

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

1.1.2  For HFO Systems

HFO systems require the following:

  • Dial-Out Prefix: Obtain from customer (required for InSite2 dial-out).

  • Site Modem Phone Number: Obtain from customer (used only for phone line testing).

  • Proxy IP Address: Preassigned and in Service Docs (reference link).

  • Proxy Port Number: Preassigned and in Service Docs (reference link).

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Type (Required): HFO.

  • Compressor Type (Required): Sumitomo.

Network cable connection from Magmon3 J5 to OW – Host LAN Hub J7 and network configuration required for communication to host for coldhead switching. Must use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer IT person.

  • Subnet Address: Obtain from customer's IT person.

  • Gateway Address: Obtain from customer's IT person.

  • Domain Name Server (DNS): Obtain from customer's IT person.

1.2  Broadband

1.2.1  For Non-HFO Systems

Network cable connection from Magmon3 J5 to Customer's network drop is required.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

Use Dynamic Host Configuration Protocol (DHCP) if available. Obtain from customer's IT person. If DHCP not available, use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer IT person.

  • Subnet Address: Obtain from customer's IT person.

  • Gateway Address: Obtain from customer's IT person.

  • Domain Name Server (DNS): Obtain from customer's IT person.

If required by the customer, use Hypertext Transfer Protocol (HTTP) Proxy:

  • Proxy Name or IP Address: Obtain from customer's IT person.

  • Proxy Port Number: Obtain from customer's IT person.

  • Account User Name: Obtain from customer's IT person.

  • Account Password: Obtain from customer's IT person.

1.2.2  For HFO Systems

Network cable connection from Magmon3 J5 to customer's network drop is required.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Type (Required): HFO.

  • Compressor Type (Required): Sumitomo.

DHCP is not used because of the Coldhead cycling hardware and the communication requirement with the Host. Must use the following:

  • Static Internet Protocol (IP) Address: Obtain from customer's IT person.

  • Subnet Address: Obtain from customer's IT person.

  • Gateway Address: Obtain from customer's IT person.

  • Domain Name Server (DNS): Obtain from customer's IT person.

If required by the customer, use Hypertext Transfer Protocol (HTTP) Proxy:

  • Proxy Name or IP Address: Obtain from customer's IT person.

  • Proxy Port Number: Obtain from customer's IT person.

  • Account User Name: Obtain from customer's IT person.

  • Account Password: Obtain from customer's IT person.

1.3  Satellite Modem (Mobiles and Fixed Sites in Outlying Areas)

Network cable connection from Magmon3 J5 to customer's network drop is required.

  • System Cryogen ID: Assigned by GE Service.

  • Magnet Types (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

Use Dynamic Host Configuration Protocol (DHCP). Obtain from customer's IT person.

NOTE:HFO Systems are not supported with this configuration at this time.

2  Laptop Port Driver Issue

Problem: Service laptop fails to communicate with magnet monitoring devices when using the Serial Null Modem Method. There is an incompatibility issue between the laptop communication port drivers and the laptop hardware. Two versions of laptop core load software have communication port drivers that are incompatible with the Dell D600 and D610 laptops.

2.1  Check Laptop Software Load Version

To check the software version loaded on your laptop:

  1. Right-click [My Computer] on the desktop.

  2. Select [Properties] from the menu.

    The System Properties window will open, defaulted to the General tab. Near the bottom of the tab is the version of laptop release software on the laptop (Example: Windows XP X-image 2005Q1).

  3. If your laptop version is either Windows XP X-image 2005Q1 or Windows XP X-image 2005Q2, proceed to the Dell website to update your chipset drivers.

2.2  Dell Website Steps to Download/Update Chipset Drivers

Proceed as follows to download the chipset drivers for your laptop:

  1. Open an Internet Explorer window and type http://www.dell.com in the Address line.

  2. Place your cursor over the [Notebooks] icon in the middle left of the page, a menu will come up; click Medium & Large Business.

  3. Select the Support tab.

  4. In the Choose a Support Option area, click [Drivers and Downloads] under Option 1: Most Popular Selections.

  5. Choose Option 2: Select a Product. Use the Laptop Type drop-down menu to select [Latitude] and the Model Type, either [D600] or [D610]. Click [Go].

  6. Choose your Operating System on this page. Use the drop-down menu to select [Microsoft Windows XP], and click [Find Downloads].

  7. In the Choose a Device for Download area, click [Chipset] > [Intel Mobile Chipset].

  8. Click [Download Now] and download the R114079.exe file to your laptop.

  9. Run the R114079.exe file on your laptop, following the directions. Reboot your laptop, and your COM1 port should be fully functional for use with any of the GE Magnet Monitoring devices for Serial Link Null modem connections.

    NOTE:Installing R114079.exe should fix the communication problem, but it will not update the laptop version shown at the bottom of the General tab in the System Properties window. If necessary for future reference, note that the new driver is installed.
