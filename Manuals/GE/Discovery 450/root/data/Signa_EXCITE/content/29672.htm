Geometry Verification

This section contains a series of tests that allow determination of the proper x-y-z-gradient. Specific symptoms of this type of problem are images that display upside down, left-right reversed, offset scans that move in the opposite directions from those annotated on the images, or some combination of all of these problems. Run this series of tests in the order described to prevent confusing results. Once the correct polarities are established, the Signa system will make properly oriented head and body scans with any imaging database.

Two Steps are required to insure proper gradient polarity

  • Verify System Configuration File Entries Are Accurate

  • Scan The System and Verify Gradient Polarities
