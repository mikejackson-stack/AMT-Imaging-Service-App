Table 1:  Field Action for Failed ICN Diagnostic

FaultProblem DescriptionGE Field Action
FailedThe ICN failed the diagnostic.
  • Verify the failed ICN has power and is running the OS.
    NOTE:The ICN is identified by its MAC Address label on the back of the ICN for 5127452 and at the front for 5127452-3.

  • Verify the Ethernet port lights are on for the ICN motherboard (two Ethernet ports furthest right on the back of ICN).
  • Verify Host to ICN network connectivity for the motherboard Ethernet port(s)--at least one of the Ethernet ports furthest right on the back of the ICN.
    1. This may involve swapping either the ICN Ethernet to switch cable (or moving it to a different switch port), or
    2. Swapping the Host eth1 to switch cable (or moving it to a different port).
      NOTE:If the Host eth1 port or cable is bad, there will be several diagnostic failures as the entire MGD subnet will be offline. If the ICN Ethernet port/cables are bad, then all of the tests for that ICN may fail (except the IPMI test, which has a separate Ethernet cable).

      Run the following Ethernet diagnostics to verify connectivity:
      • Host-ICN Ethernet Path
      • ICN Remote Shell
        NOTE:Current product configuration has redundant motherboard Ethernet connections for each ICN.
