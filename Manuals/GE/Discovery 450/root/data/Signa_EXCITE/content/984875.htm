Configuration Setup

1  Set Time and Date

The Set Time/Date page allows the setting of the internal time and date for the Magmon. This process must be done via a laptop connection, and cannot be done remotely. The internal time and date are used to timestamp the Minute Data and the Event Log items. The time zone setting is required to synchronize the MagMon3’s time to the back office time.

NOTE:The Magmon3 does not automatically change settings when daylight savings time goes into effect.

SeeIllustration 1 for details on the following steps.

  1. Set the Date, Time, Month, Year, Hour, and Minutes by clicking on each drop-down menu and making a selection.

  2. Set the Time Zone by selecting the time zone for your area from the drop-down menu. For example, if in Germany, select: GMT +1.

Illustration 1:  Set Time and Date

2  Magnet Type

The Magnet Type page configures the Magmon3 to one of the predefined magnet types. The number of sensors, type of compressors, and alarm parameters will vary between magnet model types, so the magnet type selection is a key element in the operation of the magnet and magnet monitor.

NOTICE
The Magnet Type must be configured by a GE-authorized Field Engineer before performing an InSite Checkout. RB magnets must be configured as LCC-RB, not LCC.
 
 

  1. Select the magnet type from the drop-down menu that most closely matches the system type that the Magmon3 will be monitoring. If not sure about what magnet type to select, contact the Magnet Support Team and your regional On Line Center.

    Illustration 2:  Magnet Type

  2. Select the proper compressor type from the menu shown above. Compressor 2 type should only be used when two compressors are connected to the same magnet.

  3. Click [Submit System Type] after identifying the magnet type.

3  Controls

The Controls page allows the setting of several miscellaneous items.

Display Units: Displays water flow and temperature in metric (default) or nonmetric.

He Pressure Control: Heater on/off control points for He Pressure control in the magnet’s helium vessel.

  • Default for LCC systems: 4.1 psi (Heater OFF Pressure) and 3.9 psi (Heater ON Pressure).

  • Default for HFO systems: 0.9 psi (Heater OFF Pressure) and 1.1 psi (Heater ON Pressure).

Abnormal Insite Call-in Interval: Controls how often the Magmon3 calls into the back office when in the alarm mode.

0.7T HFO = 30 minutes, LCC / LCC-RB / LCC300 = 1 hour, All other magnets = 2 hours.

Compressor Type: This selection (shown in Illustration 2) configures the software for correctly interpreting the logic of the compressor status signals.

  • The choices are: None, Sumitomo Water-Cooled or HC-10, Sumitomo Air-Cooled, Leybold or Balzers.

  • Failure to configure this correctly will result in the Magmon3 being in constant alarm.

4  System Identification

NOTICE
Each of the three GE databases has unique guidelines for how information is entered, so it is important to understand which database is used to provide appropriate customer support.
 
 

The System Identification page (Illustration 4shows an example) allows the user to configure all site identification information. The fields on this page uniquely identify the system when Magmon3 registers with the back office. It is important to enter the correct System ID, or the back office will not be able to match the System ID to the one assigned to the customer in one of GE’s three databases. These are the three GE databases:

  • CAPS database is used by Japan.

  • CARES database is used by the Americas, Australia, New Zealand, and the rest of Asia.

  • MUST database is used by Europe, the Middle East, and Africa.

    Illustration 4:  System Identification

NOTICE
All information must be completed on the Systems Identification page before an InSite Checkout can be performed.
 
 

  1. Enter the System ID, which will be the Cryogen ID for the MRI system.

    NOTE:The Cryogen ID guideline for a Magmon3 site will differ depending on the database as explained below.

    • For Magmon3 sites in the CARES database (for Australia, New Zealand and the rest of Asia), add the suffix MM3 to the end of the Primary System ID. Example: Primary System ID in CARES Database is 0910274017 + MM3 = Cryogen ID: 0910274017MM3.

    • The CAPS database in Japan does not use a System/Cryogen ID. The Online Engineer in Japan utilizes a System ID tool to assign a System/Cryogen ID for the Magmon device, which is then maintained in the VOLC database. Important: Contact the Online Engineer in Japan to have a System/Cryogen ID assigned.

    • For Magmon3 sites in the MUST database, add the suffix SMM3 to the end of the Primary System ID. Example: Primary System ID in MUST Database is 00192MRS01 + SMM3 = Cryogen ID: 00192MRS01SMM3.

  2. Enter the Magnet Serial Number.

    • (For all GE Florence magnets) The magnet serial number is located on the rear end flange of the magnet.

    • (For 7.0T GE Oxford magnets) The magnet serial number is located just above the vacuum pump-out port.

  3. Enter the Hospital (or Clinic) Name.

  4. Enter the Hospital (or Clinic) Room Name. (The customer designates this name. Example: MR Scanner #3.

  5. Enter the name of the MAC Team Leader. (If not sure who the MAC Team Leader is, contact your Regional On Line Center for assistance.)

  6. Enter the FE Name / Phone Number. (This will be the primary Field Engineer assigned to the site.)

  7. Click [Submit System ID] when all fields are completed.

6  Ethernet Interface

The Configure Network IP page configures the Ethernet interface of the Magmon3. The Magmon3 is designed to connect directly to the Internet without the need for a Virtual Private Network (VPN). In most cases, a Hospital Network Administrator will have to be consulted to obtain the correct settings. Refer to Insite2 Information Packet for Network Administrators in the Appendix of this manual. This document is useful in helping the customer’s network administrator understand the connectivity with GE equipment and how InSite 2.0 operates.

  • Magmon3 cannot be logged into remotely. The InSite 2.0 agent loaded on the device is designed to initiate the contact with the back office server. When in Idle Mode, it cannot be pinged by other devices on the network. To directly connect to the unit, the user must be on site and have physical access to the unit to place it into Web Mode, which is password protected. The unit will remain in Web Mode for 45 minutes, allowing the user to directly connect a laptop to it for configuration purposes before breaking the connection.

  • Before beginning, make sure to complete the Prerequisite Information Sheet located in the Appendix of this manual. It will be necessary to contact the customer’s Network Administrator to obtain the Static IP (otherwise known as Fixed IP) information, or confirm that DHCP is used at this facility. If DNS and or Proxy servers are used at this site, information and addresses should be obtained at this time for DNS and Proxy Server configuration.

NOTICE
For European sites using an InSite1 Broadband solution, refer to Section 6 of the Appendix for proper site configuration.
 
 

CAUTION
If the network configuration for the site requires a Subnet Mask address, it must be entered in a specific way.
For Magmon3 devices operating with revision 1.41 through 1.54 software, the user must enter the Subnet Mask string with 3 digits in each octet. For example: 255.255.000.000 (NOT 255.255.0.0.).
Failure to enter the Subnet Mask string in this manner will result in a communication failure with the Back Office. This issue is corrected in software revision 1.55, and the additional zeros are not required.

6.2.1  No Network Connection When Not in Web Mode

Check this box if a modem is to be used, or no Internet connection is available at the site. If the No network connection when not in Web Mode box is selected:

6.2.2  IP Address Assigned by DHCP Server

Dynamic Host Configuration Protocol (DHCP) is a protocol for assigning Dynamic IP addresses to devices on a network. With dynamic addressing, a device can have a different IP address every time it connects to the network. In some systems, the device's IP address can even change while it is still connected. DHCP also supports a mix of Static (otherwise known as fixed) and Dynamic IP addresses.

DHCP allows Magmon3 to auto-configure its IP settings by negotiating with a DHCP server on the local network. If the local network does not have a DHCP server, the Magmon3 must be configured with Static IP addresses.

If the IP Address assigned by DHCP server check box is selected:

  • Go to the DNS Configuration section of the page (Illustration 7).

  • The No network connection when not in Web Mode and the Static IP Address check boxes will be blanked.

6.2.3  Static IP Address

If DHCP is not used, the Network Administrator will provide a Static IP address, Subnet Mask, and a Gateway Address. (A Gateway may not be necessary. It is node on a network that serves as an entrance to another network. In enterprises, the Gateway is the computer that routes the traffic from a workstation to the outside network serving the Web pages.

  1. Select the Static IP Address box.

  2. Enter the Static IP Address information provided by the Network Administrator.

    NOTE:When the Static IP Address box is selected, the No network connection when not in Web Mode and IP address assigned by DHCP Server check boxes will be blank.

6.3  DNS Configuration

DNS Addresses Assigned by DHCP

Domain Name Server (DNS) is a protocol that allows the Magmon3 to translate URLs (such as www.ge.com) into IP Addresses.

  • If the local network does not provide access to a DNS server, which typically occurs through a proxy server, then all URL entries on the Insite2 Configuration page (accessed through the Insite 2 link shown in Illustration 7) must be entered as IP Addresses instead of URLs.

  • If DNS is not available at this site, call the On Line Center for the latest server IP Address. Avoid using the IP Address unless no other option is available to use DNS.

NOTICE
If DNS is not available and an IP Address is used: When the back office changes the Server IP address, the connection from the magnet monitor to the back office will be lost until the new IP address to the server is entered into the magnet monitor.

  • Protocol: Select HTTPS from the drop-down menu.

7.4  HTTP Proxy Server Configuration

A Proxy Server sits between a client application, such as a Web browser, and a “real” server computer. It intercepts all requests to the real server, checks to see whether it can fulfill the request. If not, it forwards the request to the real server.

The fields in this section are used for broadband sites only. The customer's network should have a single device that connects all the PCs in the building to the Internet. The Magmon3 communicates to the back-office (at the Online Center) over the Internet, so the Magmon3 must be provided with the IP address or URL of the Internet proxy device for the building network. The name or IP address of this device must be obtained from the customer’s network administrator. Some proxies require a Username and Password before they will allow a device to access the Internet. The network administrator must provide this data if required.

Proxy Server Parameters (FOR USE WITH MODEM ONLY)

  • Proxy: Box selected

  • Name/IP: 172.25.1.251

  • Port: 8002

  • Username: Leave blank.

  • Password: Leave blank.

7.5  Modem Parameters

These fields are only used for dial-up modem connections. If a broadband connection is not available, and a modem is the only option, these fields must be completed.

  • Phone Number: Insert the Online Center phone number (in the US, 877-834-4020). Call the Online Center for the number appropriate for your area.

  • User Name: Type I2-xxxx (Replace xxxx with your Cryo ID)

  • Password: Type insite2

  • Country/Region: Select from the drop-down menu; the next fields will auto-fill. Do not change the defaults unless instructed to by the Online Center.

    • Country/Region Code: Auto-filled when Country/Region is selected.

    • Modem Default Init String: Auto-filled when Country/Region is selected.

    • Dial String: Auto-filled when Country/Region is selected.

  • Insite2 Retry Number: Auto-filled when Country/Region is selected.

NOTE:Do not forget that Proxy Server Parameters are required with a modem.

8  InSite Checkout

It is mandatory after finishing the Magmon3 configuration to call your regional On Line Center Magnet Support Group to perform a Database Checkout. This is especially important if upgrading from an EDM or a Magmon2 (SHeM) to Magmon3. The following information will need to be provided, so make sure to have it available:

  • Magmon3 Cryogen System ID

  • Magnet Type

  • Country

  • Connection Type

Make sure all of the configurations are complete before performing an InSite Checkout. You must be connected to the Magmon3 unit with a laptop in order to review the configurations.

  1. Connect to the Magmon3 using a laptop. See Connecting to Magmon3 with a Laptop for more information.

  2. Select [Config Summary] to display the configurations. If all configurations are complete, proceed to the next step. Otherwise, make corrections before continuing.

  3. Call your regional On Line Center Magnet Support Group, and perform an InSite Checkout. Instructions on how to proceed will be provided.

    In Europe, the Middle East, and Africa: Perform these additional substeps:

    1. For every new Magmon3 installation, the FE needs to declare the new system in the InSite database at http://insite-check-in.em.health.ge.com, even if the site is connected directly to the Internet.

    2. The FE needs to add a comment on the web site to indicate whether the Magmon3 is connected directly to the Internet.

    3. If the site is not connected via broadband, the FE needs to register the Magmon3 at the modem side of the InSite website to obtain an IP address.
