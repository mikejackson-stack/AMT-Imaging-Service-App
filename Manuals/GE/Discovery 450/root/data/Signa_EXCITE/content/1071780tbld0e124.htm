FAILEDThe ICN has failed the diagnostic.

    • If that diagnostic fails, follow the steps described on the Help page for that diagnostic.
    • If the diagnostic succeeds, rerun the ICN Memory Stress diagnostic.
  2. If the diagnostic fails again, the entire ICN must be replaced. See ICN Replacements. The identity of the ICN will display in the ‘FAILED’ message or go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
