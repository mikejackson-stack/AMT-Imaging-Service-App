ICN VRF → ICN Fast Feedback Path

1  Diagnostic Link

Diagnostics → System Function → Recon → VRF Communication Diagnostics

Diagnostics → Hardware Location → PGR Cabinet → VRF Communication Diagnostics

Illustration 1:  VRF Communication Diagnostics

2  Purpose

The purpose of the ICN VRF→ICN Fast Feedback Path is to test the feedback path between VRF and AGP.

3  Components Tested

Fast feedback path between the VRF and AGP

4  Requirements

No special requirements

5  Block Diagrams

Illustration 2:  ICN Fast Feedback Data Path for 4100 ICNs

Illustration 3:  ICN Fast Feedback Data Path for 4170 ICNs

6  Test Sequence

NOTE: (For 32-channel 4100 systems) Use the ICN Identification tool from the Common Service Desktop (Utilites → Toolbox → VRE → ICN Identification) to help distinguish ICN1 from ICN2.

(For 32-channel 4170 systems) Use the HART log to identify VRF1 and VRF2. As indicated in VRF Hardware Diagnostic link below.

  1. Select ICN VRF→ICN Fast Feedback Path from the VRF Communication Diagnostics screen.

    NOTE:If there is more than one ICN, select ICN1 and ICN2 for this diagnostic.

  2. Click [Run].

  3. Review the Test Results table to see the result of the diagnostic.

7  Expected Results

This diagnostic has either a passed or failed status. If the diagnostic has failed, review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in the table below.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe data path passed the diagnostic.No further action required.
FailedThe data path failed the diagnostic.
  1. Run the ICN RRX→VRF Datapath diagnostic.
  2. Run the ICN VRF Board Level Diagnostics.
