Table 5:  Scan Protocol: Body Mode

NOTE:This is the alternate proprietary procedure available for GE use and for sites with a valid Advanced Service Package Limited License.
  1. Select [New Pt].
    • ID: Type geservice and press <Enter>.
    • Name: Type rf test.
    • Weight (Lbs): Type 300 and press <Enter>.
  2. Set Patient Protocols to Service.
  3. At front enclosure: Landmark in the Head area and remove any coils.
  4. Press [Landmark] and [Move to Scan].
  5. In the Patient Position Protocol field: select Other, the 1.5T apb cal, and Series 1 for body.
  6. Select [Save Series].
  7. Select [Research Operations].
  8. Select [Setup Params], set TG to 50 and click [Done].
  9. Select [Research Operations].
  10. Select [Display CVs], highlight CV Name and enter the following:
    • CV Name: calmode and press <Enter>.
    • CV Value: 5 and press <Enter>.
  11. When Dual Logamp Waveform, click [Accept].
  12. Select [Research Operations] and click [Download].
