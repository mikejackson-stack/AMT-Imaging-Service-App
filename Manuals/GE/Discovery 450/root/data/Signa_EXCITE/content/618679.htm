ICN Time Sync Diagnostic

1  Diagnostic Link

Diagnostics >> VRE Subsystem >> VRE Communication and Hardware Diagnostic

2  Purpose

The purpose of this diagnostic is to verify time synchronization between the host and ICN.

This diagnostic attempts to execute the date command on the ICN via the remote shell protocol. The ICN and host times are compared.

3  Components Tested

  • Remote Shell service on the ICN.

  • Host and ICN Time synchronization.

4  Requirements

ICN is turned on and has a network connection to the Host.
