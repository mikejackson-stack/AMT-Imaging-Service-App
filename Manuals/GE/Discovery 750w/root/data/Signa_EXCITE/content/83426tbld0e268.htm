Table 3:  DCB DIAGNOSTIC TESTS

TEST NAMETEST DESCRIPTION
DIF BLD
  1. The AGP sends data command to IRF queue.
  2. IRF forwards command via IRF I/O to RRF-DIF.
  3. RRF replies to IRF via IRF I/O and this is stored in IRF Board status memory.
  4. AGP waits 2 status memory cycles (about 512 usec) and then reads the IRF status memory.
Receiver BLD
  1. The AGP sends data command to IRF queue.
  2. IRF forwards command via IRF I/O to RRF-DIF.
  3. RRF-DIF queries Receiver Board over bus.
  4. RRF replies to IRF via IRF I/O and this is stored in IRF Board status memory.
  5. AGP waits 2 status memory cycles (about 512 usec) and then reads the IRF status memory.
Exciter BLD
  1. The AGP sends data command to IRF queue.
  2. IRF forwards command via IRF I/O to RRF-DIF.
  3. RRF-DIF queries Exciter Board over bus.
  4. RRF replies to IRF via IRF I/O and this is stored in IRF Board status memory.
  5. AGP waits 2 status memory cycles (about 512 usec) and then reads the IRF status memory.
UTNS BLD
  1. The AGP sends data command to IRF queue.
  2. IRF forwards command via IRF I/O to RRF-DIF.
  3. RRF-DIF queries UTNS Board over bus.
  4. RRF replies to IRF via IRF I/O and this is stored in IRF Board status memory.
  5. AGP waits 2 status memory cycles (about 512 usec) and then reads the IRF status memory.
