Magnet Enclosure Button Test

1  Diagnostic Link

Diagnostics >> System Function >> Patient Handling >> SRI Functional Tests

Diagnostics >> Hardware Location >> Magnet Room >> SRI Functional Tests

Illustration 1:  SRI Functional Diagnostics

2  Purpose

This test verifies the proper operation of the Operator Control Panel push buttons on the front of the magnet enclosure.

NOTE:Possible equipment shutdown. Do not press the [Emergency Stop] buttons on the Display Panel during this test. The [Emergency Stop] buttons are not disabled during the test, and will shut down all cabinets that provide power to the magnet room.

3  Components Tested

  • Magnet Enclosure Operator Control Pushbuttons Codes

  • In-Room Monitor Operator Control Pushbuttons Codes

4  Requirements

None

5  Test Sequence

CAUTION
Possible Equipment Shutdown
Do not press Emergency Stop buttons on the Display Panel during this test.
The Emergency Stop buttons are not disabled during the test. Pressing the top, outer Emergency Stop buttons will shut down all cabinets that provide power to the magnet room.

5.1  Version With In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button and verify that the display on the Host Computer within the Service Browser corresponds to the button descriptions. Pressing the three buttons around the trackball does not display anything. This is the expected behavior.

5.2  Expected Results

When this test is performed each button's description will appear on the Host PC within the Service Browser.

Illustration 4:  Sample Button Test Results Screen

When a control panel button is pressed, the diagnostics page will display a unique number.

NOTE:Possible equipment shut down. Do not press the Emergency Stop buttons on the Display Panel during this test. The Emergency Stop buttons are not disabled during the test and will shut down all cabinets.
