1  Procedure

1.1   Opening the E-Reporting Tool

  1. Insert the Service Key in the host computer USB port (this applies to the FE or OLE, not the customer). The service key is needed to access the MR Service Desktop Browser.

  1. Click [Service Desktop Manager] and select [Service Browser] from the Service Desktop Manager window. The Common Service Desktop home page opens. This home page (see Illustration 1) is the FE Cockpit top-level page.

    (Step Details)

  1. Click the E-Reporting link on the FE Cockpit Home Page (see Illustration 1). The E-Reporting View Service Reports page is displayed (see Illustration 2).

    (Step Details)

1.2   Viewing a List of Service Reports

When the E-Reporting Tool is opened, a list of reports automatically displays (for reports that were already created).

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. A list of Unread reports is shown at the top of the page, and a list of Read reports is shown at the bottom of the page. When a service engineer creates a report, it goes to the Unread list. When a customer opens the report, it moves to the Read list (see Illustration 2).

1.3   Viewing a Specific Service Report

A service engineer can view a particular report by clicking the View link for that report.

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the View link for the report you want to view (see Illustration 3). The corresponding report is displayed (see Illustration 4).

    (Step Details)

1.5   Printing a Service Report

A service engineer can print a specific report by opening it and printing it. The service report is displayed as a PDF file for printing purposes. The report is printed using either the:

  • XPDF tool on the local system, which is a Linux version of PDF, or

  • Adobe Acrobat when accessed remotely through the Integrated Service Desktop (ISD)

NOTE:To print a service report, a network printer needs to be configured on the scanner. This printer must be set up to print from Adobe Acrobat, Adobe Reader, or a similar PDF program.

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the View link for the report you want to print (see Illustration 10). The corresponding report is displayed in the View Report page (see Illustration 11).

    (Step Details)

  1. Click the Print button at the bottom of the View Report page (see Illustration 11).

    (Step Details)

  1. If you print locally from the system, an XPDF page displays (see Illustration 12 ). Click the Printer icon in the toolbar at the bottom of the XPDF page to print.

    (Step Details)

1.6   Editing a Service Report

A service engineer can edit a specific report by clicking the Edit link for that report. An FE can edit only an unread report.

NOTICE
Make sure to state the facts, not hypothesis, when editing a report.
 
 

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the Edit link for the report you want to edit (see Illustration 15). The corresponding report opens (see Illustration 16).

    (Step Details)

  1. Enter your changes in the report.

  1. Click the [Save] button at the bottom of the page.

1.7   Adding Comments to a Service Report

A service engineer can add comments to a specific report by clicking the Add Comments link for that report. An FE can only add comments to a read report. After adding the comments, the report is moved to the "Unread" section.

NOTICE
Make sure to state the facts, not hypothesis, when adding comments to a report.
 
 

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the Add Comments link for the report to which you are adding comments (see Illustration 17). The corresponding report opens (see Illustration 18).

    (Step Details)

  1. In the Comments box, type comments.

  1. Click the [Save] button at the bottom of the page.

1.8   Exporting Service Reports to Media (in PDF Format)

A service engineer can export a report to media, such CD, DVD, or USB drive. The report is exported as a PDF file.

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the check box for the report you want to export (see Illustration 19). Placing a check mark in the check box will select the report.

    (Step Details)

  1. Insert the CD, DVD, or USB to which you are exporting the report. Make sure to insert the media in the proper port/drive for the computer.

  1. Click the [Export] button at the bottom of the page (see Illustration 19).

    (Step Details)

  1. Select the type of media to which you are exporting the report, such as CD.

  1. Click [OK].

1.9   Deleting a Service Report

A service engineer can delete a specific report by clicking the Delete link for that report. An FE can delete only an unread report.

  1. Open the View Service Reports page (see Opening the E-Reporting Tool).

  1. Click the Delete link for the report you want to delete (see Illustration 21).

    (Step Details)

  1. Click [OK] .
