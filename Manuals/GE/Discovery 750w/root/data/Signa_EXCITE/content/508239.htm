UPM - MNS Setup and Calibration

(Click Here for Summary Version)

2  Overview

This calibration procedure sets up the Universal Power Monitor (UPM) for MNS using the system and the Power Measurement Kit. For 1.5T systems, only Forward Power must be completed. For a 3.0T system, both Forward and Reflected Power must be completed.

4  Procedure

4.1  MNS Amplier Forward Power Calibration

  1. Inhibit T/R faults by moving Switch 2 (SW2) on the Driver Module in the RF Systems Cabinet to the TR Disable position. (See Illustration 1.)

    Illustration 1:  Driver Module Switches

  1. For a 3.0T system, plug the power supply on the dummy load into a 110 VAC service outlet in the Systems Cabinet.

    Illustration 2:  Remove any Cables on MNS Output

4.2  Setting up Software Tool to Calibrate UPM - MNS Forward Power

NOTE:This tool must have the Head coil installed in order to enable coil ID.

  1. To establish a Landmark, select [New Pt].

  1. Enter the following parameters:

    1. Patient ID: geservice.

    1. Weight: 111.

  1. Install the head coil.

  1. Align the head coil to the alignment light.

  1. Press the [Landmark] button to drive the head coil into the bore.

  1. Start the UPM calibration tool. ( Step  shows an example of the UPM tool.)

    Illustration 3:  UPM Tool

    1. For Restricted Service Tools available to GE Field Service:

      • Make sure your service key is installed.

      • Select Calibration Wizard from the calibration menu and Click here to start this tool to start the wizard.

      • Once the Calibration Wizard starts, select MNS UPM Calibration from the menu, review and approve the pre and post-dependencies, and select Click here to start this tool to start the procedure.

        NOTE:If unable to start the Restricted Service tools, use the non-proprietary method described next.

    1. For Non-proprietary Service Tools:

      • From the Common Service Desktop, select Calibration and UPM Tool from the calibration menu.

      • Select Click here to start this tool to start the procedure.

  1. The first time running the UPM Calibration tool after a Load from Cold, if the following message displays, The spectroRFampType and upm.config do not match!:

    1. Click File => Edit Config.

    1. On the screen that opens, click [Restore Defaults] and close the screen.

      The tool will now have the correct information, and this message will not re-display during future UPM calibrations.

  1. Select the Nuclei: [3IP].

  1. Select the RF Chain to calibrate: [MNS].

  1. Select the Power (monitor) Type: [Forward].

  1. Click the [Calibrate] button.

  1. Click the [Start] button, verify the hardware setup is satisfactory, then select Yes.

    NOTE:A status message should notify the user of the current step in progress, and indicate Pass/Fail upon completion of the UPM calibration. If a failure occurs, see Step .

  1. 1.5T systems are complete at this point. Select [Quit] from the UPM GUI, and proceed to Finalization, Step 1.

  1. For 3.0T systems, continue to MNS Reflected Power Calibration (3.0T Systems Only).

4.3  MNS Reflected Power Calibration (3.0T Systems Only)

  1. Leave the MNS Output Cable disconnected. (See Step .)

    Illustration 4:  Remove Any Cable on MNS Output

  1. Return to the UPM tool user interface.

  1. Make sure Nuclei 3IP and MNS are selected.

  1. Select the Power (monitor) Type: [Reflected].

  1. Click the [Start] button.

  1. In a few seconds, tool displays a Pass/Fail. If failure occurs, see Step 

4.4  If UPM Failure Occurs

  1. Verify proper calibration equipment setup.

  1. Check the cabling between the UPM and Amplifier.

  1. Check the mgd_stage file by typing: cd /w/config. Remove the p if necessary (p = UPM emulated).

  1. Perform the Maximum RF power calibration procedure, and repeat the UPM calibration.

  1. Check the UPM for power.

  1. Check the error log for details of UPM failure.

  1. Perform the Body UPM calibration.

    • If it fails, replace the detector boards; perform a UPM calibration to put the new boards into service.

    • If it passes, continue to troubleshoot the problem with the Body mode. (Most likely, the problem is with the PA section of the RF Amplifier and the cabling back to the UPM.)

5  Finalization

  1. Select [End Exam].

  1. Remove the cables and power measurement equipment from the MNS Amplifier.

  1. Re-attach the MNS heliax cables.

  1. Re-enable the T/R Driver Module by moving Switch 2 (SW2) to TR Enable. (See Illustration 1.)

  1. Upon completion of both Forward and Reflected calibration, perform a TPS Reset.
