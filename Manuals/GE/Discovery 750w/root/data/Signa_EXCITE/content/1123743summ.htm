2  Procedure

2.1   Loading Host Operating System Software

NOTICE
The software load can be corrupted if the following conditions are not met:

  • Check SaveInfo script executed.

  • System Monitor turned On.

 
 

  1. Insert the Linux OS Software DVD into the DVD-ROM drive of the host computer.

    (Step Details)

  1. Reboot the host computer.

  1. At the boot prompt, type the appropriate code for the keyboard in use, then press <Enter>:

    (Step Details)

  1. You will see a series of progress bars. The OS software load takes about 20 minutes.

    (Step Details)

  1. Once the installation is complete, the system reboots to a graphical user login prompt. Login as root. Password is operator.

    (Step Details)

  1. The OS disc will be automatically ejected and you will see the following pop-up. Remove it and continue to the next section.

    (Step Details)

2.2   Loading MR Applications Software

  1. Insert the MR Applications DVD into the DVD drive of the Host computer and click [OK].

  1. After inserting the MR Applications DVD, a pop-up displays, indicating that the MR Applications Software Installation is in progress.

    (Step Details)

  1. When the Locale Selection window displays, select the proper locale and language, then click [OK].

    (Step Details)

  1. The Guided Install screen will display. When the Message screen shown below displays, indicating the improvements made from the previous software version, click [OK] to continue.

    (Step Details)

  1. The MRApps DVD will be automatically ejected. Remove it from the drive.

  1. When the Guided Install Configuration Media Dialog window displays, confirm the type of media to use to restore the Guided Install Configuration.

    (Step Details)

  1. Proceed with the Guided Install Load. (See Step 8 to Step 13.)

NOTICE
The last installed GUI configuration can only be installed if it was previously saved using Save GI Configuration.
 
 

  1. Insert the Save Info DVD and click [OK]. Verify that the correct values are restored by checking each tab in the next step. Click [OK] to reinstall the last GUI installation configuration values.

    (Step Details)

  1. Select Basic Configuration tab shown below. Verify that all values under this tab are configured properly, including Time/Date.

    (Step Details)

  1. If the Guided Install configuration was successfully restored from the DVD, it is not necessary to change any of the parameters.

    1. Check the parameters on the Verification tab and confirm there are no failures. If there are failures, make the necessary changes.

    1. Make sure all required configuration tabs are filled out (not in any specific order) before continuing. The Verification tab lists any formatting errors as well as current settings.

  1. Set Scan Range to proper value by selecting the System Configure option under the Basic Configuration option. If the length of the Magnet Room is less then 21.5 ft. (6.5 m), select [Short]. If the length is greater than 21.5 ft. (6.5 m), select [Long].

    (Step Details)

  1. Set the the proper value in Hardware Configure.

    (Step Details)

NOTICE
If loading software for the first time on a Host PC, the initial boot-up will fail. Manually enter the Term Server information (found on the front of the terminal server in the PGR cabinet) on the Network Info screen shown in Illustration 10.

Example format: 20:2D:90:22:44. Use colons between two digits; letters are case sensitive.

 
 

  1. Proceed to the Verification tab (shown below).

    1. Look for any items with a Fail status. Go to the tab with the error and correct it.

    1. Click [Install] to open the Verification tab again.

    (Step Details)

  1. If all entries pass verification at this point, click [Install Software] to begin the MR Applications load. If the time and time zone are correct, click [Confirm] to proceed.

    (Step Details)

  1. A pop-up message will display (shown below). Remove the SaveInfo disc from the DVD drive and insert the MRApps DVD.

    (Step Details)

  1. Once the MR Applications load is complete, a confirmation message displays. Click [OK] to close the window.

    (Step Details)

  1. The GUI returns to the Guided Install window. Under the Utilities tab in the left navigation, select Save/Restore to open the Save/Restore screen.

    (Step Details)

  1. A RestoreInfo in Progress window scrolls file names as they are restored.

    (Step Details)

  1. Click [Yes] when the Quit Tool message displays.

    (Step Details)

  1. Quit the Guided Install properly.

    (Step Details)

  1. Reboot the system by clicking right-mouse-button on the desktop and select Reboot....

    (Step Details)

  1. Log in to the system as root. (Password is operator)

  1. Click [Yes] to start Guided Install.

    (Step Details)

  1. Remove the SaveInfo disc.

  1. Proceed to the next section.

2.3   Loading and Configuring VRE Software

  1. From the Guided Installation interface left navigation menu, select VRE Configuration.

    1. When the VRE Configuration screen displays, verify VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.

      (Step Details)

    1. Click [Configure VRE Blades].

  1. When the Information window displays, click [Continue] to confirm that the VRE Gigabit Switch Ethernet and Host Ethernet connections are complete and correct.

    (Step Details)

  1. When the VRE window asks for the number of connected VRE Blades, select the “1” for 750w Image Compute Nodes (ICNs) number and click [OK].

    (Step Details)

  1. IMPORTANT: A pop-up message will prompt the user to insert the VRE OS disk for copying the ICN OS contents onto the hard drive. Insert the VRE OS Software DVD into the DVD-ROM drive of the host computer and click [OK]. VRE configuration progress details will display while ICN OS contents are being copied.

    (Step Details)

  1. The VRE OS DVD will be automatically ejected. Remove it from the DVD drive and close the tray.

NOTE:If the VRE configuration continues to fail, refer to VRE Troubleshooting.

  1. When VRE configuration is complete, a configuration Success message is displayed. Click [OK] to continue.

    (Step Details)

  1. If the site has In-Room Monitor (IRM) , in the Guided Install window, select IRM Installation and then click the [Install IRM Software] button.

    (Step Details)

  1. If this is the first or initial software load, perform a Term Server Reset by executing the following steps. Otherwise, proceed to Step 9.

    1. Remove the power connector from the Term Server.

    1. Press and hold the small square Reset button (next to the power jack), and connect power to the Term Server while continuing to press this button.

      (Step Details)

    1. Continue pressing the Reset button for 20 seconds.

    1. Verify communication between the Host PC and Term Server:

      1. Open a C-shell terminal.

      1. Ping the ts1 address by typing: ping hostname-ts1 (where hostname is the hospital name). Press <Enter>.

      (Step Details)

    1. To stop the test, press <Ctrl-c>.

  1. When the Information window confirms that the configuration is complete, click [OK].

  1. Load Service Software. Refer to Loading or Deleting Proprietary Software.

  1. Load Service Methods documentation. Refer to Installing Service Methods CD onto System.
