Table 5:  Gradient Messages Error Log - Initial Message Examples

For This error:Conditions and Potential Issue:
12267833 - XGD reports no 420 V power.
  1. Check Gradient 420 V power breaker and EMO reset button.
  2. Check condition of 420 V PDU power circuit breaker and confirm system is not in E-Stop.
  3. Check the XPS Fault LED on each of the XPS units. Unit with illuminated XPS Fault LED has failed and requires replacement. This should normally be a single unit.
    NOTE:If none of the XPS Fault LEDs are illuminated and XPS units have power, recheck the error log for earlier messages that will help identify the real problem. If necessary, call the On-Line Center for assistance.

22267962 - X axis XGA-SB is reporting a PLL failure.
  1. Check the integrity of the connections at the XGA Control Board and at each XGA unit.
    NOTE:Observe the following:
    • A PLL is a Warning; it will not stop the scan. Most of the time, this error will show up as a collapsed image, which is a dark line in the image. The direction will depend on the axis that failed and type of scan being completed.
    • The PLL is derived from the signal on the single strand clock fiber from the XGA Control Board inside the GMC (Cronus) Chassis to each XGA. A loose or damaged clock fiber or fiber-optic connection at the XGA Control Board inside the GMC (Cronus) Chassis or at the XGA unit could cause this fault.

  2. Swap failing clock fiber-optic cable at the XGA Control Board (inside the GMC Chassis) with neighboring fiber-optic cable.
    NOTE:The clock signals on each clock line from the XGA Control Board to each XGA unit are identical.

  3. Perform action that causes fault, then check error log.
    NOTE:If problem moves, the XGA Control Board is faulty. Replace the XGA Control Board. If problem does not move, swap clock fiber-optic cable at the failing XGA with neighboring XGA unit. (This unit should be on same line as what was swapped at XGA Control Board.)

  4. Swap failing SFP fiber-optic cable with neighboring cable.
  5. Perform action that results in fault and check error log.
    NOTE:If problem moves, the fiber-optic line is faulty. Replace or repair it. If problem does not move, the XGA is faulty. Replace the XGA unit.

32267885 - Y axis XPS is reporting a PLL Warning
  1. Check the integrity of connections at the XPS Control Board and at each XPS unit.
    NOTE:The PLL is derived from the signal on the single strand clock fiber from the XPS Control Board inside the GMC (Cronus) Chassis to each XPS. A loose or damaged clock fiber or fiber-optic connection at the XGA Control Board inside the GMC (Cronus) Chassis or at the XPS unit could cause this fault.

  2. Swap the failing clock fiber-optic cable at the XPS Control Board (inside the GMC Chassis) with neighboring fiber cable.
    NOTE:The clock signals on each clock line from the XPS Control Board to each XPS unit are identical.

  3. Perform action that causes fault, then check error log.
    NOTE:If problem moves, the XPS Control Board is faulty; replace it. If problem does not move, swap the clock fiber-optic cable at the failing XPS with neighboring XPS unit. (This unit should be on same line as what was swapped at the XPS Control Board.)

  4. Swap failing sfp fiber optic cable with neighboring cable.
  5. Perform action that results in fault and check error log.
    NOTE:If problem moves, the fiber-optic line is faulty. Replace or repair it. If problem does not move, the XPS is faulty. Replace the XPS unit.
