Reconfiguring the System

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Re-configuring the System

  1. From the MR Service Desktop, select the Configuration tab.

  1. Expand Guided Install and select FE Mode.

  1. Click the Click here to start this tool link. The Guided Install window opens.

  1. At the password prompt, type operator and press <Enter> to access the Guided Install interface.

    (Step Details)

  1. Click [Next] to move through the tabs in order, and modify values as needed.

    (Step Details)

  1. On the Verification tab, review the changes, make any necessary corrections, and click [Configure Tab(s)] to update the system.

  1. Before exiting the GUI, insert the SaveInfo CD/DVD or a new CD/DVD. From the File menu, select Save, and then Save GI Configuration to CD/DVD.

    (Step Details)

  1. From the File menu, select Quit. If any error conditions still exist, a warning indicates that no changes will be made prior to exiting. Fix any error conditions before exiting the GUI.

    (Step Details)

1.2   Setting the Time and Date

The Set Time/Date option is not set using the [Configure ] button. This window has separate buttons for configuring the host PC time and date. To configure the time and date:

  1. Expand Basic Configuration, and select Set Time/Date to open the window.

    (Step Details)

  1. Set the time zone and then the time/date appropriately. Click [Next].

  1. Restart the host PC for the time/date change to take effect.

    (Step Details)

1.3   NTP Server Configuration

NTP server configuration can be done to synchronize the MR Scanner date/time automatically with an NTP server available on site. An NTP server and IP address are required. Follow the instruction in NTP Server Time Synchronization.
