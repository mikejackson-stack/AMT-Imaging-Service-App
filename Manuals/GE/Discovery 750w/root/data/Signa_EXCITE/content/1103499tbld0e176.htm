Table 2:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities → Toolbox → VRE → ICN Identification).
  2. Ensure that the Host-ICN Remote Shell diagnostic runs successfully.
    1. If the diagnostic fails, follow the steps described on the Help page for that diagnostic.
    2. If the diagnostic succeeds, rerun the ICN CPU Stress diagnostic.
  3. If the diagnostic fails after a second attempt, reboot the ICN. Wait until the ICN is fully enabled. Once the ICN is enabled, rerun the diagnostic.
  4. If the diagnostic fails after the ICN reboot, check the ICN. Go to ICN Identification to identify the defective ICN (Utilities → Toolbox → VRE → ICN Identification).
NOTE:If the ICN Ethernet port/cables are faulty, then all of the test for that ICN may fail. This does not apply to the IPMI Test, which has a separate Ethernet cable.

The current product configuration has a redundant motherboard Ethernet connection for each ICN.
