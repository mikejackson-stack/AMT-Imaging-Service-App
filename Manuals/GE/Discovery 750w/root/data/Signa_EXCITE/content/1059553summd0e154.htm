Noisy Head imagesNoisy Head imagesThe system can't detect a single open diode in the Body Coil DD Circuit. It is very unusual for pin diodes to fail open. However, it is possible to have Noisy Head images without a hard failure noted in the error log.

Check the Body Coil DD Circuits first. Check for diode action at the red DD cables at at J72 & J76 on the magnet room side of the penetration panel. Typically, in one direction you should see 0.42 - 0.44 vdc. Reversing the polarity of the measurement will result in an open or infinity measurement. Ohm out Body Coil “I” and “Q”. From Center pin to outer case should read Open or infinity. If there is a resistance seen, It is possible that the Body Coil may have a shorted capacitor or other electrical damage. Consult Support prior to removing/replacing Body Coil.

Replace Body Coil
Error describes a possible shorted Dynamic Disable DiodeError log describes a possible shorted Dynamic Disable DiodeGenerally, diodes fail by shorting.

The best way to troubleshoot is to check the red DD cables on the body coil at J72 & J76 on the magnet room side of the penetration panel. Do NOT measure into the Hv Filter. Use a digital multi-meter (Use Diode Test Function) to find the short diode. Look for diode action. Typically, in one direction you should see 0.35 - 0.42 vdc. Reversing the polarity of the measurement will result in an Open or Infinity measurement.

Replace defective Dynamic Disable Board
1077534964 The Driver Module Has Detected a Power Supply Fault. Source of Fault is High Voltage Power Supply.

Actual Voltage = xx.x V

Limit Voltage = xxx.x V

This error can be a result of a shorted output of the Driver Module.

Utilize the TR DD System Path Check diagnostic document to pinpoint the cause of failure.

  1. Remove all 3 DD Cables (J72, J74, J76).
  2. Run the Driver Module diagnostic.
  3. Run TR DD System Path Check or cycle power on the Driver Module, (CB1). (Reset Module Error circuitry).
  4. Attach one DD Bias cable at a time. Watch Module Error LED. If this Module Error LED illuminates, problem is on that (DD) Dynamic Disable circuit. Could have a short in that circuit.

Use Step Table 3 and Table 4 to isolate which Driver Module output is causing the problem.

Identify cable problem.

Replace body coil or 3.0T Body Hybrid.

Replace Driver Module.
