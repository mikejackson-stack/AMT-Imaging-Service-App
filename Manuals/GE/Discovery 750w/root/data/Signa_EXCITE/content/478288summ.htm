1  Procedure

1.1   Disk Partitioning

  1. Insert the MR Applications media into the Host CD/DVD drive on the GOC (not the one on the SCSI tower).

  1. When the confirmation shown below displays, select [Yes].

    (Step Details)

  1. When the message to turn off power to the DASM (shown below) displays, do so if one is present.

    (Step Details)

  1. Select [OK] to continue with the software load when either message below displays. (The system is now partitioning the hard drives.)

    (Step Details)

  1. When a window displays with options to [Continue], [Halt] or [Close], do not make a selection; let the program run. After two (2) minutes, the system will automatically reboot.

  1. When a menu displays asking for locale selection, select the language and click [OK]. (Eventually, the Guided Install screen will display.)

    (Step Details)

  1. When a window displays indicating improvements were made from the previous software version, click [OK] to continue.

1.2   SaveInfo and Guided Install Process

NOTICE
The last GI configuration can be installed ONLY if it was previously saved using the [Save GI Configuration to MOD].
 
 

  1. A message box (shown below) for restoring the Guided Install GUI configuration will display.

    1. If the GI configuration was not saved or a software load is being performed for the first time, press the [Cancel] button to continue manually with the installation, or

    1. If the GI configuration was saved, insert the SaveInfo MOD or CD/DVD, and click the appropriate media radio button.

      (Step Details)

  1. Select the [OK] button.

NOTE:The normal SaveInfo files will be restored later in the software load process.

  1. Click each tab to verify the correct values were restored. (See illustration below.)

    (Step Details)

  1. If failures are noted, click on the failure and select Go to Tab to display the proper tab.

    (Step Details)

NOTICE
If loading software for the first time on a Linux PC, the initial boot-up will fail. Manually enter the “Term Server” information on the Network Info screen. The information must be entered in the format shown in the following example: 20:2D:90:22:44. Use colons between two digits; letters are case sensitive.
 
 

  1. Proceed to the Verification tab shown below. Check the current settings and a pass or fail status, making any necessary changes. (Failed entries are due to missing entries or those with an incorrect format.)

    1. Go to the tab with the error, correct it, then click the [Install] button to open the Verification tab again.

    1. If all entries pass verification at this point, click the [Install Software] button (shown below) to begin the MR Applications load. (The button will not activate if there are any failures.)

    (Step Details)

  1. When a message window displays with Verify time and zone, click [Confirm] to continue or [Abort] to return to Guided Install.

    1. If the Time/Date and Zone are incorrect, select the Set Time & Date option from Guided Install, and make the necessary corrections. (The Verification tab will redisplay.)

    1. A message, Software Installation in progress, will display that indicates the software is loading. (The MR Applications load will take 7 to 12 minutes, depending on the system it is loaded on.)

  1. Once the MR Applications load is complete and the message shown below displays, click [OK] to close this window.

    (Step Details)

  1. If a message displays asking, Do you want to run media/cdrom/autorun?, always click [No] or [Ignore]. Do not select [Yes].

  1. At this point, the GUI will change from the Install phase. If a SaveInfo MOD or CD/DVD is not available, go to each tab of the Guided Install and complete or update all system information manually. (A Help button is available on each tab that will open a window with information on the required data and its format for that page.)

  1. Remove the MR Applications media from the GOC.

1.3   Restore Information

If performing an Lx to HDx upgrade, RestoreInfo must be done at this time, or options will not be converted to HDx. Option conversion is restricted to the first RestoreInfo. If a restore from the same info is done a second time without a Load from Cold, converted options will be lost.

  1. To perform the RestoreInfo at this time, go to Guided Install, and choose Save/Restore to display the Save/Restore tab shown below.

    1. Select [Restore Information], and choose the proper media (either MOD or CD/DVD).

    1. Insert the proper media, and select [Restore all files automatically].

    (Step Details)

  1. A RestoreInfo in Progress window will scroll filenames as they are restored. When the RestoreInfo is complete and the message shown below displays with the instructions to run the update utility, click [OK] to continue.

    (Step Details)

  1. When the Restore Manager menu opens, make sure the All box is selected to restore all items, then click the [Update] button.

    (Step Details)

  1. When the update is complete, click [Quit] and [Yes]. A message similar to the one below will display with the location of the log file of changes made by the Restore Manager.

    (Step Details)

  1. In the next window that displays, click [OK] to exit the Guided Install. If everything updates successfully, click [Quit] and select [OK].

1.4   New Coil Parameters

Beginning with Signa 10.x, coil parameters have changed. For upgrades from 8.x or 9.x, a coil update will run to add the new parameters to the existing coil definitions.

NOTICE
If there are unknown coils that do not map to a known coil configuration, such as a research coil, inform the customer of the situation. GE Service must NOT change individual parameters for research coils. The customer must work with the Coil Vendor to obtain the proper coil config file.
 
 

  1. The success of the update is dependant on recognition of coil names. If no discrepancies are found, continue to Step 2.c. If any coils are not recognized during the update, the error message shown below will display.

    (Step Details)

  1. If unknown coils are found, click [OK], finish the software load, then:

    1. Go to the Common Service Desktop > Configuration > Config File Manager > CoilConfig.

    1. Select the Manage Unknown Coils option, and add all unknown coils. For instructions on properly managing unknown coils, refer to the Unknown Coils Configuration.

    1. If a DASM is present, turn the power back on.

  1. Reboot the system at this time by typing: reboot in a C-shell.

  1. Log into the system with the user name of root and operator for the password.

1.5   VRE Software Load

  1. Load the VRE software as follows:

    1. Go into Guided Install and select VRE Configuration to display the VRE Configuration tab shown.

      (Step Details)

    1. Click on [Configure VRE Blades].

    1. Verify that the VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.

    1. Select the proper number (1, 2 or 4) of ICNs or VRE Blades. (Choose 1 or 2 when silver 5127452-3 ICNs are installed, and 2 or 4 when black 5127452 ICNs are installed.)

      (Step Details)

  1. Once the configuration completes successfully, click [OK]. (It is not necessary to perform a system restart at this time.)

    (Step Details)

1.6   Term Server Reset for First/Initial Software Load

NOTICE
If the system does not properly boot on the first attempt, the Term Server may need to be reset. If this is the first or initial software load, perform a Term Server Reset as follows:
 
 

  1. Remove the power connector from the Term Server.

  1. Connect power to the Term Server while pressing and holding the [Reset] button (small square button next to the power jack) for about 20 seconds.

  1. If communication problems are perceived between the Linux PC and Term Server, ping the Term Server as follows:

    1. Open a C-shell.

    1. Type: cd /etc and press <Enter>.

    1. Type: more hosts and press <Enter>.

    1. Ping the TS1 address by typing: ping x.x.x.7 and press <Enter>.

      (Step Details)

    1. To stop the test, type: ^z.

  1. Exit the Guided Install screen by selecting File, then Quit.

1.7   Install System Options, Service Software and InSite

NOTICE
Restricted Service Software is only available for GE use; Advanced Service Software is only available to sites with a valid Advanced Service Package Limited License. GE Healthcare Restricted Service Software should also configure InSite Interactive.
 
 

  1. To install new options using eLicense, refer to Software Option Installation with eLicense.

  1. Make sure the MR Applications software is not running, and log in with the user name of root and the password of operator.

  1. Click the Service SW/InSite option located near the bottom of the Guided Install menu, and select the Load Restricted Software option.

    1. The system will respond with the window shown below.

    1. Read the proprietary statement, continue by sequentially clicking the 1, 2 and 3 buttons, then [OK].

    (Step Details)

  1. Insert the Restricted or Advanced service software DVD and click [OK]. The message shown below will display while the software is loading, which will take about three (3) minutes.

    (Step Details)

  1. When the InSite Interactive screen displays, select [Accept] three times if performing the InSite checkout at this time, or select [Decline] to perform the checkout later.

    (Step Details)

1.8   Enable ProDiags and InSite Checkout

The three elements for configuring InSite include ProDiags, Health Page, Device Connections and InSite Checkout. Click each tab shown in Illustration 19 and perform the tasks outlined in InSite/IIP.

  • The instructions in this section provide the minimum number of screens to enable basic functionality for ProDiags and to complete an InSite checkout with the Connectivity Center. For information on the custom setup, refer to Insite/IIP Installation for Signa Excite 1.5T or 3.0T on the 5190000 Signa Service Methods DVD.

  • ProDiags is defaulted to call out to the Automated Support Center (ASC) on a daily basis. If the initial attempt to call out fails, the software reattempts to call out hourly until successful. If the modem or network connection is down, these hourly attempts to call out can slow down the scanner. During Insite IIP setup, configure ProDiags to dial out weekly to the ASC and reattempt daily.

    NOTE:Due to the software changes at the OLC to support iLinq (formerly called InSite Interactive), all 8.3 and higher systems require a Manual Checkout. (FE must call the Connectivity Center for the initial checkout.). Once this is done, the Auto Checkout feature can be used for future reloads.

Illustration 19:  InSite Interactive Platform Configuration Screen

NOTICE
Do NOT skip the next step even if the site does not have a modem or broadband connection.
 
 

  1. Following Acceptance ( Install System Options, Service Software and InSite, Step 5), the main tabs shown below are initialized.

    (Step Details)

  1. If an InSite modem or broadband connection is not available or will be configured later, select [EXIT] and proceed to Step 6.

  1. Click the ProDiags tab to display the Proactive Diagnostics screen shown.

    (Step Details)

  1. Click the [Default] button to configure ProDiags with the default schedules provided with the software. (A status message, ProDiags Auto Setup: Completed Successfully, should display at the bottom of the screen.)

  1. When the Health Page screen shown below displays, click in the Enter Address List box and type a valid email address. Do not press the <Enter> key.

    (Step Details)

  1. Click the [Default] button to configure the Health Page with the default schedule file, and the Device Connection screen shown below will display. (A status message, Health Page Email... Completed Successfully, should also display.)

    (Step Details)

  1. Select a dial-out prefix, or type a site-specific prefix. (A dial-out prefix may be required at a site to get a line outside of the hospital. 9,1 is the most common and the default.)

    1. If the site has a broadband connection, select Network and type the “gateway” provided by the OLC.

    1. If a mistake is made while configuring the Device Connection tab and the wrong dial-out prefix is entered, it may be necessary to run a Secure from the Service S/W tab and reload the Service software.

      (Step Details)

  1. After properly verifying/configuring any switches or other parameters on the modem, click [OK] on the Modem Readme window (shown below) to program the modem. The InSite Checkout tab (shown in Illustration 25) will display.

    (Step Details)

1.9   Complete InSite Checkout

NOTICE
Due to a software bug, boot up to Signa level, shut down, then perform InSite Checkout.
 
 

NOTE:The Insite Checkout tab (shown in Illustration 25) allows the user to complete the InSite configuration process. The other checkout options are described below.

  1. When the [CHECKOUT NOW] button is clicked, the Configure InSite Now window (shown in Illustration 26) displays.

    (Step Details)

  1. After clicking [EXIT] on the InSite Checkout tab (shown in Illustration 25), an Exit Confirmation screen displays. (See illustration below.) A valid date/time should display for each function that was successfully configured. If any function shows No File, that function was not properly configured.

    (Step Details)

  1. Click [OK] on the Exit Confirmation window to exit the IIP Configuration Tool.

  1. Wait for the message, Restricted Service Load Done, in the Install GUI status bar at the bottom of the window.

1.10   Perform SaveInfo and Load Service Documents

  1. Perform a SaveInfo to save the latest changes:

    1. Insert the site SaveInfo media (MOD, CD or DVD) or blank MOD into the drive.

      (Step Details)

    1. Select the Save/Restore tab, and click the [Save Information and Save GI] button.

  1. Insert the normal SaveInfo or a new MOD/CD/DVD into the drive if not already there.

  1. At the top left of the Install GUI, select File and [Save GI Configuration to MOD]. (This will save the information that was entered in all the edit fields in the GUI.)

  1. Remove the Restricted or Advanced service software from the DVD drive.

NOTICE
Sites with in-house contracts may be able to skip these next steps. Only Revision 7 or higher Service Methods DVD will load.
 
 

  1. Launch the Guided Install.

  1. In the Guided Install window, select Service SW/Insite in the left navigation pane.

    (Step Details)

  1. Insert the Service Methods DVD into the disk drive on the PC.

  1. To mount the DVD type: mount/mnt and press [Enter].

  1. Click [Install Service Documentation].

  1. When the message shown below displays, click [Full CD].

    (Step Details)

  1. After the installation of the DVD contents, remove the DVD from the system:

    1. Open a C-shell.

    1. Type: umount /mnt/cdrom.

  1. Right mouse click on the Common Service Desktop, and select [Logout].

  1. As a part of software setup, load the Operator Manual DVD in the local language. The load will take approximately 12 minutes to complete.

1.11   Set Up MOD CD-ROM Devices

  1. Select Display MOD/CD-ROM from the Guided Install.

  1. When the MOD/CD-ROM tab displays, click [Setup Devices] and follow the outlined tasks. (The message, Device configured, displays once configuration is completed for each device.)

2  Finalization

  1. Perform a Daily Automated Quality Assurance (DAQA) scan to verify system integrity. Instructions can be found in the system Operator Manual.

  1. If applicable, verify the system can network to other systems by transferring images.

  1. If applicable, verify the system can properly film.
