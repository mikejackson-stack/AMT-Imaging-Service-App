2  Overview

This modules provides instruction to do functional checks on the Universal Power Monitor (UPM) in Head mode and Body mode.

  • 3.0T systems operate in average power mode. Functional check tests include: 10-second average power check, RF inhibit test, and short-term average power fault host trip test.

  • To run the Body UPM Functional Check, see Body UPM Functional Check

  • To run the Head UPM Functional Check, see Head UPM Functional Check

Perform this UPM Functional Check procedure in series with RF Output adjustments and UPM Head and Body Setup and Calibration. The proper order is:

1. Body Channel 1 RF Output adjustment, Body Channel 1 UPM Calibration, Body 1 UPM Functional Check

2. Body Channel 2 RF Output adjustment, Body Channel 2 UPM Calibration, Body 2 UPM Functional Check

3. Head RF Output adjustment, Head UPM Calibration, Head UPM Functional Check

CAUTION
Possible Equipment Damage.
Operating the RF amplifier with improper loads may permanently damage the amplifier.
Do not operate the RF amplifier with an improper load connected to its output.

Coils and phantoms in the magnet bore that are not connected to the system can cause equipment damage.
Prevent coil and associated switch damage by removing all phantoms and hardware (i.e., head coil, surface coil) from the magnet bore unless otherwise instructed.

4  Procedure

4.1  Body UPM Functional Check

RF output must be calibrated and UPM calibration must be completed for selected Body channel before performing these functional checks. When running functional check for Body channel 1, remove the input for channel 2 (J21). When running functional check for Body channel 2, remove the input for channel 1 (J14).

4.1.1  Body UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection. See Illustration 1. Ensure Switches SW2 and SW3 are in their respective Disable positions.

    Illustration 1:  Driver Module Switches

  1. Place the RF ENABLE switch on front of exciter in the DISABLE (Down) position.

  1. Install the dummy load.

    1. If checking Body Channel 1, remove the Body Heliax cable from BODY RF OUT / J4. If checking Body Channel 2, remove the Body Heliax cable from BODY RF OUT / J22.

    1. Connect the 35 KW RF dummy load from the Power Measurement kit into J4 or J22

    1. Plug the power supply on the dummy load into 110 VAC service outlet in the System Cabinet.

      Illustration 2:  Plug the Dummy Load into Body RF Out / J4 or J22

  1. Place the RF ENABLE switch in the ENABLE (Up) position.

4.1.2  Setting up Software Tool to Functional Check UPM - Body Channel Functional Check

  1. On the scanner operator control panel (OCP) press [Align on].

  1. Move the cradle to place the Laser alignment light on the center of the table.

  1. Press Landmark.

  1. Press Advance to Scan.

  1. Start the RF/UPM tool:

    1. In proprietary mode, [Click here to start tool] from the Calibration tab.

      Then, select RF/UPM Cal & Functional Check (Body).

    1. For the Class A service tool:

      1. From the Common Service Desktop, select the Calibration Tab.

      1. Select the [UPM Tool] from the calibration menu and select [Click here to start this tool].

      1. Illustration 3 shows an example of the UPM tool.

        Illustration 3:  UPM tool

  1. For Nuclei select [1H].

  1. For RF Chain, select [Body Ch 1] or [Body Ch 2].

  1. For Task, select [UPM Func Chk].

    NOTE:Power Type is grayed out. This is normal and is not used.

  1. Select the [Start] button then click [YES] in answer to the setup question.

    Illustration 4:  Body Coil Setup Question

  1. The user will be prompted during test execution. The following illustrations show an example of the pop up and error log that should be seen. Verify the error log and click [Yes] if an error message is seen.

    NOTE:The tool performs three tests (10-second average power, UPM1 RF inhibit, and UPM2 RF inhibit) before Host Trip. This takes 2-3 minutes before user interaction is needed.

    Illustration 5:  UPM Power Trip

    Illustration 6:  UPM Power Trip Error Log

  1. Proceed to the next logical step in the RF/UPM calibration process, or proceed to Head UPM Functional Check.

  1. If functional checks fail, refer to Universal Power Monitor (UPM) Troubleshooting.

4.2  Head UPM Functional Check

4.2.1  Head UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection in the Pen Cabinet, see Illustration 7. Ensure switches SW2 and SW3 are in the TR DISABLE and DD DISABLE positions.

    Illustration 7:  Driver Module Front Switches

  1. Switch RF ENABLE on front of the exciter to the Disable (down) position.

  1. Install the dummy load.

    Remove the Head Heliax cable from HEAD RF OUT / J3. Connect directly to the 35 KW RF Dummy Load. Plug the power supply into the Dummy Load and the power supply into 110 VAC service outlet in the System Cabinet. See Illustration 8.

    Illustration 8:  Setup for Head Output Measurement

4.2.2  Setting up Software Tool to Calibrate UPM - Head Forward Power

  1. Place the head coil and connect it to the LPCA.

  1. Landmark on the cradle where the head coil is.

  1. On the operator control panel (OCP) press Advance to Scan.

  1. Refer to Setting up Software Tool to Functional Check UPM - Body Channel Functional Check, Step 5 to start the Service browser.

  1. For Nuclei select [1H].

  1. For RF Chain select [Head].

  1. For Task, select [UPM Func Chk].

  1. Select the [Start] button.

  1. On the Head Coil Setup OK screen, click [Yes] when the head coil is ready to go.

    Illustration 9:  Head Coil Setup OK Screen

  1. The user will be prompted during test execution. Illustration 5 and Illustration 6 show examples of the pop up and error log that should be seen. Verify the error log and click [Yes] if an error message is seen.

    NOTE:The tool performs three tests (10-second average power, UPM1 RF inhibit, and UPM2 RF inhibit) before Host Trip. This takes 2-3 minutes before user interaction is needed.

  1. To proceed:

    1. If the test passes, select [Quit] from the UPM Main Window.

    1. If the test fails, refer to Troubleshooting UPM.

4.3  Finalization

  1. Switch RF ENABLE on front of exciter to the Disable (down) position.

  1. Remove the cables and measurement equipment.

  1. Reattach the Head and Body heliax cables.

  1. To re-enable fault detection, set switch SW2 and SW3 to their respective Enable positions.

  1. Switch RF ENABLE on the front of the exciter to the Enable (up) position.

  1. Complete a TPS reset and do a test scan.

  1. Any failure after Troubleshooting is complete will require a re-calibration of the UPM system. See Universal Power Monitor - Head and Body Setup and Calibration.

4.4  Troubleshooting UPM

4.4.1  Potential Tool Issues

  1. Problem: Config file CRC mismatch

    The following error message appears when starting a UPM Tool task or viewing the UPM Tool configuration file:

    Illustration 10:  UPM Error Message

    Issue: Calculated checksum value for upm.config configuration file does not match checksum at end of file. upm.config file contents were edited or corrupted.

    Solution: Copy default UPM configuration file (/usr/g/tools/upm/upm.config.3.0T.XRMW) to UPM Tool configuration file (/usr/g/tools/upm/upm.config).

  1. Problem: RF amplifier does not output power during RF amplifier or UPM calibration

    Power meter does not read any power during RF amplifier or UPM calibration.

    Potential Issue: RF amplifier or UPM has caused a trip of the RF amplifier. Check GE system log for error regarding RF amplifier/UPM fault.

    Solution 1: If RF amplifier has tripped due to an excessive power fault, launch RF Amp Cal procedure through UPM Tool, increase TG to a level that does not cause a fault, follow instructions to recalibrate amplifier in RF Amplifier Setup and Calibration section for appropriate RF Chain.

    Solution 2: If UPM has indicated that measured power has exceeded SAR Limits, re-launch RF amplifier or UPM calibration procedure through UPM Tool. Re-launch of procedure will reset measured power and allow calibration to continue.

  1. Problem: UPM Tool procedure fails to launch, returns “ERROR” status

    UPM Tool procedure fails to launch with message “Incorrect Rx, please check coil and landmark” in Status Window.

    Potential Issue 1: Incorrect coil attached.

    Solution: Attach correct coil: No coil plugged in for Body Ch 1 or Body Ch 2 procedure, Head Coil plugged in for Head procedure, 31P MNS TR Switch plugged in for MNS procedure.

    Potential Issue 2: No landmark established.

    Solution: Perform a landmark with the correct coil. Press “Advance to Scan” button.

  1. Problem: RF power output during UPM Calibration procedure is not within specified limits

    Power meter measured power does not read within the specified limits during UPM Calibration procedure

    Potential Issue: RF amplifier calibration out of specification

    Solution: Follow instructions to recalibrate amplifier in RF Amplifier Setup and Calibration section for appropriate RF Chain.

4.4.2  Potential Hardware Issues

  1. Solution 1:

    • Check all cabling to the UPM-Boards to make sure that they are properly cabled. Be aware that while the UPM Processor Board will illuminate the Inhibit LED for cables that are an open circuit, it will function the same for cables that are terminated in a short circuit.

    • Repeat the UPM Functional Test

  1. Solution 2: Recheck RF Amp output

    • Cycle Power to the UPM Chassis.

    • Reset TPS.

    • Repeat the UPM Functional Test (Head or Body).

  1. Solution 3: Reboot the system. .

    Repeat the UPM Functional Test (Head or Body).

  1. Solution 4:

    • Remove power from the UPM.

    • Re-seat the Processor Module.

    • Restore power to the UPM.

    • Reset TPS.

    • Repeat the UPM Functional Test (Head or Body).

  1. Solution 5:

    • Remove power from the UPM.

    • Reset the Detector Boards.

    • Restore power to the UPM.

    • Reset TPS.

    • Repeat the UPM Functional Test (Head or Body).

  1. Solution 6: The problem could be a bad Processor Module

    • Remove power from the UPM.

    • Replace the Processor Module.

    • Restore power to the UPM.

    • Reset TPS.

    • Repeat the UPM Functional Test (Head or Body).

  1. Solution 7: The problem could be a bad Detector Board

    • Remove power from the UPM.

    • Replace both Detector Boards.

    • Restore power to the UPM.

    • Reset TPS.

    • Repeat the UPM Functional Test for the Receive chain that failed (Head or Body).

  1. For additional troubleshooting information, refer to Universal Power Monitor (UPM) Troubleshooting.

4.5  UPM Theory

The Universal Power Monitor calibration parameters found in the UPM configuration file (/export/home/signa/tools/upm/upm.config) are used in the Calibration/Functional Check tasks. This configuration file is accessible from within the UPM Calibration tool from the File menu > View Config option. These values can be used during troubleshooting to help determine where the power monitor is tripping (if at all). The UPM configuration file shown in Illustration 11 contains the default configuration values for all of the UPM parameters. This screen is just for reference, as the content and values will be different based on the system type. The final UPM digital attenuator values are written to the UPM calibration configuration files (Upm1Cal.cfg, Upm2Cal.cfg) located in directory w/config.
