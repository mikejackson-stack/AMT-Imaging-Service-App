IXG Fiber Loopback Diagnostic

1  Diagnostic Link

Diagnostics >> System Function >> RF >> IXG Fiber Loopback Diagnostic

Diagnostics >> Hardware Location >> PGR Cabinet >> RF >> IXG Fiber Loopback Diagnostic

Illustration 1:  IXG Fiber Loopback Diagnostic

2  Purpose

The IXG Fiber Loopback Diagnostic can be used to test the dual fiber connectors of the IXG board and the external dual fiber cables that connect the IXG to the RRX, DTX, and XGD. This diagnostic requires the user to manually install a fiber loopback adapter on one of the IXG fiber jacks or install a fiber loopback adapter and duplex sleeve at the far end of the DTX, RRX, or XGD fibers. Once the fiber loopback adapter is in place, the user instructs the system to test that single connection. Data is sent from the IXG and is verified as arriving back at the IXG intact. This diagnostic cannot be used to test the fiber links between the RRX and the ICN.

3  Components Tested

The lower 4 IXG fiber ports

4  Requirements

  • Do not run this test until IXG BLD has completed without errors.

  • DVMR link fiber loopback adapter (P/N 5306530, found in DVMR Service Cable Hardware Kit, P/N 5306523)

5  Test Sequence

  1. Select Start Loopback mode.

  2. Click [Run].

  3. Manually disconnect a single fiber from the IXG board and attach the fiber loopback adapter.

  4. Select the correct [Test Fiber in J1_] button.

    NOTE:Only the lower 4 fibers are tested.

  5. Click [Run].

  6. Ensure that the diagnostic passes by reviewing the status in the Test Results table.

  7. Repeat steps 2 and 3 with other fibers as desired.

  8. Remove the fiber loopback adapter and reconnect the normal cables.

  9. Select Stop Loopback mode.

  10. Click [Run].

6  Expected Results

This diagnostic shows either a passed or failed status. If the diagnostic fails, review the error log and corresponding extended error message for subsequent actions.

If the diagnostic reports a timeout, the diagnostic may not have been executed. Retry the test. If it continues to time out, complete a TPS Reset and then retry the test.
