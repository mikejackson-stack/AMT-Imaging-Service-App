RF Amp Interface

1  Diagnostic Link

Diagnostics >> Peripheral >> RF Amplifier Diagnostics

2  Purpose

This diagnostic confirms that the SCP can communicate via CAN to the RF Amplifier Interface Board in the ASC Chassis and that the RF Amplifier Interface Board can communicate to and control the RF Amplifier via the serial link between the RF Amplifier Interface Board and the RF Amplifier.

This test does not test the actual RF Amplifier - just the control and monitoring functionality.

3  Components Tested

  • RF Amplifier Interface Board

  • RF Amplifier State/Mode Operation

4  Requirements

No requirements to run this diagnostic.

6  Test Sequence

  1. SCP commands RF Amplifier to power off.

  2. SCP commands RF Amplifier to standby.

  3. SCP commands RF Amplifier to operate.

  4. CP commands RF Amplifier to standby.

  5. SCP commands RF Amplifier to head mode.

  6. SCP commands RF Amplifier to operate.

  7. SCP commands RF Amplifier to standby.

  8. SCP commands RF Amplifier to body mode.

  9. SCP commands RF Amplifier to operate.

  10. SCP commands RF Amplifier to standby.

  11. SCP commands RF Amplifier to head mode.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.

8  Etcetera

On some amplifier types it can take minutes for the amplifier to power on, in this case the test may take minutes to complete.
