12267807 - Safe mode startup of the XGD (XPS-SB X axis) failed.Check EMO reset and perform a TPS reset. If this error occurs again, contact your service representative.
  1. Reference extended error message in from CSD error log, and perform all the recommended actions, especially with regards to fiber optics.
  2. Swap dual-fiber optic cable on failing axis with another at front of XPS Control Board (Example: swap Y and X fibers), then reset TPS.

    Illustration 14:  Fiber Optic Cable Connectors

    • If problem moves: Issue is not in the XPS Control Board. Go to next section and swap dual-fiber cable at failing XPS.
    • If problem does not move: Try swapping the fiber-optic transceiver module (also known as SFP shown below) on the failing axis with another at the front of the XPS Control Board, and perform TPS Reset.

      Illustration 15:  Fiber-Optic Transceiver Module (SFP)

      • If problem moves: Fiber-optic transceiver is faulty. Temporarily borrow spare SFP from unused J12 on IRF3 Board to get scanner operational. (Check FRU manual for P/N of SFP.) Otherwise, order replacement XPS Control Board.
      • If problem does not move: XPS Control Board is faulty; order a replacement.
  3. Swap dual-fiber cables at front of failing XPS module, then perform TPS Reset.
    • If problem moves: The issue is not the fiber-optic cable. Go to next section and swap fiber-optic SFP on failing XPS.
    • If problem does not move: The fiber-optic cable may be faulty. Check that it is seating properly into SFP. Inspect and repair or replace.
  4. Swap fiber-optic transceiver module (SFP) at front of failing XPS module with one from another unit, or borrow one from unused J12 Port on the IRF3 Board in CAM Chassis. Perform TPS Reset.
    • If problem moves: Fiber-optic transceiver is faulty. (Check FRU manual for P/N of fiber-optic transceiver.) Otherwise order replacement FRU XPS unit.
    • If problem does not move: Failing XPS module is faulty; order a replacement.
