Discovery MR750w GEM Service Methods
Module Version  2.0,  Version Date  10/19/11

Guided Install Options

1  Under [System Configure]

Date Format Enter the date format to be used by the customer

Weight Unit Enter either Pounds or Kilograms

Keyboard Enter keyboard that is used for specific country

Language Enter language that will be used by customer

Video Card Not used at the introduction for MR750w

Display type Enter the video monitor that will be used for the system

Enable HO Shim Must be No, as High Order Shim is not available for MR750w

Legacy Image Type Should be set to [Yes]

Scan Range (micro-meter) Options are either long or short. Select [short] if there is not enough room for the cable overhang between the rear ped and the customer wall.

2  Under [Hardware Configure]

Field Strength must be 3.0T for 750w

Package Name must be XGD SR120 for 750w

Gradient type must be 8920(XGD)

Resonance Module must be XRMw

Magnet Serial Number Enter actual magnet serial number, first two letters are UA

Table Limit is default, cannot change

Line Frequency Set to either 50 or 60 hz

RF Amp Type must be dual drive for 750w

Governing Body should be set to [fda2]

ISO Vector Z should be 3.0T 70cm magnet enclosure

Magnet Enclosure must be wide open (tight fit)

PAC type Select the proper PAC

RF-Systems Cabinet(RFS) Select YES

Spectro RF Amp type Select [none] if site does not have the spectroscopy option or [AMT] if site does have spectroscopy option.

Scanner channel configuration must be 32 as all MR750w systems are 32 channels

LPCA configuration type Select either [1 P-port on LPCA] which is the GEM configuration or [2 P-port on LPCA] which is the non-GEM configuration
