ICN Infiniband Loopback Test

1  Diagnostic Link

Diagnostics >> VRE Subsystem

2  Purpose

This diagnostic verifies the Infiniband hardware within a single ICN (as part of a multi-ICN system) to rule out hardware issues specific to an ICN by using the Infiniband "traceroute" utility to trace the path between port 1 and port 2 to establish connectivity. Since the hardware cannot be configured electronically for loopback operation, it is necessary to connect an Infiniband loopback cable between the ports for the test. This diagnostic provides a pass/fail indication for the Infiniband hardware within Master ICN. Used with other Infiniband tests (MGD Chassis Diagnostics, Infiniband Communication Diagnostic) to isolate an Infiniband problem.

NOTE:This diagnostic does not apply to a single ICN system. The ICN Infiniband Loopback Test can only be used with a multi-ICN system.

3  Components Tested

VRE (Infiniband hardware)

4  Configuration

When running this diagnostic, it is necessary to change the Infiniband data cable connections on the ICN from their standard product configuration. The original connections must be established after running this diagnostic.

7  Procedure

  1. Identify the Master ICN as follows:

    1. Go to Insite Browser => Utilities => VRE => Power Control

      Do not change any settings on this screen

    2. Note the MAC address for the Master ICN

    3. For the 5127452 ICN's, the MAC address (paper) label is at the rear of the ICN. For the 5127452-3 ICN, the Mac address is located on the front of the ICN.

    4. The Master ICN can then be identified using its MAC address.

  2. At the rear of the Master ICN, locate the Infiniband data ports and remove the cable connected to the Infiniband port1. Note that after disconnecting this cable, the green and yellow LEDs will be off.

  3. Connect the Infiniband Loopback cable as shown in Illustration 1 for the 5127452 and Step  for the 5127452-3.

  4. The green LED next to each Infiniband port should turn on as soon as the cable is connected.

  5. Wait 15 seconds and confirm that the yellow LED next to each Infiniband port illuminates.

  6. Go to Insite Browser => Diagnostics => VRE Subsystem => ICN Infiniband Loopback Test as shown in Illustration 3.

  7. Enter the desired iteration amounts in the fields provided.

    Click [Run] and wait for the test to complete. (See Illustration 4.)

    NOTE:Once you click [Run], do not click anywhere else in the Common Service Desktop until the test is completed. If you need to abort the test prior to its completion, you must click [Stop].

  8. Confirm that the test was successful.

8  Problem/Solution Table

Review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic results are as follows:

Table 3:  Problem/Solution Table

FaultProblem DescriptionGE Field Action
The green LEDs do not display when the Infiniband loopback cable is connected.
  • ICN is Off.
  • Cable is not securely connected.
  • Bad loopback cable.
  • Master ICN system software is not running.
  • Make sure the ICN is powered at Utilities => VRE Power Control.
  • Reconnect cable.
  • Replace loopback cable.
  • Make sure the Master ICN is running.
Yellow LEDs do not display within 15 seconds of connecting the Infiniband loopback cable.
  • Connection is not on Master ICN.
  • Master ICN system software is not running.
  • Connect on Master ICN.
  • Make sure Master ICN is running.
Test FailedMaster ICN Infiniband hardware problem.Replace Master ICN.

9  Finalization

  1. Remove the Infiniband loopback cable from the Infiniband ports on the rear of the Master ICN.

  2. Reconnect the original Infiniband data cable to port 1.

  3. Perform a TPS reset.
