WARNING
ELECTRICAL/RF BURN HAZARD.
RF BURNS Can Occur AS A RESULT OF DISCONNECTING HELIAX CABLES WHILE THE SYSTEM IS SCANNING.
PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3, J4, or J22 ON THE RF AMP BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE AND THE RF ENABLE SWITCH IS IN THE “OFF” POSITION.

CAUTION
Possible Equipment Damage.
Operating the RF amplifier with improper loads may permanently damage the amplifier.
Do not operate the RF amplifier with an improper load connected to its output.

CAUTION
Possible Equipment Damage.
Coils and phantoms in the magnet bore that are not connected to the system can cause equipment damage.
Prevent coil and associated switch damage by removing all phantoms and hardware (i.e., head coil, surface coil) from the magnet bore unless otherwise instructed.

3  Procedure

3.1   Body UPM Functional Check

RF output must be calibrated and UPM calibration must be completed for selected Body channel before performing these functional checks. When running functional check for Body channel 1, remove the input for channel 2 (J21). When running functional check for Body channel 2, remove the input for channel 1 (J14).

3.1.1  Body UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection. See Illustration 1. Ensure Switches SW2 and SW3 are in their respective Disable positions.

    (Step Details)

  1. Place the RF ENABLE switch on front of exciter in the DISABLE (Down) position.

  1. Install the dummy load.

    1. If checking Body Channel 1, remove the Body Heliax cable from BODY RF OUT / J4. If checking Body Channel 2, remove the Body Heliax cable from BODY RF OUT / J22.

    1. Connect the 35 KW RF dummy load from the Power Measurement kit into J4 or J22

    1. Plug the power supply on the dummy load into 110 VAC service outlet in the System Cabinet.

      (Step Details)

  1. Place the RF ENABLE switch in the ENABLE (Up) position.

3.1.2  Setting up Software Tool to Functional Check UPM - Body Channel Functional Check

  1. On the scanner operator control panel (OCP) press [Align on].

  1. Move the cradle to place the Laser alignment light on the center of the table.

  1. Press Landmark.

  1. Press Advance to Scan.

  1. Start the RF/UPM tool:

    1. In proprietary mode, [Click here to start tool] from the Calibration tab.

      (Step Details)

    1. For the Class A service tool:

      1. From the Common Service Desktop, select the Calibration Tab.

      1. Select the [UPM Tool] from the calibration menu and select [Click here to start this tool].

      1. Illustration 3 shows an example of the UPM tool.

        (Step Details)

  1. For Nuclei select [1H].

  1. For RF Chain, select [Body Ch 1] or [Body Ch 2].

  1. For Task, select [UPM Func Chk].

    (Step Details)

  1. Select the [Start] button then click [YES] in answer to the setup question.

    (Step Details)

  1. The user will be prompted during test execution. The following illustrations show an example of the pop up and error log that should be seen. Verify the error log and click [Yes] if an error message is seen.

    (Step Details)

  1. Proceed to the next logical step in the RF/UPM calibration process, or proceed to Head UPM Functional Check.

  1. If functional checks fail, refer to Universal Power Monitor (UPM) Troubleshooting.

3.2   Head UPM Functional Check

3.2.1  Head UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection in the Pen Cabinet, see Illustration 7. Ensure switches SW2 and SW3 are in the TR DISABLE and DD DISABLE positions.

    (Step Details)

  1. Switch RF ENABLE on front of the exciter to the Disable (down) position.

  1. Install the dummy load.

    (Step Details)

3.2.2  Setting up Software Tool to Calibrate UPM - Head Forward Power

  1. Place the head coil and connect it to the LPCA.

  1. Landmark on the cradle where the head coil is.

  1. On the operator control panel (OCP) press Advance to Scan.

  1. Refer to Setting up Software Tool to Functional Check UPM - Body Channel Functional Check, Step 5 to start the Service browser.

  1. For Nuclei select [1H].

  1. For RF Chain select [Head].

  1. For Task, select [UPM Func Chk].

  1. Select the [Start] button.

  1. On the Head Coil Setup OK screen, click [Yes] when the head coil is ready to go.

    (Step Details)

  1. The user will be prompted during test execution. Illustration 5 and Illustration 6 show examples of the pop up and error log that should be seen. Verify the error log and click [Yes] if an error message is seen.

    (Step Details)

  1. To proceed:

    1. If the test passes, select [Quit] from the UPM Main Window.

    1. If the test fails, refer to Troubleshooting UPM.

3.3   Finalization

  1. Switch RF ENABLE on front of exciter to the Disable (down) position.

  1. Remove the cables and measurement equipment.

  1. Reattach the Head and Body heliax cables.

  1. To re-enable fault detection, set switch SW2 and SW3 to their respective Enable positions.

  1. Switch RF ENABLE on the front of the exciter to the Enable (up) position.

  1. Complete a TPS reset and do a test scan.

  1. Any failure after Troubleshooting is complete will require a re-calibration of the UPM system. See Universal Power Monitor - Head and Body Setup and Calibration.

3.5   UPM Theory

The Universal Power Monitor calibration parameters found in the UPM configuration file (/export/home/signa/tools/upm/upm.config) are used in the Calibration/Functional Check tasks. This configuration file is accessible from within the UPM Calibration tool from the File menu > View Config option. These values can be used during troubleshooting to help determine where the power monitor is tripping (if at all). The UPM configuration file shown in Illustration 11 contains the default configuration values for all of the UPM parameters. This screen is just for reference, as the content and values will be different based on the system type. The final UPM digital attenuator values are written to the UPM calibration configuration files (Upm1Cal.cfg, Upm2Cal.cfg) located in directory w/config.
