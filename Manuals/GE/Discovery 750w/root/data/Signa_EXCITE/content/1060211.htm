4.1.2   Probe/P Tuning Procedure

  1. Landmark the MRS phantom to prevent PSD download errors.

  1. Position the phantom on the head support in the single channel head coil with the temperature strip visible. Do NOT use the head loader with the MRS phantom. Use the foam support for quick alignment instead of using foam padding to center the phantom in the head coil. Phantom-centering (up/down/left/right/in/out) within 5 mm of the Isocenter in all directions is important.

  1. Run a 3-plane localizer to make sure the MRS phantom is properly centered. If necessary, an additional 3-plane localizer should be performed. Once the phantom is centered, make sure the phantom remains stationary for at least 5 minutes before the start of any PROBE calibration scan. (This is to allow the fluid in the phantom to reach equilibrium and to minimize the effects of long-term eddy currents.)

  1. Start the Probe/P Tune Tool.

    NOTE:Restricted Service tools available to GE Field Service. Make sure the service key is installed.

    • In the Common Service Desktop, go to Calibration >> Install and Calibration Wizard. Select [Click here to start this tool](see Illustration 4).

    • Once the Install and Calibration Wizard (ICW) starts, select Probe/P Tune from the menu (see Illustration 5).

    • Review and okay the pre- and post-dependencies, and select [Click here to start this tool] to start the procedure.

    NOTE: If you are unable to start the Restricted Service tools, use the non-proprietary method described below.

4.2  Probe/SV SNR Procedure

The MRS Phantom (without the loader) must be used for the Signal-to-Noise Ratio (SNR) procedure. Enter the most visible number of the temperature strip as a Control Variable (tempC).

4.2.1  Probe-S SNR Procedure

NOTE:The MRS phantom must be used for all SNR procedures. Position the MRS phantom centered on the head coil. Do NOT use the tuning ring or head loader. Use foam padding as necessary to center the phantom in the Head Coil. Phantom-centering (up/down/left/ right/in/out) is important. Run any head localizer to ensure the phantom is properly centered before beginning the Probe- SNR procedure.

  1. Select [Create new worklist].

    1. Patient ID: geservice

    1. Name: probe snr

    1. Weight (lb.): 111

    1. Select [Show All Protocols].

    1. Select Protocol Library option [Service] and select [Other] tab. Scroll through the list to the protocol [Probe-S SNR]. Select [Series 1] and [Accept].

    1. Make sure graphic RX region of interest (ROI) is a 2cmx2cmx2cm voxel at iso-center (i.e., S10-I10; R10-L10; A10-P10).

    1. Select the test to run and click the arrow in between the two list boxes to add the test to the Multi Protocol Basket.

  1. Click [Accept].

  1. Click [Start Exam].

  1. Click [Save Rx].

  1. Navigate to Research options.

    1. Click the arrow button next to the [Scan] button. A drop down menu will display (see Illustration 7).

    1. Select Research to find research options.

    Illustration 7:  Research Options

  1. [Display CVs]. Highlight the CV Name and verify the following:

    CV Name: opfov<Enter>, CV Value: 240<Enter> - (default in protocol)
    CV Name: opte<Enter>, CV Value: 30000<Enter> - (default in protocol)
    CV Name: optr<Enter>, CV Value: 2000000<Enter> - (default in protocol)
    CV Name: tempC<Enter>, CV Value: ##<Enter> (most visible number of temperature strip)
    CV Name: deltax<Enter>, CV Value: verify per tuning results<Enter>
    CV Name: deltay<Enter>, CV Value: verify per tuning results<Enter>
    CV Name: deltaz<Enter>, CV Value: verify per tuning results<Enter>
    NOTE:To view the tuning results, open a command window and type in /usr/g/caldir/probep_cal.log to view log file.

  1. Click [Accept].

  1. Click [Research], then[Download].

  1. Click [Scan] (the system Auto Prescans then Scans).

  1. Select Message Window, which is located in the bottom-center of the scan desktop. Record R1, R2, TG, AX, (if present, record FWHM, WS Angle, WS%) on the Data Sheets. Close the window.

  1. SNR is not annotated on the auto viewer. Access the image from the Browser on the [Display (Advantage Windows) Desktop]. On this desktop, click on [Browser], [Sort], and [Sort examinations by date].

  1. Once you have done this, the most current exams display in the upper window. Select the most current Image from the most current Series from the lower window and click on [Viewer].

  1. Select [Format] then click on the single box (in the upper left corner).

  1. Record the displayed results of "CR SNR" on the Data Sheets for Probe-S SNR.

  1. Retain a hard copy of the Probe SNR image for reference. This can be used to make a comparison of the Cr SNR from the most recent Probe-s and Probe-p scans with the Cr SNR previous/future scans.

    NOTE:It is imperative that a minimum of three scans be performed (back-to-back) to get an estimated average Probe-S SNR.

  1. Repeat Step 9 through Step 15 three times, to get an average Probe-S SNR (C-SNR).

  1. Probe-S SNR specification minimum is 50.0 Cr SNR for 3.0T.

4.3  Help

This section contains Illustrations of Probe SNR Spectra, both incorrectly tuned and correctly tuned to familiarize the user with what a good spectrum looks like. During tuning or SNR troubleshooting, it may be necessary for a site to back up the original echoloc.dat file. This backup process requires renaming the file, otherwise, it will be overwritten during the tuning calibration. Additional information can be obtained concerning the cause of an Auto-Water Suppression (AWS) failure by logging the messages generated during the Probe APS. A site may be required to send Probe SNR raw data to an expert for review. This section explains the P raw file location process and how to transfer it.

4.3.1  Example SNR Spectra

Errors in the Probe Tuning Calibration Procedure can introduce changes in the appearance of the resulting Probe SNR spectra. This section contains example spectra from a Probe-P SNR protocol using the MRS phantom. Illustration 8 shows a correctly-tuned spectra. Pay particular attention to the base (left and right) of the NAA (NA) peak; this is the largest peak located at the center of the spectrum.

4.3.2  Directory Creation

  1. On the MR Service Desktop, click on [C Shell].

  1. Create a directory to hold the log file by entering the following:

    cd /usr/g<Enter>

    mkdir probe_data<Enter>

    cd probe_data<Enter>.

  1. Log in to the Multi-Generational Data (MGD) Applications Gateway Processor (AGP) and direct the output to a file and to the screen. Use the pipe symbol (|) on the keyboard where indicated below. Local is the lowercase “l” key.

  1. rlogin agp | tee agp_log<Enter>.

  1. Log in using the user name agp , then press <Enter>. When prompted, enter the password agpservice and press <Enter>.

    At this point logging is running. DO NOT type anything in the AGP window. Watch the AGP messages appear on the screen; everything is logged into the file entered after the tee command (tee agp_log). This file is overwritten each time.

  1. Select the Rx Manager icon.

  1. Run Auto Prescan (APS).

    NOTE:No data appears in AGP_LX> during APS.

  1. Select the Service Desktop Manager icon and use the scroll bar to review the log.

  1. When done, type logout in the AGP window. This disconnects the AGP from the C Shell. A message confirms the logout Connection closed.

  1. To view the log file created, verify that the current directory is /usr/g/probe_data.

  1. Type: more agp_log and press <Enter>.

  1. Close the C Shell when you’re done.

  1. The log file can be sent to the OLC, or e-mailed to whomever the site is working with to resolve any problems.

    NOTE:During the troubleshooting process, the site may be required to identify the P raw data files generated when Probe SNR was performed. These files may be helpful in determining a reason for an SNR failure.

4.3.3  P Raw Data File Location

This portion of the procedure should be performed after running a Probe SNR protocol to facilitate P raw file identification.

  1. At the Service Desktop Manager, click on [C-Shell...].

  1. At the prompt enter the following:

    cd /usr/g/mrraw<Enter>

    ls -lt P*| head<Enter>

  1. The most recent P files will be displayed. The most recent P files will be displayed on the top of this list. Record the Probe raw data file (P####.7). The size of the P file is ~449584.

  1. Close the C Shell when finished.
