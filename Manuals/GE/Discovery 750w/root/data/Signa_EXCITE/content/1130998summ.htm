1  Procedure

1.1   Master Boot Record (MBR) Cleanup

  1. Shut down the Host Computer.

  1. Disconnect the SCSI tower.

  1. Power on the Host Computer.

  1. Insert the OS DVD and type rescue at the OS install prompt.

    (Step Details)

  1. Type root at the Rescue login: prompt.

    (Step Details)

  1. When the rescue prompt appears, type the following command and press [Enter]:

    (Step Details)

  1. When the rescue prompt appears again, type the following command and press [Enter]:

    (Step Details)

  1. When the rescue prompt appears again, type the following command and press [Enter]:

    (Step Details)

  1. Type halt to shut down the system.

  1. Reconnect the SCSI tower.

  1. Continue with LFC procedure.

1.2   Complete Disk Wipe

Follow the below procedure only if the MBR procedure in Step  fails to address the problem

  1. Shut down the Host Computer.

  1. Disconnect the SCSI tower.

  1. Power on the Host Computer.

  1. Insert the OS DVD and type rescue at the OS install boot prompt (see Step ).

  1. Type root to login at the Rescue login: prompt (see Step ).

  1. When the rescue prompt appears (see Step ), type the following command and press [Enter]:

    (Step Details)

  1. When the rescue prompt appears again, type the following command and press [Enter]:

    (Step Details)

  1. When the rescue prompt appears again, type the following command and press [Enter]:

    (Step Details)

  1. Type halt to shut down the system.

  1. Reconnect the SCSI tower.

  1. Continue with the LFC procedure.
