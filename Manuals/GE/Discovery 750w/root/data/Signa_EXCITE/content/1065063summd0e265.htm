• If coherent noise exists, then the Pin Diode Test is invalid, and this indicates a problem. See Table 2 for potential coherent noise issues.

  • If coherent noise does not exist, perform the following calculation: C=100*(STD_A-STD_B)/STD_A

  • If C is greater than ±1.5%, Pin Diodes may be faulty.
