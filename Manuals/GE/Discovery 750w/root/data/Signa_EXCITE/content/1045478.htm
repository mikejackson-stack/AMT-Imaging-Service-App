2  Overview

The Installation and Calibration Wizard (ICW) is designed to guide the user to follow the proper sequence of installation workflow, or allow access to calibrate software after system installation is completed.

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

Options keys installation should be performed prior to bringing up the ICW for the first time.

4  Procedure

4.1  Starting ICW

  1. Insert the Service Key.

  1. Launch the Service Browser.

    1. Click the Tools icon.

    1. Click the [Service Browser] button and then select [Start] to display the Common Service Desktop.

  1. Click the Calibration tab.

  1. Click [Install and Calibration Wizard] and the link: Click here to start this tool.

  1. ICW will launch the mode that corresponds to the system status: either Install or Maintenance mode. See appropriate section below for details.

4.2  Install Mode - New System Installation

Clicking the [Help] button in the lower right corner will open the service document for the active calibration step.

  1. Ensure all options purchased by the customer are installed. A pop-up similar to the one shown in Illustration 1 will display summarizing the results. Review the status of these option keys, and confirm the correct configuration.

    1. Click [Quit] if the site configuration is unknown or does not match the option key status.

    1. If the configuration is correct, click [Continue].

    NOTE:The Option Key Check is only done the first time the tool is used. Any change to the option key status after the ICW has started will not be registered by the tool.

    Illustration 1:  ICW Alert Pop-Up

  1. Some calibrations have certain dependencies.

    To understand the dependencies that the tool uses during Install mode, see the first illustration below. (Machine data refers to data stored on the system.)

    Illustration 2:  Install Mode Dependency Matrix

    Illustration 3:  Advancing Through Manual Items During Installation

  1. For the manual tasks, acknowledge the completion of each task listed by clicking the box next to it, then clicking [Submit].

  1. For those tools (calibrations) with machine data, click the link: Click here to start this tool. When the tool interface displays, follow the links (available in Calibrations) for specific instructions on setting up and running a particular tool.

  1. When the calibration is completed or aborted, close the tool.

  1. Click [Check Status]. This will check the tool’s pass/fail status. If the tool passes, the next calibration in the flow will become active. If the tool fails or was incomplete, the tool will turn red and the user will be unable to continue until that calibration passes.

  1. The ICW will remain in Install mode until every task listed on the left side (shown in Illustration 3) is successfully completed. After completing all tasks in Install mode, exit the ICW. (The next time the Install and Calibration Wizard is launched, it will open in Maintenance mode.)

4.3  Special Considerations

  1. Relaunching Machine Data Calibrations:

    If the user tries to launch a calibration in the ICW after it already passed, the system will warn the user that the selected calibration may be dependent on other calibrations. (See illustration below.) The user may want to rerun the calibrations (pre-dependencies) listed prior to rerunning the selected calibration. While not enforced by the interface, this is highly recommended.

    Illustration 4:   Warning Message for Rerun on a Passed Calibration

  1. Tool Failures:

    If a task is incomplete or a calibration fails, the interface will turn the name of that task/calibration red and the message shown below, The selected test has failed. Please rerun the tool will display. Post dependencies will not become available until the task/calibration passes.

4.6  Maintenance Mode

After all steps are successfully completed in Install mode, the next time the ICW is launched, it will be in Maintenance mode. In Maintenance mode, no calibration order is enforced. If a selected calibration is affected by or affects any other calibration, a pop-up message displays and affected calibrations display in bold. (See the illustration below.)

Illustration 7:  Starting Maintenance Mode

  1. Click [Yes] to acknowledge the Pre and Post Dependencies. All pre-dependencies are unbolded, and the selected tool becomes active.

  1. Perform all necessary setup prior to launching the tool. (See the illustration below for instructions on how to start calibrations in the Maintenance mode.)

    Illustration 8:  Running Calibrations in Maintenance Mode

  1. When [Check Status] is clicked, one final pop-up message alerts the user to the post dependencies.

    1. Clicking [Acknowledge] will unbold the post dependencies.

    1. Clicking [More] will display the Dependency matrix used to determine the pre and post dependencies. (See Illustration 2.)

    • For troubleshooting purposes, before performing a certain calibration (or task), it is beneficial to identify the pre-dependencies related to that calibration and consider performing them. If pre-dependencies are not run, the system will not be negatively affected.

    • After the ICW is launched in Maintenance mode, it will assist by keeping track of calibrations that were run during the current session by changing the font color of the calibration name to blue. As long as the ICW remains open, it will track all calibrations for which [Check Status] was clicked.

5  Finalization

  1. To exit from the ICW, select Quit from the File menu.

  1. When the pop-up box shown below displays:

    Illustration 9:  Exiting ICW

    1. Click [No] to remain in the ICW.

    1. Click [Exit] to exit from the ICW without performing a SaveInfo.
