2  Purpose

The ERF Board Level Diagnostic tests the circuitry internal to the ERF board. The test is run from the AGP board that accesses the ERF board over the cPCI bus.

This diagnostic is only run if the system has an ERF board installed. This board is optional depending on customer purchased options, such as MNS.

3  Components Tested

The entire board is tested with the exception of the fiber modules.

4  Requirements

  • Standard configuration of the board (ERF is connected to IXG, clock daisy chain, refclock to exciter)

  • If the power has been cycled, a TPS reset is required.

6   Test Sequence

  1. Select ERF-1 BLD from the Data Acquisition screen.

  2. Click [Run].

  3. Review the Test Results table to see if the diagnostic passed or failed.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.
