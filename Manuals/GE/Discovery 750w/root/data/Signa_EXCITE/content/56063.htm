Power-up Tests

Power-up Tests examine Gradient Processor (GP) board interrupts, memory, and register access. They are run:

  • Each time the system is brought up to the applications level

  • Each time the MGD is reset, and

  • The first time the Gradient Driver Tests are invoked from the Diagnostic menu on the Service Desktop

When the MGD code is loaded the first time, the MGD resets (TPS Reset). All subsequent Run Diags sessions do not run Power-up Tests.

For a complete description of the Power-up Tests, see the procedure for Gradient Driver Power-up Diags.
