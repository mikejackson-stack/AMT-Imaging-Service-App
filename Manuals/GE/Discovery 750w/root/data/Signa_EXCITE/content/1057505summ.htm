Printer Configuration for Film Composer

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Configuring a DICOM printer for Film Composer

  1. Boot system to Application level.

  1. Start the Mini-Viewer and select [Film Composer] from the menu.

  1. Select [Configure] option on the Film Composer GUI. See Illustration 1,

    (Step Details)

  1. Click [Add].

  1. A new GUI will appear called “Type of Laser Camera”. Click [DICOM.].

  1. A list of possible printers will appear. Select the printer being used. See Illustration 2.

    (Step Details)

  1. After selecting the camera, the [Configuration GUI] will appear. Fill in necessary information. When done, click [OK] to configure the printer. For the Codonics Printer see Table 1. Also see Illustration 3.

    (Step Details)

1.2   Configuring Postscript Printer for Film Composer

  1. Boot Signa to Application level.

  1. Start the Mini-Viewer and select [Film Composer] from the menu.

  1. Select [Configure] option on the Film Composer GUI. See Illustration 1.

  1. Click [Add] option from the Remote printer configuration GUI. See Illustration 4.

    (Step Details)

  1. Then select Postscript camera to be configured.

  1. Enter the applicable information in the PS printer configuration parameters GUI. See Illustration 5.

    (Step Details)

  1. Click [OK] to complete the printer configuration.

2  Finalization

  1. After camera configuration, create a test film.

  1. Ensure the system is working before turning over to customer.
