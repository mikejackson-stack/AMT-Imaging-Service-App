Installing Codonics Printer for BrainWave or SAGE

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

Applications Software is installed and configured.

-

-

2  Procedure

  1. If applications are up and running, restart the computer by clicking [System Restart] and [OK].

  1. From login screen, login as root . Do not bring up Guided Install.

  1. Right Mouse click and bring up [Configure Printer](see Illustration 1).

    (Step Details)

  1. Click on the [New] option (see Illustration 1).

  1. Click on [Forward] The screen shown in Illustration 2 appears.

    Illustration 2:  Add a New Print Queue

  1. Enter name of the Codonics Printer as GENNavprntr (case sensitive) (see Illustration 3). For BrainWave, you must use the name of GENNavprntr. For SAGE option, the name is not important. To proceed, click [Forward].

    (Step Details)

  1. Select Queue type as Networked UNIX (LPD) as shown in Illustration 4. To proceed, click [Forward].

    Illustration 4:  Queue Type

  1. Enter hostname or IP address for the Server, (example IP is 10.1.11.11).

  1. Enter queue name as 2.a-cvp, then select [Forward].

  1. For Printer Model, select Postscript printer, as shown in Illustration 5. To proceed, click[Forward].

    Illustration 5:  Printer Model

  1. At the screen shown in Illustration 6, click [Finish].

    Illustration 6:  Finish and Create the New Print Queue

  1. At the screen shown in Illustration 7, click [Yes] to apply changes and print a test page. The printer test page should print successfully at this time.

    Illustration 7:  Print Test Page

3  Finalization

  1. To verify SAGE printing, open the SAGE option. Select [File] then [Print]. A GUI will appear. In the Printer text field, remove the default printer and enter the name of the printer that was used in Step 6.
