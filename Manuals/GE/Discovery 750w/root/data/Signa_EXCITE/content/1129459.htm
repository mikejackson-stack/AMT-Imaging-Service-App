PSE to IXG Datapath

1  Diagnostic Link

Diagnostics >> System Function >> Acquisition/Pulse Generation >> Data Acquisition

Diagnostics >> Hardware Location >> PGR Cabinet >> CAM >> Data Acquisition

Illustration 1:  PSE to IXG Datapath

2  Purpose

Tests the data path between the PSE and the IXG boards.

3  Components Tested

  • AGP

  • IXG

  • PSE

4  Requirements

  • AGP

  • IXG

  • PSE

5  Block Diagram

If you system has the MNS option, Illustration 2 would show the ERF on the PCI bus and RRX-1 and RRX-2 would connect through the ERF board instead of the IXG board. The data acquisition for this diagnostic test performs the same for both configurations.

Illustration 2:  PSE to IXG Block Diagram without MNS

6  Test Sequence

  1. Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

  2. Click [Run] to initiate the test.

    Other than Test Iterations, do not change the Test Options settings from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings need to be changed.

The test executes in these steps:

  1. The AGP configures the PSE to play out a PSD with a test data pattern.

  2. The PSE sends the test data out on to the sequence bus.

  3. The IXG captures the data and stores it in a bypass FIFO queue.

  4. The AGP reads the data in the FIFO queue and compares it to the original data.

7  Expected Results

Output values are judged pass or fail. In the event of failure, details can be found in the GE System Log.

You can click the 1st Error number to see the nature of the error; however, GE recommends that you view the GE System Log to see all the errors that were recorded.

NOTICE
Prior to scanning, a TPS reset is required.
