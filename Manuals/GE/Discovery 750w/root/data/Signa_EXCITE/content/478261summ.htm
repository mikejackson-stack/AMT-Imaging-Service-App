2  Procedure

NOTICE
The software load can be corrupted if the following conditions are not done:

  • Check Info Script executed.

  • DASM powered off.

  • System Monitor turned on.

  • SCSI tower on.

 
 

  1. Insert the MR PC LINUX CD (current revision) into the CD drive of PC.

  1. Reboot the computer.

NOTICE
The Proper OS Load command must be entered in order for the mouse to be detected and for foreign keyboards. At the Boot prompt type one of the following commands based on your Keyboard type:

  • English Keyboard: GEHC-MR<Enter> (GEHC dash MR, no spaces).

  • French Keyboard: GEHC-?R<Enter> (GEHC dash question mark R, no spaces).

  • Portuguese Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces)

  • Italian Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).

  • Spanish Keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).

  • German Keyboard: GEHCβMR<Enter> (GEHC Beta symbol MR, no spaces).

  • Swedish Keyboard: GEHC+MR<Enter> (GEHC plus sign MR, no spaces).

 
 

  1. At the boot: prompt type GEHC-MR or appropriate input for keyboard from the list in the Notice above. Then push the <Enter> key.

    (Step Details)

  1. Remove the CD from the drive after the drawer opens. Do not insert the Applications CD at this time!

  1. When OS Software is properly loaded,Illustration 3 appears.

    (Step Details)

  1. Press <Enter> to continue.

  1. After Pressing <Enter>, the PC reboots.

  1. A terminal window appears after 2 minutes.

  1. The OS software load is now complete, Proceed to MR_APPS Software Load.
