Loading or Deleting Proprietary Software

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Loading Proprietary Software

Shut down all applications before loading the Restricted service or Advanced service media. This media should not be loaded with applications software running.

  1. Restart the system and log in as root with the Password: operator.

    (Step Details)

  1. Open the Guided Install and select FE Mode and the link: Click here to start this tool.

    (Step Details)

  1. Insert the Service Software media and from the left navigation menu, select [Service SW/InSite] and click [Load Restricted Software] or [Load Advanced Software].

    (Step Details)

  1. When the proprietary statement window displays, read the proprietary statement and click [Accept] three times to continue.

    (Step Details)

  1. When the message displays: Please Insert CD-ROM to Install Restricted Service, click [OK]. The Restricted software load in progress window displays.

    (Step Details)

1.2   Deleting Proprietary Software

To delete proprietary software, proceed as follows:

  1. Open Guided Install and select FE Mode and the link: Click here to start this tool.

  1. From the left navigation pane of the Guided Install, select [Service SW/InSite].

  1. Click <Secure System> to delete proprietary software.
