2  Overview

The Multi-Coil Quality Assurance (MCQA) Tool is a new tool that will simplify data acquisition and analysis of the Signal-to-Noise Ratio (SNR) for surface coils. It will aid in detecting dead coil elements, as well as developing improved Integrated Signal-to-Noise Ratio (ISNR) specifications for all multi-coils, independent of scanner instabilities.

The tool does not rely on Region of Interest (ROI) placement as other SNR tools have in the past. Instead, it chooses slice locations based on coil geometry, acquires one Spin Echo Image, and turns off Radio Frequency (RF) to gather a noise image. The noise mean of the 2D, noise-only image is subtracted from the 2D intermediate image.

The summed signal of the 2D intermediate image minus noise mean is calculated, and this signal is divided by the Standard Deviation of the Noise for all pixels of the noise only image resulting in the ISNR. See the formula below.

    4  Procedure

    4.1  Multi-Coil Quality Assurance Tool - New Version Screen I/O

    All RF Coil related tests must be run on a system that is well calibrated and passes all system tests. The system should have passed Install In Spec (IIS), especially white pixel, correlated noise, and Multi-Coil-Receive (MCR) tool.

    1. If possible, run the Multi-Coil Chain Receive (MCRv) tool to validate the receive chain function before running the MCQA tool. If the MCRv tool has missing or failed results, the MCQA tool will detect them and a pop-up will display asking the user to continue.

    1. From Common Service Desktop, open the Service Browser, select [Image Quality], Multi-Coil QA Tool and Click here to start this tool.

      Illustration 2:  Multi Coil QA Tool Screen

    1. Upon startup, the MCQA tool will attempt to identify the coil connected to the system.

      • If successful, it will be automatically list the connected coil in the Current Coil field.

      • If the coil is not recognized, a message displays indicating the coil needs to be configured.

      Illustration 3:  Current Coil Field

    1. Upon startup, the MCQA tool will identify the coil connected to the system.

      • If successful, it will automatically list the currently connected coil in the Current Coil field. Select the coil to be tested from the drop-down list.

      • If the coil is not recognized, a message displays indicating the coil needs to be configured. (The Help menu will pop up a new window to display the MCQA setup procedure for the GEM coils only.)

      Illustration 4:  Current Coil Field

    1. If a recognized coil has the capability of using either a Legacy Phantom Set or a Unified Phantom Set, a pop-up will display prompting the user to make a selection. Click [OK] to continue.

      Illustration 5:  Confirmation Pop-Up

    1. Follow the guidelines in the NOTE below for Phantom Set selection. (The illustration is an example of an active drop-down list for phantom set selection.)

      NOTE:The Phantom Set field varies depending upon the coil that is plugged into the system.

      • If the Phantom Set field provides an active drop-down list, select the phantom choice based on the phantoms used during setup for the MCQA test as described in the coil’s service manual.

      • If the Phantom Set field is grayed out (unselectable), the tool has automatically selected the phantom set based on the coil used.

      Illustration 6:  Phantom Set Drop-Down Menu

    1. The current coil field will be automatically filled in based on the Coil ID of the coil connected to the LPCA. Enter the serial number of the coil being tested in the Coil Serial Number field.

    1. Enter the serial number of the coil being tested in the Coil Serial Number field.

    1. Click [Start] to begin the automated test shown below. (Depending on the number of test locations (coil complexity), the test may take from 3 to 20 minutes.)

      Illustration 7:  Begin Automated Test

    1. When a confirmation pop-up displays asking the user to continue, click [Yes].

      Illustration 8:  Confirmation Pop-Up

    1. Upon startup, this message displays: Phantom placement and coil landmarking are critical for repeatable results. If the landmark was set correctly and no air bubbles exist in the phantom, click [Yes] to continue.

      Illustration 9:  Startup Message

      NOTE:The Status window of the MCQA tool GUI will continuously update providing information on what the tool is doing at any point in time. A time bar (shown below) displays showing the approximate total test time, elapsed time and percent complete.

      Illustration 10:  Status Window

    1. When the test is completed, test results display on the screen (shown below). The Pass/Fail status field will display PASS if all coil elements are functioning properly. If any coil element displays FAIL, call the GE Service Representative for coil repair.

      Illustration 11:  Test Results

      The MCQA Tool GUI displays FAIL for reasons including, but not limited to:

      • Bad coil element

      • Incorrect phantom used for testing

      • Incorrect positioning/placement of phantom

    1. Click [Quit] to exit the MCQA tool.

    4.2  Viewing Report Results

    1. After running the Multi-Coil QA test, select [View Report Details] to review the results. The [MCQA Viewer] (shown below) will display.

      • The Results File and Pass/Fail Status are listed across the top of the viewer.

      • The test results display in the Results window on the left side of the viewer.

      NOTE:To review past results: select File, Open Results File, and the desired coil results file.

      Illustration 12:  MCQA Results Viewer

    1. To review the results of a different test for this same coil, select the appropriate number from the Test # scroll box near the lower portion of the screen.

    1. To graph the data, select one of three choices: Isig, Noise or Isnr. radio buttons. (The corresponding results will display in the window to the right. The integrated signal, noise, or integrated SNR values are listed on the vertical axis with the images along the horizontal axis.)

    1. To graph the Isnr Specification values in addition to the data, select the Isnr Specs box below Test # in the lower portion of the viewer.

    1. The graph results will automatically scale according to the data values. To manually change the vertical scale, enter the value into the Ymax and/or Ymin fields at the top right of the viewer.

    1. To view all the Signal or Noise Images, select [View Signal Imgs] or [View Noise Imgs], and an image viewer will display with one image per coil element, ordered left-to-right and top-to-bottom as shown in example below.

      Illustration 13:  Example of Signal and Noise Images

    1. From the MCQA Viewer (Illustration 12), select [Plot noise CC] to display a 3D plot of the noise cross-correlation data for the results being viewed. (The data shows the relative cross correlation of noise between receiver channels. Green data is a one-to-one correlation; red data are correlations above the threshold. See the illustration below for an example plot.)

      NOTE:There are currently no specs for the noise cross-correlation data. It may be possible to determine patterns per coils and set specs as more data is collected.

      Illustration 14:  Signal and Noise Images

    1. Past MCQA results are stored on the system, which allows for trending of ISNR data over time. On the MCQA Viewer (Illustration 12), select [Trend Data], and the MCQA Trend Viewer will display.

      Illustration 15:  MCQA Trend Viewer

    4.3  MCQA Trend Viewer

    Every time an MCQA test is completed, a new results file is generated. These results can be graphically trended within the MCQA Trend Viewer (shown above). All the Results Files available for trending are listed in the window to the left of the screen.

    1. Select the Test # and Image # of the desired data for review from the related scroll boxes.

    1. Choose the Isig, Noise or Isnr radio button that corresponds with the desired graph.

    1. The data will display over time (number of tests run). To change the vertical scale, enter new values into the Ymax and/or Ymin box at the top of the screen.

      NOTE:Statistics pertaining to the existing data will be provided in the lower left of the viewer.

    5  Finalization

    1. Select [Close] to exit the MCQA Trend Viewer and MCQA Results Viewer.

    1. Click [Quit] to exit the MCQA tool.

    1. Close any Image files still open on the screen.

    1. Remove all coils and phantoms from the system bore.
