SCP to CAN DP

1  Diagnostic Link

NOTE:This diagnostic has been removed for systems with 20.1 software or higher. This diagnostic is only present for 20.0 systems.

Diagnostics >> System Function >> Acquisition/Pulse Generation >> Data Acquisition

Diagnostics >> Hardware Location >> PGR Cabinet >> CAM >> Data Acquisition

Illustration 1:  Data Acquisition Screen

2  Purpose

This diagnostic tests the communication between the SCP board and the CAN PMC daughter board attached to the SCP.

3  Components Tested

None

4  Requirements

The test will not send out any CAN packets, but does require SCP applications to be loaded.

5  Block Diagram

None

6  Test Sequence

  1. Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

  2. Click [Run] to initiate test.

    The diagnostic will read some registers from the CAN board and determine whether or not the drivers are correctly communicating between the two boards.

    NOTE:Other than Test Iterations, the Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.
