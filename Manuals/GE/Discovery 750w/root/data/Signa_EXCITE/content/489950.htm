2  Overview

Verify SaveInfo Data is used to verify content of SaveInfo media to the original data on the system disk drive. The program firsts checks that all files are present on the SaveInfo media and then if check sums match.

Verify MOD compatibility to host PC and how to convert data from MOD to CD/DVD.

ConditionReferenceEffectivity

4  Procedure

  1. Insert your already created SaveInfo MOD or DVD into the appropriate drive if it's not already there.

  1. At the host computer, go to the Service Desktop and open the Service Browser if it's not already running and start the Guided Install tool in FE Mode. See the illustration below.

    Illustration 1:  Starting Guided Install From The Service Browser

  1. In Guided Install, go to the Save / Restore screen and start the verification process. See illustration below.

    Illustration 2:  Starting SaveInfo Verification

  1. The following dialog box opens prompting you to select the type of media being used for SaveInfo.

    Illustration 3:  Select SaveInfo Media

  1. The tool will verify the data on the media with that on the system hard drive. If no media is present, the you see an error message. While the media is being checked, the popup shown in the following alert box displays. The process takes about twi minutes.

    Illustration 4:  Verification Wait Screen.

  1. Once verification is complete, the system will ask if you want to view the log. See . Click [Yes] .

    Illustration 5:  

  1. The Log Contents alert box, similar to the illustration below, displays a list of the located content. If any errors are reported, create a new SaveInfo.

    Illustration 6:  SaveInfo Verification Log

    NOTE:The Z400 host computer does not support MOD read/write. If the site has some data on MOD, then before upgrading the site host computer to Z400, MOD data has to be converted to CD/DVD.

    The steps to convert the MOD data to CD/DVD:

    1. If it is save info, just do save info on DVD.

    2. If it is an image or some other data, Do restore from MOD to system. Then save the data on to the CD/DVD.

5  Finalization

  1. Store Save/Restore media in a safe place.

  1. Do a test scan before customer turnover to ensure proper operation.
