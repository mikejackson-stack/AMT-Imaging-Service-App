2  Overview

IP Protection Tool, in regions where it is implemented, is designed to prevent unauthorized access to proprietary tools.

To use this feature, contact Region Service Operation Leader to create the account to access to the IP Protection Authorization Server.

The authorization is valid on the host for 24 hours.

This feature enabled only if "iprotect" option key is not installed.

4  Procedure

  1. When launching Service Browser with service key plugged at USB Port, the following screen will come up.

    Illustration 1:  IP Protection Tool at Host

  1. From the Internet Explorer of PC, access to the IP Protection Authorization Server. URL will be provided by Region Service Operation Leader.

  1. Enter SSO ID and Password provided by Region Service Operation Leader.

    Illustration 2:  Access IP Protection Authorization Server

  1. Click on Apply Code Menu.

    Illustration 3:  Apply Code Menu

  1. Enter IPP Key provided by Host and click on [Generate] button. Activation Code will be shown.

    Illustration 4:  Generate Activation Code

  1. At host side, enter Activation Code and click [OK].

    Illustration 5:  Enter Activation Code

  1. Click [OK] for the following message.

    Illustration 6:  Notice

  1. The service browser comes up with proprietary mode.

    Illustration 7:  Service Browser With Proprietary Mode (Example)
