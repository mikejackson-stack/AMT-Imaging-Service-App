In Room Display Diagnostics

1  Diagnostic Link

Diagnostics >> System Function >> Patient Handling>> In Room Display

Diagnostics >> Hardware Location >> Magnet Room>> In Room Display

Illustration 1:  In Room Display Diagnostics

2  Purpose

This diagnostic determines if the trackballs are detected by the host PC and obtains status information on the connectivity of the trackball devices. It provides a mechanism to restart only the In Room Display (IRD) without restarting the host PC. The system may lose connectivity to the Trackballs/IRD Display due to several causes:

  • a loss of PHPS power

  • replacement of the IRD console/trackball/IRD interface box

  • reconnecting the USB/DVI-D/fiber optic cables.

All communication for these diagnostic functions is over the fiber optic connection between the IRD on the front magnet enclosure and the IRD interface box inside the GOC.

3  Components Tests

  • In Room Display

  • Operator Control Panel

  • In Room Display Interface Box

4  Requirements

In Room Display software must be installed.

5  Test Sequence

  1. Click [Run IRD Diagnostics] to determine the trackball connectivity status.

  2. If the In Room Display Diagnostics indicate that the trackballs are detected, confirm that none of the trackballs could move the pointer on the IRD. Proceed to step 3 only if:

    • Trackball 1 and trackball 2 are detected, and

    • Trackballs on the Operator Control Panel are not moving the pointer

  3. Click [Reset IRD Console] to restart the IRD.

  4. Wait for about two minutes until the IRD comes up.

  5. Confirm that the IRD is up and both trackballs move the mouse pointer on the IRD.

6  Expected Results

The In Room Display is reset and the trackball function works to move the cursor on the In Room Display.
