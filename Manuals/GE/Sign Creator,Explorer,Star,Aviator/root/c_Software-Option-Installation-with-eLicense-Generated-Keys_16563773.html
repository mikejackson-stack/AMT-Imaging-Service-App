Software Option Installation with eLicense Generated Keys

1 Overview

This procedure describes how to use eLicense to generate and install software options on MR scanners running 11.x software or greater (Core products) and OpenMR4 or greater software (Open products). eLicense allows the field to generate license keys for MR scanners and removes the need to send out physical media for all options on the order. The first step in creating option keys is to go to the eLicense website and register the scanner. To access the eLicense website, you must have a computer with connectivity, as well as a single sign-on (SSO) account. The eLicense website can be accessed at http://elicense.gehealthcare.com.

The MR system must be tied to the Global Order Number (GON) through the Host ID and System ID of the scanner. After the site information is entered, the keys can be generated and distributed by e-mail, downloading, saving to an eFloppy or eCD, or printing. This file can then be installed on the system through InSite download, eFloppy, eCD, or manual entry.

The illustration below shows the eLicense process flow. For additional information on how to generate and obtain these keys from the eLicense server, see the eLicense User Guide under the HELP tab of the eLicense website.

2 eLicense Website Tasks

2.1 Create Licenses

This feature creates option keys for a new or existing system based on an order. To create new licenses, you must have order number(s) that list the options ordered, as well as the Host ID and System ID of the system.

2.1.1 Obtaining System Host ID

  1. Select the Service Tools Desktop.
  2. From the Service Desktop Manager, select Guided Install and select Start… to open Guided Install.
  3. When a command window displays the message Type Root Password, type the system’s root password operator (system default), and press Enter.
    note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  4. After the Guided Install window opens, select the Option Keys tab. The Host ID is in the Install Temporary Service Key section shown below.
    note: The screen shown below is an example, and the interface may differ on other systems.
  5. Another method of obtaining the Host ID is to type sysinfo at a command prompt.
    note:

    hostid is not a valid command to obtain the Host ID. This causes an error when trying to generate keys, due to the incorrect host ID. The methods listed above must be used to get a valid ID.

2.1.2 Adding system to order (for new installations)

  1. Go to the eLicense website http://elicense.gehealthcare.com and log on using your single sign-on (SSO) username and password.
  2. On the eLicense homepage, enter the order number in the Order Number field and click Go.

    The order associated with the number entered from the eOM system displays. The order number may be a new global order number or an FDO number, depending on when the order was placed. This number is listed on the packing list included with the order.

  3. It is possible that the order number is not unique to your customer. If this is the case, a list of all matching sites displays on the Site Selection screen shown below. Select the desired system and click Go to display the order. If the order number is unique, eLicense automatically brings up the order and displays the Order Information screen. Verify that the Customer Information at the top left of the screen is the correct customer.
  4. Click Add a System to associate the order to a specific system.

  5. Enter the Host ID obtained in Obtaining System Host ID, select Host ID from the drop-down menu, select MR for the modality, and click Go.

  6. When a screen displays requesting additional information for this system, select the Model Type for the system from the table below, and enter the System ID. Leave the Serial Number field blank for all MR systems. (See Figure 7.)

2.1.3 Adding a system to an order (For upgrades)

  1. Go to the eLicense website http://elicense.gehealthcare.com and log on using your single sign-on username and password.
  2. From the eLicense homepage, enter the System ID, select System ID from the drop-down menu and MR for the modality as shown below. Next, select Go. (If the System ID is not associated with keys in eLicense, select Host ID from the pull-down and enter the Host ID of the original computer. To determine the Host ID of the system, open a C-shell and type sysinfo. Also, the original order number can be used if known, but not the new order number.)
    note:
    It is important to locate all of the option keys prior to creating new keys on upgrades. Older system types like Signa LX do NOT have option keys in eLicense.
  3. When the screen shown below opens, record the Order Number(s) that display.
    note:

    The Order ID column contains all of the order numbers of any key created for the system. It is good practice to record these numbers prior to doing the upgrade.

  4. Select Edit System Information.
  5. Select the Model Type for the system from the drop-down menu. (See Table 1 for Model Type Information.)
    note:

    If the Host computer is being replaced, delete the Host ID in the Edit System Information GUI, and enter the new one. Do NOT transfer the NIC card to the new computer. All previous option keys are automatically regenerated with the Host ID.

  6. Select Continue on the GUI.
  7. Select Generate Licenses on the eLicense GUI.
    note:

    Never select the Reconfigure button. It can erase all option keys if selected.

  8. Enter the New/Upgrade Order Number recorded in step 3 (above).
    There should be additional Options noted as shown below.
  9. Click on the new options, and select Generate Licenses.

2.2 Viewing existing licenses for a system

A list of licenses previously generated for a system can be retrieved by searching from the eLicense homepage.

  1. Go to the eLicense website http://elicense.gehealthcare.com and log on using your single sign-on username and password.
  2. From the eLicense homepage, enter the System ID or Host ID and modality in the System Configuration section, and click Go. (The System Information screen, shown below, lists all the options generated for that system. Other information listed: Generate Date, Order ID, License information and the SSO of the user who generated the option keys.)
  3. An alternative method for retrieving a list of existing licenses is to enter the Global Order Number in the Order Management section and click Go. (As long as keys were created, the System ID or Host ID that it is tied to can be found. On the Order Assignment screen shown below, locate the proper System ID, and select Details.)

2.3 Distributing licenses

There are four methods for distributing license keys generated at the eLicense server: e-mail, save, print, or download via InSite. These options can be accessed from the eLicense System Information screen shown below. (Refer to Viewing existing licenses for a system to access this page, or click the Details button on the Order Information screen shown in Figure 16.)

2.3.1 Downloading Licenses

One method of installing option keys is a direct download to a site with connectivity that has completed an InSite checkout. The download is processed from the eLicense website, NOT from the scanner itself.

note:

The preferred method of installing option keys is to burn to a CD-ROM. (See Viewing existing licenses for a system.) A download may not install all option keys because dependent keys are not on the system.

  1. After generating the option keys for the system, go to the eLicense System Information screen by clicking Details next to the Host ID.
  2. Click on the download link to activate the desired option as shown below. If a link is not available, a modem or broadband connectivity was not established. Try one of the other installation options.
  3. Wait for the request to be processed. (A status page provides information on the downloading process.)
  4. Repeat the previous two steps for all options that must be activated on the scanner.

2.3.2 E-mailing licenses

The license file can be e-mailed to any e-mail address. Then, save this file to a floppy disk or CD, print it, or send it via FTP to the target system following the steps in Section 3.

  1. From the System Information screen, select Email Licenses.
  2. The Email License Keys window displays, as shown below.
  3. Additional e-mail can be added to this message.
    1. If the recipient is a GE employee, enter their first and last name, and then click Search. Select the name you want from the list.
    2. If the e-mail address is an external address, type it in the Address field, and click Add.
  4. To remove unwanted addresses, click Delete.
  5. When all recipients are added, click Continue.

  6. A verification window displays. Click Close Window in the upper right corner.

2.3.3 Saving licenses to a disk

You can save the license file to a floppy disk for installation via Guided Install on the scanner. The file can also be saved to the hard drive, and later transferred to a disk, printed, or sent via FTP to the scanner.

  1. From the System Information screen, click Save Licenses.
  2. On the File Download screen, select Save this file to disk and click OK. (Shown below.)
  3. At the Save As screen, you can select the destination of the license file.
    1. If saving to a disk, insert a disk into the computer’s drive and select the drive from the menu.
    2. If saving to the hard drive, select the folder to save the file to.
  4. The filename must be license.sh. The software looks for this exact name.
    note: Windows will try to change the filename to license.txt. You must ensure that the file name is license.sh or installation will fail on the system.
  5. In the Save as Type field, select All Files.
  6. Click Save when finished.
  7. After the file is saved, a Download Complete window displays. Click Close.

2.3.4 Printing Licenses

The license key file can also be printed. You can then use the document as a reference when manually entering the option keys into the Guided Install screen.

  1. From the System Information screen, click Print Licenses.

  2. From the Generated Licenses screen, select Print from the File menu to print the screen. (Shown below.)

3 Option Installation

There are five methods for installing eLicense option keys on the system. The details of each method are given in the following sections.

note:

The preferred method of installing option keys is to burn to a CD-ROM. (See Saving licenses to a disk.) Download may not install all option keys because dependent keys are not on the system.

  • notice
  • When installing options on a system, make sure the option matches the upgrade being performed. All other conflicting option keys should be removed. Failure to remove them can result in a de-rated system configuration. EXAMPLE 1: System options for HiSpeed and EchoSpeed are both installed. The result is the system will perform as a HiSpeed, NOT as an EchoSpeed. TO RESOLVE – The HiSpeed option must be removed to allow the system to configure as an EchoSpeed. EXAMPLE 2: System options for 8-Channel and 16-Channels are both installed. The 8-Channel option must be removed to allow the system to configure as a 16-Channel.

3.1 eLicense Floppy

note:

On new systems the option floppy is no longer a supported feature. Verify the host PC has a floppy drive prior to creating an eLicense Floppy.

All of the eLicense option keys can be saved onto one floppy disk. After creating this floppy disk, follow these instructions to load them onto the system.

note:

The option key file must end with a .sh suffix. If the file was saved as anything other than license.sh, the file will not be recognized when loaded onto the scanner. Rename the file to license.sh.

  1. Insert the floppy disk into the host computer floppy drive.

  2. Select the Service Tools Desktop.

  3. Select Guided Install from the Service Desktop Manager and press Start . . . to open Guided Install.

  4. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press Enter.

    note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  5. Once the Guided Install window opens, select the Option Keys tab.

  6. Select the eLicense Floppy check box on the Install Option Key portion of the window, and then select Install.

    note:
    Select the Floppy check box when using an option floppy sent with the system and not generated through eLicense. The eLicense floppy will NOT work when the floppy check box is selected. Please use the eLicense Floppy selection for keys generated with eLicense, and Floppy for factory generated keys.
  7. The option key file will begin loading. Load times per option key are very short. Typically less than one minute. When the keys are finished loading, a pop-up displays (shown below), listing all the installed options. Scantools and EchoPlus options are shown in the Illustration.

  8. Verify that the option list in the Guided Install GUI is updated with the options just loaded, if they were previously “Not Installed” or of type “FlexTrial”.

    • notice
    • When installing options on a system, make sure the option matches the upgrade being performed. All other conflicting option keys should be removed. Failure to remove them can result in a de-rated system configuration. EXAMPLE 1: System options for HiSpeed and EchoSpeed are both installed. The result is the system will perform as a HiSpeed, NOT as an EchoSpeed. TO RESOLVE – The HiSpeed option must be removed to allow the system to configure as an EchoSpeed. EXAMPLE 2: System options for 8-Channel and 16-Channels are both installed. The 8-Channel option must be removed to allow the system to configure as a 16-Channel.

  9. Select Quit from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

3.2 eLicense CD-ROM

All of the eLicense option keys can also be saved onto one CD-ROM. This is the preferred method for installing option keys. Once you create the CD, the options can be loaded onto the system, described in Obtaining System Host ID.

3.2.1 Making the eLicense CD-ROM

Once the option key file is downloaded from the eLicense site to the hard drive of a computer, it can be burned onto a CD. The MR system requires that the disc be ISO-compliant. This format type cannot be burned with Windows XP's built-in disc burning. To burn an ISO-compliant disc, you must use a program such as Sonic RecordNow, which burns ISO-compliant discs by default.

  1. Start Sonic RecordNow.

    note:

    To obtain a licensed copy of Sonic go to ftp://globe/globepro/swstore/applications/HelpDesk/SONIC and download the Sonic Record Now 7.exe file or call GE Healthcare's Help Desk.

  2. From Sonic's homepage, select the Data Projects tab, and then click Data Disc. (Shown below.)
  3. Click Add Files and Folders (shown below), and then browse your PC to add the license.sh to the Data Disc list.

  4. Put a blank CD in the computer's CD-ROM drive and click Burn.

3.2.2 Loading Options from eCD

After creating this CD-ROM, follow these instructions to load the keys onto the system.

  1. Insert the CD-ROM into the host computer CD drive.

  2. Select the Service Tools Desktop.

  3. Select Guided Install from the Service Desktop Manager and press Start… to open Guided Install.

  4. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press Enter.

    note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  5. Once the Guided Install window opens, select the Option Keys tab.

  6. Select the eLicense CD check box on the Install Option Key portion of the window, and then select Install.

  7. When the keys are finished loading, a pop-up displays the list of the installed options.

  8. Verify the option list in the Guided Install GUI is updated with the options just loaded.

  9. Select Quit from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

3.3 Option Key Auto Download

If the auto download procedure is performed, the keys will be on the scanner waiting for a reboot.

  1. Reboot the MR scanner after all option keys have been downloaded from the eLicense server.

  2. Verify that a pop-up displays the message New option keys have been installed after the Please do not interact with the system until this message disappears… window disappears.

  3. Open Guided Install, and verify the downloaded option keys are installed as permanent keys on the Option Keys tab.

  4. Complete a Save Info to retain all newly installed options on an Info MOD.

3.4 FTP Option Keys to Scanner

If an inSite checkout has not been completed on the scanner, but the system is connected to the hospital network, the option keys can be sent to the scanner via FTP. The option key file must be saved to the computer hard drive before continuing.

  1. Obtain the scanner IP address and connect to the system.

  2. Send the option key file from the desktop to the scanner via FTP.

  3. Move the file to the temp directory by typing mv license.sh /usr/tmp.

  4. Rename the file by typing mv license.sh flexkeys_install.

  5. Reboot the system.

  6. Verify that a pop-up displays the message New option keys have been installed after the Please do not interact with the system until this message disappears… window disappears.

  7. Open Guided Install, and verify that the option keys are installed as permanent keys on the Option Keys tab.

  8. Complete a Save Info to retain all newly installed options on an Info MOD.

3.5 Manual Option Key Entry

If all other methods of option key installation are unavailable, you can enter the keys manually. A printed copy of the keys is needed to transcribe the strings.

  1. Select the Service Tools Desktop.

  2. Select Install… from the Service Desktop Manager to open Guided Install.

  3. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press Enter.

    note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  4. After the Guided Install window opens, select the Option Keys tab.

  5. Select the Manual check box on the Install Option Key portion of the window, enter the 24-character license key string into the text box, and select Install. This field is case-sensitive.

  6. The option key will load immediately.

  7. Verify the option list in the Guided Install GUI is updated with the option just loaded.

  8. Repeat steps 5-7 for all the option keys that you are installing.

  9. Select Quit from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

4 Transferring eLicenses Using USB Flash Drive to the Host System

  1. Using the USB File Transfer procedure in Common Field Service Tasks, mount the USB flash drive containing the eLicense option keys to the host.

  2. Copy the required eLicense option key files (license.sh) from the USB flash drive to /usr/tmp on the host.

  3. Using the USB File Transfer procedure in Common Field Service Tasks, remove the USB flash drive from the host.

  4. Rename the file by typing mv license.sh flexkeys_install.

  5. Reboot the system.

  6. Verify that a pop-up displays the message New option keys have been installed after the Please do not interact with the system until this message disappears… window disappears.

  7. Open Guided Install. Verify that the option keys are installed as permanent keys on the Option Keys tab.

  8. Complete a Save Info to retain all newly installed options on an Info MOD.

6 Glossary

Bloodsupp

Blood Suppression

Cine

Images usually of moving anatomy scanned and arrange for playback rapidly in movie format.

ConnectPro (HIS/RIS)

Provides DICOM modality work list connectivity to hospital or radiology information system.

DW EPI

Diffusion Weighted Echo Planer Imaging

eOM

Electronic Order Management, the Oracle order management system.

Fast cine

Fast gated multi-phase images of the heart that show the heart as it contracts and expands during cardiac cycle in a movie format.

FTP

Short for File Transfer Protocol, the protocol used to exchange files between computer systems.

IVI

Interactive Vascular Imaging.

iDRIVE Pro

Interactive imaging uses a fast GRE pulse sequence and a new user interface to acquire continuous 2D images at a high frame rate and provide on-image navigation. Not available on systems with a single i860 AP.

Multi-Nuclear Spectroscopy

Provides access to additional spectroscopy PSD that may be used in proton mode.

MS/MA

Multi-Slice/Multi-Angle Oblique

Sgdperf

SGD enhancements, which increase, slew rates and duty cycles for higher resolution thin slice imaging.

SmartPrep

Automated triggering for contrast enhanced MRA.

SmartPrep2000

Provides SmartPrep automated table motion.

Spectroscopy/PROBE

Single voxel proton spectroscopy with PROBE-S and PROBE-P.

Probe2000 Upgrade

Multi voxel proton spectroscopy (PROBE - SI).

SPECIAL

Spectral / Spatial Fat Suppression. Chemical saturation using an inversion pulse (180º pulse). This key will always suppress just fat and cannot be changed to suppress water.

SSFSE

Single Shot Fast Spin Echo

Tagging

The placement of "tags" in an MR image is used to assess myocardial wall functions visually.
