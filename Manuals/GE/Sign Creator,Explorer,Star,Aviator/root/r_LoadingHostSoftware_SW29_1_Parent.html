SV29.1 or SV25.4 and later (USB and IRIS load)

Install or upgrade the host system software for SV29.1 or SV25.4 and later (USB and IRIS load).

Beginning with software release SV29.1 or SV25.4, the software load procedure has been split into different workflows. Be sure to select the link for the specific instance you require.

Note: Before beginning, talk with your customer administrator to identify the user accounts they will want to create during the setup process. See MR customer password management process for software 29.1 and later and Passwords rules.
  • For a new installation or Explorer Lift installation, see Installing SV29.1 or SV25.4 (USB load only) or MR30 (USB load only) on a new system.
  • If you are upgrading the host system software from SV29.1 or SV25.4 and later SW version remotely, see Upgrading from previous software versions (IRIS installation).
  • If you are upgrading the host system software from SV20.X, SV23.X or SV25.X, see Upgrading SV20.X, SV23.X or SV25.X to SV29.1 or SV25.4 and later (USB load only).
  • If you need to reload the host system software, see Reloading SV29.1 or SV25.4 and later SW version (USB load only).
  • Installing SV29.1 or SV25.4 (USB load only) or MR30 (USB load only) on a new system
    Install the host system software for SV29.1 or SV25.4MR30 (USB load only).
  • Upgrading from previous software versions (IRIS installation)
    Install the host system software for software releases after SV29.1 or SV25.4 (IRIS load only).
  • Upgrading SV20.X, SV23.X or SV25.X to SV29.1 or SV25.4 and later (USB load only)
    Upgrade the host system software from SV20.X, SV23.X, or SV25.X to SV29.1 or SV25.4 (USB load only).
  • Reloading SV29.1 or SV25.4 and later SW version (USB load only)
    Reload the host system software for SV29.1 or SV25.4 MR30 and later (USB load only) if you do not want to reset your passwords.
  • Reloading software for system recovery from forgotten passwords
    Reload the host system software for SV29.1 or SV25.4 and later (USB load only) if you want to reset your passwords.
