Roughly Adjust the Table Lateral Center and Longitudinal Gap

Procedure

  3. Move the Table to up limit position by up pedal.
  4. Roughly adjust the Table Lateral Center and Longitudinal Gap while caster is attached to the Patient Table.
    1. Move the Patient Table laterally to align the table edge line and bridge edge line
    2. Perform the following step to adjust the Longitudinal Gap.

      1. Move the Patient Table longitudinally and adjust the gap using 6mm jig as follows for left and right.

      2. After the adjustment, confirm that 8mm side cannot be inserted into the gap for left and right.

  6. Move up the lowest telescopic cover a little and fix it with masking tape.

    1. Loosen Anchor nut.

  9. Remove 4 casters.

    1. Lower the 6 leveling pad with the same turns so that the Table screw holes can be seen through the dock frame slotted hole.

Dock Frame Location Check

Procedure

  1. Check the following two items.
    1. Verify the table is centered by aligning the table edge line and bridge edge line (0~0.5 mm).
      Note:

      If not centered, measure the record the adjustment value.

      Lateral Difference mm
    2. Check that the gaps of bridge and table are 6.0 +/- 2.0 mm
      Note:

      If the gap does not satisfy the specification, record the adjustment value for each side.

      Gap Right mm
      Gap Left mm
    3. The gap difference between left and right is within 1mm.
      Gap Difference mm
    Note:

    If adjustment is needed, perform the following step to adjust the Longitudinal Gap.

    1. Move the Patient Table longitudinally and adjust the gap using 6mm jig as follows for left and right.

      Note that the gap specification is 6.0 +/- 2.0 mm. 6mm jig is used to adjust the Table to the center target.

    2. After the adjustment, confirm that 8mm side cannot be inserted into the gap for left and right.

  2. If adjustment is required, refer to the following procedure.

    • Table Lateral Center Adjustment: Table Lateral Center Adjustment.

    • Table Longitudinal Gap Adjustment: Table Longitudinal Gap Adjustment

  3. If adjustment is not required, no further adjustment for Table Location is needed.
Topic ID: id_SL493382-1318527

Table Lateral Center Adjustment

Procedure

  1. Perform the following steps.
    1. Mark the lines on the floor along the both side of frame edge.
    2. Loosen Anchor stud nut.
    3. Loosen four fixing bolts.
  2. Move the Table Position laterally so that Patient Table is adjusted to meet the specification in Step 1.a. Use the alignment line as reference to understand the movement.
  3. If the Gap adjustment is required, perform Table Longitudinal Gap Adjustment.
  4. If the Table gap adjustment is not required, fix the Dock Frame by restoring the four screws of Dock Frame and the nut for floor stud.
Topic ID: id_SL3125671-1318527

Table Longitudinal Gap Adjustment

Procedure

  1. Perform the following steps.
    1. Loosen Anchor nut.
    2. Remove four fixing bolts.
  2. Insert/remove the washer according to the adjustment value for each side.
  3. Fix the Dock Frame by restoring the four screws of dock frame and the nut for floor Stud.
Topic ID: id_15401171

Finalization

Procedure

Confirm Dock Frame Location. Refer to Dock Frame Location Check.
