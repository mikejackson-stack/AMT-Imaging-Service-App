1 Head Coil

Procedure

  1. Head Coil Setup
    1. Coil Setup for new Head Coil (Split Head Coil).

      1. Place the split head coil on the patient table.

      2. Place the phantom in the head coil. See Figure 1.

      3. Place the nesting plate on the patient table so that it butts flush against the head coil positioner. See Figure 1.

    2. Coil Setup for old Head Coil

      1. Place the nesting plate on the patient table so that it butts flush against the bottom of the head coil. See Figure 2.

2 Invoking SPT Full Test Mode

Procedure

    • notice
    • Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on End Exam to terminate any previous exam. It is not necessary to click on New Pt as SPT automatically enters the scan protocol when it is invoked via the MR Tools menu.
  1. To start the SPT Full Test tool from the Service Browser, follow the steps on Figure 3, below.
  2. Select the head coil currently in use, then click on Start. A SPT Test menu appears in a window on the desktop. The Field Engineer should always use the Full Test Mode (see Figure 4).
    1. In the Select All tests field, click No.
    2. To select a reason for the test, click the button to the right of Test Purpose. Select a reason from the list. If desired, enter text in the Comments field.
    3. Click the On button to select the test that you want to run.
    4. To select Multiple Passes of the test(s), select the Multi Passes button, then enter the desired number of passes in the box that appears to the right.
    5. Click Start SPT to begin.

      You may be prompted to make additional selections as the test begins.

      Status messages will appear in the text box below the menu as the tests are run. Use the scroll bar on the right side of the box to move up or down through the messages.

    6. If desired, click the WhatFailed button. An example of WhatFailed output can be found in Troubleshooting.
    note:

    This screen will be displayed until you quit SPT, so if you're in a troubleshooting mode, all you need to do is press the Start SPT button to go again.

  3. To exit SPT, click the Quit SPT button.
  4. To view SPT results, select the Utilities tab on the Service Browser, then select Report Manager.
  5. Enter the Report Manager password (the same password used for the Service Methods CD-ROM) and press Enter.

3 Finalization

Procedure

  1. Do a TPS Reset after completing SPT to put the system back into a know state.
  2. If for any reason a SPT scan is aborted, Shutdown and Reboot the system.
