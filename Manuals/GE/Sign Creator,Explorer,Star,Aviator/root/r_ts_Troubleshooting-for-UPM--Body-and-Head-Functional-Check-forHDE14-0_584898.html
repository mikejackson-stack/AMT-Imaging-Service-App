If BODY UPM FUNCTIONAL CHECK IS FAILED

  1. Edit Upm1Cal1.cfg as following procedure.
    1. Open File Editor by selecting Utility/File Editor from Common Service Desktop.
    2. Select File/Open.
    3. Select 'w/config/Upm1Cal.cfg' and Open.
    4. Select Save As... and save the file as 'Upm1Cal.cfg.bk' .
    5. In case of over peak power, decrease the Body cal code by '1'.

      In case of lower peak power, increase the Body cal code by '1'.

    6. Save the config file.
    7. Quit the tool.
    8. Perform [TPS Reset].
  2. Inhibit TR faults. Disable the Driver Module. Move switch 2 to the TR Disable position. See Figure 7.
  3. Remove the Body RF cable from J4. Connect the RF dummy load into J4. Use 7/16 Male - N Female Adapter attached in System Cabinet.
  4. Place the Body Sphere and Loader on the Nesting Plate as shown in Figure 9.
  5. Press Align on.
  6. Move the cradle to place the Laser alignment light on the center of the Body Loader and phantom.
  7. Press Landmark.
  8. Press Advance to Scan.
  9. From the Common Service Desktop:
    1. Select Calibration Tab
    2. For the Class A/C service tool, select UPM Tool from the calibration menu and select Click here to start this tool
    3. Figure 10 shows an example of the UPM tool.
  10. Select the Nuclei [1H].
  11. Select the RF Chain you are going to check [Body].
    Note:

    Power Type selection will be grayed out. This is normal, and is not used.

  12. Select: [Func Chk] Button
  13. Select the [Start] button.
  14. After that, the tool takes full control and runs the 3 functional tests for whatever setup is currently active. The result of each test is compared against a Specification File on the system. Status should indicate Pass/Fail.

    During the tests, the user will be prompted 3 times as each test completes. Look in the error log to confirm that the tests completed successfully. The following illustrations show an example of pop ups and error logs that should be seen.

    Note:

    A TPS Reset must be preformed when testing is complete before scanning can resume.

  15. Check that the Measure Peak Power satisfies the specification. See Figure 16.
  16. If measured peak power does not satisfy the specification in Figure 16, go back to If BODY UPM FUNCTIONAL CHECK IS FAILED.
  17. It the test is passed, restore the Body out cable to SRFD3. Restore Driver Module switch 2 to the TR Enable position
  18. Perform TPS Reset.
  19. Perform UPM- Body Functional Check.

If Head UPM FUNCTIONAL CHECK IS FAILED

  1. Edit Upm1Cal1.cfg as following procedure.
    1. Open File Editor by selecting Utility/File Editor from Common Service Desktop.
    2. Select File/Open.
    3. Select 'w/config/Upm1Cal.cfg' and Open.
    4. Select Save As... and save the file as 'Upm1Cal.cfg.bk' .
    5. In case of over peak power, decrease the Head cal code by '1'.

      In case of lower peak power, increase the Head cal code by '1'.

    6. Save the config file.
    7. Quit the tool.
    8. Perform [TPS Reset].
  2. Remove the Head RF cable from J3. Connect the RF dummy load into J3. Use 7/16 Male - N Female Adapter attached in System Cabinet.
  3. Withdraw the Cradle from its previous position.
  4. Place the head coil on the cradle.
  5. Insert the Head Sphere and Loader into the Head coil as shown in.
  6. Press Align on.
  7. Place the laser alignment light on the center of the Phantom in the Head coil. Refer toFigure 24.
  8. Press Landmark
  9. Press Advance to Scan
  10. Select the Nuclei 1H
  11. Select the RF Chain you are going to check Head.
  12. Select: Func Chk Button
  13. Select the Start button.
  14. After that the tool takes full control and runs the 3 functional tests and the UPM status should indicate Pass/Fail.

    During the tests, the user will be prompted 3 times as each test completes. Look in the error log to confirm that the tests completed successfully. The following illustrations show an example of pop ups and error logs that should be seen.

  15. Check that the Measure Peak Power satisfies the specification. See Figure 29.
  16. If measured peak power does not satisfy the specification in Figure 29, go back to If Head UPM FUNCTIONAL CHECK IS FAILED.
  17. It the test is passed, restore the Head out cable to SRFD3. Restore Driver Module switch 2 to the TR Enable position
  18. Perform TPS Reset.
  19. Perform UPM- Head Functional Check.
Topic ID: id_14919465

Finalization

  1. Check that cable at SRFD is restored
  2. Check that SW2 of Driver Module is set to enable.
  3. Return the system to patient scanning configuration and do a test scan.
