BRM CHILLER Auto Restart Setup

Effectivity

System with Lytorn BRM Chiller(Kodiak Recirculating Chiller. RC045J03BG0C011)

Concern

When the system is not used for a while, the system becomes Standby mode. At this time, if the auto restart setting of BRM Chiller is not setup to 'ON', the power of BRM chiller won't be restarted after the system is recovered from Standby Mode.

Solution

If the following condition is already confirmed, skip the procedure described in this manual.

  • Condition: BRM chiller restarts after the system is recovered from Standby Mode.

Note:

If system is not used about 1 hour after [End Exam], the system will become Standby Mode. At this time, BRM Chiller will be powered off simultaneously. When [New patient] is clicked, the system recovers from standby mode and BRM chiller also restarts if auto restart setting of BRM Chiller is 'ON'.

If the condition above is not confirmed, please confirm that the auto restart setting of BRM Chiller is set to 'ON' according to the following procedure during System Installation or Replacement of Lytron BRM Chiller.

  1. Enter the customer menu by holding both the “UP” and “DOWN” arrow keys for 3 seconds.

  2. Use the “SET” key to scroll to “Ar”.

  3. The display toggles between “Ar” and its current setting. Confirm that current setting is set to 'ON'.

  4. If it is not, set to 'ON' using “UP” or “DOWN” arrow key.

  5. Press, “SET” to accept the setting on the display and exit from the menu.

  6. Verify that the BRM chiller restart after the system is recovered from Standby Mode.
