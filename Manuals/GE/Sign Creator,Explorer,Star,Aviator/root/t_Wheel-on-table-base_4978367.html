Procedure

  1. Move table to topmost position
  2. Turn the system power OFF. Refer to Lockout / Tagout for System Cabinet PDU Main Breaker.
  3. Disconnect the Table from MR Magnet; take it out from the Magnet room. Refer to TAKE TABLE OUT FROM THE MAGNET ROOM.
  4. Remove table base FRP cover
  5. Remove table inner scissor cover
  6. Remove wheel guide plate
  7. Remove the shaft holder
  8. Pull the table about 3mm up, and replace the wheel and install shaft holder
  9. Restore wheel guide
  10. Restore table inner scissor cover
  11. Remove table base FRP cover

Finalization

  1. Turn the system power ON. Refer to Lockout / Tagout for System Cabinet PDU Main Breaker.
  2. Level the Table and perform Height Adjustment. Refer to LEVELING FIXED TABLE and TOP HEIGHT ADJUSTMENT.
  3. Fix the FRP Covers of the Table.
  4. Perform CRADLE HOME SENSOR CHECK .
  5. Check the Table Function. Refer to TABLE CHECKS AFTER INSTALLATION .
  6. Perform Express Coil MCQA Test to check that the PA coil cable is properly connected.
