About this task

Follow this process to prepare for the automated SNR Test using the 1.5T 8-Channel Neurovascular Array Coil by Invivo (M3335M).

Note:

Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.

Topic ID: id_SL2927056-585033

Legacy Phantom Procedure

Procedure

  1. Note:

    If installing the coil for the first time in a system, refer to Auto Coil Install.

    End the previous exam if not already done.
  2. Make a note of the serial number of the coil.
  3. Remove the top of the coil, and secure the base of the Invivo HD 1.5T 8-Channel Neurovascular Array to the cradle in the same position (shown in Figure 1) as the standard head coil.
  4. Place the phantom positioner on the coil as shown in Figure 2.
  5. Place the phantom on the positioner as shown in Figure 3.
    Note:

    For correct bottle placement, fully insert the bottom of each phantom bottle until it touches the curved inside surface of the main phantom. (See Figure 4.)

  6. Attach the top to the coil as shown in Figure 5.
  7. Perform the Multi-Coil Quality Assurance (MCQA) Tool if available, otherwise perform the Surface Coils SNR Test.
Topic ID: id_SL2927057-585033

Unified Phantom Procedure

Procedure

  1. Place the base of the NV array coil on the patient table and latch it to the table as shown in Figure 6.
  2. Place the phantom positioner in the coil as shown in Figure 7.
  3. Place the phantoms in the positioner as shown in Figure 8.
  4. Carefully align the connector pins on the base of the coil with the top part of the coil and then latch both the coil sections into place as in Figure 9. (The scanner will not operate if the coil sections are not latched correctly).
  5. Connect the coil to Port A of the system LPCA. Landmark the coil at the cross mark as shown in Figure 10 and advance to scan.
  6. Run the Multi-Coil Quality Assurance (MCQA) Tool with the Unified Phantom Set.
