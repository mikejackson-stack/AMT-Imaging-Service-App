Overview

This procedure provides instruction to replace the HP z420 host computer with another HP z420.

1 Prepare the Workstation for Host Computer Removal

Procedure

  1. Ask the customer to archive all images to an external storage device such as a PACS or DVDs.
  2. Perform a Save Info.
  3. Shut down the host computer.
  4. Perform LOTO on the GOC/operator workspace. See Lockout/Tagout of the GOC.

2 Remove Host Computer from GOC

Procedure

  1. Remove the two screws that secure the left side panel of the GOC.
    note:

    The side panel has a short ground lead connecting it to the main chassis. When removing the side panel, do not strain this ground lead.

  2. Disconnect the short ground lead that connects the side panel to the GOC main chassis at the center of the lead.
  3. Remove the left side panel and set it is a safe place.
  4. Remove all the cables connected to the host computer.

    Confirm that the cables are properly labeled. Note their locations for reattachment.

  5. Loosen the strap and remove the hook.
  6. Remove adhesive tape.
  7. Remove the host computer from the GOC.
    1. Remove the two screws securing the back bracket to the GOC.
    2. Remove the one screw on the side plate.
  8. Carefully remove the computer using the back brackets, and install the bracket to new computer.
  9. Remove the PCI AA from the defective PC and install it in the new PC, see PCI AA Replacement).
  10. Remove the dust filter from the old computer. Remove the Velcro strips from the inside of the front cover of the old machine and the dust filter. Attach them to the inside of the new machine’s cover. Attach the Velcro strips to the dust filter. Install the dust filter. If the old filter is not reusable, install a new one.
  11. Install the new PC by performing the steps above in reverse order.

3 Finalization

Procedure

  1. Remove LOTO from the GOC to return power. If needed, reconnect the twist-n-lock main power cable to the rear of the console. See Lockout / Tagout for GOC .
  2. Power up host computer.
  3. Verify that the host computer front panel power LED is illuminated as a steady blue signal.
  4. Load software and applications onto the operating system.

    See Loading Host System Software.

    note:

    Load From Cold (LFC) must be performed to properly transfer customer options.

  5. Power up the GOC System Startup and Shutdown.

    If present, reconnect the optional UPS and ensure power is restored.

  6. From Guided Install, select RestoreInfo.
  7. Update the eLicense with the new Host ID. See Software Option Installation with eLicense Generated Keys.
  8. Perform Check Scan to confirm the system and applications are working properly.
  9. Confirm that all customer functions are operational (auto voice, filming, network, archive).
  10. Repackage the defective PC for return.
