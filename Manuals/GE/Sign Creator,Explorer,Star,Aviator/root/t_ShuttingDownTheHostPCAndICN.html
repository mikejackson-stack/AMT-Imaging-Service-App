Shutting down the ICN and host computer

Procedure

  1. If the system login is root, power down the ICN before shutting down the host computer. See Powering Down the ICN from Root Level Shutting Down the ICN from the Root Level.
  2. To shut down the host computer from the Common Service Desktop, select Utility > System Shutdown. Click Shutdown to shut down the PC and ICN.
    If the system login is root,
    1. Right click and select Logout.
    2. Click Yes.
    3. At Menu, select Shutdown.
    4. Select Turn Off Computer.
