Loading service license softkey

Follow this procedure to install a service license softkey on a system.

Prerequisites

The customer must obtain the license softkey from the regional representative before doing this task. If needed, see Ordering service license softkey.
Required conditions
System time must be correct before loading the license softkey.

About this task

After the request is approved, an email is sent to the email address provided with the request.
Note: If a softkey has unexpectedly stopped working, check the time and date on the system. If the date or time has been changed, this causes the softkey to stop working. Change the date and time back to the previous setting to correct the issue.

Procedure

  1. Open the email from the regional representative and download the license softkey.
  2. Make sure that the system time is set correctly before loading the license.
  3. To transfer the software license file to the system, save the license(s) on either a USB stick or DVD.
    Multiple license softkey types can be saved to the same USB stick or DVD for multiple systems.
    Note: USB keys used must be formatted to FAT32 otherwise the USB will fail to mount. If the SSA installation with USB fails, check and format the USB to FAT32.
  4. Use one of the following methods to access the Service License GUI.
    • From the operator console, click the drop-down menu on the Tools icon.
    • Double-click the key icon on the bottom right corner of the Tools Desktop.
    • Log on as root during system startup.
  5. Select Install Service License.
  6. Insert the USB stick or DVD where you saved the license softkey and select CD/DVD or USB.

    Result

    The system will automatically load the correct license softkey for a given system ID.
  7. Select the language for the system.

    The system language must be decided before getting the service license ID. If the language is changed on the system, it will also change the 16-digit service license ID assigned to the system and cause the existing license to fail.

  8. When the installation is finished, use the Eject button to disconnect the USB key so it does not become corrupted.
