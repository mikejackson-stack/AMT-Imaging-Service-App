3D FRU Viewer Help

This manual describes the operation of 3D FRU Viewer.

  • Open 3D FRU Viewer and Basic 3D Operation: Open 3D FRU Viewer and Basic 3D Operation

  • FRU information identification by 3D Model: FRU information identification by 3D Model

  • Search Function: Search Function

  • View Button Operation: View Button Operation

  • Model Tree and 3D Model: Model Tree and 3D Model

  • Part Options of 3D Model: Part Options of 3D Model

Open 3D FRU Viewer and Basic 3D Operation

  1. Basic 3D Model Operation is shown in Figure 1.

FRU information identification by 3D Model

  1. Click on module to be identified. Then, FRU information is shown in the bottom field.

  2. If there exists related manual link, click on it to open the manual.

Search Function

  1. Enter keyword in the search field and click [Search]. Selection which include the keyword will be shown.

  2. Click on the desired item. Searched object will be highlighted and FRU information will be shown.

View Button Operation

Click on view button to show different view.

Model Tree and 3D Model

  1. Click on [Show/Hide Model Tree] to show/hide model tree.

  2. Click on module in 3D viewer. Then, corresponding model is highlighted in model tree.

Part Options of 3D Model

  1. Select object and select “Part Options” > “Hide”. Then, selected object is hidden.

  2. Select object and select “Part Options” > “Isolate”. Then, only selected object is shown and the others are hidden.

  3. Select object and select “Part Options” > “Make Transparent”. Then, selected object becomes transparent.
