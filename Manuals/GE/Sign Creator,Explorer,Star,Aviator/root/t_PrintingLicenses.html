Printing licenses and manually entering option keys

If all other methods of option key installation are unavailable, the license key file can be printed. You can then use the document as a reference when manually entering the option keys into the Guided Install screen.

Procedure

  1. From the System Information screen, click Print Licenses.
  2. From the Generated Licenses screen, select Print from the File menu to print the screen.
  3. Use the printed document as a reference to manually enter the option keys into the Guided Install screen.
  4. Select the Service Tools Desktop.
  5. From the Service Desktop Manager, select Guided Install and select Start… to open Guided Install.
  6. When a command window displays the message Type Root Password, type the system's root password: operator (default), and press Enter.
    note: It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.
  7. Once the Guided Install window opens, select the Option Key tab.
  8. Select the Manual checkbox on the Install Option Key section of the window, enter the 24-character license key string into the text box, and click Install.
    This text field is case-sensitive.
    The option key will load immediately.
  9. Verify the option list in the Guided Install window is updated with the option just loaded.
  10. Repeat as needed for all the option keys that you are installing.
  11. Select File > Quit to exit the Guided Install tool.
  12. Reboot the computer and verify that all options are available.
  13. Complete a SaveInfo to retain all newly installed options on an Info MOD.
