System Performance Testing (SPT)

Procedure

  1. From the CSD PM page, select PM Mode in the expanded PM folder on the left side of the page.
  2. Click the link: Click here to start this tool to start the SPT tool.
  3. Notice
    Failures must be resolved and the SPT rerun before proceeding to the PM Check.
    The System Performance Test (SPT) screen will open.
    Note:

    For more information on System Performance Tests, including phantom set up, refer to .

    • For the PM SPT mode, all the tests are preselected and cannot be changed. The test takes just over one hour to complete.

    • In the upper right corner of the SPT screen, the remaining test time will display in the upper right corner of the SPT screen. Test Progress and Results will display in the lower portion of the screen.

Topic ID: id_SL288315-628582

EPI White Pixel PM Mode

Procedure

  1. Place an empty head coil on the cradle.
  2. Landmark on the head coil.
  3. Press Move to Scan.
  4. From the CSD, select the PM tab, EPI White Pixel Mode, and click the link: Click here to start this tool.
  5. The tool will run through Head EPIWP PM, then move the head coil out of the way and perform Body EPIWP PM. If the test stops before the tool has completed both head and body modes, view the Error Log to determine the troubleshooting path.
  6. The EPI PM files generated by this tool can be found in the Report Manager tool:
    1. From the CSD, select the Utilities tab, then Report Manager.
    2. Use the password, mrgo1. Look for file type: EPT and find those files with the PM extension. IBIS will be looking for these files to track Planned Maintenance completion.
Topic ID: id_SL2087310-628582

MCR Tool Check

About this task

The MCR Tool Check is used for 14.0M5 and earlier software only.

Procedure

  1. From the CSD, select the PM tab, then select MCR PM Mode to start the tool.
    Note:

    The system will select either the MCR2 tool or MCR3 tool based on the configuration. Sites with the new Forward Production LPCA must use the MCR3 Tool. Sites with the old style Excite HD LPCA must use the MCR2 Tool.

  2. Select Run. The tool prompts for insertion of the MCR tool into each applicable Connector (A, B and C).

    • Once the test is completed in Connector A, move the MCR tool to Connector B, and select Done B option. Same for Connector C.

    • All applicable channels must pass for successful IBIS certification. (An example is shown below.)

Topic ID: id_SL288319-628582

PM Check

Procedure

  1. To verify that the PM was completed successfully, select PM Check.
    Note:

    PM Check will only pass if LVShim passes within 24 hours of passing a run of SPT.

  2. When the PM Check window opens, note the information shown.

    In the example below, Body GRE Stab has a SEVERE failure.

    • This must be resolved for the PM Assist to be considered complete.

    • The FE will have 21 days to resolve SEVERE issues; the system will notify the operator of the problem if not resolved in the 21-day window.

    For PM Assist to be successful and complete, all test results must pass as shown.

Topic ID: id_SL288323-628582

PM Schedule

About this task

The PM Schedule tool will display:

  • Date of Last LVShim and SPT PM Mode runs on the system,

  • When the next Planned Maintenance is due,

  • Marginal/Severe failures remaining from last Planned Maintenance, and

  • When the clinical user will be notified about the remaining severe failures.

Procedure

  1. Select PM Schedules in the expanded PM folder. (The right side of the screen will provide more details about the PM Schedules and a link to start the PM Schedules tool.)
  2. Click the link: Click here to start this tool to start the PM Schedules tool.
Topic ID: id_SL2066084-628582

PM Never Performed on System

About this task

If Planned Maintenance was not performed on this system, this message will display in the tool: There is no PM performed on this system at least once. Schedule a date for PM, Run SPT & LVS PM tests and Hit PM Check link on CSD.

Procedure

  1. Enter your Name or initials and press Enter.
  2. Type the next scheduled PM date using the format: mm/dd/yyyy, and press Enter.
Topic ID: id_SL2066089-628582

System Following Normal PM Schedule

Procedure

  1. The tool will display the date the last PM was performed. Enter a date for the next PM.
  2. Make sure the date for the next PM is within the specified time limit provided by the tool, and press Enter.
Topic ID: id_SL774990-628582

PM History

Procedure

  1. Select PM History in the expanded PM folder. The right side of the screen will provide more details about PM History and a link to start the PM History tool.
  2. Click the link: Click here to start this tool to start the tool and access the PM History Page.

    The PM History page will display:

    • Current Date

    • Last Performed PM Date

    • Month Next PM Due

    • Customer Scheduled PM Date

    • Field Engineer PM Date

    Note:

    The Customer Scheduled PM Date and Field Engineer PM Date should be the same date. If not, discuss PM scheduling with the customer immediately.

  3. Press Enter to quit PM History.
