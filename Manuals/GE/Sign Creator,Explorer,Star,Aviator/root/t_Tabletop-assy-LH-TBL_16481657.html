Procedure

  1. Turn the system power OFF
  2. Disconnect the Table from MR Magnet and ground; take it out from the Magnet room.
  3. Remove the scissor covers from the table.
  4. Remove the Cradle from the Table.
  5. Remove the Support block fixed to the tabletop for the cables.
  6. Remove the Cable tract connecting screw to the table top.
  7. Remove the cable strap, cramp and track and remove cables.
  8. Remove the Cable assemblies along with the cable tract from the Tabletop.
  9. Remove the Table Top side FRP covers fixing screws in the Table and remove side FRP coversside FRP covers
  10. Remove the cables connected to the Limit switch of the home sensor.
  11. Remove the Home sensor Cable assembly from the Tabletop.
  12. Remove wheel guide fixing screws and then remove wheel guides
  13. remove 2 shafts connecting tabletop and table scissor
  14. Now the Table top is free in the Table. Lift the Table Top from the base/scissor assembly.
  15. Put down the New Table top on base/scissor assembly.
  16. Move the Table top on either side and adjust such a way that the 2 shaft holes of table top will align with the scissor hole.
  17. Install the 2 shafts connecting tabletop and table scissor
  18. Install wheel guides
  19. Install the Home sensor cable in the table top.
  20. Connect the Home sensor cable to the Home sensor.
  21. Install tabletop side FRP covers.
  22. Insert the PA coil coaxial and DC cable Assembly from the top of the Tabletop.
  23. Fix the Cable track of the PA coil coaxial and DC cable Assembly to the Tabletop.
  24. Fix the support block to the Table top.
  25. Rout the cables in the table and wind the spiral tube around all Assemblies.
  26. Assemble the cradle to the table.
  27. push the table back to magnet room and connect it with Dock frame
  28. Connect the cables of the table.
  29. Level the table.
  30. Dock centering and Height adjustments.
  31. Fix the scissor covers from the table.
  32. Fix the FRP Base Covers of the Table.

Finalization

  1. Turn the system power ON. Refer to Lockout / Tagout for System Cabinet PDU Main Breaker.
  2. Level the Table and perform Height Adjustment. Refer to LEVELING FIXED TABLE and TOP HEIGHT ADJUSTMENT.
  3. Fix the FRP Covers of the Table.
  4. Perform CRADLE HOME SENSOR CHECK .
  5. Check the Table Function. Refer to TABLE CHECKS AFTER INSTALLATION .
  6. Perform Express Coil MCQA Test to check that the PA coil cable is properly connected.
