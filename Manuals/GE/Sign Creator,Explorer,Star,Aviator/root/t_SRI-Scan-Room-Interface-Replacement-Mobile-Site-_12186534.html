SRI (Scan Room Interface) Replacement (Mobile Site)

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable30 minutesNot Applicable
Table 2. Required conditions
ConditionReferenceEffectivity

System Power must be turned OFF. Refer to System Cabinet PDU Main Breaker LOTO Procedure.

--

About this task

The SRI Assembly is located on the wall.

Topic ID: id_SL12186560-1208638

Removal of SRI (Mobile Site)

Procedure

  1. Remove Cover.
  2. Remove front bracket with 2 screws.
  3. Pull out to loosen from PAC/SRI tray.
  4. Disconnect the all cables attached to the SRI.
  5. Remove SRI
Topic ID: id_SL12186567-1208638

Install new SRI (Mobile Site)

Procedure

  1. Place new SRI on tray.
  2. Connect the all cables.
  3. Fix the cables with tie-wraps.
  4. Fasten it with belt.
Topic ID: id_15005479

Finalization

Procedure

  1. Perform SRI functional Check.
    1. Open Common Service Desktop.
    2. Select 'Diagnostics / System Function / Patient Handling / SRI Functional Check'.
    3. Perform each test and verify that the each function works ok.
  2. Perform Signal to Noise - Head Scan.
