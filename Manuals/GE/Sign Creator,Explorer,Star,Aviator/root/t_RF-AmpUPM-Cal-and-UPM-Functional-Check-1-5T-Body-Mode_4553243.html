Before You Begin

Procedure

  1. The (U)CERD Exciter or RRF Master Exciter cannot be adjusted. (U)CERD Exciter or RRF Master Exciter describes how to measure and verify that the Exciter or RRF Master Exciter output is correct. The head and body RF output power levels must be checked and, if not correct, adjusted into specification. Three methods are available and listed in the order of preference for measuring head and body RF output power:

    • RF Power Measurement Kit - Easy to use, preferred method of power measurement. If you are measuring RF power with the RF Power Measurement Kit, refer to the Tools and Test Equipment section above for equipment required.

      The RF Power Measurement Kit is the preferred method for RF power measurement.

    • Bird wattmeter - Must account for cable and load loss to determine actual power.

    • Oscilloscope - Must know the scope channel correction factor if the scope bandwidth is < 300 MHz. Must account for cable and dummy load loss and the scope bandwidth limitation (channel correction factor) to accurately calculate the power from the observed peak voltage. Refer to Scopes with Less than 300 MHz Bandwidth. This method works but the process used to derive the power is somewhat complex and lacks the accuracy of the previous two methods. It is, for this reason, not recommended.

      If you are measuring RF power with an oscilloscope, refer to Alternate Equipment Setup.

  2. It is strongly recommended that you use the RF Power Measurement Kit to obtain an accurate measurement of the RF output power. If you cannot obtain an RF Power Measurement Kit, you can use one of the two other methods, provided that:

    • The Dummy Load and Cables Calibration procedure in Dummy Load and Cables Calibration has been performed and the individual loss values are known.

    • The oscilloscope input channel correction factor is known when the scope bandwidth is < 300 MHz and the wattmeter is not being used. See Scopes with Less than 300MHz Bandwidth.

Topic ID: id_SL4171216-1137108

RF Amplifier Setup and Calibration

About this task

This procedure describes how to calibrate the RF Amplifier. The RF Amplifier should come from the factory pre-calibrated and, ideally, initial calibration of the module in the field should not be needed. However, this procedure must be performed to confirm it is calibrated. Calibration is done to prevent faults and to make sure the RF Amplifier is outputting the specified kW of RF body power and head power. Adjustments may need to be made if any of the hardware in the RF chain was replaced, output levels decreased with age, or if any of the measurements taken during the check are not found to meet specifications.

Topic ID: id_SL4171303-1137108

System Preparation

Procedure

  1. Warning
    POSSIBLE RF BURNS
    POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE REAR OF THE SRFD2.
    PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE REAR OF THE SRFD2 BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE.
    Notice
    Property Damage! Prevent coil and associated switch damage by removing all phantoms and hardware (e.g., head coil, surface coil, etc.) from the magnet bore.
    Verify that the system is not scanning and that all coils have been removed from the magnet bore. Refer to the messages above.
  2. Notice
    When hooking up the Power Measurement Kit , set the SW RF Enable switch on the RF I/O to OFF!
    Remove the front cabinet cover and open the rear cabinet cover of the RF Cabinet.
    Note: Set the RF Enable switch to OFF position.
  3. Inhibit TR and DD faults by moving the TR Enable switch (SW2) to the Disable Down position on the Driver Module.
  4. Set up the equipment according to the type you are using:

    • If using the RF Power Measurement Kit, refer to the RF Power Measurement Kit laminated card set.

      Note:

      If possible, use the new card set. Part numbers are:

      • Head - Card Number 63. Part number – 46-317724P18

      • Body - Card Number 72. Part number – 46-317724P17

      1. Look in the upper right corner of each card and find the card labeled CAL.

      2. Configure the scope as shown in the illustration on the card.

      3. Follow the directions on the card to calibrate the scope using the 4 dBm calibrator.

    • If using the wattmeter, complete the Dummy Load and Cables Calibration procedure in Dummy Load and Cables Calibration.

    • If using the oscilloscope, complete the Dummy Load and Cables Calibration procedure in Dummy Load and Cables Calibration. Also make sure that the scope correction factor has been determined for the input channel to be used as described in Scopes with Less than 300 MHz Bandwidth.

  5. Check the output against the specification, using the correct method for your measurement type:

    • If using the RF Power Measurement Kit, refer to the RF Power Measurement Kit laminated card set:

      1. Look in the upper right corner of each card and find the card labeled 72 (1.5T Body Output).

        Note: The body RF output is no longer connected to the nonexistent EFB unit, as the older RF Power Measurement Kit cards show, but instead to the J4 output on the rear of the SRFD2 module. An RF adapter is provided in the RF Power Measurement Kit to connect between the HN J4 body RF output and the RF Power Measurement Kit 40 dB N-connector coupler.

      2. Configure the system as shown in the illustration on the card.

      3. Confirm that the rotary attenuator is set to the correct position indicated on the card.

    • If using the wattmeter or if using the oscilloscope, refer to Alternate Equipment Setup for the proper system body configuration.

Body RF Output Power Check

Procedure

  1. Verify that the Body LED is illuminated on the front of the SRFD2 Module.
  2. Perform a landmark for a body scan. A phantom is not needed.
  3. Start the RF/UPM tool:
    1. In proprietary mode:

      1. On the Calibration tab, select Calibration Wizard.

      2. On the Calibration Wizard screen, select Click here to start tool.

      3. Select RF/UPM Cal & Functional Check (Body).

      4. At the alert, select Yes to open the RF/UPM Tool (shown in Figure 3).

    2. For the non-proprietary service tool:

      1. On the Common Service Desktop, select the Calibration tab.

      2. From the Calibration menu, select UPM Tool.

      3. Select Click here to start this tool to open the UPM Tool.

  4. Make the following selections for the settings.
    Table 4. Body Mode Settings
    SettingValue
    TaskLaunch RF Cal
    RF ChainBody
  5. Select Start.
  6. When a popup appears asking if the system is properly set up, click Yes.

    The system sets the proper sequence for RF calibration of the body channel. This process takes about one minute.

  7. When a popup titled RF Amp Calibration appears, do not select anything.
  8. Click the Patient icon to go to the Scan workplace.
  9. In the Prescan Looping window, set the Transmit Gain (TG) to 180. Confirm that a reading is present on the Wattmeter.

    If the reading is zero or very low, confirm correct center frequency value and then select Done to stop looping and recheck test setup cabling.

  10. If the amplifier trips, reset the TG to its highest setting before tripping.
    Note: If Manual Prescan must be stopped and restarted, you must re-launch the calibration sequence using the UPM Tool. Select Failure in the RF Amp Calibration popup (see Figure 4), and then click Start on the UPM Tool with the same menu selections to re-launch the calibration sequence.
  11. Slowly increase the TG to 200.
    Note: Check the system center frequency NOW, especially if this is a new installation, and confirm that it consists of 8 digits and that it is correct. The RF amplifier will output a low and distorted RF waveform if center frequency is wrong due to a missing digit.

    If the RF amplifier trips, adjust the Body Gain pot counter-clockwise to reduce the RF output power and then increase the TG. Repeat this process until TG = 200 and the body RF output power is 16 ± 0.5kW (72 ± 57dBm).

    Allow 10 seconds for the meter reading to stabilize before making the next adjustment.

    Note: The Power Amplifier should be capable of 0.3dB to 0.4dB more than the required 72dBm RF output. Improperly adjusted systems will trip if the gain is set above 72dBm, creating a Peak Power Fault.
  12. Verify that the Unblank LED on the front of the SRFD2 Module pulses on/off, indicating that the amplifier is outputting RF energy.
  13. If the SRFD2 faults with a peak power fault error and the cabling to and from the SRFD2 is correct, you need to calibrate the amplifier (see Adjusting the Body RF Output).
Topic ID: id_SL4178220-1137108

Adjusting the Body RF Output

Procedure

  1. Check the output against the specification, using the correct method for your measurement type:

    • If using the RF Power Measurement Kit, refer to the specified number of divisions printed on the RF Power Measurement Kit card 72 (1.5T Body RF Output) needed to achieve 16kW of RF power output. Adjust the Body Gain pot on the front of the SRFD2 (Figure 7) so that the RF waveform displayed on the scope meets, but does not exceed, this number of divisions.

  3. Go back to the CSD by clicking the CSD icon.
  4. If the RF output is within specification, click Success on the RF Amp Calibration popup (see Figure 4).
    Note: The RF Amp Calibration popup may be hidden behind the ICW window. Move the ICW window to the left or right to see the RF Amp Calibration popup.
  5. Click Yes to confirm that the RF Output was successful.

    After a few seconds, PASS appears in the status area of the UPM Tool.

  6. After calibrating the body channel, continue with UPM Calibration.

UPM Calibration

About this task

This procedure sets up the Universal Power Monitor (UPM) in Body mode by using the system and the Power Measurement Kit. For 1.5T systems, only Forward Power must be completed.

Topic ID: id_SL4171326-1137108

Body Forward Power Calibration

Procedure

  1. DANGER
    FATAL ELECTRIC SHOCK HAZARD!
    dangerous voltages throughout the cabinet.
    TO PREVENT FATAL electrical SHOCK, MAKE SURE THE RF AMPLIFIER IS DISABLED WHEN CONFIGURING THE CALIBRATION TOOLS.
    Note:

    If you are continuing from the Body RF Amp Calibration section, the hardware setup should already be done. Go to Setting Up Software Tool to Calibrate UPM - Body Forward Power.

    To inhibit TR faults, disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet). Move the SW2 switch to the TR DISABLE position.
  2. Remove the Body Heliax Cable from J4 on the back of the RF Amplifier, and connect the RF dummy load into J4.
    Note:

    If the RF Calibration procedure was just completed, the configuration is the same. Leave the Body RF Heliax Cable disconnected, and keep the coupler (1.5T) in line on the Body output. It will not change the outcome of the calibration.

Setting Up Software Tool to Calibrate UPM - Body Forward Power

About this task

This tool must see a landmark only. It is not necessary to have a body phantom in place or any other scan parameter entered other than what is described below. Simply landmark on the cradle where the body phantom would be.

Procedure

  1. Press the Align button.
  2. Move the cradle into the bore.
  3. Press the Landmark button when the alignment light is approximately where the center of the Body Phantom would be.
  4. Start the UPM Tool:
    1. Proprietary tool (available to GE Field Service only):

      1. Verify that the service key is installed.

      2. From the Calibration menu, select Calibration Wizard, and select Click here to start this tool.

      3. After the Calibration Wizard starts, select RF/UPM Calibration & Functional Check (Body) from the menu.

      4. Review and confirm the pre- and post-calibration dependencies.

      5. To start the procedure, select Click here to start the tool.

        The UPM Tool is displayed (see Figure 3).

        If unable to start the Restricted Service Tools, use the non-proprietary method.

    2. Non-proprietary service tools:

      1. From the Common Service Desktop (CSD), select the Calibration tab.

      2. From the Calibration menu, select UPM Tool

      3. Select Click here to start this tool.

        The UPM Tool is displayed (see Figure 3)

  5. Make the following selections for the settings.
    Table 5. Body mode setting
    SettingValue
    Nuclei1H
    TaskCalibrate UPM
    RF ChainBody
    Power TypeForward
  6. Select Start and verify that the hardware setup works, and then select Yes.

    After approximately one minute, you are prompted to confirm the peak power value output from the amplifier. The peak power should be 12% of 16kW. If the power read from the power meter is within these limits, click Yes. Otherwise, click No and re-check calibration of RF amplifier.

    Note:

    This RF Amplifier power measurement check of within 12% of 16kW during UPM calibration is performed only as a sanity check and does not have any correlation with RF Amplifier calibration specifications.

    The tool reports the steps as they progress. The Status field on the UPM Tool interface should say PASS or FAIL within about three minutes.

UPM Functional Check

About this task

RF output must be calibrated and UPM calibration must be completed for body channel before performing these functional checks.

Topic ID: id_SL4173512-1137108

Body UPM Functional Check Setup

About this task

The Universal Power Monitor (UPM) functional checks for 1.5T consist of three automated tests: 10-second average power check, RF inhibit test, and short-term average power fault host trip test.

Procedure

  1. To inhibit TR faults, disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet). Move Switch 2 to the TR Disable position.
    Note: If you are continuing from the Body RF Amp Calibration procedure, the hardware should already be set up. Go to Setting up Software Tool for UPM Functional Checks.
  2. Remove the Body Heliax Cable from J4, and connect the RF Dummy Load into J4.
    Note:

    If the RF Max Power Out procedure was just completed, the configuration is the same. Leave the Head RF Heliax Cable disconnected, and the body output can keep the coupler in line. It will not change the outcome of the calibration.

Setting up Software Tool for UPM Functional Checks

About this task

This tool must recognize a landmark. It is not necessary to have a body phantom in place or any scan parameter entered other than what is described below. Simply landmark on the cradle where the body phantom would be located.

Procedure

  1. Press the Align on button.
  2. Move the cradle into the bore.
  3. Press the Landmark button when the align light is approximately at the center of the Head Coil.
  4. Press Advance to Scan.
  5. Start the RF/UPM tool:

      1. From the Common Service Desktop, select the Calibration tab.

      2. Choose Click here to start tool.

      3. Select RF/UPM Cal & Functional Check (Body).

    2. For the non-proprietary service tool:

      1. From the Common Service Desktop, select the Calibration tab.

      2. From the calibration menu, select UPM Tool.

      3. Select Click here to start this tool.

  6. Make the following selections for the settings.
    Table 6. Body mode setting
    SettingValue
    Nuclei1H
    RF ChainBody
    TaskUPM Func Chk
    Note: Power Type is grayed out. This is normal and is not used.
  7. Select the Start button. Click Yes in answer to the setup question.
  8. You will see prompts during test execution. The following illustrations show examples of the popup and error log that should be seen. Verify the error log and click Yes if an error message is seen.
    Note:

    The tool performs three tests before Host Trip. It takes 2 to 3 minutes before user interaction is needed.

  9. If functional checks pass, the status area of the UPM Tool will display a message saying PASS. Continue to Finalization.
Topic ID: id_14995826

Finalization

Procedure

  1. Remove the cables and power measurement equipment.
  2. Reconnect the Body Heliax Cable to the amplifier.
  3. Re-enable T/R Drive fault detection (see Figure 9).
  4. Upon completion, select Reset TPS. The system will not scan until this is done.
