Head Coil Setup

Procedure

  1. Place the split head coil on the cradle and connect the connector to LPCA.
  2. Place Head sphere phantom, loader, and positioner in the head coil. See Figure 1.
  3. Press Alignment light button. Move the table into the bore so that axial alignment hit on the axial line on the loader in the head coil. Press landmark button and then press the MOVE TO SCAN button.

Invoking SPT Full Test Mode

Procedure

  1. Notice
    Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on End Exam to terminate any previous exam. It is not necessary to click on New Pt as SPT automatically enters the scan protocol when it is invoked via the MR Tools menu.
    To start the SPT Full Test tool from the Service Browser, follow the steps on Figure 2, below.
  2. The SPT Head Coil Selection screen appears. See Figure 3.
  3. Select 'Split Top Head Coil and Phantom' then click on Start. A SPT Test menu appears in a window on the desktop ).
    1. In the Select All tests field, click No.
    2. Select 'Head' for Coil Type.
    3. To select a reason for the test, click the button to the right of Test Purpose. Select a reason from the list. If desired, enter text in the Comments field.
    4. Click the On button to select the SNR.
    5. Leave the other button as they are.
    6. Click Start SPT to begin.

      Status messages will appear in the text box below the menu as the tests are run. Use the scroll bar on the right side of the box to move up or down through the messages.

  4. To exit SPT, click the [Quit SPT button.
  5. To view SPT results, select the Utilities tab on the Service Browser, then select Report Manager.
  6. Enter the Report Manager password (the same password used for the Service Methods CD-ROM) and press Enter.
Topic ID: id_15004312

Finalization

Procedure

  1. Do a TPS Reset after completing SPT to put the system back.
  2. If for any reason a SPT scan is aborted, Shutdown and Reboot the system.
