Procedure

  1. Run the Driver Module Functional Diagnostic.
    1. Open Common Service Desktop.
    2. Select 'Diagnostics / Hardware Location / System Cabinet / Driver Module Diagnostics'.
    3. Select 'Power Supply Data' and Select 'Run'.
  2. Check that the result values satisfy the specification. See Table 3 for Specification.
    Table 3. Power Supply Specification
    Power Supply Specification
    ISO 24V 21.0 < Value < 26.0
    POS 15V 13.5 < Value < 16.5
    NEG 15V 13.5 < Value < 16.5
    POS 12V 10.5 < Value < 13.5
    NEG 12V 10.5 < Value < 13.5
    NEG Drive 15V 13.5 < Value < 16.5
    POS Drive 12V 10.5 < Value < 13.5
    MC1 POS 10V 9.0 < Value < 11.0
    MC1 NEG 10V 9.0 < Value < 11.0
    High Volt 475 < Value < 600
    DCB 3.3V 3.1 < Value < 3.5
    DCB 5V 4.7 < Value < 5.3
    DCB 3.3V Current (A) 0.0 < Value < 3.3
  3. Select 'IO Status' and Select 'Run'.
  4. Verify that Fan1 and Fan2 are Operational. Check that there is no 'Fail' or 'Not Present'.
