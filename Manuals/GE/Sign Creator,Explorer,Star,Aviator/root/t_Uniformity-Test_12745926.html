Uniformity test

Procedure

  1. At the scanner, remove any surface or head coil from the bore.
  2. Set the angle of the phantom to 0 degrees.
    Note: Allow the phantom solution to settle for 5 minutes before scanning. This prevents flow-related artifacts, which can affect the test results.
  3. Landmark on the center of the phantom. Press Landmark and Advance to Scan on the keypad on the front of the magnet enclosure.
  4. Install the service key.
  5. Notice
    A localizer body scan must be run before the automatic uniformity tool.
    At the operator console, select New Pt and prescribe the following scan:
    ID: geservice
    Name: Localizer
    Weight (Lb): 150
    Patient Position: Supine
    Patient Entry: Head First
    Coil: Body
    Plane: 3-Plane
    Mode: 2D
    Pulse Seq: Gradient Echo
    Grad Mode: Whole
    Imaging Options: Seq, Fast
    FOV: 40 cm
    Slice Thickness: 3.0 mm
    Spacing: 0
    Scanning Range: S/I = 0, R/L = 0, A/P = 0
    # of Slices: 1
    Freq Matrix: 256
    Phase Matrix: 128
    NEX: 2.0
    Phase FOV: 1.0
    Freq Dir: Unswap
    Autoshim: Auto
  6. Select Scan and allow the scan to complete.
  7. Notice: Do NOT re-landmark between scans.
    In a command window, type the following:
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.

    cd /usr/g/service/mclass/uniformity

    touch .uniformity_enable

    run_uniformity_tool

    The Uniformity Tool screen displays with the scan status and results.

    All buttons are inhibited during a scan. Only the Abort Scan button is available during a scan (but is inhibited when the scan is idle).

  8. From the Data acquisition mode menu, select either Single Scan or Four Scans.
  9. Click Scan and Analysis.
  10. Click Yes when asked, Have you landmarked?
  11. Rotate the phantom to horizontal as instructed, wait 5 minutes for it to settle, then select Continue to start the scan.
  12. During the scan, record the RF amplifier peak forward (FW) power value from the LCD display on the front of the RF amplifier in Table 3.
  13. If Four Scans was selected, a dialog displays requesting you to reposition the phantom after the first scan.
    Note: If Single Scan was selected and if the site is running DV25 software version or later, two plots appear. Figure 4 shows the profile of the ePhantom. Figure 5 shows the uniformity plot for the ePhantom. These plots are used for the centering of the body coil on the MR750 system. They can be ignored for other systems.
    Note:

    The illustration below shows the various phantom positions as viewed from the table end.

  14. When asked to position the phantom, rotate it counterclockwise to the 45-degree plane, and wait 5 minutes for the phantom to settle. Select Continue to start the scan.
  15. During the scan, record the RF amplifier peak forward (FW) power value.
  16. After the second scan completes, a dialog displays requesting you to reposition the phantom.
  17. When asked to position the phantom, rotate the phantom counterclockwise to the 90-degree plane, and wait 5 minutes for the phantom to settle. Select Continue to start the scan.
  18. During the scan, record the RF amplifier peak forward (FW) power value.
  19. After the third scan completes, a dialog displays requesting you to reposition the phantom.
  20. When asked to position the phantom, rotate it counterclockwise to the 135-degree plane, and wait 5 minutes for the phantom to settle. Select Continue to start the scan.
  21. During the scan, record the RF amplifier peak forward (FW) power value.
  22. The scanner stops after scanning in the 135-degree position, and automatically processes and displays the results.

    The screen indicates if the Uniformity test passed or failed.

  23. Record the TG and uniformity (U) values in the table below.
    Table 3. Uniformity phantom data table
    Elliptical Phantom Position Exam/Series/Image TG Power Uniformity
    FW Channel 1 FW Channel 2 U
    0
    45
    90
    135
    Note:

    The body peak power or RF amplifier peak forward (FW) power values vary somewhat during a scan, but a general reading can be determined within a few seconds. Be consistent throughout this procedure in the method used to record this value.

    TG values can be obtained from the Uniformity Tool screen results.

  24. The screen indicates if the Uniformity Test passed or failed. If it failed, proceed to the coil alignment section of 3.0T Twin RF Body Coil Replacement to align the coil.

Finalization

Remove service equipment, phantom, and head coils.
