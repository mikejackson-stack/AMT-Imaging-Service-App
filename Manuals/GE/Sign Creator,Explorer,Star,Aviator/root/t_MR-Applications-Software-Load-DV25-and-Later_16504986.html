MR Applications Software Load (DV25 and Later)

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-30 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
MR Applications Software DVD1--

About this task

Important: Make sure that the latest service pack is loaded. Refer to the latest revision of the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library. If more information is needed for how to load service packs, see Installing service packs.

Procedure

  1. After the system reboots, the Welcome to MRHost screen shows. Log on using these parameters:
    • User ID: root
    • Password: operator
  2. Insert the MR Applications Software DVD into the appropriate DVD drive when prompted. Click OK after the DVD drive LED stops blinking.
    Note:

    Dell T5810 host PCs have two solid-state disks. Raid will not be created for the /export/home1 partition. One disk will be used for the OS while the other will be used for the /export/home1 partition.

  3. From the Select your locale window, select the correct language for the site. Click OK.

    A series of messages and a progress bar report the progress of the installation. When complete, the Guided Install screen opens.

  4. The prompt Do you want to load GI Configuration from DVD? opens.

    • (For existing systems or training PC reinstallation) Insert the Save Info media and select Yes after the DVD drive LED stops blinking. Load GI restores Guided Install information. When the process is complete, reinsert the MR Applications Software DVD and continue to HIPAA/Security .

      Note:

      If upgrading to a new configuration, make sure that the same configuration is applied in Guided Install. See Guided Install Site Configuration Options for more information.

    • (For new systems) Close the drive and select No. Use the information recorded in Guided Install Site Configuration Options to complete this section.

    • (For first-time training PC installation) Close the drive and select No. Use the information recorded in Guided Install Site Configuration Options to complete this section.

  5. Select security level.
    1. Go to Preferences > HIPAA/Security.
    2. Select the security option appropriate for the site per the customer. See Security levels for more information.
    Note:

    You cannot choose Signa Secure Advanced at this point. If the customer has purchased the Signa Advanced key, complete the remaining software installation in typical security mode, then download the options and configure to the Signa Secure Advanced.

  6. Continue to the Verification tab. Review the entries on the page to determine if all entries passed verification (the Install Software button will not be active if there are any failures). Failed entries result from missing or improperly formatted entries.
    1. Go to the tab with the error and correct it. Click Install to open the Verification tab again.
    2. If all entries pass verification, click Install Software to begin the MR applications load. This process takes 15 to 20 minutes.
      Note:

      A prompt shows reminding you to configure the NTP server (if present) through the Network Info tab. It also reminds you to make sure that the current time and time zone are configured properly on the Set Time/Date tab.

      If both are correct, select Confirm. If not, select Abort and configure the NTP server (if present) and the current time and time zone.

  7. A confirmation message shows after the applications load completes. Click OK to close the window. Return to to continue installation.

Finalization

Important: Make sure that the latest service pack is loaded. Refer to the latest revision of the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library. If more information is needed for how to load service packs, see Installing service packs.
