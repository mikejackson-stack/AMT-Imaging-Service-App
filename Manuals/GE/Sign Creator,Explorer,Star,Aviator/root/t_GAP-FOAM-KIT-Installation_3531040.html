Note:

If there are multiple Tables at site, please order the GAP FOAM KITs according to the number of the Table at site.

About this task

If the Table is adjusted correctly according to the Service Methods, the gap between the patient table and enclosure bridge satisfies the specification of IEC/UL. Also, the following caution is described in Operator Manual.

Caution Make sure the patient connected IV lines, oxygen tubing, urinary catheters, and any other tubing and cables are long enough to allow full travel of the system and will not become entangled, pinched, or pulled.

The foam installation is needed to minimize the gap to prevent possibility of tubing/cables such as intravenous drip tubing to be caught on this gap. This procedure introduces the FRU and procedure to adhere gap foam.

Topic ID: id_SL3140521-1101665

Notes of installation

Procedure

  1. Pre-requisite Condition:

    • Table must be adjusted according to Service Methods before installing GAP FOAM.

  2. Degreasing Table and Bridge

    • Wipe the foam mounting locations with alcohol.

    • Dry out the alcohol before attaching the foam pieces.

  3. GAP FOAM Installation

    • Do NOT re-use any foam which was once attached and subsequently removed. Once it is removed, the adhesiveness will be significantly weakened.

    • It will take 24 hours for the foam adhesive to set firmly. Please inform customer to treat foam carefully for 24 hours after installing gap foams.

  4. Shapes

    There are two types of GAP FOAM in GAP FOAM Kit. And, there are two pieces for each types. Please make sure to identify the foam shape before starting the procedure. Refer to the following illustration for the shape and name of each foam piece.

  5. If Table adjustment is performed in the future, check that the GAP FOAM location satisfies the conditions of Figure 7 and Figure 8. If the GAP FOAM locations do not satisfy the conditions, please order GAP FOAM and attach them according to this Procedure.
  6. At every PM visit, FE’s need to check if there is any damage or peeling of this foam, and to replace it if necessary.

Foam Installation to Table side

Procedure

  1. Prepare the following foams for each side of Table. DO NOT attach each foam now. Figure 6 is showing the types of foam to be attached.
  2. Move and dock the Table. Move the Table to uplimit.
  3. Figure 7 shows the side view of Table and Bridge. Match the slope of GAP FOAM for the Table to the GAP FOAM on the Bridge side.
  4. Figure 8 shows the top view of Table and Bridge. Align each foam edge.
  5. Attach each foam to the table following the conditions of Step 3 and Step 4.
Topic ID: id_SL3140544-1101665

Adhere the GAP FOAM

Procedure

  1. Undock the Table.
  2. Push each GAP FOAM vertically to adhere them securely.
    Note:

    It will take 24 hours for the foam adhesive to set securely. Please inform customer to treat foam carefully for 24 hours after installing gap foams.
