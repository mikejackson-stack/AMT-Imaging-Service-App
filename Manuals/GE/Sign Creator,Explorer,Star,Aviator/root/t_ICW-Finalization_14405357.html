ICW Finalization

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable45 minutesNot Applicable

About this task

Finalization can be run at any time during the install flow. It is one of the final steps of the Installation Portion of the Installation Calibration Wizard. During Finalization, there are six tasks that must be completed and checked off:

  • Magnet Monitor Checkout

  • Functional Check of Magnet Pressure Control

  • Oxygen Monitor Setup and Calibration

  • Initialize Planned Maintenance

  • Perform Save Info

  • Enter Product Locator information in GIB

Procedure

  1. Insert the Service Key
  2. Launch the Service Browser (Common Service Desktop)
  3. Click on the Calibration Tab.

    If you are in Install mode, click on [Install and Calibration Wizard] ⇒ [Click here to start this tool].

  4. See Figure 1.
  5. Call the On Line Center to perform checkout of the Magnet Monitor. Be prepared to provide the Cryogen ID. The customer provides the Cryogen ID, usually at the same time as they provide the System ID. When this is complete, check the box next to “Is Magnet Monitor Checkouted with OLC?”
  6. Perform Magnet Pressure Control Functional Check. Do this by viewing pressure reading on the Magnet Monitor. For LCC magnets, it should be between 3.9PSI-4.1PSI. When this is complete, check the box next to “Is Magnet Pressure Control Functional Check done?”
    Note:

    The Magnet Pressure Control Functional Check only needs to be performed for LCC magnets. For all other magnet types, it is not necessary to perform the Magnet Pressure Control Functional Check. Check this box to indicate complete.

  7. Perform Oxygen Monitor Setup and Calibration. When this is complete, check the box next to “Is Oxygen Monitor Setup and Calibration done?”
  8. Initialize Planned Maintenance. When this is complete, check the box next to “Is Planned Maintenance Initialization done?”
  9. Perform SAVE INFO.. Then, perform Verifying Save Restore Media . When this is complete, check the box next to “Is Save Info done?”
  10. Enter Product Locator information in Global Installed Base. Refer to Where is product locator card ... for location. This can be done one of two ways. Collect all Product Locator Cards from equipment, then either:
    1. If you do not have easy access to GE Intranet Connectivity, complete the information on the cards and send via regular mail.
    2. If you have a connection to GE Intranet,

      1. Use web link to GIB: http://egems.gehealthcare.com/gib/gib_MainMenu.jsp

      2. Log on using SSO # and password.

      3. Select Global Installed Base Entries.

      4. Scroll down and enter the customer's System ID and Country.

      5. Click on Submit.

      6. vi. Click on New Entries:

        1. For Model - enter the GE Part Number (example:2357500)

        2. For Serial - enter the system cabinet serial number (example: 00000259976MR9)

        3. For Inst./Deinst Date (YYYY-MM-DD): - enter the system installation date shown at the top of the page.

      7. For Add (A): - enter A

      8. Click on Submit

        When this is complete, check the box next to “Is Product Locator Data entered into GIB?”.

  11. Applicable Service Licenses generated and installed on system. (see Service Licensing )
  12. Click Submit

Finalization

  1. Dispatch your hours for the install.
  2. If there are remaining steps in the Installation Calibration Wizard, return to the ICW procedure for information regarding how to advance to the next calibration and for links to other calibration procedures.
  3. If all the steps of the Installation Calibration Wizard are complete and have passed, close both the Installation Calibration Wizard and the Common Service Desktop. The next time the Installation Calibration Wizard is accessed from the Common Service Desktop ⇒ Calibration tab, the wizard will be in Maintenance Mode. Information for Maintenance Mode can be found in Install and Calibration Wizard.
