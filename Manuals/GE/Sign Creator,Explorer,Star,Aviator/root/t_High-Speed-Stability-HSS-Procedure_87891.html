Overview

The HSS (High Speed Stability) test evaluates the effects of vibration, or other rapid environmental or system phenomena, on the stability of the MRI process, or of the hardware used to receive and process MRI signals. For TwinSpeed, select one of the gradient coils to be used for the tests, and complete it with the same GradMode. For Help with HSS, see the following documents:

  • Analyzing HSS Results

  • Troubleshooting Phase Ghosting on CX Magnet

  • HSS and Vibration Troubleshooting

  • HSS Theory

note:

HSS Viewer will automatically start once the scan (described in the procedure below) is complete.

note:

Report Manager/ Viewer help can be obtained from the tool itself. Alternately, HSS files can be viewed by the report manager tool too.

2 Procedure

This section includes both Low- and High-Frequency Bandwidth tests.

Procedure

    note:

    Make sure the RF Amplifier is set up per RF Amplifier Setup, “RF Amplifier Setup.”

  1. Connect the cable from Universal 1.5T or 1.0T SST RF coil to the proper adapter.
    2. note:

    For 1.5T, use Extremity Coil/Linear Head Coil Adapter or 1.5T Service Tool Interface; for 1.0T, use the Service Tool Interface Adapter.

  2. Insert the proper sample vial into the coil.
    note:

    Use 0.25M NiCl2 (green in color) for low-bandwidth mode (to test for vibration disturbance).

    note:

    Ensure no solution is trapped in the top section of the vial before inserting the vial into the coil. If solution is trapped in the vial top, correct by flicking the vial with your finger to knock the solution to the bottom of the vial.

    • notice
    • SAMPLE MOTION CAN AFFECT HSS OUTPUT. TO ENSURE THE VIAL FITS SNUGLY INTO THE COIL HOUSING, A PIECE OF TAPE CAN BE WRAPPED COMPLETELY AROUND THE VIAL BEFORE PLACING INTO THE HOLDER.
  3. Disable the TNS.
    1. Position the base plate at the head end of cradle. Place and lock the coil into the base plate in the corner; then connect the adapter to the head carriage (see Figure 3).
    2. Landmark on the center of the base plate. The Coil / Sample should be off the iso-center in all 3 planes.
    3. At the MR Service Desktop, start HSS Tool as shown in Figure 4.
    4. If this system has an SRFD2 Cabinet or RFS Cabinet, as show in Figure 2, then Click on the Select Port Pull down and select Head Port as shown in Figure 5.
    5. If this system has an SRF cabinet, as shown in Figure 1, leave the Select Port selection defaulted to Test Port as shown in Figure 6.
    6. Select Scan From the HSS GUI
    7. The prescan and scan will be done automatically. No user scan setup is required. The scan will take a few minutes to complete.
    8. After the scan is finished the HSS Viewer will automatically start. Please see the Viewing Results for instructions concerning how to display the results.

    3 Finalization

    Procedure

    1. Restore the connections at the back of the RF cabinet (refer to RF Amplifier Setup initial setup.
    2. Remove all SST Coil hardware (coil, test cables, etc.) from the bore.
    3. Go to the Utilities menu – select Raw File manager – and click as shown in Figure 7 to start the tool. A screen similar to the one as shown in the Figure 8 will pop up.
    4. Under the DISK heading, highlight the HSS files, and click on Delete.
    5. Perform at least one head scan to verify proper system operation. For TwinSpeed, repeat for each gradient mode.
