Emailing licenses

The license file can be e-mailed to any e-mail address. Then, save this file to a CD/DVD/USB, or print it, or send it through SFTP to the target system as described in.

Procedure

  1. From the System Information screen, select Email Licenses.
    The Email License Keys window displays, as shown below.
  2. If needed, add additional e-mail addresses to this message.
    • If the recipient is a GE employee, enter their first and last name, and then click Search. Select the name you want from the list.
    • If the e-mail address is an external address, type it in the Address field, and click Add.
  3. Open the email and save the attached license.sh file to a local directory.
  4. Choose one of the following installation methods.
    • Installing from an eLicense CD/DVD.
    • Transferring option keys with a USB flash drive.
    • Transferring option keys with SFTP.
    • Printing licenses and manually entering option keys.
