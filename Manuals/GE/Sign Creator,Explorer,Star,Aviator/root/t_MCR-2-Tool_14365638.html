About this task

The MCR 2 and MCR 3 tools are identical in functionality. The only difference is that the MCR 2 tool cannot be used with systems that have the HDx LPCA. Legacy systems that have been upgraded to 32-channels or have a forward production LPCA were provided with a new MCR tool that replaces the MCR 2 tool.

Running MCR 2 Diagnostics

Procedure

  1. Start the Common Service Browser if it is not already running.
  2. Click the Diagnostics tab and then click the Multi-Coil Receive II Diag from manual diagnostics link. See Figure 1.
  3. Once on the MCR2 Diag page, Click the Troubleshooting Overview link in the center of the page for hardware hookup information. See Figure 2.
    Note:

    Additional troubleshooting information can be found in MCR 2 Troubleshooting (links to a separate document).

  4. Troubleshooting flowcharts for Connector A and Connector B can be obtained from the hyperlinks in “Troubleshooting” section as shown in Figure 1 below.
  5. Once tests are setup, Click the Run button. The test should indicate in the lower Test Status window that it is executing.
  6. The test will complete in about 25 seconds. After the test runs successfully, we get the screen as shown in Figure 3.
  7. Failures are highlighted in red font while passing data is always highlighted in blue font.
  8. Once testing is complete, perform a TPS Reset before continuing.
