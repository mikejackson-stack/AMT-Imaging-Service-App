Hardware Set-up

Procedure

  1. Unfold the 6-coil grafidy fixture and lock the arms into place. Place the fixture at the front (Head coil end) of the MR table with the connection box away from the bore.
  2. With the SMA to BNC cable, connect J7 on the grafidy connection MUX box to the service quick disconnect (QD box). Plug the service QD box into the system connection on the table. See Figure 1. (Coil ID light will not come on.)
  3. Connect one end of the (9 pin) data cable to 9 pin plug on the grafidy connection MUX box, and the other end to an open slot on the pen panel. Tighten (but don't over tighten) the retaining screws.
  4. Go to the equipment room side of the penetration panel, and connect the second (9-pin) data cable to the matching slot selected in the previous step. Route this cable to the front of the system cabinet.
  5. Connect the 4-to-1-connection cable to the (9 pin) data cable routed to the system cabinet inStep 4 above. Connect the 3 BNC connections to J12, J13, and J14 on the FP I/O, as labeled on the cables.
  6. Connect the output of the 5V plug-in power supply to the remaining connector on the 4-to-1-cable and plug the power supply into the outlet at the bottom of the Systems Cabinet (see Figure 3). Verify that the Service Outlet Power Switch is “ON”.
  7. Check that the system is not scanning. At the back of the RF Amp, remove the RF input cable from J14 and connect it to the variable attenuator. Connect the small BNC wire from the attenuator back to J14 (RF input). Set the attenuator to 40dB.
  8. Return to the magnet room and center the laser crosshairs on top of the fixture. Landmark the system and press Advance to Scan.

Running Grafidy 3

Procedure

  1. From the Common Service Desktop, select the Calibrations tab and start the Grafidy 3 tool.
  2. The tool will load with the Zero Out tab selected (see Figure 5). The first time you run Grafidy (in both modes), you should zero out all of the values (except for the shorts.) Click the Select All button, and then Zero Out Cal Values.
  3. If you receive the following message about short TC Cal Values, click Yes.
  4. Click on the Auto Mode tab. All three coil axes will be selected. Click the Scan button to start the calibration. (When the scan is active, you can stop it by pressing the Abort button.)
  5. The Grafidy 3 software runs multiple scans to bring each term into specification. It iterates up to the maximum specified (default is 5). This usually takes about 4 hours, the first time it is run.

    As each component finishes a scan/analysis iteration, the residual of the eddy current of the measurement displays in the results table. The results are color-coded, see Table 5.

    Table 5. Color Coding
    Text Color Meaning
    RedValues above spec.
    GreenWithin Spec

    Review the numeric output values from the auto mode scan. Verify that the results of final iteration for each component are at or below target (green). SeeFigure 8 for help in reading output values.

  6. If a component is not in spec after the maximum number of iterations you will need to use manual mode to calibrate that component. See Manual Mode.

Manual Mode

About this task

Use Manual Mode when Auto Mode fails to bring one or more of the terms into specification. Manual Mode lets you iterate through process yourself, and decide when to stop.

Procedure

  1. Select the Manual Mode tab.
  2. Select the desired terms, and then press Scan.
  3. After the scan is complete, a graph of the results will pop up (see Figure 10).
  4. If a “good fit” is shown (i.e. residual eddy currents are getting smaller), click the Accept button. The values will be saved to disk, and these values will be used in the next scan. Repeat this process by going back to Step 2.
  5. If a “bad fit” is shown (i.e. residual eddy currents are increasing), click Cancel. This will leave the last accepted values in the calibration files. Do not expect any improvement on future scans when the plots diverge.
  6. The last iteration for any component should be a check only, and you should not accept them.
  7. Refer to Working With Grafidy 3. Or if problems are encountered, see EXCITE 3.0T Grafidy 3 Troubleshooting.
