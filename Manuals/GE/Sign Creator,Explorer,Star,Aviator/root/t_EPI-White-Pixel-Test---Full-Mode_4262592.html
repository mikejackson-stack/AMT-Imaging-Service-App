This procedure uses EPI scans and the raw data mode of reconfiguration to analyze the raw data for white pixel artifacts; these can exhibit themselves as corduroy artifacts in images. There are two modes of operation for the EPI White Pixel Test.

  • Mode 1 creates 48 images while iterating on Readout Axis (X, Y, Z), ESP (readout train frequency), and placement of the data acquisition window over the attack "knee" and decay "knee" of the readout trains’ positive and negative lobes. In addition, Mode 1 generates various report fields and plot files that can be used to analyze white pixels. Mode 1 was incorporated in the EPT test to be run as a single test.

  • Mode 2 prompts the user to enter an image number that generates the most white pixels from the Mode 1 test, and allows use of the real time display feature of EPI to loop on that condition for troubleshooting purposes.

Procedure

  1. At the keypad on the front magnet enclosure, press LANDMARK and proceed as follows:
    1. (For Body EPI White Pixel) Remove the head coil.
    2. (For Head EPI White Pixel) Place an empty head coil on the cradle.
  2. Press Move to Scan.
  3. On the Service Desktop, start the Service Browser (if not already running) and select the Image Quality tab, select EPI White Pixel Test and Click here to start this tool as shown below.
  4. When the EPICal screen displays, answer each question shown below.
    note:

    To run Mode 2, follow the instructions above to start the tool, but select Mode 2. Mode 2 runs continuously for approximately four minutes for troubleshooting purposes (provided the pause key is not pressed).

  5. For the question, Do you want to run raw data analysis?, respond YES.
    note:

    A file named sn_report.body or sn_report.head (depending on which coil is being scanned) is created showing a header file and the white pixel information if any. If there are no white pixels detected, only the header information will appear in the file. These output files are stored on the system in /usr/g/bin.

  6. When prompted for the image number, enter the image number (1 to 48) determined from completing Mode 1.

    The following prompt will display:


                              Hit Scan to start scan in RTD mode. (Select [Scan] on the Scan desktop
    Use [Pause] and [Start Scan] hardkeys to start and stop scan
    while troubleshooting. (Return to the service desktop)
    Hit [Stop Scan] hardkey if you want to finish before the scan
    completes.

    Carriage return here to exit Mode 2...
                            
  7. To repeat the looping process, return to the Scan desktop and press the Scan button again, and use the hard keys to run as previously instructed.

    The table below indicates how the logical to physical gradients are played out in Mode 1 operation. It also indicates which images from Mode 1 are using which scan plane (useful information when using this tool in Mode 1 or 2). Typically, the frequency encode axis is the one that generates the spike noise because that is the axis that has the high amplitude, high duty cycle EPI readout train. This is not always the case as there have been instances when the phase encode axis caused problems resulting in defective gradient filter boxes.

Finalization

  1. Perform a Check Scan to verify proper operation.
  2. Turn the system over to the customer.
