Grafidy adjusts and compensates short, long, and very long time constant eddy currents for both linear and B0 terms. Use the Grafidy procedure to perform eddy current compensation. Grafidy should be run in auto mode first. If auto mode fails to bring any of the terms into specification, manual mode can be used.

Grafidy uses a dedicated pulse sequence, six-channel fixture, and Grafidy software. The Grafidy P-port connector plugs into the port for transmit/receive. No additional fixtures or cables are needed.

This tool simplifies setting up the calibration and collects data from all six coils simultaneously.
