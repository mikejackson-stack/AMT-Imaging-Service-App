Overview

IMPORTANT: Make sure that the latest Service Pack is loaded. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library.

If more information is needed for how to load Service Packs, see Installing Service Packs.

Procedure

  1. When prompted, insert the MR applications software DVD into the appropriate DVD drive and click OK.
  2. A message appears, stating that the MR applications software installation is in progress.

    If this message does not appear, right-click on the desk top and choose Install MRApps to begin installation.

  3. The system begins partitioning hard drives, which takes 10-15 minutes. A progress window appears.
  4. From the HDD Preparation Complete window, click OK to start Guided Install.
  5. From the Locale Selection window, select the correct language for the site.
    1. Check Set as default.
    2. Click OK.
  6. The Guided Install screen appears, followed by the Message screen. Review the improvements made from the previous software version and click OK after the DVD drive LED stops blinking. Use the information recorded in Guided Install Site Configuration Options to complete this section.

    • (For HP Z400/Z420 PC) The MR Applications Software DVD automatically ejects. Remove it from the drive.

    • (For XW8400 PC) Leave the MR Applications Software DVD in the top DVD drive.

  7. Proceed to the Verification tab. Review the entries on the page to determine if all entries passed verification (the Install Software button will not be active if there are any failures). Failed entries result from missing or improperly formatted entries.
    1. Go to the tab with the error and correct it. Click Install to open the Verification tab again.
    2. If all entries pass verification, click Install Software to begin the MR applications load. This process takes 15-20 minutes.
      note:

      A prompt appears, reminding you to configure the NTP server (if present) through the Network Info tab. It also reminds you to verify that the current time and time zone are configured properly on the Set Time/Date tab.

      If both are correct, select Confirm. If not, select Abort and configure the NTP server (if present) and the current time and time zone.

  8. A confirmation message appears after the applications load completes. Click OK to close the window. Return to to continue installation.

Finalization
