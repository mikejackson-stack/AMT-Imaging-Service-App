IBIS Specifications

Test Procedure Criteria for Passing Notes
PM Schedule Run once at time of system turnover.
Updates Go to CSD, PM section and execute PM Patch. Document can be found in PM Assist Broadband site: Informs FE of available Upgrades needed, and Upgrades that have been automatically downloaded, then prompts FE to load Upgrades. No Customer notification
LVShim Go to CSD, PM section and execute LVShim. Document can be found in PM Assist Must meet Customer Acceptance values in following links (BRM WB (Whole Body)) Customer receives warning message for failures 21 days following PM. IBIS logs failure
SPT Go to CSD, PM section and execute SPT. Document can be found in PM Assist


                  There can be no Severe failures in the following tests:

Head SNR
Head Coherent Noise
Head FSE Stability
Head GRE Stability
Head Eddy Currents
Body Shimming
Body SNR
Body FSE Stability
Body GRE Stability

                

 Customer receives warning message for failures 21 days following PM. IBIS logs failure
White Pixel Go to CSD, PM section and execute EPT. Document can be found in PM Assist Run test only. White Pixel failures not counted by IBIS. This is for trending/data-collection purposes only. No Customer notification
PM Check Run this script after all checks noted above have been executed
