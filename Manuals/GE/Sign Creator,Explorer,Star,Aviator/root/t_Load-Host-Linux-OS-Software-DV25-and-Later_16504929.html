Load Host Linux OS Software

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-40 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Linux OS Software DVD1--

Procedure

  1. Insert the Linux OS Software DVD into the appropriate DVD drive.
  2. Restart the host computer.
  3. From the HELiOS based GEHCMR Operating System (MR OS) Install screen, select 1. GEHCMR – MR Auto Install and press Enter.

    The Welcome to HELiOS for x86_64 screen displays.

    Note:

    During the beginning of this process (checking dependencies, formatting disk drive, etc.), there are two active buttons in the lower right: ←Back and →Next . Do not select these buttons. Later in the process, these buttons are greyed out (inactive).

    The software load proceeds through some checks and then begins the OS load. No responses are required.

    A progress bar shows the percentage complete. This process takes about 15 or 20 minutes.

  4. When the software load is complete, a message appears stating that installation has completed successfully.
  5. Eject and remove the DVD.
  6. Select Reboot.

    The OS software load takes about 20 minutes. A progress bar displays during the reboot sequence.

Finalization

Return to and continue.
