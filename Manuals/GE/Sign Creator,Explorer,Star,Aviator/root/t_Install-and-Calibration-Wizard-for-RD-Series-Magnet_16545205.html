Overview

The Install and Calibration Wizard is designed to guide the user to follow the proper sequence of installation workflow.

1 Starting Install Calibration Wizard

Procedure

  1. Insert the Service Key(SSA Key).
  2. Launch the Service Browser (Common Service Desktop).
  3. Click on the Calibration Tab:
    1. If you are in Install Mode, click on [Install and Calibration Wizard] ⇒ [Click here to start this tool].
    2. If you are in Maintenance Mode, click on [Calibration Wizard] ⇒ [Click here to start this tool].
  4. The wizard will launch the mode that corresponds to the system status, either Install Mode or Maintenance Mode (see sections below for detail)

2 Install Mode – New System Installation

Procedure

    note:

    Clicking on the Help button of the menu bar will open this document. Click in on the Help button in the lower right corner will open the Service document for the active calibration step.

    note:

    Please make sure option keys installed before you launch ICW, or need restart the system to refresh the ICW list if there is new option key installed.

  1. Some calibrations have certain dependencies. To understand the dependencies that the tool is using during Install mode, see Figure 4. The Installation Calibration Wizard in install mode will not allow the user to complete a calibration for the first time until all the necessary pre-requisite tasks and calibrations are complete. Some calibration steps will have machine data. Machine data refers to data that is stored on the system. Example is LV shim data which is stored under /usr/g/service/data directory. Other calibrations will not have machine data. For these tests that have no machine data you must verify that you have performed the tasks by clicking check marks in the boxes for each step then Submit. See Figure 2.
  2. For the manual tasks, you must acknowledge completion of each task listed by clicking the box next to it, then click Submit.
  3. For those tools that are calibrations with machine data, click Click here to start the tool. The tool interface will appear. Follow links for specific instructions regarding setting-up and running any particular tool.
  4. When the calibration has completed and/or has been aborted, you must close the tool. To close the tool, left mouse click the [-] in the upper left corner of the tool, then left mouse click [Close]. (See Figure 3)
  5. Click Check Status. This will register the tool’s pass/fail status. If the tool has passed, the next calibration in the flow will become active. If the tool failed or was incomplete, the tool will turn red and you will be unable to continue until that calibration has passed.
  6. The Installation Calibration Wizard will remain in Install Mode until every task listed on the left side has been successfully completed. After completion of all tasks in Install mode, exit out of the ICW.
  7. The next time the Install Calibration Wizard is launched, it will open in Maintenance Mode.
    note:

    How to read this matrix: The same tasks calibrations are listed along the top and along the side. The ideal order of task / calibration completion is from the top to the bottom. Anything with no red squares to the right has no pre-dependencies, therefore it can be run at any time. If there are red squares to the right of any of the tasks/calibrations, then the tasks/calibrations indicated in the vertical column(s) associated with each red square must be completed successfully before that task/calibration becomes available.

3 Special Considerations

Procedure

  1. Re-launching machine data calibrations.

    If the user tries to launch a calibration in the ICW after it has already passed, the system will warn the user that the selected calibration may be dependant other calibrations. The user may want to re-run the calibrations listed prior to re-running selected calibration. While this is not enforced by the interface, it is highly recommended that the user make note of these pre-dependencies and run them before completing the selected calibration. See Figure 5.

  2. Tool Failures.

    1. If a task is incomplete or a calibration fails, the interface will turn the name of that task/calibration red. Post-dependencies will not become available until the task/calibration has passed. See Figure 6.

5 MAINTENANCE MODE

Procedure

  1. After all steps have been successfully completed in the “Install” mode, the next time the Install Calibration Wizard is launched it will be in “Maintenance Mode”.
  2. In Maintenance mode there is no calibration order enforced, however if a selected calibration is affected by or affects any other calibration, then a pop-up message is displayed and affected calibrations are Bold. SeeFigure 12 .The Dependency Matrix for Maintenance Mode is shown in Figure 4
  3. After the user acknowledges the Pre- and Post- Dependencies by clicking [Yes], all pre-dependencies are un-bolded and the selected tool becomes active.
  4. Perform all necessary set-up prior to launching the tool. See Figure 13for instruction on how to start calibrations in Maintenance Mode.
  5. When you click [Check Status], one final pop-up message will alert you to the post-dependencies. Clicking [Acknowledge] will cause the post-dependencies to be de-bolded. Clicking [More] will show the “Dependency” matrix used to determine the pre and post dependencies. See Figure 14
    note:

    To read the dependency matrix for Maintenance Mode: The same tasks are listed vertically and horizontally. In the vertical column, find the calibration that you wish to run. Follow that line horizontally until you reach the yellow square. Any task vertically directly above the yellow square is a pre-dependency, and any task vertically directly below the yellow square is a post-dependency.

    For troubleshooting purposes, if user is about to perform a certain calibration (or task), it would be beneficial to see what pre-dependencies are related to that calibration and consider performing them. If pre-dependencies are not run, the system will not be negatively affected. Post-dependencies, however, are very important. For example, if Grafidy is run, the LV Supercon, Gradcal EPT and Probe values may have changed. Each one of these calibrations should be run after the completion of Gradify because they are Post-Dependencies of that cal.

  6. It is highly recommended that any calibration highlighted as a post-dependency also be run immediately after the selected calibration.
  7. After the Install Calibration Wizard is launched in Maintenance Mode, it will help you keep track of what calibrations have been run during the current session by changing the font color of the calibration name to blue. As long as the ICW remains open, it will track all calibrations for which Check Status has been clicked.
    note:

    The ICW will only track those calibrations run while that instance of ICW is running. If the ICW is closed and re-opened, the font color for all calibration names returns to black.

6 Finalization

Procedure

  1. To exit from the Install Calibration Wizard, click on [File] -> [Quit]. A pop-up box will appear as in Figure 15.
  2. Choose Yes to exit from the ICW and perform a Save Info
  3. Choose No to remain in the ICW.
  4. Choose Exit] to exit from the ICW without performing a Save Info.
