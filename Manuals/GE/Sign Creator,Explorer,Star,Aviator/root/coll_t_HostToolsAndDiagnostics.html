Host Tools and Diagnostics Steps

This is the standalone version of the eddy current check procedure that is part of SPT.

Prerequisites

Table 1. Required Conditions
Condition
  • Cancel all previous exams. Click End Exam.
  • Remove any patient positioning devices, such as patient restraints or other attached devices.
    • Coherent Noise Check Description: This tool measures the noise that could arise due to a breach in RF shield room integrity and also zipper artifact noise.
    • Stability Test Description: This tool measures and shows the magnitude drift, phase offset and echo shift using Fast Spin Echo and Gradient Resolved Echo sequences for either the body coil or local coils.
    • Eddy Current Check Description: This tool measures the long term eddy current (2.5 to 2000 ms) (both B0 and linear) error for all combination of coil axes and gradient axes.
    • SNR Description: This tool measures the SNR level for the body coil.

    Procedure

    1. Refer to Data Sheets for the tuning data sheet.
    2. From the Common Service Desktop, select Calibration. Select Probe/S Tune from the Calibration menu, and then select Click here to start this tool.
    3. View the complete results as follows:
      1. Select C Shell.
      2. Type more /usr/g/caldir/probes_cal.log and select Enter.
      The specification criteria (absolute value) are as follows:
      • Single delta parameter, < 0.8
      • Sum of all delta parameters, < 1.0
    4. Set up the TDI HNA as follows:
      1. Remove the service filler panel to uncover the cradle slot.
      2. Put the TDI HNA coil into the cradle slot and insert the connector.
      3. Landmark on the center line of the TDI HNA.
      4. Push Advance to Scan.
    5. If the test does not pass, resolve all errors or failures and run the test again.
      6. note: You can enter text into the Comments field.

    7. Select the settings as follows:
    8. Click Start.
    9. If the test does not pass, resolve all errors or failures and run the test again.

    10. The test results show automatically. If you closed the test results, you can click Viewer to show them again.


    11. Refer to Installing host system software (quick start) for more information.

      note: If the system is staged with enhanced GOC, do not load software.
    12. Undock the patient table.
    13. At the same time, press the cradle latch block and push in the cradle release button at the front of the cradle.
    14. While holding down the latch block and pressing the cradle release button, slide the cradle forward enough so that the cradle covers the top area of the cradle latch block. Release the latch block and cradle release button.
      • caution
      • PINCHED FINGERS!
      • FORWARD MOVEMENT OF CRADLE CAN PINCH FINGER WHILE HOLDING DOWN CRADLE LATCH BLOCK.
      • MOVE CRADLE FORWARD SLOWLY AND DELIBERATELY UNTIL BOTTOM EDGE OF CRADLE SUFFICIENTLY COVERS TOP OF CRADLE LATCH BLOCK SO THAT YOU CAN REMOVE YOUR FINGER FROM BLOCK.
    15. Push in the right actuator on the table front base.
      16. note:

      Pressing the actuator button engages the secondary cradle latch cable and causes the pin stop to move down flush with the table top surface, allowing the cradle to slide forward.

    16. Prop up the cradle or remove the cradle from the patient table to perform desired maintenance.
    17. Connectivity
    18. This tool works regardless of the connectivity profile in use.
      note: The AUTO CHECKOUT option can only be used if a checkout was successful. If the site has completed a checkout using the CHECKOUT NOW button at some previous time, an /export/home/insite/sclink.cfg file is present. If the site has not done InSite checkout earlier, please perform the InSite checkout using the Executing InSite/IIP checkout procedure.
    19. On the InSite Checkout tab, click AUTO CHECKOUT to begin the verification process.
      The status bar indicates the status of the verification process. An Auto Checkout Cancel dialogue displays while the process is running.
    20. Allow the system to run until the box disappears.
      When AUTO CHECKOUT is complete, the status bar displays the message InSite Dial out check completed successfully.
    21. Disabling TR, DD, and RF inputs for head channel
    22. Make sure that the system is idle and all coils have been removed from the magnet bore.
    23. Open the front door of the .
    24. Disable the following switches on the driver module and the exciter.
      1. On the front of the driver module, set SW2 to TR DISABLE (down).
        note: Leave SW1 set to HV ENABLE (up).
      2. On the front of the exciter, set the RF ENB switch to the disabled (down) position.
