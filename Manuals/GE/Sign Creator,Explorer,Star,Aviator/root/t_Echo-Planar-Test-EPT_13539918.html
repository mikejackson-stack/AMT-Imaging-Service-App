About this task

EPT combines the functionality of the current B0 Dither Calibration, Group Delay Calibration, and B0 Image Test into a single tool with a simple user interface. The output is suitable for remote support access, trending, and automatic checking of results against acceptance limits. In addition, EPT automatically updates the EPI calibration files when authorized by the user.

Startup

About this task

Be aware of the following before starting EPT:

  • For TwinSpeed, EPT is run for each GradMode, Whole-Body (WB) and Zoom (ZM).

  • Both GradModes can be selected in a single pass, and both require calibration at least once per installation and during any other routine system tests.

Procedure

  1. Click New Pt, and enter geservice for the ID.
  2. Make sure the correct type of phantom is used for the EPT.
    1. (For 3.0T systems) Use the pink phantom.
    2. (For 1.5T systems) Use the green phantom.

    • For 1.5T and 3.0T systems with LCC 300 or the short bore magnet, place a 100 mm sphere phantom, EPI foam phantom holder, and phantom loader in the head coil as shown below.

    • For 3.0T systems with the long bore magnet, place a 100 mm sphere phantom and EPI foam phantom holder without a phantom loader in the head coil as shown below.

      Landmark on the center of the sphere, but do not advance to scan.

  3. Place an EPI foam phantom holder and a second 100 mm sphere on the Grafidy base plate as shown below.
    1. Move the table into the bore 1100 mm from landmark.
    2. Slide the Grafidy base plate so the center of the 100 mm sphere is at the axial alignment light, and press the MOVE TO SCAN button.
  4. Start the Echo Planar Test Calibration tool.

    • Non-proprietary service tools: From the Common Service Desktop, select Calibration. From the Calibration menu, select Echo Planar Test, and select Click here to start this tool to begin the procedure.

  5. Click the Start button.
  6. The Echo Planar Test window displays.
    Note:

    Based on the selected head coil, the options in the user interface may differ.

    For TwinSpeed, the GradMode option is displayed with the following three entries: Whole, Zoom, and Whole & Zoom.

  7. For calibration, set the Select All Tests option to Yes (default is No).
    Note:

    For troubleshooting, select individual tests as desired.

    When running EPT with GradMode set to Whole & Zoom and running all tests, two separate files (EPT.ZOOM and EPT.WHOLE) are created in /usr/g/service/data when the scan is completed. Because the results in the status box of the EPT Test screen show only the last coil mode run (not both), it is possible to have a failure in the first mode run that is not reported. The workaround when running EPT tests is to select one mode at a time.

    • Run either Zoom or Whole and view the results, then run the other mode and view the results, or

    • Run Whole & Zoom mode at the same time, and use the Report Manager to view the resulting EPT.ZOOM and EPT.WHOLE files.

  8. Select the following options before starting EPT:
    1. Select Multi Passes and type an integer in the text box to perform more than one pass of the tests.
    2. Select Config Update to update the configuration files with new calibration data if the new data is within specifications for one or more of the selected tests.
  9. Select a Test Purpose from the pull-down menu.
  10. Type two lines of comments if desired. If no comments are entered, the text NO COMMENT will display in the results file.
  11. CAUTION
    Equipment Movement!
    Initiating the EPT will move the cradle.
    Take appropriate precautions to ensure that no one is in its path.
    Select Start EPT. Running all the tests takes about one hour and will thoroughly test the EPI performance of the system. This is the recommended mode for baseline, PM, and initial problem finding.

    The Single Test mode is meant to be used while troubleshooting. If possible, run the full set of tests at the end of troubleshooting to verify system performance. While EPT is running, each test will be displayed in the message window indicating the amount of time the test requires to run. (Actual run time of the test may not coincide with the countdown clock displayed on the interface.)

    Note:

    EPT will create many images. If not enough space is available, a window will display notifying of this situation.

Image-Based Short Cross-Term Eddy Current Tool

About this task

If the B-zero image fails during the EPT, quit EPT and run the Image-Based Short Cross-Term Eddy Current tool. This tool may reduce EPI ghosting and is designed to work in conjunction with EPT. If B-zero image passes, proceed to Test Termination.

Procedure

  1. Note:

    Consider running this test even if the B-zero image passed. Based on past experience, this may improve image quality.

    Quit the EPT.
  2. Open a C-shell by clicking the C Shell... button in the Service Desktop Manager, and type /usr/g/bin/runsct.

    The tool window appears.

  3. Click Apply and Scan.

    The tool checks the eddy current compensation parameters first. If the long cross-term compensation is not significant, the following message will display: The long xy alpha value (2 terms added) is: value. The correction would be too small to make improvement. Short cross term correction is not required. This tool does not need to be run.

    Click Exit. The tool quits and cross-term compensation is removed.

  4. If the system determines that correcting the short cross-term values may fix the ghosting problem, compensation is applied and the B-zero image scan starts with the new values. Data collection takes 10 to 15 minutes and the resulting ghosting level is measured and displayed.
    Note:

    Clicking Abort before the test is complete stops data acquisition and removes the short cross-term compensation values added by the tool.

    • If the B-zero image passes, the procedure is complete and the results are displayed. Click Exit and rerun the EPT tool.

      When running the tool, go to the Body section of the Test Options page and click Off next to B-zero Image. This saves time by not rerunning this part of the EPT.

    • If the B-zero image results are not within specification, the cross-term compensation is removed. Click Exit.

  5. After EPI ghosting problems are brought into specification, rerun the EPT and proceed to the next section.

Test Termination

Procedure

  1. When the tests are complete, one of these four messages displays:
    1. Your tests completed successfully.
    2. A minor system problem has been detected. This problem is NOT expected to affect image quality.
    3. A serious system problem has been detected. This problem IS expected to impact image quality.
    4. EPT was unable to determine PASS/FAIL status of the tests.
  2. Select Quit EPT, and confirm when a confirmation window displays.
    Note:

    If the EPT process is not shut down in an orderly manner, the service protocol directions may need to be reset. This can be done by opening a C-shell and typing:

    cd /usr/g/service/cclass/ept and pressing Enter

    resetept and pressing Enter

Topic ID: id_14951775

Finalization

Procedure

  1. Reset TPS to bring the system back into a known mode.
  2. Do a test scan to ensure the system is working properly before turning it over to the customer.
