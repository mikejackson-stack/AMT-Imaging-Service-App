Guided Install Site Configuration Options

The tables below describe some options available when configuring a site system using Guided Install. Only tabs containing system-dependent information are described below.

To see additional information about a field in the Guided Install interface, put the cursor in that field and look at the bottom line of the screen. For additional information about a tab, use the Help menu.

Note:

For Artist XT and Architect XT systems, option keys must be installed for system handover.
