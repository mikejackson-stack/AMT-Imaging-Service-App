About this task

GOC calibrations there are three tasks that must be completed and checked off:

  • Intercom Adjustments

  • PACS/HIS-RIS and networking

  • Pneumatic Patient Alert Check

Procedure

  1. Insert the Service Key.
  2. Launch the Service Browser (Common Service Desktop).
  3. Click the Calibration tab.
    Note:

    a. If you are in Install or Upgrade mode, clickInstall and Calibration Wizard and then Click here to start this tool.

  4. If it is required to be completed, the GOC Calibrations checklist will be one of the final items listed in the ICW, see Figure 1.
  5. Perform . When this is complete, check the box next to Is Intercom Adjustment done?
    Note:

    PCI-AA Intercom function is pre-adjusted and not necessary to perform during Installation. Check the Audio Function from SCIM to Magnet Bore. Then, check from Magnet Bore to SCIM. If necessary, perform Intercom Adjustment For Simple OC Audio Board as troubleshooting.

  6. Perform PACS/HIS/RIS Camera Site Specific Networking set up. When this is complete, check the box next to Is PACS/HIS/RIS Camera Site Specific Networking done?

    • PACS setup

    • HIS/RIS setup

    • Camera set up

      1. Printer Configuration for Film Composer

      2. Printer Configuration for Flexi Filmer

      3. Filmer Switch

  7. Perform Pneumatic Patient Alert Check. This is done by compressing the Patient warning “Squeeze bulb” that is located by the magnet enclosure, and is connected to the PAC assembly. The Audio Alert which is a small box that is located near the console should produce an audible alarm. When this is complete, check the box next to Is Pneumatic Patient Alert Check done?
  8. Click Submit. This will complete the GOC Calibrations section of the ICW.

Finalization

  1. Return to the Install Cal Wizard for information regarding how to advance to the next calibration and for links to other calibration procedures.
