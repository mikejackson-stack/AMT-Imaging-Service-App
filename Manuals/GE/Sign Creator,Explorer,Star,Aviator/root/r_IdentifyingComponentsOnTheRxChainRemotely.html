Identifying components on the Receive Chain (RxChain) remotely

Identify components on the RxChain remotely by using information about the BoardType, BoardLocation, BoardRevision, FirmwareRevision, and SerialNumber.

For each receiver and Receiver Distributor (RxDist) component, the firmware writes values to the BoardType, BoardLocation, BoardRevision, FirmwareRevision, and SerialNumber fields.

To identify the components on the Receive Chain remotely:
  1. Open a C-shell or terminal window.
  2. Type cd /usr/g/service/log and press Enter.
  3. Type hartViewer -c | less and press Enter. This lists all of the components on the Receive Chain and their parameters.
Table 1. Example HART Log output for RxChain component

...................CURRENT_STATUS_RECORD#44..............................

InstallDate: 27/2/2018

BoardType: RRxPPort-1

BoardLocation: Side of magnet 1

BoardRevision: 0x0512

FirmwareRevision: 2

SerialNumber: 0500000e3591021c

CurrentDateTime: 17/4/2018 12.56.59

PowerOnDiagResults: Serial Number Confirmation Successful

TaggedPerfIndicators: NIL

TaggedHWfailInfo: NIL

TaggedPowerOnDiagFailInfo: NIL
These parameters include:
  • BoardType: The name of the hardware.
    • For receivers: RRxPPort - #.
    • For the RxDistribution module: RxDist.
  • BoardLocation: The side of magnet number (#), where # matches with the receiver number found in BoardType. For the RxDist, the number 6 is used (one more than the maximum number of receiver modules supported).
  • BoardRevision: This is the most important field. This is 4-digit number representing a combination of fields, including the board revision, board variation, and board type.
    In Table 1 from above:
    • The leftmost digit is unused and should be a 0.
    • The next digit is the board type. In this example, the board type digit is set to 5, which means LN (Gen 2) DPP receiver.
      Table 2. Other Board Type definitions
      IdentifierBoard Type
      0RRX (used with RF Hub)
      1P-port (Gen 1, Pioneer only)
      2A-port
      3M-port (on hold)
      4RxDistribution
      5LN P-port (Gen 2)
      6LCRx (on hold)
      73T DS P-port
      8DS RxDistribution
    • The digit to the right of the board type is the board variation digit. In this example, the board variation is 1, which means it is a 3T 32 channel receiver, given that the board type from above is determined to be a LN DPP module.
      Table 3. Definition of the codes
      IdentifierBoard variation (RF Hub/RRX ONLY)Board variation (DPP ONLY)
      016-channel RRX receiver1.5T 32-channel receiver
      18-channel RRX receiver3T 32-channel receiver
      2N/A1.5T 16-channel receiver (on hold)
      3N/A3T 16-channel receiver (on hold)
  • FirmwareRevision: The FPGA revision loaded on the module.
  • SerialNumber: The serial number read from the 1-wire device on the module. If the 1-wire read failed, the value FFFFFFFFFFFFFFFF is written.
  • CurrentDateTime: When the HART entry was logged.
