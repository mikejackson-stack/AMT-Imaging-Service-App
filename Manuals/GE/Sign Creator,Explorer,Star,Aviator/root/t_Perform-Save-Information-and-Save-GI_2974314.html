Perform Save Information and Save GI

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1 -20 minutes -

About this task

After completing final site configurations, perform a SaveINFO:

Procedure

  1. From the Common Service Desk Top, open the Guided Install GUI.
  2. Select the SaveRestore under Utilities. The Save/ Restore window will open.
  3. A dialog Box will open asking if MOD or CD/DVD will be used. Insert the media to be used into the drive.
    Note:

    Beginning December 2009, the MOD drive will be going end-of-life. Please use CD/DVD to complete Save/INFO.

    Note:

    Use Verbatim or TDK 48x R CDROM or Verbatim or TDK 2x –R DVD media.

  4. Make the proper selection in the Dialog Box and Click Ok.
  5. A warning message will appear informing the operator that data on the inserted media will be lost. ( MOD only ).
  6. Click Confirm to Start the SaveInfo procedure.
  7. A SaveInfo & SaveGI in progress message will be displayed.
  8. If some information is not saved a warning message will appear.
  9. Click Yes to view the Log.
    Note:

    Protocols may fail to save if an illegal character is used in the name.

  10. SaveInfo is now complete. Remove the MOD or CD/DVD and write the date and time on it.

Finalization

  1. To verify the information was properly saved on the media perform Verifying Save Restore Media.
  2. Exit the install GUI by selecting File then Quit.
