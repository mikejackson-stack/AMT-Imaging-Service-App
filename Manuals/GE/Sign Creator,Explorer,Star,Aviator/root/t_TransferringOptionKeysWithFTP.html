Transferring option keys with SFTP

If an inSite checkout has not been completed on the scanner, but the system is connected to the hospital network, the option keys can be sent to the scanner through SFTP. The option key file must be saved to the computer hard drive before continuing.

Procedure

  1. Obtain the scanner IP address and connect to the system.
  2. Send the option key file from the desktop to the scanner through SFTP.
  3. Move the file to the temp directory by typing mv license.sh /usr/tmp.
  4. Rename the file by typing mv license.sh flexkeys_install.
  5. Reboot the system.
  6. Open Guided Install, and verify the downloaded option keys are installed as permanent keys on the Option Key tab.
  7. Complete a SaveInfo to retain all newly installed options on an Info MOD.
