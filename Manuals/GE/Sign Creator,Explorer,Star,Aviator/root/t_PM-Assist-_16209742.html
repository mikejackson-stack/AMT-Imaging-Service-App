Overview

Important: When running the following tasks in PM mode: Eddy Current Check, Coherent Noise and Signal to Noise check use PM_SPT (System Performance Testing (SPT)). When running Spike Noise Check in PM mode use PM_EPI (EPI White Pixel PM Mode ). When running LVShim in PM mode use PM_LVShim(LVShim).

When PM Check, use PM Check .

1 LVShim

Procedure

  1. Phantom Setup
    1. Remove all coils from the cradle and phantoms from the bore.
    2. Set-up, align, and landmark the LVShim phantom as shown inFigure 1.
    3. Press the Advance to Scan button.
  2. Running the LVShim Tool
    1. If not already in place, insert the Restricted Service Key in a host computer USB port.
    2. Click the Service Browser.
    3. On the MR Service Desktop, select the PM tab and expand the PM Assist option (seeFigure 2).
    4. Click the Click here to start this tool link.
    5. Assure that:

      • the Gradient Shim shim type is selected, and

      • the Auto Mode radio button is selected.

      To proceed, click the Scan button.

  3. In Auto mode, the tool automatically does the following:
    1. Sets up the protocol and collects image data.
    2. Calculates the harmonics and compares it with the specification.
    3. Calculates dc offsets for X, Y, and Z.
    4. Completes multiple iterations (maximum = 5) until harmonics meets the specification.
    5. Final column will have last iteration reanalyzed at 45DSV in Test mode (customer acceptance specs).
  4. After the scan is complete (with the service key inserted), the tool compares all the of the harmonics to spec in Test mode.

    • Green cell = Passed specification

    • Red cell = Failed specification

  5. When all iterations are complete and all the harmonics are within specifications, click Exit in the LVShim window.

    • If any harmonics fail in Gradshim, re-run Grafidy 3 Calibration

    • If this still fails, run passive shim for RD series magnets (refer to Magnet & Cryogen Manual for Passively Shimmed Magnets, part number: 5495018 ) or run active shim for R series magnets (refer to Magnet & Cryogen Manual for Actively Shimmed Magnets, part number: 5495019)

2 System Performance Testing (SPT)

Procedure

  1. Landmark the phantom set-up as shown below, using the appropriate Head TLT Sphere and loader in the head coil. The LVShim phantom can be removed for this test. The process for proper landmark is:
    1. With landmark still set on the Head Loader, drive the table in until the position reads 1135mm
    2. Without moving the table, move the Body Sphere with Body Loader so the laser is on the back centerline of the loader.
    3. Place the foam pads/wedges on both sides of the Body Loader to prevent roll.
    4. Press [Advance to Scan].
  2. From the Common Service Desktop PM page select PM mode by clicking on it in the expanded PM folder on the left side of the page. Figure 5 and Figure 6
  3. Start the SPT tool by clicking the “Click here to start this tool” link Figure 5
  4. The System Performance Test (SPT) screen will open Figure 7 For the PM SPT mode, all the tests are preselected and cannot be changed. The test takes just over one hour to complete. In the upper right-hand corner of the SPT screen the remaining test time will be displayed. Figure 7 & Figure 8 Test Progress and Results will be displayed in the lower window of the SPT page. Figure 9

    For more information on System Performance Tests, including phantom setup, follow direction 2333500 (Signa Excite Service Methods). /Troubleshooting/Image Quality Troubleshooting Tools/System Performance Tests (SPT)/ .

    Failures must be resolved and the System Performance Test (SPT) Must Be Re-Run before proceeding to the PM Check.

3 EPI White Pixel PM Mode

Procedure

  1. Place an empty head coil on the cradle
  2. Landmark on the Head Coil.
  3. Press MOVE TO SCAN.
  4. From the Common Service Desktop, select the "PM" tab then select EPI White Pixel PM Mode. Click to start the tool, Figure 10.
  5. The tool will run through head EPIWP PM first then it will move the head coil out of the way and perform body EPIWP PM. If the test stops before the tool has completed both head and body modes, view the error log to determine troubleshooting path.
  6. The EPI PM files generated by this tool can be found in the Report Manager tool (From the CSD click on the Utilities tab, Report Manager, password is mrgo1). Look for file type EPT and find those files with the PM extension. IBIS will be looking for these files to track Planned Maintenance completion.

4 PM Check

Procedure

  1. Verify that the PM has been completed successfully. Click on PM check. Figure 11 and Figure 12
  2. The PM Check window will open. Figure 13 the following information shall be displayed.
  3. As you can see in the example “Body GRE Stab” has a SEVERE failure. This must be resolved for the PM Assist to be considered complete. The FE will have 21 days to resolve SEVERE issues. The system will notify the operator of the problem if not resolved in the 21 day window.
  4. For the PM assist to be successful and complete all test results must pass Figure 14.
