HSS Results

High Speed Stability plot and data results should be viewed using the HSS Viewer Tool. This provides many new ways to easily view the results. This is described in Viewing Results with HSS Viewer, Viewing Results with HSS Viewer. See HSS Limits, HSS Limits, concerning understanding if the results meet the specification or not. The results can also be reported with both graphics and text using the Report Manager tool, which is located under Utilities from the MR Service Desktop. Refer to the Report Manager Tool to view the HSS test results.

1 Viewing Results with HSS Viewer

The HSS Viewer starts automatically after the execution of HSS Tool is finished. HSS Viewer can also be started manually. See Figure 1.

  1. Select File, Open, and then select the desired file from the list. See Figure 2.

  2. The results can be read from the bottom-most window. Note the 3 limit lines visible on the plot. Ensure that none of the peaks from the plot extend beyond the rose colored 40cm DSV limit line. See Figure 3.

  3. The results can also be compared to other HSS data sets using the Compare function under Features. See Figure 4.

  4. Explanations of the various options can be found under the Help pulldown at the top of the HSS Viewer GUI.

note:

Peaks in the plot near 0 Hz may not indicate a problem. If peaks are seen near the 0 Hz line, then enable “Base Line Correction” and see if the peaks decreases under the limit line. If the peaks do move under the limit line with “Base Line Correction” turned on, they can be ignored.

2 HSS Limits

Table 1 lists the frequency limits for fixed point stability for the 45Hz (vibration) bandwidth mode. At present, there are no specs for the 250Hz (electrical) bandwidth mode. Figure 5 shows the allowable instability in the MR frequency, given the limits on the amplitude of the frequency components in a Fourier transform of (x1,y1,z1,t) for the 45Hz bandwidth mode.

Table 1. FREQUENCY LIMITS FOR FIXED POINT STABILITY (45HZ BW MODE ONLY)
Frequency Deviation Limits For Fixed Point Stability (45Hz BW Mode) Frequency Dev. (p-p) Units
Frequency instability (p-p) 0.5 p-p Hz
Frequency instability, cold head off 0.2 p-p Hz

HSS Area Measurement Specification: The upper limit is 1.2 for CERD, UCERD2, EXCITE and 1.9 for UCERD.

note:

Figure 5 is to be used for low-frequency (45Hz) bandwidth tests only.
