Mesh Shield Installation

Procedure

  1. Mark the four corner screw positions of Mesh Shield and Penetration Panel for the alignment.
  2. Install Mesh Shield to the opening for system Cabinet. Fix the four corner screws first.
    Note:

    200 pieces of screws (U0035AA) are shipped with PP COVER RF PANEL SET (5333909).

    You can use these screws to fix the Mesh Shield according to the site condition.

  3. Attach the protection rubber on the lower mesh shield frame.
Topic ID: id_SL1590752-1083216

Install System Cabinet

Procedure

  1. Move the System Cabinet to satisfy the following conditions.

    • System Cabinet is parallel to the wall.

    • Screw holes of System Cabinet is aligned to the hole of Mesh Shield frame.

  2. Fix the System Cabinet with washer (2001-M5-10) and screws (1107-M5C010-37) at every two hole pitch. (54 fixing screws.)
  3. Lower the adjusters so that they reach to the floor.
Topic ID: id_SL1590759-1083216

Cabinet Level Check

Procedure

  1. Check that the System Cabinet is leveled. Specification: <+/-0.5deg
    Note:

    Use precision levels('Block Type' or 'Square Frame Type') 150mm or longer. Specification of precision levels: JIS B7510 (A Grade, Sensitivity 1~3) or equivalent.

  2. If System cabinet is not leveled, adjust the cabinet using adjuster.

Seismic anchor design instructions

About this task

Seismic anchor attach point is selectable according to site condition. Make sure that the seismic brackets and anchors do not conflict with System Cabinet covers and water hose routing. The front seismic bracket height cannot over the dotted line, make sure that it does not conflict with the four screws within the dotted rectangle, seeFigure 10.
