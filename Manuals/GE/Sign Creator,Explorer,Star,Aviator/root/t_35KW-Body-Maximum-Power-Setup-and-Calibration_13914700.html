Production Systems Using TR In Driver Module

Procedure

  1. Verify that the system is idle and all coils have been removed from magnet bore.
  2. Remove the front cover of the EXCITE Systems Cabinet.
  3. On the front of the Driver Module, disable T/R error reporting by setting the TR switch to the DIS (disable faults) position.
    Note:

    HV, DD and MC should remain set to Enable.

Topic ID: id_SL13914785-113908

Setting up the RF Coupler

Procedure

  1. Insert the 50KW Element into the Forward Sensor Port, (Blue- 4300A374-3). Make sure the arrow on the element points in the direction of the arrow (from Input to Output) on the Sensor. Lock Element in place using the locking tab on the sensor.
  2. Insert the 5000W Element into the Reflected Sensor Port (Blue- 4300A374-6). Make sure the arrow on the element points in the opposite direction of the arrow (from Input to Output) on the Sensor. Lock Element in place using the locking tab on the sensor Figure 2. The reflected port is not used during this procedure. Placing the 5000W element into the reflected port is just a safety measure, and is not used during Body calibration.

Wattmeter and Dummy Load Setup

Procedure

  1. Warning
    ELECTRICAL/RF BURN HAZARD
    RF BURNS AS A RESULT OF DISCONNECTING HELIAX CABLES WHILE THE SYSTEM IS SCANNING
    PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RF AMP BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE AND THE RF ENABLE SWITCH IS IN THE “OFF” POSITION.
    Notice
    Possible equipment damage. Do not turn connect/disconnect Wattmeter Sensor while Meter is ON. Always turn Meter OFF prior to plugging/unplugging Sensor.
    Verify scanner is in “idle”, turn off RF Enable at the Exciter (FP-I/O) or disconnect J14 RF Drive Input) from the back of the RF amplifier.
  2. Disconnect the Body cable J4 “Body Output” from the back of the RF Amplifier.
  3. To protect the Head Amplifier section, disconnect the Head cable J3 “Head Output” from the back of the RF Amplifier as well.
  4. Connect the Input of the Coupler to J4 on the back of the RF Amplifier.
  5. Connect the Output of the RF Coupler to the 35KW Dummy Load.
  6. Connect one end of the Wattmeter cable to the Wattmeter Sensor connector, (RS232 is unused). Connect the other end to the Coupler.
  7. Make sure to plug in the fan for the dummy load. AT NO TIME should you use this dummy load without its fan running.
  8. Notice
    Do Not Apply RF Power To The Dummy Load Without Its Fan In Operation. Doing So Will Result In Catastrophic Damage To The Dummy Load.
    Reconnect J14 on the back of the amplifier. Switch RF Enable to ON.

Setting Up The Wattmeter to Measure Forward Body Maximum Power

Procedure

  1. For a more detailed discussion of the Wattmeter, see Watt Meter (2372868) Introduction.
  2. Press the ON button on the Wattmeter. (If coupler and sensor is not correctly attached to the amplifier you will get a “No Sensor” indication)
  3. Select the arrow button under Scale.
  4. Type: 50000 to set the range.
  5. Select Enter button.
  6. Check the setting, by selecting the arrow button under Scale once again.
  7. Press Enter to exit this mode.
  8. Select the arrow button under Fwd Units make sure the scale reads “W” (or “kW “on some watt meters). If the scale reads dBm, select the arrow button under Fwd Units again, to toggle the scale to read “W” (Watts or kW kiloWatts) on the TOP, Forward Power scale. Ignore the BOTTOM, reflected Power scale value. It is not used during Maximum Power Calibration.
  9. Select the Shift button.
  10. Select the arrow button under Setup.
  11. Verify it reads “43”. If not, type the number “43” followed by the Enter button. (The figure below shows what should be displayed at this time.)
    Note:

    This action displays the Sensor Type configured in the Wattmeter. This procedure uses Sensor” Type 43”, which is optimized for peak power measurement.

  12. Select Enter button.
  13. Select the arrow button under Type, change unit of measurement to Peak.
  14. Some kits require an offset to ensure accurate measurement. Locate the Element Offset Factors card in the kit and view the offset for 3T Body Output.
  15. If an offset exists, press the Offset Button on the wattmeter. Enter in the value that was displayed on the kits offset card and press enter. (Illustration below shows what should be displayed at this time).

Scan Setup

Procedure

  1. Prepare the system to scan in Body mode Using o.41.1 Body APB Cal Service Protocol.
  2. Set Landmark
  3. Save Series
  4. Select Research Options with the mouse cursor, and right click. Then select Setup Params. Set TG to 50Done.
  5. Select Research Options with the mouse cursor, and right click, select Display CVs From the drop down menu.
  6. Set value of CV calmode to 5Enter (Dual Logamp Waveform). (Make sure to press Enter to capture the setting.
  7. Select Accept, then Download.
  8. Go to the amplifier and remove the Keypad cover, located on the front of the amplifier near the display.

Adjusting the RF Amplifier Output Power (Body)

Procedure

  1. This section adjusts the gain of the Solid State pre-amplifier (VVA SETUP) and if necessary, also adjusts the Attenuation of the PA stage, (ATTN SETUP). The Gain (VVA -Variable Voltage Adjustment) of the Solid-state amplifier is setup first, maximizing its output. The Attenuation of the PA stage can also be adjusted to “Fine tune” the final value to as close as possible to 35KW, (34,500-35,300 Watts). VVA Setup and ATTN Setup interact with each other, and you may find yourself jumping back and forth between these adjustments until the amplifier is properly calibrated.
  2. Select Manual Prescan.
  3. Select Scan TR.
  4. Set the Transmit Gain to 180. Make sure everything is functioning normally and you are getting a reading on the Wattmeter. Allow scanner to pulse at TG180 for 6 minutes. This is due to the drop in gain that occurs over the 6 minute period.
  5. Slowly increase the TG to 200. (If the amplifier trips set the TG at its highest setting).
Topic ID: id_SL212038-113908

VVA SETUP (Solid State amplifier Gain adjust)

Procedure

  1. Notice
    Press Only The Buttons Required By This Procedure. Avoid Pressing Mode Button. It Controls The Output Drive Of The Solid State Amplifier, Switching From Body To Head Mode Of Operation. See Keyboard Operation / Description of IPA and PA Stages for information on the RF Setup Keypad.
    While the system is pulsing RF, Press the Menu Button on the Keypad located inside the RF amplifier until the LCD Display on the front of the amplifier reads the following:

    > ATTN SETUP

    VVA SETUP

  2. Press Down Arrow to select VVA SETUP.

    ATTN SETUP

    >VVA SETUP

  3. Press Enter

    VVA STEP: 1 (Each time Enter is pressed this incremental Step Value changes)

    VVA: 3368

  4. Continue to press Enter button until you’ve. selected the desired step size. For smaller and finer calibration use smaller incremental step sizes such as 1 or 10. (Step size values can be set to 1,10,20,30,40,50,60,70,80,90,or 100).
  5. Once the Step Size is selected, Press Down or up arrow to actually adjust the Gain:

    VVA Step: 10

    >VVA: 3368 (This value will change by 10 counts)

  6. Using the Down/Up arrows resume the adjustment of the gain until you have achieved 35KW (Approx. 34,500-35,300 Watts on the meter.
  7. If you can achieve 35KW (Approx. 34,500-35,300 Watts) on the meter display Press the Menu button until you reset the keypad to its power measurement display.
    Note:

    If you are still not able to achieve the proper maximum Wattage setting, you may need to adjust the PA stage Attenuation, see Adjusting ATTN SETUP (PA Attenuation), and then repeat VVA SETUP (Solid State amplifier Gain adjust).

  8. Proceed to Saving New Calibration Settings Saving New Calibration Settings.

Adjusting ATTN SETUP (PA Attenuation)

About this task

This section only needs to be performed if you can’t achieve 35KW (Approx. 34,500-35,300 Watts) with VVA SETUP. (Note: At this time the RF amplifier is still pulsing at TG of 200)

Procedure

  1. Press the Menu Button until the LCD Display on the front of the amplifier reads the following:

    >ATTN SETUP

    VVA SETUP

  2. Select Enter.

    > ATTN: 13 (This value will change when the down/up arrows are pressed)

  3. Press the Down or Up arrows while watching the Wattmeter to adjust the attenuation of the RF amplifier PA stage. Slowly attenuate the RF power to as close to 35KW as you can. (Approx. 34,500-35,300 Watts). If you cannot achieve 35KW, adjust the attenuation to a value that is below 35KW.
  4. Press the Menu button to exit
  5. Press the Menu button again to return the LCD Display to its power measurement display.
  6. If you did not achieve 35KW, proceed to VVA SETUP (Solid State amplifier Gain adjust) VVA SETUP (Solid State amplifier Gain adjust). If you achieved 35KW (Approx. 34,500-35,300 Watts) proceed to Saving New Calibration Settings Saving New Calibration Settings.

Saving New Calibration Settings

Procedure

  1. As a quick check, look at the LCD display on the front of the amplifier. It should be reading 35KW + or - approximately 2000 Watts. This will vary site to site and can be used as a confidence indicator as to your actual setting. The LCD display should not be relied on as an accurate measurement device.
  2. Stop Manual Prescan.
  3. Press the Menu button multiple times until the original screen on the amp LCD reappears.
  4. Press the Off button. This will STORE the value in NVRAM. Wait 30 seconds and press the “Operate” (Or “standby) button. Wait another 30 seconds for the amplifier to react to the new settings.
  5. Reduce the TG to zero, once the RF Output is calibrated to specification. If the Amplifier is setup correctly, the RF amplifier Display, and Wattmeter should be very close to the same value.
  6. Test the new Maximum Power value by restarting Manual Prescan.
  7. Select Scan TR.
  8. Slowly increase the TG to 200. The system should not trip.
  9. Take a final look at the Wattmeter display; making sure the desired value is displayed.
  10. Reduce TG to Zero.
  11. Stop Manual Prescan

Finalization

Procedure

  1. Warning
    Electrical / RF BURN HAZARD
    RF BURNS AS A RESULT OF DISCONNECTING HELIAx CABLES WHILE THE SYSTEM IS SCANNING
    PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RF AMP BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE AND THE RF ENABLE SWITCH IS IN THE "OFF" POSITION.
    Notice
    Property Damage! Prevent Coil And Associated Switch Damage, By Removing All Phantoms And Hardware (I.E., Head Coil, Surface Coil...) From The Magnet Bore.
    Before proceeding, perform a [Reset TPS]. This is to ensure that the RF Amplifier is in a known state to the system.
  2. Perform UPM (Universal Power Monitor - Body Setup and Calibration) to ensure the UPM is properly calibrated and functioning properly.
  3. Verify scanner is in “idle”, turn off RF Enable and disconnect J14 from the back of the RF amplifier.
  4. Disconnect the RF Watt Sensor from the J4 Body Output Connection.
  5. Connect the Original Body Output Cable to RF Amplifier, J4 and original head output cable to RF amp J3.
