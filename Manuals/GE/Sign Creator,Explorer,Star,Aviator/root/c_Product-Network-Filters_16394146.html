Product Network Filters

1 Software Release

1.1 Overview

Product Network Filters (PNF) is a software firewall tool that allows a site Network Administrator to control traffic from the site's internal network to the Diagnostic Imaging System. This tool was created in response to the customer's need for security.

  1. Click the Utilities tab on the Common Service Desktop (CSD) and select Product Network Filter.
  2. Click Click here to go to the link.
    note: When accessing PNF configuration, the firewall status displays Pause, but is still turned On.
  3. The main page of PNF configuration will appear.

1.2 Firewall rules (filters)

  • notice
  • The system ships with factory defaults firewall rules already loaded and firewall turned On. Factory defaults have no firewall rules, effectively isolating the systems external Ethernet connection (eth2) from the hospital backbone.
  • Generally, firewall rule creation is not necessary.
  • As options are applied or application features are configured, rules are automatically added to the system (PNF Configuration) to allow specific connections to external servers and services.

1.3 Edit or add a rule

  • notice
  • Editing or adding of rules should not be performed unless user understands what is required and has been trained or guided appropriately. Changes to the rules may cause improper networking functionality which may also cause applications to fail on the system.
  1. By expanding Named Services, the user will see all rules applied as well as the Edit, Delete and Add a rule buttons.
  2. Click Edit to open the Edit a firewall rule page.
  3. Make changes required and then click Save.
  4. Adding a rule in the category may be accomplished by clicking Add a rule button and completing the necessary information in the Add a Rule page.
  5. Rules previously created may be deleted by selecting Delete.

1.4 Backup current rules

Use this feature for creating a backup of the firewall rules once the system has been fully installed, the options loaded and the application features configured. This backup can be used to restore the firewall rules if software corruption occurs or to recover from improper configuration attempts. Also note that the firewall rules are included in the system state backup.

To create a backup of the firewall rules:

  • Click the Backup Current Rules link on the PNF Configuration page.
  • The Backup page will open.
  • Enter a Backup Name for the backup file, then click Save.

The backup file will be created and saved in the /usr/share/gehc_security/pnf/backups directory. The filename is a combination of the date and the name the user applied to the backup.

1.5 Restore from backups

To restore a backup of the firewall rules:

  • Click the Restore from Backups link on the PNF Configuration page.
  • The Restore rules from backup page will open.
note: User may quit the Restore rules from backup page at any time by clicking Close.
  1. Select desired backup file from the list.
  2. Once the backup file is selected, click Apply Rules to load rules to system.
  3. Click OK to restore and apply firewall rules.
    note: The new rules are applied automatically and the firewall is restarted. It is not necessary to manually restart the firewall.

2 Finalization

  1. Close the Service Desktop.
  2. If changes have been made in the PNF configuration, run save System State. Run System State - Save and Restore from the Software procedure list.
