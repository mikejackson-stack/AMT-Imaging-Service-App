Low Height Fixed Table Planned Maintenance

Fixed Table PM is scheduled 4 times a year. Refer to the following matrix for Fixed Table Planned Maintenance.

Procedure Type Time (min) Period
ABCD
CHECK EMERGENCY RELEASE OF CRADLE AND PATIENT TRANSPORT 12XX
HOME SENSOR FUNCTION CHECK 12XX
DOCK CENTERING 33XX
CLEANING OF LIGHTWEIGHT CRADLE WHEELS 330 X
VISUAL CHECKS 32X
CRADLE SIDE LOCK ADJUSTMENT 32X

  • TYPE 1 - SAFETY AND REGULATORY

  • TYPE 2 - IMAGE QUALITY

  • TYPE 3 - OTHER

CHECK EMERGENCY RELEASE OF CRADLE AND PATIENT TRANSPORT

  1. Press Cradle in button on the Gantry, Take cradle in by 500mm approximately. Rotate the Handle on the Cradle, and pull the cradle out to the home position. Ensure its possible to pull the cradle with this process.

  2. If cradle fails to release, repair cradle immediately. Refer to CRADLE EMERGENCY RELEASE CHECK AND ADJUSTMENT.

HOME SENSOR FUNCTION CHECK

  1. Press Cradle in button on the Gantry, Take cradle in by 500mm approximately. Press the Down pedal on the Dock FRP cover. Ensure that the table is not coming down.

  2. If Home sensor is not functioning, Repair Home sensor immediately. Refer to CRADLE HOME SENSOR CHECK.

DOCK CENTERING

  1. Raise patient transport to maximum height using UP pedal.

  2. Verify the table is centered by aligning the table edge line and bridge edge line. Check that Cradle moves smoothly.

    Note:

    If not centered, measure the offset of the Table by checking the line of Bridge and Table and record it.

  3. Check that the gaps of bridge and table are 0.75 inches +/- 0.25 (19.0 +/- 6.4 mm).

    Note:

    If the gap does not satisfy the specification, record the adjustment value for each side.

  4. If adjustment is required, refer to the following procedure.

    • Table Center Adjustment: Table Center Adjustment.

    • Table Gap Adjustment: Table Gap Adjustment

PATIENT TRANSPORT TOP HEIGHT CHECK

  1. Raise patient transport to maximum height using UP pedal.

  2. Check alignment of Patient table Top against the bridge. Guide ridge (cradle rolling area) of Tabletop should match guide ridge (cradle rolling area) of bridge (Up- Down Height).

  3. If adjustment is required, refer to TABLE LEVELING AND TOP HEIGHT ADJUSTMENT .

CONNECTING ROD CHECK

  1. Move the cradle inside the bore until free from the side guards (400mm - 450mm).

  2. Release the cradle from the LPCA.

  3. Place the thin foam underneath the cradle front to prevent bridge and cradle from scratching.

  4. Lift the cradle at the handle by 1 hand and use the other hand to insert the foam.

    Note:

    Foam is stored in the Card during installation.

  5. Check if connecting rod had come out in front cradle section, if it had come out push it back.

  6. Restore the cradle.

CLEANING OF LIGHTWEIGHT CRADLE WHEELS

  1. Remove table cradle and turn over on its back. Refer to Express Coil: Posterior Array Coil Replacement without removing Fixed Table for removal of cradle.

  2. Using a flathead screwdriver, lift out each cradle wheel.

  3. Disassembly wheels.

  4. Check for any damages, wear and tear of wheels.

  5. Change and replace the wheels if the wheels are damaged.

  6. Assemble Housing and Wheel.

  7. Assembly the Wheel and housing back the Cradle assembly.

  8. Repeat the above process for all 18 no’s wheel assemblies.

  9. Restore cradle. Refer to Cradle Assembly procedure:.

  10. Perform MCQA test to check the cable connection and operation of PA coil.

VISUAL CHECKS

  1. Check for Table Up/Down Table stickers. If any damage, replace the stickers.

  2. Check for Table Top Front End and Side bumpers Damage, If any damage, replace the Bumpers by referring to TABLE TOP HEAD END BUMPER or TABLE TOP SIDE BUMPER　

  3. Check for Table FRP and Dock FRP covers Damage, If any damage, replace the FRP Covers by referring to FRP Covers.

CRADLE SIDE LOCK ADJUSTMENT

  1. Press the table down pedal on the FRP Dock cover; take the table to the down by approximately 100mm.

  2. Check for the proper latching of the cradle in the Table delrin guide by moving cradle in shown direction.

  3. If the cradle is not latching properly, readjust it by referring toCRADLE SLIDE LOCK ADJUSTMENT

  4. If the cradle is latching properly, but a play of >3mm observed, then the cradle Side Delrin guide needs to be readjusted. Refer to CRADLE GUIDE RAIL LATCH ADJUSTMENT for adjustment.
