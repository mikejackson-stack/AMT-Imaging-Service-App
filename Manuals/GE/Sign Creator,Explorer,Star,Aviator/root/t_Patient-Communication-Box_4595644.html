System Power must be turned OFF. Refer to Lockout / Tagout for 1.5T System Cabinet PDU Main Breaker.

--

Procedure

  1. Remove Rear Pedestal left cover.
  2. Disconnect all connectors from patient communication box. (J6, J7, J8, and J9)
  3. Remove 2 screws and remove patient communication box with bracket.
  4. Restore it by the reverse order of the removal.

Finalization

  1. Restore the Power. Refer to Lockout / Tagout for 1.5T System Cabinet PDU Main Breaker.
  2. Check intercom function. Basically, intercom adjustment of GOC Audio Box is not required. If necessary, perform Intercom Adjustment for Simple OC Audio Box as troubleshooting.
