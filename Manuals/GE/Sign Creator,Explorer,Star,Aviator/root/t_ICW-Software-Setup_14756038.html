About this task

Software Setup is the first step of the Installation Calibration Wizard. During Software setup there are four tasks that must be completed and checked off:

  • Install Software Updates (also known as Patches).

  • Load system options.

  • Reboot Computer.

Procedure

  1. Install Restricted Service Software according to Loading or Deleting Proprietary Software.
    Note:

    When first invoking ICW, the following screen will comes up. Please re-configure and load Option Software according to this instruction.

  2. Insert the Service Key.
  3. Launch the Service Browser (Common Service Desktop).
  4. Click on the Calibration Tab.

    If you are in Install mode, click on Install and Calibration Wizard ⇒ Click here to start this tool.

  5. The first step in the ICW is Software Setup. See Figure 2
  6. If patch software exists, load Current Software Updates. When this is complete, check the box next to “Does System has Latest Software Loaded ?”. If patch does not exist or patches are already installed at manufacturing, check this box and go to next step.
  7. Perform a functional check of the DVD archive. This can be performed by inserting a DVD in the SCSI tower and performing a SAVE INFO.. Then, perform Verifying Save Restore Media . If the Save INFO is successful, then the DVD archive function performs correctly. When this is complete, check the box next to “Have you performed a functional check of the DVD Archive?”
  8. From the Common Service Desktop, click on the “Utilities” tab then “System Restart”. Wait for the system to reboot. Logon using:
    1. Username sdc
    2. Password adw2.0
  9. Open the Install Calibration Wizard.
  10. Click on Software Setup.
  11. The top three boxes should be checked from the work done previously in this procedure. Now that the system has rebooted, also check the box to indicate “Reboot System” is complete.
  12. Click Submit.

Finalization

  1. Perform Insite Checkout instructions found in InSite/IIP load.
  2. Setup Autovoice Language according to the customer's request. Refer to Auto Voice Language Selection.
  3. Finally, as a part of Software Setup, load the Operator Manual DVD in the local language.
