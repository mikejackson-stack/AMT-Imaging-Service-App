Guidelines and Procedures for Upgrading Existing MNS Installation

Procedure

  1. Connections to the system support module (SSM): J507, spectro bias, spectro A and B remain the same.
  2. The RF input to the MNS amplifier cabinet no longer comes from the SSM. The RF input to the MNS amplifier cabinet is provided via J52 on the systems cabinet. J52 is the output from the MUX board labeled SLAVE EXCITER OUT. If the BNC connector for J52 is missing, the cable should be in a bag in the systems cabinet.
  3. (For upgrades only) Install the SSM filter kit FMI if available. These filters are placed in-line on all the sub-D type connections on the rear of the SSM. MNS SNR may improve when installed.
  4. The MNS system will be calibrated to 1.58 kW (62 dBm) using the adjustable gain potentiometer on the rear of the amplifier. Only the new CPC amplifier is rated to 2 kW.
  5. The MNS receive chain has changed. There is no longer a dedicated MNS receive line to the systems cabinet. The MNS receive path runs from the RX connector on the LPCA cover, through the cable tray and to J23 on the 16-channel switch.
  6. The previous dedicated MNS receive cabling to the pen panel, 20 dB gain block, and cabling to the systems cabinet may be removed from the system.
  7. The MNS TX path starts at the MNS amplifier RF out, and passes through the PEN panel to the rear pedestal. At the rear pedestal, the TX line connects to the cable that runs through the cable tray and is attached directly to the LPCA cover. (See LPCA Replacements for LPCA cable routing.) Verify -14.5 VDC (receive) or 5 VDC (transmit) on the TX line for proper connection.
  8. The TX and RX connections for MNS are new for Excite. TR switch cables plug into these connectors.
  9. A TX patch cable is provided to run between the TX port on the LPCA cover and the TX port on the legacy TR switch. This cable is not tuned and may be used for all TR switches.
  10. (For legacy 31P TR switch only) An RX patch cable is provided. A filter designed for 31P is included in the legacy patch cable. This filter is not compatible with other MNS frequencies. Contact the GE Spectroscopy Team to obtain RX patch cables for use with legacy TR switches for other frequencies. A 20% loss in SNR will be observed when running MNS without this filter on the legacy RX patch cable.

MNS Amplifier Installation on Upgraded System

Procedure

  1. Install the rails into the RF cabinet using the provided hardware. The lower rails should be installed approximately 4 inches (10 cm) above the RF amplifier. The upper rails should be installed approximately 11 inches (28 cm) above the bottom rails.
    Note:

    The upper rails prevent the MNS amplifier from accidental tipping or falling during installation.

  2. Install the eight retaining clips onto the rails in the RF cabinet. The retaining clips secure the amplifier to the cabinet.
  3. Install the universal hoist onto the RF cabinet.
  4. Install the CPC amplifier onto the hoist.
  5. Install the CPC amplifier into the cabinet as shown in Figure 1. One FE must operate the hoist, while the other FE balances the amplifier.

Exciter Installation

Procedure

  1. Turn off power to the systems cabinet.
  2. Remove the cover over slot 9 and install the slave exciter (2373070).
  3. Connect the long cable between the slave exciter RF out and the MUX board slave exciter in ports.
  4. Connect the short cable between the slave and master LO In/Out ports.
  5. Connect the cable from the MUX board slave exciter out to the BNC bulkhead fitting J52 on the rear of the systems cabinet.

BB Amplifier I/F and RF Detector Board Installation for Forward Production (ASC/MGD Chassis)

Procedure

  1. Remove the two RF detector boards and the broadband amplifier I/F board from their packing material.
  2. At the back of the RFS cabinet, locate slots 10 and 13 of the UPM chassis, and insert one RF detector board into each slot.
  3. Locate slot 6 of the UPM chassis, and insert the broadband amplifier I/F board into this slot.
  4. Locate the cables labeled Slot 10 J4 and Slot 13 J4. Attach them to their respective connection spots on the two RF detector boards and down to IO panel J102 and J104 connections.
  5. Add the 50 ohm terminators to all empty J numbers on the RF detector boards.
  6. Locate cable P/N 5113183-4, and attach as labeled, BB Amp I/F Board J3, to driver module J13.
  7. Locate cable P/N 5115645, and attach as labeled, BB Amp I/F Board J5, to IO panel J123.

BB Amplifier I/F and RF Detector Board Installation for Forward Production (CAM Chassis)

Procedure

  1. Remove the two RF detector boards and the broadband amplifier I/F board from their packing material.
  2. At the front of the RFS cabinet, locate slots 19U and 19L on the CAM chassis. Insert one RF detector board in each slot.
  3. Locate slot 17U/18U on the CAM chassis, and insert the broadband amplifier I/F board into this slot.
  4. Locate the cables labeled CAM Slot 19U-J4 and CAM Slot 19L-J4. Attach them to their connection spots on the two RF detector boards and down to IO panel J102 and J104 connections.
  5. Add the 50 ohm terminators to all empty J numbers on the RF detector boards.
  6. Locate cable P/N 5113183-4 and attach as labeled, BB Amp I/F Board J3, to driver module J13.
  7. Locate cable P/N 5115645 for 2 kW amplifier or P/N 5115644 for 4 kW amplifier. Attach as labeled, BB Amp I/F Board J5, to IO panel J123. Refer to the two tables below for all cable connections.

Cable Installation on Upgraded System Cabinet

Procedure

  1. Refer to the illustration below for the interconnects.
  2. Install the following:
    1. Transmit cable run 1147 from the rear pedestal to PEN panel J83. (Refer to the appropriate Signa Installation manual for details on terminating RF cables.)
    2. Transmit cable run 1146 from MNS amplifier RF Out to PEN panel J83.
    3. Data cable between MNS amplifier J7 and SSM J507.
      Note:

      If MNS installation is using the new (silver) CPC amplifier, and not an older ENI or Analogic amplifier from an existing MNS installation, a pin extraction tool should be used to remove pin 21 in the cable between the SSM J507 and the amplifier. After the pin is removed, use electrical tape on the pin to insulate.

    4. BNC cable between MNS amplifier J1 and SSM J101.
    5. BNC cable between MNS amplifier J9 and the RF systems cabinet driver module J8.
    6. AC power cable between MNS amplifier J8 and the PDU terminals 13, 14, and GND.
    7. BNC cable between MNS amplifier J12 and SSM J102.
    8. Cable run 1058 from MNS amplifier J3 to RF systems cabinet MR2-A11-J52.

System Configuration

Procedure

  1. Go to the Service Desktop and start the Service Browser.
  2. Start the System Config File Manager.
  3. When the MRconfig Editor displays, click the MRconfig tab.
  4. Set Spectroscopy RF Amplifier and Broadband Transceiver to Yes.
  5. Press the Save Changes button, then Quit.
  6. Load the following options:
    1. MNS Option Key
    2. SAGE7
    3. PROBE 3D BRAIN
    4. PROBE2000
  7. Shut down and restart the system.
