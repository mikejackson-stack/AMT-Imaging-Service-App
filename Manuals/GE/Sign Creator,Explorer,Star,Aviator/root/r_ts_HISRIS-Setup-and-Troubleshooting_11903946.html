Table 2. Safety
Warning
Connection of MR System to a NETWORK/DATA COUPLING that includes other equipment could result in previously unidentified RISKS to PATIENTS, or OPERATORS and RESPONSIBLE ORGANIZATION should identify, analyze, and control such RISKS.
Warning
Subsequent changes to NETWORK/DATA COUPLING introducing new RISKS and requiring new analysis; and changes to NETWORK/DATA COUPLING include:
  • Changes in NETWORK/DATA COUPLING configuration;
  • Connection of additional items to NETWORK/DATA COUPLING;
  • Disconnecting items from NETWORK/DATA COUPLING;
  • Update of equipment connected to NETWORK/DATA COUPLING;
  • Upgrade of equipment connected to NETWORK/DATA COUPLING.

This procedure documents the set up and calibration of the system to a clinical hospital information system (HIS) or a radiology information system (RIS).

Setup

  1. From the Common Service Desktop, select the Configure button, select the Guided Install button, and in FE Mode login as root (password is operator).
  2. Under Connectivity, select HIS/RIS.
  3. Enter applicable information in all fields (as provided by site) and click the Configure button.
  4. Under MWL Configuration, select MWL Config Details. The detail field description shown in Table 4.

  5. If any of fields, other than the defaults, are desired to appear in the Modality Worklist, select or deselect appropriately and click the Configure button.
  6. Under MWL Configuration, select Return Tag Configure.
  7. If any fields, other than the defaults, are desired by the site to be refreshed in the Modality Worklist, select or deselect appropriately and click theConfigure button.
  8. Under MWL Configuration, select SCP Configure.
    Note: SCP means Service Class Provider, it is used for HIS/RIS server (which provides MWL service) configuration.
  9. Click the New button to setup a new item.
  10. Enter applicable information in all fields (as provided by site) and click the Configure button.
    Note: For the first time configure, please click "DefaultSelected" to enable configure button.
  11. To verify network connectivity, click the Ping button.
  12. Under MWL Configuration, select Table Column Selection Configure.
  13. Select or deselect any fields desired to be displayed in the patient record table (located at the top of the scan window) and click the Configure button.
  14. Under MWL Configuration, select PPS Configure.
    Note: At release of this document, PPS Configure is available with 1.5T systems only. PPS Configure will be available for 3.0T at a later time.
  15. Click the New button to setup a new setup.
  16. Enter applicable information in all fields (as provided by site) and click the Configure button.

Functional Check

  1. Click the Work List icon for the scan screen (see Figure 8).
  2. To confirm the connectivity of the system to the RIS system, go into the scan desktop and select the New Patient icon (see Figure 9).
  3. On the scan screen enter the following:
    1. Patient ID:geservice
    2. Weight:111
  4. Click the Save button.
  5. In the Search/Refresh box, click the Search Data button (see Figure 10).

    The Search Data window displays as shown in Figure 11.

    From this page select how you want to pull information from the RIS system. The Get Patient List options are:

    1. Enter a patient Name, Patient ID, Accession Number, or Procedure ID to define the search.

    2. Selecting This System, which pulls the patient lists entered for this system.

    3. Selecting This Modality pulls the patient list for all MR systems at this facility.

    4. Selecting All Modalities pulls the patient list for all systems associated with this facility. Using this option may cause the scanner to hang if the facility has too large of Work List for all scanners at the site.

    5. Selecting Date Range pulls patient lists for any set day or date range.

  6. After entering the proper Search Data, click the Search button (see Figure 12).
  7. The results appear in the list above the patient information (see Figure 13).

Troubleshooting

  1. From the Common Service Desktop, select the Guided Install button, and in FE Mode login as root (see Figure 14).
  2. Under Connectivity select HIS/RIS (see Figure 15).
  3. Ensure that the Hospital Name, Suite ID, Host ID, and Local AE Title are correct for the MR system. The Local Port Number (Host Port) should be set to 4000 (same as the DICOM (Digital Imaging and Communications in Medicine) networking port number for MR systems). These are the parameters that the hospital RIS system uses to identify our system (see Figure 15).
  4. Under MWL Configuration, select SCP Configuration (see Figure 16).

    Ensure the following information with the site network administrator:

    • Host Name is the site name.

    • AE Title is the Modality Work List (MWL)Application Entity (AE) title of the RIS system of the site.

    • IP Address is the internet protocol (IP) address of the RIS server.

    • Port Number is the port number of the RIS system of the site.

  5. Under Home, select Verification (see Figure 17.
  6. Select Configure and confirm no errors.
  7. Select File>Quit.
