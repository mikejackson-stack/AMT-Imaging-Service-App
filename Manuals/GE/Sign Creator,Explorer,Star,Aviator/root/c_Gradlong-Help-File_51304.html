Gradlong Help File

gradlong <dqa, headsphere or body> [t=?] [zoom] [fpref=?] [cdpw=?] [vl] [a=?] [cp] [(b,g,s,a)t] [apssep] [gampoff] [noplot] [d]

Table 1. Gradlong Terminology Help
dqa, headsphere, bodySelects acquisition mode, NOT optional (rcv coil & phantom combo) dqa selects head coil, 24 cm FOV, for DQA phantom (don't use dqa w/HFO) headsphere selects head coil, 24 cm FOV, for 10cm or 17cm sphere. body selects body coil, 32 cm FOV, for 27cm sphere (worst choice).
t=?Specs 2 letter keyword or list of comma separated keywords that define tests where 1st letter is physical axis donor (x,y,z,a=x y & z) 2nd letter is physical axis recipient (x,y,z,a=z,y & x or o=ON axis only) Keyword opts: [x,y,z,a][x,y,z,a] OR ao (e.g. xy,xx,az,za,zy,aa,ao..) "ao" means (a)ll donors with (o)nly on-axis recips (i.e. ao="zz,yy,xx"). Keywords with "a" for donor and/or recip must be used ALONE. Don't repeat keywords. Valid examples (head or body mode): t=xx t=ya t=xx,zx,yz t=ao t=aa t=xx,yy,zz,zx,zy,yz Order spec'd is order run ("a" orders zyx in time). In dqa mode without the apssep option there are some limitations since the first (=only) autoprescan must be done on the sagittal plane to prevent later over-ranges. In this case if ANY test has a z recipient, then the first test must have a z recipient (w/dqa mode). The default is "aa" (= "zz,zy,zx,yz,yy,yx,xz,xy,xx") if t=? switch is NOT used.
zoomSelects "ZOOM" mode for TRM via protocol (default is "WHOLE" mode)
fpref=?Specs prefix appended to results tarfile (ala ?.gradlong.tar.gz)
cdpw=?Changes default EC excitation flat-top width (ms) [400,2000,6000] (def=6000)
vl ( this is a v and lower case L )Changes time mode from long (default) to VERY LONG time constant (increases TR).
a=?Specs #acqs time interleaved for final waveforms,[1..8] (default = 1)
cpChange default scan plane(s) used for measurements (see author for details). This switch is NOT compatible with dqa acquisition mode.
(b,g,s,a)t Self test modeSelf test mode: bt=B0 sim(w/CF increment), gt=grad sim(w/daq timeshift), st=grad sim(w/gradshim offset), at= (bt,gt,st) for first 3 tests respectively
apssepDo separate APS per scan (defaults is 1st APS used for rest).
gampoffTurns off (zeros amplitude) of EC grad excitation pulse (%calcs still done w/def amp).
noplotTurns off automated results plotting at end & extends post ADVANCE_TOSC sleep time.
dTurns debug mode ON.
Note:

DATA MANAGEMENT & DISPLAY SWITCHES BELOW ARE USED ONE AT A TIME! gradlong [h or help] [mlin [%]] [mb0 [%]] [show] [spec] [rpd] [ecbackup] [clean] [list] [mp"key" [plotoption] [p,P]] [get host] [gettar host [prefix]]

Table 2. Gradlong Terminology Help
help or hDisplay this help menu.
mlin [%]Plot all available linear gradient (from +/-%), (default =0.2).
mb0 [%]Plot all available b0 data (from +/-%), (default =0.2).
showDisplay EC comp related files.
specList the spec comparison data from file gradlong.sum.
rpdResets SIGNA protocol directory to /usr/g/protocols
ecbackup Backup SIGNA dir /usr/g/caldir EC related contents to tar file ecbackup.tar ONLY if tar file DOES NOT already exist.
cleanCleanup data files (use before un-zipping/un-taring gradlong tar file)
listList output files present.
mp[key] [plotoption] [p,P]key=(plane)(donor)(recip)[.acq#]=(a,s,c)(x,y,z)(x,y,z)[.?], like axx,syz,czx.1key=blank= display data menuplotoption (1-15,def=blank= display plot option menu)p=+hrdcpy, P=hardcpy only (use only on workstation w/printer)
get hostGet gt.* results files from host.
gettar host [prefix]Get [prefix.]gradlong.tar.gz file from /usr/g/service/cclass on host
