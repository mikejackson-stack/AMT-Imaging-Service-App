Preparing for New Service Pack Installation

About this task

Any previously installed service pack must be removed prior to installing a new service pack.

Procedure

  1. Back up your system by performing a SaveInfo.
  2. Notice
    For safety reasons, a service pack must be installed on the system at all times. Do not remove any service pack unless an alternate service pack is available for installation.
    Note:

    If installing a service pack as part of Load From Cold (LFC), complete the LFC and the VRE configuration as described in the service manual, then install the service pack disk. (It is preferable to install the service pack disk after a test scan.)

    Restart the system and log in as root at the login prompt.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. When asked to invoke Guided Install, click Yes.
  4. Open Guided Install and select Patches in left navigation pane, and select the Patches tab.
  5. Under Installed Patches, uninstall the Service Pack for the system first, and then uninstall all the other patches by selecting each patch and clicking Uninstall.
    Note:

    If multiple patches are selected and then Uninstall is clicked, only the top patch will be uninstalled. Once the Uninstall button is clicked, a patch is uninstalled.

  6. After uninstalling the patches, restart the system by typing: reboot in a C-shell.
  7. To verify the patches are uninstalled, open a C-shell and type: getver. None of the patches should be listed. (This step is not actually required to uninstall, but is just for verification.)
Topic ID: id_SL692630-495398

Installing a Service Patch

About this task

The installation process is the same whether installing service packs from a disk that was sent to you from GE Healthcare or one that you burned.

Procedure

  1. Log in as root at the login prompt.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  2. Insert the disk with the patches into the Host PC disk drive.
  3. In the Guided Install window, select Patches in the left navigation pane, and select the Patches tab.
  4. Select CDROM as the patch medium. The patches contained on the disk will be listed.
  5. Note:

    The order of installation is important as there may be dependencies on other application patches that are required prior to installing a patch. Normally, install patches first and the Service Pack last. The Guided Install will not proceed until all required application patches are loaded, so the system cannot be damaged by attempting to install a patch before all its dependencies are met. If a message displays indicating that a dependent patch was not installed, simply install the required patch before proceeding.

    Select each patch and click Install.
    Note:

    If multiple patches are selected and Install clicked, only the top patch will be installed. Each patch is installed after the Install button is clicked.

  6. After installing all the patches, restart the system by typing: reboot in a C-shell.
  7. To verify that all the patches are installed, open a C-shell and type: getver. Verify that the service pack just installed is listed. (This step is not actually required to complete installation, but is just for verification.)
