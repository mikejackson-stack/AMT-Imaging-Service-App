MCR 2 Troubleshooting

This procedure should be followed after performing the procedures outlined in the MCR 2 Diagnostics.

If there is any failure indicated in the MCR 2 Diagnostic's test results, follow the steps indicated below. If the failure is with a channel in Port A see Connector A, if it is with a channel in Port B see Connector B Overview.

It is recommended that the 16-channel Switch and System Cabinet Loopback diagnostics are run prior to troubleshooting the receive chain with the MCR 2 tool. In most cases, when those other diagnostics have been performed and are passing, the cause of the MCR 2 diagnostic failure should be identified prior to performing Testing Receive Chain Path through the 16-channel Switch or Testing Receive Chain Path through the 16-channel Switch.

Connector A

Topic ID: id_ov-1525795887443

Testing LPCA Connector A

  1. Remove LPCA cover.

  2. Locate Connector A cables on the IF connector on top of LPCA and disconnect both cables from cable track.

  3. Remove Test Cable Assembly from MCR 2 Tool.

  4. Connect both cable track cables directly to MCR 2 tool as shown in Figure 1.

  5. Run MCR 2 Tool Diagnostics in A mode.

    • If test passes, repair or replace A connector and then go to Restoring Original Connections to the Receive Chain.

    • If test fails, remove the MCR 2 tool and reconnect cables to J11 and J12 on the LPCA's IF panel.

      Reconnect MCR 2 tool to the Test cable assembly, and connect MCR 2 tool test cable back to A connector in LPCA. Go to Testing Cable Track Assembly.

Topic ID: id_SL625283-621355

Testing Cable Track Assembly

  1. Disconnect the cable at J21 on the 16-channel Switch.

  2. Locate the RF cable kit and swap the failing channel with a neighboring channel that is passing. Figure 3 assumes a failure with either channel 1 or channel 2.

  3. Run MCR 2 test again in A mode.

    • If the problem moves, repair or replace cable track assembly and then go to Restoring Original Connections to the Receive Chain.

    • If the problem does not move, remove the test cables reconnect the original cable to J21 on the 16-channel Switch and go to Testing Receive Chain Path through the 16-channel Switch.

Topic ID: id_SL625488-621355

Testing Receive Chain Path through the 16-channel Switch

  1. Remove the cable from J1 on the 16-channel Switch.

  2. Use the RF Cable kit to swap the failing channel with an adjacent channel as shown in Figure 4.

  3. Run MCR 2 diagnostics again in A mode.

    • If the failure moves to another channel, repair or replace the 16-channel switch and then go to Restoring Original Connections to the Receive Chain.

    • If the problem does not move, remove the test cables and re-install cables to J1 on 16-channel switch and go to Testing Path between 16-channel Switch and Pen Panel. Go to Testing Path between 16-channel Switch and Pen Panel.

Topic ID: id_SL625397-621355

Testing Path between 16-channel Switch and Pen Panel

  1. Swap cables between J1 and J2 on the 16-channel Switch as shown.

  2. Swap cables between J200 and J201 on the equipment room side of the pen panel.

  3. Run MCR 2 diagnostic again in A mode.

    • If the diagnostic passes, repair or replace the cable between J2 and J200 and then go to Restoring Original Connections to the Receive Chain.

    • If the diagnostic fails, go to Testing Path between RFS/System Cabinet and Pen Panel.

Topic ID: id_SL625493-621355

Testing Path between RFS/System Cabinet and Pen Panel

  1. Swap cables between J1 and J2 on the 16-channel Switch back to original configuration (see Figure 6).

  2. Leave cables J200 and J201 swapped at the equipment room side of the pen panel.

  3. Swap cables J200 and J201 at the RFS or System Cabinet as shown (see Figure 6).

  4. Run MCR 2 diagnostics again in A mode.

    • If the diagnostics pass, then repair or replace the cable between 201 on the RFS or System Cabinet IF panel and J201 of the Pen Panel.

    • If the diagnostics fails, go to Testing Path between IF Panel and MUX.

Topic ID: id_SL625400-621355

Testing Path between IF Panel and MUX

Keep cables in swapped position from Figure 6.

  1. Open the rear door of the RFS or System Cabinet. Locate the J5 connector on the MUX board in slot 13 & 14. In the RRF chassis, remove the connector at J5.

  2. Use the RF cable kit to swap the failing channel with an adjacent channel.

  3. Run MCR diagnostics again in A mode.

    • If problem moves, repair or replace cable between IF panel and MUX and then go to Restoring Original Connections to the Receive Chain.

    • If problem does not move, problem is in the RRF chassis.

      Run RRF datapath, board level or RF Receive Chain FRU Isolation diagnostic to find the problem. If these diagnostics pass, then repair or replace the MUX board.

      Return all cables to original position as shown in Figure 8 and go to Restoring Original Connections to the Receive Chain.

Topic ID: id_SL625176-621355

Restoring Original Connections to the Receive Chain

All cables should be in original position.

  1. Put MCR 2 tool on A connector.

  2. Run MCR 2 diagnostics again in A mode.

  3. Verify that there are no failures.

  4. Return MCR 2 tool to the storage container.

Connector B Overview

The LPCA's B Connector is different from the A Connector as the B Connector can pass signals.

When running MCR 2 diagnostics on the B Connector, there are two possible paths:

  • B1 or channels 1-8 (4, 8, or 16-channel systems)

  • B2 or channels 9-16 (16 channel systems only; not present in 4 and 8 channel systems).

If there is a common failure on B1 and B2 in a 16-channel system the problem is the electronics somewhere between the B Connector in the LPCA and the inside of the 16-channel Switch.

Example:

Failure on B1, channel 1 and failure on B2, channel 9. Since the failure is on the same channel for B1 and B2, this suggests that the problem is either in the cabling and connector prior to the 16-channel Switch or inside the 16-channel Switch. Continue with Step 1of this document, B Connector Receive Chain Troubleshooting.

If there is a failure on B2 in a 16-channel system but B1 passes then the problem must either be inside the 16-channel Switch or on channels 9-16 back to the System Cabinet. Continue with Step 3 of this document, B Connector Receive Chain Troubleshooting.

If there is a failure on B1 in an 8 or 4-channel system then continue with Step 1 of this document, B Connector Receive Chain Troubleshooting.

If there is a failure on B1 in a 16-channel system but B2 passes then the problem must either be inside the 16-channel Switch or channels 1-8 back to the System Cabinet.

Run MCR 2 on the A Connector. If A Connector passes then replace the 16-channel Switch. If it fails, however, then start at Step 3 in the A Connector Receive Chain Troubleshooting documents to isolate to the failure.

Testing LPCA Connector B

  1. Remove LPCA cover.

  2. Locate Connector B cables on the IF connector on top of LPCA and disconnect both cables from cable track.

  3. Remove Test Cable Assembly from MCR 2 tool.

  4. Connect both cable track cables directly to MCR 2 tool as shown in Figure 1.

  5. Run MCR 2 tool diagnostics.

    • If test passes, repair or replace B Connector and go to Restoring Original Connections to the Receive Chain.

    • If test fails, remove the MCR 2 tool and reconnect cables to J21 and J22 on the LPCA's IF panel.

      Reconnect MCR 2 tool to the Test cable assembly, and connect MCR 2 tool test cable back to B Connector in LPCA.

      Go to Testing Cable Track Assembly.

Topic ID: id_SL625265-621355

Testing Cable Track Assembly

  1. Disconnect the cable at J22 on the 16-channel switch.

  2. Locate and use the RF cable kit, and swap the failing channel with a neighboring channel that is passing. Figure 10 assumes a failure with either channel 1 or channel 2.

  3. Run MCR 2 test again.

    • If the problem moves, repair or replace cable track assembly and go to Restoring Original Connections to the Receive Chain.

    • If the problem does not move, remove the test cables and reconnect the original cable to J22 on the 16-channel Switch and go to Testing Receive Chain Path through the 16-channel Switch.

      If this is an 8-channel system AND failure is on channels 1 through 8, proceed to A Connector Receive Chain Troubleshooting, Testing Receive Chain Path through the 16-channel Switch. If the failure is on channel 9 through 16, proceed to Testing Receive Chain Path through the 16-channel Switch.

Testing Receive Chain Path through the 16-channel Switch

  1. Remove the cable from J2 on the 16-channel Switch.

  2. Use the RF Cable kit to swap the failing channel with an adjacent channel as shown.

  3. Run MCR 2 diagnostics again.

    • If the failure moves to another channel, repair or replace the 16-channel Switch go to Restoring Original Connections to the Receive Chain.

    • If the problem does not move, remove the test cables re-install cable to J2 on 16-channel switch. Go to Testing Path between 16-channel Switch and Pen Panel.

Topic ID: id_SL625258-621355

Testing Path between 16-channel Switch and Pen Panel

  1. Swap cables between J1 and J2 on the 16-channel Switch as shown in Figure 12. Swap cables between J200 and J201 on the equipment room side of the pen panel.

  2. Run MCR 2 diagnostics again.

    • If the diagnostics pass, then repair or replace the cable between J1 and J201 and go to Restoring Original Connections to the Receive Chain.

    • If the diagnostic fails, go to Testing Path between RFS/System Cabinet and Pen Panel.

Topic ID: id_SL625255-621355

Testing Path between RFS/System Cabinet and Pen Panel

  1. Swap cables between J1 and J2 on the 16-channel switch back to original configuration (see Figure 13).

  2. Leave cables J200 and J201 swapped at the equipment room side of the pen panel (see Figure 13).

  3. Swap cables J200 and J201 at the RFS or System Cabinet as shown in Figure 13.

  4. Run MCR 2 diagnostics again.

    • If the diagnostics pass then repair or replace the cable that normally interconnects J201 on the RFS or system cabinet IF panel and J201 of Pen Panel and go to Restoring Original Connections to the Receive Chain.

    • If diagnostics fail, go to Testing Path between IF Panel and MUX.

Topic ID: id_SL625280-621355

Testing Path between IF Panel and MUX

Keep cables in swapped position from Figure 13.

  1. Open the rear door of the RFS on System Cabinet. Locate the J5 connector on the MUX board in slot 4 & 5. In the RRF chassis, remove the connector at J5.

  2. Use the RF cable kit to swap the failing channel with an adjacent channel.

  3. Run MCR Diagnostics again.

    • If Problem moves, repair or replace cable between IF Panel and MUX. Go to Restoring Original Connections to the Receive Chain.

    • If problem does not move, problem is in the RRF chassis.

      Run RRF datapath, board level, or RF Receive Chain FRU Isolation diagnostics to find problem. If these diagnostics pass, then repair or replace the MUX board and go to Restoring Original Connections to the Receive Chain.

      Return all cables to original position as shown in Figure 15.

Topic ID: id_SL625514-621355

Restoring Original Connections to the Receive Chain

All cables should be in original position.

  1. Put MCR 2 tool on B Connector.

  2. Run MCR 2 diagnostics again.

  3. Verify that there are no failures.

  4. Return MCR 2 tool to the storage container.
