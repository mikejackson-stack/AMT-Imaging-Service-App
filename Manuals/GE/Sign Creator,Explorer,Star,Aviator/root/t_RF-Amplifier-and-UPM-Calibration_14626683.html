Table 3. Safety
DANGER
FATAL ELECTRIC SHOCK HAZARD!
The RF amplifier is not disabled.
To prevent fatal electric shock, ensure the RF amplifier is disabled while configuring the calibration tools.
CAUTION
Electrical/RF burn hazard
RF burns can occur as a result of disconnecting heliax cables while the system is scanning.
To prevent possible RF burns when disconnecting heliax cables from the RF amplifier, make sure that the system is not manually prescanning or scanning. Make sure that the scan desktop icon displays the “idle” message and the RF enable switch is in the “off” position.
CAUTION
Possible equipment damage!
Operating the RF amplifier with an improper load can cause permanent damage to the amplifier.
Do not operate the RF amplifier with an improper load connected to its output.
CAUTION
Possible equipment damage!
Hardware and phantoms left in the magnet bore can cause equipment damage.
Prevent coil and associated switch damage by removing all phantoms and hardware (such as head coil or surface coil) from the magnet bore.
CAUTION
Possible equipment damage!
If the wattmeter sensor is connected or disconnected while the meter is ON, equipment damage can occur.
Do not connect/disconnect the wattmeter sensor while the meter is ON. Always turn the meter OFF before plugging/unplugging sensor.

About this task

This procedure provides instruction to set up and calibrate the maximum power for the RF amplifier. The procedure also proceeds through the calibration and functional check of the Universal Power Monitor (UPM) for each channel.

Use the UPM Tool to process each channel through each procedure. For example, when you select Head mode, the tool executes the RF amplifier calibration and, if the amplifier passes, proceeds to the UPM calibration and then to the functional check. The process is order-dependent.

For RF Amp calibration, process body channel 1 first, then body channel 2, and then the Head channel last.

Per each channel calibration, RF amplifier forward power for channel is performed first, then UPM forward and reflected power calibration for channel, and finally UPM functional check is performed for channel.

Coolant Temperature Check

Procedure

  1. Confirm that ICC / CCU temperature is above 30°C.
  2. (For non-proprietary mode) If the CCU temperature is below 30°C, it is necessary to check the CCU temperature again during Manual Prescan at TG=100 in the procedure and raise the temperature by manual prescan.
Topic ID: id_SL1748073-1224490

Disabling T/R, DD, and RF Input for Body Mode

Procedure

  1. (For Agilent wattmeters) Plug in the wattmeter and turn it on. The wattmeter must be powered for at least 30 minutes for stable and accurate readings.
  2. DANGER
    Fatal electric shock hazard!
    The RF Amplifier is not disabled.
    To prevent fatal electric shock, ensure the RF Amplifier is disabled while configuring the calibration tools.
    Verify that the system is idle and all coils have been removed from the magnet bore.
  3. Open the front door of the ISC.
  4. Set Driver Module and Exciter switch per following steps.
    1. On the front of the driver module, set SW2 to TR DISABLE (down) and set SW3 to DD DISABLE (down).
      Note: Leave HV set to ENABLE.
    2. Set the RF Enable switch on the exciter to DISABLE (down).

Adjusting RF Amplifier Output Power for Body Channel 1

Procedure

  1. Set RF ENB to ENABLE (up).
  2. Press Landmark. Then, advance to scan. A phantom is not needed.
  3. (For non-proprietary mode) On the Common Service Desktop, select Calibration > UPM Tool and select Click here to start this tool.
  4. Make the following selections for the settings.
    Setting Value
    Nuclei 1H
    Task Launch RF Cal
    RF Chain Body Channel 1
    Note: Power Type is grayed out. This is normal.
  5. Select Start.
  6. When a popup appears asking if the system is properly set up, click Yes.

    The system sets the proper sequence for RF calibration of the selected body channel. This process takes about one minute.

  7. When a popup titled RF Amp Calibration appears as shown Figure 6, do not select the Success or Failure button at this time. First, go to the Scan Desktop as shown in Figure 7.
  8. Click the Patient icon to go to the Scan workplace.
  9. In the Prescan Looping window, set Transmit Gain (TG) to 100.
  10. Check if the CCU temperature is above 30°C or not.

    • If temperature is below 30°C, leave the manual prescan as it is until CCU temperature becomes 30°C or more.

    • If temperature is (becomes) above 30°C, go to next step.

  11. Set Transmit Gain (TG) to 180.
  12. Confirm that the reading of wattmeter is more than 1kW and less than 9.5kW.

    • If the reading is zero or very low, then 1) confirm the correct center frequency value and 2) select Done to stop looping and recheck the test setup cabling.

    • If the reading exceeds 9.5kW, adjust the gain to 9.5kW +/- 500watts for the body channel.

    If the amplifier trips, reset TG to the highest setting it reached before tripping.

    Note: If Manual Prescan must be stopped and restarted, you must relaunch the calibration sequence using the UPM Tool. Select Failure in the RF Amp Calibration popup (see Figure 6), and then click Start on the UPM Tool with the same menu selections, to relaunch the calibration sequence.
  13. Slowly increase TG to 200.
    Note: Allow 10 seconds for the meter reading to stabilize before making the next adjustment.
  14. Check the wattmeter to see if the reading is 15kW +/- 500 watts. If yes, proceed to the next step. If no, adjust the gain for the body channel.

    Alternate increasing TG in small increments, and slowly adjusting the CH1/HD gain adjust encoder on the RF amplifier front panel, until the wattmeter reads 15kW +/- 500 watts with TG at 200.

  15. After the RF output is calibrated to specification, reduce TG to 0 (zero) and then click Done.
  16. From the scan desktop, click the CSD icon.
  17. When the RF output is within specification, click Success on the RF Amp Calibration popup (see Figure 6).
    Note: The RF Amp Calibration popup may be hidden behind the ICW window. Move the ICW window to the left or right to see the RF Amp Calibration popup.

    If the RF output cannot be adjusted to spec, run the RF Amp Power Check Tool .

  18. Click Yes to confirm that the RF output calibration was successful.

    After a few seconds, PASS appears in the status area of the UPM Tool.

Calibrating UPM Forward Power for Body Channel 1

Procedure

  1. Proceed to calibrating forward power for the UPM in body mode. On the UPM Tool, make the following selections:
    For this setting: Select:
    Nuclei 1H
    Task Calibrate UPM
    RF Chain Body Channel 1
    Power Type Forward
  2. Select Start.
  3. Select Yes when the prompt asks if the hardware setup is correct.

    After approximately one minute, you are asked to confirm the peak power value output from the amplifier.

    If the power read from the power meter is within specification, click Yes. Otherwise, click No and recheck the calibration of the RF amplifier.

  4. The tool reports the steps as they progress. In about three minutes, the Status field on the UPM Tool displays PASS or FAIL.

    A popup appears reminding you to run reflected power after you have completed forward power.

Topic ID: id_SL5525136-1224490

Calibrating UPM Reflected Power for Body Channel 1

About this task

After calibrating forward power, calibrate reflected power as follows.

Procedure

  1. Disconnect the RF dummy load per following steps.
    1. Set RF ENB to DISABLE (down).
    2. Disconnect the RF dummy load from BODY RF OUT J4 for the body channel 1.
    3. Set RF ENB to ENABLE (up).
  2. From the UPM Tool, make the following selections:
    For this setting: Select:
    Nuclei 1H
    Task Calibrate UPM
    RF Chain Body Channel 1
    Power Type Reflected
  3. Select Start.
  4. Select Yes when the prompt asks if the hardware setup is correct.
  5. The tool reports the steps as they progress. The Status field on the UPM Tool interface displays PASS or FAIL within about three minutes.
  6. Reconnect coupler to J4 per following steps.
    1. Set RF ENB to DISABLE (down).
    2. When the body channel is calibrated (PASS) for reflected power, reconnect the coupler to RF amplifier body channel 1 port (J4). The stub cable remains connected to J22.
    3. Set RF ENB to ENABLE (up).
  7. Proceed to UPM Functional Check for Body Channel1.

UPM Functional Check for Body Channel1

About this task

After completing the UPM calibration, continue with the UPM functional check.

Procedure

  1. From the UPM Tool, make the following selections:
    For this setting: Select:
    Nuclei 1H
    Task UPM Func Chk
    RF Chain Body Channel 1
    Note: Power Type is grayed out. This is normal and is not used.
  2. Select Start.
  3. Select Yes when the prompts ask if the hardware is set up correctly.
  4. Prompts are displayed during test execution, including a popup message about the UPM tripping and a power trip error message. The tool performs three tests before the host trip. This takes 2 to 3 minutes before any user interaction is required.

    From the CSD, open the error log. Verify the error log contains the message that the UPM has “detected a power fault on Body Short Term Average.” Select Yes if an error message is displayed.

  5. After completing the calibration and check of the body channel 1, proceed to calibrating the RF amplifier for body channel 2. See Setting up and Calibrating RF Amplifier for Body Channel 2.
Topic ID: id_SL5525236-1224490

Setting up and Calibrating RF Amplifier for Body Channel 2

Procedure

  1. Setup hardware per following steps.
    1. Set RF Enable to DISABLE (down).
    2. Disconnect the 3/16-Wavelength Cable Stub from the RF amplifier channel 2 body port (J22) and set aside.
    3. Disconnect the body input BNC cable J14 (for body channel 1) from the RF amplifier and set aside.
    4. Disconnect input of coupler from J4 and attach the 3/16-Wavelength Cable Stub to the body channel output J4.

      This arrangement should remain in place during RF calibration, UPM calibration and UPM functional check for body channel 2 ONLY.

    5. Connect the input of the coupler to J22 on the RF amplifier.
    6. Reconnect the body channel 2 BNC input cable with cable labeled “J21” to BNC port J21 on the front of the RF amplifier.

      Confirm that the power meter is set up as it was for the body channel 1 procedure.

    7. Warning
      Electrical shock risk!
      Failure to connect the dummy load correctly could result in electric shock.
      Pay close attention to the connections to the dummy load.
      Set RF ENB to ENABLE (up).
  2. From the CSD, open the UPM Tool and make the following selections.
    Note: Power Type is grayed out. This is normal and is not used.
  3. Select Start.
  4. If the setup is ready, select Yes when the prompt asks if the hardware set up is correct.
  5. When a popup appears providing information about RF calibration adjustment, do not select either the Success or Failure button at this time.
  6. Go to the Scan Desktop and select the Patient icon to go to the Scan workplace.
  7. In the Manual Prescan Looping window, slowly move the Transmit Gain (TG) slide to 180. See Figure 8.
  8. Confirm that the reading of wattmeter is more than 1kW and less than 9.5kW.

    • If the reading is zero or very low, then 1) confirm the correct center frequency value and 2) select Done to stop looping and recheck the test setup cabling.

    • If the reading exceeds 9.5kW, adjust the gain to 9.5kW +/- 500watts for the body channel.

    If the amplifier trips, reset TG to the highest setting it reached before tripping.

    Note: If Manual Prescan must be stopped and restarted, you must relaunch the calibration sequence using the UPM Tool. Select Failure in the RF Amp Calibration popup (see Figure 6), and then click Start on the UPM Tool with the same menu selections, to relaunch the calibration sequence.
  9. Slowly increase the TG to 200.
  10. Check the wattmeter to see if the reading is 15kW +/- 500 watts. If yes, proceed. If no, adjust the gain for body channel 2 using the adjustment encoder marked CH2. See Figure 9.

    If the RF output cannot be adjusted to spec, see RF Amp Power Check Tool.

  11. After the RF output is calibrated to specification, reduce TG to 0 (zero) and then click [Done].
  12. Click Success to confirm that the RF output calibration was successful.

    After a few seconds, PASS appears in the status area of the UPM Tool.

UPM Functional Check for Body Channel 2

Procedure

  1. Notice
    This procedure is for dual drive RF amplifiers.
    On the UPM Tool, make the following selections:
    For this setting: Select:
    Nuclei 1H
    Task UPM Func Chk
    RF Chain Body Channel 2
    Note: Power Type is grayed out. This is normal and is not used.
  2. Select Start.
  3. Select Yes when the prompt asks if the hardware set up is correct.
  4. Prompts are displayed during test execution, including a popup message about the UPM tripping and a power trip error message. The tool performs three tests before the host trip. This takes 2 to 3 minutes before any user interaction is required.

    From the CSD, open the error log. Verify the error log contains the message that the UPM has “detected a power fault on Body Short Term Average.” Select Yes if an error message is displayed.

  5. Restore the Body RF cables per following steps.
    1. Set RF Enable to DISABLE (down).
    2. Disconnect the 3/16-Wavelength Cable Stub from J4and set it aside. Reconnect the system body channel 1 transmit cable to RF amplifier body output channel 1 RF OUT J4.
    3. Disconnect the coupler from RF amplifier channel 2 RF OUT J22 and set it aside. Reconnect the system body channel 2 transmit cable to RF amplifier body output channel 2 RF OUT J22.
    4. Reconnect body channel 1 BNC input cable with cable labeled "J14" to BNC RF input port J14 on the front of the RF amplifier.
    5. Set RF Enable to ENABLE (up).
  6. After completing the calibration and check of body channel 2, proceed to calibrating the RF amplifier for head mode Disabling T/R, DD, and RF Input for Head Channel.

Adjusting RF Amplifier Output Power for Head Chennel

Procedure

  1. Set RF ENB to ENABLE (up).
  2. Press Landmark. Then, advance to scan. A phantom is not needed.
    Note: No phantom is needed since dummy command for head connection is set in UPM Tool Head mode for SIGNA Pioneer.
  3. On the UPM Tool, make the following selections for the settings.
    Setting Value
    Nuclei 1H
    Task Launch RF Cal
    RF Chain Head
    Note: Power Type is grayed out. This is normal.
  4. Select Start.
  5. When a popup appears asking if the system is properly set up, click Yes.

    A message displays asking if you have completed the body mode. Click Yes.

    The system sets the proper sequence for RF calibration. This process takes about one minute.

  6. When a popup titled RF Amp Calibration appears, do not select either the Success or Failure button at this time. First, go to the Scan Desktop.
  7. Click the Patient icon (shown in Figure 7) to go to the Scan workplace.
  8. In the Scan workplace, click the patient model to open the manual prescan window.
  9. Slowly move the Transmit Gain (TG) slider to 180. Make sure everything is functioning normally and there is a reading on the wattmeter.
  10. Slowly increase the TG to 200 (if the amplifier trips, reset the TG to the highest setting it reached before tripping).
  11. Check the wattmeter to see if the reading is 4500 watts (4.5kW) ± 100 watts. If yes, proceed to the next step. If no, adjust the gain for the head channel.

    Turn the head adjust encoder (CH1/HD) on the RF amplifier front panel and, if necessary, increase the TG in small increments until the wattmeter reads 4500 watts (4.5 kW) ± 100 watts with TG at 200. If the output stops changing relative to the rotation of the gain adjustment encoder, cycle the amplifier power. Wait at least 10 minutes and then repeat the adjustment process.

    Allow 10 seconds for the meter reading to stabilize before the next adjustment.

  12. After the RF output is calibrated to specification, reduce the TG to 0 (zero) and then click [Done].
  13. From the scan desktop, click the CSD icon (see Figure 10).
  14. If the RF output is within specification, click Success on the RF Amp Calibration popup.
    Note: The RF Amp Calibration popup may be hidden behind the ICW window. Move the ICW window to the left or right to see the RF Amp Calibration popup.
  15. Click Yes to confirm that the RF output was successful.

    After a few seconds, PASS appears in the status area of the interface.

UPM Calibration for Head Channel

Procedure

  1. Proceed to calibrating the UPM in Head mode.
    For this setting: Select:
    Nuclei 1H
    Task Calibrate UPM
    RF Chain Head
    Power Type Forward
  2. Select Start.
  3. Select Yes when the prompt asks if the hardware setup is correct.

    After approximately one minute, you are asked to confirm the peak power value output from the amplifier.

    If the power read from the power meter is within specification, click Yes. Otherwise, click No and recheck the calibration of the RF amplifier.

  4. The tool reports the steps as they progress. In about three minutes, the Status field on the UPM Tool displays PASS or FAIL.

    A popup reminds you that you must run reflected power after you have run forward power.

  5. After calibrating forward power, calibrate reflected power as follows:
    1. Set RF ENB to DISABLE (down).
    2. On the front of the RF amplifier, disconnect the coupler from HEAD RF OUT/J3. Leave J3 open and unconnected.
    3. Set RF ENB to ENABLE (up).
    4. From the UPM Tool, make the following selections:
      For this setting: Select:
      Nuclei 1H
      Task Calibrate UPM
      RF Chain Head
      Power Type Reflected
    5. Select Start.
    6. Select Yes when the prompt asks if the hardware is set up correctly.
    7. Upon completion of reflected power calibration, return the cable configuration to support testing for forward power.

      1. Set RF ENB to DISABLE (down).

      2. On the front of the RF amplifier, connect the coupler to HEAD RF OUT/J3.

      3. Set RF ENB to ENABLE (up).

UPM Functional Check for Head Channel

Procedure

  1. After completing the UPM calibration, continue with the UPM functional check.
    1. On the UPM Tool, make the following selections:
      For this setting: Select:
      Nuclei 1H
      Task UPM Func Chk
      RF Chain Head
      Note: Power Type is grayed out. This is normal and is not used.
    2. Select Start.
    3. If the functional check passes, select Quit.
  2. CAUTION
    Electrical/RF burn hazard
    RF burns can occur as a result of disconnecting heliax cables while the system is scanning.
    To prevent possible RF burns when disconnecting heliax cables from the RF amplifier, make sure that the system is not manually prescanning or scanning. Make sure that the scan desktop icon displays the “idle” message and the RF enable switch is in the “off” position.
    Notice
    Possible equipment damage. Do not connect/disconnect the wattmeter sensor while the wattmeter is ON. Always turn the wattmeter OFF before plugging/unplugging sensor.
    Restore RF cables per following steps.
    1. Set the RF ENB switch to DISABLE (down).
    2. Disconnect the RF coupler from J3 and reconnect the head and transmit cables.
    3. Re-enable the TR and DD fault switches on the front of the driver module.
    4. Set RF ENB switch to ENABLE (up).
  3. After the RF amplifier and UPM are calibrated for head mode, proceed to Finalization.
Topic ID: id_14994189

Finalization

Procedure

  1. Confirm that the other RF amplifier system cables are reconnected to their correct locations for clinical scanning.
  2. Perform Check Scan.
  3. If all the calibrations have been successfully made, perform a SaveInfo to save the UPM calibration results.
