Starting SPT Stability Viewer

Procedure

  1. From Common Service Desktop (CSD) select Image quality, then SPT Stability viewer, Figure 1.
  2. Select the SPT pass that you want to analyze, then select open, Figure 2.
  3. At this time all stability plots for the selected SPT run will be displayed, Figure 3.
