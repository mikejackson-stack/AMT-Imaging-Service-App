About this task

Verify SaveInfo Data is used to verify content of SaveInfo media to the original data on the system disk drive. The program firsts checks that all files are present on the SaveInfo media and then if check sums match.

Procedure

  1. Insert your already created SaveInfo DVD into the appropriate drive if it's not already there.
  2. At the host computer, go to the Service Desktop and open the Service Browser if it's not already running and start the Guided Install tool in FE Mode, Figure 1.
  3. In Guided Install, go to the Save / Restore screen and click Check Information to start the verification process.
  4. The tool will then begin the verification of the data on the media with that on the system hard drive. SeeFigure 3
    If no media is present, the user will receive a error message at this time. See Figure 4
    While the media is being checked, the popup shown in Figure 5will be displayed on the screen. The run will take about 2 minutes.
  5. Once verification is complete, the system will ask if you want to view the log. See . Click the Yes button, Figure 6.
  6. A log will be shown that will list content found and it . See Figure 7. If any errors are reported, it his highly suggested that a new SaveInfo be created.

Finalization

Procedure

  1. Store Save/Restore media in a safe place.
  2. Do a test scan before customer turnover to ensure proper operation.
