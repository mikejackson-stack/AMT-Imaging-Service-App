Doing the ICN hard disk integrity diagnostic

Diagnostic Link

Diagnostics > System Function > Recon > VRE Hardware Diagnostics

Diagnostics > Hardware Location > PGR Cabinet > Recon > VRE Hardware Diagnostics

Purpose

The purpose of this diagnostic is to test the integrity for both hard disks on an ICN. Hard disk store acquisition data for certain applications in DVMR. This diagnostic essentially verifies the ICN hard disks can be used to reliably store and retrieve data by writing a known pattern to the acquisition partitions, reading it back, and comparing the contents.

Note: This diagnostic takes about 85 minutes to complete.

Components tested

ICN hard disks.

Requirements

The ICN is turned on and has at least one network connection from the ICN motherboard Ethernet port to the Host.

Block diagrams

Test sequence

  1. Select the ICN Hard Disk Integrity diagnostic from the VRE Hardware Diagnostics screen.
  2. Click Run.
    Note: After you click Run, do not click anywhere else in the Common Service Desktop until the test is complete. If you need to abort the test prior to its completion, click Stop.
  3. Make sure the ICN passes the diagnostic by reviewing the status in the Diagnostic Results table.

Expected results

This diagnostic has either a passed or failed status. If the diagnostic has failed, please review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in the table below.

Table 1. Diagnostic results
Result Description GE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Make sure the ICN is turned on. To identify the ICN, see Identifying the Image Compute Node (ICN) and use the following path: Utilities > Toolbox > VRE > ICN Identification.
  2. Make sure the Ethernet switch is turned on.
  3. If the diagnostic fails after a second attempt, run the ICN hard disk stress diagnostic. See Doing the Image Compute Node (ICN) hard disk stress diagnostic and use the following path: Diagnostics > System Function > Recon > VRE Hardware Diagnostics.
    1. If the diagnostic fails, replace the hard disk. Look at the System Error Log for the corresponding error message. This contains the slot number location of the hard drive. To identify the ICN, see Identifying the Image Compute Node (ICN) and use the following path: Utilities > Toolbox > VRE > ICN Identification.
    2. If the diagnostic succeeds, re-run the ICN hard disk integrity diagnostic.
  4. If the diagnostic fails after the third attempt, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. To identify the ICN, see Identifying the Image Compute Node (ICN) and use the following path: Utilities > Toolbox > VRE > ICN Identification.
    Note: If the ICN Ethernet port/cables are bad then all the tests for that ICN may fail. This does not apply to the IPMI test, which has a separate Ethernet cable.
    Note: The current product configuration has redundant motherboard Ethernet connection for each ICN.
