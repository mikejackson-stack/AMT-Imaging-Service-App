About this task

Tests in this section allow the service engineer to selectively force head mode peak power, pulse width, and duty cycle beyond allowable limits.

Procedure

  1. Notice
    If the SSM has switch cover (5120058) installed, remove the cover before performing the procedure outlined below.
    Verify that the system is not scanning and that all coils have been removed from the magnet bore. See the Safety section and the note in this section.
    Note:

    PROPERTY DAMAGE! PREVENT COIL AND ASSOCIATED SWITCH DAMAGE, BY REMOVING ALL PHANTOMS AND HARDWARE (I.E., HEAD COIL, SURFACE COIL...) FROM THE MAGNET BORE.

  2. If using the RF Power Measurement Kit then refer to the RF Power Measurement Kit laminated card set.

    1. Look in the upper, right corner of each card and find the card labeled 63 (1.5T Head Output).

      Note:

      The head RF output connection is no longer to the non-existent EFB unit, as the reference cards in some of the older kits show, but instead to the J3 output on the rear of the RFI.

    2. Configure the system as shown in the illustration on the card.

    3. Confirm that the rotary attenuator is set to the correct position indicated on the card.

  3. If using the wattmeter or scope (NOT the RF Power Measurement Kit) to measure power then refer to ALTERNATE EQUIPMENT SETUPS & NON-SERVICE PROTOCOLS for the proper system head configuration.
  4. At operator workspace, select the scan desktop ICON in the desktop control panel, if you have not already done so.
  5. At the operator workspace, prepare the system for a Head Power Monitor scan using the "Service Protocols" procedure in Table 5 below. Refer to ALTERNATE EQUIPMENT SETUPS & NON-SERVICE PROTOCOLS for the non-proprietary protocol.

  7. Start at the first Test row in Table 9. Under the Scan Conditions column highlight or type-in the CVs into the CV Name box. Then enter the listed corresponding number into the Current Value box. Right mouse-click on the remaining items listed in the column.
  8. Advance to the Adjustments column on the right and perform the directions listed in the column. Refer to the following steps for measuring the RF output power.
  9. If using the RF Power Measurement Kit then refer to card 63 (1.5T Head Output) and note the Attenuation value listed on the calibration sticker affixed to the bottom, right of the card.

    1. Measure the amplitude of the RF waveform from the scope face in divisions.

    2. Mouse click on the ToolBelt Icon and then [Utilities], [RF Calculator], [Start].

    3. Use the RF Calculator program to determine the power output from the amplifier. Enter the actual reference and measured values in place of the sample values in the example below in Table 6.

    4. Note the amplifier output power calculated by the RF Calculator program. Continue with the Table instructions.

  12. When all measurements have been completed then reference the specified limits in the Verify column and record the PASS/FAIL status of the test.
  13. Perform the steps in Conclusion column and then proceed to the next row and repeat the process again. Continue this until all the tests listed in the Table have been completed.
