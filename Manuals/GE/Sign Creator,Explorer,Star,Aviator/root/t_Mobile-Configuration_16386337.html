Mobile Configuration

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable15 minutesNot Applicable

About this task

The Mobile Site Setup feature provides the ability to change a mobile's Hospital Name, Host Name, IP Address, Netmask and the Host or Network DICOM information on the Mobile Site Setup window. The IIP InSIte connection will work at each site, provided it was checked out and has its own System ID in the Online Center database.

Topic ID: id_SL52738-1243427

Starting the Mobile Setup Tool

Procedure

  1. With Signa up and running in Scan mode, open the Service Desktop by clicking the Service Desktop button on the left side of the screen. (See Figure 1.)
  2. On the Service Desktop, open the Common Service Browser if not already running. Start the Mobile Tool as shown in Figure 2.
  3. In the center of the Service Desktop Manager (shown in Figure 2), select Mobile to open the Mobile Setup window.
  4. When the command prompt asks for a password, enter the root password, operator and press Enter.
Topic ID: id_SL1445819-1243427

Mobile Site Setup Window Description

Procedure

  1. Refer to the Mobile Setup window in Figure 3 and Table 2 for a description of each field on this window.
    Table 2. Mobile Setup Field Descriptions
    Field Description
    (1) Hospital NameEnter the hospital name (up to 30 characters using A-Z, a-z, 0-9, & - only).
    (2) Host NameThe system's host name can consist of up to 30 characters, and is stored in the configuration file. A GE Service Engineer enters the system's host name initially.
    (3) IP AddressAn IP address is four groups of integers with a dot between each group that uniquely identifies the computer on the network. Consult a GE Service Engineer for this information.
    (4) NetmaskNetmask address should be a four groups of integers with a dot between each group that uniquely identifies the computer on the network. Consult a GE Service Engineer for this information.
    (5) RouterThis information will need to be provided by the site's network administrator. Typically, an IP Address will be provided (generally called Default Gateway).
    (6) List of Previously Entered HospitalsSelect this key to choose a different hospital.
    (7) AE Title and Port No.Host DICOM information is optional for mobiles that interface with a Network DICOM device. Consult a GE Service Engineer for this information.
    (8) Network DICOM DevicesUsed to add up 5 network DICOM devices that interface with the mobile. Consult a GE Service Engineer for a list of IP addresses, AE Title and port number.
    (9) AddSelect Add to add a hospital to the list.
    (10) ChangeSelect Change to edit or modify previously stored hospital information.
    (11) RemoveSelect Remove to delete a hospital from the list.
    (12) SearchSelect Search to find a hospital on the list. Search options are executed by either Hospital or Host name.
    (13) ActivateSelect Activate to activate the selected hospital.
    (14) DoneSelect Done to exit the Mobile Site Setup window.
  2. Click Add to add a hospital to the list.
  3. Click Done to exit the Mobile Site Setup window.

Mobile Site Activation Window Description

Procedure

  1. Note:

    Mobile Site Activation is opened by clicking (13) Activate.

    Figure 4 displays the Mobile Site Activation window.Table 3 offers an description of each button.
    Table 3. Mobile Site Activation Field Descriptions
    Button Description
    (1) Activate SiteSelect this button to activate a different hospital. A reboot is required with this selection.

Applications and Considerations

About this task

The Applications feature is used to update the image annotation with the appropriate name for the hospital or outpatient facility.

Procedure

  1. Below are some general considerations:

    • Periods, commas, or apostrophes (non-alphanumeric characters) are not valid for hospital names. For example: “St. Luke's” is invalid, whereas “St Lukes” is valid.

    • Purchased options and features stay with the mobile unit and will not change from site to site. To add a hospital to the list, the minimum entry is the MR Scanner information (Hospital, Host Name, IP Address, Netmask and Router).

    • Hospital Name, Host Name, IP Address, Netmask, Router, Host or Network DICOM information will have to be obtained from the site's network System Administrator before attempting to add a new system.

    • If changes are made to DICOM or network information in the Browser or Install, the entry in the list needs to be deleted and re-entered.

    • Only Activate Site requires a reboot of the system.

  2. In order to add the current hospital to the list of previously entered sites, select Get Active Site from the Mobile Site Activation window.

    • The Mobile Site Setup window will prompt for information to be entered into the mobile database.

    • If Yes is selected, the hospital is added. If the Mobile Site Setup window does not provide a prompt, the hospital name is already in the mobile database.

Selecting a Different Hospital

Procedure

  1. With Signa up and running, open the Mobile Setup window. (See Figure 3.)
  2. Select a hospital from the list on the Mobile Site Setup window. (See Figure 5.)
  3. Select Activate.
  4. Select Activate Site on the Mobile Site Activation menu. (See Figure 6.)
  5. If another pop-up displays, click Continue.
  6. Select Done.
  7. Click Yes on the Exit Mobile GUI dialog box. (See Figure 7.)
  8. Shut Signa down from the Service Desktop, then restart. The system will display the updated information for the selected hospital.
Topic ID: id_SL1445837-1243427

Adding a New Hospital Using Get Active Site

Procedure

  1. With Signa up and running, open the Mobile Site Setup window. (See Figure 3.)
  2. Select Activate on the Mobile Site Setup window.
  3. Select Get Active Site on the Mobile Site Activation menu. (The Mobile Site Setup window will be updated using the currently active hospital's information. See Figure 4.)
    Note:

    If the hospital name is not in the mobile database, the system will ask if the hospital information should be added. Select Yes to add it. (Refer to Step 2.)

  4. Select Done on the Mobile Site Setup window.
  5. On the Exit Mobile GUI menu, select Yes.
Topic ID: id_SL1445846-1243427

Adding a New Hospital

Procedure

  1. With Signa up and running, access the Mobile Setup window. (SeeStarting the Mobile Setup Tool.)
  2. Select Add on the Mobile Site Setup window.
  3. At the minimum, enter the Hospital Name, Host Name, IP Address, Netmask and Router. Consult with a GE Service Engineer for this information if unknown.
  4. Click Add again.
  5. If the newly added hospital needs to be activated, proceeds as follows:
    1. Select the new hospital from the list.
    2. Select Activate on the Mobile Site Setup window.
    3. Select Activate Site on the Mobile Site Activation menu. (See Figure 4.)
    4. Select Continue.
    5. Select Done on the Mobile Site Setup window.
    6. On the Exit Mobile GUI menu, select Yes. (See Figure 7.)
Topic ID: id_14983556

Finalization

Procedure

  1. Shut Signa down from the Service Desktop and restart.
  2. Perform a quick test scan. The system should now display the correct site information. If not, repeat the procedure in Starting the Mobile Setup Tool.
