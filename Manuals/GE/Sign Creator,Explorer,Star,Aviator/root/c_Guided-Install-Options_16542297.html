Guided Install Options

note:

For item with default selection as blank, must be configured per hardware configuration list below/above. The additional selection choices are other 1.5T serial signa products. Incorrect selection of the hardware configuration would result in prohibition of proceeding.

1 Under [System Configure]

Date Format Enter the date format to be used by the customer

Weight Unit Enter either Pounds or Kilograms

Keyboard Enter keyboard that is used for specific country

Language Enter language that will be used by customer

Video Card Not used at the introduction

Display type Enter the video mointor that will be used for the system

Enable HO Shim Must be No, as High Order Shim is not available

Legacy Image Type Should be set to [Yes]

2 Under [Hardware Configure]

Product Name 1.5T, 60cm, SIGNATM Creator / Explorer

Field Strength must be 1.5T

Package Name must be XFD SR120

Gradient type must be 8919(XFD)

Resonance Module BRM/BRM2

Magnet Serial Number Enter actual magnet serial number.

Table Limit is default, cannot change

Line Frequency Set to either 50 or 60 hz

RF Amp Type Select 1.5T SRFD3 RF amp or 1.5T CSA RF amp.

note:

According to the real RF Amp Type on site, choose the RF Amp Type configuration.

Governing Body Select fda2,For Japan, select ‘MHLW-JIS’.

ISO Vector Z 9600 Magnet Enclosure

Magnet Enclosure shall select “SIGNA Creator/Explorer”

PAC type Select the proper PAC

RF-Systems Cabinet(RFS) Select YES

Spectro RF Amp type Select [none]

Mega swich type Select 16 ch

Shim Supply type Select [none]

note:

Table configuration selected by checking table part number

  • 5777777 for Fixed Table 160.0 kg weight limitation

  • 5777777–2 for Fixed Table 200.0 kg weight limitation

Table type Select fixed table/detachable table

Grad Processor type Select GP4
