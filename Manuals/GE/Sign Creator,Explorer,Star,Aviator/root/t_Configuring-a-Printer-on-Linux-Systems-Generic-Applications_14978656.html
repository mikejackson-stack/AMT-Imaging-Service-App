Configuring a Printer on Linux Systems (Generic Applications)

About this task

This document provides instruction on configuring both network and local printers on Linux systems.

Topic ID: id_SL3521447-1330225

Procedure for Network Printer

Procedure

  1. Log out by clicking on System Restart then OK. The system will then reboot.
  2. When the login screen appears, login as root password is operator.
    Note: It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.
  3. Place cursor in the background, and “right click” on the mouse.
  4. Select Configure Printer option. The Printer configuration window appears.
  5. Click New to add printer to the system.
  6. A New Printer window appears. Click Network Printer >> Find Network Printer.
  7. Type the printer IP address In the Host area and click Find.
  8. The Queue information appears, click Forward.
  9. The Choose Driver window appears. Click Forward.
  10. The Describe Printer window appears. Click Apply.
  11. A window pop up reminding you to print a test page. Click Yes.
  12. A window pop up reminding you the test page submitted. Click OK.
  13. Check the paper has been printed successfully. And the printer will show in the window.
Topic ID: id_SL1963012-1330225

Procedure for Local Printer

Procedure

  1. Connect local printer to the parallel port in the rear of the Linux PC.
  2. Log out by clicking on System Restart then OK. The system will then reboot.
  3. When the login screen appears, login as root and type the root password.
    Note: It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.
  4. Place cursor in the background, and “right click” the mouse.
  5. Select Configure Printer option. The Printer configuration window appears. See Figure 1.
  6. Click New. The Select Device window appears and the local printer is shown.
  7. Select the local printer and click Forward. The Describe Printer window appears. See Figure 5.
  8. Click Apply and a window pop up reminding you to print a test page. Click Yes.
  9. A window pop up reminding you the test page submitted. Click OK.
  10. Check the paper has been printed successfully. And the printer will show in the window.
