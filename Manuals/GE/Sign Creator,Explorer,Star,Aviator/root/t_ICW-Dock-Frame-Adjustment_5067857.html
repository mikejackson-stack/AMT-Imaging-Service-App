ICW Dock Frame Adjustment

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable60 minutesNot Applicable

About this task

During Dock Adjustments there are one tasks that must be completed and checked off:

  • Dock Frame Location Check and Adjustment

Procedure

  1. Insert the Service Key.
  2. Launch the Service Browser (Common Service Desktop).
  3. Click the Calibration tab.
    Note:

    a. If you are in Install or Upgrade mode, clickInstall and Calibration Wizard and then Click here to start this tool.

  4. The second step in the ICW is Dock Adjustments (see Figure 1). Verify that all previous steps in the ICW are complete. They should be highlighted and Blue.
  5. Perform the adjustment.

    Fixed Table

    • Check the Dock Frame Location. Refer to Dock Frame Location Check and Adjustment for Fixed Table.

      When this is complete, check the box next to “Is Dock Centering done?”

    • There is no hook on Fixed Table Dock Frame. Just check the box next to “Is Dock Hook Tension Adjusted?”

    • Click Submit. This will complete the Dock Adjustment section of the ICW.

    Low Height Fixed Table

    • Check the Dock Frame Location. Refer to Location Check and Adjustment for Low Height Fixed Table.

      When this is complete, check the box next to “Is Dock Centering done?”

    • There is no hook on Fixed Table Dock Frame. Just check the box next to “Is Dock Hook Tension Adjusted?”

    • Click Submit. This will complete the Dock Adjustment section of the ICW.

Finalization

No finalization steps.
