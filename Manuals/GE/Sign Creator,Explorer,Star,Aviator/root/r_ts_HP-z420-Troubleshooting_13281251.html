2 Computer Status

The power button on the front of the computer contains an LED that signals the state of the computer through color and blinking. No audible codes (beeps) accompany these states.

LED Status LED Color System Status
Solid Blue System is ON
Blinking Blue System is in standby
Solid or blinking Red System has error
None No light System is in hibernate mode or is OFF

4 LED and Beep Codes

When the system starts up, the system firmware performs pre-boot diagnostics to test the hardware configuration. If a problem is detected during pre-boot, the system activates the LED and makes audible beeps, which provide an encoded error message. The system displays a different blinking pattern and makes a different number of beeps for each type of error. The sequence may start with a modem-like sound lasting about three seconds, followed by a number of clear beeps or, it may make only clear beeps. Blinks and beeps repeat for five cycles. After the fifth set, only blinks continue to repeat.

note:

Troubleshooting actions are described in Troubleshooting Problems during Operation and POST Codes.

Beeps LED Possible Cause Action
2 Red Power LED blinks two times, once every second, followed by a two-second pause. Two beeps.

CPU thermal protection activated by either of the following methods:

  • A fan might be blocked or not turning.

  • The heatsink and fan assembly is not properly attached to the CPU.

  1. Ensure that the computer air vents are not blocked and the cooling fan is running.

  2. To prevent damage, disconnect the computer power cord.

  3. Open the access panel, press power button, and verify that the CPU fan is spinning. If the CPU fan is not spinning, make sure the fan cable is plugged into the computer board header. Ensure the fan is fully and properly seated or installed.

  4. If fan is plugged in and seated properly, but is not spinning, the problem might be in the CPU fan. Contact HP for assistance.

  5. Verify that the fan assembly is properly attached. If problems persist, there might be a problem with the CPU heatsink. Contact HP for assistance.
3 Red Power LED blinks three times, once every second, followed by a two-second pause. Three beeps. CPU not installed (not an indicator of bad CPU).

  1. Verify that the CPU is present.

  2. Reseat the CPU.
4 Red Power LED blinks four times, once every second, followed by a two-second pause. Four beeps. Power failure (power supply is overloaded).

  1. To prevent damage, disconnect the computer power cord.

  2. Open the access panel and ensure that all power connections are secure on the system board.

  3. Check if a device is causing the problem by removing all attached devices (such as hard, diskette, or optical disk drives, and expansion cards.) Power on the computer. If the system enters the POST, power off and replace one device at a time; repeat this procedure until failure occurs. Replace the device that is causing the failure. Continue adding devices one at a time to ensure all devices are functioning properly.
5 Red Power LED blinks five times, once every second, followed by a two-second pause. Five beeps. Pre-video memory error.

  1. To prevent damage, disconnect the computer power cord.

  2. Reseat DIMMs.

  3. The problem might be on the system board. Contact HP for assistance.
6 Red Power LED blinks six times, once every second, followed by a two-second pause. Six beeps. Pre-video graphics error.

  1. To prevent damage, disconnect the computer power cord.

  2. Reseat the graphics card.

  3. Verify the graphics auxiliary power cable is connected (if applicable).

  4. Confirm the graphics card is in the appropriate slot (PCIe x16).

  5. The problem might be on the graphics card. Contact HP for assistance.
7 Red Power LED blinks seven times, once every second, followed by a two- second pause. Seven beeps. System board failure (ROM detected failure prior to video).

  1. To prevent damage, disconnect the computer power cord.

  2. Clear CMOS.

  3. The problem might be on the system board. Contact HP for assistance.
8 Red Power LED blinks eight times, once every second, followed by a two-second pause. Eight beeps. Invalid ROM based on bad checksum.

  1. Clear CMOS.

  2. Upgrade the ROM using SoftPaq, either from the hard disk drive, CD, diskette, or USB removable device (for example, HP Drive Key).

  3. The problem might be on the system board. Contact HP for assistance.
9 Red Power LED blinks nine times, once every second, followed by a two-second pause. Nine beeps. System powers on, but does not start.

  1. The problem might be on the system board. Contact HP for assistance.

  2. The problem might be in the CPU. Contact HP for assistance.
10 System does not power-on and LEDs are not blinking. No beeps. System unable to power on.

To resolve the problem, choose one of the following options:

  1. Press and hold the power button for less than four seconds. If the hard disk drive LED turns green, then:

    1. Remove the expansion cards one at a time and try holding the power button again for less than four seconds.

    2. The problem might be on the system board. Contact HP for assistance.

  2. Press and hold the power button for less than four seconds. If the hard disk drive LED does not turn on green then:

    1. Check that unit is plugged into a working AC outlet.

    2. Open the access panel and check that the power button harness is properly connected to the system board

    3. Check that all power supply cables are properly connected to the system board.

    4. Check the power supply functionality..

      • Disconnect the AC power.

      • HP Z820 Workstation only—Remove the power supply from the chassis. All other workstations, unplug cables connected to system board.

      • Plug in AC power.

        If the power supply fan spins and the BIST LED illuminates, the power supply is good; replace the system board.

        If the power supply fan does not spin or the LED does not illuminate, replace the power supply.

5 Troubleshooting Problems during Operation

The following table describes problems that may occur during operation of the HP z420.

Problem Possible Cause Possible Solution

Poor performance

Processor is hot.

  1. Verify that airflow to the workstation is not blocked.

  2. Verify that the workstation chassis fans are connected and working properly. Some fans operate only when needed.

  3. Verify that the processor heatsink is installed properly.

Workstation powers off automatically; the power LED flashes 2 times followed by 2 beeps.

Processor thermal protection is activated.

A fan may be blocked or not turning.

OR

The processor heatsink is not properly attached to the processor.

  1. Verify that the workstation air vents are not blocked.

  2. Open the access panel and press the workstation power button.

  3. Verify that the system fan is running.

  4. Verify that the processor heatsink fan spins. If the fan is not spinning, verify that the heatsink fan cable is plugged into the system board connector and that the heatsink is properly seated.

8.2 Boot Process for SAS Devices

To view all hard drives detected by the BIOS:

  1. Enter the BIOS by turning off the PC, turning it back on, and pressing F10 while the computer boots.

  2. Select Storage, and then select Boot Order.

    The screen displays a list of the hard drives and the order in which the computer tries to boot from them.

    note:

    The default CMOS setup is the normal configuration for this HP z420 PC. This is not true for all HP PCs.

  3. Exit the BIOS by pressing Esc twice. Move the cursor to highlight Ignore Changes and Exit and press Enter. The PC will then boot

8.3 SAS Diagnostics

To run a hard drive diagnostic, follow these steps.

  • notice
  • Potential for Inaccurate Scans Running the smartctl utility while scanning a patient may degrade disk perfomrance for up to several hundred milliseconds. Do not run smartctl while scanning a patient.

  1. Open a terminal window and log in as root.

  2. Type the appropriate command to view the diagnostic for the drive you are diagnosing:

    For this drive: Type this command:
    HDD0 (/SDA) smartctl -a /dev/sda
    HDD1 (/SDB) smartctl -a /dev/sdb
    HDD2 (/SDC) smartctl -a /dev/sdc

  3. Make sure the SMART Health Status is “OK” and the Current Drive Temperature is less than the Drive Trip Temperature.

9 POST Codes

The information in this section is taken from the HP manual for the computer, and can help in troubleshooting issues with the HP z420 PC.

Power On Self Test (POST) is a series of diagnostic tests that run automatically when the system is turned on. An audible and/or visual message occurs if POST encounters a problem. To ensure that the workstation is working properly, POST checks the keyboard, DIMMs, diskette drives, all mass storage devices, CPUs, controllers, fans, temperature sensors, cables (front/rear panels, audio, and USB ports).

POST checks can be used to assist with failure isolation.
