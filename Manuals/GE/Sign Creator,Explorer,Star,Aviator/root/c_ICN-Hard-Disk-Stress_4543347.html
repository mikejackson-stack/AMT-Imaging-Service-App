Doing the ICN hard disk stress diagnostic

Diagnostic link

Diagnostics > System Function > Recon > VRE Hardware Diagnostics

Diagnostics > Hardware Location > PGR Cabinet > Recon > VRE Hardware Diagnostics

Purpose

The purpose of this diagnostic is to test the disk throughout for both of the hard disks on an ICN. Hard disks store acquisition data for certain applications in DVMR. This diagnostic essentially verifies the ICN hard disk performance is fast enough to keep up with the incoming data during acquisition.

Components tested

ICN hard disks

Requirements

The ICN is turned on and has at least one network connection from the ICN motherboard Ethernet port to the host.

Block diagrams

Test sequence

  1. Select the ICN Hard Disk Stress diagnostic from the VRE Hardware Diagnostics screen.
  2. Click Run.
    Note: After Run is selected, do not click anywhere else in the Common Service Desktop until the test is complete. If you need to abort the test prior to its completion, click Stop.
  3. Make sure the ICN passes the diagnostic by reviewing the status in the Diagnostics Results table.

Expected results

This diagnostic has either a passed or failed status. If the diagnostic has failed, review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in the table below.

Table 1. Diagnostic results
Result Description GE Field Action
PassedICN passed the diagnostic.No further action required.
Failed ICN failed the diagnostic.
  1. Make sure the ICN is turned on. To identify the ICN, see Identifying the Image Compute Node (ICN). (Utilities >> Toolbox >> VRE >> ICN Identification).
  2. Make sure the Ethernet switch is turned on.
  3. If the diagnostic fails after a second attempt, run the ICN Hard Disk Integrity diagnostic. See Doing the ICN hard disk integrity diagnostic. (Diagnostics >> System Function >> Recon >> VRE Hardware Diagnostics).
    Note: The ICN hard disk integrity diagnostic takes about 50 minutes to complete.
    1. If the diagnostic fails, replace the hard disk. Look at the System Error Log for the corresponding error message. This contains the slot number location of the hard drive. To identify the ICN, see Identifying the Image Compute Node (ICN). (Utilities >> Toolbox >> VRE >> ICN Identification).
    2. If the diagnostic succeeds, re-run the ICN Hard Disk Stress diagnostic.
  4. If the diagnostic fails after the third attempt, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN. (Utilities >> Toolbox >> VRE >> ICN Identification).
    Note: If the ICN Ethernet port/cables are bad, all the tests for that ICN may fail. This does not apply to the IPMI test, which has a separate Ethernet cable.

    The current product configuration has a redundant motherboard Ethernet connection for each ICN.
