Topic ID: id_SL307489-307566

Overview and Flowchart

Procedure

  1. This procedure describes how to calibrate the AMT RF amplifier (also referred to as the MNS (multi-nuclear spectroscopy) amplifier, or broadband amplifier) in the 3.0T Signa system.
  2. Calibration is done to make sure that the AMT RF amplifier is producing the specified amount of RF power for broadband operation. The RF output power should be checked if any of the hardware in the RF chain is replaced. If the output levels are not within specification, then adjustments should be made to the AMT RF amplifier output to achieve the proper level of power. The AMT (MNS) amplifier output should be adjusted to a maximum output power of 2.5 kW.
  3. This procedure is for 3.0T head and body systems only.
Topic ID: id_SL11885703-307566

Overview

Procedure

  1. DANGER
    PROPERTY DAMAGE!
    PREVENT COIL AND ASSOCIATED SWITCH DAMAGE.
    Remove ALL PHANTOMS AND HARDWARE (such as AMT MNS COIL and SURFACE COIL) FROM THE MAGNET BORE.
    DANGER
    PERSONAL INJURY!
    PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RFI BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRE-SCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE AND THE UCERD SWITCH IS IN THE "DISABLE" POSITION.
    The calibration procedures described in this section must be performed for the following situations:

    • Initial system installation

    • The RF exciter has been changed (this change can possibly affect the RF output level of the exciter)

    • DRSM replacement

    • Any of the AMT RF amplifier FRU 1s has been changed (this change can possibly affect the power gain of the amplifier)

  2. A calibration flowchart (Figure 2) has been provided in the overview.
  3. Process summary:
    1. Disable T/R drive fault condition.
    2. Disable RF power monitor.
    3. Determine losses - perform dummy load and cable calibration.
    4. Check MNS mode - maximum RF power output.
    5. Adjust the broadband potentiometer on the front of the DRSM.
    6. Re-enable the power monitor.
    7. Re-enable the T/R drive fault condition.
  4. DANGER
    PROPERTY DAMAGE!
    PREVENT COIL AND ASSOCIATED SWITCH DAMAGE
    Remove ALL PHANTOMS AND HARDWARE (such as HEAD COIL and SURFACE COIL) FROM THE MAGNET BORE.
    Disable T/R drive fault condition:
    1. The T/R drive system will generate a fault and inhibit scanning if the head T/R networks are not attached to the RF amplifier. This calibration procedure requires the disconnection of the cables that cause this fault condition, which will allow the system to scan.
    2. Verify that the system is idle, and all coils have been removed from magnet bore.
    3. Remove the front cover of the accessories cabinet.
    4. On the front of the SSM, disable T/R error reporting by setting the TR switch to the DIS (disable faults) position.
  5. Disable the RF power monitor:
    1. Note:

      HVON should remain set to EN (enabled), and the power monitor switches should remain in NORMAL position. The SSM power monitors are NOT used in this system.

      This section disables the 3.0T RF power monitor by removal of the RF sense cables. This is necessary to perform the RF maximum power calibrations for both head and body modes.
    2. Open the rear door of the accessories cabinet.
    3. If not already marked, make sure to mark the 4 sense cables.
    4. Remove the 4 RF sense cables from the power meters.
  6. Calibrate dummy load and cables:
    1. Overview:

      1. The Signa system exciter, receiver, reference cables, DC block, and adaptor connectors are used as a test setup to measure the attenuation of the dummy load, connectors, and test cables that will be used in the measurement.

      2. Process: The test setup is connected between J1 and J2 of the system cabinet (see Figure 3). Receiver gains R1 and R2 and transmit gain (TG) are set for near full scale reading on the power spectrum during prescan calibration. A reference scan is performed and analyzed using the atten_test tool on a minimum test setup to establish a baseline. After the baseline is created, the test setup hardware is reconfigured to include all of the cables, connectors and dummy load that will be used to make the measurement (see Figure 3) and another scan is performed. The data from these two scans is then analyzed using the atten_test tool.

      3. Output: The atten_test tool provides the [Magnitude Squared Attenuation Factor] for each test setup. The result is used to calculate the attenuation in dB for each test setup.

    2. Tools and instruments required:
      Table 3. Required Tools and Instruments
      Description Quantity
      50 ohm dummy load, 200 watt, 30 dB attenuator - Bird model 8322 (or equivalent).1
      RF test cables kit 1
  7. Initial setup:
    1. Remove the front cover from the system cabinet.
    2. Note:

      You will need at least two BNC cables for the reference cable setup. The cable connected to J2 at the system cabinet must be long enough to reach the rear of the magnet in order to connect to the N connector attached to the head T/R input.

      Configure test hardware as shown in the illustration below.
    3. Note:

      It may not be necessary to use all adapters from the RF cable kit when connecting to the RF transmit path, dummy load, and test cable or dial attenuator and test cable.

      Note:

      Failure to insert a DC block will cause permanent damage to the receiver.

      Make sure the accessory PC is in Operate mode; otherwise, the system will not scan.
  8. Reference scan:
    1. Click New Pt.
    2. Id: geservice.
    3. Weight (Lb): 111.
    4. Set Patient Protocols to Service.
    5. Select Other and scroll down to the protocol named 3T dummy load cal depending on software revision.
    6. Select Series 1, Dummy Load, Cal: RF Cab.
    7. Set a landmark if necessary, then Save Series.
    8. Right-click Research Operations, then select Display CVs.
    9. Set value of CV calmode to 2 (trapezoid pulse).
    10. Important: Make sure the previous CV has been cleared before entering the next one. Look at the screen!
    11. Set value of CV p2_ramp to 1 (1 µsec ramp time).
    12. Set value of CV t2 to 50000 (50 msec tr).
    13. Set value of CV pismode to 1 (exc service).
    14. Set value of CV pmode to 1 (data collection).
    15. Set value of CV daqm to 1 (data in window).
    16. Select Accept and then Research Operations. Select Download and then Manual Pre-scan.
  9. Reference scan - analysis:
    1. In Manual Prescan, set Analog Gain R1 to 7, and Digital Gain R2 to 14.
    2. Adjust TG to achieve an R1 or R2 (on IP display) of approximately 98%, without going over.
    3. Select Done.
    4. Note:

      On the LX systems tested, the scan time starts at 13 seconds, counts down to 7 seconds, then ends. This is normal.

      Select Scan. (Ignore the message “MR signal too large, reduce receiver gain.”)
    5. From the MR Tools desktop, select Cals/checks and then Attenuation Test.

  12. Measuring the output power of the AMT amplifier:
    1. In this section you reconnect the calibrated cables and dummy load.
    2. At the front of the TPS chassis, set the safety switch to DISABLE the UCERD RF output.
    3. Disconnect the RF output cable from the RF OUTPUT connector from the back of the AMT RF amplifier.
    4. Reconnect the 30 dB dummy load to the RF OUTPUT connector, using the calibrated RF connectors and cables.
    5. Set the sweep rate to 5 nsec.
    6. Confirm that the channel-input impedance is not set for 1 M-ohm.
    7. Confirm that the scope bandwidth limit switch is not enabled.
  13. Note:

    After you download, the Research and Spectro LEDs on the front of the DRSM should activate.

    Preparing to scan:

    Prepare the system to scan the information below.

    4. Weight (Lb): 300 Enter

    9. Mode: 2D

    Image Option: EDR Accept

  14. Calculation of RF power:
    1. In this section you actually measure the AMT amplifier output, using the power calculator or formula, to determine the voltage level in amplitude necessary to achieve 2.5 kW of power at the rear of the AMT RF amplifier.
    2. Peak voltage should be used in the calculation in order to get an accurate result. Use the formula or the power calculator to get this calculated voltage level. To get an accurate measurement, you need to factor in scope correction factors and actual total losses associated with the test setup.
      Note:

      If the scope calibration factor or roll-off is not known, you can assume its value is 1. However, for an accurate measurement, it is recommended that the oscilloscope roll-off calibration procedure (see Characterization for Scopes with Less than 300 MHz Bandwidth) be performed. Signal roll-off is due to the inability of the oscilloscope to measure high-speed pulses. At 51.7 MHz (phosphor center frequency), a 100 MHz scope may experience some signal roll-off. Each scope has a different roll-off value.

    3. From the formula or the power calculator, record the calculated voltage level.
    4. Select: Spectro Prescan
    5. Entry Point: single1
    6. Nucleus: 31
    7. R1: 13
    8. R2: 30
    9. AX : Default
    10. Select Scan TR.
    11. Set the TG to zero to start. Look at the oscilloscope. Verify its operation and its proper connection to the AMT amplifier output.
      Note:

      Verify that the Bandwidth Limit button is not selected on the oscilloscope. If the button is selected, the measured signal will be dramatically reduced.

    12. Gradually increase the TG towards maximum value (200), while watching the oscilloscope.
    13. At a TG of 200, the calculated voltage level should equal the actual voltage measurement on the scope. If it does not, adjust the DRSM broadband gain potentiometer up or down until the actual voltage measured is equal to the calculated voltage level.
      Note:

      If you cannot achieve the calculated voltage level value, troubleshoot problems with the DRSM, RF drive/excessive transmit path attenuation.

    14. Decrease TG to zero.
    15. Select Done.
    16. When the actual voltage measured is set to the calculated voltage level, the calibration process is complete.
    17. Troubleshooting notes:

      1. If you cannot adjust the BB gain pot enough to match the calculated voltage level, you may have excessive losses, a bad DRSM, or a bad exciter.

      2. Check cabling of DRSM and AMT amplifier.

      3. Check to make sure all cable connectors are tight.

      4. If you suspect excessive losses, restart this procedure at Step 6 (dummy load and cables calibration).

      5. Check exciter output.

Re-enabling Power Monitor

About this task

This section must be done to return the power monitor to the proper configuration. This must be performed before patient scanning.

Procedure

  1. Open the rear door of the accessories cabinet.
  2. Reattach the 4 RF sense cables at the rear of the power meters.

System Restoration

Procedure

  1. Remove all test equipment.
  2. Verify the AMT heliax cable is connected to the RF OUTPUT connector and tightened securely.
  3. Reinstall any cabinet covers if removed.
  4. Successfully complete one body scan.
  5. Successfully complete one head scan.

Spectro RF Amplifier Troubleshooting

Procedure

Problem 1: Cannot attain 2.5 kW output during calibration process.
  1. Solution 1: If you have not already performed the oscilloscope roll-off calculation, do so now. Using this roll-off value, recalculate the calculated voltage level.
  2. Solution 2: Using the illustration below, check the exciter (UCERD) output.
    Note:

    The slower the oscilloscope, the more signal roll-off it will experience. This roll-off is unique to every oscilloscope. Some are worse than others. The frequency you are measuring is 57.7 MHz signal. There is no standard roll-off value that you can use. Scope roll-off will also affect a 350 MHz scope, but it may not be as severe. Roll-off will make the UCERD output look smaller than it really is.

  3. Solution 3: Check cable losses between the UCERD and the back of the RF amplifier. Length is a factor. Temporarily replace the cable with a shorter cable, and re-measure at the output.
  4. Solution 4: Replace the cable between the DRSM and the Spectro RF amplifier.
  5. Solution 5: Possible bad DRSM. Consult OLC for further troubleshooting support.
  6. Problem 2: AMT amplifier goes into standby.

    1. If a fault occurs in the AMT (MNS) amplifier, there can be up to a 5 to 6 minute delay for it to self-clear.

    2. Before proceeding with any troubleshooting, wait for at least 6 minutes for this action to occur.
