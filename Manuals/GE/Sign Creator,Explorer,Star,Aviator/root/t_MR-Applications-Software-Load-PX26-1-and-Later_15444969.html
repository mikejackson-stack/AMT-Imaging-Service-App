MR Applications Software Load (PX26.1 and Later)

Procedure

  1. After the system reboots, the Welcome to MRHost screen displays. Log in using these parameters:

    • User ID: root

    • Password: operator

  2. Insert the MR Applications Software DVD into the appropriate DVD drive when prompted. Click OK after the DVD drive LED stops blinking.
    Note:

    Dell T5810 host PCs have two solid-state disks. Raid will not be created for the /export/home1 partition. One disk will be used for the OS while the other will be used for the /export/home1 partition.

  3. From the Select your locale window, select the correct language for the site. Click OK.

    A series of messages and a progress bar report the progress of the installation. When complete, the Guided Install screen appears.

  4. The prompt Do you want to load GI Configuration from DVD? appears.

    • Insert the Save Info media and select Yes after the DVD drive LED stops blinking. Load GI restores Guided Install information. When the process is complete, reinsert the MR applications software DVD and continue to HIPAA/Security (for PX26.1 and later).

      Note:

      If upgrading to a new configuration, check to make sure that the same configuration is applied in Guided Install. See Guided Install Site Configuration Options for more information.

    • (For new systems) Close the drive and select No. Use the information recorded in Guided Install Site Configuration Options to complete this section.

  5. (For PX26.1 and later) Select security level.
    1. Go to Preferences > HIPAA/Security.
    2. Select the security option appropriate for the site per the customer. Refer to Security Levels for more information.
  6. Proceed to the Verification tab. Review the entries on the page to determine if all entries passed verification (the Install Software button will not be active if there are any failures). Failed entries result from missing or improperly formatted entries.
    1. Go to the tab with the error and correct it. Click Install to open the Verification tab again.
    2. If all entries pass verification, click Install Software to begin the MR applications load. This process takes 15-20 minutes.
      Note:

      A prompt appears reminding you to configure the NTP server (if present) through the Network Info tab. It also reminds you to verify that the current time and time zone are configured properly on the Set Time/Date tab.

      If both are correct, select Confirm. If not, select Abort and configure the NTP server (if present) and the current time and time zone.

  7. The Service License screen appears, where you install the site’s service license key (created previously). Leave as it is.
    Note:

    The Service License screen is displayed continuously when the user logs on as root.

  8. The Save/Restore screen appears.
  9. Remove the MRApps DVD from the drive. Insert the SaveInfo DVD for reinstallation.
  10. Return to Loading Host System Software (Quick Start) to continue installation.

Finalization

No finalization steps.
