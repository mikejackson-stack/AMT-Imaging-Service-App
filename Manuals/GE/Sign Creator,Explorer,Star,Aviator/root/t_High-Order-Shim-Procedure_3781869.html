High Order Shim Power Supply Communication Functional Check

Procedure

  1. Note:

    Field Map Creation must be done on both Whole and Zoom Modes if your system is using a TRM.

    Verify one end of the RS232 communication cable is connected to COM 1 on the rear panel of the High Order Shim power supply and the other end is connected to the USB to serial converter and cable assembly that interfaces to the USB port on the rear of the host.
  2. Open a C Shell and type: whoamiEnter If you are NOT “sdc” then type: su sdcEnter Password is adw2.0Enter.
    Note:

    You must be “sdc” to correctly execute the following commands.

  3. Type the following command and verify the screen shows the same output as shown below:

    setzero Enter

    zy = 0

    x2-y2 = 0

    zx = 0

    xy = 0

    z2 = 0

    z3 = 0 (Note: Z3 is used only on GEMS/O 3.0T / 940 systems)

    Note:

    All of the shim output channels should be shown set to 0. If this does not occur then refer to the troubleshooting TBD section to identify the problem and correct it prior to doing the next step.

  4. Enter Guided Install and confirm that Enable HO Shim pull down under System Configure is set to Yes.

FIELD MAP CREATION

About this task

It is recommended to generate the 48 cm FOV map first then follow with the 28 cm FOV map second when performing both maps in the same session.

Procedure

  1. Notice
    After loading, landmarking and Advance To Scan, the Phantom must be allowed to settle for 15 minutes prior to scanning.
    At the operator workspace, select the Service Desktop and prepare the system by performing a TPS Reset.
  2. Load and landmark a phantom.
    1. For the 48 cm FOV Field Map: Setup the Inner Sphere of the LVShim Phantom on the patient cradle. Figure 1.
    2. For the 28 cm FOV Field Map: Install the Head Coil and setup the Body SPT Sphere inside the Head Coil. Figure 3
    3. For the 28 cm FOV Field Map: Place the body SPT sphere on a pad and place the whole assembly in the location where the head coil would normally be located. See Figure 2
  3. Landmark on the center of the sphere using the Alignment Lights.
  4. At the keypad on the magnet enclosure, press LANDMARK, then MOVE TO SCAN.
    Note:

    Phantoms should be allowed to settle for 15 minutes after being landmarked and advanced to scan before proceeding with this procedure.

  5. Setup and Run Localizer Scan. Refer toTable 5 for Localizer Scan Protocol.
    Table 5. Localizer Scan Protocols

Topic ID: id_SL1523946-35334

Running The Makereference Script

Procedure

  1. From the Common Service Desktop, start HO Shim Reference Map as shown in .
    Note:

    On earlier software revisions Ho Shim will not be part of Common Service Desktop. If the link is not found in Common Service Desktop, the tool must be started by opening up a CShell and typing : cd /usr/g/binEnter. Then start the tool by typing: makereferenceEnter.

  2. Note:

    The required options are:

    • FOV 28. Preferred method is option 4. If the 28cm phantom does not fit in the Head coil, perform option 1.

    • FOV 48. Perform option 2

    • FOV 24. Perform option 3

    • Optional: If 8-Channel HR Brain coil is available, perform option 5.

    Select Option:

    1. Optional Method for FOV 28:FOV 28 reference map using body coil - 28 cm phantom (w/o loader) with body coil

    2. Body coil FOV 48 or 44 reference map - LVShim phantom(w/o shell) with body coil

    3. FOV 24 reference map using body coil - 28 cm phantom (w/o loader) with body coil

    4. Preferred Method for FOV 28:Standard Head coil FOV 28 reference map using head coil - 28 cm phantom (w/o loader) with head coil

    5. OPTIONAL: 8-channel HR brain coil reference map using 8channelHR brain coil. - 17 cm phantom (w/o loader) with 8HRBRAIN coil

  3. The reference map script will automatically check to ensure the config file states that the system has HO Shim. If the config file does not have HO Sim enabled, and error message will appear. If the error message appears, run Guided install to enable HO Shim.
  4. The script will ask to confirm the previous entries match the phantom setup. If the system is setup correctly, press Enter.
  5. During the running of the makereference script, several graphs will eventually pop up. When a dialogue box appears asking if the graphs should be closed, Click Yes.

    • The process for creating one reference map will take roughly 2 hours.

    • When the reference map is created you will receive a message stating, The High order shim reference Maps have now been successfully created.

  6. Rerun the procedure and create a 28 cm FOV Field Map, FIELD MAP CREATION.
  7. If the site has an 8 Channel HR Brain coil, the rerun following direction for creating a 24 cm FOV field Map, FIELD MAP CREATION.
Topic ID: id_14966171

Finalization

Procedure

  1. If there are any perceived issues with the supply, refer toHigh Order Shim Functional Checks .
  2. Perform saveInfo to save calibration files.
  3. If completed, put away all phantoms and tools.
  4. Do a check scan to insure the scanner is ready for patient scanning.
