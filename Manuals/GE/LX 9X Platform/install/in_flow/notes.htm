Installation Flowchart Notes

 

NOTE 1: Standard correlated Noise Check not required if proprietary SPT Full Test Mode procedure performed earlier during installation. (However, Multi-Coil and Fast Receiver Option correlated Noise Checks in procedure are still required.)

NOTE 2: If Troubleshooting necesary.

NOTE 3: A "SaveInfo" should be done before SPT is run. With the EPI Option, it is necessary to "SaveInfo" again so that any data collected for calibration will not be lost if a problem occurs.

NOTE 4: Values of LVShim are dependent upon Eddy Current Compensation.

NOTE 5: Values of Eddy Current Compensation are independent of Magnet Shim.

NOTE 6: Overnight Diagnostics may be run at the end of any day to detect possible errors.
