To use any of these links, you must have Office 97 Word or Office 97 Viewer loaded. The links here go to Microsoft Word 97 format documents. When using Internet Explorer, clicking any of the links will open the document in the browser. Fields in the forms are electronically updateable. Tab to the field to be updated and type in it. When done, go to File on the menu bar and select <Save As>. Chose a name and location to save it. If you just wish to save the document to disk, move your cursor over the link, press the right mouse button and select <Save Target As>, then select where on your system to save the file.

If your site log is Rev 0, update to Rev 1 by downloading this Update.pdf file. Place your cursor over "update.pdf" link, press the right mouse button, select <Save Target As>, then select where on your system to save the file. After the download (33 KB), print the pdf file and follow the instructions on the first page of the file.
