4  Procedure

  1. Locate and insert the Linux Operating System disk (current revision) into the DVD drive on the PC.

  1. Reboot the host computer.

NOTICE
The proper OS load command MUST be entered for foreign keyboards and for the mouse to be detected.
 
 

  1. At the boot prompt, type one of the following commands based on your keyboard type:

    • English keyboard: GEHC-MR<Enter>(GEHC dash MR with no spaces).
    • French keyboard: GEHC-?R<Enter> (GRHC dash question mark R).
    • Portuguese keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).
    • Italian keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).
    • Spanish keyboard: GEHC’MR<Enter> (GEHC single quote MR, no spaces).
    • German keyboard: GEHCßMR<Enter> (GEHC Beta symbol MR, no spaces).
    • Swedish keyboard: GEHC+MR<Enter> (GEHC plus sign MR, no spaces).

    The OS load will take about 15 minutes to complete. After about 90 seconds, the message (shown in Illustration 1) displays indicating the OS software load files are being copied.

    Illustration 1:  Copying Files

    After a few minutes, a message (shown in Illustration 2) displays indicating the OS software load has begun.

    Illustration 2:  Starting Installation

    After a few minutes, a terminal window displays with the message similar to the one shown in Illustration 3 indicating the Linux OS software load is now complete.

    Illustration 3:  OS Software Load Completed

  1. The OS disk automatically ejects once the installation is complete. Remove the disk from the drive tray.

  1. The Linux OS software load is now complete, proceed to MR Apps Load.
