Monitor Gamma Value Reset

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. In the C-Shell, type su<Enter> to log in as root; enter the root password (default is operator).

  1. B/W Monitor:

    1. Type jot /usr/g/grayPix/grayPix.cfg<Enter> to edit the grayPix.cfg file.

    1. Modify the numerical value for “gamma” to 0.9

      (Step Details)

    1. Type jot /usr/g/colorPix/colorPix.cfg<Enter> to edit the colorPix.cfg file.

    1. Modify the numerical value for “gamma” to 1.1

      (Step Details)

    1. Type jot /usr/g/colorPix/colorPix.cfg<Enter> to edit the colorPix.cfg file.

    1. Modify the numerical value for “gamma” to 1.05 (NEC 2010) or 1.0 (EIZO L660)

  1. In the jot window, select [File] -> [Save], then [File] -> [Exit] to save the changes. This modifies the gamma value so whenever the system reboots, the new value is not lost.

  1. In the C-Shell, enter one of the following:

    (Step Details)

  1. Return to Host Reconfiguration or Continue to Loading Service Software.
