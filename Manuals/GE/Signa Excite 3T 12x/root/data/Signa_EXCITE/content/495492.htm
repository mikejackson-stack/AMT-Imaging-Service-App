Software Option Installation with eLicense Generated Keys

1  Overview

This procedure describes how to generate and install software options on the Signa scanners running 11.x software or greater on Core products and OpenMR4 or greater software on Open products using eLicense. eLicense allows the field to generate license keys for MR scanners and removes the need to send out physical media for all options on the order. The first step in creating option keys is to go to the eLicense website and register the scanner. To access the eLicense website, you must have a computer with connectivity, as well as a single sign-on account. The eLicense website can be accessed at http://elicense.gehealthcare.com.

The MR system must be tied to the Global Order Number (GON) through the Host ID and System ID of the scanner. Once the site information is entered, the keys can be generated and distributed by: e-mail, downloading, saving to an eFloppy or eCD or printing. This file can then be installed on the system through InSite download, eFloppy, eCD, or manual entry.

The illustration below shows the eLicense process flow. For additional information on how to generate and obtain these keys from the eLicense server, refer to the eLicense User Guide under the HELP tab of the eLicense website.

2.1  Create Licenses

This feature creates option keys for a new or existing system based on an order. To create new licenses, you must have order number(s) that list the options ordered, as well as the Host ID and System ID of the system.

2.1.1  Obtaining the System’s Host ID

  1. Select the [Service Tools Desktop].

  2. Select [Guided Install] from the Service Desktop Manager and press [Start…] to open Guided Install.

  3. When a command window displays the message: Type Root Password, type the system’s root password operator (system default), and press <Enter>.

    NOTE:If the customer changed the root password, obtain the correct root password from the customer.

  4. Once the Guided Install window opens, select the Option Keys tab. The Host ID is in the Install Temporary Service Key section shown below.

    Illustration 2:  Guided Install Window with Host ID

    NOTE:The screen shown above is representative of 12.x and higher systems only.

  5. Another method of obtaining the Host ID is to type sysinfo at a command prompt.

    NOTE:hostid is not a valid command to obtain the Host ID. This causes an error when trying to generate keys, due to the incorrect host ID. The methods listed above must be used to get a valid ID.

2.3  Distributing Licenses

There are four methods for distributing license keys generated at the eLicense server: e-mail, save, print, or download via InSite. These options can be accessed from the eLicense System Information screen shown below. (Refer to Section 2.2 to access this page, or click the [Details] button on the Order Information screen shown in Illustration 16.)

2.3.1  Downloading Licenses

One method of installing option keys is a direct download to a site with connectivity that has completed an InSite checkout. The download is processed from the eLicense website, NOT from the scanner itself.

NOTE:The preferred method of installing option keys is to burn to a CD-ROM. (See Section 2.2.) A download may not install all option keys because dependent keys are not on the system.

  1. After generating the option keys for the system, go to the eLicense System Information screen by clicking [Details] next to the Host ID.

  2. Click on the download link to activate the desired option as shown below. If a link is not available, a modem or broadband connectivity was not established. Try one of the other installation options.

    Illustration 18:  eLicense System Information Screen

  3. Wait for the request to be processed. (A status page provides information on the downloading process.)

  4. Repeat the previous two steps for all options that must be activated on the scanner.

2.3.2  E-mailing Licenses

The license file can be e-mailed to any e-mail address. Then, save this file to a floppy disk or CD, print it, or send it via FTP to the target system following the steps in Section 3.

  1. From the System Information screen, select [Email Licenses].

  2. The Email License Keys window displays, as shown below.

    Illustration 19:  Email License Keys Pop-Up

  3. Additional e-mail can be added to this message.

    1. If the recipient is a GE employee, enter their first and last name, and then click [Search]. Select the name you want from the list.

    2. If the e-mail address is an external address, type it in the Address field, and click [Add].

  4. To remove unwanted addresses, click [Delete].

  5. When all recipients are added, click [Continue].

  6. A verification window displays. Click [Close Window] in the upper right corner.

2.3.3  Saving Licenses to a Disk

You can save the license file to a floppy disk for installation via Guided Install on the scanner. The file can also be saved to the hard drive, and later transferred to a disk, printed, or sent via FTP to the scanner.

  1. From the System Information screen, click [Save Licenses].

  2. On the File Download screen, select [Save this file to disk] and click [OK]. (Shown below.)

    Illustration 20:  File Download Screen

  3. At the Save As screen you can select the destination of the license file. (See Illustration 21.)

    1. If saving to a disk, insert a disk into the computer’s drive and select the drive from the menu.

    2. If saving to the hard drive, select the folder to save the file to.

  4. The filename must be license.sh. The software looks for this exact name.

    NOTE:Windows will try to change the filename to license.txt. You must ensure that the file name is license.sh or installation will fail on the system.

  5. In the Save as Type field, select [All Files].

  6. Click [Save] when finished.

    Illustration 21:  Save As Menu

  7. After the file is saved, a Download Complete window displays. Click [Close].

3  Option Installation

There are five methods for installing eLicense option keys on the system. The details of each method are given in the following sections.

NOTE:The preferred method of installing option keys is to burn to a CD-ROM. (See Section 2.3.3.) Download may not install all option keys because dependent keys are not on the system.

NOTICE
When installing options on a system, make sure the option matches the upgrade being performed. All other conflicting option keys should be removed. Failure to remove them can result in a de-rated system configuration.

EXAMPLE 1: System options for HiSpeed and EchoSpeed are both installed. The result is the system will perform as a HiSpeed, NOT as an EchoSpeed. TO RESOLVE – The HiSpeed option must be removed to allow the system to configure as an EchoSpeed.

EXAMPLE 2: System options for 8-Channel and 16-Channels are both installed. The 8-Channel option must be removed to allow the system to configure as a 16-Channel.

 
 

3.1  eLicense Floppy

NOTE:On new systems the option floppy is no longer a supported feature. Verify the host PC has a floppy drive prior to creating an eLicense Floppy.

All of the eLicense option keys can be saved onto one floppy disk. After creating this floppy disk, follow these instructions to load them onto the system.

NOTE:The option key file must end with a .sh suffix. If the file was saved as anything other than license.sh, the file will not be recognized when loaded onto the scanner. Rename the file to license.sh.

  1. Insert the floppy disk into the host computer floppy drive.

  2. Select the [Service Tools Desktop].

  3. Select [Guided Install] from the Service Desktop Manager and press [Start . . .] to open Guided Install.

  4. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press <Enter>. If the customer has changed the root password, you need to obtain the correct password from the customer.

  5. Once the Guided Install window opens, select the Option Keys tab. (See Illustration 25.)

  6. Select the eLicense Floppy check box on the Install Option Key portion of the window, and then select [Install].

    NOTE:Select the Floppy check box when using an option floppy sent with the system and not generated through eLicense. The eLicense floppy will NOT work when the floppy check box is selected. Please use the eLicense Floppy selection for keys generated with eLicense, and Floppy for factory generated keys.

    Illustration 25:  Guided Install Window

  7. The option key file will begin loading. Load times per option key are very short. Typically less than one minute. When the keys are finished loading, a pop-up displays (shown below), listing all the installed options. Scantools and EchoPlus options are shown in the Illustration.

    Illustration 26:  eLicense Floppy Key Installation Complete Message

  8. Verify that the option list in the Guided Install GUI is updated with the options just loaded, if they were previously “Not Installed” or of type “FlexTrial”.

    NOTICE
    When installing options on a system, make sure the option matches the upgrade being performed. All other conflicting option keys should be removed. Failure to remove them can result in a de-rated system configuration.

    EXAMPLE 1: System options for HiSpeed and EchoSpeed are both installed. The result is the system will perform as a HiSpeed, NOT as an EchoSpeed. TO RESOLVE – The HiSpeed option must be removed to allow the system to configure as an EchoSpeed.

    EXAMPLE 2: System options for 8-Channel and 16-Channels are both installed. The 8-Channel option must be removed to allow the system to configure as a 16-Channel.

     
     

  9. Select [Quit] from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

3.2  eLicense CD-ROM

All of the eLicense option keys can also be saved onto one CD-ROM. This is the preferred method for installing option keys. Once you create the CD, the options can be loaded onto the system, described in Section 2.1.1.

3.2.1  Making the eLicense CD-ROM

Once the option key file is downloaded from the eLicense site to the hard drive of a computer, it can be burned onto a CD. The MR system requires that the disc be ISO-compliant. This format type cannot be burned with Windows XP's built-in disc burning. To burn an ISO-compliant disc, you must use a program such as Sonic RecordNow, which burns ISO-compliant discs by default.

  1. Start Sonic RecordNow.

    NOTE:To obtain a licensed copy of Sonic go to Software Store and download the Sonic Record Now 7.exe file or call GE Healthcare's Help Desk.

  2. From Sonic's homepage, select the Data Projects tab, and then click [Data Disc]. (Shown below.)

    Illustration 27:  Creating A Data Disc

  3. Click [Add Files and Folders] (shown below), and then browse your PC to add the license.sh to the Data Disc list.

    Illustration 28:  Adding Files

  4. Put a blank CD in the computer's CD-ROM drive and click [Burn].

3.2.2  Loading Options from eCD

After creating this CD-ROM, follow these instructions to load the keys onto the system.

  1. Insert the CD-ROM into the host computer CD drive.

  2. Select the Service Tools Desktop.

  3. Select [Guided Install] from the Service Desktop Manager and press [Start…] to open Guided Install.

  4. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press <Enter>. If the customer has changed the root password, you need to obtain the correct password from the customer.

  5. Once the Guided Install window opens, select the Option Keys tab.

  6. Select the eLicense CD check box on the Install Option Key portion of the window, and then select [Install].

    Illustration 29:  Guided Install Window

  7. When the keys are finished loading, a pop-up displays the list of the installed options.

  8. Verify the option list in the Guided Install GUI is updated with the options just loaded.

  9. Select [Quit] from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

3.3  Option Key Auto Download

If the auto download procedure is performed, the keys will be on the scanner waiting for a reboot.

  1. Reboot the MR scanner after all option keys have been downloaded from the eLicense server.

  2. Verify that a pop-up displays the message New option keys have been installed after the Please do not interact with the system until this message disappears… window disappears.

    Illustration 30:  Boot Up Pop-Up Message After Installing New Options

  3. Open Guided Install, and verify the downloaded option keys are installed as permanent keys on the Option Keys tab.

  4. Complete a Save Info to retain all newly installed options on an Info MOD.

3.4  FTP Option Keys to Scanner

If an inSite checkout has not been completed on the scanner, but the system is connected to the hospital network, the option keys can be sent to the scanner via FTP. The option key file must be saved to the computer hard drive before continuing.

  1. Obtain the scanner IP address and connect to the system.

  2. Send the option key file from the desktop to the scanner via FTP.

  3. Move the file to the temp directory by typing mv license.sh /usr/tmp.

  4. Rename the file by typing mv license.sh flexkeys_install.

  5. Reboot the system.

  6. Verify that a pop-up displays the message New option keys have been installed after the Please do not interact with the system until this message disappears… window disappears.

  7. Open Guided Install, and verify that the option keys are installed as permanent keys on the Option Keys tab.

  8. Complete a Save Info to retain all newly installed options on an Info MOD.

3.5  Manual Option Key Entry

If all other methods of option key installation are unavailable, you can enter the keys manually. A printed copy of the keys is needed to transcribe the strings.

  1. Select the Service Tools Desktop.

  2. Select [Install…] from the Service Desktop Manager to open Guided Install.

  3. A command window displays Type Root Password. Type the system’s root password (operator is the Signa default root password) and press <Enter>. If the customer has changed the root password, you need to obtain the correct password from the customer.

  4. After the Guided Install window opens, select the Option Keys tab.

  5. Select the Manual check box on the Install Option Key portion of the window, enter the 24-character license key string into the text box, and select [Install]. This field is case-sensitive.

    Illustration 31:  Guided Install Window

  6. The option key will load immediately.

  7. Verify the option list in the Guided Install GUI is updated with the option just loaded.

  8. Repeat steps 5-7 for all the option keys that you are installing.

  9. Select [Quit] from the File main menu bar to exit the Guided Install tool.

  10. Reboot the computer, and verify that all options are available.

  11. Complete a Save Info to retain all newly installed options on an Info MOD.

5  Glossary

Bloodsupp 

Blood Suppression

Cine 

Images usually of moving anatomy scanned and arrange for playback rapidly in movie format.

ConnectPro (HIS/RIS) 

Provides DICOM modality work list connectivity to hospital or radiology information system.

DW EPI 

Diffusion Weighted Echo Planer Imaging

eOM 

Electronic Order Management, the Oracle order management system.

Fast cine 

Fast gated multi-phase images of the heart that show the heart as it contracts and expands during cardiac cycle in a movie format.

FTP 

Short for File Transfer Protocol, the protocol used to exchange files between computer systems.

IVI 

Interactive Vascular Imaging.

iDRIVE Pro 

Interactive imaging uses a fast GRE pulse sequence and a new user interface to acquire continuous 2D images at a high frame rate and provide on-image navigation. Not available on systems with a single i860 AP.

Multi-Nuclear Spectroscopy 

Provides access to additional spectroscopy PSD that may be used in proton mode.

MS/MA 

Multi-Slice/Multi-Angle Oblique

Sgdperf 

SGD enhancements, which increase, slew rates and duty cycles for higher resolution thin slice imaging.

SmartPrep 

Automated triggering for contrast enhanced MRA.

SmartPrep2000 

Provides SmartPrep automated table motion.

Spectroscopy/PROBE 

Single voxel proton spectroscopy with PROBE-S and PROBE-P.

Probe2000 Upgrade 

Multi voxel proton spectroscopy (PROBE - SI).

SPECIAL 

Spectral / Spatial Fat Suppression. Chemical saturation using an inversion pulse (180º pulse). This key will always suppress just fat and cannot be changed to suppress water.

SSFSE 

Single Shot Fast Spin Echo

Tagging 

The placement of "tags" in an MR image is used to assess myocardial wall functions visually.
