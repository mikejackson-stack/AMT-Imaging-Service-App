CoilConfig.cfg Changes with Driver Module

The CoilConfig.cfg file is located in the /w/config directory.

1  Parameters That Do Not Change Between Arrays of Same Coil

A single array (for example, the CTL array with CTLTOP, CTLMID, CS12, etc.) can have multiple config files associated with it, but the following three parameters should remain unchanged when defining the array, no matter which subset of coils within the array you want to receive from.

  • · mcVoltConfig

  • · mcOpenCktConfig0 - mcOpenCktConfig3

  • · mcShortCktConfig0 - mcShortCktConfig3

NOTE:The parameter within the driver module is actually 32 bits long, but only eight bits are used now because that is the limit of our coil interface. MGD is currently only compatible with arrays having eight or fewer channels.

1.1  mcVoltConfig0 and mcVoltConfig1

Each coil in an array must be configured for a voltage. Based on this information, the drivers are set up properly with a 3-, 5-, or 7-volt output. See 1. The default setting if no information is given (e.g., during a non-phased array scan) is 5 volts.

1.2  mcOpenCktConfig0 - mcOpenCktConfig3

This information is used as a set of four bits for each channel to determine the open circuit current threshold for the coil array. Each channel can be set independently.

For example:

  • mcOpenCktConfig0=126

  • mcOpenCktConfig1 = 0

  • mcOpenCktConfig2 = 126

  • mcOpenCktConfig3 = 0

In summary, all the parameters described in Section 1-1 tell the Driver Module:

  • · Which driver channels should have coils attached

  • · What the positive output voltage should be for those channels with coils attached

  • · What the open circuit detection level should be for those channels that have coils attached

  • · What the short circuit detection level should be for those channels that have coils attached

2  Array-Specific Parameters

The mcBiasEnable and mcChannelSelect parameters define how the array is to be used for the particular scan. With the new capability of eight possible receivers, either the entire array can be used (as in the eight-channel brain coil) or a subset of the array can be used (as in the CTL array).

2.1  mcBiasEnable

This information in this parameter is used to configure which driver channels within the driver module are selected to toggle between a positive and negative output using the unblank control signal.

0 = Not Selected

1 = Selected

This parameter must be a “subset” of the mcVoltConfig parameter. If a channel is selected that does not have voltage configuration associated with it, an error will occur and scanning will not be allowed.

For example:

2.2  mcChannelSelect

This information is only used to configure the 8 x 8 Cross-Point Switch. The Driver Module gets the information via the CAN link and decodes it for the Cross-Point Switch before it is sent through a stream of bits to the switch. This parameter is currently only 8 bits long. The Cross-Point Switch uses this information to configure which coil input channels are routed to receivers. After a download has been completed a representation of this pattern can be seen visually on the 8 LEDs located on the input side (side where cabling from LPCA connects) of the Cross-Point Switch in the rear pedestal.

0 = Not Selected

1 = Selected
