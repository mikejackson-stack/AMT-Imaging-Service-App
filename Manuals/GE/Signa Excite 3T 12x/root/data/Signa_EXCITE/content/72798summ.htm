Determining the Software Revision for Linux

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Using the Common Service Desktop

  1. From the Service page, start the Service Browser.

  1. Verify that the Home tab is selected.

  1. For Release and software revision information, see Illustration 1.

    (Step Details)

1.2   Using a C-Shell

  1. If you are not already on the Service Desktop, click on the [Service] icon. See Illustration 2.

    (Step Details)

  1. From the Service Desktop Manager, click on [C-Shell] to open an xterm.

  1. Locate the cursor in the window.

  1. To see the software revisions used on your system, at the prompt, type <sw_config_status> and press <Enter>. See Illustration 3 to view what is displayed on the Terminal when using this command.

    (Step Details)
