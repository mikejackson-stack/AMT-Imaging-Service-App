Fiber Optic Repeater Loopback Test

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Set loopback jumper in the Fiber Optic Repeater Board (PP1A17A1) located on the equipment room side of Pen Panel, to Position "B" (Loopback). See Illustration 1.

    (Step Details)

  1. To start the Repeater Board Loop back check, on the Service Browser Diagnostics Tab, click the Fiber Repeater Diagnostics link. Run both tests. See Illustration 2.

    (Step Details)

2  Finalization

  1. Set loopback jumper in the Fiber Optic Repeater Board back to position “A”.

  1. Do a test scan before customer turn over.
