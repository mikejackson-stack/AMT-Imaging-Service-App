NOTE:if you push the button on the front of the CDROM Reader and it does not open, it is because you did not properly unmount the CDROM from the File System.

  1. Re-open a C-shell

  2. login as root, Password: operator<Enter>

  3. Type: umount /CDROM<Enter>

  4. Exit the C-Shell.

  5. Eject the CDROM with the button.
