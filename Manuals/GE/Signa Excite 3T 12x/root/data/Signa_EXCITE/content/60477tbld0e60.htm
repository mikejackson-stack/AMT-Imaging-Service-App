Table 1:  User Buttons and Descriptions

Select buttonAdvances LED bar to appropriate controller function.
Gauge Select buttonToggles display between Gauge 1 and Gauge 2 inputs. Note that the system will only use Gauge 1.
Raise/Lower buttonsUsed to raise or lower setpoint limits, atmosphere setting and zero calibration adjustment. The new style Vacuum Gauge Controller disables this button. Note that we will not use zero calibration adjustment for this system.
