Setting System Time and Date

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
12 mins

2  Overview

This procedure explains the steps necessary to set the date and time of the system host.

3  Procedure

  1. Set the time and date.

    The Time/Date tab is the only tab that the Configure button will never be highlighted to set options. There are separate buttons for configuring this tab (see Illustration 1). If you need to re-configure the Host time and/or date at any time, do the following:

    Illustration 1:  SET TIME/DATE MENU

  1. Select the Time Zone your system is located in, then push the [Set Time Zone] button.

  1. Select the date and local time, then push the [Set Time/Date] button.

4  Finalization

  1. Insure the Date and Time is correct for the system.

  1. Click here to return to the main Load From Cold Procedure
