2  Procedure

2.1   Patch Load Procedure Overview

  1. GO into Guided Install menu from Common Service Desktop (CSD) on the Service desktop. Click on Configure then Guided

  1. Click on [Patches] Tab. See Illustration 1.

    (Step Details)

  1. From this GUI we can perform the following tasks:

    1. Determine patches that have been loaded onto the system disk by selecting [Installed Patches] option

    1. Determine patches that are on the CD-ROM by selecting [CD-ROM] option.

    1. Determine patches that have been downloaded to the /usr/g/insite/data via InSite by selecting [Repository] option.

    1. Help files can be viewed if available for patches on the system, CD-ROM, or in the /usr/g/insite/data directory by selecting the [Patch Information]

2.2   Installing A Patch

  1. There are 2 options for loading patches, load from Repository or load from CDROM.

    1. To load a patch from Repository (located in /usr/g/insite/data), select [Repository]. The list of applicable patches that have been downloaded to the site via InSite will appear on the GUI.

    1. To load a patch from CD-ROM, insert the Patch CD into the drive on the Linux PC. Select [CD-ROM]. The list of applicable patches that are on the CD will appear on the GUI.

  1. Click on the applicable patch that you want to load. The patch should be highlighted. See Illustration 2

    (Step Details)

  1. To verify that the patch properly loaded, click in Installed patches. The patch, if properly loaded will now appear. Also look at the Status section of the Guided Install GUI. A message indicating Patch Load done indicates successful load.

  1. The Patch will verify proper software revision and conflict information before loading. If the software revision of the patch does not match the Applications revision, the following message will be displayed. The patch cannot be loaded.

    (Step Details)

  1. If there are conflicts between patches on the system, and patches to be loaded, the following message will be displayed.

    (Step Details)

2.3   Patch Removal Process

  1. Click on Installed Patches section of GUI

  1. Click on the specific patch that you want to remove. The patch will be highlighted.

  1. Click on [Uninstall]. The patch will then be removed. See Illustration 4.

    (Step Details)

  1. If there is a conflict which prevents a patch from being uninstalled, the following message will appear. The conflict must be resolved by possibly removing another patch.

    (Step Details)

3  Finalization

  1. Do a “Good by” scan to insure proper scanner operation.

  1. Cleanup any material that was used during the Patch operations.
