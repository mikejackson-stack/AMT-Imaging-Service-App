2  Overview

With the HDMR 12.0 release, the Film Composer now supports DICOM Color printing. If your paper printer supports DICOM Color, you will want to use DICOM as opposed to Postscript format. The setup for DICOM greyscale and color paper is identical—the printer and scanner will determine if the image is color or grayscale and set elements in the DICOM header appropriately. In the Film Composer setup, you need to select the appropriate media type (paper) and film size. There is no explicit configuration for color versus grayscale.

3.1  Configuring a DICOM printer for Film Composer

  1. Boot Signa to Application level.

  1. From the Browser select Film Composer on the right side on the menu.

  1. Select [Configure] option on the Film Composer GUI. See Illustration 1,

    Illustration 1:  Film Composer GUI

  1. Click [Add].

  1. A new GUI will appear called “Type of Laser Camera”. Click [DICOM.].

  1. A list of possible printers will appear. Select the printer being used. See Illustration 2.

    Illustration 2:  Camera Configuration

3.2  Configuring Postscript Printer for Film Composer

  1. Boot Signa to Application level.

  1. From the Browser select [Film Composer] on the right side on the menu.

  1. Select [Configure] option on the Film Composer GUI. See Illustration 4.

    Illustration 4:  Film Composer

  1. Click [Add] option from the Remote printer configuration GUI. See Illustration 5.

    Illustration 5:  Remote Printer Configuration

  1. Then select Postscript camera to be configured.

  1. Enter the applicable information in the PS printer configuration parameters GUI. See Illustration 6.

    Illustration 6:  Printer Configuration Parameters

  1. Click [OK] to complete the camera configuration.

4  Finalization

  1. After camera configuration, create a test film to ensure the system is working before customer turnover.
