2  Overview

This section should get you familiar with the basic operation of the monitor controls. The intent of this section is to adjust the monitor to a "default" condition to proceed with calibrations. It also will allow you to become familiar with the button panels and the Screen Management setup for this monitor. Refer to the Vendor manual that came with the new LCD for operation of the monitor controls.

3  Procedure

  1. Open the Screen Setup, Refer to the vendor manual that came with the monitor.

  1. If it has an “Auto Adjust” Feature, initiate the Auto Adjust of the Phase/ Vertical and Horizontal Centering. If it does not, Skip to the next step.

    NOTE:Manual Adjusting the position of the image to the center point of the LCD screen in all four directions is rarely needed. Automatic adjustment takes care of this.

  1. Find and set the monitor “Color Temperature” to (9300). Refer to the vendor manual that came with the monitor.

  1. Press the <Exit> Button. These settings will remain in effect even if power is removed, or system software is re-booted. Unless manually changed by the Operator.

  1. The monitor adjustment is complete. The LCD monitor is now ready for integration to Signa.

    NOTE:For further information on the setup screens and button identification refer to the User's Manual that came with the LCD Display.
