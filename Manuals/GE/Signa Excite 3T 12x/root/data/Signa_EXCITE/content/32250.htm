2  Procedure

  1. On the Config File Manager screen, select [MR Config File]. See Illustration 1.

    Illustration 1:  Config File Manager Screen

  1. The SAR Config File screen is displayed. See Illustration 2.

    Illustration 2:  TYPICAL SAR CONFIG FILE SCREEN

  1. Either click in the fields or tab through the fields to enter values. Use the [Delete] key to edit text. The [Backspace] key works from the end of the field instead of from where the cursor is located.

  1. To apply changes to the SAR Config File, exit the Config File Manager. Make sure to click the [Save] button when the Save dialog box appears. Then, shut down Signa and reboot the computer. (Refer to Exiting the Config File Manager.)
