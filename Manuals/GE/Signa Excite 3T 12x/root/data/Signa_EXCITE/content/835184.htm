Login Modes

1  Customer Access – Logging Into Magmon3

All Magmon3 units are pre-configured by the manufacturer in non-Proprietary mode before the units ship to GE. Customers not on a GE Service contract will need access to the unit to be able to perform some configuration tasks in the event of a hardware failure where the Magmon3 would need replacement.

1.1  Magmon3 Non-Proprietary Mode

The unit can perform these basic functions in non-Proprietary mode:

  • Display last sample of He Level (%).

  • Allow the user to initiate He Level Sample to update the displayed information.

  • Display He Vessel Pressure (psi).

  • Perform pressure control for magnets with Recondenser Refrigeration systems.

  • Display alarms when a monitored parameter is out of range.

  • For Signa OpenSpeed products, the Magmon3 will communicate with the MRI System Host PC via a network connection, and provide parameter data needed to support coldhead cycling.

  • Allows the user to access Data Mode for viewing current sensor values.

  • Allows the user to access Fill Mode to increase He Level sampling during the fill operation.

1.2  Preconditions

  1. Laptop directly connected to the Magmon3 using either a network crossover cable or a serial cable.

  2. Laptop communication configured to support either network or serial connection.

  3. Laptop communicating with the Magmon3 unit and the login screen displayed on the laptop's web browser.
