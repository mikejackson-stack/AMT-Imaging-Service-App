3  Procedure

3.1   FIELD MAP CREATION

It is recommended to generate the 48 cm FOV map first then follow with the 28 cm FOV map second when performing both maps in the same session.

NOTICE
After loading, landmarking and Advance To Scan, the Phantom must be allowed to settle for 15 minutes prior to scanning.
 
 

  1. At the operator workspace, select the Service Desktop and prepare the system by performing a [TPS Reset].

  1. Load and landmark a phantom.

    1. For the 48 cm FOV Field Map: Setup the Inner Sphere of the LVShim Phantom on the patient cradle. (see Illustration 1).

    1. For the 28 cm FOV Field Map: Install the Head Coil and setup the Body SPT Sphere inside the Head Coil. (see Illustration 2)

    1. For the 24 cm FOV Field Map: Place the body SPT sphere pads and place the whole assembly in the location where the head coil would normally be located. (see Illustration 4). Position phantom in A/P direction of the mid point of the 8 Channel brain Coil. Do not use the Brain coil to make the reference map. It should only be used as a reference for A/P centering of phantom.

    (Step Details)

  1. Landmark on the center of the sphere using the Alignment Lights.

  1. At the keypad on the magnet enclosure, press <LANDMARK>, then <MOVE TO SCAN>.

    (Step Details)

  1. Setup and Run Localizer Scan. Refer toTable 1 for Localizer Scan Protocol.

    (Step Details)

3.2   Running The Makereference Script

  1. On TwinSpeed Systems, this sections will take 6 hours to complete.

  1. From the Common Service Desktop, start HO Shim Reference Map as shown in .

    (Step Details)

  1. Select Option:

    (Step Details)

NOTE:The required options are:

  • FOV 28. Preferred method is option 4. If the 28cm phantom does not fit in the Head coil, perform option 1.

  • FOV 48. Perform option 2

  • FOV 24. Perform option 3

  • Optional: If 8-Channel HR Brain coil is available, perform option 5.

  1. Select Option:

    (Step Details)

  1. The reference map script will automatically check to ensure the config file states that the system has HO Shim. If the config file does not have HO Sim enabled, and error message will appear. If the error message appears, run Guided install to enable HO Shim.

  1. The script will ask to confirm the previous entries match the phantom setup. If the system is setup correctly, press <Enter>.

  1. During the running of the makereference script, several graphs will eventually pop up. When a dialogue box appears asking if the graphs should be closed, Click [Yes].

    (Step Details)

  1. Rerun the procedure and create a 28 cm FOV Field Map, FIELD MAP CREATION.

  1. If the site has an 8 Channel HR Brain coil, the rerun following direction for creating a 24 cm FOV field Map, FIELD MAP CREATION.

4  Finalization

  1. If there are any perceived issues with the supply, refer toHigh Order Shim Functional Checks .

  1. Perform saveInfo to save calibration files.

  1. If completed, put away all phantoms and tools.

  1. Do a check scan to insure the scanner is ready for patient scanning.
