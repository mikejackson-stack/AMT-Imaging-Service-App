Configuring High Order Shim Communication

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Configuration of HOS Communication

  1. Go to the Service Desktop and start Guided Install. See Illustration 1.

    (Step Details)

  1. Click on the Term Server Tab

  1. Ensure that the MAC address for both term servers has been entered. See Illustration 2. If the second term server address is missing, see Illustration 3 for where to locate this information.

    (Step Details)

NOTICE
The following two steps are CRUCIAL. Do not skip these steps!
 
 

  1. Cycle Power on the HOS Power Supply.

  1. At the console, reboot the entire system.

  1. From the console, ensure that you can communicate with the HOS Term Server by following these steps:

    1. Open a C-Shell.

    1. At the command prompt, type: more /etc/hosts<Enter>.

    1. Look for the IP address associated with xxx-ts2 (where xxx depends on system ID)

    1. At the command prompt type: ping xx.xx.xx.xx (where xx.xx.xx.xx is the IP address of ts2) <Enter>.

    1. After a few seconds , at the keyboard, press and hold the <ctrl> key down and then push the <C> key to cancel the ping. Ensure 0% loss. If there is 100% loss, see “Troubleshooting Term Server Connection”. If there is 0% loss, continue to Step 7.

  1. In the C-Shell, type: readallcurrent<Enter>.

    (Step Details)

1.2   Troubleshooting Term Server Connection

  1. Disconnect the power from the Term Server.

  1. Using a long, thin, non-conductive material (such as half of a toothpick), press and hold the small <Reset> button. This is the small hole on the same side of the Term server as the MAC Address sticker.

  1. While holding the <Reset> button depressed plug in the power connector. CONTINUE TO HOLD RESET BUTTON DEPRESSED after the power is plugged in, watching the Power LED. Wait for a pattern of 1:5:1 to begin blinking. When you see that pattern then the Port server has reset. If this pattern is not seen, repeat the Troubleshooting Term Server Connection of this document.

  1. When the pattern is seen, it will take 1-4 minutes for the device to receive and use its IP address.

  1. Release the <Reset> button.

  1. From the console, ensure that you can communicate with the HOS Term Server by following these steps:

    1. Open a C-Shell.

    1. At the command prompt, type: more /etc/hosts<Enter>.

    1. Look for the IP address associated with xxx-ts2 (where xxx depends on system ID)

    1. At the command prompt type: ping xx.xx.xx.xx (where xx.xx.xx.xx is the IP address of ts2) <Enter>.

    1. After a few seconds , at the keyboard, press and hold the <ctrl> key down and then push the <C> key to cancel the ping. Ensure 0% loss.

1.3   Troubleshooting HOS Communication

If the command readallcurrent returns communication errors such as RS232 errors:

  1. Verify that the connections are correct per Illustration 4:.

    (Step Details)

  1. If all connections are verified to be correct, first cycle power on the HOS Supply

  1. At the console, open a C-shell and type: readallcurrent<Enter>.

  1. If there are still communication errors, reboot the computer.

  1. At the console, open a C-shell and type: readallcurrent<Enter>.

  1. If there are still communication errors, type the following at a C-Shell prompt:

    1. cd /var/spool/locks<Enter>.

    1. rm rf*<Enter>.

    1. readallcurrent<Enter>.
