2  Procedure

  1. Route the 12 Gradient cables and resistive shim cable through the opening in the rear end bell. Install all gaskets that were removed prior to terminating the gradient cables

  1. Slowly move the rear end bell into place.

  1. Use an 8 mm allen wrench to install the 24 M10 bolts that secure the rear end bell to the magnet. Use a star pattern when tightening the bolts. The front enclosure should touch the aluminum ring when finished.

  1. Install the 8 nuts that secure the rear end bell to the RF Coil. See Illustration 1.

    Illustration 1:  REAR END BELL

  1. Install the 32 screws from the Gradient Vacuum seal fixture. See Illustration 2.

    Illustration 2:  GRADIENT VACUUM SEAL FIXTURE

  1. If necessary connect the optional resistive shim cable.

  1. Install the vacuum pump connector at the rear end bell and install the cosmetic cover. See Illustration 3.

    Illustration 3:  REAR END BELL

  1. Re-terminate the gradient cables. Refer to .

  1. Slide the rear pedestal to its proper location in back of the magnet.

  1. Install the Patient Comfort Module.

  1. Route and connect the cable going from the patient lights to the light source. See Illustration 4.

    Illustration 4:  LIGHT SOURCE

  1. Connect the speaker and microphone cables to the intercom board located on rear pedestal. See Illustration 5.

    Illustration 5:  REAR COVERS

  1. Install the bridge. See .

  1. Remove the lock out and tag out.
