Appendix D - Service Software Load

1  Loading Service Software

  1. Go to the install GUI window, and select the [ServiceSW/Picture this/InSite] tab.

  2. Proceed to Section 2, Load Advanced Service Software, or Section 3, Load Restricted Service Software (for sites with GE Service Only).

    (Restricted Service Software is only available for GE use; Advanced Service Software is only available to sites with a valid Advanced Service Package Limited License.)

2  Load Advanced Service Software

To load Advanced Service Software on the system:

  1. Place the Advanced Service CD-ROM 2167558, in the host CD-ROM drive.

  2. Select [Load Advanced Service].

  3. Read the proprietary message window, and respond accordingly.

  4. A message “Advance software load in progress…” will display. The load will take about 5 minutes.

  5. Wait for the message “Advanced Service load done” in the Install GUI status bar (at bottom of window).

  6. Proceed to , Option Keys and Verification of Restored Information.
