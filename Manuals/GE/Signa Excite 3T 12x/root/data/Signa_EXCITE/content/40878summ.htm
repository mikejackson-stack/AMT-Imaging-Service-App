1  Procedure

1.1   Transferring the Gamma Files

Do the following steps to update the monitor configurations and insure compatibility between monitor and camera.

1.2  

Setting the gamma level or loading the correct gamma table improves the window/level abilities of the Signa CRT and LCD flat panel monitors. Proper gamma setup is essential for best Image Quality.

NOTE:Read all the instructions carefully and completely, before attempting to perform gamma setup.

  1. There are TWO methods to get the necessary files. One procedure requires the transfer of files from the latest MR Service Methods CDROMS. CD ROM 2160623 Rev 14. Or Service CD 2250758 Rev 2, and the other procedure requires an internet login to the MR Service Engineering Web Site: http://3.87.118.28/optec3/gamma/gamma.htm. Both procedures have been included to ensure all sites have access to these files. You may also consult the On Line Center in your Pole.

1.3   METHOD 1: Transferring Files from the Service Methods CDROM

NOTE:If you don't have the latest MR Service Methods CDROMS. CD ROM 2160623 Rev 14. Or Service CD 2250758 Rev 2 then you MUST use METHOD 2. (Skip to section 6-2-3 Page 27)

1.4   Mounting the Service CDROM:

  1. Insert your current GEMS Service Documentation CD ROM for this system into the Signa host CDROM drive. The service class of the service CDROM does not matter.

  1. On the Host SGI Computer, Open C-Shell.

  1. Type: cd /usr/g/bin<Enter> (IRIX is case sensitive. Always use case exactly as shown)

  1. Type: su root<Enter>

  1. At password, type: operator<Enter>

  1. Type: mediad <Enter>(Mount CDROM Drive to File System, takes 20-30 seconds)

    (Step Details)

1.5   Transferring the necessary files from the CDROM to the system for Gamma setup:

  1. Type: cp /CDROM/gamma/setgamma /usr/g/bin <Enter>

    (Step Details)

  1. Type : cp /CDROM/gamma/gammaup /usr/g/bin<Enter>

    (Step Details)

  1. Type : cp /CDROM/gamma/rungamma /usr/g/bin<Enter>

    (Step Details)

  1. Type : cp /CDROM/gamma/eizoL660.tar /usr/g/bin<Enter>

    (Step Details)

  1. Type : cp /CDROM/gamma/nec1850x.tar /usr/g/bin<Enter>

    (Step Details)

  1. Type : cp /CDROM/gamma/nec2010x.tar /usr/g/bin<Enter>

    (Step Details)

  1. Type: chmod 555 setgamma<Enter>

    (Step Details)

  1. Type: chmod 555 gammaup<Enter>

    (Step Details)

  1. Type: chmod 555 rungamma<Enter>

    (Step Details)

  1. Type: umount /CDROM<Enter> (Release the CDROM drive)

  1. Type: exit<Enter> (Changes user privileges. "root level" access to "sdc level" access).

  1. Type: exit<Enter> Close the C-Shell.

  1. Remove the CDROM from the CDROM Reader.

    (Step Details)

  1. Proceed to Setting the Gamma Value For Your Monitor Configuration in section 3.7 below.

1.6   METHOD 2: Transfering Files from the Service Engineering Website:

  1. Using your laptop, log into the GE intranet and point your web browser to the following site: http://3.87.118.28/optec3/gamma/gamma.htm

  1. Create a temporary directory on your laptop and Download the zip file (gamma.zip) containing the patch file(s) to your service laptop This file is very small, 42 Kbytes.

  1. Un-zip the gamma.zip file in this temporary directory on your hard drive. You should now be able to see the following files: (See Table 1)

    (Step Details)

  1. Attach your laptop to the Service Ethernet port and prepare to transfer the files directly to the SGI computer.

    (Step Details)

  1. FTP the files in BINARY to directory : /usr/g/bin

  1. On the SGI Computer open a C-Shell

  1. Switch to root owner. ( su root<Enter> ; password: operator<Enter>)

  1. type: cd /usr/g/bin<Enter>

  1. type: chmod 555 gammaup<Enter>

    (Step Details)

  1. type: chmod 555 rungamma<Enter>

  1. type: chmod 555 setgamma<Enter>

1.7   Setting The Gamma Value for your Monitor Configuration

  1. Depending on the monitor your system is using, Select the appropriate section as indicated in Table 2.

    (Step Details)

1.8   SECTION A- B/W CRT Monitors (MDW321) (Barco)

  1. In the C-Shell.

  1. Switch to root owner. ( su root<Enter> ; password: operator <Enter>)

  1. type: cd /usr/g/bin<Enter>

  1. Type setgamma 0.9<Enter> . The system will instantly change to this value.

    (Step Details)

  1. Type: exit<Enter> (exits root)

  1. Type: exit<Enter> (to exit C-Shell)

1.9   SECTION B- Color CRT Monitors (MDW321+)(Barco)

  1. In the C-Shell.

  1. type: cd /usr/g/bin<Enter>

  1. Switch to root owner. ( su root<Enter> ; password: operator <Enter>)

  1. Type setgamma 1.1 <Enter> . The system will instantly change to this value.

    (Step Details)

  1. Type: exit<Enter> (exits root)

  1. Type: exit<Enter> (to exit C-Shell)

1.10   SECTION C- NEC 2000 and NEC2010 LCD Panel 20 inch Monitor

  1. In the C-Shell.

  1. type: cd /usr/g/bin<Enter>

  1. Switch to root owner. ( su root<Enter> ; password: operator<Enter>)

  1. Type setgamma 1.05<Enter> . The system will instantly change to this value.

    (Step Details)

  1. Type: exit<Enter> (exits root)

  1. Type: exit<Enter> (to exit C-Shell)

1.11   SECTION D- NEC 2010X LCD, NEC 1850X and Eizo L660

These monitors do not use an individual Gamma setting. They require a gamma Look-Up Table.

  1. In the C-Shell.

  1. type: cd /usr/g/bin<Enter>

  1. Type: rungamma<Enter> (Menu shown in Table 3.)

    (Step Details)

  1. Determine the LCD monitor type your system is using. The name and model number is usually found on the front face of the monitor.

  1. At the prompt type the number corresponding to your monitor type and if you wish to install or uninstall the gamma tables.

    (Step Details)

  1. Type: exit<Enter> Close the C-Shell.

  1. Re-boot Signa to save and activate the change to software.
