1  Procedure

1.1   Startup

EPT combines the functionality of the current B0 Dither Calibration, Group Delay Calibration and B0 Image Test into a single tool with a simple user interface. The output is suitable for remote support access, trending, and automatic checking of results against acceptance limits. In addition, EPT automatically updates the EPI calibration files when authorized by the user.

  • For TwinSpeed, EPT is run for each GradMode, Whole-Body (WB) and Zoom (ZM).

  • Both GradModes can be selected in a single pass, and both require calibration at least once per installation and during any other routine system tests.

  1. Click on [New Pt], and enter the following:

    (Step Details)

  1. For 1.5T and 3.0T systems with LCC 300 or the short bore magnet, place a 100 mm sphere phantom, an EPI foam phantom holder, and a phantom loader in the head coil as shown in Illustration 1. For 3.0T systems with long bore magnet, place a 100 mm sphere phantom and an EPI foam phantom holder WITHOUT a phantom loader in the head coil as shown in Illustration 2. Landmark on the center of the sphere, but do not advance to scan.

    (Step Details)

  1. Place an EPI foam phantom holder and a second 100 mm sphere on the Grafidy base plate as shown in Illustration 5. Move the table into the bore 1100 mm from landmark. Slide the Grafidy base plate so the center of the 100 mm sphere is at the axial alignment light, and press the [MOVE TO SCAN] button.

    (Step Details)

  1. Start the Echo Planar Test Calibration Tool.

    (Step Details)

  1. The Head Coil being used is preselected as shown in Illustration 6.

    (Step Details)

  1. Click the [Start] button.

  1. The Echo Planar Test window displays as shown inIllustration 7.

    (Step Details)

  1. For calibration, set the [Select All Tests] option to [Yes].

    (Step Details)

  1. There are four option buttons on the screen that must be chosen before starting EPT:

    1. Selecting the [Multi Passes] button and entering an integer in the text box can perform more than one pass of the tests.

    1. One or more of the selected tests can automatically update the config files with new calibration data if the new data is within specifications. Select [Config Update] before starting EPT.

  1. Select a Test Purpose from the pull-down menu.

  1. Two lines of comments can be entered, if desired. If no comments are entered, the text, NO COMMENT will be entered into the results file.

    (Step Details)

CAUTION
Equipment Movement!
The test you are about to initiate will move the cradle.
Please take appropriate precautions to ensure that no one will be in its path.

  1. Select [Start EPT]. Running all the tests takes about one hour and will thoroughly test the EPI performance of your system. This is the recommended mode for baseline, PM, and initial problem-finding. The single test mode is meant to be used while troubleshooting. If possible, run the full set of tests at the end of your troubleshooting to verify system performance. While EPT is running, each test will be displayed in the message window indicating the amount of time the test requires to run.

    (Step Details)

1.2   Image-based Short Cross Term Eddy Current Tool

If the B-zero Image fails during the EPT, quit the EPT and run the Image-based Short Cross Term Eddy Current tool. This tool may reduce EPI ghosting and is designed to specifically work in conjunction with the EPT. If you passed B-zero Image, you should proceed to Test Termination Procedure.

NOTE:Consider running this test even if the B-zero image passed. Based upon past experience, this may improve image quality.

  1. Quit the EPT.

  1. Open the C-shell (click on the [C Shell...] button in the Service Desktop Manager) and type /usr/g/bin/runsct

    (Step Details)

  1. Click [Apply and Scan].

    (Step Details)

  1. If the system determines that correcting the short cross term values may fix the ghosting problem, compensation is applied and the B-zero Image scan starts with the new values. Data collection takes 10-15 minutes and the resulting ghosting level is measured and displayed.

    (Step Details)

  1. If the B-zero Image passes the procedure is complete and the results are displayed. Click [Exit] and re-run the EPT tool (see Illustration 7). When running the tool, go to the Body section of the test options page and click Off next to the B-zero Image (see Illustration 7). This saves time by not rerunning this part of the EPT.

  1. If the B-zero Image results are not within specification, the cross-term compensation is removed. Click [Exit] and troubleshoot the system for other ghosting sources (see Troubleshooting EPI Ghosting Problems).

  1. Once EPI ghosting problems have been brought into specification, rerun the EPT and continue to Step .

1.3   Test Termination Procedure

  1. When the tests are complete, one of four messages shown below displays:

    1. <Your tests completed successfully>, or

    1. <A minor system problem has been detected. This problem is NOT expected to affect image quality>, or

    1. <A serious system problem has been detected. This problem IS expected to impact image quality>, or

    1. <EPT was unable to determine PASS/FAIL status of the tests.>

  1. Select [Quit EPT] , and confirm when a confirmation window displays.

    (Step Details)

2  Finalization

  1. Reset the TPS to bring the system back into a known mode.

  1. Do a test scan to ensure the scanner is working properly before customer turn over.
