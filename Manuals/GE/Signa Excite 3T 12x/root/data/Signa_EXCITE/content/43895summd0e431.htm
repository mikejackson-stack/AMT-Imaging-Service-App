The weight of the empty RRF Chassis (39 lbs. or 15.9 kg) requires that a Lift Tool be used to remove it from the Systems Cabinet.

There are two Lift Tool Kits:

  • Fixed Site Lift Tool Kit (46-317266BOM6)

  • Mobile Lift Tool Kit (46-317266G2)

See Appendix A for a complete list of the contents of each kit.

  1. Attach a grounding wrist strap.

  2. Remove all boards from the RRF Chassis and store them in a static-safe location. See Section 6-2 for removal instructions.

  3. Remove Power Supply Units from the RRF Chassis. See Section 6-3 for removal instructions.

  4. Remove the upper front cover attachment bracket from the Systems Cabinet. See Illustration 10.
