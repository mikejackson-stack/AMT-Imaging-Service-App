Disk Wipe

The Disk Wipe procedure should only be used prior to an Operating System (OS) Load from Cold (LFC) and takes less than 10 minutes. Disk Wipe writes zero data into the Master Boot Record (MBR) and the disk label partition table. It does not erase all disk data, but removes any normal access to it. This prevents further access to existing disk data, and a LFC is required.

1  Overview

The Disk Wipe procedure is done to remove remnant boot or partition information from all disk drives. This will prevent any instances when the OS installer is confused by reused disk drives that contain previous boot and partition information. The typical symptom of OS installer confusion is that the OS load appears to succeed normally, but all subsequent hard disk boot attempts result in a Linux PANIC error because it tries to mount the wrong root partition.

2  Procedure

Follow these steps for a Disk Wipe:

  1. Unplug or turn the power off to any SCSI/USB Tower with a MOD drive.

  2. Boot the GE Healthcare Linux OS DVD until the keyword prompt displays, then type: linux rescue and press <Enter>.

    NOTE:This will boot the DVD into Linux Rescue mode, which is a memory-only version of Linux that provides a root command shell.

  3. Be patient for the Linux Driver load screens to display. Select the desired screen language (default is US-English), tab to OK and press <Enter>. Select the desired keyboard type (default is US), table to OK and press <Enter>. Proceed as follows:

    1. On the Network screen, tab to No and press <Enter>.

    2. On the Rescue screen, tab to Skip and press <Enter>.

  4. When the root command shell prompt displays, proceed as instructed below for each disk drive.

    1. Wipe the first disk drive by entering:

      dd if=/dev/zero of=/dev/sda bs=4k count=100000

    2. Wipe the second disk drive by entering:

      dd if=/dev/zero of=/dev/sdb bs=4k count=100000

    3. Wipe the third disk drive by entering:

      dd if=/dev/zero of=/dev/sdc bs=4k count=100000

  5. Eject the OS Linux DVD, turn the power on or replug the SCSI/USB Tower, and follow the normal product Load from Cold procedure.

  6. Eject the OS Linux DVD, turn the power on or replug the SCSI/USB Tower, and follow the normal product Load from Cold procedure.
