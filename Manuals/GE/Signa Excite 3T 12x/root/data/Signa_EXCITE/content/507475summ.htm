Longitudinal Drive Calibration

(Click Here to Return to Detailed Procedure)

  Safety

CAUTION
Dangerous Magnetic Field!
Possible Personal Injury and/or equipment damage. Tools made of ferrous or magnetic material may become dangerous projectiles and cause equipment damage or bodily injury when used near the magnet.
Use only a nonferrous measurement scale for this procedure.

1  Procedure

1.1   Longitudinal Drive Calibration

Longitudinal Drive Calibration must be performed before the Electrical Isocenter Calibration procedure.

  1. During Load From Cold, the Beginning of Travel (BOT) should be set to 50 and End of Travel (EOT) set to 2568. These are typical values, but the procedure will use whatever values are currently in the config file. Refer to Config File Update if parameter updates are necessary.

  1. Move the cradle to the home position.

  1. Move the cradle approximately 50 to 100 mm into the bore.

  1. Turn on the alignment lights, and press landmark to set the control panel position display to 0 (zero).

  1. Place a piece of tape on the cradle near the point farthest from the magnet and another piece aligned with it on the edge of the table. (See Illustration 2.)

    (Step Details)

  1. Record the scale point as A1 in Table 1. Record the shroud display reading as D1.

    (Step Details)

  1. Fast forward the cradle into the bore until the first piece of tape is located near the end of the table (at least 700 mm from the first point).

    (Step Details)

  1. Place a third piece of tape on the edge of the table aligned with the first piece of tape on the cradle. (Two pieces of tape are now on the table.) The two pieces of tape are spaced apart the same distance that the cradle has moved. (See Illustration 3.)

    (Step Details)

  1. Read the cradle position displayed on the control panel. This is the displayed distance. Record the shroud display reading as D2 in Table 1.

  1. Measure the distance on the table between the second and third pieces of tape. This is the measured distance. Record the scale distance as A2 in Table 1. Move the table away from the magnet if necessary to use a steel rule but DO NOT move the cradle. The display on the gantry should not change, (1 in. = 25.4 mm).

  1. Calculate the actual distance traveled as DA = [(A2 - A1)], and record value in Table 1.

  1. Calculate the shroud distance as DD = [(D2 - D1)], and record value in Table 1. If DD differs from DA by 1 mm or less, no further calibration is needed. If DD differs from DA by more than 1 mm, continue with this procedure.

  1. Calculate the parameter EOT. (See Table 1. (Round off calculated value to nearest mm).

    (Step Details)

  1. Enter this new value in the configuration file. Refer to Config File Update .

1.2   Config File Update

  1. Go to the Service Desktop, start the Service Desktop Browser if not already running, and start the Configuration File Manager.

  1. Go to the Configuration tab.

    (Step Details)

  1. Select Config File Manager.

  1. Click on the link: Click here to start this tool.

  1. Click the [MRconfig] button.

  1. Confirm that the parameter Beginning of Travel (mm) is 50 mm. (See Illustration 4.

    (Step Details)

  1. Change the parameter End of Travel (mm) to the Calculated EOT value in mm.

  1. Save the changes.

  1. Reset TPS.

1.3   Check Calibration

  1. Repeat Longitudinal Drive Calibration.

  1. DD should now equal DA within 1 mm. If it does not, continue Longitudinal Drive Calibration steps, update config file and recheck calibration.
