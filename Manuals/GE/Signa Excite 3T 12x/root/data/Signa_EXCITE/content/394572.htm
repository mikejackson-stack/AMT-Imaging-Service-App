2  Overview

Follow this process to install the 3.0T HD Shoulder Array by GE/USAI (M3334TR).

Last Updated03/18/2005

3  Procedure

  1. Go to the Service Desktop and start the Service Desktop Browser if it's not already running.

  1. Follow the steps shown in Illustration 1.

    Illustration 1:  Starting the Config. File Manager

  1. Click the [CoilConfig]button on the left. The following screen will appear, see Illustration 2.

    Illustration 2:  CoilConfig Screen

  1. Add the following coil name(s) to the list of site coils.

    • HD Shoulder

    • HD ShoulderServ

  1. Restart Signa.

  1. Perform theSurface Coils SNR Test for this coil.

  1. Add the following traced part number(s) to product locator: 2414362.

No finalization steps.
