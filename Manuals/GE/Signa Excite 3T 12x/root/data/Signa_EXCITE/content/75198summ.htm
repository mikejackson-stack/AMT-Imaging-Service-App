Bandpass Asymmetry Correction Tool (BAT)

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

This procedure must be performed after installation of a DFR2 Board module.

-

-

DRF2 boards are good for 8 channels and 16 channel systems.

-

-

2  Procedure

  1. Start the BAT tool:

    1. On the Service Desktop, open the Service Browser if it is not already running.

    1. Select the Calibration Tab.

    1. Start the BAT tool as shown in Illustration 1.

    (Step Details)

  1. The window shown inIllustration 2 will open. Type 1<Enter> to start the calibration.

    (Step Details)

  1. Calibration takes about 3 minutes.

    (Step Details)

  1. Process Existing BAT Data Only.

    (Step Details)

  1. Re-display BACC Correction Plots.

    (Step Details)

3  Finalization

  1. The scanner should automatically perform a [Reset TPS] upon exiting the tool. If the scanner does not perform a automatic [Reset TPS], then perform a manual reset before continuing. The tool itself will not shut down until the reset is complete.

  1. Do a test scan to ensure proper system operation before turn over to the customer.
