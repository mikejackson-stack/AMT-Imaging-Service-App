If all terms come within spec and the optimal calibration is shown on the last iteration, click the Exit button. All the performance data and cal values will be saved to a log in the /usr/g/bin/z2ecc/log directory. The calibration is complete!

If all terms are not in spec, refer to Running Z2 Eddy Current Calibration Tool Manual Mode to run the tool in manual mode.

If the last iteration does not show the best fit possible, refer to Selecting Earlier Iteration Results to select an earlier iteration. The best-fit possible has the smallest number.
