Configuring DICOM Printer

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Select Browser from scan Icon.

  1. Click [Film Composer] on the browser option page. See Illustration 1.

    (Step Details)

  1. Click [Configure] from the Film Composer GUI. See Illustration 2.

    (Step Details)

  1. Click [Add] from the Remote Printers List GUI. See Illustration 3.

    (Step Details)

  1. Select DICOM or PostScript Printer Type.

  1. Select proper camera configuration from Camera Configuration Dialog GUI, then click on [Select].

  1. Fill out the Printer Configuration Parameters page. See Illustration 4.

    (Step Details)

  1. Click [OK], then [Update].
