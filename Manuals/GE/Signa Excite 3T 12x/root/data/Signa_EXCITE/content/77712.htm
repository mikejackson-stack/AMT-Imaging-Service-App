Basics of Grafidy

Use the Grafidy 3 procedure to calibrate the system for eddy current compensation. Grafidy 3 adjusts and compensates for short, long and very long time constant eddy currents for both linear and B0 terms. Grafidy 3 should be run in Auto Mode first. If auto mode fails to bring any of the terms into specification, Manual Mode can be used for touch up.

Grafidy3 uses the Grafidy pulse sequence (psd), 3.0T 6-coil fixture, and Grafidy3 software. The 3.0T Excite version of this tool uses an enhanced algorithm that offers an improved B0 compensation.

Basics of Grafidy 3:

The basic steps in required in Grafidy 3 are:

  1. Setup the 3.0T 6-coil Grafidy fixture.

  2. Place a rotary attenuator set for 40dB of attenuation between exciter output and RFI.

  3. Start Grafidy 3 tool. Select terms that are going to be calibrated and zero out their calibration values. Run the tool in Auto Mode.

  4. Manual Mode. If auto mode does not bring all terms into spec (still “red” in the result area/table), go to manual mode to do “touch up”.

  5. Review the detailed description for using the Grafidy 3 Tools.
