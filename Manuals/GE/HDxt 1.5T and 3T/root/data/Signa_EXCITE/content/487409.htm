4  Procedure

  1. If Signa applications are up and running, restart the computer by right-clicking on the mouse, select [Service Tools], and then [System Restart].

  1. From Signa login screen, login as root, password is operator. Do not bring up Guided Install.

  1. Right Mouse click and bring up [Configure Printer], (see Illustration 1).

    Illustration 1:  Configure Printers

  1. Click on the [New] option, (see Illustration 1).

  1. Click on [forward].

  1. Enter name of the Codonics Printer as GENNavprntr (case sensitive), Illustration 2. For Brainwave you must use the name of GENNavprntr. For SAGE option, the name is not important.

    Illustration 2:  Create New Printer Profile

  1. Select Queue type as Networked UNIX (LPD), then select [Forward].

  1. Enter hostname or IP address for the Server, (example IP is 10.1.11.11).

  1. Enter queue name as 2.a-cvp, then select [Forward].

  1. For Printer Model, select Postscript printer, then [Forward].

  1. Click, [Apply].

  1. The printer test page should print successfully at this time.

5  Finalization

  1. To verify SAGE printing, open the SAGE option. Select File then Print. A GUI will appear. In the Printer text field, remove the default printer and enter the name of the printer that was used in Step .
