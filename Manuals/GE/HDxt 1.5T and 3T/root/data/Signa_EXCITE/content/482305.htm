UPM - Head Setup and Calibration

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable30 mins5 mins

2  Overview

This procedure sets up the Universal Power Monitor (UPM) in Head mode by using the system and the Power Measurement Kit.

  • For 1.5T systems, only Forward Power must be completed.

  • For 3.0T systems (both LCC300 and 3T/94 Excite-based), both Forward and Reflected Power must be completed in Head mode.

4  Procedure

4.1  Head Forward Power Calibration

  1. To inhibit TR faults, disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet). Move the SW2 switch to the TR DISABLE position. (See Illustration 1.)

    Illustration 1:  Driver Module Front Switches

  1. (For 1.5T Systems) Remove the Head Heliax Cable from J3 on the back of the RF Amplifier, and connect the RF dummy load as shown in Illustration 2.

    NOTE:If the RF Maximum Power Out procedure was just completed, the configuration is the same. Leave the Head RF Heliax Cable disconnected, and keep the coupler (1.5T) or wattmeter (3.0T) in line on the Head Output. It will not change the outcome of the calibration.

    Illustration 2:  Setup for 1.5T Head Output Measurement

  1. (For 3.0T and LCC300 Systems) Remove the Head Heliax Cable from J3, and connect the 35 kW RF dummy load into J3. Plug the power supply on the dummy load into a 110 VAC service outlet in the System Cabinet. (See Illustration 3.)

    Illustration 3:  Setup for 3.0T and LCC300 Head Output Measurement

  1. (For 3T/94 Excite-Based Systems) Remove the Head Heliax Cable from the coupler connected to J3, and connect the 35 kW RF dummy load into J3. Plug the power supply on the dummy load into a 110 VAC service outlet in the System Cabinet. (See Illustration 4.)

    Illustration 4:  Setup for 3T/94 Head Output Measurement

4.2  Setting Up Software Tool to Calibrate UPM - Head Forward Power

This tool must have the head coil installed in order to enable the Coil ID.

  1. Install the head coil.

  1. Align the head coil with the alignment light.

  1. Press [Landmark], and drive the coil into the bore.

  1. To start the UPM Calibration tool:

    • For Restricted Service Tools available to GE Field Service:

      1. Make sure Service Key is installed. Select [Calibration Wizard] from the Calibration menu, then Click here to start this tool.

      2. Once the Calibration Wizard starts, select [UPM Calibration, Head and Body] from the menu; review and validate the pre and post dependencies.

      3. Select Click here to start this tool to start the procedure.

      4. If unable to start the Restricted Service tools, use the non-proprietary method described next.

    • To start Non-Proprietary Service Tools: From the Common Service Desktop, select [Calibration] => [UPM Tool] from the Calibration menu, and Click here to start this tool to start the procedure.

    NOTE:The first time the UPM Calibration tool is run after a Load from Cold, this error message may display: The spectroRFampType and upm.config do not match! Click [File] -> “Edit Config”. When the window opens, click [Restore Defaults] and close the window. (The tool should now have the correct information so this pop-up will not display during future UPM calibrations.)

    Illustration 5 shows an example of the user interface for the UPM tool.

    Illustration 5:  UPM Tool User Interface

  1. Select [1H] for Nuclei.

  1. Select [Head] for the RF Chain to be calibrated.

  1. Select [Forward] for the Power (monitor) Type.

  1. Select [Calibrate].

  1. Select [Start] and validate the hardware setup, then select [Yes].

  1. Verify that status indicates a Pass or Fail within five minutes. (Tool should notify user of the current step in progress.) If failure occurs, see UPM Troubleshooting.

    NOTE:Head Reflected Power Calibration only applies to 3.0T systems. For 1.5T systems, perform UPM - Body and Head Functional Check before proceeding to Finalization, Step 1.

4.3  Head Reflected Power Calibration

  1. (For 3.0T and LCC300 Systems) Disconnect the RF dummy load from the Head Output J3 on the back of the RF Amplifier. (See Illustration 3.

  1. Locate the 12 in. cable stub in the 3.0T Power Measurement Kit, and attach it to J3 using the necessary adapters. (See Illustration 6.)

    Illustration 6:  Cable Configuration for 3.0T and LCC300 Systems

  1. (For 3.0T/94 Excite-Based Systems) Disconnect the RF dummy load from the coupler connected to the Head Output J3 shown in Illustration 7.

    Illustration 7:  Cable Configuration for 3T/94 Systems

    NOTE:If the RF Amplifier at the site is a 25 kW / 35 kW MKS version with an LCD display on the front, disconnect the dummy load directly from J3 because an RF coupler is not required for this amplifier.

  1. Return to the UPM Tool user interface.

  1. Confirm [1H] is selected for Nuclei.

  1. Confirm [Head] is selected for RF Chain.

  1. Select [Reflected] for the Power (monitor) Type.

  1. Confirm [Calibrate] is selected.

  1. Click the [Start] button, validate the hardware setup, and select [Yes].

  1. Verify that status indicates a Pass or Fail within five minutes. (Tool should notify user of the current step in progress.) If failure occurs, see UPM Troubleshooting.

  1. Perform UPM - Body and Head Functional Check before proceeding to Finalization, Step 1.

5  Finalization

  1. Remove the cables and power measurement equipment.

  1. Reconnect the Head and Body Heliax Cables to the amplifier.

  1. Re-enable TR Drive fault detection. (See Illustration 1.)

  1. Upon completion of UPM calibration, select [Reset TPS]. The system will not scan until this is done.
