PAC Power-up

1  Diagnostic Link

Diagnostics >> Peripherals >> PAC Diagnostics

2  Purpose

This test causes the SPU to initiate a PAC module power-up, which the PAC repeats. The diagnostic logs the first error found.

3  Components Tested

  • PAC Module

  • Communication link between SPU (at the TRF board), STIF, and PAC

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

None

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

If this test fails, try running the STIF to PAC LED test (see PAC Manual) to confirm that the PAC fiber optic cable driver on the STIF board is working and the fiber optic cable between STIF and PAC is working. If the STIF to PAC LED test succeeds, try running the Fiber Repeater (FO) diagnostic test (see SPU -> STIF DP) to verify the FO lines and the FO repeater board.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.

8  Etcetera

Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

9  Finalization

TPS reset is required prior to scanning.
