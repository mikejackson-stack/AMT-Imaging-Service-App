RRX Board Level Diagnostics

1  Diagnostic Link

Diagnostics >> System Function >> RF >> Receiver Diagnostics

Diagnostics >> Hardware Location >> Magnet Room >> Receiver Diagnostics

Illustration 1:  Receiver Diagnostics

2  Purpose

There are one (16 channel) to two (32 channel) RRX modules attached to the side of the magnet. The RRX Board Level Diagnostics test each RRX module installed and the dual fiber link between the RRX and the IRF3. It also tests the circuitry internal to each RRX module. The test is run from the AGP. This diagnostic creates a log file in the directory /usr/g/service/log for each RRX tested. These log files contain he results of the RRX signal quality tests.

The diagnostic will always create the file /usr/g/bin/service/log/RRX-1_loopback_<date>.log if there is only one RRX module. If the system being test has two modules (32 channels), there will be a second RRX module installed which generates another file /usr/g/bin/service/log/RRX-2_loopback_<date>.log.

NOTE:The date in the log files show the current date and time of the test. For example, RRX-1_loopback_2008MAR13_01_45_19.log shows the module followed by the year, month, day, and then time of the test.

3  Components Tested

  • Dual fiber link connectivity to the IRF3 board

  • Programmable registers and logic internal to the RRX

  • Analog and digital filters of the RRX (tested using signal generators internal to each RRX)

  • Ability of the RRX to collect sample data

    NOTE:This diagnostic does not include the analog signal inputs from the RF Hub, the TNS related connections to the TDM, nor the fiber link between the RRX and the ICNs.

4  Requirements

No special requirements.

6  Test Sequence

  1. Select RRX Board Level Diagnostics from the Receiver Diagnostics screen.

  2. Click [Run].

  3. Ensure that the diagnostic passes by reviewing the Test Results table.

7  Expected Results

This diagnostic has either a passed or failed status. If the diagnostic has failed, please review the error log and corresponding extended error messages for subsequent actions.
