SRI Loop Test

1  Diagnostic Link

Diagnostics >> Peripherals >> SRI Data Paths

2  Purpose

This diagnostic verifies that the SRI is responding to commands sent to it from the SCP and that the response from SRI is received by SCP.

3  Components Tested

  • SRI

  • SCP

  • STIF

  • MGD

4  Requirements

None

5  Block Diagram

Illustration 1:  SRI Block Diagram

6  Test Sequence

The test executes the following steps:

  1. The SCP sends a command and data packet to the SRI.

  2. The SRI modifies the data portion of this packet and sends it back to the SCP.

  3. The SCP verifies that it received the correct data.

7  Expected Results

If this test fails, these are the possible reasons:

  1. The SRI is bad or powered off.

  2. The plastic fiber cables between the MGD chassis and SRI are disconnected or broken.

  3. The optical repeater in the pen panel is defective or in loopback mode.

  4. The STIF board is defective.

  5. The SCP board is defective.

8  Etcetera

This test is similar to the SRI Streamed Loopback test with the exception that this test sends only one test data byte.
