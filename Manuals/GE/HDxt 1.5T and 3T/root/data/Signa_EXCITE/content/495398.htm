4  Procedure

4.1  Downloading Patches from SupportCentral and Burning to a CD

If a disk is shipped that contains the patches, skip this section and proceed to Preparing for New Service Pack Installation. If a disk is not available that contains the patches, download the patches onto your PC and then burn them onto a disk that can be used on the MR system. The MR system requires that the disk be ISO-compliant. This format type cannot be burned with Windows XP's built-in disk burning capability. To burn an ISO-compliant disk, a program such as Sonic RecordNow must be used, which burns ISO-compliant disks by default.

  1. From your PC, go to the MR OLC Support Central.

  1. In the right navigation pane, click Process and the link: Patches Download Support Central under Software Updates (Patches).

    Illustration 1:  MR OLC Support Central Page

  1. Select the proper version of the patches required, and download all of the *.rpm files listed for that version onto your PC.

    The download time will vary, depending on the number and size of files to be downloaded.

NOTE:To obtain a licensed copy of Sonic, go to ftp://globe/globepro/swstore/applications/HelpDesk/SONIC and download the Sonic Record Now 7.exe file or call the GE Healthcare Help Desk.

  1. To burn these *.rpm files, insert a blank CD into the CD-ROM drive.

  1. Start Sonic RecordNow.

  1. From Sonic's home page, select the Data Projects tab, and click [Data Disc] (shown in Illustration 2.)

    Illustration 2:  Creating a Data Disc

NOTE:Since the system's Guided Install automatically looks for the *.rpm files in the dist folder, this folder must be created on the CD.

  1. To create the dist folder on the CD, click the [New Folder] icon, and type: dist in the Name field (shown in Illustration 3).

    Illustration 3:  Creating dist Folder

  1. Double click the dist folder so it appears in the Save In field, click [Add Files and Folders] (shown in Illustration 4), and browse on your PC to add the .rpm files to the Data Disc list (shown in Illustration 5).

    Illustration 4:  Adding Files to dist Folder

    Illustration 5:  Browsing to Select Files for the Disc

  1. To burn the disc, click the red [Burn] button.

4.2  Preparing for New Service Pack Installation

Any previously installed service pack must be removed prior to installing a new service pack.

  1. Back up your system by performing a SaveInfo.

NOTICE
For safety reasons, a service pack must be installed on the system at all times. Do not remove any service pack unless an alternate service pack is available for installation.
 
 

NOTE:If installing a service pack as part of Load From Cold (LFC), complete the LFC and the VRE configuration as described in the service manual, then install the service pack disk. (It is preferable to install the service pack disk after a test scan.)

  1. Restart the system and log in as root at the login prompt.

  1. When asked to invoke Guided Install, click [Yes]. (See Illustration 6.)

    Illustration 6:  Starting Guided Install

  1. Open Guided Install and select Patches in left navigation pane, and select the Patches tab.

    Illustration 7:  Installed Patches

  1. Under Installed Patches, uninstall the Service Pack for the system first, and then uninstall all the other patches by selecting each patch and clicking [Uninstall].

    NOTE:If multiple patches are selected and then [Uninstall] is clicked, only the top patch will be uninstalled. Once the [Uninstall] button is clicked, a patch is uninstalled.

  1. After uninstalling the patches, restart the system by typing: reboot in a C-shell.

  1. To verify the patches are uninstalled, open a C-shell and type: getver. None of the patches should be listed. (This step is not actually required to uninstall, but is just for verification.)

4.3  Installing a Service Patch

The installation process is the same whether installing service packs from a disk that was sent to you from GE Healthcare or one that you burned.

  1. Log in as root at the login prompt.

  1. Insert the disk with the patches into the Host PC disk drive.

  1. In the Guided Install window, select Patches in the left navigation pane, and select the Patches tab.

  1. Select CDROM as the patch medium. The patches contained on the disk will be listed.

    Illustration 8:  Patches Available for Installation

NOTE:The order of installation is important as there may be dependencies on other application patches that are required prior to installing a patch. Normally, install patches first and the Service Pack last. The Guided Install will not proceed until all required application patches are loaded, so the system cannot be damaged by attempting to install a patch before all its dependencies are met. If a message displays indicating that a dependent patch was not installed, simply install the required patch before proceeding.

  1. Select each patch and click [Install].

    NOTE:If multiple patches are selected and [Install] clicked, only the top patch will be installed. Each patch is installed after the [Install] button is clicked.

    Illustration 9:  Installing Patches with Dependencies Last

  1. After installing all the patches, restart the system by typing: reboot in a C-shell.

  1. To verify that all the patches are installed, open a C-shell and type: getver. Verify that the service pack just installed is listed. (This step is not actually required to complete installation, but is just for verification.)
