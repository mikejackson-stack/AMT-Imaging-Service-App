Mobile Configuration

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Starting the Mobile Setup Tool

  1. With Signa up and running in Scan mode, open the Service Desktop by clicking the [Service Desktop] button on the left side of the screen. (See Illustration 1.)

    (Step Details)

  1. On the Service Desktop, open the Common Service Browser if not already running. Start the Mobile Tool as shown in Illustration 2.

    (Step Details)

  1. In the center of the Service Desktop Manager (shown in Illustration 2), select Mobile to open the Mobile Setup window.

  1. When the command prompt asks for a password, enter the root password, operator and press <Enter>.

1.2   Mobile Site Setup Window Description

  1. Refer to the Mobile Setup window in Illustration 3 and Table 1 for a description of each field on this window.

    (Step Details)

  1. Click [Done] to exit the Mobile Site Setup window.

1.3   Mobile Site Activation Window Description

NOTE:Mobile Site Activation is opened by clicking (13) [Activate].

  1. Illustration 4 displays the Mobile Site Activation window.Table 2 offers an description of each button.

    (Step Details)

  1. Select [Get Active Site] to obtain the currently active hospital's configuration Host Name, IP Address, Netmask, and Host or Network DICOM information for the Mobile Site Setup window. Mobile site information is saved with SaveInfo.

1.4   Applications and Considerations

The Applications feature is used to update the image annotation with the appropriate name for the hospital or outpatient facility.

  1. Below are some general considerations:

    (Step Details)

  1. In order to add the current hospital to the list of previously entered sites, select [Get Active Site] from the Mobile Site Activation window.

    (Step Details)

1.5   Selecting a Different Hospital

  1. With Signa up and running, open the Mobile Setup window. (See Illustration 3.)

  1. Select a hospital from the list on the Mobile Site Setup window. (See Illustration 5.)

    (Step Details)

  1. Select [Activate].

  1. Select [Activate Site] on the Mobile Site Activation menu. (See Illustration 6.)

    (Step Details)

  1. If another pop-up displays, click [Continue].

  1. Select [Done].

  1. Click [Yes] on the Exit Mobile GUI dialog box. (See Illustration 7.)

    (Step Details)

  1. Shut Signa down from the Service Desktop, then restart. The system will display the updated information for the selected hospital.

1.6   Adding a New Hospital Using Get Active Site

  1. With Signa up and running, open the Mobile Site Setup window. (See Illustration 3.)

  1. Select [Activate] on the Mobile Site Setup window.

  1. Select [Get Active Site] on the Mobile Site Activation menu. (The Mobile Site Setup window will be updated using the currently active hospital's information. See Illustration 4.)

    (Step Details)

  1. Select [Done] on the Mobile Site Setup window.

  1. On the Exit Mobile GUI menu, select [Yes].

1.7   Adding a New Hospital

  1. With Signa up and running, access the Mobile Setup window. (SeeStarting the Mobile Setup Tool.)

  1. Select [Add] on the Mobile Site Setup window.

  1. At the minimum, enter the Hospital Name, Host Name, IP Address, Netmask and Router. Consult with a GE Service Engineer for this information if unknown.

  1. Click [Add] again.

  1. If the newly added hospital needs to be activated, proceeds as follows:

    1. Select the new hospital from the list.

    1. Select[ Activate] on the Mobile Site Setup window.

    1. Select [Activate Site] on the Mobile Site Activation menu. (See Illustration 4.)

    1. Select [Continue].

    1. Select [Done] on the Mobile Site Setup window.

    1. On the Exit Mobile GUI menu, select [Yes]. (See Illustration 7.)

2  Finalization

  1. Shut Signa down from the Service Desktop and restart.

  1. Perform a quick test scan. The system should now display the correct site information. If not, repeat the procedure in Starting the Mobile Setup Tool.
