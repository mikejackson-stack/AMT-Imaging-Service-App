Table 1:  Error Messages and Recommended Actions

Fault and Error NumberSymptomAction(s)
HFA_Failed_Ready

2244570

Gradient Amplifier _ Axis failed to go to Ready when commanded.
  • G_Enable test point on the front of Gradient Amplifier J2 is High; replace the Gradient Amplifier Axis.
  • Check cable between GP3 and Gradient Amplifier.
  • Replace GP3.
     
HFA_Cable_Off_Fault

2244571

GP3 reported a Gradient Amplifier _ Axis cable off fault.
  • Check cable between GP3 and Gradient Amplifier.
  • Replace GP3.
  • Swap Gradient Amplifiers and replace appropriate axis.
              
HFA_Power_Off_Fault

2244572

GP3 reported a Gradient Amplifier _ Axis power off.
  • Make sure 208V line cable is fully seated between Gradient Amplifier and PDU.
  • Replace Gradient Amplifier.
   
HFA_WF_PSUV_Fault

2244573 AND 2244574

GP3 reported a Gradient Amplifier _ Axis internal wiring fault and internal power supply under voltage.
  • Perform a TPS Reset.
  • Replace Gradient Amplifier.
HFA_OC_Fault

2244575

GP3 reported a Gradient Amplifier _ Axis over current fault.
  • Check output cabling to the Coil.
  • Replace Gradient Amplifier.
HFA_OV_Fault

2244576

GP3 reported a Gradient Amplifier _ Axis over voltage fault.
  • If no other faults reported, replace Gradient Amplifier.
  • See other faults.
HFA_UV_Fault

2244577

GP3 reported a Gradient Amplifier _ Axis under voltage fault.
  • If no other faults reported, replace Gradient Amplifier.
  • See other faults.
HFA_IDIST_Fault

2244578

GP3 reported a Gradient Amplifier _ Axis current distortion fault.
  • Check L Coil calibration.
  • Run Gradient Driver tests to isolate FRU. If diagnostics pass, write CQA.
HFA_OT_Fault

2244579

GP3 reported a Gradient Amplifier _ Axis over temp fault.
  • Wait at least for 5 minutes for cabinet to cool.
  • Check fan phase rotation, fan filter, and make sure gradient cabinet rear door is closed.
  • Check Gradient Amplifier.

Z_HFA_OVRANGE_Fault

Z Axis Gradient Data Over Range Occurred: GP3 detected an error in the incoming high speed data from the SCP.Usually a PSD problem; ignore all other faults except Rollover 2244582.

  • Check DC Offset calibration.
  • Check PSD application.
  • Write CQA.

Z_HFA_RollOver_Fault

Z Axis Gradient Data Rollover Occurred: Application of digital DC Offset compensation caused the gradient data to roll over.
  • Check DC Offset calibration.

  • Write CQA.
SGAPS_Ready_Fault

2244586

SGA-PS failed to go to Ready when commanded or came out of Ready.
  • Press Reset button on SGA-PS.
  • If Enable test point on the SGA-PS J2 connector is High, replace SGA-PS.
  • Check the cable from GP3 to SGA-PS.
  • Replace GP3.
SGAPS_Cable_Off_Fault

2244587

GP3 reported a SGA-PS cable off fault.
  • Check the cable between the GP3 and SGA-PS.
  • Replace the SGA-PS.
SGAPS_Power_Off_Fault

2244588

GP3 reported a SGA-PS power off.
  • Check 420V power breaker on PDU; if tripped, replace SGA-PS. Do not cycle power.
  • Make sure 420V power line is fully seated between PDU and SGA-PS.
  • Push EMO reset switch on PDU.
  • Replace SGA-PS.
SGAPS_WF_PSUV_Fault

2244589

GP3 reported a SGA-PS internal wiring fault or internal power supply under voltage.
  • Reseat SGA-PS connectors.
  • Replace the SGA-PS.
 
SGAPS_OT_Fault

2244590

GP3 reported a SGA-PS over temp fault.
  • Wait at least for 5 minutes for cabinet to cool.
  • Check fan phase rotation, fan filter, and make sure gradient cabinet rear door is closed.
  • Check SGA-PS.
SGAPS_OC_Fault

2244591

GP3 reported a SGA-PS over current fault.
  • Check SGA-PS LEDs to determine which axis is source of problem; replace that Gradient Amplifier axis.
  • Replace SGA-PS.
  • Power cycle HFD Power breaker on PDU to recover.
SGAPS_OV_Fault

2244592

GP3 reported a SGA-PS over voltage fault.
  • Check SGA-PS LEDs. If BUS_OV LED is lit, check PDU 420V output. If primary, replace SGA-PS.
  • If OV_X, Y, Z LED is lit, swap military connectors to isolate Gradient Amplifier vs. SGA-PS.
  • Replace SGA-PS.
  • Power cycle HFD Power breaker on PDU to recover.
SGAPS_UV_Fault

2244593

GP3 reported a SGA-PS under voltage fault.
  • Check SGA-PS LEDs. If BUS_UV LED is lit, check PDU 420V output.
  • If primary, replace SGA-PS.
  • If UV_X, Y, Z LED is lit, swap military connectors to isolate Gradient Amplifier vs. SGA-PS.
  • Replace SGA-PS.
  • Power cycle HFD Power breaker on PDU to recover.
HFA_Failed_Standby

2244594

Gradient Amplifier _ Axis failed to go to Standby when commanded.
  • If G_ENABLE test point on the front of Gradient Amplifier J2 connector is Low, replace the Gradient Amplifier Axis.
  • Check the cable between GP3 and Gradient Amplifier.
  • Replace GP3.

Current Driver Tests

2245044

GP3 reported an X Axis Gradient Amplifier internal wiring or internal power supply under voltage fault.
  • Cycle two breakers on PDU.
