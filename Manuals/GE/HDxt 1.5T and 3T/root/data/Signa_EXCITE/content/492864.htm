Grafidy3 Eddy Current Calibration

Use the Grafidy 3 procedure to perform eddy current compensation. Grafidy 3 adjusts and compensates long and very long time constant eddy currents for both linear and B0 terms. Grafidy 3 should be run in Auto Mode first. If Auto mode fails to bring any of the terms into specification, Manual Mode can be used for touch up.

Grafidy3 uses a dedicated pulse sequence (psd), 6-channel fixture, and Grafidy3 software. The HDMR2 version of this tool uses an enhanced algorithm that offers an improved B0 compensation. The Grafidy 3 fixture plugs into the LPCA for Transmit / Receive. No additional fixtures or cables are needed.

The HDMR2 version of the tool simplifies the tool setup and collects data from all 6 coils simultaneously.

The basic steps required in Grafidy 3 are:

  1. Setup the 6-channel Grafidy fixture.

  2. Start Grafidy 3 procedure. Run the tool in Auto Mode.

  3. If Auto mode does not bring all terms into spec (still “red” in the result area/table), go to Manual Mode to do “touch up”.

Review the detailed description for using the Grafidy 3 Tools. For information concerning troubleshooting, see Grafidy 3 Troubleshooting.
