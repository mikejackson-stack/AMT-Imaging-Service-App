2  Overview

With Excite software only the 90 degree RF waveform will be visible on the oscilloscope. The 180 degree RF waveform will not be visible. This was done to simplify the RF power calibration process by pre-setting the CVs “ia_rf1” and “ia_rf2” to 32766 (maximum amplitude) and 0 (zero; minimum amplitude), respectively.

4  Procedure

NOTICE
Disconnect the RF out to the SRF Cabinet by removing the cable connected to J1 at the System Cabinet I/F on the rear of the System Cabinet.
 
 

  1. At keypad on front magnet enclosure, press LANDMARK and ADV TO SCAN.

  1. At Operator Work space, select the scan icon in the desktop control panel, if you have not already done so.

  1. Click on [New Pt], and <enter>

    Id: geservice

    Name: rf waveform

    Weight (Lb): 111

    Set Patient Protocols to [Service].

  1. In the Protocol field, select Other, and find RF waveform protocol, series 1 and accept.

  1. Click on [Save Series].

  1. [Research Operations], [Setup Params] with the right mouse button, enter settings per the following

    R1 = 13

    R2 = 14

    TG = 200

    Number of Frames: 2<Enter>[Done]

    [Research Operations], [Display CVs]

  1. Set calmode= 5<Enter> (SINC Pulse), select [Accept].

  1. Select [Manual Prescan], [Scan TR]

  1. Refer to WAVEFORM DIAGRAMS for RF waveforms.

  1. When finished select [Done].

5  Finalization

  1. Make sure pulsing has stopped by selecting [Done] and [End Exam].

  1. Reconnect the cable disconnected earlier to J1 on the System Cabinet I/F at the rear of the System Cabinet.

  1. Ensure that all system cables are re-installed.

NOTE:Whenever the “Calmode” CV is changed, a TPS reset must be done before attempting to scan. This is necessary in order to set the MGD back into imaging mode. Failure to do this will result in the loss of receive signal and autoprescan failures.

  1. Perform a TPS Reset to set the MGD back to imaging mode so that the system will be able to scan. Failure to do this will result in Autoprescan failures due to a loss of receive signal.

  1. Successfully complete one head scan.
