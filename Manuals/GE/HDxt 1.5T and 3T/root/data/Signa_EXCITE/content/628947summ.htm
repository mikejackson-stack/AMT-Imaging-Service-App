RF Transmit Cable Attenuation Measurement

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Upper level Overview

  1. The Test Setup is connected between J1 of the System Cabinet and J13 of the MUX board in the RRF Chassis, for an upgrade system with both a System and RF cabinet, or for a 3T system. In a system with the RFS Cabinet, the Test Setup is connected between J8 of the Exciter in the RRF Chassis and J13 of the MUX board in the RRF chassis Illustration 1) Receiver gains R1 and R2 and transmit gain TG are set for near full scale reading on the power spectrum during prescan calibration. A reference scan is performed and analyzed using the atten_test tool on the Test Setup to establish a base-line. After the baseline is created the Test Setup hardware is reconfigured and connected along one of the RF transmit paths, another scan is performed and the data analyzed using the atten_test tool. This reconfiguration and connection process is repeated for each other RF transmit path.

    (Step Details)

  1. The ‘atten_test’ program will provide the [Magnitude Squared Attenuation Factor] for each test setup. The result will be use to calculate the Attenuation in (dB) for each test setup.

1.2   Initial Setup

  1. Remove front cover from system cabinet.

  1. Configure test hardware as shown in Illustration 1.

  1. At the operator workspace, prepare the system for scan using the following procedure

    1. Click on [New Pt]

    1. Id: geservice

    1. Weight (Lb): 111

    1. Set Patient Protocols to Service

    1. Select Other and scroll down to the protocol named, 1.5T dummy load cal ,or 3T dummy load cal depending on software revision.

    1. Select Series [1], [Dummy Load], [Cal: RF Cab]

  1. Set a landmark if necessary, then Save Series.

  1. Use the right mouse key, select [Research Operations] then select [Display CVs].

    (Step Details)

  1. Select [Accept] and then select [Research Operations], then select [Download] then select [Manual Prescan].

1.3   Data Collection

  1. When in [Manual Prescan], set Analog Gain R1 to 7, and Digital Gain R2 to 14.

  1. Adjust transmit gain (TG) to achieve an R1 or R2 (on IP display) of approximately 98%, without going over.

  1. Select [Done].

  1. Select [Scan] (Ignore the message: MR signal too large, reduce receiver gain.)

  1. From the MR Tools desktop Service Desktop, start [Attenuation Test]. See Step .

    (Step Details)

  1. Use [Atten Test] tool selection to analyze data, as shown in Illustration 3.

    (Step Details)

  1. Measure the RF Amp output path attenuation from the RF Amp up to Head T/R SW-input (upgrade LPCA with Bendix connector) or Multicoil I/F box (Forward Production LPCA) as follows. Verify the TR switch at the front panel of the Driver Module is in the “DISABLE” position. (TR Fault Disable Mode/Service/Bypass)

    1. Remove the bullet from in between the test setup cables, to separate them.

    1. Disconnect the head RF output cable attached to the RF power amplifier and connect it with a BNC - N adaptor to the coax reference cable coming from the system cabinet J1 (RF out) or RFS cabinet J8 from the Exciter Board.

    1. For an upgraded system with a Bendix connector, disconnect J6 (the RG-223 cable) from the Head T/R Switch inside the carriage cover on the patient table cradle and connect it to the coax reference cable coming from the MUX Board J13 through the DC block unit.

    1. For a Forward production system, disconnect J18 from the Multicoil I/F Box inside the carriage cover on the patient table cradle, and connect it to the coax reference cable coming from J13 of MUX through the DC block unit.

  1. Reselect the scanning icon again to activate the scanning screen.

  1. Select [Scan].

  1. When the scan is completed, re-select the tools icon again to activate the ‘atten_test’ analysis section again. Go to Step  for analysis instructions. Do not make this run the reference.

  1. After analysis is complete , reconfigure the hardware to measure the attenuation of the RF Body Transmit chain as follows:

    1. Reconnect the Head RF Transmit cable to the RF amp and Head I/F switch or Multicoil I/F Box in the LPCA.

    1. Disconnect the Body RF transmit cable from the RF amp and connect it to the coax reference cable coming from the system cabinet. J1 (RF out) or RFS cabinet J8 from the Exciter Board using BNC 7116 DIN adaptors.

    1. Disconnect the flexible RF Body Transmit cable from the input to the Body Hybrid J6 and connect it to the coax reference cable coming from the MUX Board J13 Through The DC Block using BNC-7116 DIN adaptors.

      (Step Details)

  1. Select [Scan].

  1. When the scan is completed, return to the MR Tools desktop Service Desktop, start [Attenuation Test] again. See Step  for help if needed.

  1. After analysis is complete, reconfigure the hardware to measure the attenuation of the RF MNS Transmit chain (If Applicable) as follows:

    1. Reconnect the Body RF Transmit cable to the RF amp and the Body Hybrid in the Rear Pedestal.

    1. Disconnect the MNS RF transmit cable from the MNS RF amp and connect it to the coax reference cable coming from the system cabinet J1 (RF out) or RFS cabinet J8 from the Exciter Board using BNC 7116 DIN adaptors.

    1. Disconnect the MNS RF Transmit cable from the input at J1 of the LPCA and connect it to the coax reference cable coming from the MUX Board J13 Through The DC Blockusing BNC-7116 DIN adaptors.

NOTE:Must use multiple adaptors from both the 3T RF Power measurement Kit and the RF test Cable Kit.

  1. Select [Scan].

  1. When the scan is completed, re-select the tools icon again to activate the ‘atten_test’ analysis section again. Go to Step  for analysis instructions.

1.4   Analysis

  1. After selecting the Attenuation Test from the Calibration menu as described above, analysis is run as shown in Illustration 4.

    (Step Details)

  1. Record “Magnitude Squared Attenuation Factor” value produced by the analysis program, for each hardware setup being analyzed.

    1. Setup 1 RF transmit path (Head) – Table line item 1.

    1. Setup 2 RF transmit path (Body) – Table line item 2.

    1. Setup 3 RF transmit path (MNS) optional – Table line item 3.

  1. Calculate the attenuation (dB) for each hardware setup using the formula: 10 * log [Max Squared Attenuation Factor].

  1. Record in Table 1 line items 1, 2 and 3.

    (Step Details)

2  Finalization

  1. Remove all test equipment and return cabling to proper locations.

  1. Replace any covers that were removed.

  1. Reset the TPS.

  1. Perform a Body and Head scan to verify system functionality.
