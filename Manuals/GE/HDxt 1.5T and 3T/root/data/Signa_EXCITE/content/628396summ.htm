ICW - Install In Spec

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

All calibrations required for IIS are complete.

-

-

Install In Spec Key must be generated.

-

-

2  Procedure

  1. Insert the Service Key.

  1. Launch the Service Browser (Common Service Desktop).

  1. Click on the Calibration Tab then click on Install and [Calibration Wizard] ⇒ [Click here to start this tool]

  1. Install In Spec is about ¾ of the way down the list. See Illustration 1.

    (Step Details)

  1. Click on [Click here to start the tool].

  1. Click [Check Status]. If all calibrations necessary to complete Install In Spec have been completed and pass, then the Install In Spec key will be generated and this step in the Installation Calibration Wizard will be marked as passing.

  1. When [Check Status] is selected, a dialog box will pop-up alerting the user that this is a good time to perform a Save Info. Select [Yes] to launch the Save Info process. See Verifying Save Restore Media.

  1. All failures must be corrected and steps Step 4 - Step 6 must be repeated until Install In Spec passes.

    (Step Details)

3  Finalization

  1. Return to the Install Cal Wizard for information regarding how to advance to the next calibration and for links to other calibration procedures that must be completed prior to turning the system over to the customer.
