Table 3:  Diagnostic Results

ResultDescriptionGE Field Action

Passed

No further action required

Failed

The ICN has failed the diagnostic

  1. Ensure that the ICN is powered on. (Utilities>Toolbox>VRE>ICN Identification
  2. Ensure that the Ethernet switch is on.
  3. Run the Host ICN Remote Shell diagnostic. If it fails, troubleshoot this diagnostic.
  4. If it passes, re-run this diagnostic.
  5. If it fails, reboot the ICN.
  6. Perform a TPS reset and re-run the diagnostic.
  7. If the diagnostic fails, re-configure the VREs using Guided Install.
  8. Restart the system and re-run the diagnostic.
  9. If it fails again, identify the defective ICN from the System Error log. (Utilities>Toolbox>VRE>ICN Identification)
  10. Replace the defective ICN.
