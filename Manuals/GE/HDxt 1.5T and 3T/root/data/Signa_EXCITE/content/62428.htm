Longitudinal Drive Calibration Overview

This calibration compensates for errors in table positioning. Errors can be caused by differing encoders and stacking tolerances in the drive system components.

This calibration is normally required after initial start-up of software on a new system. An error is logged to indicate the need for this calibration (see Screen 1).

SCREEN 1

EM_SRI_INVALID_CALIB_VALUE

The encoder calibration value was invalid.

Please run the cradle calibration routine.

Specified Calibration Constant: (Difference between current endTravel and begTravel)

Minimum Calibration Constant: 2250

Maximum Calibration Constant: 2750

This error is only a warning, and indicates that the table calibration files are not correct. Calibration may be necessary if the image does not align with the landmark. However, other factors could be causing this error, and calibration may not be the solution.

Refer to procedure for Longitudinal Drive Calibration.
