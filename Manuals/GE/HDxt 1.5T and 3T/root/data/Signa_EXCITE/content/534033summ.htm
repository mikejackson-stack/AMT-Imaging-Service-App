RDHD (Read Header)

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. On the Service Browser, select the [Utilities] tab, then [Read Header], then [Start this tool] (see Illustration 1).

    (Step Details)

  1. Select an Exam, Series, and Image. Type <A>, <B>, and <C> to directly enter the desired exam, series, and image number, or type <D>, <E>, and <F> to list/select each one.

    (Step Details)

  1. After entering the exam, series, and image number, type <G><Enter> to go to the Display Header menu. See Illustration 3

    (Step Details)

  1. Select <A> to <W> to display the desired header information. Select <X> for all header information. Select <Q><Enter> to quit.

    (Step Details)
