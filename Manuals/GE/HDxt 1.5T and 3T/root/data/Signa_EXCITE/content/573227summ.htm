3  Procedure

3.1   Running the Tool

  1. Under RRF Chassis, select [Multi-coil Receive Chain Tool] from the menu on the left side of the Diagnostics screen.

  1. Under Multi-coil Receive Chain Tool on the right side of the screen, select [Click here to start this tool]. The Multi-coil Receive Chain Test window opens as shown in Illustration 1, below.

    (Step Details)

  1. Make the appropriate test selection; see Illustration 1 and Illustration 2 for options. Click [Continue].

    (Step Details)

  1. Prepare for a head scan using the TLT phantom in the head loader by landmarking the phantom and advancing to scan. Do not use scan prescription; the tool will automatically prescribe the necessary scan. See Illustration 3.

    (Step Details)

NOTICE
The middle two selections shown in Illustration 2 for checking channels 1-4 and 5-8 will not be selectable on systems with eight (8) channels. The first selection for testing channels 1-8 will not be selectable on systems with only four (4) channels.

It is very important that the initial landmark setting is maintained throughout the entire series of channel tests. The original landmark and scan provide the baseline SNR that is used for the tests performed on each channel.

 
 

  1. In the setup window, click [OK]. The system performs a head scan and temperature compensation scan to create the baseline for all of the Multi-coil Receive Tests.

  1. When the head data collection is complete, install the Multi-coil Receive Tool in the Multi-coil Quick-Disconnect receptacle. See Illustration 5.

    (Step Details)

  1. Attach the receiver cable (with the DC block) to the connector directed in the Reconfigure Hardware window. Leave the transmit cable attached to the coil connector and install the head coil connector into the head port, as shown in Illustration 4 and Illustration 5

    (Step Details)

  1. Click [OK] to continue the test.

  1. After the scan, continue to change the receive cable connections as directed on the screen.

  1. After the test is completed, the individual channel SNR results are displayed. See Illustration 6. Review the data for discrepancies in SNR from channel to channel. See “Example Data” in Illustration 9.

    (Step Details)

  1. To view the results of the test, in the Multi-coil Receive Chain Test window select File, then View Results. The results will then be displayed in an MCR Results window. See Illustration 7.

    (Step Details)

  1. To view the Log File, in the Multi-coil Receive Chain Test window, select File, then View Log File. See Illustration 8.

    (Step Details)

  1. The results files can be reviewed later from the standard Report Manager. Choose the file type MCR to recall these files.

  1. To exit the Multi-coil Receive Chain Test, on the Multi-coil Receive Chain Test screen, select [File], then [Quit]. See Illustration 10.

    (Step Details)

  1. When you see the prompt “Press Ok Button below on this dialog box, if you want to exit,” click [OK].

3.2   Troubleshooting MCR Failures

If you closed the Multi-coil Receive Chain Test screen without selecting [File], then [Quit] on the Multi-coil Receive Chain Test screen , you will see this message shown in Illustration 10. Although it does not appear on the desktop, the previous Multi-coil Receive Chain Tool session is still running and must be closed before you can start a new session. To close the previous session, follow these steps:

  1. From the Service Desktop Manager, open a [C-shell].

  1. In the winterm window:

    1. Type su root and press <Enter>

    1. At the password prompt, type operator and press <Enter>

    1. Type /usr/g/service/cclass/mcr/kill_mcr and press <Enter>

  1. When a multi-digit number appears (confirming that the command was processed), start a new Multi-coil Receive session by following the instructions in Step .
