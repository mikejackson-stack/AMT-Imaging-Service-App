3  Procedure

3.1  Using the Common Service Desktop

  1. Insert Rainbow Service key into the Global Operator Console Computer Cabinet. See Illustration 1.

    Illustration 1:  Insert The Rainbow Service Key

  1. From the Service page, start the Service Browser.

  1. Verify that the Home tab is selected.

  1. For Release and software revision information, See Illustration 2.

    Illustration 2:  Common Service Desktop Home Screen

  1. See Release Information for software revision information.

    Illustration 3:  Common Service Desktop Home Screen

3.2  Using a C-Shell

  1. If you are not already on the Service Desktop, click on the [Service] icon. See Illustration 4.

    Illustration 4:  Going To The Service Desktop

  1. From the Service Desktop Manager, click on [C-Shell] to open an xterm window.

  1. Locate the cursor in the window.

  1. To see the software revisions used on your system, at the prompt, type <sw_config_status> and press <Enter>. See Illustration 5 to view what is displayed on the Terminal when using this command.

    Illustration 5:  SW_CONFIG_STATUS Example
