Upgrades

Magmon2 (SHeM) to Magmon3 Upgrade

1  Upgrade Prerequisites

The business plan for upgrading a Magmon2 (SHeM), manufactured by Granite, to a Magmon3 is to replace it upon failure. All parts needed for the upgrade will be ordered from the Global Parts Operation.

Here are some key points that you need to know and perform before upgrading:

  • Plan on installing new wall anchors for mounting the Magmon3. The footprint is different between these two units. Refer to Magmon3 Specifications for mounting hole locations and dimensions. Use an anchor system that is capable of supporting the 8 pound weight of the Magmon3 unit. These parts are to be procured locally.

  • The adaptor cable for the Leybold CoolPak 4000 compressor is not compatible with Magmon3. The cable is missing wiring that allows Magmon3 to remotely reset and auto-reset compressor functions after a compressor fault condition has cleared. You will need to order a new cable (Item 3 in Table 1) for systems with this compressor configuration.

  • Magmon3 does not support the following cable interconnections and are no longer used:

    • The serial communication cable that was connected between the UPS for the Magmon and MSM1-J3.

    • The cable Run 941 that was connected between MSM1-J11 and the Ellis & Watts System Cooling Cabinet.

  • If currently using a modem, contact the customer's IT person and try to get the site converted over to a broadband connection for InSite connectivity. This is the preferred method of connection for Magmon3.

  • For HFO systems, you need to order additional parts for the monitoring of the second compressor.

Use the checklist in Table 1 for determining which parts to order to make the upgraded system fully functional.

2  Install New Magmon3 Hardware and Connect Cables

  1. Mount the Magmon3 in place of the Magmon2 (SHeM).

  2. If using a broadband connection, connect Run 942 between the customer's network wall jack and the Magmon3-J5. Skip to Step 4.

  3. If using the Global Modem:

    1. Mount the modem to the wall above or below the Magmon3 unit using the Velcro supplied with the unit.

    2. Connect Run 940 (serial cable) from the modem to Magmon3-J1 and connect the phone line between the modem and the phone wall jack.

    3. Connect one end of the power supply adaptor to the modem and AC plug into the same wall outlet that the Magmon3 is powered from.

  4. Make the remaining cable connections to the Magmon3 unit, per the appropriate interconnect diagram based on magnet and system type. Refer to Interconnect Maps.

  5. For HFO systems, install the water flow / temperature meter into the supply line of the second compressor. Refer to Water Flow / Water Temp Sensor section in Hardware Installation.

  6. For HFO systems, install the additional cables for the second compressor and water flow meter.

3  Power-Up and Configuration

  1. Verify all cabling and connections to the Magmon3, Global Modem (if phone connection is used), MUX-box (if being used), broadband connection (if network connection is used), and the magnet sensors are correct.

    NOTE:The serial cable that ran from the Magmon2 to the UPS can be discarded, as the Magmon3 does not support this communication feature. See Step 1 of Step  for more information.

  2. Follow this startup and configuration sequence:

    1. Apply AC power to the Magmon3 and Global Modem (if used) by plugging them into the customer supplied (7 × 24) wall outlet.

    2. Set up your laptop to directly connect the Magmon3. Refer to Connecting a Laptop to the Magmon3.

    3. Put the Magmon3 into Web Mode (use fixed IP). Refer to Section 2.3.1 of Magmon3 Front Panel User Interface.

    4. Use the login setup for initializing the proprietary software. Refer to Initializing Proprietary Mode in Non-Proprietary and Proprietary Login Modes.

    5. Set the Magmon3 to Proprietary Mode, and then log off. Refer to Initializing Proprietary Mode in Non-Proprietary and Proprietary Login Modes.

    6. Reset the Magmon3 to Web Mode again. Refer to Section 2.3.1 of Magmon3 Front Panel User Interface.

    7. Log in as Proprietary Service User. Refer to Section 2.3.2 of Magmon3 Front Panel User Interface.

    8. Set the Magmon3's date and time. Refer to Section 1 of Configuration Setup.

    9. Select the correct magnet type and compressor type. Refer to Section 2 ofConfiguration Setup.

    10. Fill in and submit the input fields on the System ID page. Refer to Section 4 of Configuration Setup.

    11. Establish the correct network settings on the Network page. Refer to Section 5 of Configuration Setup.

    12. Fill in and submit the input fields on the InSite2 page. Refer to Section 6 of Configuration Setup.

    13. Click [Logout] on the top left side of the web page to activate the new settings.

    14. Wait at least 10 minutes and then check for alarms on the front panel, as indicated by the alarm LED and the [Alarms] button.

    15. Put the Magmon3 into Web Mode, login to the web interface.

    16. Inspect these pages: View Alarms, View Event Log, and View InSite2 Log.

    17. Contact your regional Online Center magnet support group to perform a checkout and provide information regarding the site upgrade from Magmon2 to Magmon3.

4  Completion and Cleanup

  1. Properly dispose of all cables and hardware associated with the Magmon2 upgrade that are no longer being used by following the Renewable Resources Return Process for de-installed parts.

  2. Update your Cryogen Administrator on the upgrade to Magmon3 for the site.

  3. Update the customer on the functionality of the Magmon3 and proper power-up and power-down procedures.

  4. Notify your Cryogen Supplier Technician that performs the site fills that the unit has been upgraded to Magmon3. Instruct the Technician on the Magmon3 fill mode process, the details are covered on the User Guide Label on the front panel of the Magmon3 unit.
