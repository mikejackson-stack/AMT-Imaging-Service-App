Read Current/Voltage

1  Diagnostic Link

Diagnostics >> Peripherals >> Shim Supply Diagnostics

2  Purpose

This diagnostic provides readback of the channels’ present voltage & current.

This diagnostic is part of the Shim Supply Diagnostics that comprise the series of tests that verify & display various Shim Supply values by communicating from the SCP to the Shim Supply via the CAN link.

  1. Set the Test Duration to the number of seconds desired.

  2. Select the Read Current/Voltage radio button, then press the [Run] button.

  3. Examine the display results.

3  Components Tested

  • Shim Supply

  • Coil Channels

  • RTD Channels

4  Requirements

Software Configuration

  • Standard Software

  • CAN communications NOT emulated

Hardware Configuration

  • MGD Chassis: SCP, AGP, and APS Processor boards. Bridge board

  • Shim Supply, cabling, etc

6  Test Sequence

  1. The Operator selects the Read Current/Voltage radio button, then presses the [Run] button.

  2. The Diagnostic issues a command that instructs the Shim Supply to return the present voltage for each coil channel.

  3. The Diagnostic displays the results.

NOTE:The Shim Supply is first checked to ensure it is in the proper state. Commands to the Shim Supply are issued via the CAN interface on the SCP.

7  Expected Results

Input errors, Shim Supply State errors, and test condition errors are indicated in red.
