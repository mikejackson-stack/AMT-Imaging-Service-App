ReFlex AP Option Installation for EXCITE II

(Click Here to Return to Detailed Procedure)

  Safety

NOTICE
This option is only compatible for systems with an Excite II version System Cabinet.
 
 

NOTICE
EQUIPMENT DAMAGE POSSIBILITY. Electro Static Discharge (ESD) precautions must be used when removing the AP assembly or replacing any modules on the AP.
 
 

1  Procedure

1.1   Signa 11.x Options Installed by this Manual

  1. M3000RH - EXCITE II ReFlex 200B

  1. M3000RJ - EXCITE II ReFlex 400B

  1. M3000RK - EXCITE II ReFlex100B

1.2   Power Off Procedure

  1. Remove the System Cabinet front cover and open rear door.

  1. Turn off power switch at rear of MGD chassis. See Illustration 1.

    (Step Details)

1.3   Installation of ReFlex 200B

1.3.1  Set-Up of Master Slave Boards

  1. Rotary Switch SW2 is used to determine Master or Slave boards. See Illustration 2 for the location of SW2.

    (Step Details)

  1. The Master board must have SW2 set to 0 should be installed in slot 2.

  1. The Slave board must have SW2 set to 2 should be installed in slot 3.

1.3.2  Installation of Option

  1. Slots 2 and slot 3 will be used.

  1. See Illustration 3.

    (Step Details)

1.4   Installation of ReFlex400B

The ReFlex400B is made up of two boards with two daughter-cards on each board. There are no adjustments or jumper settings are necessary for the Reflex400B.

  1. Insert part number 2325947-12 (label 900-07072) into slot 2. See Illustration 3.

  1. Insert part number 2325947-13 (label 900-07071) into slot 3.

  1. Fasten in place with screws at top and bottom of front plate.

    (Step Details)

1.5   Installation of ReFlex100B

The ReFlex100B is made up of one motherboard.

  1. 2325947-11 (label 900-07063) must have SW2 set to 6 and should be installed in the slot 2. See Illustration 3 and Illustration 4.

    (Step Details)

  1. Fasten in place with screws at top and bottom of front plate.

1.6   Installation of PIM modules

NOTE:Some cabinets may already have PIM module installed. If the PIM is installed, proceed to Power On and TPS Reset.

NOTE:Use caution when inserting the PIM module. The backplane pins can be damaged if excessive force is used or if the PIM is not straight when being plugged in.

  1. Remove four faceplates from the rear of the MGD chassis. See Illustration 5.

    (Step Details)

  1. Install the PIM module onto the SC backplane between slots 2 and 3. See Illustration 5 and Illustration 6. The PIM modules allow communication between the Master and Slave boards.

    (Step Details)

  1. Re-install the four faceplates back onto the MGD chassis.

1.7   Power On and TPS Reset

  1. After installing the motherboard(s) and attaching the RACEway Adapter cables (only for the dual board configuration), power on the MGD chassis, then do a [TPS Reset].

  1. There is no need to modify the configuration file because the system software will autoconfigure the new board(s).

2  Finalization

  1. To verify the new installed hardware was configured by the system, use the Hardware Tracker (HART) software tool as follows:

    1. On the host computer, click the Service Desktop icon and (if not already open) start the MR Service Desktop by clicking the [Service Browser] button on the left side of the screen.

    1. Select the [Error Logs] tab.

    1. Select [HART logs].
