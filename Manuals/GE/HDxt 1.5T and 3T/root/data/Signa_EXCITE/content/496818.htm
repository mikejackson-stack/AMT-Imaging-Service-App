System Performance Test (SPT)

This document relates to Signa HD products and covers the System Performance Test, Full Test Mode procedure. The System Performance Test (SPT) provides a means of quickly verifying that all critical parameters that affect image quality are within specification. The data generated by SPT are useful for both local and global trending, and for additional automated interpretation by processes that are not part of SPT.

There are two SPT procedures to chose from based on the system configuration:

  • SPT Full Test Mode Procedure for 1.5T BRM and 1.5T or 3.0T TRM .

  • SPT Full Test Mode Procedure for CRM/3T94 Eclipse.
