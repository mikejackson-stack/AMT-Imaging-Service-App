1. Access the On Screen Manager OSMTM by pressing one of these buttons: + - < >

  2. Press <>> 3 times to select ”RGB” display.

  3. Press <Select / 1--2> button.

  4. Press <>> button to select option 1 (9300K for all monitor types except NEC1990sx. For the NEC 1990sx set to 5000K). (Monitor Color Temperature)

  5. Select the <Exit> button

NOTE:Manual Adjustment of the Position Control and Image Adjust H. Size/Fine controls is rarely needed. Automatic adjustment takes care of this.
