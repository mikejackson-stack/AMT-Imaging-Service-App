2  Procedure

2.1   Invoking SPT Full Test Mode

NOTICE
Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on [End Exam] to terminate any previous exam. It is not necessary to click on [New Pt] as SPT automatically enters the scan protocol when it is invoked via the MR Tools menu.
 
 

  1. To start the SPT Full Test tool from the Service Browser, follow the steps on Illustration 1 below.

    (Step Details)

  1. An SPT Test menu displays in a window on the desktop. Always use the Full Test Mode shown in Illustration 2.

    Illustration 2:  Field Engineer Test Selection - Example of Full Test Mode

    1. For Select All Tests?, click [No].

    1. To select a reason for the test, click the button (labeled None in above example) to the right of Test Purpose, and choose a reason from the list.

    1. If desired, type any appropriate text in the Comments field.

    1. For systems with a CRM Body Coil, select [Off] for Shimming in the Body section.

    1. Click the [On] button next to the appropriate test(s) to run.

    1. To select multiple passes of the test(s), select the [Multi Passes] button, and type the desired number of passes in the box that displays to the right.

    1. Click [Start SPT] to begin.

      (Step Details)

    1. If desired, click the [WhatFailed] button. An example of What Failed output can be found in Troubleshooting.

    (Step Details)

  1. To exit SPT, click the [Quit SPT] button.

  1. To view SPT results, select the Utilities tab on the Service Browser, then select [Report Manager].

  1. Enter the Report Manager password and press [Enter]. (For more information, see Report Manager Tool.)

  1. If appropriate, return to SPT for more selections.

3  Finalization

  1. Perform a TPS Reset after completing SPT to return the system to a normal working state.

  1. If for any reason an SPT scan is aborted, shut down and reboot the system.
