1  Procedure

1.1   Load Restricted Service (Only available for GE use.)

To load Restricted Service Software on the system:

  1. Place the appropriate Restricted Service CD-ROM in the host CD-ROM drive.

  1. Select [Load Restricted Service].

  1. Read the proprietary message window, and respond accordingly.

  1. A message “Restricted software load in progress…” will display. The load will take 5 to 10 minutes depending on host type.

  1. Illustration 1 will display near the end of the software load. GEMS Field Engineers loading GEMS Restricted Service Software should also configure InSite at this time (see Illustration 1). If you do not have an InSite modem or you will configure it later, click on [Exit].

  1. Refer to procedure “Insite/IIP Installation” to complete the Insite configuration on the Service Methods CD-ROM.

  1. Wait for the message “Restricted Service load done” in the Install GUI status bar (at bottom of window).

    (Step Details)

1.2   Load Advanced Service (Only for sites with a valid Advanced Service Package Limited License.)

To load Advanced Service Software on the system:

  1. Place the appropriate Advanced Service CD-ROM in the host CD-ROM drive.

  1. Select [Load Advanced Service].

  1. Read the proprietary message window, and respond accordingly.

  1. A message “Advance software load in progress…” will display. The load will take 5 to 10 minutes depending on host type.

  1. Wait for the message “Advanced Service load done” in the Install GUI status bar (at bottom of window).

  1. Return to Main Host Reconfiguration Procedure, or proceed to SaveInfo and Save your work.
