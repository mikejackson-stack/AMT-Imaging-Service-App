2  Procedure

2.1   Phantom Setup

  1. Starting LVShim Tool:

    1. The preferred method for accessing the LVShim tool is through the Calibration Wizard. The Restricted Service Key must be inserted. On the Service Desktop, start the Service Browser if not already running. Select [Calibration Wizard] from the Calibration Menu and select [Click here to start this tool]. Once the Calibration Wizard starts, select the required test from the menu, review and okay the pre & post-dependencies, and finally start the tool.

      (Step Details)

    1. On the Service Desktop, start the Service Browser if not already running. From the calibration menu and select [LVShim] and then click [Click here to start this tool].

  1. Remove the Head Coil and any phantoms from the cradle.

  1. Setup and align the LVShim Phantom per Illustration 1.

    (Step Details)

  1. Press <Advance to Scan>.

2.2   Main LVShim Scan Prescription

NOTE:On newly ramped magnets, after ramping the magnet, the cryocooler coldhead must be turned off for 10 minutes before installing shim currents. This is due to the magnetic flux buildup within a superconducting shield around the coldhead sleeve during magnet ramping.

NOTE:To reduce noise, prior to scanning, make sure the screen room door and any other screen room opening is closed tight.

  1. At the Host Computer, select the scan icon in the desktop control panel and set up LVShim scan as follows:

    (Step Details)

  1. Click [Autoprescan]. Make sure TG is between 130 and 160. Also Make sure X, Y and Z Gradshims are 0. If autoprescan fails, attempt manual prescan in Step 3. Otherwise, skip to Step 4.

  1. Click [Manual Prescan].

    (Step Details)

  1. When finished with prescan, click [Scan].

    (Step Details)

2.3   LVShim Analysis

NOTE:For the Class M (Restricted Service) service tool (i.e. when the service key is inserted), select [Calibration Wizard] from the calibration menu and select [Click here to start this tool]. Once the Calibration Wizard starts, select the required test from the menu, review and okay the pre & post-dependencies, and finally start the tool. If the service key is not available, start the tools as given in the next paragraph.

Select LVShim from the calibration menu on the common service desktop and then click [Click here to start this tool].

  1. At the Host Computer, go to the Service Desktop and open the Service Browser if it's not already running.

  1. Start the LVShim tool from the Service Browser as shown in Illustration 2.

    (Step Details)

  1. For TwinSpeed, highlight [WHOLE] and click [OK].

  1. The menu as shown in Illustration 3 should appear in a C-Shell window once the LVShim tool has been started:

    (Step Details)

  1. Change the following parts to calculate the next set of currents while performing Main LVShim:

    1. Shim Type should be set to the supercon shim set appropriate for the magnet type. Type 1<Enter> until the correct set is displayed.

    NOTE:Two selections are available for Supercon, Rough and Fine. The Calibration Wizard requires that Fine calibration be run and pass before the step is considered complete.

    1. Image Data should show the Exam, Series and the first Image number of the previously scanned LV Shim series. Type 2<Enter> and change if necessary.

    1. Operation Mode should be set to Service. Type 3<Enter> until this is listed correctly.

    1. Display Mag and Phase Diff Images should be set to No. Type 4<Enter> until this is listed correctly.

    1. The calibration file should list the correct configuration file to use. Type 5<Enter> to view possible filed.

    1. The existing current in each coil should match the currents set in each coil from the previous iteration (or the initial currents). Type 6<Enter> and modify the currents if necessary.

  1. Once the LV Shim Analysis tool is setup correctly via Step 5, type 0<Enter> to run the analysis.

  1. If image phase wrap was detected, the following message appears: “Excessive phase wrapping….Please re-scan at Wider Bandwidth or smaller test diameter”. If this occurs, return to Main LVShim Scan Prescription and re-scan and a greater bandwidth.

  1. A output should now be seen, an example is shown in Illustration 4 . Bandwidth, Exam, Series and Image # will match the LV Shim series under analysis.

    (Step Details)

  1. If “NaN” is displayed in the Harmonic Coefficient data, you should return to Main LVShim Scan Prescription and rescan. Make sure the TG value is between 130 and 160.

  1. Enter Comments as desired. Once comments are entered, the following is displayed (# of coils/options vary depending on magnet type). (see Illustration 5)

    (Step Details)

  1. Select coil set that you would like to use to improve magnet homogeneity. Refer to the correct magnet documentation for details on coil sets to use. Enter in the appropriate value.

  1. Once the shim current set is entered, each coil will be presented with Existing, Delta and New currents. See below for an example when the full 18 coils were chosen. (see Illustration 6)

    (Step Details)

  1. Record this data in the appropriate Data Sheet for your magnet.

  1. Compare this data to the LV Shim Specifications given in the tool. Make sure to verify the correct bandwidth was used in the initial scan. If the shim is within spec, you can reject these currents and exit the tool.

  1. You can modify or accept the new currents if you are outside of spec. These currents are saved in LV Shim as the actual currents. Use the magnet documentation on directions to burn in these currents as it varies between magnet type

  1. If you accepted the new currents, type Y<Enter> once the new currents have been burned into the coil, update the Data Sheets.

  1. Return to Main LVShim Scan Prescription and use the suggested bandwidth. Continue iterating Main LV Shim until the magnet meets specification.

    (Step Details)

3  Finalization

  1. Remove phantoms and equipment used during LVShim.

  1. Proceed to Gradient Shim.
