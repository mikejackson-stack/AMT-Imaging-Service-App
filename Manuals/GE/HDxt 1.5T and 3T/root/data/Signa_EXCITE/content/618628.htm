ICN Process Verification Diagnostic

1  Diagnostic Link

Diagnostics >> VRE Subsystem >> VRE Communication and Hardware Diagnostic

2  Purpose

The purpose of this diagnostic is to verify the correct number of processes is running on an ICN.

This diagnostic uses a configuration file that specifies the process name and the number of occurrences that should be running on the ICN.

3  Components Tested

Processes running on the ICN

4  Requirements

ICN is turned on and has a network connection to the Host.

6  Test Sequence

  • Execute Diagnostic.

  • Verify each ICN tested passed the diagnostic.
