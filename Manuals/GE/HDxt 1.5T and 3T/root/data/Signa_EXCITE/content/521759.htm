Power Supply Data Diagnostic

1  Diagnostic Link

Diagnostics >> Peripherals >> Driver Module Diagnostics

2  Purpose

This diagnostic reads the Power Supply information from the DCB board every five (5) seconds for the specified Test Duration (max 300 secs).

3  Components Tested

Driver Module

4  Test Sequence

This diagnostic reads the Power Supply information from the DCB board every five (5) seconds for the specified Test Duration (max 300 secs). The values are checked against the tolerances listed in the DcbConfig.cfg file.

5  Expected Results

Any failing values will be printed out in red. Passing values will be printed out in blue.

No error messages will be logged for failing power supplies since the Applications Code will be logging these errors automatically.
