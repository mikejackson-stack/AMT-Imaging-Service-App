2  Overview

Tests in this section verify that each power monitor is capable of shutting down the RF Amplifier independently of the other, and further verify both the logic and relay shutdowns for each channel. Set points are not checked in this section — this test is forcing a shutdown. When one or both of the monitors is in bypass mode, the HV relay shutdown is disabled.

4  Procedure

NOTICE
If the SSM has switch cover (5120058) installed, remove the cover before performing the procedure outlined below. The cover may prevent the power monitor switches from functioning properly.
 
 

  1. Enable power monitor A by placing the monitor A switch on the front panel of the SSM in the bottom Normal (down) position.

  1. At the operator workspace, prepare the system for an Amp Shutdown Verification scan using the "Service Protocols" procedure in Table 1 below. Refer to the body protocol in ALTERNATE EQUIPMENT SETUPS & NON-SERVICE PROTOCOLS for the non-proprietary protocol.

    NOTE:Verify that the Head Coil has been removed from the patient table before continuing.

    Table 1:  SCAN PRESCRIPTION - HIGH VOLTAGE RELAY SHUTDOWN — BODY MODE

    1. From the Rx MANAGER select, [New Series].At Patient Protocols – select other.
    2. Scroll through the list to the protocol [1.5T power monitor]Select [Series 3] for the Power Monitor Check protocol, and [Accept].[OK] (if required).
    3. [Save Series].
    4. [Research Operations].
    5. [Setup Params]. Set TG to 0. [Done].
    6. [Research Operations].
    7. [Display CVs]. Highlight CV Name and enter the following:CV name: trig<ENTER>, 1<ENTER>CV name: aset<ENTER>, 120<ENTER>
    8. CV name: calmode<ENTER>, 2<ENTER>
    9. CV name: pwset<ENTER>, 255<ENTER>
    10. CV name: dcset<ENTER>, 255<ENTER>
    11. CV name: p1<ENTER>, 3100<ENTER>
    12. CV name: p3<ENTER>, 2400<ENTER>
    13. [Accept]
    14. [Research Operations]
    15. [Download]
    16. Select [Manual Prescan].
    NOTE:The system error log will be checked in the next step for a power monitor fault error message. Make sure the error log Viewing Level selection is set to “ALL” before reading the error log. The error message may not otherwise be visible.

  1. Increase TG until monitor A FAULT LED illuminates. Quickly verify the following:

    • The FAULT LED on for monitor A (resets automatically after 1 second).

    • Software Message Log - Software will log a power monitor fault in the message log.

    • Verify oscilloscope or Wattmeter (press FWD PEP then MAX) reads zero RF power.

    NOTE:Do not perform any operations at the keyboard while In Place Error Recovery (IPER) is resetting the RF amplifier.

  1. While waiting for the system to recover, place monitor B in normal mode by placing the monitor B switch on the front panel of the SSM in the Normal (down) position. Now both monitors A and B should be in normal mode.

  1. After IPER has reset the RF amplifier (the “Please Press Start Scan Button” message appears in the upper left message window), decrease TG by 25 counts (2.5 dB) and then press [START SCAN] on the operator's console to initiate looping.

  1. Increase TG until the FAULT LED for monitor A or B illuminates. Quickly verify the following:

    • FAULT LED on for monitor A or B (resets automatically after two seconds).

    • Software Message Log - Software will log a power monitor fault in the message log.

    • Verify oscilloscope or Wattmeter (press FWD PEP then MAX) reads zero RF power.

    NOTE:Do not perform any operations at the keyboard while In Place Error Recovery (IPER) is resetting the RF amplifier.

  1. While waiting for the system to recover, disable power monitor A by placing the monitor A switch on the front panel of the SSM in the Bypass position.

  1. After IPER has reset the RF amplifier (the “Please Press Start Scan Button” message appears in the upper left message window), decrease TG by 25 counts (2.5 dB) and then press START SCAN on the operator's console to initiate looping.

  1. Increase TG until monitor B FAULT LED illuminates. Quickly verify the following:

    • FAULT LED on for monitor B (resets automatically after two seconds).

    • Software Message Log - Software will log a power monitor fault in the message log.

    • Verify oscilloscope or Wattmeter (press FWD PEP then MAX) reads zero RF power.

    NOTE:Do not perform any operations at keyboard while In Place Error Recovery (IPER) is resetting the RF amplifier.

  1. After IPER has reset the RF amplifier (the “Please Press Start Scan Button” message appears in the upper left message window), select [Done].

  1. In the Rx Manager, select [End Exam], then [Confirm].

  1. Proceed to SYSTEM RESTORATION.

5  Finalization

Re-install the SSM switch cover which was removed in Section 4, Procedure.
