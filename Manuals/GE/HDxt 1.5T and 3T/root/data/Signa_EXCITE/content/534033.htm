2  Overview

This tool reads and displays exam, series, and image headers. This can help provide information relating to complaints of artifacts or poor quality in Signa images. Frequently asked questions involve transmit gain, receive gain, power monitor, patient weight, critical scan parameters, gradient coil, etc. This tool also provides easy access to raw file header information, such as the "base" run number. This Run # is correct for single-scan image mode, but for multi-scan image mode, you must use the Raw File Manager tool to obtain the correct Run number for the desired image.

3  Procedure

  1. On the Service Browser, select the [Utilities] tab, then [Read Header], then [Start this tool] (see Illustration 1).

    Illustration 1:  Service Browser window

    The RDHD Main Menu is displayed: (See Illustration 2)

    Illustration 2:  RDHD Main Menu

  1. Select an Exam, Series, and Image. Type <A>, <B>, and <C> to directly enter the desired exam, series, and image number, or type <D>, <E>, and <F> to list/select each one.

    If you select an Exam, you will be prompted to select one of the exam's Series, and then to select one of the series' images. Once an Exam, Series, and Image has been properly selected, there will be a reference number for each of these above the RDHD Main Menu.

  1. After entering the exam, series, and image number, type <G><Enter> to go to the Display Header menu. See Illustration 3

    Illustration 3:  Display Header Menu

  1. Select <A> to <W> to display the desired header information. Select <X> for all header information. Select <Q><Enter> to quit.

    NOTE:Item A ~ W are dicom standard modules. Item M ~ W are GE private modules.
