Stopping and Starting UTNS3

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable5 minsNot Applicable

2  Overview

If the system is equipped with a UTNS3 (This does not apply to UTNS or UTNS2.) See Step  for procedure to stop the UTNS3 and then Step  for turning the UNTS3 back on.

3  Procedure

3.1  Stopping the UTNS 3 Via Software

  1. On the Common Service Desktop go to the Utilities Tab and start [TNS Software Control]. See Illustration 1.

    Illustration 1:  Starting TNS Tools

  1. Once the mgd_script page opens, at the command line type: mgd_tns -b m=a 0<Enter> to turn off the UNTS3. See Illustration 2.

    Illustration 2:  Command Line to Stop UTNS3

  1. You’ll see the Notching Write successful if the shut down was successful. See Illustration 3

    Illustration 3:  Notching Write Successful Statement

  1. Leave the window open. Closing the window will enable the UTNS3 again.

3.2  Enabling the UTNS3 Via Software

  1. On the Common Service Desktop go to the Utilities Tab and start [TNS Software Control]. See Illustration 1.

  1. Once the mgd_script page opens, at the command line type: mgd_tns -b m=a 1<Enter> to turn on the UNTS3. See Illustration 4.

    Illustration 4:  Starting The UTNS3

  1. If successful you will see notching will be enabled for all channels. See Illustration 5.

    Illustration 5:  Successful UTNS3

  1. Select q to exit from the window.

4  Finalization

No finalization steps.
