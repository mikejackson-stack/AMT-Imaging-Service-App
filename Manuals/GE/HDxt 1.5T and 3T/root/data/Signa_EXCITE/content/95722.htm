Signa System-In-Spec Key Installation

Service scanning and calibration can be done without the key. The key is generated from the executable software resident on the system. After all the system calibrations and test scans have successfully completed, the FE will start an executable script that in turn runs a System Health that confirms that certain critical system calibrations and test results are within specification. Once the key has been generated it can then be saved during the next SaveINFO process. The next time a software reload is done it will be restored when a RestoreINFO is performed. It should not be necessary in the future to repeat this process to generate the key again as long as a valid RestoreINFO is performed.

The key will be generated only after all calibrations and test scans have successfully completed.
