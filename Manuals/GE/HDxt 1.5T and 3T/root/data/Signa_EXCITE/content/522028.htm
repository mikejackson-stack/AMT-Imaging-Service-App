SRI XRam Test

1  Diagnostic Link

Diagnostics >> Peripherals >> SRI Functional Tests

2  Purpose

This test runs a memory test on the XRAM memory internal to the SRI.

3  Components Tested

4  Requirements

5  Block Diagram

6  Test Sequence

The SCP causes the SRI to run a memory test on the XRAM memory internal to the SRI. When the SRI completes the test it will send a Pass/Fail result back to the SCP.

Since this test changes the contents of the Control Block on the SRI, the SRI code is re-downloaded to the SRI from the SCP after the test is completed. The download process takes about 15 seconds.

7  Expected Results

Pass/Fail result

NO-RESPONSE type error 

Use the SRI STIF LoopBack test to determine if the problem is in the SRI module or the fiber optic connections.
