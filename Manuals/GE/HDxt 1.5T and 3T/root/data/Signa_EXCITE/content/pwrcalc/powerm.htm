POWER CALCULATOR
The following tool can be used to determine Power in watts from oscilloscope measured Vpeak, or to determine a Vpeak measurement when the desired power output is known. These formulae are to be used when:
  •  Not using the RF Power Measurement Kit 
  •  The Dummy Load & Cable Attenuation Factor has accurately been determined
  •  The Scope Correction Factor for the oscilloscope being used is known

Fill in the required data in the gray shaded area, push the [Calculate] button to view the answer.

RF Kit Calibration Verification 
RF Kit Calibration Verification can be done by determining the attenuation between the RF source and the scope by using the Dummy Load and Cable Calibration procedure. After you have determined the "Magnitude of Squared Attenuation Factor" of the elements under test, enter the "Magnitude Squared Attenuation Factor" value into the shaded cell below and push the [Calculate] button to the right to read the dB attenuation. The dB should be very close to the value stated on the Reference Card.
