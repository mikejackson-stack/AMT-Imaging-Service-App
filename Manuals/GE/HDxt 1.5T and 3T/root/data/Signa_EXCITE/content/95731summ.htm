Generating System in Spec Authentication Key

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Confirm that the software is booted and that the applications software is running.

  1. On the service desktop open a C-shell window.

    (Step Details)

  1. In the C-shell window, type: cd /usr/local/bin and press <Enter>.

  1. In the C-shell window, type: install_in_spec and press <Enter>.

  1. The System Health will start, and information similar to Illustration 2 displays for about 30 seconds.

    (Step Details)

  1. After about 30 seconds System Health results will be displayed. Illustration 3 is example Install In Spec output data from a system that is passing all of its calibration, configuration and performance checks.

    (Step Details)

  1. Failures, like those shown in Illustration 4, must be corrected and Step 3 through Step 5 repeated until the displayed results indicate that all parameters passed and the key was generated.

    (Step Details)

  1. Perform a SaveINFO once Install In Spec indicates the system can be turned over for clinical scanning. (This will save the key to the SaveINFO MOD so that it will not be necessary to generate it again in the future.)

  1. If unable to generate a key, see Troubleshooting Guidelines.
