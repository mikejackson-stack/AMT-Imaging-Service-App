T File Cleanup

  1. To access T File Cleanup, click on the [Service Desktop] icon.

  2. If it is not already running, start the Service Browser.

  3. Click the [Utilities] tab.

  4. Under Toolbox, select [T File Cleanup].

  5. Select <Click here to start this tool>. See Illustration 1.
