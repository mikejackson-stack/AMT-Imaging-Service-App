Host Load from Cold for Linux Computer

This document describes the flow to perform a Load-from-Cold (LFC) on the Signa Linux PC.

NOTICE
Do not attempt to shortcut the LFC process. Doing so will add time to the process as the load will have to be starred at the beginning a second time to successfully complete the process.
 
 

Required media:

  • PC Linux Operating System CD-ROM

  • MR Applications CD-ROM

  • Two SaveInfo MaxOptic MOD media (either blank or previously used)

Optional:

  • MR Restricted Service CD-ROM (GE Service only)

  • MR Advanced Service CD-ROM (licensed in-house customers)

    NOTE:No other material is required.

    Refer to Table 1 for the LFC procedure and Table 2 for LFC support documents.

Table 1:  LFC Process

  1. Backup the System before Starting a Load from Cold.
  2. Operating System Load.
  3. MR Applications Load
  4. Set Time/Date Tab.
  5. Perform the setup and calibration for the monitor used at this site. Host LCD Monitor Setup and Cal.
  6. Load Loading or Deleting Proprietary Software.

Table 2:  LFC Support Documents

Configuring Mouse for Permanent Left-Handed Use.
