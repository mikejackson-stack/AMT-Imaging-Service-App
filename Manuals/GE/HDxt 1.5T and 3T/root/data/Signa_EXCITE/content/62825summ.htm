Table Top Height Adjustment

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Dock Patient Transport.

  1. Pump table top to fully raised position.

  1. Use a small screwdriver and carefully remove cover plug on table top. See Illustration 1.

    (Step Details)

  1. Adjust screw in table top to set table top height equal to bridge height.

  1. Replace cover plug.
