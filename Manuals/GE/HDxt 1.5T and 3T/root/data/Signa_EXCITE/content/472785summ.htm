1  Procedure

1.1   Scan Prep and Scan

  1. Phantom Setup:

    1. Remove the Quad head Coil from the cradle and remove any other phantoms from the bore.

    1. Setup and align the LVShim phantom per Illustration 1. Landmark with markings on top of the LVShim Phantom.

      (Step Details)

    1. Press <Advance to Scan>.

  1. At the operator workspace, select the scan icon in the desktop control panel and set up LVShim scan as follows:

    (Step Details)

  1. Click <Auto Prescan>. Make sure TG is between 130 and 160. If Auto Prescan fails, attempt Step 4, otherwise skip to Step 6.

  1. [Click Manual Prescan]

    (Step Details)

  1. Click [Done] to exit Manual Prescan.

  1. When finished with prescan, Click [Scan].

    (Step Details)

1.2   Rough Shim Analysis

  1. Start the LVShim tool.

    1. The preferred method for accessing the LVShim tool is through the Calibration Wizard. The Restricted Service Key must be inserted. On the Service Desktop, start the Service Browser if not already running. Select [Calibration Wizard] from the Calibration Menu and select [Click here to start this tool]. Once the Calibration Wizard starts, select the required test from the menu, review and okay the pre & post-dependencies, and finally start the tool.

      (Step Details)

    1. On the Service Desktop, start the Service Browser if not already running. From the calibration menu, select [LVShim] and then click [Click here to start this tool].

  1. For TwinSpeed, highlight Whole and click OK. Proceed as follows.

  1. The menu shown in Illustration 2 should appear in a c-shell window once the LV-Shim tool has been started.

    (Step Details)

  1. Change the following parts to calculate the next set of currents while performing Rough LV Shim

    1. Shim Type should be set to the supercon shim set appropriate for the magnet type. Type 1<Enter> until the correct set is displayed. Example shows Sup18.1.5T.

    1. Image Data should show the Exam, Series and the first Image number of the previously scanned LV Shim series. Type 2<Enter> and change if necessary.

    1. Operation Mode should be set to Service. Type 3<Enter> until this is listed correctly.

    1. Display Mag and Phase Diff Images should be set to No. Type 4<Enter> until this is listed correctly.

    1. The calibration file should list the correct configuration file to use. Type 5<Enter> to view possible files. You can view detailed information on these files in the LVShim Software document.

    1. The existing current in each coil should match the currents set in each coil from the previous iteration (or the initial currents). Type 6<Enter> and modify the currents if necessary.

  1. Once the LV Shim Analysis tool is setup correctly as shown in Step 4, type 0<Enter> to run the analysis.

  1. If image phase wrap was detected, the following message appears: “Excessive phase wrapping….Please re-scan at Wider Bandwidth or smaller test diameter”. If this occurs, return to Scan Prep and Scan and rescan and a greater bandwidth.

  1. An output similar to what is as shown in Illustration 3 should appear (Bandwidth, Exam, Series and Image # will match the LV Shim series under analysis and # of coils vary depending on magnet type):

    (Step Details)

  1. If “NaN” is displayed in the Harmonic Coefficient data, you should return to Scan Prep and Scan and rescan. Make sure the TG value is between 130 and 160.

  1. Enter Comments as desired. Once comments are entered, the out put as shown in Illustration 4 will displayed (# of coils/options vary depending on magnet type):

    (Step Details)

  1. Select coil set that you would like to use to improve magnet homogeneity. Refer to the correct magnet documentation for details on coil sets to use. Enter in the appropriate value.

  1. Once the shim current set is entered, each coil will be presented with Existing, Delta and New currents. See Illustration 5 for an example when the full 18 coils were chosen.

    (Step Details)

  1. You are given the option to select a different coil set, if you do, return to Step 10. Otherwise, you can modify, reject or accept the new currents. If you reject the currents, you do not have to enter any current in the magnet and the previous currents are saved in LV Shim as the actual currents. If you modify and/or accept and install the new currents, then these currents are saved in LV Shim as the actual currents. Use the magnet documentation on directions to burn in these currents as it varies between magnet types.

  1. If the currents were rejected because the Rough Shim is complete, then exit LV shim by typing N<Enter> when prompted to run LV Shim Again.

  1. If you accepted the new currents, type Y<Enter> once the new currents have been burned into the coil to continue run LV Shim again.

  1. Return to Scan Prep and Scan and use the suggested bandwidth. Continue iterating Rough Shim until the suggested bandwidth is equal to or less than 1000Hz and the DSV analyzed is 45 cm for BRM/TRM or 40cm for CRM.
