Viewing SPT Results and Calibration Files

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Viewing Results - Report Manager Tool

After SPT has finished the analysis, the data files can be viewed using the Report Manager Tool. The specification files can also be viewed to compare the results against the specifications.

  1. To view SPT results, follow the steps on Illustration 1 to open the Report Manager.

    (Step Details)

  1. When prompted for a password, enter the same password used for the Service Methods CD-ROM. Press [Enter].

    (Step Details)

  1. To view an SPT report, first make sure the File Type is SPT. (If it is not, click the button following “File Type” and select SPT from the list.)

  1. Select the report you’d like to view, then click [OK].

    (Step Details)

  1. To print a report, select [File], then [Print] from the Report Manager menu.

  1. To view another report, select [File], then [Open]. Select the report from the list, then click [OK].

    (Step Details)

1.2   Viewing the Specification Files

The specification files can be viewed using the more command, or the xedit editor. For definitions of each specification file, go to , SPT Specification File Definition. For TwinSpeed, refer to the file with a GradMode extension, hence as cal.spt.WHOLE and cal.spt.ZOOM, rather than the original file cal.spt.

NOTE:The specification file contents change based on whether the user selected the old or new head coil at the start of SPT. The file names do not change. Use any one of the three methods below to view the file contents

  1. More Method

    1. On the Service Desktop, click on [C Shel]l.

    1. View the specification files. Type: cd /usr/g/service/cclass/spt and press <Enter>.

    1. To view the specification file of interest, type <more filename>. Press <Enter>. Use the filenames from Table 1

  1. xedit Method

    1. On the Service Desktop, click on [C Shell]. Type: cd /usr/g/service/cclass/spt and press <Enter>.

    1. Type xedit and press <Enter>. A xedit window will appear on the desktop.

    1. Select Open from the File pull-down menu. Select the specification file of interest from the browser list, and click on [Accept]. Refer to the file list from Table 1.

    1. To exit xedit, select File, then Exit.
