1  Procedure

1.1   Phantom Setup

  1. The preferred method for accessing the LVShim tool is through the Calibration Wizard. The Restricted Service Key must be inserted. To start LVShim tool:

    1. On the Service Desktop, start the Service Browser if not already running.

      1. Select [Calibration Wizard] from the Calibration menu, and Click here to start this tool.

      1. Once the Calibration Wizard is accessed, select the required test from the menu, review and okay the pre and post-dependencies, and finally start the tool.

      (Step Details)

    1. On the Service Desktop, start the Service Browser if not already running. From the Calibration menu, select [LVShim] and Click here to start this tool.

  1. Remove the Head Coil and any phantom from the cradle.

  1. Set up and align the LVShim Phantom per Illustration 1.

    (Step Details)

1.2   Gradient LVShim Scan Prescription

  1. At the Host Computer, prepare the system for scanning as follows:

    1. Select [New Pt].

    1. For ID, type: geservice, <Enter>.

    1. For Name, type: lvshim.

    1. For Weight (lb), type: 300, < Enter>.

    1. Set Patient Protocols to Service.

    1. At the front enclosure, press <LANDMARK>, then <MOVE TO SCAN>.

    1. Under Patient Protocols, select [Service], then [Other].

    1. Find and click on the Protocol for LVShim, then click on the Series to be used.

    1. Click [Accept] to download the Series.

    1. In Additional Parameters, click [User CVs Screen].

      (Step Details)

    1. Click [Save Series].

  1. Click [Auto Prescan]. Make sure Transmit Gain (TG) is between 130 and 160, and record the Gradient Shim current value.

    1. If Auto Prescan fails, proceed to Step 3, Manual Prescan.

    1. Otherwise, proceed to Step 5.

  1. Click [Manual Prescan].

    1. While in the Center Freq. Fine (CFH) mode, center the frequency peak in the display as necessary. After locating the best signal, open the Frequency menu at the top of Manual Prescan window, and select Save Frequency to save the new center frequency.

    1. Click [Transmit Gain (TG)], open the Markers menu at the top of the Manual Prescan window, and select Horizontal Hairline. Adjust TG for the highest value (should be between 130 to 160).

      (Step Details)

    1. Select Scan TR (R1/R2). Verify that R1 and R2 are not outside of the range. Adjust R1 and R2 for approximately 50%.

  1. Click [Done] to exit the Manual Prescan.

  1. When finished with Manual Prescan, click [Scan].

    (Step Details)

1.3   Gradient LVShim Analysis

  1. At the Host Computer, open the Service Browser (if not already running) from the Service Desktop.

  1. Start the LVShim tool as shown in Illustration 2.

    (Step Details)

  1. Focus on the LVShim tool main menu that displays (example shown in Illustration 3).

    (Step Details)

  1. Once the LVShim parameters above are set up correctly, type 0<Enter> to run the analysis.

  1. If image phase wrap was detected, the following message displays: Excessive phase wrapping….Please re-scan at Wider Bandwidth or smaller test diameter. If this occurs, return to Gradient LVShim Scan Prescription and rescan at a greater bandwidth.

  1. Check the output that opens in a C-shell. (See Illustration 4 for an example.)

    (Step Details)

  1. If NaN displays in the Harmonic Coefficient data, return to Gradient LVShim Scan Prescription, make sure the TG value is between 130 and 150 and rescan.

  1. Enter Comments as desired. Once comments are entered, the following displays:

    (Step Details)

  1. Record this data on the appropriate Data Sheet.

  1. Compare this data to the appropriate LVShim specifications for the site's magnet. Keep iterating until no noticeable shim improvement is observed.

  1. If accepting the new grad shim values, type y, <Enter>.

    1. Return to Gradient LVShim Scan Prescription and rescan. (The new currents are automatically entered into the gradient amplifiers by the software.)

    1. Update the Data Sheets.

2  Finalization

  1. Remove any phantoms and or tool used during LVShim.

  1. Perform a [TPS Reset].

  1. Do a head or body test scan before turning the system over to the customer.
