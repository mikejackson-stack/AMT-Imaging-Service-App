2  Procedure

2.1   Instructions for Software Release Pre-15.0_M4B, 20.x, and 21.x

2.1.1  Procedure for Network Printer

  1. Log out by clicking on [System Restart] then [OK]. The system will then reboot.

  1. When the login screen appears, login as root password is operator. Place cursor in the background, and “right click” on the mouse.

  1. Select Configure Printer option. The following GUI will display (shown below).

    (Step Details)

  1. Click [New] to add printer to the system. See Illustration 1. A new window will appear (see Illustration 2). Click [Forward] to continue.

    Illustration 2:  Add a New Print Queue

  1. At the Queue name screen, type a name for the printer (shown below). After entering the name, click [Forward] to continuė.

    Illustration 3:  Queue Name

  1. Select Queue type as Networked Unix (LPD) (shown below).

    (Step Details)

  1. Select the printer type (shown below). Then select [Forward].

    (Step Details)

  1. Click [Finish] to complete printer installation.

2.1.2  Procedure for Local Printer

  1. Connect local printer to the parallel port in the rear of the Linux PC.

  1. Log out by clicking on [System Restart] then [OK]. The system will then reboot.

  1. When the login screen appears, login as root password is operator.

  1. Place cursor in the background, and “right click” the mouse.

  1. Select Configure Printer option. The GUI shown in Illustration 6 will start.

    (Step Details)

  1. Click [New]. A GUI will display, see Illustration 2.

  1. Click [Forward]. Then enter printer name if needed and short description (see Illustration 3). Click [Forward] again.

  1. The “Queue Type” will now appear. If the printer is recognized by the system, it will display (shown below).

    Illustration 7:  Add New Print Queue Screen

  1. Verify that “Locally-connected” option on top is selected. Click [Forward].

  1. Verify that the proper printer model is selected. Click [Forward].

  1. If the system does not recognize the printer that is connected, select Printer Manufacturer and Model from the top screen (shown below). Then select the exact printer and click [Forward].

    (Step Details)

  1. Click [Finish]. The printer is now selected. If needed, print a test page.

2.2   Instructions for Software Release 15.x at/higher than 15.0_M4B and 22.x and Higher

2.2.1  Procedure for Network Printer

  1. Reboot the system.

  1. When the login screen displays, login as root and password is operator.

  1. Place the cursor in the background, and right click the mouse.

  1. Select the Configure Printer option, and the following GUI will display (shown below).

    (Step Details)

  1. Click [Add] to add the printer to the system (shown above). If selecting a printer for the first time, a pop-up will display (shown below). Click [OK] to continue.

    (Step Details)

  1. On the Add New Printer Configuration screen, click [Connection Wizard] (shown below). The GUI in Illustration 12 will display.

    (Step Details)

  1. Under the Access Network Printer or Printerserver Box via label, select Line Printer Daemon (LPD) Protocol (shown below). Fill in the printer IP Address, printer name, and select the manufacturer (shown below).

    (Step Details)

  1. Click [Test Connection], which will verify that the IP address entered is valid for the site network.

  1. Click [OK].

  1. The system will search for printer drivers. Select the appropriate driver (shown below) and click [OK] to return to the Printer Configuration GUI.

    (Step Details)

  1. Print a test page to ensure that the printer has been configured correctly.

  1. Click [OK] to exit the Printer Configuration GUI.

2.2.2  Procedure for Local Printer

NOTE:Only USB connected printers are supported.

  1. Connect local printer to the USB port on the Linux PC.

  1. Reboot the system.

  1. When the login screen displays, login as root and password is operator.

  1. Place the cursor in the background, and right click the mouse.

  1. Select the Configure Printer option, and the following GUI will display (see Illustration 9).

  1. Click [Add] to add the printer to the system (see Illustration 9).

  1. The directly connected printer will be automatically recognized, as evident by two popup process bars (shown below).

    (Step Details)

  1. Click [OK] to accept detected printer and return to the Printer Configuration GUI.

  1. Print a test page to ensure that the printer has been configured correctly.

  1. Click [OK] to exit the Printer Configuration GUI.
