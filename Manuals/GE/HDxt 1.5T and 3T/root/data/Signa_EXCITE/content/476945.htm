Terminal Server Comm Help

1  Diagnostic Link

Diagnostics >> Host >> Terminal Server Diagnostic >> Communications

2  Purpose

The Terminal Server Communications Functional Diagnostic verifies the Terminal Server’s related configuration files, processes, and communications.

This diagnostic performs a number of O/S level checks to verify Terminal Server communications.

3  Components Tested

The following aspects of the Terminal Server can be tested:

  • Terminal Server Configuration on the Host

  • Terminal Server processes running on the host

  • Terminal Server Hardware

  • Interconnects between the host and terminal server

4  Requirements

The minimum hardware configuration requires the Host computer, Terminal Server, and appropriate interconnects.

6  Test Sequence

  1. Select the diagnostic.

  2. Click [Run].

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.
