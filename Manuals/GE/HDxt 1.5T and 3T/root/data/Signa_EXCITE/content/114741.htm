(Non-Staged) Signa EXCITE 3.0T Installation Calibration Flow

This flow process represents the steps necessary to calibrate a new installation of a Signa EXCITE 3.0T System that was not pre-staged by GE Healthcare. Complete all steps in order. Print this page and check off each procedure as it is completed to ensure no steps are missed. Save the final copy for record keeping.
