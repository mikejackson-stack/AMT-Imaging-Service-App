TR Map

TRMAP is designed to allow the user to quantify the effects of transmit/receive coil coupling in both transmit and receive mode, transverse magnetic field (B1) homogeneity/penetration versus coil design and patient loading, and spatial variation in receive sensitivity profile. This is accomplished by acquiring scans at varying transmit gain (TG) values with all other parameters fixed. The TG values are symmetric about the nominal transmit level (most commonly determined by the SIGNA auto prescan routine). The transmit B1 altered intensities are then filtered and fit to expressions for transmit and receive dependencies to determine the optimal transmit level and maximum achievable intensity on a per voxel basis. Image plane space maps of optimal transmit level, flip angle, corrected image intensity and normal image subtracted from the corrected image are then created at each slice location of interest. TRMAP allows the user to gauge the performance of the coil. See TRMAP Theory for a description of the theory of TRMAP. This tool currently only supports the body and head coils. Surface coils are not supported.
