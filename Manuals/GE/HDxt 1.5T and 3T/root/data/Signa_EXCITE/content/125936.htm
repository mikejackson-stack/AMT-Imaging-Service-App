Signa HDxt Service Methods
Module Version  1.0,  Version Date  5/3/07

System Power On

  1. Notify field service and other installation personnel that are working at the installation site that the PDU main disconnect locks and tags will be removed so that PDU power can be turned on.

  2. Restore power to the PDU from the main disconnect.

  3. Press FULL ON button on the PDU front control panel.

  4. Except for ACGD Gradient Cabinet power modules, switch all cabinet circuit breaker to ON. The ACGD Power module circuit breakers should remain OFF until room humidity stabilizes under 60%.
