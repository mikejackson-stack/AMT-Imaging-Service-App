  1. The prescan and scan will be done automatically. No user scan setup is required. The scan will take a few minutes to complete. If problems exist with Auto-Prescan section of HSS (where Analog Gain [R1] ~ 1, Digital Gain [R2] ~ 14, and TG ~ 70 to 130), change the attenuation on the attenuator and run HSS tool again.

  1. If the problem with the Auto-Prescan persists, manually load HSS protocol by following this procedure:

    1. Go into the scan desktop.

    1. Set up for scan using geservice as Patient ID.

    1. Select [Service] protocols.

    1. Select [Other], scroll down and select [HSS] protocol. Highlight the [HSS] protocol, then click on [Accept].

    1. Select [Save Series].

    1. Right-click on [Research Options], then select [Display CV's]. By CV name, type rfamp_type, and change the Current Value to 2 (or head mode). Then click on [Accept].

    1. Right-click on [Research Options], then select [Download].

    1. Select [Manual Prescan]. The receive signal will be a flat line. Value for R1 should be between 30 and 100. Values for R2 should be between 20 and 60.

    1. If values for R1 and R2 are close to zero, there are issues with the setup. Fix any issue, and verify that proper signal is received prior to proceeding with HSS.

    1. Verify that Transmit Gain (TG) is properly set by selecting [Scan TR] in the Manual Prescan page and decreasing/increasing the TG until maximum signal (R1 and R2 value) is achieved.

    1. If issues persist, remove the HSS phantom and the attenuation that is in series with the RF amp and connect the head coil. Set up the HSS protocol as noted above. Perform Auto Prescan. Nominal values are noted below.

2  Finalization

  1. Restore the connections at the back of the RF cabinet (refer to Step  initial setup).

  1. Remove all SST Coil hardware (coil, test cables, etc.) from the bore.

  1. Place TR Driver switch on the Driver Module back to Enable position.

  1. HSS creates extensive locked raw files that must be removed to restore locked raw file capacity. Follow the steps on the graphic below:

    (Step Details)

  1. Under the DISK heading, highlight the HSS files, and click on [Delete].

  1. Perform at least one head scan to verify proper system operation. For TwinSpeed, repeat for each gradient mode.
