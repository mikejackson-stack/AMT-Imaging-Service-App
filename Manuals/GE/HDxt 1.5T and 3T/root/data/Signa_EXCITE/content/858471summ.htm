2  Procedure

2.1   Download a Software Patch

  1. Create a directory on your desktop for the patch download. The patches MUST end up in directory called dist. Create a folder with the software revision, for example: 91.29I_M4_0311 .b then a sub-directory called dist. See Illustration 1.

    (Step Details)

  1. Go online and log into the following URL:

    (Step Details)

  1. Under the Projects heading, select the software revision patch needed.

  1. Select all the files for the needed revision. Make sure that both the Readme Files and Download Files are downloaded to the newly created directory on the laptop.

2.2   Patch CD-ROM Creation

NOTE:Sonic™ RecordNow! Plus must be loaded on the laptop, if not, load it from the D610 Laptop Supplemental disk provided with the laptop deployment

  1. Place a blank CD-ROM in the CD-ROM drive of the laptop.

  1. Once the laptop recognizes a blank CD-ROM, Sonic™ RecordNow! Plus program should launch automatically. If it does not, access the software application as follows:

    1. Select [Start].

    1. Select Programs => Sonic =>RecordNow! Plus => RecordNow! Plus. See Illustration 2.

      (Step Details)

  1. The main screen will display. See Illustration 3.

    (Step Details)

  1. Select the Wrench on the upper right side of the screen. See Illustration 3.

  1. This will display the Options screen. Select Data on the left side and make sure the settings are the same as shown in Illustration 4.

    (Step Details)

  1. Under Data, select Advanced. See Illustration 5.

    (Step Details)

  1. Make sure that Type: and File System is set as listed above (Illustration 5).

  1. Click [OK].

  1. Select Data Disk as shown in Illustration 6.

    (Step Details)

  1. The Data Disc screen will display. See Illustration 7.

    (Step Details)

  1. Click on the words, Volume Label and type in the Patch revision information, so it is similar to what is shown in Illustration 8.

    (Step Details)

  1. In the Explorer window, select the dist directory created in Download a Software Patch, Step 1, drag it into the window shown in Illustration 7.

  1. Click the button.

  1. Once completed eject the disk and label with a Sharpie (Felt Tip) marker.

  1. Continue with patch installation on the system host using the Install GUI.
