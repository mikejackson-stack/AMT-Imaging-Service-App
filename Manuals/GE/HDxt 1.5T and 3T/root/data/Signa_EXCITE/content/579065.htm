Hardware Link Devices Status Check

This material covers checking the status of the Hardware Link devices, including the use of the hwStatus command. On occasion, it is helpful to know the status of the peripheral devices. The Serial Peripheral Interface (SPI), which is located on the Scan Control Processor (SCP) Board, reports the status of each peripheral device on the MDS Link.

Sometimes, when there is a fault on the MDS Link or CAN link, the LEDs on the hardware peripheral devices do not match the state reported by SPI. This is when the hwStatus command is useful. It can check the SPI view of the state of the hardware. For example, if the scanner will not go to Ready, and it is not obvious what is causing the problem, the command can help you locate the cause of the problem.

It is most helpful to use the error log in conjunction with the hwStatus command. Step  describes how to execute this command.

NOTE:The hwStatus command cannot be used to change the state or status of any piece of hardware on the MDS Link or CAN link. It is used only for reporting what the SPI thinks the state of the MDS peripheral devices are.

1  USING THE HWSTATUS COMMAND

  1. Insert the Service Key.

  2. Click the (Service Tools) icon to open the Service Desktop Manager.

  3. Click in the lower part of the Service Desktop Manager if the Common Service Desktop is not already visible.

    NOTE:It takes a few seconds for the Common Service Desktop to appear. If the Common Service Desktop never appears, then confirm that it isn’t already open and that it hasn’t been dragged partially off the screen or that it isn’t hidden behind another open window.

  4. Click the (Utilities) icon at the top of the Common Service Desktop.

  5. Select [Log Into APS/AGP/SCP] from the menu on the left side of the screen.

  6. Under Log Into APS/AGP/SCP window on the right side of the screen, select <Click here to start this tool>. The SCP window opens in front of the APS and AGP windows.

  7. Place the cursor inside the SCP window and press <Enter> once so that a prompt displays inside the window.

  8. Type <hwStatus><Enter> in the SCP window as shown in Illustration 1.

2  System Restoration

  1. Close the SCP, AGP, and APS windows when done.

  2. Perform a head or body scan to ensure system functionality.
