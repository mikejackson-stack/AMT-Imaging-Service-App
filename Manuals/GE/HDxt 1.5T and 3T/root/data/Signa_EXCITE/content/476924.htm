Spectro RF Amp

1  Diagnostic Link

Diagnostics >> Peripherals >> SSM Diagnostics

2  Purpose

This diagnostic confirms that the SCP can access the Spectro RF Amp control registers on the SSM-CPD.

3  Components Tested

This test does not test the actual Spectro Rf amp - just its control registers on the SSM-CPD.

4  Requirements

This test does not require the presence of a Spectro RF Amp.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.
