ICN Monitor Display

1  Diagnostics Link

Diagnostics >> VRE Subsystem >> ICN Monitor Display

2  Test Sequence

  1. Select tests.

  2. Click [Run].

    NOTE:Once you click [Run], do not click anywhere else in the Common Service Desktop until the test is completed. If you need to abort the test prior to its completion, you must click [Stop].

3  Expected Results

Output values are judged pass or fail, and the details of the test are displayed in the Test Results field.

In the event of a failure, the values are colored red and time of last failure is displayed.

NOTE:This test checks all the records in sensor log files. So, if the test fails, pay attention to the last failed date/time and check the failure actually came from the issue of ICN itself.
