2  Overview

This document contains possible error messages and faults due to the 35 kW MKS Narrowband Amplifier. It is not an exhaustive list of possible faults due to the MKS Amplifier.

3  Procedure

  1. In many cases, problems with the MKS will display as faults in the system error log. The table below contains the fault numbers, a description of each fault, the recommended action and the replacement parts to overcome the fault if applicable.

  1. Set up to test MKS RF Amplifier diagnostics by selecting [Diagnostics], Peripherals folder, and RF Amp Diagnostic. A screen shot of the diagnostic is shown in Illustration 1.

    Illustration 1:  Starting RF Amp Diagnostic Test

    Click [Run] when ready to start testing.
