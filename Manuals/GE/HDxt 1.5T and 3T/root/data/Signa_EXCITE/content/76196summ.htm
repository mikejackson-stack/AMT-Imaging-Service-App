PAC Voltage Configuration

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

The SSM High Voltage (HV) Board jumper, JP1, must be set to either the 1000V position for 1.5T or 500V position for 1.0T systems. This high voltage bias is for the Body 1 and Body 2 Dynamic Disable Circuits in the RF body coil and the Direct Drive Circuitry (DD) in the body hybrid splitter. Jumper JP1 should come preset for all new installations and should not require changing. If the HV board ever fails, however, and is replaced, the position of this jumper on the new board should be checked before it is installed.

2  Procedure

2.1   Via the Software (Alternate Proprietary GE Procedure)

NOTE:The alternate proprietary GE procedure via the laptop software does not work properly for setting the PAC voltage, but can be used to verify the current PAC voltage setting. The following steps describe the PAC voltage setting verification procedure. To change settings use Via the Front Panel Switches via the Front Panel Switches.

  1. Connect the laptop to J46 Serial Port of the SSM via the null-modem serial cable. If the null-modem cable normally shipped with the RF/PDU or SRF cabinet is not available, a standard 9-pin to 25-pin serial cable with a null-modem adapter can be used instead. See Illustration 1.

    (Step Details)

  1. Run the program CPD.EXE. See Table 1.

    (Step Details)

  1. A message that reads, “OOPS no CRC value today XXXX. Press a key.” may be displayed if using the version 2.0 software. This is normal. Press any key to continue.

    1. The main selection screen will be displayed. Note the headline at the top of the screen that reads, “CPD.EXE Rev 2.0 CRC XXXX” where XXXX is some hexidecimal value.

    1. If the hexidecimal value is all zeros then select E to exit from the CPD.EXE program and then restart it again.

    1. Verify that status of the hexidecimal value as in the previous step. Failure to verify that the hexidecimal value is not all zeros may result in the program reporting erroneous values.

    1. If the hexidecimal value is not all zeros then continue with the next step.

  1. Select the C) Perform Special Operations menu.

  1. Select H) Change PAC Power Supply Voltage (8V, 9V).

  1. The current PAC configuration is shown (see Table 2).

    (Step Details)

  1. Type N<ENTER>

  1. Press <Esc> twice to exit to DOS. To return to Windows, type exit<ENTER>

  1. Cycle the main breaker power at the SSM by turning CB4 to the OFF position, waiting 15 seconds, then setting CB4 to the ON position. This step saves the changes to the SSM.

2.2   Via the Front Panel Switches

  1. Remove Fiber Optic cables from rear of SSM (RX & TX). See Illustration 2.

    (Step Details)

  1. Remove the plastic cover on the front of the SSM.

    (Step Details)

  1. To change the PAC voltage setting, perform one of the following steps:

    1. For systems without the fiber optic repeater, set to 8 VDC. Place switch 6 in the Down position and switches 4 & 1 in the UP position. Ensure that all other switches are in the Down position.

      (Step Details)

    1. For systems with the fiber optic repeater, set to 9 VDC, place switches 6, 4, and 1 in the UP position.

      (Step Details)

  1. Place switch 1 in the Down position.

  1. Place all other switches in the Down position.

  1. Cycle the main breaker power at the SSM by turning CB4 to the OFF position, waiting 15 seconds, then setting CB4 to the ON position. This step saves the changes to the SSM.

  1. Replace the plastic cover on the front of the SSM.

  1. Connect the Fiber Optic cables to RX & TX on rear of SSM.

  1. Perform TPS Reset by clicking the [Service Desktop] icon and clicking the [TPS Reset] button on the Service Rx.
