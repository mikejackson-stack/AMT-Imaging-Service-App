GDT Stat Help

1  Purpose

Allows the user to troubleshoot Power Up Register failures without power cycling the GP board

2  Components Tested

None

3  Requirements

In TwinRoom systems, the user can run this test with the GP connected to the Whole body coils, the Zoom coils, or on both coils sequentially.

4  Block Diagram

None

5  Test Sequence

ACGD Static Tests begins with the re-execution of the Power Up Memory/Register Test.ACGD Static Test then executes a Local GP Board Reference Voltage Check. This procedure shall confirm that all reference voltages on the GP are in their normal operating ranges. The core diagnostic features of Static tests include the play out of a range of constant voltages and currents with ACGD in Standby and Ready. Various real-time ASM signals are monitored during this voltage play out.

6  Expected Results

Output values are judged pass or fail based on the FRU meeting its functional requirement in the circuit. Instead of relying on fixed signal ranges for testing, input and output relationships are used as the basis of testing measured signals.
