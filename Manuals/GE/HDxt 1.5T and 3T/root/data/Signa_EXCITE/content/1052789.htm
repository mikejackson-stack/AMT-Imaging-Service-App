ICN Infiniband Stress (SUN 4100)

1  Diagnostic Link

Diagnostics >> System Function >> Recon >> VRE Communication Diagnostics

Diagnostics >> Hardware Location >> PGR Cabinet >> Recon >>VRE Communication Diagnostics

Illustration 1:  VRE Communication Diagnostics

2  Purpose

The ICN Infiniband Stress diagnostic tests the cabling and Infiniband performance between the SUN 4100 ICNs only. (It is not applicable to systems with a single ICN as this configuration does not have an Infiniband cable.) The Infiniband is a high-throughput, low latency interconnect used for acquisition and recon data transfers between ICNs. This diagnostic uses the Infiniband trace route to trace the path between the Infiniband ports on the ICNs. Essentially, the diagnostic ensures that the Infiniband link (includes Infiniband board and cable) between the ICNs meets the minimum performance requirements for acquisition data transfer for a multi-ICN product configuration. The ICN Infiniband Stress diagnostic sends messages of different sizes starting from 1K bytes to 1M bytes for multiple iterations and verifies the throughput is as expected.

This diagnostic should be used during one of the following conditions:

  • After the Ethernet diagnostics are complete.

  • If the system log indicates a problem with the Infiniband, this ICN Infiniband Stress diagnostic should be conducted in conjunction with the ICN Infiniband Connectivity diagnostic and the ICN Infiniband Loopback Test to isolate problems related to the cable or ICN hardware.

3  Components Tested

  • Infiniband Cables

  • VRE (Infiniband Hardware)

5  Test Sequence

Before running the ICN Infiniband Stress diagnostic, ensure that the Ethernet cabling and Ethernet switches are functioning correctly. The Infiniband data cables must be connected in their original configuration.

NOTE:This test will unconditionally pass for a one ICN product configuration.

  1. Select the ICN Infiniband Stress diagnostic from the VRE Communication Diagnostics screen.

  2. Enter the desired iteration amounts in the fields provided.

  3. Click [Run].

    NOTE:Once [Run] is clicked, do not click anywhere else on the Common Service Desktop until the test is complete. If it is necessary to abort the test prior to its completion, click [Stop].

  4. Ensure the diagnostic passed by reviewing the Test Results and Test Status areas.

6  Expected Results

If the diagnostic does not pass, review the Error Log and corresponding extended error message for subsequent actions. Additional responses to the diagnostic's results are outlined below.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
The green LED next to the Infiniband board Port 1 is not on.
  • ICN is off.
  • Infiniband cable is not securely connected.
  1. Check that both ICNs are powered at Utilities >> Toolbox >>VRE >> Power Control.
  2. Reseat the Infiniband cable connecting both ICNs.
Yellow LED next to the Infiniband board Port 1 is not on.
NOTE:Extend the ICN from the cabinet to see the LED.

  • Infiniband cable is not securely connected.
  • Infiniband subnet manager process is not running on ICN1.
  1. Reseat the Infiniband cable connecting both of the ICNs.
  2. Reboot the ICNs. (Refer to the ICN On/Off Procedure.)
  3. If rebooting does not resolve the issue, refer to VRE Reconfiguration.
ICN Infiniband fails the diagnostic.
  • Infiniband cable is not securely connected.
  • Infiniband subnet manager process is not running on ICN1.
  • Infiniband cable is defective.
  • ICN Infiniband hardware is defective.
  1. Check that both ICNs are powered on by ensuring the green LEDs on the front are illuminated.
  2. Ensure the Infiniband cable between the ICNs is connected securely.
  3. Make sure the Infiniband port LEDs are on. If the LEDs are off, reboot the ICNs and repeat the diagnostic.
  4. If the problem persists, perform the ICN Infiniband Connectivity diagnostic again for both ICNs.
  5. If any of the connectivity diagnostics fail, replace the Infiniband cable. Repeat the ICN Infiniband Connectivity diagnostic tests on both ICNs.
  6. If the ICN Infiniband Connectivity diagnostic fails on either ICN1 or ICN2, replace ICN.
NOTICE
When this diagnostic is complete, perform a scan to ensure the system is operating correctly.
