SWIFT Cable DP

1  Diagnostic Link

Diagnostics >> MGD Chassis >> MGD Data Paths

2  Purpose

This diagnostic tests the communication between the MGD Chassis and the Driver Module through the SWIFT Cable.

3  Components Tested

  • MGD Chassis

  • Driver Module

  • SWIFT Cable

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

The diagnostic will send out some DAB pulses through the IRF I/O board and validate that the Driver Module has received the DAB pulses properly.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.

If this test fails, perform the SPU->STIF Loopback test to verify the MGD chassis. Perform the SPU- Fiber Optic Repeater Loopback test to verify the repeater in the penetration panel. Verify that the PAC module has power.

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

8  Etcetera

Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

9  Finalization

TPS reset is required prior to scanning.
