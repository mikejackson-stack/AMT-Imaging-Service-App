Install and Calibration Wizard (ICW) Software Setup

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

Basic Software Load (Apps CD and restricted service software) must be completed in order to begin using the ICW (Install and Calibration Wizard.) .

-

-

2  Procedure

  1. Insert the Service Key.

  1. Launch the Service Browser (Common Service Desktop).

  1. Click on the Calibration Tab.

    (Step Details)

  1. The first step in the ICW is Software Setup. See Illustration 1.

    (Step Details)

  1. Load Current Software Updates. When this is complete, check the box next to “Have you loaded

NOTICE
System options MUST be loaded and system must be rebooted before the [Submit] button is clicked for the first time!!
 
 

  1. Load all System Options that have been ordered by the customer. When this is complete, check the box next to “Have you loaded System Options”

  1. Load the Service Documentation from the most recent version of the HDx service methods DVD on the system. When this is complete, check the box next to “Have you loaded Service Documentation?”

  1. From the Common Service Desktop, click on the “Utilities” tab then “System Restart”. Wait for the system to reboot. Logon using:

    1. Username sdc

    1. Password adw2.0

  1. Open the Install Calibration Wizard (see steps Step 1- Step 3 above)

  1. Click on [Software Setup].

  1. The top three boxes should be checked from the work done previously in this procedure. Now that the system has rebooted, also check the box to indicate “Reboot System” is complete.

  1. Click [Submit].

3  Finalization

  1. Verify the DVD archive by inserting a DVD into the SCSI tower and performing a Save INFO. If the Save INFO is successful, then the DVD archive function performs correctly.

  1. Also as a part of this Software Setup, perform Insite Checkout instructions found in MR Applications load.

  1. Finally, as a part of Software Setup, load the Operator Manual DVD in the local language.

  1. Return to the ICW procedure for information regarding how to advance to the next calibration and for links to other calibration procedures.
