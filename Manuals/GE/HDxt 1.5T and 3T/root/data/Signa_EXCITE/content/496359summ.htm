2  Procedure

2.1   Starting Installation and Calibration Wizard

  1. Insert the Service Key.

  1. Launch the Service browser from the Common Service Desktop.

  1. Click on the Calibration tab:

    (Step Details)

  1. The first time the ICW is used, a status of the option keys for HOS, MNS, Probe-P and Probe-S is performed. A pop-up will display similar to the one shown below summarizing the results. Review the status of these option keys, and confirm the correct configuration.

    1. Select [Quit] if the site configuration is unknown or does not match the Option Key status. Update the Option Key and restart the ICW.

    1. If the configuration is correct, select [Continue].

      (Step Details)

  1. The ICW will launch the mode that corresponds to the system status: Install, Upgrade or Maintenance. Refer to the related section below for more details.

2.2   Install Mode - New System Installation

  1. Click on the [Help] button in the lower right corner of the menu bar to open the Service document for the active calibration step.

  1. Some calibrations have certain dependencies. To understand the dependencies the tool is using during the Install mode, refer to Illustration 2.

    (Step Details)

  1. For those calibrations with machine data, click the link: Click here to start the tool. When the tool interface displays, follow the links (available in Calibrations) for specific instructions regarding setting up and running any particular tool.

  1. For those calibrations that have no machine data, acknowledge completion of each task listed by clicking the box next to it (check mark will display), and selecting [Submit]. (See illustration below.)

    (Step Details)

  1. When the calibration completes and/or aborts, close the tool by left mouse clicking the – in the upper left corner of the tool, then select [Close].

    Illustration 4:  Navigating Through Calibrations with Machine Data

  1. Click [Check Status]. This will register the tool’s Pass/Fail status.

    (Step Details)

  1. The ICW will remain in Install mode until every task listed on the left side is successfully completed. After completion of all tasks in Install mode, exit the ICW. (The next time the ICW is launched, it will open in Maintenance Mode.)

2.5   Install Mode - Systems Upgrading from Previous Platform to HDx or HDxt

When upgrading to HDx or HDxt from a previous platform, the ICW will open showing only those calibrations required for the type of upgrade being performed.

  1. When upgrading from HD (12.x) to HDx (14.x) or HDxt (15.x), RestoreInfo restores the Grafidy files, but they must be converted to HDx format before the system recognizes the files. To convert, access Grafidy, then exit by clicking the [Tool Exit] button. Upon exiting, the former 12.x Grafidy files will be converted to the new format.

    (Step Details)

  1. In the Install mode for upgraded systems, the order of the calibration steps follows the same logic as in the ICW Install Mode Dependency Matrix shown in Illustration 2 with fewer calibrations than in full Install mode. For those tests that have no machine data, verify that the tasks were performed by clicking the box next to each (a check mark will display), then click [Submit]. (See Illustration 3.)

  1. When the calibration is completed and/or aborted, close the tool for the ICW interface to become active: Left mouse click on the – in the upper left corner of the tool, then select [Close]. (See Illustration 4.)

  1. Click [Check Status] to register the tool’s Pass/Fail status:

    (Step Details)

2.6   Maintenance Mode

Once all calibrations are completed, the ICW opens in Maintenance mode where no calibration order is enforced. If a selected calibration is affected by or affects another calibration, an Alert message (similar to the one shown in the middle of the illustration below) displays, and affected calibrations are bolded. (Examples shown in Illustration 2.)

Illustration 7:  Starting Maintenance Mode

  1. Click [Yes] to acknowledge the pre and post dependencies. All pre dependencies are unbolded, and the selected tool becomes active.

  1. Perform all necessary setup prior to launching the tool. (See the illustration below for instructions on how to start calibrations in Maintenance mode.)

    (Step Details)

  1. When [Check Status] is clicked, one final pop-up message displays with an alert about the post dependencies.

    1. Click [Acknowledge] to unbold the post dependencies.

    1. Click [More] on the Alert screen (shown below) to display the Dependency Matrix used to determine the pre and post dependencies.

      (Step Details)

  1. It is recommended that any calibration highlighted as a post dependency also be run immediately after the selected calibration.

    (Step Details)

  1. After the ICW is launched in Maintenance mode, keep track of what calibrations were run during the current session by changing the font color of the calibration name to blue. As long as the ICW remains open, it will track all calibrations for which [Check Status] was clicked.

    (Step Details)

3  Finalization

  1. To exit from the ICW, click File and Quit. The pop-up shown below displays.

    (Step Details)

  1. Choose [Yes] to exit from the ICW and perform a SaveInfo.

  1. Choose [No] to remain in the ICW.

  1. Choose [Exit]] to exit from the ICW without performing a SaveInfo.
