Gradient Hammer Test

The purpose of this test is to have the TRF (Trigger-Related Functions) Board output known gradient data at the maximum rate while the GP continuously monitors the gradient data. The TRF also monitors the gradient data. The timing of the TRF code is adjusted to duplicate the timing of applications code as much as possible. This test tries to detect spurious gradient data errors in the Sequencer Related Function / Trigger and Rotation (SRF/TRF) Board and SRF / TRF Interface (STIF) Board.
