Explanation of Default_mc.txt

The following data sets were taken with the applicable MCR tool and is provided as a reference when troubleshooting. There are four different configurations:

  • 1.5T system with new Forward Production LPCA (using MCR3)

  • 1.5T system with Excite style LPCA (using MCR2)

  • 3.0T system with new Forward Production LPCA (using MCR3)

  • 3.0T system with Excite style LPCA (using MCR2)

Data was taken with no coil connection. Then the applicable MCR tool (either MCR2 or MCR3) was connected to the different ports on the LPCA. The data can be used for reference.
