4  Procedure

4.1  PM Patch Information

  1. PM Patch Theory:

    The PM Patch is a new function with 12.x so the Field Engineer will load all applicable patches during the PM. A Patch Template is generated for all sites with 12.x software. The Patch Template contains a list of available patches for the software revision, and will be downloaded to all 12.x sites that have connectivity (both Modem and Broadband) and placed in the /usr/g/insite/data directory.

    • For sites with Broadband connection, all applicable patches will be automatically downloaded into the /usr/g/insite/data directory. The FE must then install the patches onto the scanner during the PM. A Checksum is performed on downloaded patches to verify patch size. If a patch fails, the Checksum patch is deleted.

    • For sites with Modem connection, the FE must obtain the necessary patches via quarterly patch CD release or from the Engineering web site, and then install them.

    The patch status will appear on the FE Cockpit page. (See Illustration 1.) All patches under the Mandatory list must be loaded for IBIS to pass.

    Illustration 1:  MR Service Desktop

  1. Patch installation process:

    1. Open the Common Service Desktop (CSD), and click on PM tab.

    1. Click on [PM Assist] in the left corner.

    1. Click on [PM Patch Info]. (See Illustration 2.)

      Illustration 2:  Start PM Patch

      The tool displays the following information:

      • Patches that were downloaded and installed.

      • Patches that were downloaded to the scanner via Sweep, but not installed. (This option only applies to sites with Broadband connection.)

      • Patches that need to be installed, but have not been downloaded.

      • Patches that may be out of date in the “Other” category. Example: The template file indicates that patch 12.0_M3A_07_rev g should be active, but there is a previous revision on the scanner: 12.0_M3A_07_rev b.

      • Trial patches that are unique to this system.

  1. To install patches that were downloaded to the scanner, log out to the root level by doing the following:

    1. Right mouse click on the background, select [Service Tools], then [System Restart]. The system will shut down.

    1. When the Log In window displays, log in as root with the password, operator.

    1. When the Guided Install menu displays (shown in Illustration 3), click on [Patches]. This displays the patches that were downloaded via Broadband in the Repository section.

      Illustration 3:  Patch Installation from Guided Install

    1. Click on [Install]. If needed, refer to Installing Software Patches and Service Packs for instructions on installing patches.

  1. After installation, patches can be archived to MOD. To archive patches, install MOD and select [Save to MOD] shown in Illustration 4. This will allow restoration of patches via MOD if the software crashes.

    Illustration 4:  Patch Archive to MOD

4.2  LVShim PM Mode

The LVShim GradShim procedure is performed in LVShim PM mode. The objective is to fine tune the homogeneity of the magnet by using gradients only. The GradShim process is performed with a sampling diameter of 22 cm DSV and the same bandwidth as Fine Shim, which depends on the quality (good or bad) of the fine tuning. Once the scan passes and all harmonics are in spec, the magnetic field is reanalyzed for customer acceptance in Test mode automatically at 45 DSV.

4.2.1  Phantom Setup

  1. Remove all coils from the cradle and phantoms from the bore.

  1. Set up, align, and landmark the LVShim Phantom as shown in Illustration 5.

    Illustration 5:  Aligning LVShim Phantom on Patient Table

  1. Press the [Advance to Scan] button.

4.2.2  Run LVShim Tool

  1. If not already in place, insert the Restricted Service Key into a host computer USB port.

  1. Click Service Browser.

  1. On the MR Service Desktop, select the [PM] icon and expand the PM Assist option. (See Illustration 6.)

    Illustration 6:  MR Service Desktop, LVShim PM Mode

  1. Click the Click here to start this tool link shown in Illustration 7.

  1. Refer to Illustration 6 and ensure that the [Gradient Shim] shim type and [Auto Mode] radio button are selected.

    Illustration 7:  LVShim Tool

  1. To proceed, click the [Scan] button. In Auto mode, the tool automatically does the following:

    • Sets up the protocol and collects image data.

    • Calculates the harmonics and compares it with the specification.

    • Calculates dc offsets for X, Y and Z.

    • Completes multiple iterations (maximum = 5) until harmonics meets the specification.

    • Lists the last iteration reanalyzed at 45 DSV in Test mode (customer acceptance spec) in the final column.

    After the scan is complete (with the service key still inserted), the tool compares all the of the harmonics to spec in the Test mode.

    • Green cell = Passed specification

    • Red cell = Failed specification

  1. When all iterations are complete and all harmonics within specifications, click [Exit] in the LVShim window.

4.3  System Performance Testing (SPT)

  1. Landmark the phantom set-up as shown in Illustration 8, using the appropriate Head TLT Sphere and loader in the head coil. The LVShim phantom can be removed for this test. The process for proper landmark is:

    1. Insert DQA phantom and turn on alignment lights.

    1. Move cradle so alignment lights align with the center mark on the DQA phantom.

    1. Remove DQA phantom and insert TLT phantom.

    1. Position TLT phantom so the centering line is aligned with the alignment light.

    1. Insert body TLT sphere as shown in Illustration 8.

      Illustration 8:  Phantom Positioning for SPT, PM Mode

  1. From the Common Service Desktop PM page, select [PM Mode] by clicking on it in the expanded PM folder on the left side of the page (shown in Illustration 9 and Illustration 10).

  1. Start the SPT tool by clicking the link:[Click here to start this tool] shown in Illustration 9.

    Illustration 9:  SPT PM Page

    Illustration 10:  SPT PM Mode

  1. When a window displays requesting selection of the Head Coil and Phantom Type, select the appropriate combination by clicking on the related radio button, then click the [Start] button. (See Illustration 11.)

    Illustration 11:  Head Coil Selection Screen

  1. The System Performance Test (SPT) screen will open (Illustration 12). For the PM SPT mode, all the tests are preselected and cannot be changed. The test takes just over one hour to complete. In the upper right corner of the SPT screen, the remaining test time will display as shown in Illustration 12 and Illustration 13. Test Progress and Results will display in the lower portion of the SPT screen shown in Illustration 14.

    For more information on System Performance Tests, including phantom set up, follow the System Performance Test (SPT) procedure.

    Important: Failures must be resolved and the SPT must be re-run before proceeding to the PM Check. SPT in PM mode executes on a TRM System in the Zoom mode only. If failures occur, verify that all subsequent iterations are run in Zoom mode for TRM Systems.

    Illustration 12:  Remaining Test Time

    Illustration 13:  Close Up of Remaining Test Time

    Illustration 14:  Test Progress and Results

4.4  EPI White Pixel PM Mode

  1. Place an empty head coil on the cradle.

  1. Landmark on the head coil.

  1. Press <MOVE TO SCAN>.

  1. From the CSD, select the PM tab, EPI White Pixel Mode, and click on the link: [Click here to start this tool]. (See Illustration 15.)

    Illustration 15:  Start EPI White Pixel PM Mode Tool

  1. The tool will run through Head EPIWP PM, then move the head coil out of the way and perform Body EPIWP PM. If the test stops before the tool has completed both head and body modes, view the Error Log to determine the troubleshooting path.

  1. The EPI PM files generated by this tool can be found in the Report Manager tool. From the CSD, click the Utilities tab, then [Report Manager]. Use the password, mrgo1. Look for file type: EPT and find those files with the PM extension. IBIS will be looking for these files to track Planned Maintenance completion.

4.5  16-Channel Switch Diagnostics

NOTE:The 16-Channel Switch Diagnostics is used for 14.0M5A forward and 15.x software.

  1. Click on [16 Ch Switch diags PM Mode]. (See Illustration 16.)

    Illustration 16:  16-Channel Switch PM

  1. Verify that there is no coil connected to the LPCA.

  1. Under Test Options, verify that the [Test All Ports] option is selected; under Constraints, verify that [No] is selected. (See Illustration 16.)

  1. Click on [Run].

  1. Verify that all channels pass.

  1. TPS Reset must be performed upon completion of 16-Channel Switch Diagnostics.
