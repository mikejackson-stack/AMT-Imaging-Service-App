NOTE:Later versions of the S-1 Magnet (Model Number Series 46-260531) have an added helium vapor exhaust line called the Second Penetration. This flow can be spot checked separately by attaching one of the flow meters of the Helium Flow Gauge Assembly to the vapor line leaving the Second Penetration just to the left and below the P-3 Cryoplug. The flow meter should read 0.1 SCFH, with the flow meter needle valve set wide open.
