Planned Maintenance Initialization

  Safety

NOTE:For Signa OpenSpeed, this tool is supported from OpenSpeed4 M4 and later.

For Signa Ovation, this tool is supported from Ovation4 M4 patch and later.

1  Procedure

1.1   Setting up a planned Maintenance Schedule

  1. Install the USB Service Key into the system.

  1. On the Service Desktop, start the Service Browser if it is not already running.

  1. Select the [PM] tab.

  1. Double Click on the [PM Assist] Folder to expand it's menu/content.

  1. Refer to Illustration 1. Select [PM Schedule].

    (Step Details)

  1. Create a new PM Record by entering a name of who will do the PM and when is it scheduled.

1.2   Checking Status or Validating Current PM Results

  1. Install the USB Service Key into the system.

  1. On the Service Desktop, start the Service Browser if it is not already running.

  1. Select the [PM] tab.

  1. Double Click on the [PM Assist] Folder to expand it's menu/content.

  1. Refer to Illustration 2.

    (Step Details)

  1. If this is the first time you have entered this option, without the PM Assist mode of LVShim or SPT completed, it will indicate a incomplete PM. This is normal for the first time. After a PM, which includes LVShim and SPT (which must be run from the PM Assist Menu) the output will include the latest LVShim and SPT PM Pass/Fail results as well as last and Next Scheduled PM Dates.
