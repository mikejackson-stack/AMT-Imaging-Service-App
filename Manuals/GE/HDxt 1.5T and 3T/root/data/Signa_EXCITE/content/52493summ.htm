Image Extraction

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Starting the Image Extraction Tool

This document describes the procedure for extracting images from the image database for OnLine Center downloading.

  1. In the Service Desktop Manager, click on the [Service Browser] button.

  1. Follow the instructions on Illustration 1, below.

    (Step Details)

  1. In the winterm window, you’ll be prompted to type the InSite password. Type <2getin> (in either upper- or lowercase), then press <Enter>. Note that the password will not appear on the screen as you type.

    (Step Details)

1.2   Navigating the Menus

Below are some navigational aids.

  1. To make selections from the menus, the pointer must be within the winterm window.

  1. Only ten items (exams, series or images) can be displayed at once. To display the next ten items, use the navigational keys at the bottom of the screen:

    (Step Details)

  1. If you’re in a submenu (e.g., the Series menu) and you want to return to the previous menu, type <Q> at the prompt and press <Enter>.

  1. If you’re at the Main Menu, type <Q> to return to the Service Browser.

1.3   Selecting an Exam, Series and Image(s) by Number

Use this procedure if you know the exam, series and image numbers you’re looking for. If you enter a number that doesn’t exist in the database, the system will display a menu of all entries from which to choose.

  1. To select an exam by number, on the Main Menu, type <A> (in upper- or lowercase) and press <Enter>.

  1. At the prompt Exam No. ?, type the exam number you want to view. Press <Enter>.

    1. If you typed an existing exam number, the Main Menu will reappear. Go to step 3.

    1. If you typed an exam number that doesn’t exist in the database, the Exam Menu will appear, from which you can select an Entry number. See the example in Illustration 4.

      (Step Details)

    1. On the Exam menu, type the Entry number (not the exam number) preceding the desired exam, then press <Enter>. When the Main Menu reappears, go to step 3.

  1. To select a series by number, on the Main Menu, type <B> and press <Enter>.

  1. At the prompt Series No. ?, type the series number (in the previously-selected exam) that you want to view. Press <Enter>.

    1. If you typed an existing series number, the Main Menu will reappear. Go to step 5.

    1. If you typed a series number that doesn’t exist in the database, the Series menu will appear, from which you can select an Entry number. See the example in Illustration 5.

      (Step Details)

    1. Type the Entry number (in the first column) that precedes the series you’d like to view, then press <Enter>. Go to step 5.

  1. To select an image or images by number, on the Main Menu, type <C> and press <Enter>.

    1. When the prompt Image No ? appears, you’ll also see this message:

      (Step Details)

    1. To select more than one image, you can enter a range of images separated by a space.

      (Step Details)

    1. If you typed an existing image number (or range of numbers), go to step 6.

    1. If you typed an image number or range that doesn’t exist in the database, the Image Menu will appear, from which you can select an Entry number. See the example in Illustration 6.

      (Step Details)

  1. After you’ve selected an image or a range of images, a message similar to this will appear:

    (Step Details)

  1. If the image(s) you selected already exist(s) in the /usr/g/insite/tmp directory, you’ll see a message like this:

    (Step Details)

  1. If the list contains more than ten items, use the navigational keys at the bottom of the screen to move between “pages.” See Illustration 3.

    (Step Details)

1.4   Selecting an Exam, Series or Image from a List

If you’d prefer to select the exam, series or image from a list of all entries in the database, follow the procedure below.

  1. To select an exam from a list, on the Main Menu, type <D> (in upper- or lowercase) and press <Enter>. Refer to Illustration 2.

    (Step Details)

  1. A list of the exams in the database is displayed, as shown in Illustration 8.

    (Step Details)

  1. Each Exam number is preceded by an Entry number. At the prompt, enter the Entry number preceding the exam you’re looking for (not the number of the exam itself). Then press <Enter>.

  1. If the list contains more than 10 items, use the navigational keys at the bottom of the screen to move between “pages:” See Illustration 3.

    (Step Details)

  1. When the Series Menu appears, select the Entry number of the series (the second column, labeled Ser) you want to view. Then press <Enter>. See Illustration 9.

    (Step Details)

  1. When the Image Menu appears, type the Entry number of the image you want to view. Press <Enter>. See <Illustration 10>.

    (Step Details)

  1. If there are multiple “pages” of images, go to the next page by positioning the pointer anywhere in the winterm window, then type <N> and press <Enter>.

    (Step Details)

  1. To select a single image, type the number in the Entry column that precedes the image you want. Press <Enter>.

    (Step Details)

  1. To select a consecutive range of images:

    1. Return to the Main Menu by typing <Q> at the Entry prompts.

    1. At the Main Menu, type <C >(Select Images).

      (Step Details)

    1. Type the first image number and the last image number, separated by a space.

      (Step Details)

1.5   Exiting the Image Extraction Tool

  1. If necessary, type <Q> at the current menu (Exam, Series or Image) and press <Enter> until you return to the Main Menu.

  1. At the Main Menu, type <Q> and press <Enter>to return to the Service Browser.
