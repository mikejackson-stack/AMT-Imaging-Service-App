Clinical Image Extraction Tool (CIET)

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Select the images to extract from the Display Browser and then launch CIET.

    1. In the Examination field, select the Exam that has the images you want to extract.

    1. In the Exam no ... field, select the Series that has the images you want to extract.

    1. In the Series no ... field, select the image(s) you wish to extract.

      (Step Details)

    1. Click [CIET].

    (Step Details)

  1. Type the requested information in the Clinical Image Extraction Tool window.

    1. In the top field, type the reason for extracting the images.

    1. In the lower field, enter the directory name these images will be stored. Any name can be used as long as it doesn't contain spaces or wild cards.

      (Step Details)

  1. To locate your images, go to /export/home1/ciet/Step7Name.

    (Step Details)

  1. In order to save space and make finding images in the /ciet directory easier next time, click [Clean Up](see Illustration 2).
