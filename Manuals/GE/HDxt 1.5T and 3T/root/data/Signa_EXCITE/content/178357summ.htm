3.1   1.5T Body UPM Functional Check

  1. To inhibit TR faults, disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet) shown in Illustration 1. Move Switch 2 to the TR Disable position.

    (Step Details)

  1. Remove the Body Heliax Cable from J4, and connect the RF Dummy Load into J4.

    (Step Details)

3.1.2  Setting Up Software Tool to Calibrate UPM - Body Forward Power

This tool must recognize a landmark. It is not necessary to have a Body Phantom in place or any scan parameter entered other than what is described below. Simply landmark on the cradle where the Body Phantom would be located.

  1. Move the cradle into the bore.

  1. Press [Align on].

  1. Move the cradle to place the laser alignment light on the approximate location of where the body phantom would be located.

  1. Press [Landmark].

  1. Press [Advance to Scan].

  1. From the Common Service Desktop:

    1. For the Class M service tool, select Calibration Wizard from the calibration menu, and [Click here to start this tool]. Once the Calibration Wizard starts, select UPM Calibration (Head and Body) from the menu, review and okay the pre & post-dependencies, and select [Click here to start this tool]. (May also start the tool under Class A/C mode shown next.)

    1. Select the Calibration Tab.

    1. Select UPM Tool from the Calibration menu, and [Click here to start this tool]. (Illustration 3 shows an example of the UPM tool.)

      (Step Details)

  1. Select the Nuclei: 1H.

  1. Select the RF Chain to check: Body.

  1. Click the [Func Chk] button.

    (Step Details)

  1. Click the[Start] button. When the message shown in Illustration 4 displays, click [Yes] if the Body Coil is ready to go.

    (Step Details)

  1. The UPM tool now takes full control, and runs the three functional tests for the setup currently active.

    (Step Details)

  1. To proceed:

    1. If any of the tests fails, refer to Troubleshooting UPM.

    1. If all three tests pass, proceed to 1.5T Head UPM Functional Checkfor 1.5T.

3.5   Supplemental UPM Checks

For troubleshooting purposes, the UPM Functional Check tool can be run using the system load setup shown in Illustration 28. Note that a “PASS” result does not provide the required verification of UPM functionality, nor does a “FAIL” result indicate that the UPM or any other part of the transmit chain is faulty or out of specification using this setup.

NOTE:The UPM Functional Checks must pass with the prescribed dummy setups in 1.5T Body UPM Functional Check Setup and 1.5T Head UPM Functional Check Setup as part of the system verification. However, running the Functional Check tool with the system load can be useful when trying to isolate an issue to a particular part of the chain. For this purpose, the supplemental check procedure is defined.

NOTE:The UPM Functional Checks must pass with the prescribed dummy setups in 3.0T Body UPM Functional Check and 3.0T Head UPM Functional Check as part of the system verification. However, running the Functional Check tool with the system load can be useful when trying to isolate an issue to a particular part of the chain. For this purpose, the supplemental check procedure is defined.

  1. Place the Head Coil on the cradle.

  1. Insert the Head Sphere and Loader into the head coil as shown in Illustration 28.

    (Step Details)

  1. Place the SPT Nesting Plate on the cradle, as tight against the head coil as possible.

  1. Place the Body Sphere and Loader on the nesting plate as shown in Illustration 28.

  1. Press the [Align on] button.

  1. Move the cradle to place the laser alignment light on the center of the Body Loader and Phantom if doing Body Functional Checks, or on the Head Coil Phantom if doing Head Functional Checks.

3.6   Troubleshooting UPM

  1. Solution 1:

    1. Check all cabling to the UPM components to make sure they are properly installed.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. Solution 2:

    1. Cycle power to the UPM Chassis.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. Solution 3: Reboot the system.

  1. Solution 4:

    1. Remove power from the UPM.

    1. Reset the Processor Module.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. Solution 5:

    1. Remove power from the UPM.

    1. Reset the Detector Boards.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. Solution 6:

    1. Check the Processor Module. (Problem could be that it is bad.)

    1. Remove power from the UPM.

    1. Replace the Processor Module.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. Solution 7:

    1. Check the Detector Boards. (Problem could be that one is bad.)

    1. Remove power from the UPM

    1. Replace both Detector Boards.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the receive chain that failed (Head or Body).

  1. For additional troubleshooting information, refer to Universal Power Monitor (UPM) Troubleshooting.

3.7   UPM Theory

The Universal Power Monitor calibration parameters found in the UPM calibration file (/export/home/signa/tools/upm.config) are used in the Calibration/Functional Check program. The Program code sets the Digital Attenuators in the UPM based on the results of the tests run and a comparison to these UPM Calibration parameters.

  • The UPM calibration file is accessible within the UPM Calibration tool from the “File” pull-down menu, “Edit Config” option. These values can be edited and saved during troubleshooting to perhaps understand where the power monitor is tripping. Before changing any parameter, make sure to select and run the Bkup UPM Cal option first to allow a return to the default values at any time.

  • A screen shot of the UPM Calibration file (shown in Illustration 29) contains the default configuration values for all of the UPM parameters. This illustration is for reference only, as the content and values will be different based on the system type and calibration results. (Use the [Restore Defaults] on the Config File Editor GUI to get back to known default values.) The final UPM Digital Attenuator values are written to the UPM Calibration Configuration files (Upm1Cal.cfg, Upm1Cal.cfg, etc.) located in directory: w/config.

  1. Note that the format of the Upm1Cal.cfg and Upm2Cal.cfg examples is as follows:

    1. 85←Head FORWARD Power, attenuator setting in HEX

    1. 9f←Head REFLECTED Power, attenuator setting in HEX

    1. 0← Head Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. 8d← Body FORWARD Power, attenuator setting in HEX

    1. 8e←Body REFLECTED Power, attenuator setting in HEX

    1. 9d←Body Quad Hybrid Reflected Power, attenuator setting in HEX

    1. 93←MNS FORWARD Power, attenuator setting in HEX

    1. 83←MNS REFLECTED Power, attenuator setting in HEX

    1. 0 ← MNS Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. 0 ←CW FORWARD Power, attenuator setting in HEX (currently not used)

    1.  0←CW REFLECTED Power, attenuator setting in HEX (currently not used)

    1. 0←CW Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

  1. Any changes to these values are temporary, and can be quickly restored by selecting the [Restore Defaults] button shown in Illustration 29.
