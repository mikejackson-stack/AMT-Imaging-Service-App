Infiniband Troubleshooting

Follow the steps below to troubleshoot Infiniband communications.

  1. Remove the Infiniband Switch if it is still installed. Refer to Infiniband Switch Replacement/Rewiring.

  2. Perform Infiniband Communication Diagnostics.

    • If diagnostics pass, call the On Line Center. Troubleshooting is complete.

    • If diagnositics fail, proceed to Step 3.

  3. Check Ethernet/Infiniband cabling.

    • If the cabling is correct, proceed to Step 4.

    • If the cabling is faulty, correct the cable fault. Troubleshooting is complete.

      NOTE:The Loopback Cable (P/N 5146975-8) should be connected between Port 2 of one ICN and Port 2 of another ICN. Remember to replace the cables after the test is completed.

  4. Check the Infiniband Board for visible damage.

    • If the Infiniband board appears satisfactory, proceed to Step 5.

    • If the Infiniband board appears faulty, replace it as instructed in Pinot Chassis / MGD Chassis Replacements.

  5. Set up the ICN Infiniband Loopback Test and run the test for ICN 1. See ICN Infiniband Loopback Test.

    • If the test passes, proceed to Step 6.

    • If the test fails, replace the Loopback Cable and rerun the test.

      • If the test passes, proceed to Step 6.

      • If the test fails, replace the ICN as explained in ICN Replacements. Troubleshooting is complete.

  6. Set up and perform the Infiniband Board Loopback Test as described in Infiniband Board Loopback Test.

    • If the test passes, call the On Line Center. Troubleshooting is complete.

    • If the test fails, replace the Infiniband Board as explained in Pinot Chassis / MGD Chassis Replacements. Troubleshooting is complete.
