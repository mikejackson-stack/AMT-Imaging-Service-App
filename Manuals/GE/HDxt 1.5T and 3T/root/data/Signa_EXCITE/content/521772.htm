SRI Coil ID Stress Test

1  Diagnostic Link

Diagnostics >> Peripherals >> SRI Functional Tests

2  Purpose

This tests the communication function of identifying coils. You may run this test on any coil plugged in to the system.

3  Components Tested

4  Requirements

The coil tested must have a coil ID.

5  Block Diagram

Illustration 1:  SRI Coil ID - 16-Channel Switch Block Diagram

6  Test Sequence

The SCP commands the SRI to check for any coil connected. The SRI reads the coil presence information from the coil via the 16-channel Switch. If a coil is present, the SRI communicates with the coil through the 16-channel Switch.

7  Expected Results

If the coil is connected and is programmed with identification information, the coil id is read and identified on the diagnostic screen. The user can enter the number of iterations to be performed in the corresponding field. The test continues until all iterations have been performed or the user clicks [Stop].
