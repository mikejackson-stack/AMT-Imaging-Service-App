NOTE:Only version 2.0 of CPD.EXE is compatible with all MR system types.

Table 1:  ALTERNATE PROPRIETARY PROCEDURE — LAPTOP SOFTWARE

Start the software diagnostic program CPD.EXE on the laptop.
NOTE:The CPD.EXE program, if not loaded on the service laptop, can be loaded from the MR Service Methods CD-ROM. Insert the CD-ROM into the drive. Under Windows 95/98 use the cursor to select [Start] and then [Run] and then [Browse]. Select the CDROM drive from the down arrow to the right of the [Look in:] entry box in the [Browse] menu. In the edit box type the following (include the quotes): “PC CDROM Drive Drive:\mrtools\Setup.exe”

Follow the setup program instructions to install the tool onto the laptop. The CPD.EXE must be run in MS-DOS mode and not from a Windows shell to DOS. In Windows95/98 perform the following steps:
  1. [Start], [Shut Down...], Restart the computer in MS-DOS mode?, [Yes]
    NOTE:It may take up to 1.5 minutes for some Dell laptops to restart in MS-DOS mode.

  2. At the C:\Windows> prompt, type cd \cclass\rftools<ENTER>
  3. At the C:\CCLASS\ERBTEC> prompt type cpd.exe<ENTER>
