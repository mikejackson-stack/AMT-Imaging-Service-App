Grad Warp - This is a Normal Phenomenon

Image Info:
This is a normal example of what the GE algorithm for Gradwarp produces.  

Symptom:
The hourglass shape along the perimeter of this image is due to the Gradwarp Algorithm setting all the values it has replaced that contain no image data to zero instead of leaving them as noise values.  

Root Cause/Solution:
There is no service action to be taken with an image like this, as it is considered normal.
