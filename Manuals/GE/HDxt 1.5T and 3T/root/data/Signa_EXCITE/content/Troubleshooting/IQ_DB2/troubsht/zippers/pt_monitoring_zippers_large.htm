Patient Monitoring Device Interference

Image Info:
The system is a 1.5T LX HighSpeed.  

Symptom:
Note the multiple zippers in this image.  Also see the results of SPT Coherent noise test below in this state.  

Flowchart:
See the Zipper Troubleshooting Flowchart

Root Cause:
This problem was caused by a patient monitoring device that the Customer had in the scan room.  This device is designed to be used in the scan room and had not been a problem before.  Evidently something failed in this patient monitoring device which caused RF to be transmitted into the room and cause these artifacts.  To isolate this as the cause, we turned this monitoring device off and the zippers in the images went away.  In addition, another run of SPT Coherent Noise test came out clean.
