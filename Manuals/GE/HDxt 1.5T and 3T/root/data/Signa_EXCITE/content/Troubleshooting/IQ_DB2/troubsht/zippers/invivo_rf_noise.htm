Invivo RF Noise

Image Info:
This is on an Excite system running 10.0 M4 software.

Symptom:
Vertical zippers throughout image

Flowchart:
See the Zipper Troubleshooting Flowchart

Root Cause:
The Customer experiences these artifacts on images when using the Invivo monitor.  This site also has a 1.5T LX running 9.1 software that does not get this artifact when they use the Invivo monitor.  It appears that the Excite system is more sensitive to this noise from the Invivo system.  Found out from Invivo that there are additional filters that need to be added on the Invivo monitor when it is connected to an Excite system.  The problem is with Invivo, not a problem with our system.
