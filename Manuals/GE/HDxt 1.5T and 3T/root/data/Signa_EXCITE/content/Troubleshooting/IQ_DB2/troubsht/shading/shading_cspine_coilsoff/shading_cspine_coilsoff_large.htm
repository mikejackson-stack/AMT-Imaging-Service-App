C-Spine Wrong Coils Turned Off

Image Info:
The system is a 1.0T LX.  The image here with shading is a C Spine scan done with the CTL coil.  

Symptom:
Severe Shading.

Flowchart:
See the Shading Troubleshooting Flowchart.  

Root Cause:
The problem was caused by operator error.  The Tech had landmarked and intended on doing a C Spine but made the mistake of selecting the T Spine protocol which has the CTLMID coil configuration selected.  So as result the top 2 coils are turned off.  

Solution:
The Tech repeated the scan again with CTLTOP config selected and produced the image below:
