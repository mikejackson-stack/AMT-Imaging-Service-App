EPI Bandpass Asymmetry

Image Info:
The system is a 1.5T HighSpeed with Excite running 10.0 M4 software.  This is a dwepi scan with the 8HRBRAIN coil.  

Symptom:
The Customer complaint was “Line artifacts on the images”.  See the increased nyquist ghost on this image and more importantly the structured “Lines” in the ghost.  You can see some of these lines in the image as well but most noticeable in the ghost.     

Flowchart:
See the Ghosting Troubleshooting Flowchart.  

Root Cause:
If they scan the same sequence with the standard HEAD coil, they don’t see these “lines” or the ghost.  The FE had replaced the 8 channel Brain coil which didn’t resolve the issue.  This problem turned out to be caused by a problem with the epi bandpass asymmetry calibration files.  BACC was run when this system was upgraded to Excite but evidently something didn’t calibrate correctly.  

Solution: 
All it took to correct this issue was to simply run BACC (or BAT) again. 

 Image Info: 
Seen when the customer ran EPI diffusion scans using the 1.5T 8 Channel HR Brain Coil.  Running the failing EPI diffusion protocol using the 1.5T 8 Channel HR Brain Coil and a 10cm spherical phantom resulted in the image seen here. 

Symptom: 
Line artifacts.  In addition to being visible when the customer ran EPI diffusion scans with the 8-Channel HR Brain Coil, they may also have been seen when running diffusion scans using other phased array coils.  

Flowchart:
See the Ghosting Troubleshooting Flowchart.  

Root Cause:
Disabled the BACC values by setting the CV RHBP_CORR to 0, re-did the reference scan, and then scanned.  The resulting image was clean and the vertical lines were gone. It was finally determined that, during the install, BACC had not been run on all 8 MGD receivers so at least 7 of the receivers were missing valid BACC values. 

Solution:
Re-ran BACC on all 8 receivers and this ultimately corrected the problem.
