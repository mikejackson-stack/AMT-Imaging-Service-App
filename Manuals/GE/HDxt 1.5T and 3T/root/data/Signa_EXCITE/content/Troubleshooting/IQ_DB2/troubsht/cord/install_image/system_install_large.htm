First Image after System Installation

Image Info:
This raw data image was taken shortly after the installation of a new MR System.  

Symptom:
The raw data for this image show many white pixels.  

Flowchart/Root Cause/Solution:
After system installation, there are many possible causes of white pixels.  To be thorough, refer to the White Pixel Troubleshooting Flowchart.  Quick suggestions include:

  • Check the cabling
  • Check the Installation of the Body Hybrid and Head T/R Coils
