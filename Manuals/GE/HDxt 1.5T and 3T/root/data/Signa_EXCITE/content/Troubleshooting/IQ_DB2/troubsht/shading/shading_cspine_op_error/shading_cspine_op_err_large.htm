C-Spine Operator Error

Image Info:
The system is a 1.5T 5.X.  

Symptom:
The signal void seen here was due to operator error.  

Flowchart:
See the Shading Troubleshooting Flowchart.

Root Cause:
The Customer had done a C Spine series first using the CS12 config with an Inferior sat band on that scan.  This came out fine.  The tech then did a “RX Scan” and did a large Superior table delta and changed the coil config to CTLMID in order to scan the Thoracic area here.  The void seen here is the Inferior Sat Band that was placed on the earlier C Spine scan.  “RX Scan” will keep the same location of the earlier prescribed sat band which is now in the FOV on this T Spine scan.  

Solution:
The Tech should have done a “RX Series” or performed new scan with a new landmark.  See the images below for some more detail on this
