8 Channel Coil Preamp Oscillation

Series 1 Series 2

Image Info: 
This example uses a MRID 8 channel NV coil, but could occur on any coil using on-board preamps (all coils with 8 channels or greater). 

Symptom:  
For an 8 channel surface coil:

  • “White pixel” or “corduroy” artifacts only on 1st series of images.
  • ALL images in 1st series share the same artifact.
  • All subsequent series have good quality.  No changes made between series.
  • QA Test Passes

Root Cause:  
If artifacts appear on all images in the first series, it is likely that excess pre-amp oscillation is occurring.  8 channel coils contain onboard pre-amps, so the problem is coil-related.

Note:  If similar artifacts occur randomly within series, the problem is not necessarily coil-related.  Troubleshoot white pixels.

Solution:  
If occurring on a coil with onboard preamps (all coils > 8 channel), replace the coil.  If occurring on a coil that uses system preamps, troubleshoot the RF receive chain.
