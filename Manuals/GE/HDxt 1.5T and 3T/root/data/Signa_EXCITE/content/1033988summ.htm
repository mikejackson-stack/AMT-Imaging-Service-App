Loading or Deleting Proprietary Software

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

If loading Service Software, an Advanced or Restricted Service Software CD-ROM is required.

-

-

If loading Advanced Service Software, the Inhouse Service Key is required. If loading Restricted Service Software, A GE FE Service Key is required.

-

-

If Advanced or Restricted software is re-loaded on a functioning system, ALL applicable Service Packs must be re-loaded.

-

-

2  Procedure

  1. Under Guided Install, select [FE mode]. Select [Click here to start this tool]. The installTool window appears.

  1. At the password prompt, type operator and press<Enter>. The Install menu appears.

  1. Click [Service SW/Insite]. See Step  for steps to load or remove proprietary software.

    (Step Details)

  1. Once completed, exit the Install GUI.
