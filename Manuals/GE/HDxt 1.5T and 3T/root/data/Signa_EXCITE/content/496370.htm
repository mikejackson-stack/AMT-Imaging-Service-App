Auto Coil Install

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
15 minsNot applicable

2  Overview

The Auto Coil Install tool will automatically detect and configure new coils.

3  Preliminary Requirements

3.1  Tools and Test Equipment

ItemQtyEffectivityPart#Manufacturer
Any new coil that has not yet been configured for a system. N/A---

4  Procedure

  1. Plug the coil into an LPCA Port. The system will automatically detect the new coil and a pop-up will appear stating the coil has not yet been configured for this system. See Illustration 1

    Illustration 1:  New Coil Detected Pop-up

  1. Select [Yes] to configure the new coil. If the process is successful, a new pop-up, shown in Illustration 2, will be displayed. Select [OK] and prescribe a new patient for changes to take effect.

    Illustration 2:  Configuration Successful Pop-up

  1. If the required information was not found on the system, and the coil could not be configured, the pop-up, shown in Illustration 3, will be displayed. Insert the CD, which contains the coil configuration data, and select [OK].

    Illustration 3:  Configuration Not Successful Pop-up

  1. If the system was unable to configure the coil, and no media is available containing the coil data, select [Cancel] from the window shown in Illustration 3.

  1. Find the required information in the coil service manual, and use the Unknown Coils Configuration Procedure to manually enter the coil configuration data.

5  Finalization

No finalization steps.
