Gradient Cabinet PDU Installation Input Voltage Selection

(Click Here to Return to Detailed Procedure)

  Safety

DANGER
Electrocution Hazard!
LETHAL VOLTAGES ARE PRESENT WITHIN THE PDU.
CHECK THAT POWER AT THE MAIN DISCONNECT IS OFF, LOCKED, AND TAGGED BEFORE PROCEEDING.

1  Procedure

1.1   Input Voltage Selection

  1. Move cabinet to final position. WARNING! Using a voltmeter or other voltage indicating device, check to be sure that no voltage is being applied to the input of the PDU.

  1. Remove the plate from the front of the PDU marked INPUT CIRCUIT BREAKER CURRENT SELECT / INPUT VOLTAGE SELECT. See Illustration 1

    (Step Details)

  1. For each of the three phases, be sure the wire is connected to the proper terminal for the actual input voltage at the site and that the terminal screw is tight to make a good connection.

1.2   Circuit Breaker Dip Switch Settings

  1. Depending on the age of the Gradient Amplifier, refer to Illustration 2 or Illustration 3 for circuit Breaker Dip Switch Setting.

    (Step Details)

  1. Close up all open panels before applying power to the PDU.
