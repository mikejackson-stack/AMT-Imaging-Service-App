Planned Maintenance Initialization

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Setting up a Planned Maintenance Schedule

  1. Install the USB Service Key into the system.

  1. On the Service Desktop, start the Service Browser if it is not already running.

  1. Select the [PM] tab.

  1. Expand the [PM Assist] menu.

  1. Select [PM Schedules]. Refer to Illustration 1.

    (Step Details)

  1. Click the Click here to start this tool link.

  1. Enter a name and time for the next planned maintenance to create a new PM Record.

1.2   Checking Status or Validating Current PM Results

  1. Install the USB Service Key into the system.

  1. On the Service Desktop, start the Service Browser.

  1. Select the [PM] tab.

  1. Expand the [PM Assist] menu. See Illustration 2.

  1. Click the Click here to start this tool link.

  1. (Step Details)

  1. If running this option for the first time, you must first run the LVShim, EPI White Pixel PM Mode, and SPT PM Mode procedures. After performing a Planned Maintenance check, which includes LVShim, EPI White Pixel, and SPT, the output includes the latest LVShim, EPI White Pixel, and SPT PM Pass/Fail results, and the PM schedule dates.
