2  Troubleshooting Connectivity Issues Using “View InSite2 Status”

The Magmon3 will post messages in both the InSite2 Status file and on the unit's Front Panel Display.

Table 2 provides the two message formats and a service action, if it is deemed necessary.

Table 2:  InSite2 Status Messages and Service Actions

LineInSite2 Status File Message (Viewable via laptop connection)Front Panel - Abbreviated Message (Viewable via the Data button)Service Action
1“Agent not running because it is not configured.”“InSite Stopped, Not Configured”Verify InSite2 configurations on the Magmon3 are complete and submitted.
2“Agent not running because satellite mode is configured.”“InSite Stopped, Satellite Mode”For Satellite mode this message is normal. When in Satellite mode the InSite2 configuration is ignored and blanked out.
3“Agent not running - waiting for a request to connect by modem.”“InSite Stopped, No Demand”None – This is the normal Idle state message for a modem-based system.
4“Agent not running - waiting for WebMode with fixed IP to end.”“InSite Stopped, Webmode Wait”InSite2 is turned off when the MM3 is in Web Mode with fixed IP. This should time out after 45 minutes or can be forced off by the user to exit the service mode.
5“Agent is being restarted because WebMode ended.”“InSite Restart, Webmode Ended”None – Normal status message after a Web Mode session is complete. At this time the InSite2 agent will pick up any recent configuration changes.
6“Agent not running - no network connection.”“InSite Stopped, No Network”Check network connection and network activity. The MM3 doesn't have a network connection, so it can't start InSite2. The customer’s network may have been down.
7“Agent not running - waiting for modem dial-out to complete.”“InSite Stopped, Dialing Now”None – Normal status message
8“Agent not running - Modem dial-out failed.”“InSite Stopped, Dial Out Failed”
  • Check modem power
  • Check modem serial connection to Magmon3
  • Check modem connection to phone line
  • Check for an active phone line
  • Check connectivity configuration in Magmon3
  • Check with Online Center for modem activity
9“Agent running: Idle.”“InSite Running, Idle”None – Normal status message when InSite2 is running with no tasks to perform.
10“Agent running: Upload in progress.”“InSite Running, Uploading”None – Normal status message
11“Agent should be running but it has stopped responding.”“InSite Running, But Frozen”None – status message is displayed just prior to Magmon3 software performing a recovery.
12“Agent is being restarted because its log is too long.”“InSite Restart, Too Many Errors”Most likely a problem with the network that is generating numerous errors and filling up the log. If this entry continues to appear then capture the content of the InSite2 log file into a word file or email message and send to the Online Center for review and action.
13“Agent is being restarted because there is no agent log.”“InSite Restart, Internal Fault”None – An InSite2 log is generated whenever the Agent is started successfully. If for some reason the Agent did not start successfully it will automatically get restarted.
14“Agent is being restarted because it stopped responding.”“InSite Restart, Was Stuck”None – Normal status message if the InSite2 agent hangs and times out, the Magmon3 will automatically attempt to restart the agent.
15“Agent not running - Agent died. Possible registration problem.”“InSite Stopped, Net or Cfg Err”Conditions: Magmon3 contacted the back office but was rejected due to the following examples:
  • Duplicate names for system ID
  • Back office not recognizing the device type.
  • Back office server is down.
Action: Capture the content of the InSite2 log file into a word file or email message and send to the Online Center for review and action.
16“Agent running but can't connect to the back office.”“InSite Running, Can't Connect”Possibly a configuration problem with network addressing, proxy settings, netmask entries. Capture the content of the InSite2 log file into a word file or email message and send to the Online Center for review and action.
17“Agent registering with the back office.”“InSite Running, Registering”None – Normal status message
