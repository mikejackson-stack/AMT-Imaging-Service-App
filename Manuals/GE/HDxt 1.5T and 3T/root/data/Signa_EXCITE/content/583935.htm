Check RF Output Power

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable30 minsNot Applicable

2  Procedure

  1. Run SPT according to IBIS/PM Assist requirements.

  1. Verify that the SPT SNR Test (Head and Body) is within the following specifications:

    1. If the SNR test is within specification, the RF Output Power is OK. If it is out of specification, determine if the TG value is causing the failure. If the TG value is causing the failure, schedule time to adjust the RF Output Power.

    3  Finalization

    1. If TG Passes, none.

    1. If TG Fails Head refer to the appropriate document for the system type and adjust the Head Max Output Power:

    1. If TG Fails Body refer to the appropriate document for the system type and adjust the Body Max Output RF Power:
