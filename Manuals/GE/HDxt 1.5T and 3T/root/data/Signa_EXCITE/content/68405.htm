Magnet Enclosure Display Test

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable10 minsNot Applicable

2  Overview

This test provides a quick method of testing the displays and control panels.

3  Procedure

  1. Return cradle to Home position.

  1. Start the Magnet Enclosure Button Test as shown in Illustration 1.

    Illustration 1:  Starting Magnet Enclosure Button Test

  1. Verify all LEDs turn on, and that no LED remains on all the time during the test See Illustration 2.

    Illustration 2:  DISPLAY TEST INDICATORS

  1. Select [Stop Diags] to end the test. Select [Quit] to exit diagnostics.

4  Finalization

No finalization steps.
