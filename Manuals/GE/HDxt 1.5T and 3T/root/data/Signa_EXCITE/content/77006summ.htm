1  Required Conditions

ConditionReferenceEffectivity

Operating System Load was completed. The concept “Load from Warm” does not exist for this system. Do not attempt to short cut the process by just loading MR Applications.

-

-

2  Procedure

2.1   Configure and Load MR Applications

  1. Insert the MR Applications CD into the disk drive, and the CD will auto boot. When the message shown in Illustration 1 displays, click [Run Command].

    (Step Details)

  1. Click [OK] after confirming that the DASM (if applicable) was powered Off. (See Illustration 2.)

    (Step Details)

  1. Wait for the system to reboot. It will probe hardware, partition the hard drives, and then reboot.

    1. When a message dialog box in Illustration 3displays, click [OK] to close it.

    1. After the system reboots, the Linux desktop displays and the Guided Install screen (shown in Illustration 3) automatically launches about two minutes later.

    (Step Details)

  1. Insert the SaveInfo MOD into the MOD drive, and click [OK] when the message (shown in Illustration 4) displays.

    (Step Details)

  1. Once the GI Configuration load is complete, the Guided Install Verification tab (shown in Step ) displays.

    1. If the SaveInfo was performed on an 11.1 system that generated an IIS key, the Verification tab should activate the [Install Software] button shown in Step .

    1. If this button is not active, address any failing issues that exist before proceeding. (For help using Guided Install, see Host Reconfiguration.)

    (Step Details)

  1. Verify that the MR Applications CD is inserted and click [OK]. (See Illustration 6.) MR Applications takes about 5 minutes to load.

    (Step Details)

  1. Once the software installation is complete, remove the MR Applications CD from the disk drive and click <OK>. (See Illustration 7.)

    (Step Details)

2.2   Restore System Settings

  1. Insert the SaveInfo MOD into the MOD drive. From the Guided Install, select the Save/Restore tab. Click the [Restore Information] button shown in Illustration 8.

    (Step Details)

  1. Select [Restore all files automatically], and press [Continue] shown in Illustration 9.

    (Step Details)

  1. When it finishes and the message shown in Illustration 10displays, click <OK> to run Update Utility.

    (Step Details)

  1. When the message displays asking, Do you want to quit the tool, click <Yes>.

  1. When the message, Log file (restore.log) has been created in /usr/g/service/log directory displays, click <OK>.

  1. To restart the system, select [File] and [Quit], and click [Yes] when asked to confirm. (The system will reboot, and all changes made during the restore process will be set.)

2.3   Load Restricted or Advanced Service Software

  1. After the system reboots, log in as root with the password: operator.

  1. Click [Yes] to invoke Guided Install. (See Illustration 11.)

    (Step Details)

NOTICE
Restricted or Advanced Software must be loaded prior to loading Service Packs.
 
 

  1. Insert the Restricted or Advanced Service Software CD into the drive, and click the appropriate [Load Restricted Software] or [Load Advanced Software] on the Service SW/Insite tab. (See Illustration 12.)

    (Step Details)

  1. Read the proprietary statement shown in Illustration 13, and click the numbered buttons: [1], [2]and [3] in order.

    (Step Details)

NOTICE
Before loading Advanced or Restricted Service software, make sure the service key is inserted. If the service key is not inserted:

  • No error message will display to advise software did not load.

  • It will be necessary to shut down, log in as “root,” reload the software, and boot up again.

 
 

  1. When asked to insert the CD-ROM, confirm the Service Software disk is in the drive, and click [OK]. The load takes about 3 minutes.

NOTICE
InSite should only be configured after the service pack is installed. The following step does not display when loading Advanced software.
 
 

  1. Once complete, the system will launch the InSite configuration. Click [Accept] three times.

  1. From the InSite Interactive Platform Configuration screen, click [Exit] and continue to the patch installation. (See Installing Software Patches and Service Packs.)

    (Step Details)

2.4   Loading InSite Software

  1. After the system reboots, log in as root with the password: operator.

  1. Click [Yes] to invoke Guided Install. (GE Healthcare Field Engineers loading Restricted or Advanced Service Software should configure InSite at this time.)

    (Step Details)

  1. Following acceptance, the main tabs are initialized. (See Illustration 14.)

    (Step Details)

  1. If an InSite modem or broadband connection is not available or it will be configured later, select [Exit] and go to Step 14.

  1. Select the ProDiags tab to display the screen shown in Illustration 15.

  1. Click [Default] to configure the ProDiags feature with default schedules provided with the software. A status message, ProDiags Auto Setup: Completed Successfully, should display at the bottom of the screen.

    (Step Details)

  1. When the Health Page (shown in Illustration 16) displays, click in the Enter Address List field.

    (Step Details)

  1. Type a valid e-mail address with the format name@location into the Enter Address List field. Do not press the <Enter> key.

    (Step Details)

  1. Select the [Default] button to configure Health Page with the default schedule file.

    (Step Details)

  1. Select the appropriate Connection Device Type: Network or Modem. (See Illustration 17.)

    1. For a network connection, enter the IP Address where indicated in Illustration 17.

    1. For a modem connection, refer to Illustration 18 and select a Dial-out Prefix or type a site-specific prefix in this field.

      (Step Details)

    1. Select the Modem Type available at your site. (The Modem Type was recorded in the System Options Data Table.)

    1. Select [Apply] to set up registers on the modem, and store values to the modem's NVRAM. When the [Apply] button is selected, the Modem Readme screen (shown in Illustration 19) displays for the selected modem type.

    (Step Details)

  1. After properly verifying/configuring any switches or other modem parameters on the modem, select [OK], which will do the programming of the modem. The InSite Checkout tab (shown in Illustration 20) displays.

    (Step Details)

  1. Click [CHECKOUT NOW]. The InSite Checkout tab allows the user to complete the InSite configuration process.

    NOTE:[CHECKOUT NOW] configures PPP to allow a dial-in connection from the OLC. The user must call the local OLC to complete the checkout.

    1. If an InSite Checkout cannot be completed at this time, select [Cancel] followed by [Exit]after clicking [CHECKOUT NOW]. This will display the Exit Confirmation window shown in Illustration 21.

    1. Select [OK] to exit the InSite Configuration GUI. Exiting in this manner leaves the serial port of the computer enabled allowing the OLC to complete the checkout at a future time without requiring an FE on site.

      (Step Details)

    (Step Details)

  1. After [OK] is selected, an updated summary shown in Illustration 22 is provided.

    (Step Details)

  1. Select the [OK] button to exit the IIP Configuration Tool.

  1. Wait for the message Restricted Service load done in the Install GUI status bar at bottom of window.

3  Finalization

  1. Insert the MOD with the saved protocols.

  1. Select the Save/Restore tab, and click the [Restore Protocol] button.

  1. To exit Guided Install, select [File] then [Quit], and answer [Yes]. (If any error conditions still exist, Guided Install will force a fix of the errors or the changes will not be saved.)

  1. To log out of the system, right click on the desktop and select [Logout], and click [Yes] when the next prompt displays.

  1. Log back in as user: sdc and password: adw2.0.

  1. Reconnect the DASM if required.

  1. Restore YP Networking if required.

    (Step Details)
