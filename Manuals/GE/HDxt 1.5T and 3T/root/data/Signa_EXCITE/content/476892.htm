Respiratory Gain and Offset

1  Diagnostic Link

Diagnostics >> Peripherals >> PAC Diagnostics

2  Purpose

This test causes the PAC module to test its respiratory gain and offset circuits.

3  Components Tested

  • PAC Module

  • SPU (at the TRF board) and PAC communication link

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

None

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log. In the case of errors, click the 1st Error number to see the nature of the error. The recommendation is to view the GE System Log to view all recorded errors.

If this test fails, try running the PAC LED manual test (found in PAC Manual Help) to confirm that the SPU and PAC communication link is working, which then isolates the cause of the failure to the PAC module.

Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

8  Finalization

TPS Reset is required prior to scanning.
