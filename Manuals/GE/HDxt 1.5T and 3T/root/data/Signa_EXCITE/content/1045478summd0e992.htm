• For troubleshooting purposes, before performing a certain calibration (or task), it is beneficial to identify the pre-dependencies related to that calibration and consider performing them. If pre-dependencies are not run, the system will not be negatively affected.

  • Post dependencies are important. For example, if Gradshim is run, EPT and Probe Cal needs to be run after that as shown in Illustration 3. It is important that any calibration highlighted as a post dependency also be run immediately after the selected calibration.
