SaveInfo Backup File and Log File

1  SaveInfo Backup File

Beginning with software release Signa 9.1 and 10.0, whenever a SaveInfo is made a backup file is created of all the files saved to the SaveInfo MOD. This backup file is located in /usr/g/service/log/saveINFO.tar.gz and can be used to manually update configuration files in the advent the SaveInfo MOD becomes corrupted. It is suggested that a backup copy be keep by using FTP to move the file to the service laptop or other machine and saved.

To use the contents of this file is a manual process at the moment. Following is some quick steps for file example file recovery:

  1. Create a directory to move the backup file to. It is suggested to create the directory in /temp. If created there the files will be deleted on reboot saving disk space.

    > cd /temp<Enter> (Move to temp directory)

    > mkdir junk<Enter> (Create a directory named “junk”)

  2. Move or FTP your saved copy of saveINFO.tar.gz to /temp/junk

  3. Now unzip and tar the SaveInfo file.

    > gunzip saveINFO.tar.gz<Enter>

    > tar –xvf saveINFO.tar<Enter>

  4. You will now find a subdirectory tree created under /temp/junk. cd to /temp/junk/usr/g/MRINFO/holdingtank and you will find in that directory a directory tree similar to the Signa product directory tree. All the configuration files that where saved during the saveInfo can be found in the directory it came from on the system.

As an example assume the MRconfig.cfg file on you system became corrupted and you wanted to just replace that file. Unzip and tar the saveInfo file as show above. Then do the following command line step to replace the file:

> cp /temp/junk/usr/g/MRINFO/holdingtank/usr/gvx/w/config/MRconfig.cfg usr/g/MRINFO/holdingtank/usr/gvx/w/config/MRconfig.cfg<Enter>

In this example there is not enough room here to show it, but this whole statement is on one line with a space between MRconfig.cfg and usr. The system will ask if you want to over write the existing file. Answer yes.

Or, perhaps the you may not want to view the contents the older file and compare it’s contents to what is seen in the current config file. Then you would only need to do the following:

> more /temp/junk/usr/g/MRINFO/holdingtank/usr/gvx/w/config/MRconfig.cfg<Enter>

2  SaveInfo Log File

Beginning with software release Signa 9.1 and 10.0, SaveINFO now creates a log file in /usr/g/service/log directory called saveINFO.log. This file will list all the files that saveINFO was expecting to save but could not find on the system and hence could not save. Some of the files may be specific to TWIN or HFO or MGD systems and in those cases the log file will have a comment to that effect so that the FE is not confused. It is not required but is a good practice that this file is checked after a saveInfo to insure all files have been successfully saved.
