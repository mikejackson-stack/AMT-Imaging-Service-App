Switch Comm

1  Diagnostic Link

Diagnostics >> Peripherals >> Driver Module Diagnostics

2  Purpose

This diagnostic runs the patterns on the 16-channel switch LEDs for the specified Test Duration (max 300 secs).

3  Components Tested

Driver Module

4  Requirements

None

5  Expected Results

Note that the Ch 9-12 and Ch 13-16 LEDs will always be lit except when the Ch 1-4 and Ch 5-8 LEDs are in the J22 position.

# Ch 1-4 and Ch 5-8 LEDs cycle from J21 to J24

# Ch 1-4 and Ch 5-8 LEDs cycle from J24 to J21

If the test is repeated, there will be around a five (5) second pause in between the pattern repeating.
