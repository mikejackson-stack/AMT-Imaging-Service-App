2267807

Safe mode startup of the XGD (XPS-SB X axis) failed

Check EMO reset and perform a TPS reset. If this error occurs again, contact your service representative.
  1. Reference extended error message in from CSD error log, and perform all the recommended actions, especially with regards to fiber optics.
  2. Swap dual-fiber optic cable on failing axis with another at front of XPS Control Board (Example: swap Y and X fibers), then reset TPS.

    Illustration 14:  Fiber Optic Cable Connectors

    • If the problem moves: The problem is not in the XPS Control Board. Go to next section and swap dual-fiber cable at failing XPS.
    • If the problem does not move: At front of XPS Control Board try swapping the fiber optic transceiver module (also known as SFP; see below) on failing axis with another and perform TPS Reset.

      Illustration 15:  Fiber Optic Transceiver Module (SFP)

      • If problem moves: Fiber optic transceiver is faulty. You might be able to temporarily borrow “spare” SFP from unused J12 on IRF3 Board to get scanner operational. SFP in process of being made a FRU. Check FRU manual. Otherwise you must order replacement XPS Control Board.
      • If problem does not move: XPS Control Board is faulty. Order another.
  3. Swap dual-fiber cables at front of failing XPS module, then reset TPS.
    • If problem moves: The problem is not the fiber optic cable. Go to next section and swap fiber optic SFP on failing XPS.
    • If problem does not move: The fiber cable appears faulty. Please inspect and repair or replace. Check that it is seating properly into SFP.
  4. Swap fiber optic transceiver module (SFP) at front of failing XPS module with one from another unit. You might also be able to borrow one from unused J12 port on IRF3 Board in CAM chassis. Perform TPS Reset.
    • If problem moves: Fiber optic transceiver is faulty. Fiber optic transceiver in process of being made a FRU. Check FRU manual. Otherwise order replacement FRU XPS unit.
    • If problem does not move: Failing XPS module is faulty. Order another.
