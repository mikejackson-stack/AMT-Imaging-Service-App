Host-ICN Memory Stress Diagnostic

1  Diagnostic Link

Diagnostics => VRE Subsystem => VRE Communication and Hardware Diagnostic

2  Purpose

The purpose of this diagnostic is to stress the memory on the ICN. While this diagnostic is designed to stress the memory, it also makes heavy use of the DMA, main disk drive, and motherboard of the respective ICN.

3  Components Tested

  • ICN Memory

  • ICN Disk Drive (Slot 0)

  • ICN Motherboard

  • Host Ethernet Interface

  • Host to VRE Switch Ethernet Cable

  • VRE Switch to ICN Ethernet Cable

  • ICN Ethernet Interface

  • VRE Switch

4  Requirements

  • Silver SUN ICN or black Dedicated Computing ICN

  • ICN(s) turned on and at least one network connection from ICN motherboard Ethernet port(s) to Host

6  Test Sequence

  1. Select the ICN Memory Stress Diagnostic.

  2. Click [Run]. (The test takes about 15 minutes.)

    NOTE:Once [Run] is clicked, do not click anywhere else in the Common Service Desktop until the test is completed. To abort the test prior to its completion, click [Stop].

  3. Verify each tested ICN passed the diagnostic.

    Illustration 2 is an example of the output for a system containing a SUN ICN.

    Illustration 2:  Test Completion

  4. Perform a TPS reset after the test is completed.

7  Expected Results

Table 1:  Diagnostic Results

FaultProblem DescriptionGE Field Action
FAILEDThe ICN has failed the diagnostic.
  1. Make sure the Hard Disk Health Diagnostic runs successfully.
    • If that diagnostic fails, follow the steps described on the Help page for that diagnostic.
    • If the diagnostic succeeds, rerun the ICN Memory Stress diagnostic.
  2. If the diagnostic fails again, the entire ICN must be replaced. See ICN Replacements. The identity of the ICN will display in the ‘FAILED’ message or go to ICN Identification to identify the ICN (Utilities => Toolbox => VRE => ICN Identification).
ICN DisabledThe ICN has been disabled.Check Utilities => VRE => Disable/Enable ICNs.
