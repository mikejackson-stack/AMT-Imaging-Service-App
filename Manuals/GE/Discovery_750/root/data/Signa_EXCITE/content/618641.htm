ICN Remote Shell Diagnostic

1  Diagnostic Link

Diagnostics >> VRE Subsystem >> VRE Communication and Hardware Diagnostic

2  Purpose

The purpose of this diagnostic is to verify remote shell connectivity to the ICN.

This diagnostic attempts to execute a command on the ICN via the remote shell protocol.

3  Components Tested

Remote Shell service on the ICN

4  Requirements

ICN is turned on and has a network connection to the Host.

6  Test Sequence

  • Execute Diagnostic.

  • Verify each ICN tested passed the diagnostic.
