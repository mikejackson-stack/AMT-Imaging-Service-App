Amp RealTime Data

1  Diagnostic Link

Diagnostics >> Peripherals >> PHPS Functional Diagnostics

2  Purpose

This utility will print out realtime data from the Motor Amplifier.

3  Components Tested

The data printed on the screen is Temperature, Commanded Velocity, Actual Velocity, Commanded Current, and Actual Current.

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

  1. Select test.

  2. Enter in Test Duration in seconds.

  3. Click [Run].

7  Expected Results

This utility is useful to look at the data while the table is moving to determine any possible failures.
