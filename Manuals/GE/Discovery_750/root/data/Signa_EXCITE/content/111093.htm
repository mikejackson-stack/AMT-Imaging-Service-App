DANGER
FATAL ELECTRIC SHOCK HAZARD!!
Live voltages throughout the cabinet when energized.
TO PREVENT FATAL ELECTRIC SHOCK, MAKE SURE THE RF AMPLIFIER IS DISABLED WHEN CONFIGURING THE CALIBRATION TOOLS.

4  Procedure

4.1  BODY FORWARD POWER CALIBRATION

  1. Inhibit TR faults. Disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet), (see Illustration 1). Move switch 2 to the TR Disable position.

    Illustration 1:  Driver Module Switches

4.2  Setting up Software Tool to Calibrate UPM - Body Forward Power

This tool must see a Landmark only. It is not necessary to have a Body Phantom or Head coil in place, or any other scan parameter entered than what is described below. Simply Landmark on the cradle where the Head coil or Body Phantom would be.

  1. Start a [New Exam]

  1. Enter the following parameters:

    1. geservice

    1. Weight: 111

  1. Press the Align button on, (Land Mark).

  1. Move the cradle to the Home position and then drive it into the bore.

  1. Press Landmark button when the align light is approximately where the center of the Body Phantom would be. Press the Advance to Scan button.

  1. From the Common Service Desktop Select:

    1. Select [Calibration Tab]

    1. Select [UPM Tool]

    1. Start UPM tool from the Service Browser, (see Illustration 2).Illustration 3 shows an example of the UPM tool.

      Illustration 2:  Starting UPM Tool

      Illustration 3:  UPM GUI

      NOTE:The first time running the UPM Calibration tool after a load from cold, the following Error may appear: “The spectroRFampType and upm.config do not match! Please run the UPM Tool config file editor and hit [Restore Defaults] and save the config file”. If this error appears, click [File] -> “Edit Config”. When the window opens, click [Restore Defaults] then close the screen. The tool will now have the correct information and this pop-up will not appear again during future UPM Calibrations.

  1. Select the Nuclei [1H].

  1. Select the RF Chain you are going to calibrate [Body].

  1. Select: [Calibrate] Button

  1. Select Power Monitor type. [Forward]

  1. Select the [Start] button on the tool opened earlier, (see Illustration 3).

  1. Status should indicate Pass/Fail from 1 minute to 7.5 minutes depending on software version (tool should notify user of current step in progress). If failure occurs, see Universal Power Monitor (UPM) Troubleshooting.

  1. Proceed to the UPM-Body and Head Functional Check procedure, before moving to Finalization, Step 1.

5  Finalization

  1. Remove the cables and power measurement equipment.

  1. Re-enable T/R Drive fault detection. See Driver Module, Illustration 1.

  1. Upon completion of UPM calibration, [Reset TPS]. The system will not scan until this step is done
