3.0T HD 8CH Shoulder Array Coil FRUs and Replacement

1  Personnel Requirements

Required PersonsProcedure Timing
130 minutes

2  Procedure Overview

This document contains the cable replacement procedure for the 3.0T HD 8CH Shoulder Array Coil by NeoCoil, catalog M3340CC and the field replaceable units (FRUs) (see Section 5).

3  Preliminary Requirements

3.1  Tools and Test Equipment

Standard Tool Kit, Qty. 1

3.2  Replacement Parts

HD 8CH Shoulder Coil Cable Assembly, 5271265-3 (NeoCoil: NC008931), Qty. 1

4  Procedure

4.1  Cable Removal

NOTE:You will need the torque screw driver (8in-lbs) from the tool kit and the anti-static station.

  1. Remove screws from preamp housing.

  2. Carefully open housing halves and set aside cover.

  3. Remove four cable clamp screws from housing (see Illustration 1).

    Illustration 1:  Cable Clamp Screws

  4. Remove screws from four corner locations on the large PCB (see Illustration 2).

    Illustration 2:  PCB Screws

  5. Remove all eight cable connectors (see Illustration 3). Pull cable connector straight from socket to ensure no damage is done to the socket center pin. Check center pin for damage.

    Illustration 3:  Cable Connector Removal/Replacement

  6. Remove DC Connector (see Illustration 4). Use a flat screw driver to gently pry each side until loose.

    Illustration 4:  DC Connector

  7. Discard cable.

4.2  Cable Replacement

Table 1:  Cable Color Code

ChannelCoax Cable
1Brown
2Red
3Green
4Blue
5Black
6Gray
7White
8Clear

  1. Following the color code in Table 1, attach the new cable connectors (see Illustration 3) and DC Connector (see Illustration 4).

  2. Set PCB assembly into housing and replace screws to 8in-lbs. (see Illustration 5). Pay close attention to the positioning of the cables.

    Illustration 5:  Coil Cable Placement

  3. Replace cable clamp screws and torque to 8in-lbs.

  4. Carefully replace cover ensuring no cables or wires are pinched by the housing.

  5. Replace housing screws and torque to 8in-lbs.
