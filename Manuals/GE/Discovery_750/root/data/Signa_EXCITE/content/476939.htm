SRI SCP Loop Test

1  Diagnostic Link

Diagnostics >> Peripherals >> SRI Data Paths

2  Purpose

This diagnostic verifies that the SRI serial communication path on the SCP board in the MGD chassis is working correctly.

3  Components Tested

The SCP board is the only hardware tested. The internal serial communication path on the SCP is tested. The SRI and STIF board are not tested.

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

The test executes the following steps:

  1. The SCP transmits a data packet through the SRI serial port on the SCP board.

  2. The serial data is internally looped back into the SRI serial port.

  3. The SCP verifies that it received the same data that was sent.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error, it is recommended that you view the GE System Log to view all the errors that were recorded.
