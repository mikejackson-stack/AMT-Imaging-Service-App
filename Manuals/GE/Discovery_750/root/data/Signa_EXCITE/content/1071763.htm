3.1.2  Setting Up Software Tool to Calibrate UPM – MNS Functional Check

NOTICE
It is necessary to have a MNS T/R Switch connected to the A Connector.
 
 

  1. Landmark on the cradle in the location where the head coil would normally reside. Press Advance to Scan.

  1. From the Common Service Desktop, access the Install Calibration Wizard:

    1. For UPM Calibration (MNS), click [Click here to start this tool].

    1. For the Class A service tool:

      1. Select the Calibration tab.

      1. Select the UPM Tool from the calibration menu and click [Click here to start this tool].

  1. For Nuclei select [31P]. For RF Chain, [MNS] will automatically be selected.

  1. Select the [Func Chk] button.

  1. Click on the [Start] button.

  1. After that the tool takes full control and runs the functional test.

  1. The user will be prompted as the UPM Host Trip test completes. Look in the error log to confirm that the test completed successfully, and a trip error occurred.

  1. The UPM status should indicate Pass or Fail.

    1. If the test passes, select [Quit] from the UPM Main Window.

    1. If the test fails, refer to UPM - Body & Head Functional Check.

3.2  Troubleshooting UPM MNS

  1. Solution 1:

    1. Check all cabling to the UPM-Boards to make sure that they are properly cabled.

    1. Repeat the UPM Functional Test (MNS).

  1. Solution 2: Recheck RF amplifier output.

    1. Cycle power to the UPM Chassis.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (MNS).

  1. Solution 3: Reboot the system. Repeat the UPM Functional Test (MNS).

  1. Solution 4:

    1. Remove power from the UPM.

    1. Re-seat the processor module.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (MNS).

  1. Solution 5:

    1. Remove power from the UPM.

    1. Reset the MNS detector boards.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (MNS).

  1. Solution 6: The problem could be a bad processor module

    1. Remove power from the UPM.

    1. Replace the processor module.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (MNS).

  1. Solution 7: The problem could be a bad detector board.

    1. Remove power from the UPM.

    1. Replace both detector boards.

    1. Restore power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM MNS Functional Test.

  1. For additional troubleshooting information, please refer to Universal Power Monitor (UPM) Troubleshooting.

3.3  UPM Theory

The Universal Power Monitor calibration parameters found in the UPM Calibration file (/export/home/signa/tools/upm.config) are used in the calibration/Functional Check program. The Program code sets the Digital attenuators in the UPM based on the results of the tests run, and a comparison to these UPM Calibration parameters. This calibration file is accessible from within the UPM Calibration tool from the File pull-down Menu, Edit Config option. These values can be edited and saved during troubleshooting to perhaps understand where the power monitor is tripping, (If at all). Before changing any parameter, make sure to select and run the Bkup UPM Cal option first. This will allow you to return to the default values at any time. The screen shot of the UPM Calibration file shown in Illustration 4 contains the default configuration values for all of the UPM parameters. This screen is just for reference, as the content and values will be different based on the system type and calibration results. (Use the [Restore Defaults] on the config file editor GUI (graphic user interface) to always get back to known default values). The final UPM digital attenuator values are written to the UPM Calibration Configuration files (Upm1Cal.cfg, Upm1Cal.cfg.etc.,) located in directory: w/config

  1. The format of Upm1Cal.cfg and Upm2Cal.cfg example is as follows:

    1. 85←Head FORWARD Power, attenuator setting in HEX

    1. 9f←Head REFLECTED Power, attenuator setting in HEX

    1. 0← Head Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. 8d← Body FORWARD Power, attenuator setting in HEX

    1. 8e←Body REFLECTED Power, attenuator setting in HEX

    1. 9d←Body Quad Hybrid Reflected Power, attenuator setting in HEX

    1. 93←MNS FORWARD Power, attenuator setting in HEX

    1. 83←MNS REFLECTED Power, attenuator setting in HEX

    1. 0 ← MNS Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. 0 ←CW FORWARD Power, attenuator setting in HEX (currently not used)

    1. 0←CW REFLECTED Power, attenuator setting in HEX (currently not used)

    1. 0←CW Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

  1. See Illustration 4. Any changes to these values are temporary and can be quickly restored by selecting the restore defaults button.

    Illustration 4:  UPM Config Editor

4  Finalization

  1. Place RF ENABLE S2 in disable (down) position.

  1. Remove the cables and measurement equipment.

  1. Reattach the J4 RF OUT cable.

  1. To re-enable fault detection, set switch SW2 on driver module to enable (up) position.

  1. Place RF ENABLE S2 in enable (up) position.

  1. Complete a TPS reset.

  1. Perform a MNS functional check.

  1. Any failure will require a re-calibration of the UPM system. See Universal Power Monitor - MNS Setup and Calibration.
