SRF to RRX + DTX Data Path Diagnostic

1  Diagnostic Link

Diagnostics >> System Function >> RF >> Receiver Diagnostics

Diagnostics >> Hardware Location >> Magnet Room >> Receiver Diagnostics

Illustration 1:  Receiver Diagnostics

2  Purpose

The SRF to RRX + DTX data path diagnostic tests the IRF3’s ability to send sequence bus data to the DTX and RRX modules. The IRF3 to XGD sequence data transfer, on the other hand, is tested in the Gradient Hammer diagnostic. All of the sequence bus data registers of the RRX and DTX modules are tested to ensure they capture the correct data from the sequence data stream. The AGP Board runs the test.

3  Components Tested

Boards Tested

  • IRF3

  • DTX-1

  • DTX-2 (if MNS option installed)

  • RRX-1 (if 16-channel or 32-channel)

  • RRX-2 (if 32-channel)

4  Requirements

None

6  Test Sequence

  1. Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostic.

  2. Click [Run] to initiate test.

    NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. These settings rarely ever need to be changed.

7  Expected Results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log. It is recommended to review all the errors recorded in this log. If there are errors, click the 1st Error number to see the nature of the error and continue viewing each error in this fashion.

If DTX-1 Board is replaced, run:

  • Body and Head Maximum Power Setup and Calibration

  • UPM - Head and Body Setup and Calibration

If DTX-2 Board is replaced, run MNS Amplifier Calibration.

No calibration is needed if the Receiver, IRF or AGP are replaced.
