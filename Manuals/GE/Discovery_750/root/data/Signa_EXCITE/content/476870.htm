Keyboard Functional Diagnostics

1  Diagnostic Link

Diagnostics>>Peripherals>>Keyboard Functional Diagnostics>>Keyboard Processor Diagnostics

2  Purpose

This test provides a means for checking the functionality of the hard keys at the top of the keyboard assembly. Clicking [Run] and then pressing one of the five (5) keys will cause the name of the key to be displayed in the Test Results field. Releasing the key will result in its name no longer being displayed.

3  Components Tested

The following keys can be tested.

  • <Start Scan>

  • <Pause> (<Pause Scan> on newer keyboards)

  • <Stop Scan>

  • <Advance To Scan>

  • <Stop Table>

4  Requirements

None

5  Block Diagram

None

6  Test Sequence

To verify that a hard key is working, click [Run] and then press each key. As each key is pressed, verify that its name shows up in the Test Results field and is removed when the key is released.

7  Expected Results

Button status displayed on diagnostic screen.
