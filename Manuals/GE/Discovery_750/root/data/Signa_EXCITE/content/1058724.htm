System Block Diagrams

1  Overview

The purpose of this document is to provide an overview of the hardware that makes up the MR system and a quick means to troubleshoot major signals within the system. Overall System diagrams show how the major subsystems are grouped by cabinet and the main communication lines between them. The remaining block diagrams are organized into sections that correspond to major subsystems. Some diagrams show hardware from another subsystem in order to complete an entire signal flow route. For such exceptions, the board/module title of the circuitry shown will generally help identify the applicable subsystem.

These block diagrams, along with provided diagnostics, are intended to be the primary tools for troubleshooting the MR System from a system or subsystem level to the specific module or board level. When using the diagnostics, the block diagrams can provide a better understanding of what circuitry the diagnostics is testing, and how to further isolate a problem if required.
