Error Number Decoder

1  Navigation Link

Utilities >> Error Number Decoder

Illustration 1:  Error Number Detector

2  Overview

The Error Number Decoder Tool displays the message text associated with a specific error number.

3  Procedure

  1. From the Service Desktop, select the [Utilities] tab. See Illustration 1.

  2. Click [Error Number Decoder], then select the [Click here to start this tool] link.

  3. The Decoder tool starts in a window with the prompt Please enter the error No. (s or q to quit).

  4. Enter the appropriate error number. The system displays the corresponding message text.
