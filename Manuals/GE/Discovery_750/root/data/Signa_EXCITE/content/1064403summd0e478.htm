NOTE:Observe the following:

  • If there are unknown coils that do not map to a known Coil Config such as a Research coil, inform the Customer of the situation. GE Service must not change individual parameters for research coils. The Customer must work with the Coil Vendor in this case to obtain the proper Coil Config file.

  • If unknown coils are found, finish the software load then go to CSD, Configuration, Config File Manager, then CoilConfig. Select the Manage Unknown Coil option, and add all Unknown Coils. For instructions on how to properly manage Unknown Coils reference the service methods instructions: Unknown Coils Configuration Procedure.
