ICN Identification (Sun 4100)

2  Overview

Each ICN has a Host name. If there are two ICNs, one would be ICN1 and the other ICN2. This tool determines which is ICN1 and which is ICN2.

This tool applies to systems in a multiple ICN configuration only. It allows the user to physically identify which ICN has a host name of ICN1 and ICN2 for troubleshooting and repair procedures.

3  Procedure

  1. Go to Utilities → Toolbox → VRE → ICN Identification. (Shown below.)

    Illustration 1:  ICN Identification

  1. The ICN selected will be identified by a flashing LED on the front chassis. Select the identification time from the drop-down menu.

    NOTE:The default time is 30 seconds. The LED can flash up to 5 minutes.
