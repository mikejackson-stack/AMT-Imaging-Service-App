2  Overview

Follow this process to install the 3.0T HD Neurovascular Array by GE/USAI (M1385AT).

Last Updated03/16/2007

3  Procedure

  1. Ensure that the coil is properly configured for the ramp direction of the magnet. See the label and instructions on the posterior cover of the coil for details.

  1. Go to the Service Desktop and start the Service Desktop Browser if it's not already running.

  1. Follow the steps shown in Illustration 1.

    Illustration 1:  Starting the Config. File Manager

  1. Click the [CoilConfig]button on the left. The following screen will appear, see Illustration 2.

    Illustration 2:  CoilConfig Screen

  1. Add the following coil name(s) to the list of site coils.

    • HDNV Array

    • HDNV Head

    • HDNV Spectro

    • HDNV ArrayServ

    • HDNV HeadServ

    • HDNV SpectroServ

  1. Add the following traced part number(s) to product locator: 2414383.
