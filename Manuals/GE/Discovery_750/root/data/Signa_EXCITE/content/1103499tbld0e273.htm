Table 3:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities → Toolbox → VRE → ICN Identification).
  2. Ensure that the Ethernet switch is turned on.
  3. Ensure that the Host-ICN Remote Shell diagnostic runs successfully.
    1. If the diagnostic fails, follow the steps described on the Help page for that diagnostic.
    2. If the diagnostic succeeds, rerun the appropriate diagnostic (ICN Memory Stress or ICN Hard Disk Health).
  4. If the diagnostic fails after a second attempt, run the ICN Hard Disk Stress diagnostic.
    1. If the diagnostic fails, check the hard disk. Look at the System Error Log for the corresponding error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities → Toolbox → VRE → ICN Identification).
    2. If the diagnostic succeeds, rerun the appropriate diagnostic (ICN Memory Stress or ICN Hard Disk Health).
  5. If the diagnostic fails after a third attempt, run the ICN Hard Disk Integrity diagnostic.
    NOTE:The ICN Hard Disk Integrity diagnostic takes about 85 minutes to complete.

    1. If the ICN Hard Disk Integrity diagnostic fails, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities → Toolbox → VRE → ICN Identification).
    2. If the diagnostic succeeds, rerun the appropriate diagnostic (ICN Memory Stress or ICN Hard Disk Health).
  6. If the diagnostic fails again, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities → Toolbox → VRE → ICN Identification).
    NOTE:If the ICN Ethernet port/cables are faulty all the tests for that ICN may fail. This does not apply to the IPMI test, which has a separate Ethernet cable.

    The current product configuration has redundant motherboard Ethernet connection for each ICN.
