2  Overview

This procedure describes the steps for HP xw8400 Memory Module replacement.

Memory module features:

  • 8 memory slots for DIMMS

  • 1-GB and 2-GB DIMMs allowed

  • 8 GB maximum configuration

  • Supports single-channel or dual-channel DIMMs

  • Supports DDR2-667

  • No support for mirroring, no spare DIMM support

  • Standard ECC (72-bit ECC)

3.3  Safety

CAUTION
System Board or Component Damage!
The cooling fan is off only when the workstation is turned off or the power cable is disconnected. The cooling fan is always on when the workstation is in On or Standby mode.
Disconnect the power cord from the power source before opening the workstation.

CAUTION
Memory Module Damage During Removal or Installation!
Memory modules may be damaged, and the system will not recognize the memory changes if the power cord is not unplugged while installing memory.
Power off the workstation and unplug the power cord from the AC power outlet. Wait until the LED on the back of the power supply turns off before removing the memory modules.

NOTICE
Turn off the workstation before disconnecting any cables.
 
 

NOTICE
To prevent damage to equipment components, observe the following Electro-Static Discharge (ESD) precautions:

  • Work on a static-free mat.

  • Wear a static strap to ensure that any accumulated electro-static charge is discharged from your body to the ground.

  • Create a common ground for the equipment you are working on by connecting the static-free mat, static strap, and peripheral units to that piece of equipment.

For further information regarding ESD protection, refer to the Safety chapter in this publication.

4  Procedure

4.1  Workstation Service Preparation

Before servicing the workstation:

  1. Remove/disengage any security devices that prohibit opening the workstation.

  1. Disconnect all peripheral device cables from the workstation.

  1. Perform theLOTO Global Operator Console/Operator Workspace procedure before beginning the replacement.

  1. Remove the two screws that secure the left side panel.

    Illustration 1:  Screws to Remove

  1. Remove the left side panel of the GOC by lifting up. Avoid straining the short ground lead that connects the cover to the GOC chassis. It can be disconnected at the middle junction if necessary.

    Illustration 2:  Left Side Panel Ground Lead

  1. Lift up on the latch and remove the left side panel of the PC.

    Illustration 3:  Removing Left PC Panel

  1. Lay the workstation on its side with the system board facing up.

4.2  System/Memory Fan Assembly Removal

  1. Press down on the green release latch at the bottom of the system/memory fan assembly (shown below), and rotate the memory fan holder up until it snaps into a vertical position.

    Illustration 4:  System/Memory Fan Assembly Latch

  1. Disconnect the system and memory fan cables from the system board.

  1. Press down (as shown) on the top of the system/memory fan assembly to release the retaining latch.

    Illustration 5:  Removing Retaining Latch on Assembly

  1. Rotate the assembly inward until the hinge tabs on the bottom of the assembly are released.

  1. Lift and remove the system/memory fan assembly from the chassis.

4.3  Memory Module Removal

  1. Gently push out and down on the socket levers on each side of the slot that contains the suspected faulty memory module. (See Illustration 6 for slot locations.)

    Illustration 6:  Socket Levers on Slot Locations

  1. Lift the DIMM straight up and remove it from the unit as shown.

    Illustration 7:  Removing DIMM

  1. Ensure that the socket levers are still out and away from the memory slot.

NOTICE
DIMMs and the DIMM sockets are keyed for proper installation. Be sure these guides line up before pushing down in the step below.
 
 

  1. Place the new memory module into the slot, and push down firmly until the memory socket levers snap into place.

  1. Ensure that the module is fully inserted and properly seated in the slot.

4.4  System/Memory Fan Assembly Replacement

  1. Insert the hinge tabs on the bottom of the system/memory fan assembly into the slot on the chassis as shown.

    Illustration 8:  Inserting System/Memory Module Fan Assembly

  1. Rotate the top of the assembly up until the retaining latch snaps into the slot on the chassis (Illustration 9).

    Illustration 9:  Latched System/Memory Module Fan Assembly

  1. Reconnect the system and memory fan cables to the system board.

  1. Rotate the System/Memory Fan Assembly holder down until it snaps into a horizontal position as shown.

    Illustration 10:  Horizontal Position for System/Memory Module Fan

4.5  Memory Module Installation Considerations

When installing a memory module, be aware of the following considerations:

  1. Memory modules must be loaded in valid configurations, which are:

    • Four 1 GB modules in slots 1, 3, 5, 7 for Hosts 5183547-31, 5183547-41, 5183547-59, and 5183547-60 for a total of 4 GB.

    • Four 2 GB modules in slots 1, 3, 5, 7 for Host 5183547-30 for a total of 8 GB.

  1. Match multiple DIMMs by size and type.

  1. Socket configurations are show in the following table:

    Number of DIMMs to InstallSockets to Use
    11
    21, 3
    41, 3, 5, 7
    61, 2, 3, 4, 5, 7
    8All sockets
    NOTE:In DDR2 mode, dual-rank DIMMs are placed farther from the Memory Controller Hub (MCH) than single-rank DIMMs.

    The BIOS generates warnings/errors on invalid memory configurations.

    • If unable to obtain a valid memory configuration by disabling some of the plugged-in memory, the BIOS will halt with a diagnostics 2004 code for memory error (four beeps/blinks).

    • If the BIOS finds a valid memory configuration by disabling some of the plugged-in memory, it does so and reports a warning during Post, 215-mismatched memory.

      NOTE:The system can still be booted in this condition.

5  Finalization

  1. Replace and secure all cables and covers.

  1. Perform LOTO to restore power to the GOC and Operator Workspace.

  1. Run HP Linux PC Service Diagnostics using the HP Diagnostics Tool.

  1. Reboot and ensure that no memory BIOS errors are observed during this process.

  1. Perform a scan to ensure the system is operating properly.
