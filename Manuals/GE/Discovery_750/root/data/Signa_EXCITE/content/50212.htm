Troubleshooting EPI Ghosting Problems

NOTE:Running SCT (Short Cross Term calibration) as described in EPT calibration procedure may help reduce ghosting.

Troubleshooting EPI ghosting problems is often very challenging, given that EPI has so many mechanisms that contribute to ghosting. This checklist is designed to provide a structured approach to correcting EPI ghosting problems in EXCITE (12x & 14x) systems (do not use this document to troubleshoot ( 10x & 11x) systems). Here is how to check what revision software (compare the MR Software release number) your system has loaded:

NOTE:Revision may be later than what is shown.

Start by comparing the customer’s ghosted images to the examples in Troubleshooting Using EPT. Each example has a list of things to check to eliminate that particular type of ghosting, with the most likely causes (or checks taking the least amount of time) listed first. Go to EPI Ghosting Checks for instructions on how to perform each check. If you are instructed to run EPT then run it as described at the top of Troubleshooting Using EPT. Calibration File Format is a discussion of grafidy file format.
