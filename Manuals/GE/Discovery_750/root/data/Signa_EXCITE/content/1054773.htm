RF Hub Shutdown Diagnostic

1  Diagnostic Link

Diagnostics >> System Function >> RF >> RF Hub Board Level Diagnostics

Diagnostics >> Hardware Location >> Magnet Room >> RF Hub Board Level Diagnostics

Illustration 1:  RF Hub Board Level Diagnostics

2  Purpose

The purpose of this test is to diagnose problems that prevent the RF Hub from shutting down, or force it to prematurely wake up.

3  Components Tested

RF Hub

4  Requirements

There are no requirements.

5  Block Diagram

For further information, refer to the Interactive Block Diagrams.

6  Test Sequence

  1. Click [Calculate Time] to get an estimate of the time it will take to run the selected diagnostics.

  2. Click [Run] to initiate test.

NOTE:The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

7  Expected Results

Any failure is accompanied by an additional error message in the GE System Log with the details of why the shutdown was prevented, or the reason that the wakeup occurred.

8  Finalization

No finalization required.
