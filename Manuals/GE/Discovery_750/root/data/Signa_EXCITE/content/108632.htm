4  Procedure

4.1  HEAD FORWARD POWER CALIBRATION

  1. Inhibit TR faults. Disable the Driver Module TR fault detection in the RFS (RF in the System Cabinet), (see Illustration 1). Move switch 2 to the TR Disable position.

    Illustration 1:  Driver Module Front Switches

4.2  Setting up Software Tool to Calibrate UPM – Head Forward Power

NOTE:This tool must see a Landmark only. It is not necessary to have a Head coil in place, or any other scan parameter entered than what is described below. Simply Landmark on the cradle where the Head coil would be.

  1. To establish a Landmark, Start a [New Exam].

  1. Enter the following parameters:

    1. Patient ID: geservice

    1. Weight: 111

  1. Press [Align] button on.

  1. Move the cradle to the Home position and then drive it into the bore.

  1. Press Landmark button when the align light is approximately where the center of the head coil would be. Press the Advance to Scan button.

  1. From the Common Service Desktop Select:

    1. Select [Calibration Tab]

    1. Select [UPM Tool]. Illustration 2.

      Illustration 2:  Starting UPM Tool

    1. Select [Click here to start the tool] to start UPM tool. See Illustration 2.

  1. Select the Nuclei [1H]. See Illustration 3.

    Illustration 3:  UPM Monitor Tool GUI

    NOTE:The first time running the UPM Calibration tool after a load from cold, the following Error may appear: “The spectroRFampType and upm.config do not match! Please run the UPM Tool config file editor and hit [Restore Defaults] and save the config file”. If this error appears, click [File] -> “Edit Config”. When the window opens, click [Restore Defaults] then close the screen. The tool will now have the correct information and this pop-up will not appear again during future UPM Calibrations.

  1. Select the RF Chain you are going to calibrate [Head].

  1. Select: [Calibrate] Button

  1. Select Power Monitor type. [Forward].

  1. Select [Start] button.

    NOTE:Advisory message indicating head coil not present can be ignored.

  1. Status should indicate Pass/Fail from 1 minute to 7.5 minutes depending on software version (tool should notify user of current step in progress). If Failure occurs, see Universal Power Monitor (UPM) Troubleshooting.

  1. Proceed to UPM- Body and Head Functional Check before moving to Finalization, Step 1.

5  Finalization

  1. Remove the cables and power measurement equipment.

  1. Re-attach the Head and Body Heliax Cables.

  1. Remove the cables and power measurement equipment.

  1. Re-attach the Head Heliax Cables.

  1. Re-enable T/R Drive fault detection. See Illustration 1.

  1. Upon completion of any UPM calibration, [Reset TPS]. The system will not scan until this step is complete.
