Troubleshooting EPI Ghosting Problems

Troubleshooting Echo Planar Image (EPI) ghosting problems is often very challenging, given the many ghosting mechanisms of EPI. This checklist is designed to provide a structured approach to correcting EPI ghosting problems in DVMR 20x systems.

Start by comparing the ghosted EPI images of the customer to the examples in Troubleshooting Using EPT. Each example has a list of things to check to eliminate that particular type of ghosting, with the most likely causes (or checks taking the least amount of time) listed first. Go to EPI Ghosting Checks for instructions on how to perform each check. If you are instructed to run an Echo Planar Test (EPT) then run it as described at the top of Troubleshooting Using EPT.
