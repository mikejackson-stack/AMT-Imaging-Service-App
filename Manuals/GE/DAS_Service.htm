📡 GE MRI DAS & Communication Fault Guide
AMT Imaging Solutions — Field Service Quick Reference

Applies to: GE Signa Excite (9x–15x), HDxt, Discovery MR450/750, Optima 450w/750w. Covers Error E601 (DAS communication fault), subsystem communication failures, and related diagnostics.

Error E601 — DAS Communication Fault

CheckAction
DAS Power and StatusCheck DAS power supply in the electronics cabinet. Verify green status LEDs on DAS board(s). A power-cycled DAS board will typically recover from soft communication errors. Run: MR Service Desktop → Diagnostics → System Function → DAS.
DAS Cable ConnectionsInspect the fiber optic cables from the DAS boards to the system electronics. These are typically orange or yellow fiber cables. Check both ends for seating and physical damage. Fiber breaks near cable tie points are common after years of table motion vibration.
DAS Board ReseatingWith system powered down and discharged, reseat DAS boards in their card cage slots. Oxidized edge connectors can cause intermittent E601. Clean edge connectors with contact cleaner if oxidized.
Reconstruction / Data Path TestRun the full data path self-test: MR Service Desktop → Diagnostics → System Function → Recon → Data Path Test. This verifies end-to-end communication from DAS through reconstruction.
Network / Host CommunicationE601 can also occur from host computer communication faults. Check Ethernet connections between acquisition computer (ACQ) and host. Ping test between subsystems in service network diagnostics.
Temperature / Thermal StateDAS communication faults that appear after extended scanning may be thermally driven. Check DAS board temperature via Service Desktop. Ensure DAS board cooling fans are operating. Clean DAS air filter.

E601 Scenario Troubleshooting

SymptomLikely CauseFix
E601 on startup, clears after power cycleDAS boot sequence timeout — soft faultPower cycle the DAS subsystem from service menu. Check DAS initialization sequence in error log. If fault clears reliably on retry, monitor for recurrence. Reseat DAS fiber connections.
E601 intermittent — occurs randomly during scansMarginal fiber optic connection; DAS board failingFlex DAS fiber cables while monitoring Service Desktop for fault recurrence. Identify loose connector. Replace fiber segment or DAS board as indicated.
E601 persistent — system will not initializeDAS board failure; DAS power supply fault; fiber completely brokenInspect DAS board for fault LED. Measure DAS power supply voltages (+5V, +12V). Replace DAS board or power supply as indicated. Replace fiber if physically damaged.
E601 with image artifacts (banding, noise)DAS board partially functional — some channels droppedRun DAS channel test. Identify failed channel(s). Replace DAS board. Run air calibration after replacement to baseline new board.
E601 after power outageDAS corrupted by unclean power loss; DAS NVRAM issueRun DAS initialization from Service Desktop. If DAS fails to initialize, perform DAS board reset procedure per service manual. In severe cases, DAS board swap may be needed.

GE MRI Communication Architecture (Quick Reference)

Understanding the communication chain helps narrow fault location. E601 can originate anywhere in the DAS-to-host data path.
SubsystemCommunication LinkCommon Failure Mode
DAS Boards → ACQ ComputerFiber optic (high-speed data)Fiber break, dirty connector, bent fiber near cable tie
ACQ → Recon (RCB)Internal backplane or EthernetBackplane connector, ACQ network card fault
Recon → HostGigabit EthernetNetwork card, switch, or cable fault

RF Electronics → HostInternal bus + EthernetRF control board failure — may cause concurrent E305 or comm-related RF faults

Tip: The most common E601 cause on aging GE systems is a degraded fiber optic connection — either a dirty end-face or a hairline crack near a cable tie or bend point. Cleaning or reseating the fiber is the first thing to try and costs nothing.
Tip: Use MR Service Desktop → Diagnostics → System Function → DAS before touching any hardware. The diagnostic often identifies the specific DAS board or channel causing the fault, narrowing the repair significantly.
