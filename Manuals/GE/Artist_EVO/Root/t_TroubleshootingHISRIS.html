Troubleshooting HIS/RIS

Follow this procedure to troubleshoot HIS/RIS.

About this task

Check with the local IT that the MR is set up correctly in the HIS/RIS system. Ask the customer to send a simulated appointment to MR and another modality, for example CT, to make sure the local Modality Work List (MWL) server is working as expected.

Procedure

  1. Under Connectivity, select HIS/RIS.
  2. Make sure the Hospital Name, Suite ID, Host ID, and Local AE Title are correct for the MR system. The Local Port Number (Host Port) should be set to 4000 [same as the Digital Imaging and Communications in Medicine (DICOM) networking port number for MR systems]. These are the parameters that the hospital RIS system uses to identify our system.
  3. Under MWL Configuration, select SCP Configuration.
  4. Make sure of the following information with the site network administrator:
    • Host Name is the site name.
    • AE Title is the MWL Application Entity (AE) title of the RIS system of the site.
    • IP Address is the internet protocol (IP) address of the RIS server.
    • Port Number is the port number of the RIS system of the site.
  5. Under Home, select Verification.
  6. Select Configure and make sure there are no errors.
  7. Do a check of the general network connectivity by checking other MR network communications. For example, to the workstation, or try a plain ping to the MWL SCP IP address.
  8. Select File > Quit.
