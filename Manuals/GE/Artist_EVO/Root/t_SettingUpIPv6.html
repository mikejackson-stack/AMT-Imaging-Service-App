Setting up IPv6 for software versions DV26

About this task

The IPv6 transformer provides communication capability between the MR console, IPv6 devices, and IPv4 devices. The FE must work with a site IT administrator to do this procedure.

Procedure

  1. Insert the IPv4-IPv6 transformer power cable into the transformer power jack.
  2. Connect the power cable to the wall socket to power up the transformer.
  3. Make sure the green LED on the front panel of transformer lights up.
  4. Connect the transformer’s IPv4 port to the MR console external network port.
  5. Connect the IPv4-IPv6 transformer’s network port to the network.
    Table 1. IPv4-IPv6 transformer
    Item Feature Description
    1Serial port9-pin serial console interface (only used if unable to connect to Web UI)
    2IPv4 deviceLAN port: To be connected to MR console
    3NetworkLAN port: To be connected to the network
    4Power receptacle AC power receptacle
