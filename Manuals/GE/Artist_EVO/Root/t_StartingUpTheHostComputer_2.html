Starting up the host computer

How to start the host computer.

About this task

Most service functionality, including software updates and patches, can be completed with operator-level privileges. Because logging on as a super user allows you to make changes that can do irreparable damage to the system, do not log on as root unless necessary.
Note: During some startups or restarts, the system may seem to have stalled. The system startup process can take an extended period of time. Give the system at least 30 minutes before calling the GE HealthCare Online Center.

Procedure

  1. To power on the system, press the cabinet button switch on the Global Operator Cabinet (GOC).
  2. Note: As the host computer starts up, the Linux operating system launches. A welcome screen shows with a logon prompt.
    Log on with an appropriate user name and password based on the system software version.
    Note: It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.

    Result

    Logging on as an operator brings up the applications desktop. A window appears that shows the message: 
    Please do not interact with the system until this message disappears.
