Applies to: GE Signa Excite (9x–15x), HDxt, Discovery MR450/750, Optima 450w/750w and related platforms. RF error code E305 and related RF fault diagnostics.

Error E305 — RF Amplifier Fault

CheckAction
RF Amp CoolingVerify RF amp cabinet fans are running. Check air filter — clean if clogged. Verify exhaust path is unobstructed. RF amp overheat is the #1 cause of E305.
RF Amp Power SupplyCheck DC power supply rails to RF amp. Measure +28V, +15V, -15V at test points per service manual for your platform. Use MR Service Desktop → Amp Real Time Data.
RF Amp ConnectionsInspect all RF cable connections at the amplifier — power cables, coax, control lines. Reseat all connectors.
Body Coil InterfaceA body coil impedance mismatch can cause RF amp protection to trip. Run Transmit/Receive diagnostic. Check body coil tuning and matching.
RF Amp Self-TestRun RF Amplifier Diagnostics: MR Service Desktop → Diagnostics → System Function → RF → RF Amplifier. Note any failed tests.
DD/TR Bias LinesCheck DD (dynamic disable) and TR (transmit/receive) bias current draw. Run Gather Load Data test: Diagnostics → System Function → RF → Driver Module Diagnostics.

Common RF Fault Scenarios

SymptomLikely CauseFix
E305 on startup onlyRF amp DC rails slow to stabilize; power supply agingTest DC supply voltages on cold start. Replace power supply if rails below spec.
E305 after several scans (intermittent)Thermal shutdown from cooling inadequacyClean air filters. Verify room ambient temp <22°C. Check cooling fans at RF amp.
E305 with every scanRF amp output stage failure; coil mismatchRun RF diagnostics. Test with body coil only. If E305 clears with body coil, fault is in surface coil path. If E305 persists, RF amp output stage replacement needed.
SAR errors / flip angle errorsRF power calibration drift or transmit chain issueRe-run RF calibration. Verify body coil resonance. Check TR switch.
Zipper artifact with RF faultRF shield breach allowing external RF in while amp is faultedInspect RF door gaskets. Run RF shield integrity test after RF amp is repaired.

Tip: The most common fix for E305 on GE Excite/HDxt systems is cleaning the RF amp air filter and verifying the cooling fans are running. Do this first before any board-level diagnosis.
