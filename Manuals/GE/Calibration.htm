⚙️ GE MRI Calibration Procedures
AMT Imaging Solutions — Field Service Quick Reference

Applies to: GE Signa Excite (9x–15x), HDxt, Discovery MR450/750, Optima 450w/750w. Covers FREQ (center frequency) error, RF calibration, gradient calibration, and routine calibration procedures.

FREQ Error — Center Frequency Out of Range

CheckAction
Center Frequency DriftRun Prescan / Frequency Scout manually: MR Service Desktop → Diagnostics → Frequency. If system cannot find center frequency or returns an error, the Larmor frequency is outside the expected range. This indicates magnet field drift or a calibration issue.
Magnet StabilityCheck frequency over time using MR Service Desktop → Magnet Real Time Data → Field Frequency history. A sudden shift suggests a quench event or shimming issue. Gradual drift is normal aging. Extreme drift (>1 kHz) warrants GE service.
System ShimRun Automatic Frequency and Shim procedure: Diagnostics → System Function → Magnet → Auto Shim. This recalculates the optimal center frequency and passive shim settings. Required after any significant environment change.
Patient-Related SusceptibilityFREQ errors during a scan can be caused by a large patient or patient movement changing the effective field. Try re-running prescan. If persistent, perform a full system prescan with no patient and a calibration phantom.
RF Transmit ChainFREQ errors can also result from RF excitation issues (RF amp fault). Check for concurrent E305 error. Verify RF transmit chain is functional per RF service guide.

GE MRI Calibration Sequence

Run calibrations in the order listed below. Each step depends on the previous being correct. Start with the phantom in the isocenter with no patient.
StepProcedureLocation in Service Desktop
1. Center FrequencyFind Larmor frequency. System should lock within ±1–5 kHz of expected value for the field strength.Diagnostics → System Function → Magnet → Frequency
2. RF Transmit CalibrationCalibrate RF transmit power and flip angle accuracy. Requires calibration phantom. Run ATD (Automatic Transmit Calibration).Diagnostics → System Function → RF → RF Calibration
3. Gradient CalibrationVerify gradient linearity and scale factors. Geometric accuracy of images depends on this calibration.Diagnostics → System Function → Gradient → Gradient Calibration
4. Receive Gain / PrescanSet receiver gain for optimal SNR. This is run automatically before most scans (prescan) but can be forced manually.Diagnostics → System Function → Receive → Prescan
5. Image Quality CheckRun SNR, uniformity, and resolution phantoms. Document results for ACR or facility accreditation records.Run with QA phantom and appropriate ACR/NEMA protocol

Calibration Phantom Tips

ScenarioBest Practice
Phantom temperatureAllow phantom to equilibrate to room temperature (at least 30 min out of refrigerator) before calibrating. Cold phantom shifts T1 and can cause calibration errors.
Phantom positioningCenter phantom precisely at magnet isocenter using alignment lasers. Off-center phantom introduces gradient calibration errors.
Phantom fluidUse the GE-supplied calibration phantom with correct CuSO₄ or MnCl₂ solution. Check for particulate matter or precipitation — replace phantom fluid annually or per OEM guidance.
ACR PhantomFor ACR accreditation, use the ACR MRI phantom (large acrylic, 13 cm diameter, 148 mm length). Run the prescribed ACR protocol exactly as specified. Document all results.
After board replacementAlways run full calibration sequence after replacing any RF, gradient, or receiver board. Never return a system to clinical use after board swap without calibration verification.

Common Calibration Failures and Causes

FailureLikely CauseFix
FREQ error — cannot find center frequencyExtreme magnet drift; RF transmit chain fault; large B0 disturbance (ferromagnetic item near magnet)Check for ferromagnetic items moved near magnet. Check RF chain (E305). If magnet drift confirmed, contact GE.
RF calibration failure — flip angle out of rangeRF amp output degraded; body coil detuning issue; coil impedance mismatchCheck RF amp output power. Verify body coil tuning. Re-run RF diagnostics. Check TR switch.
Gradient calibration failure — geometric distortion in phantom imagesGradient amp performance issue; eddy current compensation drift; phantom off-centerRe-center phantom. Re-run gradient calibration. Check gradient amp performance. May require GE field service for eddy current recalibration.
SNR below spec after calibrationCoil issue; receive chain degradation; RFI from new sourceCheck body coil and any surface coil being tested. Inspect RF shield integrity. Run RFI test. Check receive chain.
Calibration passes but images are poorShim coil issue; patient-specific factors; sequence parameters wrongRun full auto-shim. Verify clinical protocol parameters. Check image uniformity with phantom vs. patient.

Tip: Document all calibration results in the site's equipment log. Trending calibration data over time (especially RF power and gradient scale factors) can predict hardware degradation before a clinical failure occurs.
Tip: The FREQ error is sometimes caused by something as simple as a large metallic cart being parked near the magnet room door. Always check the environment before suspecting a hardware calibration issue.
