2  Overview

If your system does not have the VCR I/F Option proceed to Section 5. Systems that have the VCR Interface Option will have to follow the steps in this section to load the video driver because it is not loaded with the operating software load. Follow these steps to install the video driver software:

4  Procedure

  1. From the log in screen, log in as root. Password is operator. You will be asked once entering the root desktop if you want to start the Install GUI. Select [No].

  1. Insert the IRIX 6.5 Boot/Update CDROM into the CDROM drive.

  1. In the winterm window type: mediad<Enter> (to mount the CDROM drive).

  1. Type: cd /CDROM/opt<Enter>

  1. Type: ./vidsetup<Enter>

    This starts the install script and a lot of screen output will scroll by in the window, and it will be apparent that file installs/removals are taking place. Then the last output to be displayed is below: 

    Reboot to start using the reconfigured kernel.
***************************************************
**                                               **
**                                               **
**      Remember to reboot the system before     **
**      attempting to use the video interface    **
**                                               **
***************************************************
{sdc@name}

  1. Type the following to verify the video driver was loaded:

    showprods –D1<Enter>

    examine the products that are loaded and ensure the following is listed:

    evo [date installed] OCTANE Personal Video Execution Environ, 6.5.4m

  1. Press the <spacebar> until you get a prompt back.

  1. Type: mediad –k<Enter> (to release the CDROM device).

  1. Remove the Boot/Update CDROM.

    NOTE:Do not reboot the system at this point to activate the video driver. The system will be rebooted after loading the patch software in the next section.

  1. Continue to Reconfiguring the System Using the Install GUI.
