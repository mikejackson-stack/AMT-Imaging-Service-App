2  Overview

The intent of this section is to adjust the monitor to a "default" condition to proceed with calibrations.

3.2  Setting the Default Condition of the Monitor

  1. To access On Screen Manager OSMTM, press one of these buttons: +,- ,<, >

    NOTE:If the OSM Display turns off anytime during this procedure just touch one of the following buttons on the front panel: + - < > and resume the setup where you left off. All setting done prior, are saved automatically when the OSM display disappears. There is no need to repeat any steps. Resume the procedure where you left off.

  1. Auto Brightness and Screen Size Setup

    1. Access the On Screen Manager OSMTM by pressing one of these buttons: + - < >

    2. Press <>> 3 times to select ”Auto BRT” feature.

    3. Press <–> or <+> button, turn OFF Auto Brightness setting. (If it is not already off).

    4. Press <Exit> button

    5. Press <>> to select “Auto” Adjust (Horizontal/Vertical positioning and focus).

    6. Press <Select / 1--2> button.

    7. Press <Select / 1--2> button again. LCD will auto adjust the following:

      1. Horizontal refresh frequency

      2. Vertical refresh frequency

      3. Horizontal and Vertical Size adjustment.

      4. Focus

    8. Press <Exit> button.

    This completes the Auto Brightness and Screen Size setup.

    NOTE:Manual Adjustment of the Position Control and Image Adjust H. Size/Fine controls is rarely needed. Automatic adjustment takes care of this.

  1. Set Color Temperature to 9300

    1. Access the On Screen Manager OSMTM by pressing one of these buttons: + - < >

    2. Press <>> 3 times to select ”RGB” display.

    3. Press <Select / 1--2> button.

    4. Press <>> button to select option 1 (9300K for all monitor types except NEC1990sx. For the NEC 1990sx set to 5000K). (Monitor Color Temperature)

    5. Select the <Exit> button

    NOTE:Manual Adjustment of the Position Control and Image Adjust H. Size/Fine controls is rarely needed. Automatic adjustment takes care of this.

  1. Press the Exit Button. All adjustments are now saved. These settings will remain in effect even if power is removed, or system software is re-booted. Unless manually changed by the operator in the OSM , On Screen Manager. The LCD Display Monitor is now ready for integration to Signa.

3.3  Turning the Auto Adjust Level Off (To prevent the display from incorrectly sizing the text or graphics after recovering from “sleep mode”)

  1. Power off the monitor

  1. Hold the <Select / 1--2> button as you power on the monitor

  1. After the Brightness/Contrast menu appears, release the <Select / 1--2> button

  1. Press the <Exit> button

  1. Press the <>> button twice to move to tab 3 ( Auto Adjust Level)

  1. Press the <Select / 1--2> button

  1. Press the <+> or <–> buttons to select “OFF”

  1. Press the <Exit> button twice to quit the monitor adjustment window.

  1. Power the monitor off and then on to reset to the OSM.
