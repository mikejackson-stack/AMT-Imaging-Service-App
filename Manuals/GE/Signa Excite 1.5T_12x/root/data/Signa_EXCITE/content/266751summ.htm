3  Procedure

3.1   Preparation for Scan

In this procedure, the strength of the gradient fields are calibrated by modifying the control variables cfxfull, cfyfull, and cfzfull. A separate scan will be taken to calibrate each of the three gradient fields (x, y, and z). For TwinSpeed, the whole procedure must be repeated for each gradient mode (GradMode) separately, Whole-Body (WB) and Zoom (ZM) gradients.

  1. Place head coil on cradle and plug coil in.

  1. Place the DQA phantom in head coil.

  1. Turn on alignment lights.

  1. Move the cradle to center the phantom with the alignment light.

  1. With laser light on center of phantom, press the Landmark button.

  1. Press Move to Scan. (Head Coil should automatically move to the center of the magnet.

  1. Go back to the GOC and resume scan setup.

3.2   Start the DQA Analysis Tool- Prepare for DQA Analysis (GradCal)

The Daily Quality tool analyzes the DQA image to determine if the image is skewed in the x direction (x-y planes). Analysis performed on an image with a few degrees of skew will still give an accurate GradCal value.

  1. Select Utilities Desktop. Refer to Illustration 1

    (Step Details)

  1. Select [Service Browser] from the Service Desktop Manager (CSD).

  1. Select the [Calibration] tab.

  1. Select the [DQA Calibration] from the calibration list.

  1. Select Start the DQA Calibration by clicking on the [Click here to start this tool]. Refer to Illustration 2.

    (Step Details)

  1. Select Test Mode Option: Type 2 [2= Auto Mode], <Enter>.

    (Step Details)

  1. Select Test Option: Type 5 [5= GradCal All Three Axis], <Enter>.

  1. The Calibration tool will begin and pause requiring that you to make a gradient coil choice. Refer to Illustration 4.

    (Step Details)

  1. Select appropriate mode for Twin Speed Systems (recommend to use option B = Both the Modes). The tool will scan and adjust in the following order: X-Whole; X-Zoom; Y-Whole; Y-Zoom; Z-Whole; Z-Zoom.

    (Step Details)

  1. You must select Y to perform the final test scan. See Illustration 6.

    (Step Details)

  1. When complete, you will see the main menu. Type 6 to select option [6=Quit], <Enter>. Then press [Enter] at the prompt [press Enter to quit ->]. See Illustration 7.

    (Step Details)

4  Finalization

  1. Remove all phantoms and coils from the magnet

  1. Return the scanner to normal operation
