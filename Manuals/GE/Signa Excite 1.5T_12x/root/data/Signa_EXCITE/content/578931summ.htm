Module Version  2.0,  Version Date  10/20/09

Perform Save Information and Save GI

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. From the Common Service Desk Top, open the Guided Install GUI.

    (Step Details)

  1. Select the SaveRestore under Utilities. The Save/ Restore window will open.

    (Step Details)

  1. A dialog Box will open asking if MOD or CD/DVD will be used. Insert the media to be used into the drive.

    (Step Details)

  1. Make the proper selection in the Dialog Box and Click [Ok].

    (Step Details)

  1. A warning message will appear informing the operator that data on the inserted media will be lost. ( MOD only ).

    (Step Details)

  1. Click [Confirm] to Start the SaveInfo procedure.

  1. A SaveInfo & SaveGI in progress message will be displayed.

    (Step Details)

  1. If some information is not saved a warning message will appear.

    (Step Details)

  1. Click [Yes] to view the Log.

    (Step Details)

  1. SaveInfo is now complete. Remove the MOD or CD/DVD and write the date and time on it.

2  Finalization

  1. To verify the information was properly saved on the media perform Verifying Save Restore Media.

  1. Exit the install GUI by selecting [File] then [Quit].
