Cradle Release Block Adjustment

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Cradle Release Block Position Adjustment

  1. Loosen four hex socket head screws securing the release block assembly. See Illustration 1.

    (Step Details)

  1. Adjust the position of the assembly so the release block is centered in the cutout on the front of the cradle assembly. Tighten hex socket screws. See Illustration 1.

1.2   Cradle Release Block Retraction Adjustment

  1. Dock Patient Transport.

  1. Remove all upper and lower trim covers from sides of Patient Transport.

  1. Loosen the lock nut, then tighten or loosen the cable adjustment screw in the pivot block so that the cradle release block is flush or just below the level of the table top. See Illustration 2.

    (Step Details)

  1. Tighten lock nut.

    (Step Details)
