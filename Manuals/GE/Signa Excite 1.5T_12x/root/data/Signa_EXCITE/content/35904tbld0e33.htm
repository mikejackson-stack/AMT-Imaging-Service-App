Table 1:  Grafidy 3 Flow

  1. Always perform L-Coil Calibration before starting either DC Offset Adjustment or Grafidy 3 Procedure.
    1. From the Calibration menu, select L-Coil Calibration.
    2. Click on the selection to start the tool. The calibration runs automatically.
  2. Always perform DC Offset Adjustment before starting Grafidy 3.
  3. Configure the system to run Grafidy 3. Things that will be accomplished here are:
    • Set up the standard two-coil Grafidy kit. The 6-coil Grafidy fixture is not supported.
    • Place a rotary attenuator set for 20dB of attenuation between exciter output and RFI.
    • Manual Prescan and get “enough signal” to make sure the setup is good and the coils are good. Then Auto Prescan.
  4. Perform the Auto Grafidy 3 Procedure.
    • Start Grafidy3 tool. Select components that are going to be calibrated and zero out their calibration values.
    • Auto Mode is the mode from which Grafidy3 should normally be run. One coil axis is run at a time. Make sure the physical coil axis and the axis selected on the tool’s user interface are the same, and then scan.
  5. Perform Manual Mode if auto mode does not make all components under spec (still in “red” in User Interface’s result area/table), go to manual mode to do “touch up.”
