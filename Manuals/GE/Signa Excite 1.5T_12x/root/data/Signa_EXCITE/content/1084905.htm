4  Procedure

4.1  Powering Off (Shutting Down) Operator Console

  1. Select one of the following methods to power off the Operator Console:

    • If Applications are running, click [Shut Down] on the desktop and select the Shutdown option.

    • If Applications are down, open a Unix Shell using the Toolchest and type: {ctuser@hostname} > halt > [Enter].

      The Operator Console monitor will display a System Halted message when it is acceptable to power off the Operator Console.

  1. Power OFF the Operator Console at the front panel switch.

  1. Make sure to follow all Lockout/Tagout requirements while performing this procedure. For added protection, disconnect the Twist-N-Lock Main Power Cable from the rear of the console.

4.2  Removing HP xw8200 Host Computer from Operator Console

  1. Remove the front and rear Operator Console covers.

  1. Remove the cable connections to the HP xw8200 Host Computer chassis.

    NOTE:Verify that all cables are labeled and clearly marked. If necessary, add a label for clarity.

  1. Remove the power cord at the rear of the Host Computer chassis.

  1. Remove the four (4) 5 mm socket-cap mounting screws from the front of the Host Computer, holding the computer to the Operator Console.

  1. Slide the Host Computer forward (out the front of console) and set aside.

4.3  Access Panel Removal

  1. If necessary, unlock the access panel using the keys located in the rear of the workstation (Item 2 in Illustration 1).

    Illustration 1:  Keys in Rear of Workstation

  1. Once unlocked, pull up on the handle and lift off the access panel cover (Illustration 2).

    Illustration 2:  Access Panel Cover Removal

4.4  Replacing HP xw8200 Host Computer Lower Level FRUs

4.4.1  Memory Module Replacement

  1. Follow the steps in HP8200 Memory Module Replacement for replacing Memory Modules in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. Continue with Reinstalling HP xw8200 Host Computer in Operator Console of this document.

4.4.2  DVD Optical Drive Replacement

  1. Follow the steps in HP8200 DVD Optical Drive Replacement for replacing DVD Optical Drive in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. Continue with Reinstalling HP xw8200 Host Computer in Operator Console of this document.

4.4.3  Hard Disk Drive (HDD) Replacement

  1. Follow the steps in HP8200 Hard Drive Replacement for replacing Hard Disk Drive in the HP xw8200 Host Computer. Return to this procedure when finished.

  1. If the OS Disk HDD was replaced, it will be necessary to perform a Load from Cold (LFC) to reinstall Host OS and Application Software. Follow appropriate LFC procedure for the system on which this HDD is installed.

    NOTE:The LFC procedure will erase and recreate the Image Database located on the Image HDDs.

  1. Proceed to Reinstalling HP xw8200 Host Computer in Operator Console.

4.5  Reinstalling HP xw8200 Host Computer in Operator Console

  1. Slide the HP xw8200 Host Computer into the Operator Console from the front.

  1. Replace the four (4) 5 mm socket-cap mounting screws to secure the Host Computer chassis to the Operator Console right side compartment, and torque to 4.6 Nm.

  1. Mount the power cord to the rear of the Host Computer chassis, and verify that its power switch on the Host Computer’s Power Supply is turned to the ON position.

  1. Replace the rear cable connections.

4.6  Powering On Operator Console

  1. Reconnect the Twist-N-Lock Main Power Cable from the rear of the console, and remove Lock Out Tag Out protection applied earlier.

  1. Power ON the Operator Console at the console’s front panel switch.

  1. Visually verify that the Host Computer front panel Power LED is illuminated. If not, press the Host Computer front panel power switch to apply power to the Host Computer.

5  Finalization

  1. Run HP Linux PC Service Diagnostics using the HP Diagnostics Tool.

  1. Reboot, and ensure that no memory BIOS errors are observed during the boot process.

  1. Take some scans, and verify that the image(s) reconstruct and display.

  1. Check that all customer functions are operational (auto voice, filming, network, archive).

  1. Reinstall console front and rear covers.
