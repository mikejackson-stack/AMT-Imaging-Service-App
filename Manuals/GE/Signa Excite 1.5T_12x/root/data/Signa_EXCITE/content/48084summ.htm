1  Procedure

1.1   Determine the PC type to be loaded.

It will first be necessary to determine what vintage PC is being used by the system to be loaded. Open the Operator work space cabinet. The PC is on the left side of cabinet.LX1PC.

  1. When starting the software load process this PC would represent, LX1PC

  1. When Starting the software load process, This PC would represent, LX2PC

  1. When Starting the software load process, This PC would represent, LXPC3.

  1. When Starting the software load process, This PC would represent, LXPC4. This PC starting in second half 2000 does not Use a CD/floppy set to reload software. But instead Only uses 2284297-2 boot floppy. The software for Reloading is mirrored on the hard drive. Refer to Loading Software , Step 2.

1.2   Loading Software

  1. Software load on LXPC 1,2 and 3

    1. Switch the system keyboard to the PC subsystem. See Section 4.1 of Loading Operator workspace PC computerfor information on switching the keyboard.

    1. Put the 2192746-4 Boot Floppy into the floppy drive and the CD into the CD ROM drive.

    1. Reboot the PC by ether pushing the [Reset] button on the front of the PC or cycling power to the PC.

    1. The system will boot to the following menu.

      (Step Details)

    1. A warning message will appear that all previously loaded software on the PC will be lost. Select Y to continue the software load.

    1. The next thing seen will be Microsoft License agreement. When the first half of the agreement displays on the screen, press any key… to view the second half. Then press the Y key to accept the agreement and continue to load the software. Pressing N will terminate the software load.

    1. The following menu will apear:

      (Step Details)

    1. The software load itself will begin. It will take approximately 2 minutes to load. When finished, remove the Boot Floppy and CD ROM and reset or power cycle the PC.

      (Step Details)

  1. Loading the LX4PC

    1. Switch the system keyboard to the PC subsystem. See Section 4.1 of Loading Operator workspace PC computer for information on switching the keyboard.

    1. Put the 2284297-2 Boot Floppy into the floppy drive.

    1. Reboot the PC by ether pushing the [Reset] button on the front of the PC or cycling power to the PC.

    1. The system will boot to the following message:

      (Step Details)

    1. Select Y to continue.

    1. Press any key to continue.

    1. Select Y to agree to the license agreement.

    (Step Details)

1.4   WS-FTP95 PRO (FTP Tool)

The standard PC load comes configured with a FTP tool to make file transfers between the system PC and the host computer easier to do. The tool can be used to transfer images, raw data, test files or any other text or binary files to or from either computer.

  1. To start the tool, select on the task bar, the [Start] button then scroll to ftp. See Illustration 8.

    (Step Details)

  1. The tool comes pre-configured for usual transfers made between the computers. See Illustration 9.

    (Step Details)

  1. Several locations have been pre-loaded into the FTP tool. See Illustration 10.

    (Step Details)

  1. To transfer files from the host to the PC;

    1. Select a session that would put you closest to the desired data.

    1. Enter a User Name. The Default would be sdc. This is case sensitive, user lower case.

    1. Enter the systems password. Signa default for sdc would be adw2.0<Enter>.

    (Step Details)

  1. For further discussion on the FTP tool itself and the how to's of using the tool, press the [Help] button at the bottom of the interface.
