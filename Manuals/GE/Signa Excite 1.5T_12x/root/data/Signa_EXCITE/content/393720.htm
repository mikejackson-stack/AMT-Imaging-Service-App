1.5T Neurovascular Array Installation

Required PersonsPreliminary ReqsProcedureFinalization
115 mins

2  Overview

Follow this process to install the 1.5T Neurovascular (NV) Array by Medrad (M3087JJ).

3  Procedure

  1. Go to the Service Desktop and start the Service Desktop Browser if it's not already running.

  1. Follow the steps shown in Illustration 1.

    Illustration 1:  Starting the Config. File Manager

  1. Click the [CoilConfig]button on the left. The following screen will appear, see Illustration 2.

    Illustration 2:  CoilConfig Screen

  1. Add the following coil names to the list of site coils.

    • HDNV Array

    • HDNV Head

    • HDNV Head Neck

    • HDNV Neck

    • HDNV Spectro

    • HDNV ArrayServ

    • HDNV HeadServ

    • HDNV HdNeckServ

    • HDNV NeckServ

    • HDNV SpectroServ

  1. Restart Signa.

  1. Add the following traced part number(s) to product locator: 5117092-2

4  Finalization

No finalization steps.
