T File Cleanup

To access T File Cleanup, click on the [Service Desktop] icon. Start the Service Browser if it is not already running. Click the [Utilities] tab, [T File Cleanup], then <Click here to start this tool>. See Illustration 1. Illustration 2 shows the T File Cleanup Interface.

Illustration 2:  T File Cleanup Interface
