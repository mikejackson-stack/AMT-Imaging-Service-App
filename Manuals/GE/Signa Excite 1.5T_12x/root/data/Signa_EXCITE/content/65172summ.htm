HP8000 and HP8200 Computer Replacement

(Click Here to Return to Detailed Procedure)

  Safety

WARNING
Electrocution Hazard!
Hazardous voltages exist in the goc when energized.
before beginning any work, shut down software if still running. remove power from the goc cabinet at the pdu and lockout/tagout (LOTO) the PC, Host and UPS breakers.

NOTICE
The system options are keyed to the Host ID on the Network Interface Card (NIC). A Load from Cold (LFC) is required to transfer the options to the new Host computer. Do not transfer existing NIC card from old computer. Update eLicense with the new Host ID.
 
 

1  Procedure

  1. Shut down system applications, if still running, and LOTO power to the GOC before continuing.

  1. Remove the four screws in the rear that secure the left side panel, and the three screws that secure the right side panel. (See Illustration 1.)

    (Step Details)

  1. Remove the left and right side panels by sliding them back.

  1. Loosen the four screws that secure the back panel. (These screws do not need to be removed to take off the rear panel.)

  1. Remove all of the cables connected to the computer, and ensure they are properly labeled.

    (Step Details)

  1. Remove the two blue straps that secure the PC to the GOC. (Illustration 3 shows the blue straps already removed.)

    (Step Details)

  1. Remove the Bit 3 Board from the bottom slot of the PC and install the board in an equivalent open spot in the new PC.

NOTICE
The computer weighs 50 pounds. Use two people to move the PC Cabinet.
 
 

  1. Carefully remove the PC from the GOC.

  1. Install the new PC by performing the steps above in reverse order.

2  Finalization

  1. Restore power to the GOC, boot the software, and ensure proper system operation.

  1. Back up the data and perform a Disk Wipe.

  1. Install the Operating System software described in Host Operating System Software Load 12.x.

    (Step Details)

  1. Update the eLicense option with new Host ID as described in 2397845 Signa Software Option Install with eLicense .

  1. Repackage defective PC for return.

  1. Include a note indicating the system was using a SCSI drive configuration. This alerts the supplier to check this circuitry in the system.

  1. Perform a scan to ensure system and applications are working properly.
