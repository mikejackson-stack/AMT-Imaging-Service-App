Running Overnight Diagnostics

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. From CSD select Diagnostic menu, then select Overnight Diagnostics. See Illustration 1.

    (Step Details)

  1. Select Schedule Overnight option at the bottom of the screen. See Illustration 1.

  1. Fill in the necessary information on the GUI for running overnight diagnostics, then select [Submit]. See Illustration 2.

    (Step Details)

  1. Select [Close]. The overnight diagnostics will run at the appointed time.
