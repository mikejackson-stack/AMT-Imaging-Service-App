Perform Save Info

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
120 mins

2  Overview

After completing final site configurations, perform a SaveINFO:

Last Update09/14/2004

3  Procedure

  1. Put the MOD that you previously used to Save GI Configuration to MOD with side A up (same side is OK because a separate partition will be created for the SaveINFO).

  1. Select the [Save/Restore] tab in the Install GUI and Save the system info.

    NOTE:If the MOD has not been used, you will see a message regarding the use of the MOD for “Raw Data Storage”; choose [Overwrite].

  1. SaveInfo is now complete. Remove the InfoMOD and write the date and time on it.

4  Finalization

  1. Exit the install GUI by selecting [File] then [Quit].

  1. On the Service Desktop, click on [System Shutdown].

  1. After the system is all the way down, when prompted, click on [Restart].

  1. On the login screen, login as Signa and bring the system up for the configuration changes to take effect.

  1. Complete any remaining system calibrations per the installation/upgrade flowchart.
