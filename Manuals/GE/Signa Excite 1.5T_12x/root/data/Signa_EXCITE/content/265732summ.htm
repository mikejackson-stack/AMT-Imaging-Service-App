3  Procedure

3.1   Preparation for Scan

The electrical isocenter is the point where the x, y and z gradients are nulled. It is very important that this point be accurately located in order to pass the image quality tests. The procedure uses the DQA phantom and Daily Quality tool for analyzing the data. The Daily Quality tool analyzes the DQA image and determines the optional z direction offset that is needed to center the landmark at the z isocenter. The tool optionally updates the isoVectorZ value contained in the system configuration file (MRconfig.cfg). If you choose to update the system configuration file, you must reboot the system. Note: For TwinSpeed, the entire procedure only needs to be run on one gradient mode, Whole Body (WB). Running the procedure on both WB and ZOOM will not hurt, but is just not necessary.

  1. Place head coil on cradle and plug coil in.

  1. Place DQA phantom in head coil.

    (Step Details)

  1. Turn on alignment lights.

  1. Move the cradle to center the phantom with the alignment light.

  1. With laser light on center of phantom, press the Landmark button.

  1. Press [Move to Scan] . (Head coil should automatically move to the center of the magnet).

  1. Go back to the GOC and resume Tool Setup.

3.2   Start the DQA Tool- Prepare for DQA Analysis (Isocenter Cal)

The Daily Quality tool analyzes the DQA image to determine if the image is skewed in the x direction (x-y planes). Analysis performed on an image with a few degrees of skew will give an accurate isocenter location. If the image is skewed more than a few degrees, it will still be analyzed, but the adjust values for isoVector-Z may be inaccurate. In this case, the phantom should be repositioned and another scan performed.

  1. Select Utilities Desktop. Refer to Illustration 1.

    (Step Details)

  1. Select [Cal/Checks] from the Service Desktop Manager.

  1. Select [Service Browser] from Service Desktop Manager (CSD). Refer to Illustration 2.

    (Step Details)

  1. Select the [Calibration] tab. Refer to Illustration 3.

  1. Select DQA Calibration from the calibration list. Refer to Illustration 3.

  1. Select [Click here to start the tool]. Refer to Illustration 3.

    (Step Details)

  1. Enter “2” and press the <Enter> key.

    (Step Details)

  1. Select the Test Option – type 1 [1= Iso center (Z) Calibration] <Enter>.

    (Step Details)

  1. If adjustment is required then type Y to update isoVectorZ value in MRconfig.cfg.

    (Step Details)

  1. Type “Y” when prompted to perform the Final Test run. See Illustration 7.

    (Step Details)

  1. Review the test results to see if the calibration passed or failed. See Illustration 8.

    (Step Details)

  1. Enter Test Step Option 6 when calibration is complete, then press <Enter> to quit.
