1. Access the On Screen Manager OSMTM by pressing one of these buttons: + - < >

  2. Press <>> 3 times to select ”Auto BRT” feature.

  3. Press <–> or <+> button, turn OFF Auto Brightness setting. (If it is not already off).

  4. Press <Exit> button

  5. Press <>> to select “Auto” Adjust (Horizontal/Vertical positioning and focus).

  6. Press <Select / 1--2> button.

  7. Press <Select / 1--2> button again. LCD will auto adjust the following:

    1. Horizontal refresh frequency

    2. Vertical refresh frequency

    3. Horizontal and Vertical Size adjustment.

    4. Focus

  8. Press <Exit> button.

This completes the Auto Brightness and Screen Size setup.

NOTE:Manual Adjustment of the Position Control and Image Adjust H. Size/Fine controls is rarely needed. Automatic adjustment takes care of this.
