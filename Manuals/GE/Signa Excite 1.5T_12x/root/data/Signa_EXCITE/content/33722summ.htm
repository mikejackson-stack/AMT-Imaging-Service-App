3  Procedure

  1. Start a new series using theBody B0 Dither scan protocol from the scan setup in Body B0.

  1. [Modify CVs] and verify cv pw_gxwl2 = 0.

  1. [Auto Prescan], [Done] then [Scan].

  1. The system scans and creates a total of 3 image plots, (one for each plane). Compare the plots to the Typical Plot Examples shown in Illustration 1 and Illustration 2. If plots look similar to the typical plots shown, continue on to the next step. Otherwise see the Troubleshooting Tips Illustration 3.

    (Step Details)

  1. After scan #1: execute the command b0 d<ENTER> from the non-TPS command window. This generates the b0vectors.dat and delay .esp files. For scans #2-8 if the plots are acceptable, execute the command b0<ENTER> (Not b0 d, as this will delete your previous work). This will append data to the files b0vectors.dat and delay.esp. Go back to step 8 of this procedure until all 8 scans are complete.

  1. After scans for all values for pw_gxwl2 setting have been collected, execute the following from the C Shell window: fitepic<ENTER> (Accept the default field name of b0vectors.dat when prompted). This creates the file b0_dither.cal. (This takes several minutes per axis to run, so be patient.)

  1. The program then analyzes the b0 vector data. As each axis is analyzed, a series of numbers is output to the screen. Record the Max. Error value for each axis for future ref.

  1. From the non-TPS command window, rename the b0vectors.dat, delay.esp, b0dither.cal and plot files to make them body specific files before proceeding to Group Delay calibration:

    (Step Details)

  1. Display plots of the b0vectors.dat on the system screen by typing each plot command. (The plots may slope considerably or have a high offset, but each axis plot should look fairly smooth. For example, see Illustration 4).

    (Step Details)

4  Finalization

  1. Continue on to Head B0 Dither procedure

  1. Or return to the main EPI B0 procedure
