2.1  PACS System Verification

The following procedure should be run at system installation time to verify there are no DICOM Connectivity issues from the HD MR system to the site PACS systems.

  1. Go to the Service Desktop and start the Service Browser if it is not already running.

  1. Go to the Configuration tab and install PACS Test Exam as shown in Illustration 1.

    Illustration 1:  Installation of PACS Test Exam

  1. On the Image Browser Desktop, the PACS test images will now be present. See Illustration 2.

    Illustration 2:  Image Browser

    These series offer a cross section of new features and DICOM types in the 12.0 release. A single exam will be installed into the database and can be viewed in the Browser. This exam consists of several series:

    • Series 1: 3 Plane Localizer: 1 image.

    • Series 3: Lx LAVA: 1 image.

    • Series 4: MR Echo: 1 image.

    • Series 7: T2Flair Propeller: 1 image.

    • Series 10: Prose: 1 image.

    • Series 300: IVI PJN of series 3 (LAVA): 1 image.

    • Series 301: IVI RFMT of series 3 (LAVA): 1 image.

    • Series 450: MR Echo Bookmark: 1 image.

    • Series 800: DW Propeller ADC: 1 image.

    • Series 801: DW Propeller eADC: 1 image.

    • Series 900: Functool Color SSAVE of series 10 (Prose): 1 image.

    • Series 902: Prose Structured Report.

    • Series 1300: MR Echo Scan and Save:1 image.

    • Series 11300: GSPS of series 1300.

  1. Try networking this exam to PACS system. If this entire exam networks without errors to a PACS system, there is little chance of future DICOM connectivity issues with this PACS.

  1. If test is successful, remove the PACS images by Selecting the proper study. Then select [Remove] from the Browser top menu, then select [Remove Examination], then select [OK]. The images can be loaded back on the system at any time.

2.2  Troubleshooting Failures In Transferring Images To The PACS System

  1. Configure the PACS DICOM network properties on the HD MR system and select it as the current networking device.

  1. Select the PACS Test Exam in the Image Browser. See Illustration 2.

  1. Select Network->[By Exam]

  1. If the exam transfers without errors: You’re done testing this PACS device. Repeat for any additional PACS devices at the site.

  1. If the exam transfer yields an error, continue to Step 6.

  1. Select a series in the series listing window. Select Network->[By Series].

  1. Go through each series in this manner and record the series which are failing.

  1. If series 1, 3, 4, 7, 10, 300, 301, 450, 800, 801, or 1300 fail, contact the On-Line center for further assistance. These are standard image types and a failure suggests a problem.

  1. If series 900 fails, check if the PACS system supports Color Screensave image types. The site may need to avoid creating Color Screensaves with Post Processing tools if the PACS system does not support.

  1. If series 902 fails, the PACS system likely does not support Structured Report DICOM Objects. Consult the PACS DICOM Conformance Statement. If the PACS does not support Structured Reports, advise the site to avoid Generating Reports in Functool.

  1. If series 11300 fails, the PACS system likely does not support Grey scale Soft copy Presentation State (GSPS) DICOM Objects. Consult the PACS DICOM Conformance Statement. If the PACS does not support GSPS, the site can disable the creation of GSPS Objects through Guided Install. If the GSPS feature is turned off, the site can use the old “Save State” (ss in the command window) and the system will not create GSPS series. Please see Disabling/Enabling GSPS Feature.

2.3  Verifying Advantage Windows Annotation Patches

The PACS Test Exam can also be used to verify that the site has the correct Annotation Patches loaded on their AW Workstations. For the HD MR 12.0 release, annotation patches exist for the following AW platforms: AW3.1, AW4.0, AW4.1, and AW4.2.

  1. Configure the AW Workstation DICOM network properties on the HD MR system. Select the AW as the current networking device.

  1. Select the PACS Test Exam in the Browser.

  1. Select Network->By Exam.

  1. If the exam transfer yields an error, troubleshoot with the above procedure.

  1. Else, move over to the AW system and view the image annotation on the following images. If annotation is missing, this will indicate that Annotation Patches need to be loaded.

  1. View the image in series 800. If the PSD name is annotated as “FSE/Prop”, this verifies that the AW has the latest MR 11.0 Annotation patch loaded. If the “Prop” is missing, the latest MR 11.0 Annotation patch needs to be loaded on the AW system.

  1. View the image in series 3. If the PSD name is annotated as “M3D/LAVA/..”, this verifies that the AW has the latest MR 12.0 Annotation patch loaded. The “LAVA” text is the key. The number annotated after “LAVA” is not important (it’s the flip angle). If the “LAVA” is missing, the latest MR 12.0 Annotation patch needs to be loaded on the AW system.

2.4  Verifying Window Width/Window Level On PACS

Using the PACS Test Exam, which includes real human anatomy, it is possible to quickly check PACS Window Level and Window Width processing. By following the following steps, it is possible to verify that the PACS system is properly receiving the HD MR Window Width/Window Level values stored in the DICOM image header.

  1. On the HD MR scanner, open the image in series 3 in the Viewer. Note the “WW/WL” values annotated in the lower right hand corner of the image:

    W = ________________ L = ___________________

  1. On the HD MR scanner, open the image in series 4 in the Viewer. Note the “WW/WL” values annotated in the lower right hand corner of the image:

    W = ________________ L = ___________________

  1. Move over to the PACS system and view the above images on the PACS system. Verify that the PACS system is using the above Window Width and Window Level settings. Note that the site PACS Administrator may need to disable some automatic preset values for this test. The goal is to verify that “by default” the correct values are being interpreted from the HD MR DICOM image header.

2.5  Verifying Filmer Connectivity

It is also possible to verify connectivity to site Filming devices by using the PACS Test Exam. Images from this test exam or the “SMPTE” pattern exam should be used to verify filming connectivity.

2.6  Disabling/Enabling GSPS Feature

  1. Invoke the Common Service desktop tool.

  1. Select Configuration tab, then select Enable/Disable GSPS Series item. See Illustration 3.

    Illustration 3:  GSPS Enable/Disable Tool

  1. By default, the mode is set to “Enable”.

  1. To disable the creation of GSPS series, select Disable GSPS feature.

  1. Quit the tool and reboot the system.

  1. From this point on, when “ss” is entered in the Viewer Command Window, the legacy Save State feature will execute and GSPS series will not be created.

  1. The creation of GSPS series can be turned back on by selecting Enable GSPS feature in the Service Browser at any time.
