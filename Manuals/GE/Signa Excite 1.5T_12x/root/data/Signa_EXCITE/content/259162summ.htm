MR_APPS Software Load

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Insert Applications CD into the Host CD drive in the GOC. Do not use the CD drive on the SCSI tower.

  1. Illustration 1 will appear

    (Step Details)

  1. Click on [yes]

  1. Illustration 2 appears as noted below

    (Step Details)

  1. Select [continue] with the software load. The system is now partitioning the hard drives.Illustration 3 will appear

    (Step Details)

  1. A pop up will appear with options to [continue], [halt] or [close]. Do not select anything, let the program run. After 2 minutes the system will reboot.

  1. Eventually the Guided Install page will appear

  1. Eventually a window will appear indicating improvements made from previous software version. Click [OK] to continue

  1. A message box will appear concerning the guided Install process. A message appears as in Illustration 4. Select proper media for Guided Install, either MOD or CD/DVD

    (Step Details)

NOTICE
The last install GUI configuration can only be installed if it was previously saved using the [Save GI Configuration to MOD].
 
 

  1. Insert the SaveInfo MOD if a GUI configuration has been saved and then push the [OK] button to reinstall your last GUI install configuration values. (The normal SaveInfo files are not restored at this point in the software load. They will be restored later). You will verify the correct values restored by checking each tab in the next step.

NOTE:If you did not save GUI configurationor are performing load for the first time), Save GI Configuration, push the [Cancel] button to continue manually with the install

  1. The Guided Install menu has changed for 12x. See Illustration 5. If any parameters do not match the expected criteria, the left column will be red. If everything is acceptable, all values will be black. If the value is changed, it will be noted in blue. Select the Basic Configuration tab and verify that all values under Basic Configuration tab are configured properly, including Time/Date

    (Step Details)

NOTICE
If you are loading software for the first time on a Linux PC, the initial boot-up will fail. You must manually enter the “term server” information into the Guided Install screen under the Network Info Screen. The information must be entered in the following format:Example is 20:2D:90:22:44 use colon's between two digits, letters are case sensitive. See Illustration 6
 
 

  1. On the System Configuration tab, be sure to select the proper model number for the LCD or CRT

  1. Proceed to the Verification tab, Illustration 6. Once in the verifications tab look for any pass or fail status, the [Install Software] button will not be active if there are any failures. Failed entries will be due to missing entries, or entries not in the correct format. Go to the tab with the error and correct it, then push the [Install] button to open the Verification Tab again. If all entries pass verification at this point, push the [Install Software] button again to begin the MR Apps load. See Illustration 6. The verification popup will open. A GUI will appear indicating “Software Installation in progress” which indicates that the software is loading. The MR Apps load will take 5-10 minutes, depending on the machine being loaded.

    (Step Details)

  1. Once the MR Apps load is done the pop up inIllustration 7 is displayed. Click on the [OK] button to close the pop up

    (Step Details)

  1. At this point the GUI will change from the Install phase. If a SaveInfo info MOD is not available, go to each tab in the Install GUI and fill in or update all system information manually. A help button is available on each tab, which will open a pop up box with information on the required data and its format for that page

    (Step Details)

  1. A pop up will ask if you want to restore all files or selectively restore, see Illustration 8. Select [Restore Information], then select the proper media, either MOD or CD/DVD. Then select [Restore all files automatically]

    (Step Details)

  1. A “RestoreINFO in Progress” window will scroll filenames as they are being restored

  1. When the RestoreINFO is finished a pop up will open telling the installer to run the update utility. See Illustration 9.

    (Step Details)

  1. Push the [OK] to continue. The Restore Manager menu opens (see Illustration 10)

    (Step Details)

  1. Make sure the box labeled “All” at the top is selected so all items are restored. Click on [Update] button when update is finished Click [Quit] then [yes]

  1. At this time a GUI might appear for selecting the proper monitor. If you have an LCD monitor select CRT, then select LCD. This is known problem for Excite II, it will be fixed in Excite IIA

    (Step Details)

  1. In response to the question, click [OK] to exit the tool. If everything updates successfully, click [Quit] to continue.

  1. Select [OK]

  1. Beginning with Signa 10.x coil parameters have changed. For upgrades from 8.x or 9.x a coil update will run to add the new parameters to the exciting coil definitions. The success of the update is dependant on recognition of coil names. If no discrepancies are found continue to Step 25. If any coils are not recognized during the update, the error message shown inIllustration 12 will pop up

    (Step Details)

  1. The following Message appears, (see Illustration 13) select [OK]

    (Step Details)

  1. Use the cursor to select [File] and then [Quit] at the top left of the Install GUI. When the GUI shuts down, the system will reboot and all the changes made during the restore process will be set.

NOTE:It is necessary to shut down the 12.0 software before attempting to load the Restricted Service or Advanced Service CDs. These should not be loaded with Applications software running. Close guided install by clicking on [file] – [quit] and reboot the system.

  1. Quit Guided Install. The System will automatically reboot at this time. Log into the system as root, password is operator.

  1. If applicable, reconnect the DASM

  1. Select [yes] to start the Guided Install GUI

  1. Insert the Service Software CD and click the Service SW/Insite option, located near the bottom of the Guided Install menu. Then select the Load Restricted Software option. The system will respond with a pop up as shown in Step . Read the proprietary statement and continue by clicking the “1,2,3” buttons in order and then click [OK].

    (Step Details)

  1. Insert the your normal SaveInfo MOD or a new MOD into the drive if not already in the drive

  1. At the top left corner of the Install GUI, select [File] then [Save GI Configuration to MOD] This will save the information that has been entered in all the edit fields in the GUI

  1. Remove restricted CD from the system.

NOTE:With software release 12x, the Service Methods CD can be loaded onto the software platform. The load will take approximately 17 minutes to complete.

  1. Insert the Service Methods CD into the CD ROM drive in the PC. Click on [Install Service Documentation]. See Illustration 14.

    (Step Details)

  1. A pop-up as shown inIllustration 15 will be displayed – click as appropriate.

    (Step Details)

  1. After the installation of the CD contents, remove the CD form the system by going to the Service Desktop – home – bottom left “Unmount CD”

  1. Perform the Term Server Reset Procedure by executing the following steps:

    1. Remove power connector from Term Server.

    1. Press and hold the small square button, labeled 'reset' next to power jack

    1. Connect power to term server, while continuing to hold in reset button

    1. Continue to hold reset button for 20 seconds

      (Step Details)

NOTICE
If the system will not properly boot on the first try, the Term Server may need to be reset. Perform the Term Server reset procedure Step 37.
 
 

  1. Exit the install GUI by selecting File then Quit from the top of the interface. If any error conditions still exists, you will be warned that no changes will be made. If no error conditions are found, the GUI will save user parameters

    (Step Details)

  1. Boot down Linux PC by “right clicking” on the mouse, and select [system restart]. This will properly configure the Term Server

  1. You can now boot Applications software

    (Step Details)
