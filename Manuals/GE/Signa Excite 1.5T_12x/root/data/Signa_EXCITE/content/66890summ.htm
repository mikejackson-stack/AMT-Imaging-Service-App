Scan-Control Intercom Module (SCIM) and Keyboard Replacement

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. If the system is up and running start with Step 2 System Software Shutdown Procedure. Signa must be shutdown and power removed from the Host SGI computer before disconnecting the keyboard/Mouse. Failure to do so, will result in loss of software control using the mouse and the inability to shut down Signa normally.

    (Step Details)

  1. SYSTEM SOFTWARE SHUTDOWN PROCEDURE: All Lockout procedures begin with a power down of the computer system.

    NOTICE
    Because the cable will be disconnected between the Workspace Interface Module (WIM) and the Keyboard, the Emergency Stop loop will be temporarily inoperative.
     
     

    NOTE:Refer to Lockou/tagout procedures.

    1. Emergency Stop the system by pressing the Emergency Stop button on the keyboard.

    1. Bring the Signa software down.

      1. Toggle mouse control back to the Signa monitor using the hardkey on the top, left side of the keyboard.

      1. Single-click on the [Toolbelt] icon.

      1. Single-click on the [System Shutdown] on the Service Desktop Manager.

      1. Select [OK] to confirm the shutdown.

      1. Wait for the system to indicate on the monitor that it is safe to power off the computer before proceeding. This usually takes about 90 seconds before this message is seen.

    1. Remove power to the Operators Workspace by shutting off the appropriate circuit breakers in the PDU. (OC Host, PC circuit breakers)
