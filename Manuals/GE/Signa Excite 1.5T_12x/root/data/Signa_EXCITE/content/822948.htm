Appendix

1  Prerequisite Information for Non-Proprietary Operation

To configure Magmon3 network connectivity, the user must obtain information from the customer’s network system administrator. This section details the type of information required based on connectivity type and system type. Make sure to start this information-gathering process at least 3 weeks in advance of the physical installation.

1.1  For Non-HFO Systems (Fixed Sites and Mobiles)

Neither a Network Connection or Cryogen System ID is used.

  • Magnet Type (Required): S2, S3, S4, S5, SX, CX, LCC, LCC300, 7.0T, VMX, MAX, Compact, Other.

  • Compressor Type (Required): Leybold or Sumitomo.

1.2  For HFO Systems

Network Cable connection from Magmon3 J5 to OW – Host Lan Hub J7.

  • Magnet Type (Required): HFO

  • Compressor Type (Required): Sumitomo.

    DHCP is not used because of the coldhead cycling hardware and communication requirement. Must use the following:

    • Static Internet Protocol (IP) Address: Obtain from customer IT person.

    • Subnet Address: Obtain from customer's IT person.

    • Gateway Address: Obtain from customer's IT person.

    • Domain Name Service (DNS): Obtain from customer's IT person.
