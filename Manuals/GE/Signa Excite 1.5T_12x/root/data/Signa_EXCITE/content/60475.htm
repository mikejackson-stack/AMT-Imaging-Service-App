Configuring Laptop for Gradient Switch Communication

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable

2  Overview

The field laptop will be configured as a VT-100 communications terminal in order to command the Gradient Switch, via the serial link, to check the status. HyperTerminal will be used to configure the laptop to perform as a VT-100 communications terminal. HyperTerminal must be properly configured or else it will not be possible to establish communication via the serial link with the Gradient Switch.

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

Disable any software running in the background on the laptop, such as Personal Digital Assistant (PDA) syncing or “Hotlink” programs, that take exclusive control of the COM 1 port and will prevent HyperTerminal from using this port. Failure to do this will result in COM 1 port availability errors when attempting to configure the port from HyperTerminal.

4  Procedure

  1. On the laptop, position the mouse cursor in the lower left corner of the screen and click [Start], then [Run].

  1. Type hypertrm in the entry box and then click [OK].

  1. If the system reports that HyperTerminal is not found, then it must be installed. Do the following:

    1. Select [Start], then [Settings], then [Control Panel], then [Add/Remove Programs].

    1. At the top of the Add/Remove Programs Properties window, select [Windows Setup].

    1. Scroll down the menu from the left scroll bar and select Communications.

    1. Scroll down the menu from the left scroll bar and click on the check mark box to the left of HyperTerminal. A check mark will appear in the left box when it has been selected. Click on [OK].

    1. On the Add/Remove Programs Properties window, click on [OK]. The system will indicate that it is attempting to load this program.

    1. Windows 95 users will, at this point, be asked to reboot. Select [Yes]. After the reboot, repeat Step 1.

    1. Windows 98 users will notice that the installation ends, but will not see any special prompt.

  1. In the Connection Description window, enter <GradSwitch >as the Name.

  1. Select the GE logo as the icon and then click [OK].

  1. In the Connect To window, left-click on the down-arrow symbol in the Connect Using box. Select [Direct to Com1] and then click [OK].

  1. Refer to Table 1 and configure the COM1 Properties windows as shown.

    Table 1:  Communications Settings

    Bits per second9600
    Data Bits8
    Stop Bits1
    Paritynone
    Flow ControlXon/Xoff

  1. Select and click on [OK] when done.

  1. Select File from the top of the window and then click on [Save]. This saves this configuration for future use as an entry labeled gradswitch.ht.

    NOTE:This configuration can be used again in the future by clicking on Gradswitch.ht from the HyperTerminal window.
