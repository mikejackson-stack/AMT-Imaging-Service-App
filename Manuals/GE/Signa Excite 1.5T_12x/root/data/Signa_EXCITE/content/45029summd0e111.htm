1. Click on the “Display Type” Field

  2. Drag your mouse over LCD.

  3. A Popup Display message will appear. Select [OK] (See Illustration 2).

  4. The Field should change to [LCD].

  5. Select [LCD] again. The menu shown in Illustration 3 will appear:

  6. Scroll to the correct Display option (1850X) and release the mouse button. The display selected will appear in the box to the right.

  7. Click on the [Configure Button] on the Install GUI to save the changes. You may see a slight change in the screen intensity when “Configure” is complete.

  8. A Popup message box will appear, Select [OK].

  9. Select [File] and [Quit] and [OK] from the Install/Reconfigure GUI Window.

  10. Reboot the System. A reboot is required to activate the changes. This completes the Gamma Calibration process.

  11. Proceed to Section 6- LCD Auto Adjustment and OSMTM On Screen Manager Operations.
