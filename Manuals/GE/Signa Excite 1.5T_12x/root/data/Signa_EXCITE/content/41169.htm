High Order Shim Supply Functional Check

NOTE:This document applies to the new style or Plexus High Order Shim Supply. The old style RRI High Order Shim Supply does not have this function. The Plexus supply can be identified by looking at the Rating plate which is on the rear of the supply.

The Shim Supply Diagnostics are comprised of a series of tests that verify & display various Shim Supply values by communicating from the SCP to the Shim Supply via the CAN link. The tests are as follows:

  • Set Current Test

  • Read Current/Voltage

  • Shim Circuit Continuity Check

  • Read Channel Set Point

  • RTD Data

  • Analog Data

2  Set Current Test

This test takes any input current designated by the Operator between –4.000 amps and +4.000 amps, programs the Shim Supply to output the assigned current on each channel, and then queries the supply for the output and then displays this back to the user. The output current should match whatever the Operator designated for that channel.

NOTE:There is a 12 amp upper limit on the total amount of current that this supply can provide. If the power supply limit is reached, you may see an error code. Make sure the total current does not exceed 12 amps.

  1. Start the diags if not already started. See Section 1.

  2. Input a current for each of the channels 1-6. (-4.000 amps to 4.000 amps).

  3. After currents entered then select the “Set Current Test” radio button and press [Run] button.

  4. Diag issues a command that sends the non-zero current values to the Shim Supply.

  5. Diag waits, allowing the command to set the channels current.

  6. Diag issues a command that instructs the Shim Supply to return the present voltage and current for each coil channel.

  7. See Table 1 for an example of Diag displays the results.

4  Shim Circuit Continuity Check

This test ensures each channel can be set to the preset current (100mA) and that the channel (a) has the desired current; (b) has the proper polarity; and (c) is isolated (i.e. no crosstalk) from the other channels.

  1. Start the diags if not already started. See Section 1.

  2. Operator selects the [Shim Circuit Continuity Check] radio button, then presses the [Run] button.

  3. Diag issues a command that turns the Shim Supply’s fault monitoring off.

  4. Diag loops through each channel, setting a single channel to 100mA and all others to 0.0mA.

  5. Diag reads currents from each channel and stores results.

  6. Diag repeats this process for all the other channels.

  7. Diag programs original currents back into Shim Supply.

  8. Diag displays the results of test and identifies any failing channels. See Table 3.

5  Read Channel Set Point

This test simply queries the Shim Supply for the currents currently output on each channel and then it displays the results.

  1. Operator selects the [Read Channel Set] Point radio button, then presses the [Run] button.

  2. Diag issues a command that instructs the Shim Supply to return the present current for each coil channel.

  3. Diag displays the results.

6  RTD Data

This test provides a read back of the present temperature on the RTD channels.

NOTE:Note: the RTD channels must be present.

  1. Start the diags if not already started. See Section 1.

  2. Operator selects the [RTD Data] radio button, then presses the [Run] button.

  3. Diag issues a command that instructs the Shim Supply to return the present temperatures on each of the RTD channels.

  4. Diag displays the results. See Table 5.

7  Analog Data

Provides a read back of the present power supply and board temperature sensor values.

  1. Start the diags if not already started. See Section 1.

  2. Operator selects the[Analog Data] radio button, then presses the [Run] button.

  3. Diag issues a command that instructs the Shim Supply to return the present power supply and board temperature sensor values.

  4. Diag displays the results. See Table 6.
