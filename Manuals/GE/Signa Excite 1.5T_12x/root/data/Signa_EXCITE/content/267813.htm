Verifying SaveInfo Media (11.1 and 12.x)

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable10 minsNot Applicable

2  Overview

This procedure is used to verify the content of the SaveInfo media with the original data on the system disk drive. The program checks that all files are present on the SaveInfo media and if check sums match.

3  Preliminary Requirements

3.1  Required Conditions

ConditionReferenceEffectivity

Signa Software is running.

-

-

4  Procedure

  1. Insert the previously created SaveInfo MOD or DVD into the appropriate drive.

  1. At the host computer, go to the Service Desktop, open the Service Browser (if not already running), and start the Guided Install tool in the FE Mode. (See Illustration 1.)

    Illustration 1:  Starting Guided Install from the Service Browser

  1. In Guided Install, go to the Save/Restore screen, and start the verification process. (See Illustration 2.)

    Illustration 2:  Starting SaveInfo Verification

  1. When the tool prompts for which media will be used for SaveInfo, make the appropriate selection. (See Illustration 3.)

    Illustration 3:  Select Media for SaveInfo

    The tool begins the verification of the data on the media with that on the system hard drive. If no media is present, the user receives a error message. While the media is being checked, the pop-up shown in Illustration 4 displays. The verification takes about 2 minutes.

    Illustration 4:  Verification Message

  1. Once verification is complete, when the system asks to view the CheckInfo log, click the [Yes] button. (See Illustration 5.)

    Illustration 5:  Message to View CheckInfo Log

  1. See Illustration 6for an example of a CheckInfo log. If any errors are reported, a new SaveInfo needs to be created.

    Illustration 6:  SaveInfo Verification Log

5  Finalization

  1. Store Save/Restore media in a safe place.

  1. Do a test scan before customer turnover to ensure proper operation.
