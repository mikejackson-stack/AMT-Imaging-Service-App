Setting Default Contrast and Brightness for the LCD Monitor

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Open the Screen Setup, Refer to the vendor manual that came with the monitor.

  1. If it has an “Auto Adjust” Feature, initiate the Auto Adjust of the Phase/ Vertical and Horizontal Centering. If it does not, Skip to the next step.

    (Step Details)

  1. Find and set the monitor “Color Temperature” to (9300). Refer to the vendor manual that came with the monitor.

  1. Press the <Exit> Button. These settings will remain in effect even if power is removed, or system software is re-booted. Unless manually changed by the Operator.

  1. The monitor adjustment is complete. The LCD monitor is now ready for integration to Signa.
