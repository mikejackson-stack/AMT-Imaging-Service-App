LVShim Flow

Main LVShim Flow. All steps should be performed in order they are given. Refer to Troubleshooting and Solutions, when problems are encountered during the shimming process.

  1. Insure the following tasks have been completeded before begingint LVShim:

    • Magnet Ramped and Parked.

    • All RF Calibration Complete.

    • DCOffset/Auto Lcoil.

    • X, Y, Z Gradients calibrated (Gradcal)

    • Longitudinal Drive Calibration.

    • For LCC Magnets - Coldhead turned of for 10 minutes to dump flux buildup in S/C shield around Coldhead.

    • LCC Magnet - Pressure Controller installed. Magnet pressure should be between 3.7 and 4.3psi.

  2. LCC Magnets - Pre-Cool the Shim Lead before installing the Shim Lead.

  3. Install Shim Currents Use NEW recommended AX2, AX4, AX6 currents from the Acceptance Test Report (ATR).

  4. For LCC Magnet - Close Shim Lead Vent Valve after shim current installation to allow helium vessel pressure to increase to specified pressure before scanning.

  5. Insure Geometry Verification, Check X, Y, Z Gradient.

    No Signal: Perform Forward/Reverse Quadrature Check.

  6. First Image OK Using 3 Piece Phantom?

    • No:

      • Use Crude Image / GradShim Troubleshooting

      • Call Support Center For Help May Require Mechanical Plot To Determine If Problem is Magnet, System or Site Related.

    • Yes: Proceed to next step

  7. Start Rough Shim. Should take 1 to 2 Iterations. Insuring the following:

    • BW = 5000 or 2000 Hz

    • Manual Prescan, TG = 130 - 160

    • LCC Magnet Helium Vessel Pressure

      • Must be = 4.0 psi +/- 0.3 psi

      • Use Basic or Full Set of Coils

  8. Perform Electrical ISO Center Calibration

  9. Perform Gradient Calibration

  10. Perform Gram Tuning (Grafidy)

  11. Perform Recheck: DC OFFSET = 0

  12. Run Main LVShim using the following.

    • If Phase Wrap Error, Change Bandwidth to 1000 Hz

    • Use Full Coil Set For SIV, SV, SX, and SX-C Active Shield Systems use no Z6.

    • Always Enter Axial Currents Last

    • LCC Magnet - Only Perform Scans with Helium Vessel Pressure at 4.0 psi + / - 0.1 psi

  13. Gradient LVShim

    If X3, Y3, Z3, Z2Y and Z2X changed dramatically by changing the BW from 500 to 200, then recheck Grafidy. After completing Grafidy re-check LVShim.
