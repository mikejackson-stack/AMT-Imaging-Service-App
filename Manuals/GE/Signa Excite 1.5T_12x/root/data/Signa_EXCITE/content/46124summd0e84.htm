Illustration 1:  INSTALL GUI “SYSTEM CONFIGURE” TAB- DISPLAY TYPE FIELD

NOTE:The “Display Type” Field has two choices:

  • CRT/Custom – This should be used to set a Custom LCD or CRT Gamma setting.

  • LCD – This should be used to set Gamma for a specific LCD listed in the dropdown box.

NOTE:It may be necessary to “Toggle” between the “LCD” and “CRT/Custom” options in the Display Type Field to select “CRT/Custom”.

  1. If “LCD” is displayed in the Field:

    1. Click on the Display Type Field

    2. Select [CRT/Custom].

    3. A Popup Display message will appear, Select [OK] (See Illustration 2)

    4. The Field should change to [CRT/Custom] and the cursor should be in the “Edit box”.

    5. Start with the default value of .95. If the customer does not like this value, enter the desired gamma value in the “Edit box” to the right, and <Enter>.

      NOTE:A Higher number will increase Brightness & Contrast; A lower number will decrease Brightness & Contrast. The Gamma Value of any LCD is highly dependent on the LCD and Display hardware as well as the Customers eye. This can vary a great deal from site to site.

    6. Click on the [Configure] Button on the Install GUI to save the changes. If you changed the gamma value you will see a slight change in the screen intensity when “Configure” is complete.

    7. A Popup message box will appear, Select [OK].

    8. Select [File] and [Exit] and [OK] from the Install/Reconfigure GUI Window.

    9. Reboot the System. A reboot is required to activate the changes.

    10. Proceed to Section 6- Setting Default Contrast and Brightness for the LCD Monitor.

  2. If “CRT/Custom” is displayed in the Field:

    1. It is recommended that you use the default value of .95. If the customer does not like this value, enter the desired gamma value in the “Edit box” to the right and <Enter>.

    2. A Popup Display message will appear, Select [OK] (See Illustration 2)

    3. Click on the [Configure] Button on the Install GUI to save the changes. If you changed the gamma value you will see a slight change in the screen intensity when “Configure” is complete.

    4. A Popup message box will appear, Select [OK].

    5. Select [File] and [Exit] and [OK] from the Install/Reconfigure GUI Window.

    6. Reboot the System. A reboot is required to activate the changes. This completes the Gamma Calibration process.

    7. Proceed to Section 6- Setting Default Contrast and Brightness for the LCD Monitor.
