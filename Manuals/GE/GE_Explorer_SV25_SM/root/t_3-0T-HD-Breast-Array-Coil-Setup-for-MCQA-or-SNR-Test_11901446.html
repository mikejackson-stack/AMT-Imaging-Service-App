About this task

Follow this process to set up for the MCQA or SNR test using the 3.0T HD 8-Channel Breast Array (M3335LA).

Note:

Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.

Unified Phantom Setup

About this task

Procedure

  1. Place the coil on the patient table and insert the phantom positioner into the coil.
  2. The position of the spherical phantoms from the side of the coil is shown below.
  3. Place the phantoms on the phantom positioner.
  4. Connect the coil to appropriate port of the system LPCA.
  5. Landmark on the center of the bridge between both the chambers as shown in Figure 3, and advance to scan.
  6. Proceed to the MCQA Test, if available. Otherwise, perform Surface Coils SNR Test.
