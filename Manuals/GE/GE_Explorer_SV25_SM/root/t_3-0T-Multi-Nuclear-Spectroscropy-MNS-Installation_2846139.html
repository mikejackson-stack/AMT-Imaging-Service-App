About this task

The Excite 3.0T Multi Nuclear Spectroscopy (MNS) Kit includes a broadband Exciter, amplifier, cabling, TR switch, and service coil for 31P spectroscopy. Other MNS nuclei are supported by the kit, although separate TR switches, coils and phantoms will be necessary. Two broadband amplifiers are supported, a 4kW amplifier (CPC) and a floor-standing 8kW amplifier (AMT/Hurley). For each type of MNS installation or upgrade, this section includes the required steps for a successful installation/upgrade. System Power Shutdown

Procedure

  1. DANGER
    FATAL ELECTRIC SHOCK HAZARD!
    LETHAL VOLTAGES ARE PRESENT WITHIN THE PDU EVEN IF ALL PDU BREAKERS ARE OFF.
    Disconnect and LOTO power from the system at the Main Disconnect for the facility.
    Notice
    Prior to powering down the entire Systems Cabinet, boot the Applications software down to the root level. The VRE System that resides in the Systems Cabinet can become corrupted if it loses power when the Applications software is active.
    Right mouse click, select Service Tools, then System Restart.
    Power down the Systems Cabinet when the login GUI displays.
    Ensure that power is disconnected from the PDU before proceeding.
  2. Notify all personnel working on the system that the system will be shut down.
  3. Shut down the system software before removing power.
  4. For a Phoenix PDU (in ACGD Cabinet with the plastic safety cover):
    1. Remove the cover from the front of the ACGD Cabinet.
    2. Open the plastic cover, and flip the Operator Workspace PC and Operator Workspace Host circuit breakers to their OFF position. (This allows control of their power up when this procedure is completed.)
    3. Rotate the larger main breaker labeled INPUT counterclockwise to the green, OFF (O) position.
    4. Apply LOTO to the PDU INPUT circuit breaker.
    5. Using a meter, test the input voltage between test inputs A-B, A-C and B-C; confirm the voltage between each is zero (0) VAC. Each test input is scaled down to 100:1 of the corresponding AC phase.

Positioning the 4kW CPC Amplifier

About this task

This procedure explains how to install the 4kW CPC Amplifier. If the site is an 8kW system, proceed to Positioning 8kW AMT/Hurley Amplifier.

Procedure

  1. CAUTION
    Lifting Hazard!
    The CPC Amplifier is heavy (132 lbs or 60 kg) and will need a significant amount of balancing to insert it into the RF Accessories Cabinet.
    Two individuals are required to perform this procedure.
    Assemble the Universal Hoist Rail and attach it to the 3.0T Accessories Cabinet. (See Figure 1.) Refer to the instructions for the Universal Lift Kit Assembly that should be with the kit.
  2. Remove the front cover of the 3.0T RF Accessories Cabinet.
  3. Remove the top and sides of the crate by turning the metal ratchets on the side shown in Figure 2.
  4. Attach the brackets (P/N 46-328451P2) and spreader bar (part of the hoist assembly) to the amplifier as shown in Figure 3. (Amplifier should still be in the case as shown in No. 3 of Figure 2.)
  5. While one FE stabilizes the Amplifier, use the hoist to lift it into place. (Brackets for the CPC Amplifier are already in place. For location of the CPC Amplifier, see Figure 4.)
  6. Attach the CPC Amplifier to the cabinet with the four screws provided.
  7. Refer to Figure 5 and Installation of Times Microwave Cables to guide the remainder of the cable installation and instructions for the 100-foot Times Microwave Cable included in the cable kit.

Positioning 8kW AMT/Hurley Amplifier

Procedure

Installation of RF Detector Boards (ASC/MGD Chassis)

About this task

For upgrading from 4kW to 8kW, no additional boards need to be added. For both the 4kW and 8kW MNS installation, the following supplemental circuit boards need to be installed:

  • Two RF Detector Boards

  • One BB Amp I/F Board

  • One Exciter Board

Procedure

  1. Ensure that all LOTO procedures were followed. Double check that the Accessories Cabinet breakers are OFF.
  2. Remove the RF Detector Boards (5250034 or equivalent) and BB Amp I/F Board from their packing material.
  3. At the front of the Accessories Cabinet, locate Slots 10 and 13 of the UPM Chassis.
    1. Insert one RF Detector Board into each slot. (See Figure 7.)
    2. Locate Slot 6 in the UPM Chassis, and insert the BB Amp I/F Board. (See Figure 7.)
  4. Locate the cables labeled: Slot 10 Jx and Slot 13 Jx (where x = 1-5). Attach them to their respective connections on the two RF Detector Boards, and run them to the IO Panel J102-105 connections.
  5. Add the 50-ohm Terminators (2329754 or equivalent) to all empty J numbers on the RF Detector Boards. (See Figure 7.
  6. Locate Cable 5113183-4 labeled: BB Amp I/F Board J3 and attach to Driver Module J13.
  7. Locate Cable 5115644 labeled: BB Amp I/F Board J5 and attach to IO Panel J123.
  8. Turn ON the Accessories Cabinet breaker.

Installation of Exciter Board

Procedure

  1. Remove the Slave Exciter Board (2373070 or equivalent) from its packing material.
  2. Locate Slot 9R at the rear of the Systems Cabinet, and insert the Exciter Board into the slot. (See Figure 9.)
  3. Locate the two Cables 5115630-2 and 5115630-4.
    1. According to its label, attach one end of Cable 5115630-2 to J6 on the Exciter Board and the other end to J11 of the board in Slot 14R.
    2. According to its label, attach one end of Cable 5115630-4 to J11 on the Exciter Board and the other end to J11 of the board in Slot 7R.

MNS T/R Switch Installation on LPCA

Procedure

  1. Note:

    The MNS T/R Module should be removed from the system when Spectroscopy scanning is completed. The presence of the module may cause IQ degradation.

    The LPCA and all cables should have been installed and connected at the time the system was installed. Refer to the Mechanical Installation Manual, Section 6-3-9-E to ensure this was done properly.
  2. Move the LPCA to a position where it can be easily accessed, either the front or rear of the magnet.
  3. Remove the MNS TR Switch from its packing material.
  4. Position the MNS TR Switch so that the square opening and two cables are facing the front of the magnet.
  5. Slide the MNS TR Switch onto the two brackets on top of the LPCA as shown in Figure 10.
  6. Attach the cables of the MNS TR Switch to the LPCA. (See Figure 10.)

Restoring System Power

Procedure

  1. Notify all personnel working on the system that the system will be powered up.
  2. Remove the cover from the front of the Gradient Cabinet.
  3. Remove LOTO.
  4. Open the plastic door over the front of the PDU breakers, and switch ON the appropriate subsystem breakers.
  5. Flip any individual circuit breakers that are turned off to the ON position.

Spectroscopy Software Installation

Procedure

  1. From the Common Service Desktop, click Configuration => Guided Install => FE mode, and start Guided Install.
  2. Type: root with the default Password: operator.
  3. After the Guided Install window opens, select the Option Key tab.
  4. If the option key is not downloaded from eLicense, insert the option key into the floppy or CD drive (depending on the media being used).
  5. Select the matching Floppy, eFloppy or eCD box in the Install Option Key portion of the window, then select Install.
  6. When the installation process is complete, either load the next floppy or when all options are loaded, select File => Quit to exit the Guided Install tool.
    Note:

    Most options are now loaded via eLicense. The MNS keys can be downloaded directly from the eLicense web page or loaded onto a floppy or CD from this site. In this case, only one floppy/CD is used, not multiple media as Step 6 above states.

  7. Remove the front panel of the computer, and place the MNS Option Rating Plate on the inside panel of the Computer Duplex front panel.
  8. Reboot the computer. The installation is now complete.

Configuration

Procedure

  1. Note:

    The MNS Option Key delivered with the Hydrogen-Only Spectroscopy Option (PROBE/SV) must be previously installed.

    At the Common Service Desktop Manager, click Config => Guided Install => FE Mode to launch the Guided Install GUI.
  2. On the Hardware Configuration screen (shown in Figure 11), select AMT for the 8kW amplifier and CPC for the 4 kW amplifier.
  3. Verify other 3.0T settings are correct for the system.
  4. Modify and save if necessary.
Topic ID: id_SL2358635-189349

Verify Configuration Settings

Procedure

  1. At the Common Service Desktop, select Tools => Utilities.
  2. Select Start to display the MR Config File Manager shown in Figure 12. Locate and change the following parameters:
    1. Spectroscopy RF Amplifier = yes to configure the MNS RF Amplifier to ready.
    2. Broadband Transceiver = yes to configure the MNS Broadband Transceiver (frequency change).
    3. Power Monitor Type = 4 to configure a 3.0T 12.x site with MNS.
    4. 3.0T Spectro RF AMP AMT Type = 0 and CPC =1.
    5. Click Save Changes to store all changes. (Discard Changes can be clicked to abort the changes.)
  3. Select Quit to close the Configuration File Manager.
  4. Reboot the system to save the file changes.
Topic ID: id_14932237

Finalization

Procedure

  1. Perform the Universal Power Monitor - MNS setup and calibration.
  2. Perform 2kW 1.5T, 4kW and 8kW 3.0T MNS Amplifier Calibration, a must for 4kW (CPC) and the 8kW (AMT) amplifiers.
  3. Perform Multi Nuclear Spectroscopy (MNS) Functional Checks.
