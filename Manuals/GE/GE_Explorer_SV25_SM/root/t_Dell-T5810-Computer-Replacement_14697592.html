About this task

Overview

This procedure provides instructions to replace the Dell T5810 host computer with a new one.

Topic ID: id_xbh_j5l_yfb

Prepare the Workstation for Host Computer Removal

Procedure

  1. Ask the customer to archive all images to an external storage device such as a PACS or DVDs.
  2. Perform a Save Info.
  3. To ensure patient privacy wipe all patient data from the hard drives. This will also wipe all data from the hard drive. This is done by following the steps below:
    1. Open DVD drive, insert Linux OS Software DVD into the DVD drive of Host computer.
    2. Perform System Restart by clicking the arrow on the Tools High Level Access tab, selecting System Restart and clicking [Yes] to confirm the restart.
    3. At the Linux installation prompt, select HELiOS/SUSE Option.
    4. At the HELiOS/SUSE Option prompt, boot the Linux DVD using the rescue mode by selecting Rescue Mode.
    5. Select English for Language.
    6. Select us for Keyboard Type.
    7. Select No for Setup Networking.
    8. Select Skip for Rescue Menu.
    9. Select shell Start shell.
    10. When the prompt displays (prompt will be bash—4.1#), type the following command and press [Enter]:

      dd if=/dev/zero of=/dev/sda bs=512000 &

    11. When the rescue prompt is displayed again, type the following command and press [Enter]:

      dd if=/dev/zero of=/dev/sdc bs=512000

      Note:

      When the commands are executing, the system will display only a flashing cursor. If the screen goes dark, hit a key on the keyboard to “wake up” the screen. The disk wipe takes about 30-40 minutes to complete. Ignore any messages indicating there is no space left on the device, for example:

      dd: writing `/dev/sdb’ : No space left on device.

    12. The disk wipe is complete when the bash—4.1# prompt appears. Eject and remove the OS DVD, then shut down the system by typing halt.
  4. Power OFF Host Computer.
  5. Perform LOTO on the GOC/operator workspace. See Lockout/Tagout of the GOC.
Topic ID: id_gch_k5l_yfb

Remove Host Computer from GOC

Procedure

  1. Remove the left side panel and set it is a safe place.
    1. Remove the two screws that secure the left side panel of the GOC
    2. Lift up and remove the left side panel. (Be careful not to strain the ground cable)
    3. Disconnect ground cable.
    Note:

    The side panel has a short ground lead connecting it to the main chassis. When removing the side panel, do not strain this ground lead.

  2. Remove all the cables connected to the host computer.

    Confirm that the cables are properly labeled. Note their locations for reattachment.

  3. loosen strap and remove hook to remove two straps.
    1. Press release lever of buckle and loosen strap.
    2. Remove the hook.
  4. Remove the host computer from the GOC.
    1. Loosen the two screws securing the back side bracket.
    2. Loosen the two screws securing the front side bracket.
    3. Loosen the two screws securing the high back bracket.
    4. Loosen the two screws securing the low back bracket.
  5. Carefully remove the host computer from the GOC.
  6. Remove the dust filter from the old computer.
    1. Remove the dust filter from the front panel of old computer. Install the dust filter to new computer. If the old filter is not reusable, install a new one.
    2. Remove the Velcro strips from front panel and attach them to the inside of the new machine’s cover. Install the Velcro strips. If the Velcro strips is not reusable, install a new one.
  7. Install the new host computer by performing the steps above in reverse order.
Topic ID: id_orz_k5l_yfb

Finalization

Procedure

  1. Remove LOTO from the GOC to return power. If needed, reconnect the twist-n-lock main power cable to the rear of the console. See Lockout / Tagout for GOC .
  2. Power up host computer.
  3. Perform the followings for BIOS setting.
    1. Power On the PC.
    2. Press F2 on Keyboard before entering the OS and then the BIOS setting GUI will show up.
    3. Use Mouse to select Power Management section > AC Recovery > Power On.
    4. Click Apply button on GUI and Exit button to exit.
  4. Load software and applications onto the operating system.

    See .

    Note:

    Load From Cold (LFC) must be performed to properly transfer customer options.

  5. Power up the GOC System Startup and Shutdown .
  6. Verify that the host computer front panel power LED is illuminated as a steady blue signal.
  7. From Guided Install, select RestoreInfo.
  8. Update the eLicense with the new Host ID. See Software Option Installation with eLicense Generated Keys.
  9. Perform Check Scan to confirm the system and applications are working properly.
  10. Confirm that all customer functions are operational (auto voice, filming, network, archive).
  11. Notice
    The computer weighs 43lbs(19.5kg). Proper lifting techniques shall be used for replacement.
    Repackage the defective PC for return.
