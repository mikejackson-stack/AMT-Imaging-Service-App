About this task

Overview

This procedure describes how to install Low Height Fixed Table.

Procedure

  1. Move the Table next to the dock structure.
  2. Fix the Table to the dock frame using four bolts. The screw type is 1006-M10C025-31.
    Note:

    Align the Table and Dock Frame by adjusting the 4 wheels.

    Note:

    Do not tighten the screws too tight now since Table adjustment will be performed later.

  3. Connect all cables.

    • Connect 5453341–J2 to 5447902–J2

    • Connect 5436192–J1 to 5443864–J1

    • Connect 5447902–J2 to Table Control Box J3

    • Connect 5443864–J1 to Table Control Box J4

    • Ground Cables (x2)

    • Connect DC Cable Assy(5346920) to Run# M1509 (from Mega SW)

    • Coaxial Cable Assy (5346919) to Run# M3511 (from Mega SW)

    Note:

    Make sure the following cables are already connected to Table Control Box.

    • RUN421 to Table Control Box J1

    • RUN#2009 (MG2-A29-J1) to Table Control Box J2

Finalization

No finalization steps.
