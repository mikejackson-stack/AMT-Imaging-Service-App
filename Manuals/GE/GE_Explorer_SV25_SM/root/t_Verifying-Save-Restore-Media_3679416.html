Verifying Save Restore Media

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable10 minutesNot Applicable
Table 2. Required conditions
ConditionReferenceEffectivity

Software is running.

--

About this task

Verify SaveInfo Data is used to verify content of SaveInfo media to the original data on the system disk drive. The program firsts checks that all files are present on the SaveInfo media and then if check sums match.

Verify MOD compatibility to host PC and how to convert data from MOD to CD/DVD.

Procedure

  1. Insert your already created SaveInfo MOD or DVD into the appropriate drive if it's not already there.
  2. At the host computer, go to the Service Desktop and open the Service Browser if it's not already running and start the Guided Install tool in FE Mode. See the illustration below.
  3. In Guided Install, go to the Save / Restore screen and start the verification process. See illustration below.
  4. The following dialog box opens prompting you to select the type of media being used for SaveInfo.
  5. The tool will verify the data on the media with that on the system hard drive. If no media is present, the you see an error message. While the media is being checked, the popup shown in the following alert box displays. The process takes about twi minutes.
  6. Once verification is complete, the system will ask if you want to view the log. See . Click Yes .
  7. The Log Contents alert box, similar to the illustration below, displays a list of the located content. If any errors are reported, create a new SaveInfo.
    Note:

    The Z400 host computer does not support MOD read/write. If the site has some data on MOD, then before upgrading the site host computer to Z400, MOD data has to be converted to CD/DVD.

    The steps to convert the MOD data to CD/DVD:

    1. If it is save info, just do save info on DVD.

    2. If it is an image or some other data, Do restore from MOD to system. Then save the data on to the CD/DVD.

Finalization

  1. Store Save/Restore media in a safe place.
  2. Do a test scan before customer turnover to ensure proper operation.
