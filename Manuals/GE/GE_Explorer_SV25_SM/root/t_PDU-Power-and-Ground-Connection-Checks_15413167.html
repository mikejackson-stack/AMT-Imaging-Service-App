About this task

PDU power and ground connections need to be tight in order to avoid system failures.

  2. For legacy system LOTO (Signa LX, EXCITE, HD, and HDi) follow these steps:
    1. Make sure LOTO at MDP is applied to isolate power from PDU.
    2. After LOTO of the PDU is applied, make sure the lights in the upper right corner (shown in figure below) are dark.
    3. Test the INPUT test points with reference to each other and OUTPUT test points with reference to GND with a multimeter to make sure there is no AC voltage. If there is AC voltage, you must correct the LOTO.
    Note: The test points are 100:1 ratio (480 VAC = 4.80 VAC, 208 VAC = 2.08 VAC). Therefore, a low voltage reading still indicates the presence of high voltage. Your voltage reading for each of the three phases must be 0 VAC before proceeding.

Tighten Connections for HD Systems

Procedure

  1. Remove the PDU front panel for CB1 access (see the applicable PDU vendor manual replacements section).
  2. Check L1, L2, L3 to ground with a multimeter to make sure there is no AC voltage prior to continuing.
  3. Tighten the incoming power and ground connections on the input power block of the PDU with a socket wrench with a 3/16 hex key extension to .

Tighten Connections for DV Systems

Procedure

  1. Open left front door of the PGR cabinet to expose the front of the PDU.
  2. Flip up the input power block lid to expose the connections as shown in the illustration below. Test the connections with a multimeter to make sure there is no AC voltage prior to continuing.
  3. Tighten the incoming power and ground connections on the input power block of the PDU with a socket wrench with a 3/16 hex key extension.
  4. Remove the front PDU panel to expose connections to CB1.
  5. Tighten the L1, L2, and L3 connections at CB1 inside the PDU.
