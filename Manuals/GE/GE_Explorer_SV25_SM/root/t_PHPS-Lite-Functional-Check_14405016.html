PHPS Diagnostics

Procedure

  1. Run the PHPS Functional Diagnostic.
    1. Open Common Service Desktop.
    2. Select 'Diagnostics/System Function /Patient Handling/PHPS Functional Diagnostic'.
    3. Select 'IO Status' and Select 'Run'.
  2. Check that the results satisfy the specification. See Table 3 for Specification.
