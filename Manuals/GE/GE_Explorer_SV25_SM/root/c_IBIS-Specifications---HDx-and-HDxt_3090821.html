IBIS Specifications - HDx & HDxt

Note:

All tests listed below are found in PM Assist Signa HDx & HDxt.

Test Procedure Criteria for Passing Notes
PM Schedule Run PM Check once at time of system turnover.
Software Updates Go to Common Service Desktop (CSD), PM section and execute PM Patch.

  • Broadband site: Informs FE of available Upgrades needed, and Upgrades that were automatically downloaded, then prompts FE to load Upgrades.

  • Modem site: Informs FE of available Upgrades needed. FE must get Upgrades from Website, load onto CD, then load onto system.

No Customer notification.
LVShim Go to CSD, PM section and execute LVShim.Must meet Customer Acceptance values in BRM TRM-Whole Body and CRM TRM-Zoom.Customer receives warning message for failures 21 days following PM. IBIS log failure(s).
SPT Go to CSD, PM section and execute SPT.There can be no Severe failures in the following tests:


Head SNR
Head FSE Stability
Head GRE Stability
Body SNR
Body FSE Stability
Body GRE Stability
Coherent Noise
Eddy Currents

Customer receives warning message for failures 21 days following PM. IBIS logs failure(s).
Note: SPT is run in Zoom mode for PMs. If failures occur, subsequent passes must also be run in Zoom Mode to pass IBIS. Severe failures must be corrected to pass IBIS.
EPI White Pixel Go to CSD, PM section and execute EPI White Pixel PM Mode.Run test only. White Pixel failures not counted by IBIS. This is for trending/data collection purposes only. See the section in Table 1 for EPT White Pixel Specs, Generating the System in Spec Authentication Key.No Customer notification.
MCR Tool (for 14.0M5 and earlier software) Go to CSD, PM section and execute MCR Tool Check. Run test. (Failures indicate a problem exists.)No Customer notification.
16-Channel Diagnostics (for 14.0M5A forward and 15.x software) Go to CSD, PM section and execute 16-Channel Diagnostics.Run test. (Failures indicate a problem exists.)No Customer notification.
PM Check Run PM Check after all tests noted above are executed and upgrades loaded.
