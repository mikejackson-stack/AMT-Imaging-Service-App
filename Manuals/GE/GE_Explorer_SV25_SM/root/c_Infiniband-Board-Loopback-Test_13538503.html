Infiniband Board Loopback Test

Diagnostic Link

Diagnostics >> MGD Chassis

Purpose

This diagnostic verifies the MGD Infiniband board by sending data between its ports over Infiniband. Since the hardware is not capable of being configured for this through software, it is necessary to disconnect the Infiniband data cables and connect an Infiniband Loopback cable to physically connect the ports together.

Table 1. Purpose of Loopback Test
Capability What It Does When to Use
Infiniband Board Loopback TestTests the stand-alone Infiniband board.If Infiniband communications diagnostic reports a failure.

Components Tested

Infiniband board in MGD chassis

Tools and Test Equipment

Table 2. Equipment Required
Item Quantity Part Number
Infiniband Loopback Cable15146975-8

Safety

Warning
ELECTROCUTION HAZARD!
DANGEROUS VOLTAGES ARE PRESENT THROUGH OUT THE SYSTEM CABINET WHEN POWER IS APPLIED.
Perform LOTO on the System Cabinet. See the “MR Service Safety Manual”, PN 5452735.

Procedure

  1. Remove the Infiniband data cables from the front of the MGD Infiniband board.

  2. Connect the Infiniband Loopback cable as shown below.

  3. Verify that the green LED next to each port is On and the yellow LEDs are Off.

  4. Click the Insite browser’s Diagnostics tab, and select MGD Chassis > Infiniband Board Loopback Test. The screen below will display.

  5. Click Run. The yellow LEDs next to each port turn On.

    Note:

    Once Run is selected, do not click anywhere else on the Common Service Desktop until the test is completed. To abort the test prior to its completion, click Stop.

  6. Wait for the test to complete.

  7. Remove the Infiniband Loopback cable.

  8. Restore the original Infiniband data cable connections to the Infiniband board.

  9. Perform a TPS Reset.

Problem/Solution Table

Review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic’s results are as follows:

Table 3. Problem/Solution for Diagnostic Results
Fault Problem Description GE Field Action
Both green LEDs do not illuminate when cable is connected.

  • Cable is not securely connected

  • Board is not properly seated

  • Loopback cable is defective.

  • Infiniband board is defective.

  • Attach cable.

  • Reseat Infiniband board.

  • Replace Infiniband loopback cable.

  • Replace Infiniband board.

Yellow LEDs do not illuminate when test starts.

  • Board is not properly seated.

  • Infiniband board is defective.

  • Reseat Infiniband board.

  • Replace Infiniband board.

Test fails.

  • Board is not properly seated.

  • Infiniband board is defective.

  • Reseat Infiniband board.

  • Replace Infiniband board.

Finalization

After exiting from Diagnostics, perform a scan to verify system is operating properly.
