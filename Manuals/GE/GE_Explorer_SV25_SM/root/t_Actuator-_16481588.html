Procedure

  1. Warning
    Please do not raise/lower the table by the screw rod, or the actuator will break.
    Ensure shut down PHPS and power to Megaswitch.
  2. Disassemble base covers, all scissor covers, rear support.
  3. Disconnect cables in dock frame area, disconnect table with dock frame.
  4. Install casters, lower leveling pads if necessary, heighten leveling pads after casters are installed. Move the table out of bay.
  5. Lower leveling pads to touch ground.
  6. Use screw rod to support.
  7. First disconnect bottom actuator pin, then disconnect top pin.
  8. Use screw rod to move table to near mid position (propose to deliver actuator when half extended).
  9. First install bottom pin, then top pin.
  10. Install mid scissor covers, then top scissor covers, ensure min. 3mm gap.
  11. Heighten leveling pads, lower casters to topmost position, push table back to bay.
  12. Push table back Lower leveling pads, remove casters Align table height with magnet and level table by adjusting leveling pads.
  13. Tighten table with Dock frame and connect all cables.
  14. Install rear supporter.
  15. Install bottom scissor covers, ensure min. 3mm gap.
  16. Install base covers and caps Install dock cover.
  17. Shut up PHPS and power to Megaswitch.

Finalization

  1. Turn the system power ON. Refer to Lockout / Tagout for System Cabinet PDU Main Breaker.
  2. Level the Table and perform Height Adjustment. Refer to LEVELING FIXED TABLE and TOP HEIGHT ADJUSTMENT.
  3. Fix the FRP Covers of the Table.
  4. Perform CRADLE HOME SENSOR CHECK .
  5. Check the Table Function. Refer to TABLE CHECKS AFTER INSTALLATION .
  6. Perform Express Coil MCQA Test to check that the PA coil cable is properly connected.
