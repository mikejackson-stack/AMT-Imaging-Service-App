Printer Configuration for Flexi Filmer

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable60 minutesNot Applicable

About this task

The DICOM/Post Script Print feature allows configuration of the filming function to accommodate filming to paper or film printer that is networked to the workstation through a DICOM/Post Script printer.

Topic ID: id_SL4520303-1146705

Go through Printer Configuration

Procedure

  1. Select Service Browser from the service desktop.
  2. From Service Browser Select Utilities Tab.
  3. Select Printer Configuration from the options available.
Topic ID: id_SL4520307-1146705

DICOM Printer Addition

Procedure

  1. Select Configure DICOM Printers.
  2. Select Add button.
  3. Configure the Printer.

    • Layouts: For a printer to be configured Layouts specify the different layouts a user can use while printing through that printer. For eg. for a printer dummyFlexiFilmer if the layout specified is 1x1 and 2x2 then the user can use only these two layouts when trying to print any film using the printer dummyFlexiFilmer through FlexiFilmer.

      How to validate the chosen layouts: Please note this is only applicable when the user has selected the Grid layout mode in FlexiFilmer. Trying to use any layout other than the ones specified during configuration for a printer, printing will not be allowed and the user will be shown an error message.

    • Film size: For a printer to be configured Film size specifies the size of the film as supported by the printer. The film size as seen in the FlexiFilmer UI will change according to the selected film size for the selected printer.

      How to validate the chosen film size: The user can specify one or more film sizes supported by the printer and can choose one of them while actual printing using the FlexiFilmer UI. The same is explained through the screen shots attached with the mail. If there is only one film size specified then the same will be displayed (and locked for change) in the FlexiFilmer UI.

DICOM Printer Configuration Modifications

Procedure

  1. Select Configure DICOM Printers.
  2. Select the Printer Already configured.
  3. Select Modify Button.
  4. Modify the Printer Configurations.
Topic ID: id_SL4520316-1146705

DICOM Printer Removal

Procedure

  1. Select Configure DICOM Printers.
  2. Select the Printer already configured.
  3. Select the remove Button.
Topic ID: id_SL4520320-1146705

Post Script Printer Addition

Procedure

  1. Select Configure Post Script Printers.
  2. Select Add Button.
  3. Configure the Printer from the UI presented.
Topic ID: id_SL4520324-1146705

Post Script Printer Modifications

Procedure

  1. Select Configure Post Script Printers.
  2. Select the Printer to modify.
  3. Select Modify Button.
  4. Modify the printer from the UI.
Topic ID: id_SL4520329-1146705

Post Script Removal

Procedure

  1. Select Configure Post Script Printers.
  2. Select the Printer to Remove.
  3. Select Remove Button.
Topic ID: id_14989360

Finalization

Procedure

  1. Systems need to be restarted for the changes to take effect.
  2. After printer configuration, create a test film.
  3. Ensure the system is working before turning over to customer.
