Gradient Calibration Image Analysis

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not ApplicableNot ApplicableNot Applicable

About this task

This section describes the procedure for analyzing the x-gradient scan. The procedure for the y-gradient and z-gradient scans is similar.

Note:

If the Z measurement is not even close to 100mm, there may be a bubble in the phantom causing the incorrect measurement. Open a C shell and type setftg to turn off Fast TG, then rescan the z axis. After the completion of gradcal, type resetftg to turn Fast TG back on.

Procedure

  1. To start the DQA Calibration tool, refer to the instructions on Figure 1.
  2. Select the Grad Mode you need to calibrate if TwinSpeed. See Figure 2.
  3. Perform correct scan (WHOLE/ZOOM), (X, Y or Z). See Table 2.
    Table 2. Running Gradcal Scans

    • GradCal - X Gradient Scan

    • GradCal - Y Gradient Scan

    • GradCal - Z Gradient Scan

  4. Step through the Calibration Screens as shown in the following Illustrations:

    Instructions for changing cfxfull, cfyfull, cfzfull CV's.

    • Right click on Research Options.

    • Select Display CV's.

    • Type the desired CV Name in the CV Name Field and hit Enter.

    • Type the new value in Current Value field and click Enter.

    • Click Accept.

    • Right click on Research Options and select Download.

  5. Record the final gradient calibration results in Table 3, Gradcal Data Sheet.

    Be sure to complete all three planes and both Grad Modes for Twinspeed, before continuing further with this procedure.

    • Gradcal Image Analysis X

    • Gradcal Image Analysis Y

    • Gradcal Image Analysis Z

  6. When all three gradient fields have been calibrated (and for the TwinSpeed, separately for each GradMode), the Signa software must be shut down and rebooted to install the changes in the MRconfig.cfg file(s).
    1. Follow the instructions as given in Figure 6 for rebooting Signa
    2. The following warning message will be displayed:

      WARNING: System Shutdown?

      Please avoid or delay shutdown IF

      film composer or archive process

      is still active

    3. Click the Yes button in the message box.

      “Shutting down the system” will appear in the message box.

    4. Wait until Signa logout is complete.
    5. Restart the system software by double-clicking on the Signa icon (or type signa in the first field), then type the password adw2.0 and press Enter. Allow initialization to fully complete before pressing any keys.
  7. Store all completed data sheets for future reference.

  1. Insure you've completed calibration on all three gradient planes.
