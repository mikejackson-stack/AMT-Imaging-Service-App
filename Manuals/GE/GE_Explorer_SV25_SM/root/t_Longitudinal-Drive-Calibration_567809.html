LONGITUDINAL DRIVE CALIBRATION

About this task

Note:

Longitudinal Drive Calibration must be performed before the Electrical Isocenter Calibration procedure.

Note:

During Load From Cold, Begin of cradle travel should have been set to 50 and End of travel set to 2568. This procedure assumes this starting point. If values are different, change them back to 50 and 2568, and download the TPS/ISE before continuing, procedure for Configuration File.

Procedure

  1. Move the cradle to the home position.
  2. Set the scale along the edge of the Table to measure the actual distance of the cradle movement.
  3. Move the cradle approximately 10 cm into the bore.
  4. Attach the tie-wrap on the cradle with tape as a measuring meter. Record the current position as A1. See Figure 1.
    Table 4. Data Sheet
    A1=
    A2=
    DD: Travel Distance of Magnet Display =
    DA: A2-A1=
  5. Turn on the alignment lights and press landmark to set the position display on the gantry to zero.
  6. Fast forward the cradle into the bore until the Magnet display indicate about 1000mm. Record the distance indicated on the Magnet display as DD.
  7. Record the current meter position as A2. See Figure 2. A2-A1 equals to the actual table movement (DA).
  8. Check that |DA-DD| ≤ 1mm. If the value satisfies the specification, no calibration needed. End the procedure.
  9. If the value does not satisfy the specification, calculate the following formula.

    The new End of cradle travel variable = [2518 x DD / DA)] +50

    Note:

    If this is the second calibration, use ‘End of cradle travel variable in config file –50’ instead of 2518.

Topic ID: id_SL62473-567809

Parameter Setting of Table end Travel

Procedure

  1. Select “Common Service Desktop” and run Config File Manager. Refer to Configuration File Manager
  2. Search file for 2568mm travel parameters by scrolling down with the Enter button.
  3. Change the parameter end Travel to from 2568mm to the calculated vale.
  4. Save and close.
  5. Repeat the procedure from the beginning and verify that the specification is satisfied. (Specification |DA-DD| ≤ 1mm ) .

Finalization

No finalization steps.
