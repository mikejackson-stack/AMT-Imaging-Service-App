SPT Full Test Mode for 1.5T

Procedure

  1. Note:

    See SPT Full Test Mode for 3.0T for SPT Full Test Mode for 3.0T.

    Disable the vacuum pump. (TwinSpeed only)
    1. Disable the TwinSpeed vacuum pump if SPT FSE or FGRE stability scans are going to be run. Failing to disable the vacuum pump may result in SPT stability failures.
    2. Remove the front cover from TwinSpeed Accessory Cabinet (TAC), and place the power switch on the right side of the vacuum pump (near the power cord connection) in the OFF position. (May also remove the power cord from the pump.)
  2. Note:

    For 12x 1.5T systems, proceed to Step 3.

    (For 11x 1.5T systems) Set up Head Coil
    1. If using the older classic Signa Head Coil, put it on the patient table. If using the newer Split Head Coil, proceed to Step 2.c.
    2. Make sure the DQA phantom is placed in the coil with the filler plugs at the rear of the coil.
      Note:
      If using the split-top head coil on an older Signa table, do not try to align the coil with the double notches on the old style table. The split-top head coil needs to be positioned on the table as close as possible to the LPCA. Failure to correctly position the head coil will result in SPT failures due to inability to use full travel distance. For all software versions prior to 14.x, verify the ability to travel from the landmark on the head coil to the crosshairs on the body loader prior to starting SPT.
    3. If using the newer Split Head Coil, place the coil on the patient table. The Split Head Coil Phantom fits in the new head coil only one way.
    4. Place the phantom in the head coil.
    5. Position the Short Loader with the Body Sphere inside on the nesting plate. (The label on the top of the short loader indicates the correct orientation.)
    6. Landmark on the axial line of the phantom in the head coil.
    7. As a final positioning check, ensure:

      • Head coil is completely in position.

      • Nesting plate is up against the head coil holder.

    8. Proceed to Step 4.
  3. (For 12x 1.5T systems) Set up the head coil.
    1. For the new Split Head Coil, proceed as follows (for the old coil, proceed to step Step 3.b):

      1. Place the Split Head Coil on the patient table.

      2. Place the head spherical phantom and loader in the head coil.

      3. Place the nesting plate on the patient table flush against the head coil positioner. Proceed to step Step 3.c.

    2. Coil Setup for Old Head Coil

      1. Insert the DQA Phantom into the head coil.

      2. Turn on the alignment light, and move the cradle until the alignment light is centered using the marks on the phantom for a reference.

      3. Remove the DQA phantom and replace it with the TLT Sphere.

    3. Position the Short Loader with the Body Sphere inside on the nesting plate.
      See Figure 6.
    4. Landmark on the axial line of the phantom in the head coil.
    5. As a final positioning check, ensure:

      • Head coil is completely in position.

      • Nesting plate is up against the head coil holder.

  4. Invoke SPT full test mode.
    1. Notice
      Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on End Exam to terminate any previous exam. It is not necessary to click on New Pt as SPT automatically enters the scan protocol when it is invoked via the MR Tools menu.
      Note:

      We do not recommend running the LVShim as part of SPT. Do not select the LVShim option when you execute the SPT. See Figure 10.

      To start the SPT Test tool from the Service Browser, follow the steps in the figure below.
    2. (For 11x systems) In the SPT Head Coil Selection screen shown in the figure below, choose the correct coil.
    3. (For 12x systems) In the SPT Head Coil Selection screen, select the correct coil.
      Note:

      The 1.5T systems use the spheres with the green solution.

    4. Note:

      We do not recommend running LVShim as part of SPT. Do not select the LVShim option when you execute the SPT. See the figure below.

      Select the head coil currently in use, and click on Start. An SPT Test menu displays in a window on the desktop.
    5. To exit SPT, click the Quit SPT button.
    6. For TwinSpeed only: When finished with SPT, position the power switch on the vacuum pump to the ON position, and replace the cover on the front of the TAC.
    7. To view SPT results, select the Utilities tab on the Service Browser, and select Report Manager.
    8. Enter the Report Manager password and press Enter. (For more information, see Report Manager Tool.)
    9. If appropriate, return to SPT for more selections.

SPT Full Test Mode for 3.0T

Procedure

  1. Note:

    The 3T systems use the spheres with the pink solution.

    Disable the vacuum pump. (TwinSpeed only)
    1. Disable the TwinSpeed vacuum pump if SPT FSE or FGRE stability scans are going to be run. Failing to disable the vacuum pump may result in SPT stability failures.
    2. Remove the front cover from TwinSpeed Accessory Cabinet (TAC), and place the power switch on the right side of the vacuum pump (near the power cord connection) in the OFF position. (May also remove the power cord from the pump.)
  2. (For 11x 3T systems) Set up the head coil.
    1. Note:

      For 12x 1.5T systems, proceed to Step 3.

      If using the older classic Signa Head Coil, put it on the patient table. If using the newer Split Head Coil, proceed to step Step 2.c.
    2. Make sure the DQA phantom is placed in the coil with the filler plugs at the rear of the coil.
      Note:
      If using the split-top head coil on an older Signa table, do not try to align the coil with the double notches on the old style table. The split-top head coil needs to be positioned on the table as close as possible to the LPCA. Failure to correctly position the head coil will result in SPT failures due to inability to use full travel distance. For all software versions prior to 14.x, verify the ability to travel from the landmark on the head coil to the crosshairs on the body loader prior to starting SPT.
    3. If using the newer Split Head Coil, place the coil on the patient table. The Split Head Coil Phantom fits in the new head coil only one way.
    4. Place the phantom in the head coil as shown in the figure below.
    5. Position the Short Loader with the Body Sphere inside on the nesting plate. See Figure 16.
    6. Landmark on the axial line of the phantom in the head coil.
    7. As a final positioning check, ensure:

      • Head coil is completely in position.

      • Phantom is all the way in the head coil.

      • Nesting plate is up against the head coil holder.

  3. (For 12x 3T systems) Set up the head coil.
    1. Place the head coil on the patient table.
    2. Place the head spherical phantom and loader in the head coil. (See Figure 16.)
    3. Place the nesting plate on the patient table flush against the head coil positioner.
    4. Position the Short Loader with the Body Sphere inside on the nesting plate. (See Figure 16.)
    5. Landmark on the axial line of the phantom in the head coil.
    6. As a final positioning check, ensure:

      • Head coil is completely in position.

      • Phantom is all the way in the head coil.

      • Nesting plate is up against the head coil holder.

  4. Invoke SPT full test mode.
    1. Notice
      Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on End Exam to terminate any previous exam. It is not necessary to click on New Pt as SPT automatically enters the scan protocol when it is invoked via the MR Tools menu.
      Note:

      We do not recommend running LVShim as part of SPT. Do not select the LVShim option when you execute the SPT. See Figure 18.

      To start the SPT Test tool from the Service Browser, follow the steps in the figure below.
    2. Select the head coil currently in use, and click on Start. An SPT Test menu displays in a window on the desktop.
    3. To exit SPT, click the Quit SPT button.
    4. For TwinSpeed only: When finished with SPT, position the power switch on the vacuum pump to the ON position, and replace the cover on the front of the TAC.
    5. To view SPT results, select the Utilities tab on the Service Browser, and select Report Manager.
    6. Enter the Report Manager password and press Enter. (For more information, see Report Manager Tool.)
    7. If appropriate, return to SPT for more selections.

Finalization

Procedure

  1. Perform a TPS Reset after completing SPT to return the system to a normal working state.
  2. If for any reason an SPT scan is aborted, shut down and reboot the system.
