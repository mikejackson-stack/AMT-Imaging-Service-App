HEAD FORWARD POWER CALIBRATION

Procedure

  1. Inhibit TR faults. Disable the Driver Module TR fault detection in the RFS (RF in the system cabinet). Move switch 2 to the TR Disable position.
  2. Remove the head heliax cable from J3 at the back of the RF amplifier and connect it directly to the RF dummy load.
    Note:

    If the RF max power out procedure was just completed, configuration is the same. Leave the body RF heliax cable disconnected and the head output can keep the coupler in line. It will not change the outcome of the calibration.

Setting up Software Tool to Calibrate UPM – Head Forward Power

Procedure

  1. Note:

    This tool must see a landmark only. It is not necessary to have a Head coil in place, or any other scan parameter entered than what is described below. Simply landmark on the cradle where the Head coil would be.

    To establish a landmark, start a New Exam.
  2. Enter the following parameters:
    1. Patient ID: geservice
    2. Weight: 111
  3. Press Align button.
  4. Move the cradle to the home position and then drive it into the bore.
  5. Press Landmark button when the align light is approximately where the center of the head coil would be. Press the Advance to Scan button.
  6. From the Common Service Desktop, select:
    1. Select Calibration Tab.
    2. Select UPM Tool.
    3. Select Click here to start the tool to start the UPM tool.
  7. Select the Nuclei 1H.
    Note:

    The first time running the UPM calibration tool after a load from cold, the following error may appear: “The spectroRFampType and upm.config do not match! Please run the UPM Tool config file editor and hit [Restore Defaults] and save the config file”. If this error appears, click File > Edit Config. When the window opens, click [Restore Defaults] then close the screen. The tool will now have the correct information and this popup will not appear again during future UPM calibrations.

  8. Select the RF chain you are going to calibrate: Head.
  9. Select the Calibrate button.
  10. Select Power Monitor type: Forward.
  11. Select Start button.
    Note:

    You can safely ignore the advisory message indicating the head coil is not present.

  12. Status should indicate Pass/Fail from 1 minute to 7.5 minutes, depending on software version (tool should notify user of current step in progress).
Topic ID: id_15010877

Finalization

Procedure

  1. Remove the cables and power measurement equipment.
  2. Re-attach the head and body heliax cables.
  3. Remove the cables and power measurement equipment.
  4. Re-attach the head heliax cables.
  5. Re-enable T/R drive fault detection. See Figure 1.
  6. Upon completion of any UPM calibration, Reset TPS. The system will not scan until this step is complete.
