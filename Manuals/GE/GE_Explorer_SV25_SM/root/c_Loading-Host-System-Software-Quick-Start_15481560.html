Loading Host System Software (Quick Start)

This quick-start guide provides an overview of the procedures required to load host system software for each software version. Refer to the linked procedures for detailed information.

Note:

The common procedures with DVMR are used. If there is “DV25.1 or later” is shown, please read as “PX26.1 or later”

Table 1. Software Load Procedures
PX26.1 and later

Prerequisites

  • (For New Installation) Identify the information you will need to have about the site and the site’s hardware.SIGNA Pioneer System and Hardware Configuration

  • Record the service license ID. Refer to “Access Service License ID 16-Digit Code)” in Service Licensing for specific information.

  • Once HIPAA/Security setting is configured, the choice cannot be changed without reinstalling the software. See Security Levels for more information.

  • If the host PC, its components, or language change, then SSA licenses must be updated. On-site Internet connectivity is required. See Service Licensing for more information.

  • Request customer to back up image data.

  • If research software and hardware are installed, contact GEHC Research Support for backup and restore instructions.

Note:

Verify that the latest service pack is loaded at the end of the system load procedure. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library. See Installing Service Packs for more information on loading service packs.
