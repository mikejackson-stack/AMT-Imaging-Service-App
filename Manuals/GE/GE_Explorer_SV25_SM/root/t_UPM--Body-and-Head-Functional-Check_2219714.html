About this task

The UPM Functional checks for 1.5T consist of three automated tests:

  • Peak Power, Pulse Width, Duty Cycle at TG=170

  • RF Inhibit test (Check that RF is disabled when inhibit condition)

  • Trip Test

    All 3 automated tests must pass to ensure the correct operation of the Universal Power monitor system.

    Run both Head and Body UPM Functional checks for the proper system type.

  • 1.5T HEAD UPM FUNCTIONAL CHECK

1.5T BODY UPM FUNCTIONAL CHECK Setup

Procedure

  1. Inhibit TR faults. Disable the Driver Module in the System Cabinet,Figure 1. Move switch 2 to the TR Disable position.
  2. Remove the Body RF cable from J4. Connect the RF dummy load into J4. Use 7/16 Male - N Female Adapter attached in System Cabinet.
    Note:

    If the body section of the 1.5T SRFD3 Max Power RF Output and Calibration procedure was just completed, configuration is the same. You can leave the head RF cable disconnected and body can keep the wattmeter in line. It will not change the outcome of the calibration.

    Note:
    7/16Male -N Female Adapter is located at System Cabinet Left Shelf. Remove left cover and find it. See Figure 2

Setting up Software Tool to Calibrate UPM – Body Forward Power

About this task

This tool must see a Landmark only. It is not necessary to have a Body Phantom in place. Simply Landmark on the cradle where the Body Phantom would be.

Procedure

  1. Press Landmark.
  2. Press Advance to Scan.
  3. From the Common Service Desktop:
    1. Select Calibration Tab
    2. For the Class A/C service tool, select UPM Tool from the calibration menu and select Click here to start this tool
    3. Figure 4 shows an example of the UPM tool.
  4. Select the Nuclei [1H].
  5. Select the RF Chain you are going to check [Body].
    Note:

    Power Type selection will be grayed out. This is normal, and is not used.

  6. Select: [Func Chk] Button
  7. Select the [Start] button.
  8. After that, the tool takes full control and runs the 3 functional tests for whatever setup is currently active. The result of each test is compared against a Specification File on the system. Status should indicate Pass/Fail.

    During the tests, the user will be prompted 3 times as each test completes. Look in the error log to confirm that the tests completed successfully. The following illustrations show an example of pop ups and error logs that should be seen.

    Note:

    A TPS Reset must be preformed when testing is complete before scanning can resume.

  9. To proceed:
    1. If any one of the tests fail, refer to Troubleshooting UPM.
    2. If all 3 tests pass, proceed to 1.5T 1.5T HEAD UPM FUNCTIONAL CHECK

1.5T HEAD UPM FUNCTIONAL CHECK Setup

Procedure

    If the Head RF power out procedure was just completed, configuration is the same. You can leave the Body RF heliax cable disconnected and the head output can keep the wattmeter in line. It will not change the outcome of the calibration.

Setting up Software Tool to Calibrate UPM – Head Forward Power

About this task

It is necessary to have a Head coil in place. It is not necessary to have a Head Phantom in place. Simply Landmark on the Head Coil.

Procedure

  1. Withdraw the Cradle from its previous position.
  2. Place the head coil on the cradle.
  3. Press Landmark
  4. Press Advance to Scan
  5. Select the Nuclei 1H
  6. Select the RF Chain you are going to check Head.
  7. Select: Func Chk Button
  8. Select the Start button.
  9. After that the tool takes full control and runs the 3 functional tests and the UPM status should indicate Pass/Fail.

    During the tests, the user will be prompted 3 times as each test completes. Look in the error log to confirm that the tests completed successfully. The following illustrations show an example of pop ups and error logs that should be seen.

  10. To proceed:
    1. If all three tests pass, select Quit from the UPM Main Window
    2. If any one of the tests fail, refer to Troubleshooting UPM.

Troubleshooting UPM

Procedure

  1. Notice
    From HDE15.0 software, it is not allowed to edit the UPM cal config file. If it is edited, Patient Scan cannot be performed because system recognizes UPM calibration is not completed. So, solution 1 is applied for HDE14.0 Only.
    Solution 1 (HDE14.0 Only):
    Note:

    This solution is applied for HDE14.0 software only. Do NOT proceed this procedure if the system is HDE15.0. Please read the note above. For HDE15.0, perform Solution 2 and later.

    • If failure is related to Over limit or Under limit of peak power, perform the following troubleshooting. UPM- Body and Head Functional Check for HDE14.0

  2. Solution 2:
    1. Check all cabling to the UPM’s make sure that they are properly cabled.
    2. Repeat the UPM Functional Test for the receive chain that failed. (Head or Body).
  3. Solution 3
    1. Cycle Power to the UPM Chassis
    2. Reset TPS
    3. Repeat the UPM Functional Test for the receive chain that failed. (Head or Body).
  4. Solution 4, reboot the system.
  5. Solution 5
    1. Remove power from the UPM.
    2. Reseat the Processor Module.
    3. Restore Power to the UPM.
    4. Reset TPS.
    5. Repeat the UPM Functional Test for the Receive chain that failed. (Head or Body).
  6. Solution 6
    1. Remove power from the UPM.
    2. Reset the Detector Boards
    3. Restore Power to the UPM
    4. Reseat TPS
    5. Repeat the UPM Functional Test for the Receive chain that failed. (Head or Body)
  7. Solution 7
    1. The problem could be a bad Processor Module
    2. Remove power from the UPM.
    3. Replace the Processor Module
    4. Restore Power to the UPM
    5. Reset TPS.
    6. Repeat the UPM Functional Test for the Receive chain that failed. (Head or Body)
  8. Solution 8
    1. The problem could be a bad Detector Board
    2. Remove power from the UPM
    3. Replace both Detector Boards
    4. Restore Power to the UPM.
    5. Reset TPS
    6. Repeat the UPM Functional Test for the Receive chain that failed. (Head or Body)
  9. For additional troubleshooting information, please refer to ASC-Lite Chassis Theory and Troubleshooting .

UPM Theory

About this task

The Universal Power Monitor calibration parameters found in the UPM Calibration file (/export/home/signa/tools/upm.config) are used in the calibration/Functional Check program. The Program code sets the Digital attenuators in the UPM based on the results of the 3 tests run, and a comparison to these UPM Calibration parameters. This calibration file is accessible from within the UPM Calibration tool from the “File” pull-down Menu, “Edit Config” Option. These values can be edited and saved during troubleshooting to perhaps understand where the power monitor is tripping, (If at all). Before changing any parameter, Make sure to select and run the “Bkup UPM Cal” option first. This will allow you to return to the default values at any time. The Screen shot of the UPM Calibration file found in this document contains the default configuration values for all of the UPM parameters as of December 8, 2003. (Use the [Restore Defaults] on the config file editor GUI to always get back to known default values).The final UPM digital attenuator values are written to the UPM Calibration Configuration files (UpmCal1.cfg, UpmCal2.cfg.etc.,) located in directory: w/config

Procedure

  1. The format of Upm1Cal.cfg and Upm2Cal.cfg example is as follows:
    1. 85←Head FORWARD Power, attenuator setting in HEX
    2. 9f← Not Used
    3. 0← Not Used
    4. 8d← Body FORWARD Power, attenuator setting in HEX
    5. 8e←Not Used
    6. 9d←Not Used
  2. Figure 19. Any changes to these values are temporary and can be quickly restored by selecting the restore defaults button.
