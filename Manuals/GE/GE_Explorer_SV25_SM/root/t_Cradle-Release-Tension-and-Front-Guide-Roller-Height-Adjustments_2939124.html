About this task

This procedure provides the instructions for the Cradle Release from the Transport Tension adjustment and the Front Guide Roller Height adjustment on the patient table.

Cradle Release from Patient Transport Tension Adjustment

Topic ID: id_SL1759600-1046169

Cradle Position During Release Mechanism Adjustment

Procedure

  1. Make sure the cradle is positioned on the Table.
  2. Remove the Table from the Scan Room to perform the rest of this service procedure.
  3. Press the cradle release pin and front Delrin stopper shown in Figure 1.
  4. Pull the cradle out. (The cradle will come approximately 50 mm away from the tabletop front; done to make sure the cradle is clear of the flipper actuation. See Figure 2.)
  5. Press the Up Limit Indicator Bumper to release the central pin shown in Figure 3.
  6. Pull the cradle out and remove it from the Table. (See Figure 4.)
  7. Once the cradle is removed from the table, place the cradle on a surface where further adjustments can be performed. (See Figure 5.)

Initial Checks to Adjust Cradle Release Mechanism

Procedure

  1. Notice
    Two people are required to conduct this check.
    Twist the handle fully to extend the Release Bar/Ramp as shown inFigure 6, and hold it in the extended position.
  2. Refer to Figure 7. Using a socket extension, nut driver or similar tool, push the Release Bar/Ramp shown in Figure 8 with approximately 10 to 20 lbs. of force (Force Gauge, 5142800 or 5142800-2).
    1. Observe the movement of the release ramp. A properly adjusted release ramp will exhibit some spring, and return to its original position when released.
    2. If the Release Bar/Ramp fails to return to its original position and moves more than approximately 1.5 mm (0.06 in.), refer to Figure 9and adjust the release mechanism tension according to the instructions in Tension Adjustment of Cradle Release Mechanism.

Tension Adjustment of Cradle Release Mechanism

Procedure

  1. Turn the cradle over to access the Kevlar cord shown in Figure 10.
  2. Remove the knot in the Kevlar cord (shown in Figure 11) with the assistance of the 3/32 in. Allen Wrench.
  3. Using the 3/32 inch Allen Wrench, loosen the grub screw as shown in Figure 12.
  4. Pull the Kevlar cord in the direction of the blue arrow shown in Figure 13to apply the necessary tension required to butt the Release Bar/Ramp against the cradle front section. See Figure 14.
  5. Notice
    When securing the tension on the Kevlar cord, make sure the grub screw is on the rivet and NOT on the Kevlar cord. The cord must be beneath the rivet when tightening the grub screw as shown below.
    Tightening Grub Screw
    Refer to Figure 15.
    1. Once the Release Bar/Ramp has the appropriate tension applied, tighten the grub screw to secure the tension on the cord.
    2. Tie a knot with the loose end of the Kevlar cord as shown above.

  7. If the height of the Front Guide Rollers requires adjustment, proceed to Front Guide Rollers Height Adjustment. If not, proceed to Step 1.

Front Guide Rollers Height Adjustment

About this task

If the Front Guide Rollers require a height adjustment, shims need to be added or removed. The Shim part number is 46-317181P1. Order additional shims if the height is to be raised. The Shims are 0.35 of an inch wide.

Procedure

  1. If the cradle is not already removed from the table top, follow Step 2, then proceed to Step 1.
  2. The Front Guide Rollers should be 0.25 inches above the cradle wheel tracks as shown in Figure 16. In there is any variation, follow the next steps in the adjustment process.
  3. To readjust the height of the rollers, the latch assembly Holding Blocks must be removed. (See Figure 17.)
  4. Using the 5/32 Allen Wrench, loosen the Allen screws while holding the block. (See Figure 18.)
  5. Using the standard screwdriver, remove the screws from the holding block as shown in Figure 19.
  6. Remove the Holding Blocks from the latch assembly.
  7. Add or remove shims so the O-rings are at the correct height of 0.25 inches (6.35 mm) above the horizontal wheel track on either side. (See Figure 20.)
  8. Refer to Figure 21. Once the appropriate height is achieved, install the Holding Bocks:
    1. Using the standard screwdriver, loosely secure the screws on both holding blocks.
    2. Use the 5/32 Allen Wrench to loosely secure the Allen screws on both holding blocks.
  9. Before securing the holding blocks in place, make sure the latch is centered in the slot of the cradle as shown in Figure 22.
  10. Check the front latch height before securing the holding blocks:
    1. Return the cradle to the table top.
    2. With the casting in the docked position, make sure the Delrin stopper is flush and the latch is projected 2 mm from the casting.
    3. Once the latch is at the proper height, secure the screws holding the holding blocks.
Topic ID: id_14944793

Finalization

Procedure

  1. Re-assemble the cradle by placing the cradle in its position on the table top.
  2. Connect the table to the scanner.
  3. Move the cradle into the bore of the scanner and then return to its normal position to make sure the cradle is properly placed on the table top.
  4. Perform an emergency cradle release by twisting the handle to release it.
    1. If it does not release, adjust the tension again.
    2. If the cradle release functions properly, proceed to Step 5.
  5. Re-engage the cradle to its functioning position.
