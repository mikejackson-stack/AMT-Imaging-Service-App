LVShim (PM Mode)

About this task

In LVShim PM Mode, the LVShim - Gradshim procedure is performed. The objective is to fine tune the homogeneity of the magnet by using gradients only. The Gradshim process is performed with a sampling diameter of 22 cm DSV and the same bandwidth as Fine Shim, which depends on the quality (good or bad) of the fine tuning. Once the scan passes and all harmonics are within specification, the magnetic field is reanalyzed in Test mode automatically at 45 cm DSV for customer acceptance.

Procedure

  1. Notice
    Normally, you can use the alignment lights to make sure the phantom is aligned properly. If that is not sufficient, perform a localizer scan to verify that the phantom is centered before performing the LVShim procedure.
    Remove all coils from the cradle and phantoms from the bore.
  2. Set up and align the LVShim phantom. Align the phantom so that:

    • The phantom’s seam is oriented perpendicular to the table.

    • The phantom’s z-axis is along the length of the cradle.

    • The phantom is centered left to right with respect to the cradle top.

  3. Landmark on the LVShim phantom crosshairs.
  4. Press the Advance to Scan button.
  5. Perform a phantom centering check scan.
  6. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > LVShim (Pre-Requisite) > Click here to start this tool.

    The LVShim Tool displays.

  7. On the LVShim Tool, select:

    • Gradient Shim shim type

    • Auto Mode radio button

      In Auto mode, the tool automatically:

      • Sets up the protocol and collects image data.

      • Calculates the harmonics and compares it with the specification.

      • Calculates dc offsets for X, Y and Z.

      • Completes multiple iterations (maximum = 5) until harmonics meets the specification.

      • Lists the last iteration reanalyzed at 45 cm DSV in Test Mode (customer acceptance specifications) in the final column.

  8. Click Scan

    After the scan is completed (with the Service Key still inserted), the tool compares all of the harmonics to specifications in the Test Mode.

  9. Check the results:

    • Green cell = Passed specification

    • Red cell = Failed specification

  10. When all iterations are complete and all the harmonics are within specification, click Exit in the LVShim Tool.

EPI White Pixel PM Mode

About this task

The Echo Planar Imaging (EPI) White Pixel tool is used to troubleshoot image artifacts. Run this during the PM, before running SPT (PM Mode). Use the Report Manager to view results.

Procedure

  1. Remove any phantoms from the cradle.
  2. Move the Cradle 320mm from Home Position and Landmark. Then, advance to scan.
  3. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > EPI White Pixel PM Mode > Click here to start this tool.

    The tool runs Body EPI White Pixel PM Mode. If the test stops before the tool completes body modes, view the Error Log to determine the troubleshooting needed.

  4. The EPI PM Mode files generated by this tool can be found in the Report Manager tool. To access:
    1. From the Service Desktop, on the Utilities tab, select Report Manager. Use the password mrgo1.
    2. Look for file type EPT, and locate files with the PM extension. (IBIS looks for PM files to track Planned Maintenance completion.)

SPT PM Mode

About this task

SPT PM Mode is a simplified version of the larger SPT process. SPT PM Mode is a special SPT mode that must be run as a part of the Planned Maintenance procedure. Important: Run SPT PM Mode only after LVShim PM Mode.

Procedure

  1. Notice
    Test functionality and system functionality may be adversely affected if the previous exam is not terminated. Click on End Exam to terminate any previous exam. It is not necessary to click on New Pt because SPT automatically enters the scan protocol when it is started from the MR Tools menu.
    Properly position the head sphere in HNU with positioner.
  2. Landmark on the center line of the HNU, but do not advance to scan.
  3. Run the cradle in so the display reads 1135 mm.
  4. Turn on the alignment light and then position the body loader on the phantom foam support so that the alignment light is properly centered on the loader crosshair. Ensure that the body loader is stable during scanning.
  5. Press Advance to Scan.
  6. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > SPT PM Mode > Click here to start this tool.

    The System Performance Test screen displays. For the SPT PM Mode, all the tests for Body Tx are preselected and cannot be changed.

    As the test runs, the remaining test time displays in the upper right corner of the System Performance Test screen. Test progress and results display in the lower portion of the screen.

  7. Select [Start SPT].
  8. Resolve failures and repeat SPT PM Mode before proceeding to PM Check.

PM Check

About this task

The PM Check tool shows the status of Planned Maintenance, including:

  • Date of last LVShim and SPT PM Mode run on the system

    Note: PM Check will only pass if LVShim passes within 24 hours of a passing SPT PM.

  • When the next Planned Maintenance is due

  • Severe failures left from the last Planned Maintenance (the clinical user will be notified in three weeks of any unresolved failures)

Procedure

  1. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > PM Check > Click here to start this tool.
  2. Click the link: Click here to start this tool.

    The pm show info window displays.

    • All failures must be resolved for PM Assist to be considered complete.

    • If the FE does not resolve Severe issues within 21 days, the system will notify the operator of the problem.

  3. For PM Assist to be successful and complete, make sure all test results pass.

PM Schedules

About this task

The PM Schedules tool allows the FE to select the next PM date. A date must be entered for one of the next two calendar months. (Scheduling the next PM will disable all PM-related pop-ups and attention messages to the customer until that date.)

Procedure

  1. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > PM Schedules > Click here to start this tool.
  2. If PM was never performed on the system:
    1. If PM was not performed on this system, the following message displays in the tool: There is no PM performed on this system at least once. Schedule a date for PM, run SPT & LVS PM tests and hit PM Check link on CSD.
    2. When the PM Schedule screen displays, enter your name or initials, and press Enter.
    3. Enter the date for the next scheduled PM, and press Enter on the PM Schedule screen that displays.
  3. If the system is following a normal PM schedule:
    1. Check the dates the last PM was performed and when the next PM is scheduled on the PM Schedule screen that displays.
    2. Enter the date when the next PM is to be performed, making sure the date is within the specified time limit provided by the tool, and press Enter.

PM History

About this task

The PM History tool displays the Planned Maintenance summary information.

Procedure

  1. On the MR Service Desktop, select the PM tab, and select Pm > PM Assist > PM History > Click here to start this tool.
  2. The PM History screen displays the following information:

    • Current Date

    • Last Performed PM Date

    • Month Next PM Due

    • Customer Scheduled PM Date

    • Field Engineer PM Date

    Note: Customer Scheduled PM Date and Field Engineer PM Date should show the same date. If not, discuss PM scheduling with the customer immediately.
