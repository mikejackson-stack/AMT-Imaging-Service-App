About this task

There are 3 different shimming procedures described in this document. There is also a Test Mode to reanlayze existing magnets.

LVSHIM-Rough (done at new site installations only):

  • The objective is to improve the homogeneity to a point where Grafidy and other calibrations can be performed. Use the three-piece LVShim phantom. The Rough Shim process is performed with the sampling diameter of 45-cm DSV and a higher bandwidth than Fine Shim and Gradient Shim.

  • Rough LVShim is normally needed at new sites that have never been shimmed before. If the site has previously been shimmed with LVShim, skip Rough LVShim and begin with Fine LVShim. For a new magnet installation, the magnet ATR shim currents are used for Rough LVShim.

LVSHIM- Fine

The objective is to further improve and tune the homogeneity as compared to LVSHIM-Rough. Use the three-piece LVShim phantom. The Fine shim process is performed with a sampling diameter of 45-cm DSV and a lower bandwidth than Rough Shim.

LVSHIM- Gradshim

The objective is to perform fine-tuning of the homogeneity of the magnet by using gradients only. The Gradshim process is performed with a sampling diameter of 22-cm DSV and the same bandwidth as Fine Shim depends on the quality (good/bad) of the fine tuning. Once the scan passes and all harmonics are in spec, the magnetic field is reanalyzed in Test mode automatically at 45DSV for customer acceptance.

LVSHIM-Test

The objective is to analyze scans at 45DSV without calculating currents. This mode performs scan and analyzes the scan in Test mode. Once the scan is complete it is analyzed in Test mode at 45DSV.

Note:

LVSHIM-Rough and Fine use the ‘Supercon shim power supply’ to dial correction currents into 18 supercon correction coils.

Note:

However, LVSHIM-Gradshim dials the correction currents into 3 (X/Y/Z) gradient correction coils.

Common to all Shimming Procedures

Procedure

  1. (For For R series magnet all configurations & RD series magnet with software version SV25.3 or earlier:) Set up LVShim procedure.
    1. Remove all coils from the cradle and phantoms from the bore.
    2. Set up and align the LVShim phantom.
  2. (For For RD series magnet with software version SV25.4/29.1 or later：) Set up LVshim procedure.
    1. Set the universal phantom pad in the middle of the table and align the pad’s crosshairs to the closest PA crosshairs using the laser alignment lights.
    2. Put the sphere on the pad with the strap (in the groove) in the orientation shown below, making sure the laser lights are cross-centered on the sphere and phantom pad.
    3. Set up and align the LVShim phantom. Align the phantom so that:
      1. The strap on the phantom is aligned parallel to the table surface.
      2. The phantom is centered left to right with respect to the cradle top.
    4. Landmark on the universal phantom pad crosshairs.
      Note: The landmarking tolerances of the LVShim tool are: I/S: ± 3 mm, A/P: ± 30 mm, R/L: ± 5 mm. Ensure accuracy of the placement for landmarking.
      Note: Due to the tight landmarking tolerance, it is important to align the lasers on the crosshairs of the LVShim phantom.
  3. Press theAdvance to Scan button.
  4. Starting the LVShim Tool
    1. Proprietary mode: Insert the Restricted Service Key in the host USB, if not already inserted.

      1. Click the Service Browser .

      2. Click the Calibration tab and select the Installation and Calibration wizard.

      3. Select the appropriate shim (Gradient Shim, Supercon Shim-Rough, Supercon Shim-Fine) to be performed from the drop-down list. This will launch the LVShim tool.

    2. Non-Proprietary mode: On the Service Desktop, start the Service Browser if not already running. Click the Calibration tab. Select LVShim from the calibration menu and click Click here to start this tool. The LVShim tool will launch.

Rough LVShim and Fine LVShim Procedure

About this task

This procedure is needed for new sites that have never been shimmed.

Note: The LVShim procedure to perform Supercon Shim-Rough and Supercon Shim-Fine are the same.

Procedure

  1. After launching the LVShim tool, select Supercon Shim - Rough.
  2. Manual Mode option is selected automatically.
  3. The LVShim tool scans at different bandwidth and analyzed at 45cm DSV.
    1. The bandwidth for Supercon Shim - Rough is 1000Hz (automatically selected).
    2. The bandwidth for Supercon Shim - Fine is 200Hz
    Note:

    To change bandwidth, go to Expert Mode.

General Rule for New Installs or Upgrades

About this task

Note:

Start with Rough LVShim.

Procedure

  1. After launching the LVShim tool, select the appropriate shim type (Supercon Shim - Rough or Supercon Shim - Fine).
  2. If performing Supercon Shim - Rough for the first time, add original currents from Florence. Click the Init Supercon Currents button. See Figure 6. A new window will be displayed.
  3. Enter the original Florence currents in the Modify Currents column one by one. Press Enteron the keyboard after each entry to move to the next line. After you have modified the entire column, Click the Dial in Currents button.
    Note:

    The current values in the Illustration are only an example.

  4. On the LVShim user interface, click the Scan button. See Figure 8 below.
    Note:

    To abort, click the Abort button and press the Stop Scan button on the control panel.

  5. After the scan is complete, the tool calculates the harmonics and compares it with the specs.

    • Green cell = Passed Spec

    • Red Cell = Failed Spec

  6. The tool calculates the delta currents and the new currents and displays currents in a pop-up window.
    1. In the LVShim user interface, if ALL harmonics data cells are green, decline the new currents by clicking the Cancel button. LVShim calibration is now complete. Click Exit.
    2. In the LVShim user interface, if ANY harmonics data cells are red, accept the new currents by clicking the Dial in Currents button on Dial in Currents window. The new currents will be displayed in a new column in the LVShim user interface as shown in illustration 10 below. Dial in the currents from the new Loaded Current column using Supercon Shim power supply. See Figure 11.

      Repeat steps 4 -6 for Rough or Fine Shim until all harmonics are in spec.

      Note:

      Refer to the Magnet documentation for wait times and procedures to dial in currents in the 18 Supercon Coils.

      Note:

      You may have to go to scan desktop to perform manual prescan to catch center frequency while dialing in the currents.

  7. The delta currents in the LVShim user interface will change to purple color if current is not accepted. There is no newly loaded current column.
  8. Click the Exit button after ALL iterations are complete and ALL the harmonics are in spec. If harmonics are not in specs, Expert mode can be used. Expert Mode can be used to scan with different parameters or reanalyze any image with different parameters.
    Note:

    You must peform the Gradify 3 Eddy Current Calibration before performing the Gradshim LVShim Procedure.

Gradshim LVShim Procedure

About this task

By default, Gradient Shim is performed in Auto Mode, though manual mode is also available.

Auto Mode

About this task

In Auto mode, gradient currents are automatically calculated after you click the Scan button. The gradient currents are automatically calculated to fine tune the homogeneity of the magnet. In this mode, the tool stops after the 'X', 'Y' and 'Z' harmonics are in specs. In test mode the image from the last scan is automatically reanalyzed at 45cm DSV.
Note: For the the software SV25.2 and above System, The value of grad shim X/Y/Z will looks bigger than before because the resolution for Gradshim values changed (shift by 4 bits).

Procedure

  1. After completing the steps defined in Common to all Shimming Procedures select Gradient Shim.
  2. Click Scan. See Figure 14
  3. In Auto mode, the tool does the following:
    1. Sets up the protocol and collects image data
    2. Calculates the harmonics and compares it with the specification
    3. Calculates the delta currents and the new currents based on the harmonics
    4. Completes multiple iterations (maximum = 5) until harmonics meets the specification
    5. Final column will have last iteration reanalyzed at 45DSV in Test mode (customer acceptance specs)

Manual Mode

About this task

Note:

This procedure is not needed in most cases. But in case Auto Shim does not bring harmonic in spec, use Manual Mode.

Procedure

  1. After completing the steps defined in Common to all Shimming Procedures, select Gradient Shim.
  2. Select Manual Mode.
  3. Click theScan button. See Illustration 13 below.
  4. After the scan is complete, the tool calculates all the harmonics, but only X, Y, Z harmonics are compared to spec. For other harmonics and rms/std dev, the spec is NA. See Figure 15

    Green cell = Passed Specification

    Red cell = Failed Specification

  5. The tool calculates the X, Y, Z gradient delta currents (for the gradient bits only) and the new currents based on the harmonics in another window.
    Note:

    The Currents in the illustrations are only examples.

    • In the LVShim user interface if X/Y/Z harmonics data cells are green, decline the new currents by clicking the Cancel button. Ignore cells with spec [NA].

    • In the LVShim user interface, if ANY harmonics data cells are red, accept the new currents by clicking the Dial In Currents button. The new currents will load in a new column in the LVShim user interface as shown in . Repeat steps 3-5.

      Note:

      If after five manual iterations ANY of the cell(s) are still red, click More Actions menu and select Expert Mode. See the LVShim Troubleshooting manual for more information.

  6. Note:

    General Information: For more information on the Cal file name, Center Frequency information, Coil Set used for scanning, click the Scan column you need more information. Then click More Info option in the More Actions menu. See Figure 18.

    Click Exit in the LVShim window when all the iterations are complete and all the harmonics are in specification.

Finalization

Procedure

  1. Remove any phantoms and/or tools used.
  2. Do a head or body test scan before turning over the unit to the customer.
