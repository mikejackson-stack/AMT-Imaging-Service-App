Software options glossary

A list of terms commonly associated with installing software options.

AIR Recon DL
A Deep Learning-based reconstruction technique that reduces noise and ringing (truncation artifacts), which can be used to reduce scan time and improve image quality.
Bloodsupp
Blood suppression.
Cine
Images usually of moving anatomy scanned and arranged for playback rapidly in movie format.
ConnectPro (HIS/RIS)
Provides DICOM modality work list connectivity to hospital or radiology information system.
DISCO
A 3D single-slab application involving a pseudo-random interleaved undersampling technique.
DL MoCo
Uses AIR Recon DL to improve the image quality and diagnostic confidence of Time Course MoCo.
DW EPI
Diffusion Weighted Echo Planar Imaging.
Fast cine
Fast gated multi-phase images of the heart that show the heart as it contracts and expands during cardiac cycle in a movie format.
Flex
Enables a water-fat separation technique that can be used in place of conventional fat saturation to produce water-only images.
iDRIVE Pro
Interactive imaging uses a fast GRE pulse sequence and a new user interface to acquire continuous 2D images at a high frame rate and provide on-image navigation. Not available on systems with a single i860 AP.
IVI
Interactive Vascular Imaging.
MAGiC
MAGnetic resonance image Compilation (MAGiC) generates multiple image contrasts from a single acquisition scan. Enables post-acquisition image contrast adjustment. Allows for the generation of parametric maps for further analysis of MRI acquisition data.
MERGE
Uses a larger receive bandwidth that reduces chemical and susceptibility artifacts and improves image quality.
MoCo
Motion Compensation is used with cardiac time course scans to correct for misalignment caused by respiratory and residual cardiac motion.
MS/MA
Multi-Slice/Multi-Angle Oblique.
Multi-Nuclear Spectroscopy
Provides access to additional spectroscopy pulse sequence database (PSD) that may be used in proton mode.
Probe2000 Upgrade
Multi voxel proton spectroscopy (PROBE-SI).
Sgdperf
Scalable gradient driver (SGD) enhancements, which increase slew rates and duty cycles for higher resolution thin slice imaging.
SmartPrep
Automated triggering for contrast-enhanced MR angiography (MRA).
SmartPrep2000
Provides SmartPrep automated table motion.
Sonic DL™ Cine
Uses a Deep Learning-based reconstruction to significantly accelerate Cardiac Cine imaging.
SPECIAL
Spectral/Spatial Fat Suppression. Chemical saturation using an inversion pulse (180° pulse). This key will always suppress just fat and cannot be changed to suppress water.
Spectroscopy/PROBE
Single voxel proton spectroscopy with PROBE-S and PROBE-P.
SSFSE
Single Shot Fast Spin Echo.
SWAN
Reduces geometric distortion and the high bandwidth helps to avoid chemical shift artifacts.
Tagging
The placement of "tags" in an MR image is used to assess myocardial wall functions visually.
