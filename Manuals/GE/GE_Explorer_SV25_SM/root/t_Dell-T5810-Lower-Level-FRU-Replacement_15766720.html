Required conditions
Access to both the front and rear of the operator console is required. Move the console away from walls and remove obstacles in the room.
No support for unbuffered memory.
DANGER
Electrocution hazard
Hazardous voltage is present when the Global Operation Console (GOC) is energized.
Before beginning any work, perform LOTO. See Lockout / Tagout for GOC .
Notice
Potential component damage
The cooling fan is off only when the workstation is off or the power cable is disconnected. The cooling fan is always on when the workstation is on or in Standby mode.
Disconnect the power cord from the power source before opening the workstation.
Notice
Potential component damage
Electrostatic discharge (ESD) can cause permanent damage to electronic components.
Observe the following ESD precautions:
  • Work on a static-free mat.
  • Wear a static strap to make sure that any accumulated electrostatic charge is discharged from your body to the ground.
  • Create a common ground for the equipment being worked on by connecting the static-free mat, static strap, and peripheral units to that piece of equipment.
Notice
Potential Component Damage
For further information on ESD protection, see the MR Service Safety Manual (5452735).

About this task

This procedure describes the steps to replace the following lower-level FRUs (LLFRUs) in the Dell T5810 host PC:
  • DVD drive
  • Solid State Drive (SSD)
  • CMOS battery
Topic ID: id_sw2_n4l_yfb

Preparing the workstation

Procedure

  1. (For SSD Replacement) Ask the customer to archive all images to an external storage device (PACS, DVDs, and so on).
  2. Do a SaveInfo.
  3. Close any PC applications and power down the GOC .

    The GOC supports an optional UPS. Confirm your site’s configuration.

  4. Perform LOTO for the GOC/Operator Workspace. See Lockout / Tagout for GOC. For added protection, disconnect the twist-n-lock main power cable from the rear of the console.
  5. Remove the host PC from the GOC. See Dell T5810 Computer Replacement.
  6. Lift up the cover release latch and lift the cover upward to a 45-degree angle, and remove it from the host PC.

Replacing LLFRUs in Dell T5810 host PC

Topic ID: d226e301

Replacing DVD drive

Procedure

  1. To prevent damage, do not remove the new DVD drive from its antistatic packaging until you are ready to install it.
  2. Disconnect the data and power cables from the DVD drive.
  3. Disconnect the cable from PCI AA and unthread the cables from the latches.
  4. Press on the clasp to release the latch holding the cables on the side of the cage.
  5. Lift the release latch on top of the cage, and slide the cage out from the compartment.
  6. Remove the four screws that secure the DVD drive to the cage.
  7. Remove the DVD drive from the cage.
  8. Install the new DVD drive in reverse sequence, and connect the power and data cables.
    Note: When restoring the DVD Drive cage, lift the release latch and slide the pins on the both side of cage along the slot till they reach to the end. Then, close the release latch.
  9. Continue to Reinstalling host computer in GOC below.
Topic ID: d226e392

Replacing SSD

About this task

The Dell T5810 has two SSDs, and they have the same replacement procedure.

Procedure

  1. Disconnect the power supply and data cables from the SSD.
  2. Press in gently on both sides of the bracket and slide the SSD carrier out of the slot.
  3. Remove the bracket from the SSD carrier.
  4. Press on the two tabs on one side of the SSD carrier to separate the pins from the SSD and remove the SSD from the carrier.
    Note: You can twist the carrier to separate the pins more easily.
    Even though the pin is long and the tab is hard, it is possible to detach the pin from the SSD. The illustration below shows how to remove the pin.
  5. Install the new SSD in reverse sequence.
    There are no jumpers required to configure the disk drives on the Dell T5810. Connect the power cables to the SATA connectors labeled on the board as HDD1 and HDD0.
    1HDD1 - DATASSDImage data
    2HDD0 - Boot DriveSSDApplication software
  6. Do a disk wipe on all applicable hard drives in the old PC. See the latest revision of the Disk Management Tool Service Manual , PN 5500610-1EN available from the online documentation library.
  7. Continue to Reinstalling host computer in GOC below.
Topic ID: d226e496

Replacing CMOS battery

Procedure

  1. Lay the workstation on its side with the system board facing up.
  2. Remove the bracket that holds the DVD Drive (refer to Replacing DVD drive),
  3. Push the tab and lift the long black cover.
  4. Find the CMOS battery on the Dell computer system board.
  5. Move the latch away from the battery to remove the battery from the socket.
    If necessary, you can use a small screwdriver to remove the battery.
  6. Let the computer sit for a minimum of 3 minutes to let the CMOS memory clear.
  7. Install the new battery, and push the battery down until the release latch moves back into place and secures it. The battery’s positive (+) side should point up.
  8. Continue to Reinstalling host computer in GOC below.
Topic ID: id_xld_p4l_yfb

Reinstalling host computer in GOC

Procedure

  1. Recover the left side cover of the host computer.
  2. Reinstall host computer to the GOC in reverse order of removal.
  3. Recover the GOC left side cover.
  4. Confirm that all cable connections to the GOC and host PC are tight.
  5. Get a GE Equipment Maintenance sticker, and write today’s date on the sticker. Put the sticker on the GOC where it is easily seen.
Topic ID: id_d3y_p4l_yfb

Finalization

Prerequisites

FRU Item Replaced Actions to be performed
DVD driveReboot and confirm that the DVD drive can read and write images.
Hard driveReload the software.
CMOS battery
  • Update the customized BIOS settings.
  • Shut down the PC and turn off the power.
  • Re-apply the power and restart the PC.
  • Make sure the date/time is correct (CMOS battery properly keeps date/time).

Procedure

  1. Remove LOTO on the GOC to return power. If needed, reconnect the twist-n-lock main power cable to the rear of the console. See Lockout / Tagout for GOC.
  2. Push the power button on the front of the host PC within the GOC .
  3. Note: If you replaced the battery, you need to go to the BIOS settings before the host PC starts. To get into the BIOS menu, you need to push F2 as soon as the Dell circle shows. The Dell circle only shows for 5 seconds.
    (For CMOS battery replacement) Push F2 when you see the Dell circle on the screen. Do the following steps:
    1. If you see a message that indicates the time-of-day is not set, press F2 to continue.
    2. Select Set Time and Date and enter the correct time. Use the Tab key to move the cursor and use the left and right arrow keys to change values.
      After you set the time and date, the BIOS settings will open.
    3. Restore the customized BIOS settings. Change only the values shown in the table below:
      Table 1. Customized BIOS settings
      Section Sub-Section Setting
      GeneralGeneral Boot Sequence Diskette Drive - disabledDiskette Drive - disabled
      USB Storage Device - disabled
      Boot Order: ODD, SSD, SSD
      System ConfigurationSATA OperationAHCI enabled
      Memory Map IOMemory Map - enabled
      PerformanceIntel SpeedStepEnable Intel SpeedStep - disabled
      c-StatesC states - disabled
      Dell Reliable Memory TechnologyEnable Dell RMT - disabled
      Virtualization SupportVirtualizationEnable Intel Virtualization - disabled
      VT for Direct IOEnable VT for direct IO - disabled
    4. Click Apply to save changes, and then press Exit.
      The system reboots. BIOS configuration is complete.
  4. Note: Make sure the host PC front panel power LED is illuminated as a steady blue signal.
    (For SSD Replacement) Load software and applications onto the operating system.

    See Loading Host System Software.

    Note: Load From Cold (LFC) must be performed to properly transfer customer options.
  5. Run a goodbye scan.
  6. Make sure all customer functions are operational (auto voice, filming, network, archive).
  7. Host PC or hard disk replacement will change the service license ID. Open a support central case from http://supportcentral.ge.com/@ssakey to update the 16-digit code, and then log into SSA website and use Renew Softkey to re-generate the soft license if applicable.
