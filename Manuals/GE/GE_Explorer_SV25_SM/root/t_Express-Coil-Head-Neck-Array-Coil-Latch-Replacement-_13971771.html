About this task

Follow this process to replace the Latch assembly.

Topic ID: id_SL2987474-1098079

Anterior Latch replacement

Procedure

  1. Take the HNU Anterior Assembly.
  2. Detach existing Latch Clip assy (2Nos) # 2422855.
  3. Take new Latch Clip assy (2Nos) # 2422855.
  4. Attach the new Latch Clip assy (2Nos) # 2422855.
  5. HNU Anterior Assembly # 5344765 with replaced new latch assembly is ready for use.
Topic ID: id_SL2987485-1098079

Posterior Latch replacement

Procedure

  1. Take the HNU posterior Assembly # 5344780.
  2. Remove HNU Posterior Bottom # 5334673 by removing M5 Screws (12 Nos) and M4 Screws (4Nos) using screwdriver.
  3. Remove HNU Posterior Bottom # 5334673 by removing M5 Screws (12 Nos) and M4 Screws (4Nos) using screwdriver.
  4. Remove the existing Latch assembly # 2422854 (2Nos) by removing M4 Brass screws (4Nos) using screwdriver.
  5. Take new Latch Clip assembly (2Nos) # 2422854 and M4 Brass screws (4Nos) from the FRU Kit.
  6. Attach the new Latch assembly # 2422854 (2Nos) by fixing Tightly the M4 Brass screws (4Nos) using screwdriver.
  7. Attach HNU Posterior Bottom # 5334673 by Tightly fixing M5 Screws (12 Nos) and M4 Screws (4Nos) using screw driver.
  8. HNU Posterior Assembly # 5344780 with replaced new latch assembly is ready for use.
Topic ID: id_14954107

Finalization

Finalization

Ensure that the anterior and posterior sections of the coil Latch smoothly, firmly latched and are functioning properly.
