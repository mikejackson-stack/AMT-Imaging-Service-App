Viewing Results - Report Manager Tool

About this task

After SPT has finished the analysis, the data files can be viewed using the Report Manager Tool. The specification files can also be viewed to compare the results against the specifications.

Procedure

  1. To view SPT results, follow the steps in the illustration below to open the Report Manager.
  2. When prompted for a password, enter the same password used for the Service Methods CD-ROM. Press Enter.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    The File Open screen will display available reports.

  3. To view an SPT report, first make sure the File Type is SPT. (If it is not, click the button following “File Type” and select SPT from the list.)
  4. Select the report you’d like to view, then click OK.

    Test results will appear in the Report Manager window. Use the Previous and Next buttons to view individual pages of the report.

  5. To print a report, select File, then Print from the Report Manager menu.
  6. To view another report, select File, then Open. Select the report from the list, then click OK.
    Note:

    For additional information on Report Manager, select Software Utilities from the Service Methods CD-ROM, then Report Manager Tool.

Viewing the Specification Files

About this task

The specification files can be viewed using the more command, or the xedit editor. For definitions of each specification file, go to SPT Specification File Definition. For TwinSpeed, refer to the file with a GradMode extension, hence as cal.spt.WHOLE and cal.spt.ZOOM, rather than the original file cal.spt.

Procedure

  1. Note:

    The specification file contents change based on whether the user selected the old or new head coil at the start of SPT. The file names do not change. Use any one of the three methods below to view the file contents

    More Method
    1. On the Service Desktop, click on C Shell.
    2. View the specification files. Type: cd /usr/g/service/cclass/spt and press Enter.
    3. To view the specification file of interest, type more filename. Press Enter. Use the filenames from Table 2
  2. xedit Method
    1. On the Service Desktop, click on C Shell. Type: cd /usr/g/service/cclass/spt and press Enter.
    2. Type xedit and press Enter. A xedit window will appear on the desktop.
    3. Select Open from the File pull-down menu. Select the specification file of interest from the browser list, and click on Accept. Refer to the file list from Table 2.
    4. To exit xedit, select File, then Exit.
  3. Both Methods

    Compare the results from the Signa Report Manager tool with the values in the correct specification files to determine the parameter that is out of specification.

    Note:

    The limits shown for Specification Files in this System Performance Test Procedure are for illustration purposes only. Actual specifications are contained within the files on the system.

  4. Viewing Phantom Position Check Results

    After finishing the phantom position check, a result file will be created. It will contain the measured results of phantom offset, shape offset and phantom size. The latest head mode and body result files will be saved under /usr/g/service/cclass/spt as SPT_pos.result.head and SPT_pos.result.body, respectively. The formats of two files are the same. Line four, five and six in those files are the detailed results from the phantom position check.

    Here is an example of the result file for body phantom position check (SPT_pos.result.body):


                      #Axial,xcent_offset,ycent_offset,xsize,ysize (mm)= 0 11 264 253
    #Sagittal,ycent_offset,zcent_offset,ysize,zsize (mm)= 11 0 252 257
    #Coronal,xcent_offset,zcent_offset,xsize,zsize (mm)= 2 2 263 253
    #X offset= L 1 mm; Y offset= A 11 mm, Z offset= S 1 mm
    #X size=259 mm; Y size=253 mm, Z size=260 mm
    #Shape offset Axial p=4 %; Sagittal p=2 %, Coronal p=4 %

                    

    For the example shown above, in line four, it shows that the final phantom offset is 1mm on L (left) direction along X-axis, 11mm on A (anterior) direction along Y-axis, and 1mm on S (superior) direction along Z-axis. In line five, it shows that the phantom size is 259mm, 253mm, 260mm along X-axis, Y-axis, and Z-axis, respectively. In line six, it shows that the shape offset will be 4%, 2% and 4% for Axial, Saggital, and Coronal images, respectively.

    In addition, SPT saves phantom poisiton check images in Joint Photographic Experts Group (JPEG) format as /usr/g/service/cclass/spt as autoshim_head.jpg and autoshim_body.jpg for head phantom check and body phantom check, respectively.

    The specs for the phantom position checks are:

    • Phantom Offset: Less than15mm along Z direction.

    • Phantom Size:For head TLT phantom, the acceptable head phantom size range is 136mm to 204 mm.

    • For body TLT phantom, the acceptable body phantom size range is 216mm to 324 mm.

    • Shape Offset: Less than 15%.
