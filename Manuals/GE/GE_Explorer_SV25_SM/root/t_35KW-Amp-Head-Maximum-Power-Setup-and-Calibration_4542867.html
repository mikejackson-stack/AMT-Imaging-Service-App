Disabling T/R Drive Error Condition (Production Systems Using TR in Driver Module)

Procedure

  1. Verify that the system is idle and all coils have been removed from magnet bore.
  2. Remove the front cover of the EXCITE Systems Cabinet.
  3. On the front of the Driver Module, disable T/R error reporting by setting the TR switch to the DIS (disable faults) position.
    Note:

    HV, DD and MC should remain set to Enable.

Topic ID: id_SL4543156-113747

Head: Maximum Power Calibratioin

Procedure

  1. Insert the 5000W element into the Forward Sensor Port (Blue- 4300A374-6). Make sure the arrow on the element points in the direction of the arrow (from Input to Output) on the sensor. Lock element in place using the locking tab on the sensor.
  2. Insert the 50KW element into the Reflected Sensor Port (Blue- 4300A374-3). Make sure the arrow on the element points in the opposite direction of the arrow (from Input to Output) on the sensor. Lock element in place using the locking tab on the sensor. (Figure 2). The reflected port is not used during this procedure. Placing the 50kW element into the reflected port is just a safety measure.
Topic ID: id_SL4543159-113747

Wattmeter and Dummy Load Setup

Procedure

  1. Verify that the scanner is in “idle”, turn off RF Enable at the exciter (FP-I/O board) or disconnect J14 (RF Drive input) from the back of the RF amplifier.
  2. Disconnect the head cable J3 “Head Output” from the back of the RF amplifier.
  3. To protect the body hybrid and amplifier section, disconnect the body cable J4 “Body Output” from the back of the RF amplifier as well.
  4. Connect the input of the coupler to J3 of the RF amplifier. (Note: Some new RF kits may require using the HN to 7/16 adapter included in the kit.)
  5. Connect the RF coupler output to the dummy load.
  6. Connect one end of the wattmeter cable to the wattmeter sensor output. (RS232 is unused). Connect the other end to the coupler.
  7. Make sure to plug in the fan for the dummy load. AT NO TIME should you use this dummy load without its fan running.
  8. Notice
    DO NOT APPLY RF POWER TO THE DUMMY LOAD WITHOUT ITS FAN IN OPERATION. DOING SO WILL RESULT IN CATASTROPHIC DAMAGE TO THE DUMMY LOAD.
    Reconnect J14 on the back of the amplifier or switch RF Enable to ON.

Topic ID: id_SL4543171-113747

Setting Up Wattmeter to Measure Forward Head Maximum Power

Procedure

  1. Press the ON button on the wattmeter. (If coupler and sensor are not correctly attached to the amplifier you will get a “No Sensor” indication)
  2. Select the arrow button under Scale.
  3. Type 5000 to set the range.
  4. Select the Enter button.
  5. Check the setting, by selecting the arrow button under Scale again.
  6. Press Enter to exit this mode.
  7. Select the arrow button under Fwd Units; make sure the scale reads “W” (or “kW “on some wattmeters). If the scale reads dBm, select the arrow button under Fwd Units again, to toggle the scale to read “W” (Watts) or kW (kiloWatts) on the TOP (Forward Power scale). Ignore the BOTTOM (Reflected Power scale) value. It is not used during maximum power calibration.
  8. Select the Shift button.
  9. Select the arrow button under Setup.
  10. Verify that it reads “43”. If not, type the number “43” followed by the Enter button.
    Note:

    This action displays the sensor type configured in the wattmeter. This procedure uses Sensor Type 43, which is optimized for peak power measurement.

  11. Select Enter button.
  12. Select the arrow button under Type, and change the unit of measurement to Peak.
  13. Some kits require an offset to ensure accurate measurement. Locate the Element Offset Factors card in the kit and view the offset for 3T Head Output.
  14. If an offset exists, press the Offset button on the wattmeter. Enter the value from the offset card and press Enter.
  15. The meter is now configured to read RF Peak Power, in Watts, for the head maximum output calibration.

  7. Go to the amplifier and remove the keypad cover, located on the front of the amplifier near the display.
Topic ID: id_SL4543207-113747

Adjusting the RF Amplifier Output Power (Head)

Procedure

  1. This section adjusts the Solid State Amplifier gain of the solid state pre-amplifier (VVA Setup) and if necessary, also adjusts the attenuation of the IPA stage, (ATTN Setup). The gain (VVA- Variable Voltage Adjustment) of the solid state amplifier is set up first, maximizing its output. The attenuation of the IPA stage can also be adjusted to fine tune the final value to as close as possible to 4000 Watts, (4000-4100 Watts) .VVA Setup and ATTN Setup interact with each other, and you may find yourself going back and forth between these adjustments until the amplifier is properly calibrated.
  2. Select Manual Prescan.
  3. Select Scan TR.
  4. Set Transmit Gain to 180. Make sure everything is functioning normally and you are getting a reading on the wattmeter. Allow scanner to pulse at TG 180 for 6 minutes. This is due to the drop in gain that occurs over the 6 minute period.
  5. Slowly increase TG to 200. (If the amplifier trips, set the TG at its highest setting). Resume the procedure at VVA SETUP (Solid State Amplifier Gain Adjust).
Topic ID: id_SL219772-113747

VVA SETUP (Solid State Amplifier Gain Adjust)

Procedure

  1. Notice
    Press only the buttons required by this procedure. Avoid pressing the Mode button, as it controls the output drive of the solid state amplifier, switching from body to head mode of operation. For information on the keypad, see Keyboard Operation / Description of IPA and PA Stages.
    While the system is pulsing RF, press the Menu button on the keypad located inside the RF amplifier, until the LCD display on the front of the amplifier reads as follows:

    > ATTN SETUP

    VVA SETUP

  2. Press Down Arrow to select VVA SETUP

    ATTN SETUP

    >VVA SETUP

  3. Press Enter.
  4. Continue to press Enter button until you have selected the desired step size. For smaller and finer calibration use smaller incremental step sizes such as 1 or 10. (Step size values can be set to 1, 10, 20, 30, 40, 50, 60, 70, 80, 90, or 100).
  5. After the Step Size is selected, press the down or up arrow to actually adjust the gain:

    VVA Step: 10

    >VVA: 3368 (this value will change by 10 counts)

  6. Using the down/up arrows, resume the adjustment of the gain until you have achieved 4000 Watts (approx. 4000-4100 Watts) on the meter.
  7. If you can achieve 4000 Watts on the meter display, press the Menu button until you reset the keypad to read Forward and Reflected Power.
    Note:

    If you are still not able to achieve the proper maximum Wattage setting, you may need to adjust the IPA stage Attenuation, see Adjusting ATTN SETUP (PA Attenuation).

  8. Proceed to Saving New Calibration Settings Saving New Calibration Settings.
Topic ID: id_SL219797-113747

Adjusting ATTN SETUP (PA Attenuation)

Procedure

  1. This section only needs to be performed if you cannot achieve 4000 Watts (approx. 4000-4100 Watts) with VVA SETUP. (Note: At this time the RF amplifier is still pulsing at TG of 200.)
  2. Press the Menu button until the LCD display on the front of the amplifier reads the following:

    >ATTN SETUP

    VVA SETUP

  3. Select Enter.

    > ATTN: 13 (This value will change when the down/up arrows are pressed.)

  4. Press the down or up arrow while watching the wattmeter to adjust the attenuation of the RF amplifier PA stage. Slowly attenuate the RF power to as close to 4000 Watts as you can. If you cannot achieve 4000 Watts, adjust the attenuation to a value that is below 4000 Watts.
  5. Press the Menu button to exit.
  6. Press the Menu button until the amp displays Forward and Reflected power readings.
  7. If you did not achieve 4000 Watts, proceed to VVA SETUP (Solid State Amplifier Gain Adjust). If you achieved 4000 Watts (approx. 4000-4100 Watts) proceed to Saving New Calibration Settings.
Topic ID: id_SL219775-113747

Saving New Calibration Settings

Procedure

  1. Note:

    The RF amplifier should still be producing RF at a TG of 200.

    As a quick check, look at the LCD display on the front of the amplifier. It should be reading 4000 + or - approximately 600 Watts. This will vary site to site and can be used as a confidence indicator as to your actual setting. The LCD display should not be relied on as an accurate measurement device.
  2. Stop Manual Prescan.
  3. Press the Menu button multiple times until the original screen on the amp LCD reappears.
  4. Press the Off button. This will STORE the value in NVRAM. Wait 30 seconds and press the “Operate” (or Standby) button. Wait another 30 seconds for the amplifier to react to the new settings.
  5. After the RF output is calibrated to specification, reduce the TG to zero. If the amplifier is set up correctly, the RF amplifier display and wattmeter should be very close to the same value.
  6. Test the new maximum power value by restarting Manual Prescan.
  7. Select Scan TR.
  8. Slowly increase the TG to 200. The system should not trip.
  9. Take a final look at the wattmeter display; making sure the desired value is displayed.
  10. Reduce TG to zero.
  11. Stop Manual Prescan.
  12. Continue with Finalization.
Topic ID: id_14933014

Finalization

Procedure

  1. Warning
    ELECTRICAL/RF BURN HAZARD
    RF BURNS AS A RESULT OF DISCONNECTING HELIAX CABLES WHILE THE SYSTEM IS SCANNING
    PREVENT POSSIBLE RF BURNS WHEN DISCONNECTING HELIAX CABLES FROM J3 OR J4 ON THE RF AMP BY VERIFYING THAT THE SYSTEM IS NOT MANUALLY PRESCANNING OR SCANNING. VERIFY THAT THE SCAN DESKTOP ICON DISPLAYS THE “IDLE” MESSAGE AND THE RF ENABLE SWITCH IS IN THE "OFF" POSITION
    Notice
    Possible equipment damage: Do not turn connect/disconnect wattmeter sensor while meter is ON. Always turn meter OFF prior to plugging/unplugging sensor.
    Verify that the scanner is in “idle.” Turn off RF Enable and disconnect J14 from the back of the RF amplifier.
  2. Before proceeding, perform a Reset TPS. This is to ensure that the RF amplifier is in a known state to the system.
  3. Perform Universal Power Monitor - Head Setup and Calibration) to verify that the UPM is properly calibrated and functioning properly.
  4. Disconnect the RF watt sensor from the J3 head output connection.
  5. Connect the original head output cable to RF amplifier J3 and the body output cable to RF amplifier J4.
