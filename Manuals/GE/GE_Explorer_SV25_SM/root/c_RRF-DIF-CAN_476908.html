RRF-DIF CAN

Diagnostic Link

Diagnostics >> RRF Chassis >> RF-DIF CAN Functional Diag

Purpose

The purpose of this diagnostic is to display the state of the RF-DIF Board, and communications between the IRF, IRF I/O, and RF-DIF board.

Components Tested

Table 1. Measurements Supplied by Diagnostics
Component: State Measured:
RF Enable SwitchState of the RF Enable Switch on the FPIO Board
20 MHz ClockState of the 20MHz clock on the RRF-DIF
Rx Signal DetectHigh Speed Chipset Comm Status
Tx Ready for DataHigh Speed Chipset Comm Status
Link ReadyHigh Speed Chipset Comm Status

Components Tested:

  • APS

  • IRF

  • RRF-DIF

Requirements

Block Diagram

None

Test Sequence

  1. Select one of the following options.

    • IO Status

    • Reset RRF

    • Volt/Temp Query

  2. Select appropriate board.

    • Master RF-DIF

    • Slave RF-DIF

  3. Enter Test Duration in seconds.

  4. Click Run.

Expected Results

If measurements do not appear normal (blue print), then first check the Gigalink connections between the IRF I/O Board and the RRF-DIF board. Also, check the seating of the RRF-DIF board in the RRF Chassis.

If the Diagnostic reports that the CAN node is in an invalid state, then check the CAN connections to the RRF-DIF board. Also verify that the RRF-DIF CAN boards are not emulated out. Finally perform a TPS Reset to return the CAN node to a known good state.
