About this task

This document covers System Cabinet PDU Main Breaker - Lockout and System Cabinet PDU - Restoring Power. Prior to performing work on the System Cabinet electronics (except PDU) and electronics in Magnet Room, the steps in this Lock Out Tag Out Procedure must be performed by a LOTO Authorized GE Field Engineer. Completing all steps in this procedure will ensure a safe environment when working on these parts.

Power Down the computer subsystems

Procedure

  1. From Common Service Desktop, click 'Utility / VRE / Power Control' and select [POWER OFF VRE] to turn off the VRE.
  2. To shut down the system, click the arrow on the Tools High Level Access tab, select System Shutdown, and then click [Yes] to confirm the shut down.
  3. Confirm that the system is shut down.
Topic ID: id_SL28617-1083182

System Cabinet PDU Main Breaker - Lockout

Procedure

  1. At the front panel of the PDU, press the Power Off button.
  2. Rotate the larger main breaker labeled INPUT counter-clockwise to the green, OFF (O) position.
  3. Lock Out Tag Out the PDU “INPUT” circuit breaker.
    1. Press on the left-pointing arrow on the end of the handle to expose the location where the lock and tag can be placed.
    2. Lock and tag out the PDU “INPUT” circuit breaker.
Topic ID: id_SL28620-1083182

System Cabinet PDU - Restoring Power

Procedure

  1. Alert necessary personnel that power is being re-applied.
  2. Remove the Lock and the Tag from the PDU “INPUT” circuit breaker.
  3. Rotate the larger main breaker labeled INPUT clockwise to the Red, 1 ONposition.
  4. Press the EMO RESET switch.
  5. Boot Signa and log into scanning level.
Topic ID: id_14976642

Finalization

Procedure

  1. Insure all subsystems have powered up successfully
  2. Do a test phantom scan to insure proper scanning
