Non-Magnetic Tools

There are 2 versions of Non-Magnetic tools:

  • Signa 1.5T Non-Magnetic Tool Kit Part Number 2385097

  • MR Titanium Non-Magnetic Tool Kit, Part Number 5112581

Signa 1.5T Non-Magnetic Tool Kit Part Number 2385097

Notice
Some of these tools have minor magnetic properties, and should not be used on magnets that are stronger than 1.5T.
