Host-ICN Ethernet Path Diagnostic

Topic ID: id_SL4182722-618622

Diagnostic Link

Topic ID: id_SL4182724-618622

Purpose

The purpose of this diagnostic is to verify network connectivity between the host and an ICN.

This diagnostic helps identify network failure points between a host and ICN by sending an ICMP (ping) packet from the host to the ICN. The ICN is expected to acknowledge the packet by responding back to the host.

Topic ID: id_SL4182725-618622

Components Tested

  • Host to VRE switch Ethernet cable

  • VRE switch to ICN Ethernet cable

  • VRE switch

Topic ID: id_SL4182729-618622

Requirements

All Ethernet cables must be connected from the host to the VRE Ethernet switch.

All Ethernet cables must be connected from the ICN to the VRE Ethernet switch.

ICN must be turned on.

Topic ID: id_SL4182730-618622

Block Diagram

Topic ID: id_SL4182732-618622

Test Sequence

  1. Verify that all Ethernet cables are connected.

  2. Execute the diagnostic.

  3. Verify that each ICN tested passes the diagnostic.

Topic ID: id_SL4182736-618622

Expected Results

Fault Problem Description GE Field Action
PASSEDThe ICN has passed the diagnosticNo action required.
FAILEDThe ICN has failed the diagnostic

  1. Re-seat the Ethernet cables.

  2. Use a different Ethernet switch ports.

  3. Replace the cables from the host to Ethernet switch.

  4. Replace the cables from the ICN to Ethernet switch.
