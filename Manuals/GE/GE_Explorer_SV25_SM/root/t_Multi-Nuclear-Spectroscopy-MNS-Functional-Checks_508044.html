About this task

The tests in this section are used to verify the operation of the Multi Nuclear Spectroscopy (MNS) subsystem. All the tests utilize a TR module and Quality Assurance (QA) probe for the nucleus under test (e.g. 13C or 31P). The tests are run in the same manner regardless of field strength or nucleus, therefore this single set of instructions will cover both 13C and 31P nuclei on 1.5T and 3.0T systems.

Hardware Setup

Procedure

  1. Install the TR module onto the top of the LPCA cover
  2. Connect the transmit (thick) and receive (thin) cables to the connectors on the LPCA cover.
  3. Place the Grafidy base plate on the patient bed near the top of the bed.
  4. Place the QA probe in the center hole of the Grafidy plate and lock into place. See Figure 2.
  5. Connect the QA probe cable to the quick disconnect module.
  6. Connect the QD module to the TR module.
  7. Landmark on the center of the QA probe and advance to scan.

Scanner Setup

Procedure

  1. Start a New Exam, click New Patient.
  2. Enter geserviceEnter for Patient ID.
  3. Enter MNS SetupEnter for Patient Name.
  4. Enter 111Enter for Patient Weight.
  5. From the Service->Other protocols choose MNS Setup.
  6. Select the Func Test, series 1, for the nucleus under test and click Accept.
  7. Landmark on the center of the QA probe, if not already completed during Hardware Setup.
  8. Click Save Series.
  9. Right-click on Research Options and select Display CVs.
  10. Set the following CVs :

    • flip_rf1 = 10, press Enter.

    • pw_rf1 = 40, press Enter. See example screen, Figure 3.

    • xmtaddSCAN = 200, press Enter.

    • Click Accept.

  11. Right-click on Research Options and select Download
  12. Click Spectro Prescan.
  13. Slide R1 and R2 to the maximum positions.
  14. Set TG (Transmit Gain) to 0 (zero).
  15. Set the top display mode to Magnitude.
  16. Click Start. After a few seconds you should see a peak in the top display and a free induction decay (FID) in the bottom display as shown in Figure 4.
    Note:

    Illustrations are for a 3.0T system. Intensities will be about 2 times lower at 1.5T.

  17. Adjust the center frequency to center the peak in the Magnitude window, using Delta Frequency DX . After each adjustment click Apply.
  18. Record the Magnitude peak height. The peak height at TG = 0 should exceed the minimum acceptable value in Table 4.
  19. Use Zoom Mode functions to measure. See Figure 5.

Signal-to-Noise Test

Procedure

  1. Hardware Setup
    1. Install the TR module onto the top of the LPCA cover
    2. Connect the transmit (thick) and receive (thin) cables to the connectors on the LPCA cover.
    3. Place the Grafidy base plate on the patient bed near the top of the bed.
    4. Place the QA probe in the center hole of the Grafidy plate and lock into place.
    5. Connect the QA probe cable to the quick disconnect module.
    6. Connect the QD module to the TR module.
    7. Landmark on the center of the QA probe and advance to scan.
  2. Scanner Setup
    1. Start a new exam.
    2. Enter geserviceEnter for Patient ID.
    3. Enter MNS SetupEnter for Patient Name.
    4. Enter 111Enter for Patient Weight.
    5. From the Service->Other protocols choose MNS Setup.
    6. Select the SNR Test series for the nucleus under test and click Accept.
    7. Landmark on the center of the QA probe, if not already completed during Hardware Setup.
    8. Click Save Series.
    9. Right-click on Research Options and select Display CVs.
    10. Set the following CVs:

      1. flip_rf1 = 10, press Enter

      2. pw_rf1 = 40, press Enter

      3. xmtaddSCAN = 200, press Enter

    11. Click Accept.
    12. Right-click on Research Options and select Download.
    13. Click Spectro Prescan.
    14. Slide R1 and R1 to the maximum position.
    15. Set TG(Transmit Gain) to 0 (zero).
    16. Set the top display mode to Magnitude.
    17. Click Start. After a few seconds you should see a peak in the top display and a free induction decay (FID) in the bottom display.
    18. Adjust the center frequency to center the peak in the Magnitude window.
    19. Change the display mode in the top window to Pure Absorp. The shape of the peak will change with some of the signal dipping below zero. The distortion will vary depending on QA coil and scanner.
    20. Use the Zero Order Phase control to adjust the shape of the peak until it is fully positive and symmetric as shown in Figure 6.
    21. Increase TG by units of 10 until the peak decreases and becomes slightly negative, about -180.
    22. Decrease TG slowly until the peak is split half-positive and half-negative. See Figure 7.
    23. Record this null value for TG.
    24. Subtract 60 units from the null TG value and set TG to this value. Now the peak will be positive again and at maximum amplitude.
    25. Click Stop and then Done.
  3. Scanning and Analysis
    1. Click Scan to collect the SNR data.
    2. Switch to the Tools Workspace and open a Command Window.
    3. Type sageEnter to initiate the SAGE spectroscopy analysis tool. See Figure 8.
    4. Click File->Load->Rawdata to open the load raw data dialog window. See Figure 9.
    5. When the scan is finished click Update List to refresh the list of P files to choose from. See Figure 9.
    6. The top-most P file is the latest. Select this file and click Load. See Figure 9.
    7. In the main SAGE panel, select Macros->Func Tests->SNR Test…. See Figure 10.
    8. Move the windows around if necessary.
    9. Setup the SNR Test window as listed in Table 5 for the nucleus under test.
      Table 5. SNR Test Panel settings for 13C and 31P SNR tests.
      Field 13 C Setting 31 P Setting
      Spectral ApodizeYESNO
      Function: Exponential
      LB 2.5 Hz
      Line Shaping NO
      Zero FillNONO
      Num pts in frame40964096
      Noise Calc Region500 to 1500500 to 1500
      Zoom Spectral Dimension50 to –50 ppm50 to –50 ppm
      Show Analysis PlotsNONO
    10. Click Run on the SNR Test window. The SNR will be calculated for the active data set and reported in the command window where SAGE was started.
    11. Record the n=32 value for peak SNR (AmpSNR). Compare to the minimum acceptable value in Table 4.

Noise Test

Procedure

  1. Hardware Setup
    1. Install the TR module onto the top of the LPCA cover.
    2. Connect the transmit (thick) and receive (thin) cables to the connectors on the LPCA cover.
    3. Place the Grafidy base plate on the patient bed near the top of the bed.
    4. Place the QA probe in the center hole of the Grafidy plate and lock into place.
    5. Connect the QA probe cable to the quick disconnect module.
    6. Connect the QD module to the TR module.
    7. Landmark on the center of the QA probe and advance to scan.
  2. Scanner Setup
    1. Start a new exam, click New Patient.
    2. Enter geserviceEnter for Patient ID.
    3. Enter MNS Setup for Patient Name.
    4. Enter 111Enter for Patient Weight.
    5. From the Service->Other protocols choose MNS Setup.
    6. Select the Noise Scan series for the nucleus under test and click Accept.
    7. Landmark on the center of the QA probe, if not already completed during Hardware Setup.
    8. Click Save Series.
    9. Right-click on Research Options and select Display CVs.
    10. Set CV ia_rf1 = 0 and then click Accept.
    11. Right-click on [Research Options] and select [Download]
    12. Click Spectro Prescan.
    13. Slide R1 and R1 to the maximum position.
    14. Set TG to 0 (zero).
    15. Disable the RF switch at the systems cabinet. See Figure 12.
    16. Set the top display mode to Power.
    17. Click Start. After a few seconds you should see a band of noise across the power spectrum as shown in Figure 13.
    18. The tops of the noise should be about even across the window without any peaks. Peaks in the power spectrum may indicate a source of noise in the scan room.
    19. Click Stop and then Done.
  3. Scanning and Analysis
    1. Click Scan to collect the Noise data.
    2. Switch to the Tools Workspace and open a Command Window.
    3. Type sageEnter to initiate the SAGE spectroscopy analysis tool. See Figure 14.
    4. Click File->Load->Rawdata to open the load raw data dialog window. See Figure 15.
    5. When the scan is finished click Update List to refresh the list of P files to choose from. See Figure 15.
    6. The top-most P file is the latest. Select this file and click Load.
    7. In the main SAGE panel, select Macros->Func Tests->SNR Test…
    8. Move the windows around if necessary.
    9. Setup the SNR Test window as listed in Table 6 for the nucleus under test.
      Table 6. SNR Test Panel Settings For Noise Tests
      Field 13 C Setting 31 P Setting
      Spectral ApodizeNONO
      Zero FillNONO
      Num pts in frame40964096
      Noise Calc Region500 to 3500500 to 3500
      Zoom Spectral Dimension240 to –240 ppm (1.5T)150 to –150 ppm (1.5T)
      480 to –480 ppm (3.0T)300 to –300 ppm (3.0T)
      Show Analysis PlotsNONO
    10. Click Run on the SNR Test window. The noise will be calculated for the active data set and reported in the command window where SAGE was started.
    11. Record the n=32 value for Noise. Compare to the maximum acceptable value in Table 4.
    12. In the spectrum window, select Chan->Power.
    13. The spectrum should be flat across the window with tapering to zero at each edge as shown in Figure 18. Broad peaks in this window suggest unwanted noise in the scan room. Use this test as a tool for tracking down noise sources if found.
    14. To zoom out and see the full spectrum, click Zoom, then right click in the window and select Unzoom. Right click again and click Quit to exit the zoom control.
    15. Enable the RF Switch at the systems cabinet. See Figure 19.

Finalization

Procedure

  1. Remove any hardware used during system testing.
  2. Do a test scan of the system to ensure proper operation.
