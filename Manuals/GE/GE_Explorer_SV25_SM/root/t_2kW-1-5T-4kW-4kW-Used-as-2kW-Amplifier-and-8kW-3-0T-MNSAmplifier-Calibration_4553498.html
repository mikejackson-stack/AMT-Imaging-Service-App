About this task

This procedure should be followed after installation of the Multi Nuclear Spectroscopy (MNS) Amplifier to calibrate either the 2kW CPC Amplifier for 1.5T or the 4kW CPC (or 8kW AMT) Amplifier for 3.0T. The procedure can also be used to calibrate the 4kW Amp cabinet used in 2kW MNS HDx systems. This cabinet has a pre-installed attenuator connected to the RF input of the amplifier.

Procedure

  1. Disabling T/R Drive error condition:
    1. Verify the system is idle and all coils have been removed from the magnet bore.
    2. Remove the front cover of the RF Accessories Cabinet.
    3. On the front of the driver module, set the T/R Switch to Disable. This will disable T/R fault reporting.
      Note:

      HV, DD, and MC should remain set to “Enable”.

    4. Disconnect the T/R Bias Cable from the RF Amplifier (J11 on AMT Amplifier or J14 on CPC Amplifier).
  2. Set up the measurement system according to one of the three diagrams shown below.
  3. Power Attenuator Method:
    1. Using an RG214 Cable, connect the RF output of the amplifier to the input of a high-power attenuator.
    2. Connect additional attenuation to the output of the high-power attenuator until a total of 65 to 70 dB of attenuation is attained.
    3. Using a BNC Cable, connect the output of the attenuators to the input of the oscilloscope.
    4. Set the oscilloscope to full bandwidth (>150 MHz) and direct current of 50-ohm input impedance.
  4. Coupler Method:
    1. Connect the RF output of the amplifier to the input of power coupler.
    2. Connect the output of the power coupler to a suitable 50-ohm Dummy Load.
    3. Connect additional attenuation to the coupled output of the power coupler until at total of 65 to 70 dB of attenuation is attained.
    4. Connect the output of the attenuators to the input of the oscilloscope.
    5. Set the oscilloscope to full bandwidth (>150 MHz) and direct current of 50 ohm input impedance.
  5. For the Power Meter method, set up according to the directions in RF Power Meter (Watt Meter) Setup.
  6. For the Power Meter method, set up according to the directions in MNS Max RF Power Meter (Watt Meter) Setup.

Finalization

  1. Perform Universal Power Monitor - MNS Setup and Calibration.
  2. Verify that scanner is “Idle” and turn off the RF Enable.
  3. If Power Meter method was used, disconnect the RF Watt Sensor from the RF Output connection.
  4. Connect the original Output Cable to the MNS RF Amplifier and tighten the connector.
  5. Perform remaining cleanup procedures.
  6. Turn on the RF Enable.
  7. Reset the TPS to put the amp back into a known state.
  8. Perform a goodbye scan.
  9. Perform Multi Nuclear Spectroscopy (MNS) Functional Checks.
  10. Perform Universal Power Monitor - MNS Setup and Calibration.
