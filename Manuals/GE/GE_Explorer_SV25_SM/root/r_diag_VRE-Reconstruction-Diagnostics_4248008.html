VRE Reconstruction Diagnostics

Topic ID: id_SL1894809-1052851

Diagnostic Link

Diagnostics > System Function > Recon > VRE Reconstruction Diagnostics

Diagnostics > Hardware Location > PGR Cabinet > Recon > VRE Reconstruction Diagnostics

Topic ID: id_SL1894811-1052851

Purpose

This document describes the VRE Reconstruction Diagnostics including:

  • Host ICN Time Sync Diagnostic - This diagnostic tests the time synchronization between the host and ICN. It attempts to execute the date command on the ICN via the remote shell protocol. The ICN and host times are compared to ensure that they meet specifications.

  • ICN Image Reconstruction - This diagnostic tests the functionally of the ICN’s image reconstruction capabilities. In doing so, each ICN will have its components tested, that is, memory, processors, software and so on. This ensures that each ICN is capable of performing image reconstruction.

    This test takes a set of previously collected raw data, and reconstructs the whole set several times, testing image integrity by performing checksums on the images and validating them against saved checksum values.

  • ICN Process Verification - This diagnostic tests the correct number of processes (like recon, acquisition) is running on an ICN. This diagnostic uses a configuration file that specifies the process name and the number of instances that should be running on the ICN.

Host ICN Time Sync Diagnostic

Topic ID: id_SL1895343-1052851

Test Sequence

  1. Select Host ICN Time Sync.

  2. Click Run.

  3. Ensure that each ICN tested passes.

Topic ID: id_SL1895346-1052851

Components Tested

  • Remote Shell service on the ICN

  • Host and ICN Time synchronization

Topic ID: id_SL1896319-1052851

Results

Table 1. Diagnostic Results
Result Description GE Field Action

Passed

The ICN has passed the diagnostic

No further action required

Failed

The ICN Time Synch Diagnostic has failed

  1. Reboot the failed ICN. (Use Toolbox > VRE > ICN Identification from the Utilities tab to identify the failed ICN). Wait for the reboot to complete.

  2. Re-run the diagnostic.

  3. If the diagnostic fails again, re-configure the VREs using the Guided Install. Wait for the configuration process to complete.

  4. Restart the system.

  5. Re-run the diagnostic. Identify the defective ICN from the corresponding error message in the System Error Log.

  6. If diagnostic fails, replace the ICN. (Use Toolbox > VRE > ICN Identification from the Utilities tab to identify the defective ICN).

Failed

ICNs are not installed correctly

  1. Re-configure the VREs using Guided Install. Wait for the configuration process to complete

  2. Restart the system.

  3. Run the following command to check that the number of ICNs installed is valid: grep "num_of_icns" /w/config/vre.cfg.

ICN Image Reconstruction

Topic ID: id_SL1896320-1052851

Test Sequence

  1. Ensure that the ICNs are turned on.

  2. Select ICN Image Reconstruction.

  3. Click Run.

    Note:

    Once you click Run, do not click anywhere else in the Common Service Desktop until the test is completed. If you need to abort the test, you must click Stop.

Topic ID: id_SL1896324-1052851

Components Tested

  • ICN hardware

  • ICN software

  • Software communication between ICNs

Topic ID: id_SL1896328-1052851

Results

Table 2. Diagnostic Results
Result Description GE Field Action

Passed

The ICN has passed the diagnostic

No further action required

Failed

The ICN Reconstruction diagnostic has failed

Reconstruction took too long

  1. Run the following diagnostics and confirm that they pass:

    • Host ICN Ethernet Stress

    • ICN CPU Stress

    • ICN Process Verification

  2. Once these all pass, re-run this diagnostic.

  3. If it fails again, reboot the ICN.

  4. Once the reboot is complete, perform TPS reset.

  5. If the diagnostic fails, re-configure the VREs using Guided Install.

  6. Restart the system and re-run this diagnostic.

  7. If it fails again, identify the defective ICN from the System Error log. (Utilities > Toolbox > VRE > ICN Identification)

  8. Replace the defective ICN.

Results

Table 3. Diagnostic Results
Result Description GE Field Action

Passed

The ICN has passed the diagnostic.

No further action required

Failed

The ICN has failed the diagnostic

  1. Ensure that the ICN is powered on. (Utilities > Toolbox > VRE > ICN Identification)

  2. Ensure that the Ethernet switch is on.

  3. Run the Host ICN Remote Shell diagnostic. If it fails, troubleshoot this diagnostic.

  4. If it passes, re-run this diagnostic.

  5. If it fails, reboot the ICN.

  6. Perform a TPS reset and re-run the diagnostic.

  7. If the diagnostic fails, re-configure the VREs using Guided Install.

  8. Restart the system and re-run the diagnostic.

  9. If it fails again, identify the defective ICN from the System Error log. (Utilities > Toolbox > VRE > ICN Identification)

  10. Replace the defective ICN.
