High Order Shim Theory

To perform High Order Shim Procedure, Click Here.

To run a functional Check only, Click here.

INTRODUCTION

The High Order Shim feature allows the user to shim over a region-of-interest (ROI) taking advantage of the High Order Shim (HOS) coils. This feature is likely to improve the local field homogeneity for use in applications such as fat suppression, spectroscopy, spiral scanning and functional imaging. The calculations performed in the High Order Shim procedure require knowledge of the change in current behavior of each individual shim coil. Hence the contribution of each one is measured using a uniform phantom. This information is stored in the Reference Field Maps, which need to be calculated once per system installation. These Field Maps need to be recalculated only if the gradient coil or resistive shim coil is moved or replaced. The Reference Field Maps are always saved during SaveInfo sessions.

Process Overview

The Reference Field Map creation process requires the user to run a localizer scan on a phantom and adjust its position to within 5 mm as prescribed in the procedure. After the phantom is positioned the user then runs a script named “makereference” which will perform the following operations automatically:

Loads the required scan protocol for doing the reference map scans.

Note:

The scan protocol is identical to the scan used in the High Order Shim Feature on a uniform phantom.

  • Perturbs the current for each of the coils, one at a time, by a prescribed amount.

  • Allows time for the coil current to stabilize before starting the scan.

  • Reconstructing the data and extracting the phase information that reflects the magnetic field variations.

  • Analyzes the data and checks for phase wrap. If phase wrap is detected the script will repeat the process on each of the coils one more time using a lower perturbation current value.

  • Creates a Reference Field Map file from the scan data that can be read by the High Order Shim feature.

The GE Magnet shim coil and the GEMS-Oxford shim coil configurations are not the same. For GEMS-Oxford systems, the ZY Coil and ZX coils behave differently, in that the ZY coil affects the ZX harmonic and the ZX coil affects the ZY harmonic.

Example: If you adjust the current for the ZY coil it actually affects the ZX harmonic that is displayed by LVShim Analysis tool.

For the High Order Shim feature this is NOT an issue, since the adjustment of the shim power supply channel is relative to the data collected during the reference map generation. This also does not affect the process of manually setting the shim currents when using the “setcurrent” command.

FIELD MAP CREATION

The High Order Shim application requires the creation of two Reference Field maps; one will be generated using the RF Head coil with a 28 cm FOV and the other will be generated using the RF Body coil with a 48 cm FOV.

These reference maps are designed to accommodate as many anatomical regions as possible. The 28 cm FOV is designed to cover smaller central regions, such as the head, neck and knees whereas the 48 cm FOV is designed for torso, spine or off-center regions.

The procedure for building the reference maps is the same for both, with the exception of the phantom that is used. The 27 cm Body TLT Sphere, without the loader shell, is used to generate the 28cm FOV reference map whereby it will produce the largest usable shim volume possible at this field of view. This is important since only anatomy inside the shim volume selected can be shimmed properly. The 48 cm FOV reference map is generated using the 30 cm Inner Sphere of the LVShim phantom. Each reference map is generated separately, and does not have to be created in the same session.
