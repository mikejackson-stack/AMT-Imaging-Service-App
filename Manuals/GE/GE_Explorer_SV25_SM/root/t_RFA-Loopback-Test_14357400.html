The Radio Frequency Analysis (RFA) Tool is designed to quantitatively measure the performance of the Transmit chain by allowing the FE to perform "loopback" tests from several different points along the chain.

Ferrous Tools!

About this task

The RFA (Radio Frequency Analysis) Tool is designed to quantitatively measure the performance of the Transmit chain by allowing the FE to perform "loopback" tests from several different points along the chain. At most points, the inter-pulse RF stability and inter-pulse RF fidelity (i.e., magnitude and phase linearity) can be measured.

  • Go to Setup Test

  • Go to Perform Test

For information about the theory behind the tests, see RF Loopback Test Theory.

Setup Test

Procedure

  1. Ensure that the system is idle and remove all portable coils from the bore.
  2. On the Driver Module in the ISC, set Switch 2 (SW2) to TR DISABLE .
  3. On the Exciter/Ref Clock module located in ISC, set the RF Enb switch down (Disable).
  4. The following table provides links to the setup diagrams for the loopback test for the various components. Locate the setup diagram that matches your system and the loopback test that you want to perform. Set up the components to match the setup diagram.
    Table 1. Reference Diagrams for Loopback Tests
    For this loopback test: Refer to this setup diagram:
    Exciter
    Note: Landmark on center of body loader shell containing the body TLT sphere on the patient table cable inside the RF body coil.
    		 14399531.pdf
    Headdummy
    Note: No phantom is needed. Landmark on cradle and press advance to scan.
    		 15244428.pdf
    Bodydummy
    Note: Landmark on center of body loader shell containing the body TLT sphere on the patient table cable inside the RF body coil.
    		 14399529.pdf
    Headsense
    Note: Set phantom by reffering to MCQA procedure. Landmark on center of phantom in the Local TR Coil (Knee, wrist, etc.)
    		 13720648.pdf
    Bodysense
    Note: Landmark on center of body loader shell containing the body TLT sphere on the patient table cable inside the RF body coil.
    		 13720645.pdf
    Note: The loopback test setup for headsense and bodysense are the same.
  5. Set the 1 dB/step and 10 db/step rotary attenuators to 10 db and 20 db, respectively [decibel (dB)].
  6. On the Exciter/Ref Clock module located in ISC, set the RF Enb switch to Enable (up).
  7. If you are running the Exciter, Headdummy, or Bodydummy loopback tests, go to Step 9 and do not configure the oscilloscope.
  8. If you are running a headsense or bodysense test, set up the oscilloscope:
    1. Obtain a Tektronix TDS 3012B, 2-channel, 100MHz, color Digital Phosphor Oscilloscope. The front panel of the scope is organized into VERTICAL, HORIZONTAL, TRIGGER, and ACQUIRE groups of controls. These four names are used below to help locate the various controls:
    2. Plug the scope into an available ISC service outlet outside the magnet room and turn the scope power ON.
    3. Use a BNC cable to connect the RTO output J3 on the front panel of the Exciter to the channel 1 (see Figure 4) input of the scope. Set the RTO select switch of the exciter to its Rho position (the lowest OR right most position depending on switch mount orientation.)
    4. Take the BNC cable at the end of the loopback path setup for headsense or bodysense modes and connect it to the channel 2 input of the scope (see Figure 4).
    5. Use a BNC cable to connect the “in view” signal output J5 on the front panel of the Exciter to the EXT TRIG input of the scope (see Figure 4). This signal indicates when data is collected during each TR interval of the Manual Pre-Scan entry point and is used to trigger the scope.
  9. On the Exciter module in the ISC, set the RF Enb switch up (Enable).
  10. Landmark as indicated in the reference diagram for the test you are running (see Setup Test, Step 4), and Move to Scan.

Perform Test

Procedure

  1. Select RFA Tool in the service browser (see Figure 5 ).
  2. Select Loopback Mode for the present setup.
    Note:

    If selecting Loopback mode of Exicter or bodydummy , there are two outputs: Channel 1 and Channel 2. Select the applicable channel in the Dual Drive Output section of RFA. Only one channel can be monitored at a time. There is the option of executing RFA with output on both channels or only one channel. This may aid in troubleshooting stability issues. To enable the channel that is not being tested, select Leave Ch1 or 2 exciter output enabled in the Dual Drive Output section of RFA. To disable the channel that is not being used, select Disable Ch 1 or 2 exciter output in the Dual Drive Output section of RFA.

    IMPORTANT: If running bodydummy mode of RFA and both Channel 1 and Channel 2 are being used, two dummy loads are required. the dummy load for the channel being monitored will require the 3.0T RF Power Measurement Kit. The standard 1.5T dummy load can be used for the channel that is not being monitored, as the RF output is 15Kw per channel. Damage to the RF Amplifier can occur if running RFA with both channels active and not using two dummy loads.

  3. Select RF Pulse Type (initially use default).
  4. Select Gradient State (use the default).
  5. CAUTION
    Avoid Equipment Damage.
    Avoid damage to the DTRSW and the preamp combiner.
    Ensure that the TR bias cable is properly connected to the RF amplifier (J10).
    Click Start .
  6. If the selected loopback mode is either headsense OR bodysense , follow the instructions in Monitoring the Loopback Signal Using an Oscilloscope to examine the loopback signal.
    Note:

    SVAT errors usually indicate a setup problem such as Landmark, 32-channel patient table connector not connected, TR or DD fault, etc. Check the error log.

  7. Check the loopback setup according to the pop-up request, then click Continue .
    Note:

    During headsense or bodysense tests, do not click OK on the sense loop popup until you are ready to end the test.

  8. A message box appears as shown in Figure 8 . (The message box appears after 60 seconds.) Click the Patient icon on upper right corner of the display as shown in Figure 7 .
  9. Adjust the output according the following steps. See Figure 9 for flowchart.
    1. Slowly increase TG to 200.
    2. Check R1% value.

      • If R1 is within 30%~70%, go to Step 9.c .

      • If R1 is out of 30%~70%, adjust rotary attenuator until R1 value becomes 30%~70%.

    3. Check R2% Value.
      Note:

      R1 value will change by adjusting rotary attenuator for R2 adjustment and it may become out of 30%~70% range in step b. But, it is acceptable once it is adjusted in step b. Focus on R2% value adjustment to meet 84%~94%.

      • If R2 is within 84%~94%, adjustment is done. go to Step 10

      • If R2% is out of 84%~94%, adjust the rotary attenuator as close to 84%~94%. If R2 % becomes 84%~94%, adjustment is done. go to Step 10 .

    Table 2. Attenuator change and R1%, R2% change ratio
    ATT R1%, R2% Change Ratio
    3x 0.71
    2x 0.79
    1x 0.89
    -1x 1.12
    -2x 1.26
    -3x 1.41
  10. When done, use Toolbelt icon to return to service window and start scan by selecting Proceed & auto-scan . See Figure 8 .
  11. After the scan and analysis ends, view the results. Compare the results to the typical normal plots shown in RFA Plot Results . Real failures will exceed the example plot values by 2 or more times. Minor differences are not failures. Select the pop-up choice to erase the displays. The plots are saved as .jpg files under /usr/g/service/cclass/RFA/ .
  12. If you want to perform another test in the same Loopback Mode , then go to Step 3 .
  13. If you want to perform another test in a different Loopback Mode , then go to Step 2 .

Monitoring the Loopback Signal Using an Oscilloscope

About this task

This procedure applies only if running in headsense OR bodysense Loopback mode. When this procedure is completed, go to Perform Test, Step 9.

Procedure

  1. Note: If selecting Loopback mode of bodysense, there are three outputs: Ch 1 output only looped back, Ch2 output only looped back, and Dual Drive output looped back. Select the applicable channel in the Dual Drive Output section of RFA. There is the option of executing RFA with output on both channels or only one channel. This may aid in troubleshooting stability issues. To enable the channel that is not being tested, select Leave Ch1 or 2 exciter output enabled in the dual Drive Output section of RFA. To disable the channel that is not being used, select Disable Ch 1 or 2 exciter output] in the Dual Drive Output section of RFA.
    Press the black Autoset button under ACQUIRE control.
  2. Press the gray MENU button under the VERTICAL controls.
  3. Press the yellow CH1 button under VERTICAL controls.
  4. Press the Coupling button on the bottom of the display:
    1. Select GND on the right of display.
    2. Select 1 MegOhm on the right of the display. Important!
    3. Use the VERTICAL/SCALE knob to set to 100mV/div. (See Figure 11.)
    4. Use the VERTICAL/POSITION knob to vertically center the yellow plot on the horizontal center line of the screen at 0 volts. (See Figure 11.)
    5. Select DC on the right of the display.
    6. Press Invert on the bottom of the display.
    7. Select Invert Off on the right of the display.
  5. Press Bandwidth on the bottom of the display.
  6. Select Full Bandwidth on the right of the display.
  7. Press the blue CH2 button under the VERTICAL controls.
  8. Press the Coupling button on the bottom of the display.
    1. Select GND on the right of the display.
    2. Select 1 MegOhm on the right of the display (very important)!
    3. Use the VERTICAL/SCALE knob to set to 100mV/div. (See Figure 12.)
    4. Use the VERTICAL/POSITION knob to vertically center the blue plot on the horizontal center line of the screen at 0 volts. (See Figure 12.)
    5. Select DC on the right of the display.
  9. Press the Invert button on the bottom of the display. Select Invert Off on the right of the display.
  10. Press the Bandwidth button on the bottom of the display. Select Full Bandwidth on the right of the display.
  11. Press the MENU button under the TRIGGER controls.
  12. Press the Type button on the bottom of the display to select Edge.
  13. Press the Source button on the bottom of the display. Under A Trigger Source on the right of the display select Ext (external).
  14. Press the Coupling button on the bottom of the display. Under A Trigger Coupling on the right of the display select DC.
  15. Press the Slope button on the bottom of the display. Under A Trigger Slope select the positive going slope.
  16. Press the Level button on the bottom of the display. Under A Trigger Level select the positive slope level. Use the small TRIGGER/LEVEL knob to set the level to 300mv (the value is displayed on the screen. (See Figure 13.)
    1. If a small green light to the left of the DELAY button under the HORIZONTAL controls is lit, then press the DELAY button to shut it off.
    2. Adjust the HORIZONTAL/POSITION knob so that the red T value at the bottom of the display reads 0%. At this point the small red T at the top of the display should be all the way to the left side of the display time line. (See Figure 14.)
    3. Adjust the HORIZONTAL/SCALE knob to set 800μs/div (the value is shown after the M at the bottom of the display). (See Figure 14.)
  17. Press the blue CH2 button under the VERTICAL controls. Adjust VERTICAL/SCALE knob to expand the blue RF pulse to the maximum vertical height without going outside the display. (See Figure 14.)
  18. Press the yellow CH1 button, then press the gray MENU button under VERTICAL controls. Adjust VERTICAL/SCALE knob to expand the yellow envelope pulse to the maximum vertical height without going outside the display. (See Figure 12.)
  19. Select Fine Scale on the bottom of the display. Use the large unmarked multipurpose knob at the top of the scope to adjust the fine scale amplitude of the yellow envelope pulse until it is coincident with the envelope of the blue RF pulse.
  20. Increase TG to 200.
  21. This is a visual test only. The two waveforms should be similar.

Finalization

Procedure

  1. On the Exciter/Ref Clock module located in the ISC, set the RF Enb switch to Disable (down).
  2. When finished with the loopback test, restore the cabling to the default clinical state.

    Default clinical state reference diagram: 3963663.pdf

  3. On the Exciter/Ref Clock module located in the ISC, set the RF Enb switch to Enable (up).
  4. On the Driver Module in the RF System cabinet, switch the TR Drive switch (SW2) to TR ENABLE.
  5. Perform a quick scan to verify the system is operating properly.
