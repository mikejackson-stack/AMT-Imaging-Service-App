Loading Host Operating System Software

Procedure

  1. Notice
    The software load can be corrupted if the following conditions are not met:
    Check SaveInfo script executed.
    System Monitor turned On.
    Insert the Linux OS Software DVD into the DVD-ROM drive of the host computer.
  2. Reboot the host computer.
  3. At the boot prompt, type GEHCMR

    The OS software load takes about 13 minutes.

    Note:

    As the install begins, it queries all physical drives in the system and builds/partitions all available devices. If the disk is not what the system expected, a warning indicating a bad disk may display. Software will fix during the install. Click Ignore to proceed with the install.

    After about 90 seconds, a progress message displays, indicating that the install image is being transferred. (See Figure 2.)

    Two minutes later, an additional message displays indicating that the install process has begun. (See Figure 3.)

  4. Once the installation is complete,click ‘enter’ on the prompt asFigure 1; the OS disk will be ejected automatically, ensure the disk is removed from the drive. Do not insert the Applications DVD at this time!
  5. When a terminal window displays after a couple of minutes, the OS software load is complete. Continue to the next section.

Loading MR Applications Software

Procedure

  1. Insert the MR Applications DVD into the DVD drive of the Host computer with root account, password operator.
  2. When the Information window (shown in Figure 5) displays, click OK to confirm the run.

    The system begins partitioning the hard drives. A progress window displays. (See Figure 7.)

    The system reboots automatically when the partitioning is complete. Do not interact with the system.

  3. Notice
    If there is Alert Window as “Please Insert MR Application Software Media and Click OK”, insert disk to the drive manually; then wait until loading completed which can judge from the indicator light. It takes around 30 seconds, then click ‘OK’ on the Alert prompt.
    The following screen is shown while system is installing Guided Install Package after click OK of “HDD preparation complete”.
  4. When the Locale Selection window (shown in Figure 9) displays, select the proper locale and language, then click OK.
  5. The Guided Install screen will display. When the Message screen (shown in Figure 10) displays indicating the improvements made from the previous software version, click OK to continue.
  6. A message box concerning the Guided Install Configuration Media will display. (See Figure 11.)
  7. Notice
    The last installed GUI configuration can only be installed if it was previously saved using Save GI Configuration in Guided Install.
    Remove Application DVD and insert the Save Info DVD. Verify that the correct values are restored by checking each tab in the next step. Click OK to reinstall the last GUI installation configuration values.

    • The SaveInfo files are not restored at this point in the software load, but will be restored later.

    • If the GUI configuration was not saved, or the load is being performed for the first time, click Cancel to continue manually with the installation.

  8. Select Basic Configuration tab shown in Figure 12. Verify that all values under this tab are configured properly, including Time/Date.Refer to Guided Install Options to verify the configuration for each item.

    • If failures are noted, click on the failure, then click Go to Tab.

    • If any parameter does not match the expected criteria, the values in the left column will be red. If everything is acceptable, all values remain black. A changed value is indicated in blue.

    Note:

    Select proper governing body for the customer site; usually IEC (or other selection if required by local regulation). For Japan, select ‘MHLW-JIS’."

  9. If the Guided Install configuration was successfully restored from the DVD, it is not necessary to change any of the parameters.
    1. Check the parameters on the Verification tab, and confirm there are no failures. If there are failures, make the necessary changes.
    2. Make sure all required configuration tabs are filled out (not in any specific order) before continuing. The Verification tab lists any formatting errors as well as current settings.
  10. Notice
    If loading software for the first time on a Host PC, the initial boot up will fail. Manually enter the Term Server information on the Network Info screen shown in Figure 12.
    Example format: 20:2D:90:22:44. Use colons between two digits; letters are case sensitive.
    Proceed to the Verification tab shown in Figure 13.
    1. Look for any items with a Fail status. Go to the tab with the error and correct it.
    2. Click Install to open the Verification tab again.
      Note:

      Failed entries are due to missing or incorrectly formatted entries. The Install Software button is inactive if there are failures.

  11. If all entries pass verification at this point, click Install Software to begin the MR Applications load. If the time and time zone are correct, click Confirm to proceed. (See Figure 14.)
  12. A message box will display concerning that if the MR Application DVD is in the DVD driver. (See Figure 15)

    Remove SaveInfo DVD-R and Insert MR Application DVD click [OK] to proceed.

    Note:

    If the Application Software Installation does not move to the next stage as Step 13, click [Install Software] button again described in Step 10.

    If the disk is ejected automatically with a message window “Please Insert MrpApps CD in the CDROM drive” is showed, insert disk to the drive manually; then wait until loading completed which can judge from the indicator light. It takes around 30 seconds, then click “OK” on the message prompt.

  13. A Software Installation in Progress message will display. The MR Applications load will take 10-15 minutes, depending on the host PC. (see Figure 16)
  14. Once the MR Applications load is complete, a confirmation message (shown in Figure 17) displays. Click OK to close the window.
  15. The GUI returns to the Guided Install window. Under the Utilities tab in the left navigation, select Save/Restore to open the Save/Restore screen shown in Figure 18.
    1. If the DVD with the saved configurations is not available, go to each tab in the Install GUI and complete all system information manually. A Help button that provides information on the required data and its format is available on each tab.
    2. If the DVD with saved configurations is available, click Restore Information, and select the proper media from the dialog box. (See Figure 11.)
    3. When the Restore Info Dialog box (shown in Figure 19) displays, click Restore all files automatically, then click Continue.
      Note:

      If restoration fails, the DVD automatically ejects the media. Exit the Guided Install and allow the system to reboot. When the system restarts, return to the Guided Install and attempt to Restore Info again.

  16. A RestoreInfo in Progress window scrolls filenames as they are restored.
    • When the restoration is completed, an Update Utility message (shown in Figure 21) displays.
    • Click OK to open the Restore Manager dialog window shown in Figure 22.
  17. Select All to restore all items, and click Update.
  18. When the update is finished, the message 'Update is complete.' is displayed at the message area. Click Quit.
  19. Click Yes when the Quit Tool message (shown in Figure 24) displays.

    • The message shown in Figure 25) confirms that a log file was created. Click OK to finish.

    • The MR Applications software load is now complete.

  20. Quit the Guided Install by selecting ‘File’ -> ‘Quit’
  21. Reboot the system, by click the right mouse button and choose Reboot, by selecting Desktop on the left corner of the monitor, then Logout, then Restart the computer, and then OK.(SeeFigure 27 and Figure 28)
  22. Log in to the system as root (password is operator)
  23. The Guided Install Starter will pop up. Click [Yes] to start Guided Install. (See Figure 30)
  24. Manually eject the DVD driver and remove the MR Applications DVD.
  25. Proceed to Loading and Configuring VRE Software.

Loading and Configuring VRE Software

Procedure

  1. From the Guided Install interface left navigation menu, select VRE Configuration.
    1. When the VRE Configuration screen (shown in Figure 31) displays, verify VRE Blades are properly installed and all hardware connections are in place, including Ethernet connections.
    2. Click Configure VRE Blades shown in Figure 31.
  2. When the Information window (shown in Figure 32) displays, click Continue to confirm that the VRE Gigabit Switch Ethernet and Host Ethernet connections (Figure 33) are complete and correct.
  3. After M4 software, a pop-up message will prompt the user to insert the SV OpenSuse OS DVD for copying the ICN OS contents onto the hard drive. Insert the SV OpenSuse OS DVD into the DVD-ROM drive of the host computer and click [OK]. VRE configuration progress details will display while ICN OS contents are being copied. For M3 software, skip this step and perform next step.
  4. The system needs to be configured for 1 ICN. This procedure will take between 25-30 minutes.

    • A VRE Configuration Progress Details window shown in Figure 35 will display.

    • When VRE configuration is complete, a configuration Success message is displayed. Click [OK] to continue.

  5. When the Information window confirms that the configuration is complete, click OK.
