Field Map Creation

Procedure

  1. Notice
    After loading, landmarking, and advancing to scan, let the phantom settle for 15 minutes before scanning.
    At the operator workstation, select Service Desktop and prepare the system by performing a TPS Reset.
  2. Load and landmark the LVShim phantom.
  3. At the operator workstation, select the scan icon in the desktop control panel and set up the High Order Shim calibration scan as follows.

    • New Pt

    • Id: geservice

    • Name: HOS Cal

    • Weight (lb.): 300

  4. Set Patient Protocols to Service

    • Under Patient Protocols select Service, and then Other

    • Click Protocol LVShim, and then Series1.

    • Click Accept to download the series.

  5. Click Save Series.
  6. Execute the scan by clicking Scan.
  7. When the image is displayed in the Autoview window, select Display in the desktop control panel. To display the image, select Exam, Series, and Image, and click Viewer. Verify that the phantom is centered in the Z axis, as follows:
    1. Click User Prefs.
    2. In the User Preferences pop-up window, find Grid Prefs and click Customize.
    3. Change Grid Spacing (mm) to 150, click OK, and then click Apply.
    4. Select the grid symbol button to turn on the grid.
    5. Adjust Window (W) and Level (L) settings until the edges of the phantom image can be clearly seen.
    6. Verify that the inner phantom sphere is centered within the 150 mm grid in the S/I direction. If the phantom is not centered, move the phantom in or out of the bore and right to left as necessary (based on the grid markings), then landmark again and re-scan.
Topic ID: id_SL2343319-481876

Running Makereference Script

Procedure

  1. On TRM systems, this section will take 45 minutes to complete. On the 3T/94 CRM, this section will take 90 minutes to complete.
  2. Start the HOShim Reference Map tool:
    1. (For restricted Service Tools) Make sure the service key is installed.

      1. On the Calibration tab, select Calibration > Install and Calibration Wizard.

      2. Select HOShim Procedure from the menu.

        If HOShim is not available, refer to ICW for instructions.

    2. (For non-proprietary Service Tools) Open the Common Service Desktop.

      1. On the Calibration tab, select Calibration > HOShim Reference Map.

      2. Select Click here to start this tool.

    The HOS Tool interface displays.

  3. Select Start Scan.
  4. When the message Scanning. Please wait Until Scan Done! displays, click OK.

    The system prescans first, then scans. There are multiple scans in this sequence with no user interaction required.

    After the scan is done (45-90 minutes, depending on system type), the lower portion of the screen says: Reference Map Creation in Progress.

  5. When the scan is complete, click Quit.
  6. Verify that the HOShim reference maps were created correctly (see HOShim Verification).
Topic ID: id_14966870

Finalization

Procedure

  1. Perform a SaveInfo to back up the calibration files. To verify the saved calibration files, refer to Save and Restore Tool.
  2. Put away all phantoms and tools.
