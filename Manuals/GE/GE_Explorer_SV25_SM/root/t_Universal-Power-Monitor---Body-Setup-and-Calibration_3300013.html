About this task

This procedure sets up the Universal Power Monitors (UPM’s) in Body Mode, by using the system and the Power Measurement Kit (Wattmeter). For proper calibration of the Universal Power Monitors, (UPM) Forward Power must be completed in Body mode.

Topic ID: id_SL1930802-1084125

BODY FORWARD POWER CALIBRATION

Procedure

  1. Remove Cabinet front cove. See SC Cover Removal.
  2. Inhibit TR faults. Disable the Driver Module in the System Cabinet, Figure 1. Move switch 2 to the TR Disable position.
  3. Place the RF ENABLE switch on front of exciter in the DISABLE (Down) position.
  4. Remove the Body RF cable from J4. Connect the RF dummy load into J4. Use 7/16 Male - N Female Adapter attached in System Cabinet.
    Note:

    If the body section of the 1.5T SRFD3 Max Power RF Output and Calibration procedure was just completed, configuration is the same. You can leave the head RF cable disconnected and body can keep the wattmeter in line. It will not change the outcome of the calibration.

    Note:
    7/16Male -N Female Adapter is located at System Cabinet Left Shelf. Remove left cover and find it. See Figure 2
  5. Place the RF ENABLE switch in the ENABLE (Up) position.

Setting up Software Tool to Calibrate UPM - Body Forward Power

About this task

This tool must see a Landmark only. It is not necessary to have a Head coil in place, or any other scan parameter entered than what is described below. Simply Landmark on the cradle where the Head coil would be.

Procedure

  1. Notice
    If Head UPM is already calibrated before Body UPM Calibration, DO NOT edit '/w/config/Upm1Cal.cfg' and '/w/config/Upm2Cal.cfg'. Calibrated value of Head UPM will be erased.
    If Head UPM is NOT calibrated before Body UPM Calibration, reset “/w/config/UPM1Cal.cfg” and “/w/config/UPM2Cal.cfg” file to 0 according to the following procedure.
    1. Open File Editor by selecting Utility/File Editor from Common Service Desktop.
    2. Select File/Open.
    3. Select '/w/config/Upm1Cal.cfg' and Open.
    4. Select Save As... and save the file as 'Upm1Cal.cfg.bk' .
      Note:

      The purpose of this step is creating backup file.

    5. Select File/Open.
    6. Select '/w/config/Upm1Cal.cfg' and Open.
    7. Edit the file so that the 12 values are set to '0'.
    8. Save the config file.
    9. Perform the same procedure for '/w/config/Upm2Cal.cfg'.
    10. Quit the tool.
    11. Perform [TPS Reset].
  2. Note:

    This tool must see a Landmark only. It is not necessary to have a Head coil in place, or any other scan parameter entered than what is described below. Simply Landmark on the cradle where the Head coil would be.

    Click New Patient Icon.
  3. Enter the following parameters:
    1. geservice
    2. Weight: 111
  4. Press the Align button on, (Land Mark).
  5. Move the cradle to the Home position and then drive it into the bore.
  6. Press Landmark button when the align light is approximately where the center of the head coil would be.
  7. From the Common Service Desktop Select:
    1. Select Calibration Tab
    2. Select UPM Tool
    3. Start UPM tool from the Service Browser, Figure 12. Figure 13 shows an example of the UPM tool.
      Note:

      The first time running the UPM Calibration tool after a load from cold, the following Error may appear: “The spectroRFampType and upm.config do not match! Please run the UPM Tool config file editor and hit [Restore Defaults] and save the config file”. If this error appears, click [File] -> “Edit Config”. When the window opens, click [Restore Defaults] then close the screen. The tool will now have the correct information and this pop-up will not appear again during future UPM Calibrations.

  8. Select the Nuclei 1H.
  9. Select the RF Chain you are going to calibrate Body.
  10. Select Power Monitor type. Forward
  11. Select: Calibrate Button
  12. Select the Start button on the tool opened earlier, Figure 13.

    One window popup to ask you if the hardware setup properly. Click [ok].

  13. Status should indicate Pass/Fail from 1 minute to 7.5 minutes depending on software version (tool should notify user of current step in progress). If failure occurs, see Universal Power Monitor (UPM) Troubleshooting.
Topic ID: id_15010730

Finalization

Procedure

  1. Place the RF ENABLE switch on front of exciter in the DISABLE (Down) position.
  2. Remove the cables and power measurement equipment.
  3. Reattach the Body Heliax Cables.
  4. Re-enable T/R Drive. See Driver Module, Figure 1.
  5. Switch RF ENable on the front of the exciter to the Enable (up) position.
  6. Upon completion of UPM calibration, Reset TPS. The system will not scan until this step is done
