Setting up a planned Maintenance Schedule

Procedure

  1. Install the USB Service Key into the system.
  2. On the Service Desktop, start the Service Browser if it is not already running.
  3. Select the PM tab.
  4. Click on the PM Assist Folder to expand it's menu/content.
  5. Refer to Figure 1. Select PM Schedule.
    Note:

    The following illustration is an example of 1.5T systems.

    According to the system, the menu or message may slightly differ.

  6. Create a new PM Record by entering a name of who will do the PM and when is it scheduled.

Procedure

  1. Install the USB Service Key into the system.
  2. On the Service Desktop, start the Service Browser if it is not already running.
  3. Select the PM tab.
  4. Click on the PM Assist Folder to expand it's menu/content.
  5. Refer to Figure 2.
    Note:

    The following illustration is an example of 1.5T systems.

    According to the system, the menu or message may slightly differ.

  6. If this is the first time you have entered this option, without the PM Assist mode of LVShim or SPT completed, it will indicate a incomplete PM. This is normal for the first time.
