Applies to: Siemens MAGNETOM Espree, Avanto, Symphony, Sonata, Trio, Verio, Skyra, Prisma and related platforms. Error F001 (Gradient Amplifier Fault) and related gradient system diagnostics.

Error F001 — Gradient Amplifier Fault

CheckAction
Gradient Amplifier CabinetOpen gradient amplifier cabinet (GRAMP). Check for fault LEDs on each gradient amp module (X, Y, Z axes). Note which axis is faulted from the LED indicators or error log.
Cooling SystemSiemens gradient amps are water-cooled on most platforms. Verify coolant supply pressure, temperature, and flow rate at the GRAMP water connections. Overtemperature is the #1 cause of F001. Check for coolant leaks.
DC Bus VoltageCheck DC bus voltage at gradient power supply (GPS). Typical value is ±350–450 VDC (platform specific). Check GPS fault indicators. Run ServiceLine → Gradient → GPS test.
Gradient Coil ContinuityUse ServiceLine to run Gradient Coil Test. Test X, Y, Z independently. A specific axis failure points to that amp or coil assembly.
Cable ConnectionsInspect all cables between GPS, GRAMP, and gradient coil. Reseat connectors. Check the gradient cable bundle at the bore entry point for wear or damage.
Error Log ReviewReview detailed fault log: ServiceLine → Error Log. F001 entries include a sub-code indicating which axis and whether the fault is thermal, overcurrent, or communication. Use sub-code to narrow diagnosis.

F001 Sub-Code Reference

The F001 error is accompanied by sub-codes in the Siemens error log. Record the full error string from ServiceLine for accurate diagnosis.
Sub-Code / DescriptionLikely CauseAction
F001 X / Y / Z — Axis specific thermal faultCoolant flow insufficient to that amp module; amp module failingCheck coolant flow. Clean heat exchangers. Verify coolant temperature at GRAMP inlet (<25°C typical). Replace amp module if thermal fault persists with good cooling.
F001 — DC Bus undervoltageGPS failure; input power issue; blown fuse in GPSCheck input power to GPS. Inspect GPS fuses. Measure DC bus output. Replace GPS if output out of spec.
F001 — Overcurrent / shortGradient coil short circuit; cable insulation failure; amp output stage faultMeasure gradient coil resistance (X, Y, Z). Check for cable damage or arc tracking. Replace faulted amp module or coil assembly.
F001 — Communication fault (GCU link)Gradient Control Unit (GCU) to GRAMP communication link failureInspect GCU-GRAMP fiber or cable link. Check GCU card in electronics cabinet for fault LEDs. Reseat GCU card. Run ServiceLine comms test.
F001 — Interlock openSafety interlock tripped (temperature, door, coolant flow switch)Check all GRAMP interlocks. Verify cabinet door is closed and latched. Check coolant flow interlock switch. Check temperature interlock relay.

Common F001 Scenarios

SymptomLikely CauseFix
F001 after several scans, clears after cooldownThermal shutdown — marginal coolingCheck coolant flow rate and temperature at GRAMP. Inspect heat exchanger for fouling. Verify chiller performance (chilled water systems). Clean air side of heat exchanger if applicable.
F001 at startup, one axis onlyGPS output degraded on one rail; single amp module faultIdentify faulted axis from LED/error log. Measure GPS output on that axis. Swap or replace faulted amp module.
F001 after heavy EPI/DTI sequencesHigh duty-cycle sequences stress gradient amps thermallyVerify cooling capacity is adequate for the sequence duty cycle being run. Consider cooling system upgrade if clinically required. Check amp module thermal performance.
F001 with image geometric distortion before full faultDegrading amp — performance marginal before hard faultRun gradient performance tests (linearity, scale). Replace amp module before complete failure causes patient safety or image quality issues.
F001 with coolant leak visible in GRAMP cabinetCoolant fitting failure; amp module coolant block crackedShut down system immediately. Clean up coolant before any electrical measurements (electrical hazard). Locate leak source. Replace fittings or amp module. DO NOT operate with coolant leak present.

Gradient Amp Cooling System — Siemens Platforms

Water in the GRAMP cabinet creates a serious electrical hazard. Always de-energize the gradient power supply before inspecting for coolant leaks. Never operate the system with a known coolant leak.

Coolant Supply Temperature15–25°C at GRAMP inletHigher temp reduces cooling efficiency; verify chiller performance in summer

Tip: The most common cause of F001 on Siemens systems is coolant-related — either inadequate flow or high coolant temperature. Before replacing any amp module, confirm the cooling system is delivering the correct flow rate and temperature. A GRAMP that runs fine in winter and faults in summer almost always has a chiller or heat exchanger problem.
Tip: Siemens ServiceLine error log sub-codes are essential for gradient fault diagnosis. Always pull and record the full error string, not just the F001 top-level code. The sub-code tells you which axis, what type of fault, and narrows repair to amp vs. power supply vs. cooling vs. coil.
Critical: GRAMP DC bus voltages are HIGH VOLTAGE (350–450 VDC). Allow full capacitor discharge after GPS shutdown before accessing internal components. Confirm discharge with a meter before touching bus connections.
