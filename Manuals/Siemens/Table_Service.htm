🛏️ Siemens MRI Patient Table & E-Stop Service Guide
AMT Imaging Solutions — Field Service Quick Reference

Applies to: Siemens MAGNETOM Espree, Avanto, Avanto Fit, Symphony, Sonata, Trio, Verio, Aera, Skyra, Prisma. Covers STE (System Emergency Stop), patient table drive faults, docking issues, and related mechanical/electrical troubleshooting.

STE — System Emergency Stop Triggered

Safety First: Before resetting any E-stop, physically verify that the scan room is clear and safe. Never reset an E-stop that was triggered by a real emergency without understanding why it was triggered.
CheckAction
Identify which E-stop was triggeredSiemens systems have multiple E-stop buttons: gantry bore (both sides), control console, and sometimes patient handgrip. Check all buttons — the triggered one is typically latched in (pushed in and rotated). Note: a single triggered E-stop disables the entire patient handling system.
Reset all E-stop buttonsRotate each E-stop button clockwise (they are twist-release type) until it pops out to its normal extended position. Check all locations systematically — a hidden or forgotten latched button is the most common cause of "E-stop won't clear."
System software resetAfter all E-stop buttons are released, reset the E-stop in the system software: ServiceLine → System → Patient Handling → E-Stop Reset (or equivalent path for your software version). The system requires a software acknowledgment after hardware reset.
Test patient handling after resetRun a complete patient table functional test: drive table in/out, up/down, verify all positions. Table should move smoothly through full range. Test both handgrip and panel controls.
STE triggered by software faultCheck the system error log in ServiceLine for any fault that triggered the E-stop programmatically (overload, position error, communication fault). Address root cause before returning system to clinical use.

Patient Table Drive Faults

SymptomLikely CauseAction
Table won't move — no error, E-stop clearTable drive interlock not satisfied; docking position not reached; weight limit exceededVerify table is fully docked. Check for obstruction. Run table functional test from ServiceLine. Check that no weight/load limit error is active.
Table moves slowly or with hesitationDrive belt worn or slipping; lubrication needed; drive motor marginalInspect longitudinal drive belt for wear, cracking, or tension loss. Check guide rail lubrication. Run table at service speed and listen for abnormal motor sounds.
Table height won't adjustVertical actuator fault; vertical position sensor error; actuator motor or drive faultInspect vertical actuator for mechanical binding. Check vertical position sensors (typically reed switches or encoders). Verify actuator drive board in patient handling cabinet.
Table won't dock to gantry (docking interlock)Docking sensor misaligned or failed; table not in correct lateral position; dock latch not engagingManually align table to docking position. Inspect docking latch mechanism. Check docking sensor alignment — Siemens docking uses proximity sensors on the gantry dock plate. Run docking test from ServiceLine.
Intermittent table fault — clears on retryCommunication error between patient handling controller and main system; connector intermittencyReseat all connectors at patient handling cabinet. Check cable drag chain for pinched or frayed cables. Review ServiceLine log for communication fault codes.
Patient handgrip buttons not workingHandgrip cable fault; connector; handgrip unit failureInspect handgrip cable connection at table. Test with ServiceLine software control to confirm table drive is functional. If software moves table but handgrip doesn't, fault is in handgrip cable or button assembly.

Siemens Patient Handling System Components

ComponentFunctionService Notes
Patient Handling Controller (PHC)Main controller board for all table movements — receives commands from console, drives motors, monitors sensorsLocated in patient handling cabinet, typically behind or under the table base. Faults shown on PHC status LEDs and in ServiceLine error log.
Longitudinal Drive MotorDrives table cradle in/out of bore along the longitudinal axisConnected via drive belt to cradle. Belt inspection annual. Motor replacement requires cradle removal on some platforms.
Vertical ActuatorRaises/lowers table height for patient positioning and bore entryElectric linear actuator. Check for binding, unusual sounds. Actuator replacement is a significant job on Aera/Skyra platforms.
Position EncoderTracks cradle position in real time — enables soft limits and docking position detectionEncoder failure causes position errors and table faults. Clean encoder strip on systems using optical linear encoders.
Docking InterfaceMechanical and electrical coupling between mobile table and gantry dock — allows table to separate for transfersInspect dock latch and proximity sensor annually. Misalignment is common after table transport. Re-alignment procedure in ServiceLine.
E-Stop LoopSafety circuit connecting all E-stop buttons in series — any single triggered button disables the entire patient handling systemIf E-stop circuit is open (triggered or wiring fault), table is completely disabled. Wiring fault in loop = all buttons appear triggered.

Horizontal Drive Replacement Reference (Avanto / Espree)

The Avanto and Espree share a similar MDSD (Modular Drive System for Docking) horizontal drive assembly. Replacement procedure documented in Siemens service document "Avanto-Espree MDSD horizontal drive replacement procedure."
StepNotes
1. System lockout / tagoutDe-energize patient handling system. System must be in service mode with table power isolated.
2. Remove cradle from table baseDisconnect all coil cables and patient handgrip. Slide cradle off table base following service manual.
3. Access drive assemblyRemove table side panels to access the longitudinal drive motor and belt assembly under the cradle track.
4. Belt inspection / replacementCheck belt tension and condition. Replacement belt must be OEM-specified — belt length and tooth pitch are critical for accurate positioning.
5. Re-assembly and calibrationAfter drive replacement, run position calibration from ServiceLine to re-teach all soft limits and docking positions.

Tip: STE (System Emergency Stop) clearing after a reset but immediately re-triggering usually means either a wiring fault in the E-stop loop (opens intermittently) or a software-initiated E-stop from an active system fault. Check ServiceLine error log for the fault code that preceded the STE — it will tell you if it was hardware button or software-generated.
Tip: Siemens table docking alignment shifts over time, especially on sites that frequently undock for patient transfers. If table reports docking errors that clear with minor repositioning, re-run the docking calibration procedure from ServiceLine to re-teach the docked position.
