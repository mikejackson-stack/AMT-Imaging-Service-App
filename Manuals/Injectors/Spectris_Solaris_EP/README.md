# Medrad Spectris Solaris EP MR Injection System

**Catalog Code:** DCB-SMRS  
**Manufacturer:** Bayer/Medrad  
**MR Safety:** MR-Conditional at 1.5T and 3.0T  
**⚠️ ONLY Bayer/Medrad injector approved for use INSIDE the MRI scan room**

## System Overview
Dual-head MR-safe contrast injector. Drive unit in scan room, control unit in control room. Communication via fiber optic cable.

## MR Safety — Critical Rules
- Keep drive unit minimum 1.5 m from isocenter
- NEVER bring control unit into scan room
- Verify MR-Conditional label before EVERY use
- Inspect fiber optic cable before every use — no sharp bends
- Use only Spectris Solaris EP syringes — NOT interchangeable with Stellant

## Error Messages
| Error | Cause | Action |
|-------|-------|--------|
| COMM ERROR | Fiber optic cable fault | Inspect full length; clean connectors; replace if damaged |
| SYRINGE NOT DETECTED | Syringe not seated or sensor fault | Remove/reseat; clean sensor; try new syringe |
| PRESSURE LIMIT | Pressure exceeded | Reduce flow; check IV site |
| AIR DETECTED | Air in line | Reprime completely |
| DRIVE FAULT | Motor error | Power cycle; self-test |
| LOW BATTERY | Battery below 20% | Connect AC power; charge minimum 30 min |

## Annual PM Checklist
- [ ] MR-Conditional label — present and legible
- [ ] Serial number matches facility asset record
- [ ] Fiber optic cable full length — no kinks, pinch points
- [ ] Fiber optic connectors cleaned with IPA swab
- [ ] Syringe port and sensor window inspected/cleaned
- [ ] Battery compartment — no leakage
- [ ] Test syringe load — "Syringe Detected" displayed
- [ ] Full plunger stroke — smooth, no binding
- [ ] Plunger tip seal — no cracks or wear
- [ ] Power on from battery — charge level 80%+
- [ ] AC adapter — charging indicator verified
- [ ] Fiber optic to control unit — communication established
- [ ] System self-test — all pass
- [ ] Flow rate test: 1 ml/sec and 5 ml/sec
- [ ] Pressure alarm at set threshold
- [ ] Air detector triggered with test bubble
- [ ] Battery runtime test — ~4% per 10 minutes
- [ ] Service report to MRI and HTM departments
