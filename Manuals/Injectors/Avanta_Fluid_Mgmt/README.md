# Medrad Avanta Fluid Management Injection System

**Catalog Code:** DCB-AVT  
**Manufacturer:** Bayer/Medrad  
**Application:** Automated contrast fluid management for high-throughput CT suites  

## System Overview
Multi-bottle contrast management and delivery system. Manages automated fill cycles, dual-head injection (A: contrast, B: saline), and inventory tracking.

## Common Issues
| Issue | Cause | Action |
|-------|-------|--------|
| Fill cycle fails | Bottle connection not sealed | Reseat bottle; check spike |
| Air in system | Air during bottle change | Run extended prime cycle |
| Incorrect dose | Flow calibration drift | Run flow calibration |
| Inventory alarm | Bottle below threshold | Replace bottle; update inventory |
| Pump motor noise | Worn pump head | Inspect; replace if bearing noise |

## Annual PM Requirements
1. All tubing inspection — no kinks, cracks, discoloration
2. Check valve inspection — verify one-way function
3. Bottle spike and connection port inspection
4. Pump head O-ring and seal inspection
5. Flow calibration (A and B heads)
6. Full fill cycle test — no errors
7. Auto-prime function verified
8. Pressure alarm test
9. Air detection test
10. Warming system calibration (if installed) — 37°C setpoint
11. Inventory tracking accuracy verified
12. Emergency stop test

## Tubing Replacement Schedule
- Patient-side disposable: single-use per procedure
- System-side permanent tubing: inspect annually; replace every 2 years
- Check valves: inspect annually; replace every 2 years or if backflow detected
