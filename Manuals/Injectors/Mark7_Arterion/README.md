# Medrad Mark 7 Arterion Angiography Injection System

**Catalog Code:** DCB-ART 700  
**Manufacturer:** Bayer/Medrad  
**Application:** High-pressure angiographic injection for cardiovascular and interventional radiology  
**⚠️ NOT MR-Compatible — CT/Angio use ONLY**

## Key Specifications
- Maximum injection pressure: 1200 PSI (82.7 bar)
- Maximum flow rate: 30 ml/sec
- Syringe sizes: 60 ml, 130 ml, 200 ml
- Display: Integrated touchscreen with protocol management

## Error Messages
| Error | Cause | Action |
|-------|-------|--------|
| SYRINGE NOT LOADED | Syringe not locked in cradle | Remove and reseat until latches engage |
| PRESSURE LIMIT EXCEEDED | Line occlusion or PSI limit too low | Check catheter; verify PSI for procedure |
| DRIVE FAULT | Motor/encoder error | Power cycle; self-test; inspect drive |
| COMM ERROR | Console/cradle communication loss | Check interface cable; reboot both |
| FILL ERROR | Auto-fill fault | Check contrast connection; verify fill line primed |
| TEMPERATURE FAULT | Contrast warmer error | Check warmer setpoint; inspect heater element |

## Annual PM Requirements
1. Syringe cradle inspection and cleaning
2. Drive mechanism inspection — Bayer-approved lubricant only
3. Plunger seal O-ring inspection and replacement
4. Check valve inspection — verify one-way function
5. Pressure transducer calibration (critical — PSI accuracy)
6. Auto-fill system inspection and test
7. Contrast warmer calibration — verified at setpoint
8. High-pressure tubing inspection — replace if discolored/stiff
9. All error alarms verified functional
10. Service report to HTM/Biomedical

## Parts (OEM Only — High Pressure Rated)
- Plunger O-ring set (critical for 1200 PSI)
- Check valve assembly
- Pressure transducer
- 60 ml / 130 ml / 200 ml Arterion syringes — HIGH PRESSURE RATED, single-use
- High-pressure tubing set — 1200 PSI rated
