# Medrad MRXperion MR Injection System

**Catalog Code:** DCB-MRXP  
**Manufacturer:** Bayer/Medrad  
**MR Safety:** MR-Conditional at 1.5T and 3.0T  
**PSC Code:** J065  

## System Overview
The Medrad MRXperion is a dedicated dual-head MR injection system for use in or adjacent to the MRI suite. Controlled via Certegra workstation.

## Key Specifications
- Maximum flow rate: 10 ml/sec (contrast), 10 ml/sec (saline)
- Maximum pressure: 325 PSI
- Syringe volumes: 65 ml, 115 ml, 200 ml
- MR Conditions of Use: must be followed per site-specific MR safety documentation

## Common Error Codes
| Code | Meaning | Action |
|------|---------|--------|
| HEAD COMM FAULT | Communication between head and workstation lost | Check cables; reboot Certegra first, then head |
| SYRINGE ERROR | Syringe not detected or incorrect | Reseat syringe; clean sensor; try sealed new syringe |
| PRESSURE FAULT | Injection pressure exceeded limit | Check IV site; reduce flow rate |
| AIR IN LINE | Air detected in fluid path | Reprime system completely |
| MOTOR FAULT | Drive motor error | Power cycle; run self-test |

## Annual PM Requirements
1. Visual inspection of head, cables, fiber optic connections
2. Syringe detection verification (both heads)
3. Plunger seal inspection and replacement if needed
4. Flow rate calibration at 1, 3, 5 ml/sec
5. Pressure transducer calibration
6. Air detector function test
7. Software version documentation
8. System self-test — all tests pass
9. Service report to HTM/Biomedical Engineering
