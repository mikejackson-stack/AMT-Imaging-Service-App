Key Safety Features

  • Disposable fluid path — single patient use, eliminates cross-contamination
  • Automatic air detection — halts injection if air is detected in line
  • Pressure monitoring — programmable pressure limit halts injection on over-pressure
  • Volume accuracy monitoring — real-time flow rate and volume tracking
  • Voice prompts for workflow confirmation

Common Alarms & Error Messages

Message / AlarmLikely CauseResolution
Pressure Limit ExceededIV occlusion, kinked line, small-gauge catheter, thick contrastCheck IV line and catheter. Reduce flow rate or increase pressure limit if clinically appropriate. Warm contrast.
Air Detected in LineAir bubble in contrast line or syringe not fully primedRe-prime line. Inspect fluid path for air entry points. Replace fluid path if air source not identified.
Fluid Path Not DetectedSingle-use set not properly installed or recognizedRemove and reinstall single-use set. Verify correct set type for this injector model. Inspect connector pins.
Piston ErrorPiston drive fault or obstructionCheck for mechanical obstruction. Power cycle. If fault persists, piston drive assembly replacement required.
Communication ErrorRemote control / head communication faultCheck cable/wireless connection. Power cycle both units. Re-pair if wireless model.
Low VolumeInsufficient contrast for programmed protocolReplace contrast container/syringe before injecting.
Temperature WarningContrast warmer above or below specVerify warmer set point (~37°C). Inspect thermostat. Allow system to stabilize before injecting.
System Error (code displayed)Internal fault — board, sensor, or motorRecord error code. Power cycle. If error persists, contact Bracco service: 1-877-272-2269.

PM Tips (Annual / Semi-Annual)

TaskNotes
Inspect piston drive mechanismCheck for wear, corrosion, or fluid contamination
Clean fluid path connectorsUse approved cleaning agents only; inspect O-rings
Inspect touchscreen and remote unitClean display; verify all buttons responsive
Test air detection sensorVerify alarm activates on simulated air bubble
Test pressure limitVerify pressure alarm activates at set limit
Volume accuracy testDeliver test volume, verify ±1 ml accuracy
Inspect mounting hardwareVerify all bolts secure; arm pivot moves smoothly
Electrical safetyPer IEC 60601 and facility requirements
Software version checkConfirm current software version; apply updates if available
Tip: The EmpowerCTA+ uses a single-use fluid path, so most "contamination-related" pressure events are IV-line or patient-access issues rather than injector hardware problems. Focus troubleshooting on the IV site first.
Tip: Air detection alarms on the EmpowerCTA+ are sensitive and reliable. If triggering frequently, verify the priming protocol is being followed by clinical staff — this is the most common cause.
Warning: Never attempt to reuse a single-use fluid path set. Doing so voids the device warranty and creates a patient safety risk.
Warning: This is a CT-only injector. NOT MR-conditional. Do not bring into the MRI scan room.
