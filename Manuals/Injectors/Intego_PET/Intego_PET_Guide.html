Error Messages

ErrorCauseAction
PUMP FAULTMotor or encoder errorEnsure no radioactive material loaded. Power cycle. Check tubing for kinks. Run self-test.
DOSE CALIBRATOR COMMInterface cable fault or calibrator offlineCheck interface cable at both ends. Verify calibrator is powered and online.
TEMP OUT OF RANGESystem temperature faultCheck ambient temperature (15-30°C). Allow warm-up time. Inspect temperature sensor.
FLOW DEVIATIONPump calibration drift or tubing issueCheck tubing for kinks. Run gravimetric flow calibration.
FILTER OCCLUDEDInline filter blockedReplace inline filter per procedure protocol. Do not bypass filter.
DOSE CAL ERRORActivity measurement outside expected rangeVerify calibrator calibration. Check syringe position. Confirm tracer lot and concentration.

Annual PM Checklist

Coordinate with Nuclear Medicine department and RSO before starting PM. Obtain written RSO clearance.
#TaskAcceptance
1RSO clearance documentation obtainedWritten clearance in hand before any work begins
2Radiation shielding integrity — no cracks or gapsVisual inspection; no damage to shield housing
3All seals on shielding housingNo breach; any gap reported to RSO immediately
4Pump head inspection: drive mechanism, O-rings, tubing portsNo wear, cracking, or contamination
5Flow rate calibration — gravimetric methodDelivered rate within ±5% of set rate
6Dose calibrator interface communication verifiedCalibrator data appears on console without errors
7All alarms and fault conditions testedEach alarm triggers correctly; audible and visual
8Inline filter and tubing connections inspectedNo blockage, cracking, or leakage points
9Software version and audit log verifiedAudit log accessible; software version documented
10Emergency stop function testedE-stop halts all pump activity immediately
11Service report completed with RSO sign-offSigned by tech and RSO; delivered to Nuclear Medicine
Important: All waste materials from PM must be handled per radioactive materials disposal protocol. Service records must include RSO documentation of radiation safety clearance.
