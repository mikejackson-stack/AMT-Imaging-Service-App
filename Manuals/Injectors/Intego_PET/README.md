# Medrad Intego PET Infusion System

**Catalog Code:** DCB-INTG  
**Manufacturer:** Bayer/Medrad  
**Application:** PET (Positron Emission Tomography) radiopharmaceutical delivery  

## ⚠️ RADIATION SAFETY
This system handles **radioactive PET tracers (FDG etc.).**  
- Never service while radioactive material is loaded
- Obtain RSO clearance before ALL maintenance
- All waste handled per radioactive materials protocol
- Radiation shielding integrity MUST be verified at every PM

## System Overview
Radiation-shielded automated injection system for PET radiopharmaceutical administration. Includes integrated dose calibrator interface and automated dosimetry tracking.

## Common Fault Messages
| Fault | Cause | Action |
|-------|-------|--------|
| PUMP FAULT | Motor/encoder error | Power cycle; verify tubing clear; self-test |
| DOSE CALIBRATOR COMM | Interface cable/calibrator offline | Check cable; verify calibrator powered |
| FLOW DEVIATION | Pump calibration drift | Run gravimetric calibration |
| FILTER OCCLUDED | Inline filter blocked | Replace filter per procedure |

## Annual PM Requirements (Coordinate with Nuclear Medicine & RSO)
1. RSO clearance obtained before start
2. Radiation shielding integrity — no cracks or gaps
3. Pump head inspection: drive mechanism, O-rings, tubing ports
4. Flow rate calibration — gravimetric method
5. Dose calibrator interface communication verified
6. All alarms and fault conditions tested
7. Emergency stop function test
8. Software version and audit log verified
9. Service report signed by RSO
