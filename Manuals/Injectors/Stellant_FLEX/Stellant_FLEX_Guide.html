Error Code Reference

CodeDescriptionAction
3016Plunger or motor sync failureCheck plunger alignment. Run self-test from Certegra. Inspect drive mechanism. Replace drive motor if persists.
867Syringe size sensor / detection faultClean sensor window with dry lint-free cloth. Reseat syringe until click. Inspect flex ring contacts for contamination. Try new sealed syringe.
2115Calibration or limit switch issueRun calibration from Certegra service menu. Inspect limit switch for debris or misalignment.
2212Drive stall or plunger stuckCheck for obstruction. Manually retract plunger via service menu. Inspect drive screw for damage.
1001Communication / data transfer errorCheck ISI cable at both ends. Reboot Certegra. Inspect serial port on head.
1010Pressure limit exceeded / transducer faultVerify IV site patent. Check pressure transducer calibration. Inspect high-pressure tubing.
1022Air detection sensor triggeredPrime both heads completely. Inspect air detector. Check syringe seating.
1050Flow rate deviation / blockageCheck IV catheter patency. Inspect tubing for kink. Verify syringe fully seated.
4001System initialization / startup failurePower cycle. Verify power supply voltages. Run system self-test from Certegra.
Invalid SyringeSyringe not recognized (most common error)1) Clean sensor window. 2) Reseat syringe until click. 3) Try sealed new syringe. 4) Inspect flex ring contacts. 5) Check syringe well for deformation.
White Screen / MEDRAD StuckCommunication or software faultPower off head and Certegra. Disconnect cables, wait 30 sec. Power Certegra first, then head. If persists, reload Certegra software.
