# Medrad Stellant FLEX CT Injection System

**Catalog Code:** DCB-FLEX  
**Manufacturer:** Bayer/Medrad  
**Application:** CT contrast injection — dual head (A: contrast, B: saline)  
**Workstation:** Certegra  

## System Overview
The Stellant FLEX is the most widely deployed VA CT injector. Dual-head design with Certegra touchscreen workstation. Used across all VISN 23 facilities.

## Error Code Quick Reference
| Code | Description | Action |
|------|-------------|--------|
| 3016 | Plunger/motor sync failure | Check alignment; self-test; replace drive motor if persists |
| 867 | Syringe sensor/detection fault | Clean sensor window; reseat syringe; inspect flex ring |
| 2115 | Calibration/limit switch issue | Run calibration from service menu |
| 2212 | Drive stall or plunger stuck | Check obstruction; manually retract; inspect drive screw |
| 1001 | Communication/data error | Check Certegra cable; reboot workstation |
| 1010 | Pressure limit/transducer fault | Verify IV site; check transducer; inspect tubing |
| 1022 | Air detection triggered | Prime both heads; inspect air detector |
| 1050 | Flow deviation/blockage | Check IV catheter; verify no kink; reseat syringe |
| 4001 | Initialization/startup failure | Power cycle; verify power; run self-test |

## Annual PM Checklist
- [ ] Power cord and inlet inspection
- [ ] Head mounting arm — no wobble
- [ ] High-pressure tubing — no cracks or kinks
- [ ] Syringe wells (A and B) — clean, no damage
- [ ] Sensor windows — clean with dry lint-free cloth
- [ ] Flex ring contacts — no corrosion
- [ ] Drive screws — no pitting or contamination
- [ ] Test syringe load — "syringe detected" both heads
- [ ] Full plunger stroke — smooth, no binding
- [ ] Plunger home position verified
- [ ] Plunger tip seals — no cracks
- [ ] System self-test — all pass
- [ ] Air detector function test
- [ ] Pressure transducer calibration
- [ ] Flow rate test: 1 ml/sec and max protocol rate
- [ ] Software version documented
- [ ] Event log reviewed — no recurring errors
- [ ] All protocols verified intact
- [ ] Service report to HTM/Biomedical

## Certegra Software Requirements (per VISN 23 Contract)
