Table Top Height Adjustment

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Dock Patient Table.

  1. Use Up Foot pedal to raise Patient Table to Full Up position and move the cradle completely into the magnet bore to expose the table top height adjustment screw. See Illustration 1.

  1. Use a standard head screw driver to remove the cover plug.

  1. Adjust screw to set table top height equal to bridge height.

    Illustration 1:  Table Top Height Adjustment Screw Location

  1. Replace the cover plug.
