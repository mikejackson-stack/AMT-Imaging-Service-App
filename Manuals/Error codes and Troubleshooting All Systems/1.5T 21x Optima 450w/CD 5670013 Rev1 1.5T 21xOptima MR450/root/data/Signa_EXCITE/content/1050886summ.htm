ReportCARD 4 Install and Service

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEffectivity

If ReportCARD is not already loaded on the system or a valid license key is unavailable, you can generate the software key through elicense using the Global Order Number (GON). Contact the Advantage Workstation Online Center for assistance generating the key.

-

2  Procedure

2.1   Installing ReportCARD 4

  1. Log in to the Advantage Workstation (AW): login name: sdc, password: adw4.x, where x represents the version of AW that you are working on.

  1. Insert the ReportCARD 4 CD into the AW drive.

  1. When the AW displays, click on [Admin] in the bottom left of the Patient List. A menu of the available applications opens. See Illustration 1.

    (Step Details)

  1. Select Install Package. The Easy Install window opens.

    (Step Details)

  1. From the Driver menu, select CDRom.

  1. Click [Contents], and then click [Install] to start the installation process.

  1. The ReportCARD Installation dialog box displays, and asks you to enter the software protection license key.

    (Step Details)

  1. Click [OK] to install ReportCARD 4.

    (Step Details)

  1. Click [Eject CDRom] to remove the CD, and then click [Quit].

  1. When the information dialog box displays, click [OK], and proceed with restarting the system.

    Illustration 5:  Restart Dialog Box

  1. To restart the system, click [System], and select Restart Software.

    Illustration 6:  System Menu Restart

    (Step Details)

2.2   Confirming the Installation

  1. Click on [Admin] as shown in Illustration 1, and select Display Configuration.

    (Step Details)

  1. In the Advantage Workstation window, select any data set.

  1. From the left navigation menu, select ReportCARD.

    (Step Details)

  1. From the Edit menu, select Preferences.

    (Step Details)

  1. From the File menu in the ReportCARD window, select Quit to exit the application.
