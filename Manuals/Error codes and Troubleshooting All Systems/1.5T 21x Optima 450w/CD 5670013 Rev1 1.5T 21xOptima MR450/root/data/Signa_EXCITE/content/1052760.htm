2  Purpose

The test set exercises the built-in self-tests which check the internal functionality of the board.

3  Components Tested

Applications Gateway Processor (AGP) board

4  Requirements

Minimum Combined ASC MGD (CAM) chassis with AGP board. The CAM chassis includes the amplifier support chassis (ASC) and the multi-generational data acquisition (MGD) components.

5  Test Sequence

NOTE:This test takes several minutes to complete.

  1. The host resets the AGP board to the power PC (PPC) diagnostic mode through the serial port.

  2. The host sends diagnostic commands to the board to invoke the built-in Motorola self-tests.

  3. The host parses the test status sent back from the boards and determines if the test passed or failed.

6  Expected Results

The diagnostic returns a PASS or FAIL result.
