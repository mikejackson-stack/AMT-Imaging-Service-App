From this page select how you want to pull information from the RIS system. The Get Patient List options are:

  1. Enter a patient Name, Patient ID, Accession Number, or Procedure ID to define the search.

  2. Selecting This System, which pulls the patient lists entered for this system.

  3. Selecting This Modality pulls the patient list for all MR systems at this facility.

  4. Selecting All Modalities pulls the patient list for all systems associated with this facility. Using this option may cause the scanner to hang if the facility has too large of Work List for all scanners at the site.

  5. Selecting Date Range pulls patient lists for any set day or date range.
