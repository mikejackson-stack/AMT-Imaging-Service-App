I/O Status

1  Diagnostic Link

Diagnostics >> System Function >> RF >> Driver Module Diagnostics

Diagnostics >> Hardware Location >> Pen Panel Cabinet >> Driver Module Diagnostics

Illustration 1:  Driver Module Diagnostics

2  Purpose

The test will display:

  • Multi_Coil Switch (always blue)

  • Dynamic Drive Switch

  • T/R Switch

  • Power Status (always blue)

  • High Speed Cable (always blue)

  • Front Panel Interface

  • Un-Blank Cable

  • Un-Blank Harness

  • High Voltage Switch

  • Fan 1

  • Fan 2

  • MCD 1 (always blue)

  • MCD2 (always blue)

  • TR/DD

  • MCD1 Cable (always blue)

  • MCD2 Cable (always blue)

  • Head Overtemp

  • Body Overtemp

  • MNS Overtemp

  • CAN Board

  • CAN ISO 5 Volts

  • CAN Flash 5 Volts

  • DCB Reset State

3  Components Tested

Driver Module

4  Requirements

None

5  Test Sequence

  1. Select I/O Status from the Driver Module Diagnostics screen.

  2. Click [Run].

  3. Based on the color of the result, the test result will either display a pass or fail.

6  Expected Results

Review the Test Results section to see if the diagnostic passed or failed. If the diagnostic failed, review the extended error messages for subsequent actions.

  • # Blue = Normal Result

  • #Red = Error
