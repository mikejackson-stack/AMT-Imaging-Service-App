NOTE:Use Step 1 in the right column as the first step for all Recommendations in this table.

  1. See the NOTE in the first row of this table.
  2. Verify that phantom is approximately in the center of the bore when scanning by visually checking position.

  1. See NOTE in the first row of this table.
  2. Check Laser Light Alignment. Make sure the axial alignment light is aimed straight down and lines up with the crosshairs on the DQA III phantom.
  3. Check that the iso-center Z value is close to the default for the magnet type. Verify proper magnet and magnet cover options are properly set in MR config file.

  1. See NOTE in the first row of this table.

Phantom appears to be rotated 16 degrees about the physical Z axis.
  1. See NOTE in the first row of this table.
  2. Visually inspect phantom in the head coil. Verify that the phantom is not rotated. A positive rotation value indicates that the phantom is rotated counterclockwise around the Z axis. The phantom needs to be rotated clockwise to correct the situation. Do not misalign phantom when repositioning.
  3. If a positive value is observed for phantom rotation about the physical Z axis, rotate the phantom clockwise in the XY plane when viewing from the front of the magnet. Do not misalign phantom when repositioning. See Illustration 8.
Phantom center appears to be offset 20 mm along physical X.
  1. See NOTE in the first row of this table.
  2. Verify that the phantom is not offset along physical X.
  3. If a positive value is observed for phantom position in X direction, move the phantom to the left (when viewing from the front). Do not misalign the phantom when repositioning. See Illustration 8.
Phantom center appears to be offset 20 mm along physical Y.
  1. See NOTE in the first row of this table.
  2. Verify that the phantom is not offset along physical Y.
  3. If a positive value is observed for phantom position in Y direction, move the phantom down (when viewing from the front). Do not misalign the phantom when repositioning. See Illustration 8.
Z gradient polarity appears to be inverted.
  1. See NOTE in the first row of this table.
  2. Review the most recent DQA exam via the image browser. Take action based on the condition that follows:
    • If the latest exam has its image labeled “Coronal”, check to see if that image looks like (regarding shape and position of phantom features) the Coronal sample image shown in Illustration 7.
      1. If the image looks like the Coronal example (even if degraded via low SNR, ghosting, distortion, etc.), suboptimal image quality may have confused the DQA II tool and the IQ-related issues must be resolved before running DQA II calibration.
      2. If the acquired Coronal image does not look like the Coronal image example, there is probably a gradient wiring/setup problem. Proceed to the next step to track that down.
    • If the latest exam has its image(s) labeled “Axial”, the tool has made an early detection of a Z gradient polarity problem from the set of multi-slice images. Check to see if the central bar feature (arrow in Illustration 6) moves toward the resolution comb feature as the slice location moves from Inferior to Superior.
      1. If it does, the Z gradient is most likely polarity flipped. Proceed to the next step to track that down.
      2. If the bar moves away from the resolution comb feature, the suboptimal image quality may have confused the DQA II tool and the IQ-related issues must be resolved before running DQA II calibration.
  3. If error is attributed to Gradient cabling, refer to Discovery MR450w Installation manual (Direction 5670002), Section 4-5, Gradient Cable Installation.
Phantom appears to be rotated 16 degrees about the physical Y axis.
  1. See NOTE in the first row of this table.
  2. Visually inspect phantom in the head coil. Verify that the phantom is not rotated.
  3. If a positive value is observed for phantom rotation about the physical Y axis, rotate the phantom clockwise in the XZ plane when viewing the phantom from above the table. Do not misalign phantom when repositioning.
