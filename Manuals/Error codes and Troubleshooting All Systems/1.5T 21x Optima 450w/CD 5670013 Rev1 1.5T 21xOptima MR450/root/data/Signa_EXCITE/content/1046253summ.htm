3  Procedure

3.1   Body UPM Functional Check

3.1.1  Body UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection. See Step . Ensure Switches SW2 and SW3 are in their respective Disable positions.

    (Step Details)

  1. Place the RF ENABLE switch on front of exciter in the DISABLE (Down) position.

  1. Install the dummy load.

    1. Remove the Body Heliax cable from the service panel in the PGR Cabinet / J21.

    1. Connect either the 35 KW Dummy Load or the 1.5T Dummy Load to J21 of the RF amplifier. If the 35 KW Dummy Load is used, the fan must be on.

      (Step Details)

  1. Place the RF ENABLE switch in the ENABLE (Up) position.

3.1.2  Setting up Software Tool to Functional Check UPM - Body Channel Functional Check

  1. On the scanner operator control panel (OCP) press [Align on].

  1. Move the cradle to place the Laser alignment light on the center of the table.

  1. Press Landmark.

  1. Press Advance to Scan.

  1. Start the UPM tool:

    1. In proprietary mode, [Click here to start tool] from the Calibration tab.

    1. For the Class A service tool:

      1. From the Common Service Desktop, select the Calibration Tab.

      1. Select the [UPM Tool] from the calibration menu and select [Click here to start this tool].

      1. Step  shows an example of the UPM tool.

        (Step Details)

  1. For Nuclei select [1H].

  1. For RF Chain select [Body].

  1. Select [Func Chk].

    (Step Details)

  1. Select the [Start] button then click [YES] in answer to the setup question.

    (Step Details)

  1. After that the tool takes full control and runs the 1.5T 10 second average power test and RF inhibit for Body. The result of the test is compared against a Specification File on the system. The status should indicate PASS or FAIL for each check.

  1. The user will be prompted during test execution. The following illustrations show an example of the pop up and error log that should be seen. Verify the error log and click [Yes] if an error message is seen.

    (Step Details)

  1. To proceed if the test passes:

    1. Switch RF ENABLE to the Disable (down) position.

    1. Disconnect BODY RF OUT / J21 cable.

    1. Connect transmit line to J21.

    1. Switch SW2 and SW3 to the Enable (up) position.

    1. Switch RF ENABLE to the Enable (up) position

    1. Proceed to Head UPM Functional Check. See Step 

3.2   Head UPM Functional Check

3.2.1  Head UPM Functional Check Setup

  1. Inhibit TR and DD faults. Disable the Driver Module TR and DD fault detection in the Pen Cabinet, see Step . Ensure switches SW2 and SW3 are in the TR DISABLE and DD DISABLE positions.

    (Step Details)

  1. Switch RF ENABLE on front of the exciter to the Disable (down) position.

  1. Install the dummy load.

    (Step Details)

3.2.2  Setting up Software Tool to Calibrate UPM - Head Forward Power

  1. Place the head coil and connect it to the LPCA.

  1. Landmark on the cradle where the head coil is.

  1. On the operator control panel (OCP) press Advance to Scan.

  1. Refer to Step  to start the Service browser.

  1. For Nuclei select [1H].

  1. For RF Chain select [Head].

  1. Select the [Func Chk] button.

  1. Select the [Start] button.

  1. On the Head Coil Setup OK screen, click [Yes] when the head coil is ready to go.

    (Step Details)

  1. After that the tool takes full control and runs the functional test. The UPM status should indicate Pass or Fail.

  1. The user will be prompted during test execution. Look in the error log to confirm that the test completed successfully, and a trip error occurred. Step  and Step  above show an example of the pop up and error log that should be seen.

  1. To proceed:

    1. If the test passes, select [Quit] from the UPM Main Window.

    1. If the test fails, refer to Step .

3.3   Troubleshooting UPM

  1. Solution 1:

    1. Check all cabling to the UPM-Boards to make sure that they are properly cabled. Be aware that while the UPM Processor Board will illuminate the Inhibit LED for cables that are an open circuit, it will function the same for cables that are terminated in a short circuit.

    1. Repeat the UPM Functional Test (Head or Body).

  1. Solution 2: Recheck RF Amp output

    1. Cycle Power to the UPM Chassis.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (Head or Body).

  1. Solution 3: Reboot the system. Repeat the UPM Functional Test (Head or Body).

  1. Solution 4:

    1. Remove power from the UPM.

    1. Re-seat the Processor Module.

    1. Restore Power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (Head or Body).

  1. Solution 5:

    1. Remove power from the UPM.

    1. Reset the Detector Boards.

    1. Restore Power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (Head or Body).

  1. Solution 6: The problem could be a bad Processor Module

    1. Remove power from the UPM.

    1. Replace the Processor Module.

    1. Restore Power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test (Head or Body)

  1. Solution 7: The problem could be a bad Detector Board

    1. Remove power from the UPM.

    1. Replace both Detector Boards.

    1. Restore Power to the UPM.

    1. Reset TPS.

    1. Repeat the UPM Functional Test for the Receive chain that failed (Head or Body).

3.4   UPM Theory

The Universal Power Monitor calibration parameters found in the UPM Calibration file (/export/home/signa/tools/upm/upm.config) are used in the calibration/Functional Check program. This calibration file is accessible from within the UPM Calibration tool from the File pull-down Menu, Edit Config option. These values can be edited and saved during troubleshooting to perhaps understand where the power monitor is tripping, (If at all). Before changing any parameter, make sure to select and run the Bkup UPM Cal option first. This will allow you to return to the default values at any time. The screen shot of the UPM Calibration file shown in Step  contains the default configuration values for all of the UPM parameters. This screen is just for reference, as the content and values will be different based on the system type and calibration results. (Use the [Restore Defaults] on the config file editor GUI (graphic user interface) to always get back to known default values). The final UPM digital attenuator values are written to the UPM Calibration Configuration files (Upm1Cal.cfg, Upm2Cal.cfg.etc.,) located in directory: w/config

NOTE:Items with an * (asterisk) indicate a non-zero hex value based on calibration.

  1. The format of Upm1Cal.cfg and Upm2Cal.cfg example is as follows:

    1. *←Head FORWARD Power, attenuator setting in HEX

      (Step Details)

    1. 0←Head REFLECTED Power, attenuator setting in HEX

    1. 0← Head Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. *← Body FORWARD Power, attenuator setting in HEX

    1. 0←Body REFLECTED Power, attenuator setting in HEX

    1. 0←Body Quad Hybrid Reflected Power, attenuator setting in HEX

    1. 0←MNS FORWARD Power, attenuator setting in HEX

    1. 0←MNS REFLECTED Power, attenuator setting in HEX

    1. 0 ← MNS Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

    1. 0 ←CW FORWARD Power, attenuator setting in HEX (currently not used)

    1. 0←CW REFLECTED Power, attenuator setting in HEX (currently not used)

    1. 0←CW Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)

  1. See Step . Any changes to these values are temporary and can be quickly restored by selecting the restore defaults button.

    (Step Details)

4  Finalization

  1. Switch RF ENABLE on front of exciter to the Disable (down) position.

  1. Remove the cables and measurement equipment.

  1. Reattach the Head and Body heliax cables.

  1. To re-enable fault detection, set switch SW2 and SW3 to their respective Enable positions.

  1. Switch RF ENable on the front of the exciter to the Enable (up) position.

  1. Complete a TPS reset and do a test scan.

  1. Any failure after Troubleshooting is complete will require a re-calibration of the UPM system. See Universal Power Monitor - Head and Body Setup and Calibration.
