Magnet Enclosure Button Test

1  Diagnostic Link

Diagnostics >> System Function >> Patient Handling >> SRI Functional Tests

Diagnostics >> Hardware Location >> Magnet Room >> SRI Functional Tests

Illustration 1:  SRI Functional Tests Screen

2  Purpose

This test verifies the proper operation of the Operator Control Panel buttons on the front of the magnet enclosure.

NOTE:Possible equipment shutdown. Do not press the [Emergency Stop] buttons on the Display Panel during this test. The [Emergency Stop] buttons are not disabled during the test, and will shut down all cabinets that provide power to the magnet room.

3  Components Tested

  • Magnet Enclosure Operator Control Buttons Codes

  • In-Room Monitor Operator Control Buttons Codes

4  Requirements

None

5  Test Sequence

CAUTION
Possible Equipment Shutdown
Do not press Emergency Stop buttons on the Display Panel during this test.
The Emergency Stop buttons are not disabled during the test. Pressing the top, outer Emergency Stop buttons (Illustration 3) will shut down all cabinets that provide power to the magnet room.

5.1  Version with In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button and verify that the display on the Host Computer within the Service Browser corresponds to the button descriptions (see Illustration 2).

    NOTE:The three long buttons surrounding the elliptical operator do not display a response on the host computer when pressed. (These are the mouse buttons for the trackball.)

    Illustration 2:  In-Room Display Operator Panel

    Illustration 3:  Emergency Stop

6  Test Sequence

CAUTION
Possible Equipment Shutdown
Do not press Emergency Stop buttons on the Display Panel during this test.
The Emergency Stop buttons are not disabled during the test. Pressing the top, outer Emergency Stop buttons (see below) will down all cabinets that provide power to the magnet room.

6.1  Version with In-Room Display

  1. Select [Magnet Enclosure Button Test].

  2. Click [Run].

  3. Press each button and verify that the display on the Host Computer within the Service Browser corresponds to the button descriptions. See Illustration 4.

    NOTE:The three long buttons surrounding the elliptical operator do not display a response on the host computer when pressed.

    Illustration 4:  In-Room Display Operator Panel

    Illustration 5:  Emergency Stop

  4. Repeat for the second control panel.

8  Troubleshooting

If one control panel fails, it is likely there is a problem with the control panel.

If both control panels fail, it is likely there is a problem with the cabling from the SRI or with the SRI itself.
