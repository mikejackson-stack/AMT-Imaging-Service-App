4.3  VRE Configuration for Software Releases Pre-15.0_M4B

Load VRE software as follows:

  1. Go into Guided Install and select Configure VRE as shown below.

    Illustration 32:  Configuring VREs

  1. Verify that the VRE blades are properly installed and all hardware connections are in place, including Ethernet connections.

    NOTE:Either Dedicated Computing 5127452 ICNs or Sun 4100 5127452-3 ICNs will be installed. A combination of the hardware types will not work on the system and should not be present.

  1. Click [Configure VRE Blades].

  1. Select the proper number of ICNs (1, 2 or 4), as follows:

    • When Sun 4100 5127452-3 ICNs are installed, choose 1 ICN or 2 ICN.

  1. This procedure takes 15-20 minutes to complete, depending on the number of ICN blades in the system.

4.5  Term Server Reset - All Software Releases

  1. If this is the first or initial software load, perform the Term Server Reset Procedure by executing the following steps:

    1. Remove power connector from Term Server.

    1. Press and hold the small square button labeled Reset next to power jack.

    1. Connect power to Term Server, while continuing to hold Reset button.

    1. Continue to hold Reset button for 20 seconds.

      NOTE:If communication problems between Linux PC and Term Server are perceived, you can ping the Term Server as follows:

      1. Open C-shell

      2. Type cd /etc<enter>

      3. Type more hosts<enter>

      4. Ping the ts1 address by typing ping X.X.X.7<enter> (where X.X.X. is the TPS Subnet address).

        You should see proper communication.

        The Term Server might need to be reset several times in order to establish communication with the Linux PC.

      5. To stop the ping, type ^c

NOTICE
If the system will not properly boot on the first attempt, the Term Server may need to be reset. Perform the Term Server reset procedure in Step 1.
 
 

  1. Exit the Guided Install screen by selecting File, then Quit.

4.6  Loading Restricted Service Software - All Software Releases

NOTE:For loading options, previous option keys are restored using RestoreInfo. If new options were purchased, refer to 2397845 Signa Software Option Install with eLicense.

NOTE:Shut down the software before attempting to load the Restricted Service or Advanced Service CDs. Do not load these CDs while Applications software is running.

  1. Reboot the system by selecting [Desktop] on top left corner of monitor, then [Logout], then [Restart the computer], then [OK].

  1. Log in to the system as root with password of operator, and load Restricted or Advanced Software if applicable.

  1. Click [Yes] to start the Guided Install.

  1. Remove the APPS CD and insert the Service Software CD. Click the Service SW/InSite option located near the bottom of the Guided Install menu. Then select the Load Restricted Software option. The system will respond with a window as shown below. Read the proprietary statement and continue by clicking the 1,2, and 3 buttons in numerical order, and then clicking [OK].

  1. Insert your normal SaveInfo MOD/CD/DVD, or a new MOD/CD/DVD into the drive if not already inserted.

  1. At the top left of the Install GUI, select [File] then [Save GI Configuration to MOD]. This saves the information that has been entered in all the edit fields in the GUI.

  1. Remove the restricted CD from the system.
