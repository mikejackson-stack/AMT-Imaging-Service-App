NOTE:Restricted Service tools available to GE Field Service. Make sure the service key is installed.

  • In the Common Service Desktop, go to Calibration >> Install and Calibration Wizard. Select [Click here to start this tool](see Illustration 1).

  • Once the Install and Calibration Wizard (ICW) starts, select Probe/S Tunefrom the menu (see Illustration 2).

  • Review and okay the pre- and post-dependencies, and select [Click here to start this tool] to start the procedure.

NOTE: If you are unable to start the Restricted Service tools, use the non-proprietary method described below.

Illustration 1:  Install and Calibration Wizard Screen

Illustration 2:  “Probe/S Tune” Selection

Starting non-proprietary service tools: From the Common Service Desktop, select [Calibration], Probe/S Tune from the calibration menu, and select [Click here to start this tool] to start the procedure (see Illustration 2).
