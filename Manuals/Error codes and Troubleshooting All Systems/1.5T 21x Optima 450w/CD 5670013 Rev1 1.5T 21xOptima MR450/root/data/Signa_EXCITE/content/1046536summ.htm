Common Field Service Tasks

1  Procedure

1.1   Opening Common Service Desktop

  1. From the Tools menu, select Service Desktop Manager.

  1. On the Service Desktop Manager, click [Service Browser].

    Illustration 1:  Service Desktop Manager

    (Step Details)

1.2   Opening Guided Install in FE Mode

  1. With the service key inserted, open the Common Service Desktop.

  1. Under the Configuration tab, expand Guided Install and then select FE Mode.

    Illustration 3:   FE Mode

  1. Click on Click here to start this tool.

  1. When the C Shell terminal opens, type your root password.

1.3   Performing TPS Reset

  1. From the Common Service Desktop, click the Utilities tab, and then select TPS Reset from the left navigation pane. See Illustration 4.

  1. Click [Reset] to start the tool.

    Illustration 4:  TPS Reset

1.4   Opening a C Shell Terminal

  1. To open a C Shell terminal, click the Tools drop-down menu, and select [Command Window]. See Illustration 5.

    Illustration 5:  Tools Menu

  1. A C Shell terminal window opens. See Illustration 6.

    Illustration 6:  C Shell Terminal Window

1.5   Accessing Planned Maintenance Utilities

  1. From the Common Service Desktop, select the PM (Planned Maintenance) tab. A list will display the status of software updates. See Illustration 7.

    Illustration 7:  Planned Maintenance Tools

  1. From this tab, you can also access the Error Log Prune and TFile Cleanup tools.

1.6   Accessing GE System Error Log

  1. From the Common Service Desktop, select the Error Logs tab.

  1. Select GE System Log. A new window displays the list of errors. See Illustration 8.

    Illustration 8:  GE System Error Log

  1. If Service Key is installed, then error number text underlined and in blue font indicates extended error detail is available.

1.7   Accessing User Documentation

  1. Insert a service key, and from the Common Service Desktop, go to the Utilities tab.

  1. In the left navigation pane, select View User Doc CD, and click the link to view the documentation. See Illustration 9.

    Illustration 9:  View User Documentation CD
