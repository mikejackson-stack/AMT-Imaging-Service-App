ICN Infiniband Connectivity (Sun 4100)

1  Diagnostic Link

Diagnostics >> System Function >> Recon >> VRE Communication Diagnostics

Diagnostics >> Hardware Location >> PGR Cabinet >> Recon >>VRE Communication Diagnostics

Illustration 1:  VRE Communication Diagnostics

2  Purpose

This diagnostic tests the cabling and connectivity between the Sun 4100 ICNs for a multi-ICN system and ensures that the ICNs are able to communicate properly over the Infiniband. The Infiiniband is a high-throughput low latency interconnect used for acquisition and recon data transfers between ICNs. This diagnostic uses the Infiniband “traceroute” to trace the path between the Infiniband ports on the ICNs. For the test to succeed, the ICN being tested must be able to reach every other ICN over Infiniband.

This diagnostic should be used during one of the following conditions:

  • After the Ethernet diagnostics are complete.

  • If the system log indicates a problem with the Infiniband. This diagnostic should be conducted in conjunction with the ICN Infiniband Stress diagnostic and the ICN Infiniband Loopback diagnostic to isolate problems related to the cable or ICN hardware.

3  Components Tested

  • Infiniband cables

  • VRE (Infiniband hardware)

4  Requirements

Electrocution Hazard!
dangerous voltages are present throughout the system cabinet when power is applied.

5  Test Sequence

Before running this diagnostic, ensure that the Ethernet cabling and Ethernet switch are functioning correctly. The Infiniband data cables must be connected in their original configuration.

NOTE:This test will unconditionally pass for a one ICN product configuration.

  1. Select ICN Infiniband Connectivity from the VRE Communication Diagnostics screen.

  2. Enter in the desired iteration amounts in the fields provided.

  3. Click [Run].

    NOTE:Once you click [Run], do not click anywhere else in the Common Service Desktop until the test is complete. If you need to abort the test prior to its completion, you must click [Stop].

  4. Ensure the diagnostic passed by reviewing the Test Results and Test Status areas.

6  Expected Results

If the diagnostic does not pass, review the error log and corresponding extended error message for subsequent actions. Additional responses to the diagnostic's results are outlined in Table 1.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
The green LED next to the Infiniband board Port 1 is not on.
  • The ICN is off.
  • The Infiniband cable is not securely connected.
  1. Check both ICNs are powered at Utilities >> Toolbox >>VRE >> Power Control.
  2. Reseat the Infiniband cable connecting both ICNs.
The yellow LED next to the Infiniband board Port 1 is not on.
NOTE:You must extend the ICN from the cabinet to see the LED.

  • The Infiniband cable is not securely connected.
  • The Infiniband subnet manager process is not running on ICN1.
  1. Reseat the Infiniband cable connecting both of the ICNs.
  2. Reboot the ICNs (refer to the ICN On/Off Procedure).
  3. If rebooting does not resolve the issue, refer to VRE Reconfiguration.
The ICN Infiniband fails the diagnostic.
  • The Infiniband cable is not securely connected.
  • The Infiniband subnet manager process is not running on ICN1.
  • The Infiniband cable is defective.
  • The ICN Infiniband hardware is defective.
  1. Check that both ICNs are powered on by whether the green LEDs on the front are illuminated.
  2. Ensure the Infiniband cable between the ICNs is connected securely.
  3. Make sure the Infiniband port LEDs are on. If the LEDs are off, reboot the ICNs and repeat the diagnostic.
  4. If the problem persists, perform the ICN Infiniband Connectivity diagnostic again for both ICNs.
  5. If any of the connectivity diagnostics fail, replace the Infiniband cable. Then repeat the ICN Infiniband Connectivity diagnostic tests on both ICNs.
  6. If the ICN Infiniband Connectivity diagnostic fails on ICN1, replace ICN1.
  7. If the ICN Infiniband Connectivity diagnostic fails on ICN2, replace ICN2.
NOTICE
When this diagnostic is complete, perform a scan to ensure the system is operating correctly.
