Patient Table Components

There are three main table types: Non-Electrical, 32-Channel Curved, and 32-Channel GEM Flat. The following illustration depicts the major replaceable components for the curved patient table.

Illustration 1:  Main Components of 32-Channel Curved Table

Non-Electrical Table: Has no P ports.

Illustration 2:  Non-Electrical Table

32-Channel Curved Table: Has P3 and P4 ports at the rear of the table.

Illustration 3:  32-Channel Curved Table

32-Channel GEM Flat Table: Has P2 and P4 ports.

Illustration 4:  32-Channel GEM Flat Table

NOTE:Tables containing P ports have coil IDs that make the table unique to the system. See the above illustrations and table matrix for details.
