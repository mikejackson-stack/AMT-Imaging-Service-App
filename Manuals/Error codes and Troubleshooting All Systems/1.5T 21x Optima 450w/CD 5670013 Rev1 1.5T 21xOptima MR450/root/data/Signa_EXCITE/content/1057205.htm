Running mgd_term

(Click Here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Not Applicable2 minsNot Applicable

2  Overview

Start the Cabinet Communication Link (Run mgd_term?)in order to proceed with other tasks. This procedure is simply a prerequisite for other operations.

3  Procedure

NOTE:If the Service Browser or the [Utilities] button is not available, use the following method:

  1. Click on the [C-shell] button.

  1. In the C-shell window, type mgd_term and press <Enter>

    The prompt should respond with “connected.” Two windows open as shown in Illustration 1. Arrange the two C-Shell windows so that they can all be seen at once.

    Illustration 1:  Making All C-Shell Windows Visible

4  Finalization

  1. There should now be two windows open.

  1. Proceed to Results of Resetting TPS.
