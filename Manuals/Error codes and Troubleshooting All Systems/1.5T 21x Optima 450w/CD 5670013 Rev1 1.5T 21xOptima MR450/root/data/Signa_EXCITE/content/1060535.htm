Patient Table Emergency Release

NOTE:Ensure that the table is fully retracted before pulling the emergency release handle.

Verify that you can undock the patient table with the emergency red handle as shown in Illustration 1. Pull the handle in the direction of the arrow. If the table fails to undock by this method, troubleshoot the Dock Assembly.

Illustration 1:  Emergency Release Handle

Once the emergency release is pulled, move the table away before docking the table back into position.
