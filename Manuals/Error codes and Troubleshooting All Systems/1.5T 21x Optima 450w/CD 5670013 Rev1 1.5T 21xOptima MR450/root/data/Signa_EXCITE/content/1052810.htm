RF Amp Interface Board Level Diagnostics

1  Diagnostic Link

Diagnostics >> System Function >> RF >> RF Amp Interface Board Level Diagnostics

Diagnostics >> Hardware Location >> PGR Cabinet >> RF >> RF Amp Interface Board Level Diagnostics

Illustration 1:  RF Amp Interface Board Level Diagnostics

2  Purpose

This diagnostic confirms that the SCP can communicate via CAN to the RF Amplifier Interface Board in the CAM Chassis, and that the cable between the RF Amplifier Interface Board and the RF Amplifier is installed.

This test does not test the actual RF Amplifier or the signals passed between the RF Amplifier Interface and the RF Amplifier. It only checks for the presence of the connection from the RF Amplifier Interface Board to the RF Amplifier.

3  Components Tested

  • RF Amplifier Interface Board

  • Cable between RF Amplifier Interface Board and RF Amplifier

4  Requirements

No requirements to run this diagnostic.

5  Block Diagram

Illustration 2:  RF Amp Interface Board Level Block Diagram

6  Test Sequence

  1. Select the desired test from the RF Amp Interface Board Level Diagnostics screen.

  2. Click [Run].

  3. Ensure that the diagnostic passes by reviewing the status in the Test Results table.

7  Expected Results

This diagnostic has either a passed or failed status. If the diagnostic has failed, please review the error log and corresponding extended error message for subsequent actions.

In the event that the diagnostic reports a timeout, the diagnostic may not have been executed. Retry the test. If it continues to time out, complete a TPS Reset and then retry the test.
