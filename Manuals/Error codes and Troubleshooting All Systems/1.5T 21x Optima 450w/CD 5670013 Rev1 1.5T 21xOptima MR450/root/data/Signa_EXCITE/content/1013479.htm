Cat-6 Troubleshooting

This guide can be used to the below issues, which may result from defective Cat-6 cables in the Systems Cabinet:

  1. TPS reset hang-up.

  2. Slow recon times.

  3. Loss of connectivity between Host and Systems Cabinet.

  • For LONG Network Cable Between Host and Ethernet Switch (5160267-3): Section 1

  • For short network cables between ICN/VRE to Ethernet Switch (5146974 & 5146974-2): Section 2

1  For LONG Network Cable Between Host and Ethernet Switch (5160267-3)

  1. Check port activity LED on Host: See Illustration 1.

    Illustration 1:  Host Ethernet Port Activity LED

    • Green: 100Mb/s

    • Orange: 1Gb/s

  2. Check data rate per Link/Activity LED on front panel of Ethernet switch, See Illustration 2.

    Illustration 2:  Ethernet Switch Indicator LEDs

  3. Test connection between Host and Switch:

    • Type in a command window: more /var/log/messages | grep “e1000: eth1: e1000_w”<Enter>

    • Look for “100” in log file, see Illustration 3.

    Illustration 3:  Eth-1 Data Rate Test

2  For short network cables between ICN/VRE to Ethernet Switch (5146974 & 5146974-2)

  1. Check port activity LED on VRE/ICN at port in question, see Illustration 4.

    Illustration 4:  VRE/ICN Ethernet Port Activity LED

    • Green: 100Mb/s

    • Orange: 1Gb/s

  2. Check data rate per Link/Activity LED for appropriate port on front panel of Ethernet switch, see Illustration 5.

    Illustration 5:  Ethernet Switch Indicator LEDs

  3. Test connection between Host and Switch

    • Telnet VRE (or ICN) and switch to root using “su -”

    • In command window type: more /var/log/messages | grep “NIC Link is U”<Enter>

    • Look for “100 Mbs” in log file, see Illustration 6.

    Illustration 6:  Look for “100 Mbs” In Log File
