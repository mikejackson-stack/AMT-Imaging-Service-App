NOTE:If communication problems between Linux PC and Term Server are perceived, you can ping the Term Server as follows:

  1. Open C-shell

  2. Type cd /etc<enter>

  3. Type more hosts<enter>

  4. Ping the ts1 address by typing ping X.X.X.7<enter> (where X.X.X. is the TPS Subnet address).

    You should see proper communication.

    The Term Server might need to be reset several times in order to establish communication with the Linux PC.

  5. To stop the ping, type ^c
