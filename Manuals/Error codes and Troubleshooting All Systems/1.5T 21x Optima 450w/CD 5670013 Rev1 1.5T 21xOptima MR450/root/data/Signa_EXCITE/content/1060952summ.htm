2  Required Conditions

ConditionReferenceEffectivity

A system restart is required after configuration for the changes to take affect.

-

-

3  Procedure

NOTICE
Reconfigure the ICNs only if it is absolutely necessary. Be aware that the ICN OS DVD that shipped with the system software collector is required in order to perform this task on systems operating with 22.0 software.
 
 

  1. On the Tools screen, select the Service Desktop Manager tab (see Illustration 1).

    (Step Details)

  1. Click [Guided Install] and then click [Start...](see Illustration 1). Enter in the root login when prompted.

  1. Select VRE Configuration in the left-hand navigation sidebar (see Illustration 2).

    (Step Details)

  1. Click [View VRE configuration file] to the view the current output status of the ICNs (see Illustration 3).

    (Step Details)

  1. Click [Configure VRE Blades]. An information window automatically displays (see Illustration 4) requesting that you check that the hardware connections are secure. This is to ensure that the operating system (OS) will be properly installed onto the ICNs.

    1. Click [Continue] if the connections are complete.

    1. Click [Abort] if the connections are not complete. Ensure that all hardware connections are secure to continue with the VRE configuration.

    (Step Details)

  1. Select the number of VRE blades to be configured in following manner: For a 16-channel system, with SUN 4100 ICN, select 1, and for SUN 4170 ICN, select 1. For a 32-channel system, with SUN 4100 ICN, select 2, and for SUN 4170 ICN, select 1(see Illustration 5).

    (Step Details)

  1. VRE configuration runs and details appear in a separate window Illustration 6. At the end of VRE configuration, a popup will be displayed with VRE configuration succeeded or failed message. If VRE configuration fails, please review the popup message and details appearing in the separate window mentioned above for subsequent actions.

    (Step Details)
