ICN Hard Disk Integrity

1  Diagnostic Link

Diagnostics >> System Function >> Recon >> VRE Hardware Diagnostics

Diagnostics >> Hardware Location >> PGR Cabinet >> Recon >> VRE Hardware Diagnostics

Illustration 1:  VRE Hardware Diagnostics

2  Purpose

The purpose of this diagnostic is to test the integrity for both hard disks on an ICN. Hard disk store acquisition data for certain applications in DVMR. This diagnostic essentially verifies the ICN hard disks can be used to reliably store and retrieve data by writing a known pattern to the acquisition partitions, reading it back, and comparing the contents.

NOTE:This diagnostic takes about 85 minutes to complete.

3  Components Tested

ICN hard disks

4  Requirements

The ICN is turned on and has at least one network connection from the ICN motherboard Ethernet port to the Host.

5  Block Diagrams

Illustration 2:  System Cabinet and GOC Diagram

6  Test Sequence

  1. Select the ICN Hard Disk Integrity diagnostic from the VRE Hardware Diagnostics screen.

  2. Click [Run].

    NOTE:Once you click [Run], do not click anywhere else in the Common Service Desktop until the test is complete. If you need to abort the test prior to its completion, you must click [Stop].

  3. Ensure that the ICN passes the diagnostic by reviewing the status in the Test Results table.

7  Expected Results

This diagnostic has either a passed or failed status. If the diagnostic has failed, please review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed result are outlined in the table below.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
PassedThe ICN passed the diagnostic.No further action required.
FailedThe ICN failed the diagnostic.
  1. Ensure the ICN is turned on. Go to ICN Identification to identify the ICN (Utilities >> Toolbox >> VRE >> ICN Identification).
  2. Ensure that the Ethernet switch is turned on.
  3. Ensure that the Host-ICN Remote Shell diagnostic runs successfully.
    1. If that diagnostic fails, follow steps described in the help page for that diagnostic.
    2. If the diagnostic succeeds, re-run the ICN Hard Disk Integrity diagnostic.
  4. If the diagnostic fails after a second attempt, run the ICN Hard Disk Stress diagnostic (Diagnostics >> System Function >> Recon >> VRE Hardware Diagnostics).
    1. If the diagnostic fails, replace the hard disk. Look at the System Error Log for the corresponding error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities >> Toolbox >> VRE >> ICN Identification).
    2. If the diagnostic succeeds, re-run the ICN Hard Disk Integrity diagnostic.
  5. If the diagnostic fails after the third attempt, replace the hard disk. Look at the System Error Log for the error message. This contains the slot number location of the hard drive. Go to ICN Identification to identify the ICN (Utilities >> Toolbox >> VRE >> ICN Identification).
    NOTE:If the ICN Ethernet port/cables are bad then all the tests for that ICN may fail. This does not apply to the IPMI test which has a separate Ethernet cable.

    NOTE:The current product configuration has redundant motherboard Ethernet connection for each ICN.
