Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
RF Hub communication failureThe SCP cannot communicate to the RF Hub over the CAN link.Run the RF Hub CAN Fiber Loopback diagnostic.
Coil ID read failureThe RF Hub reports a failure to read the coil ID information over the 1-wire line to the coil ID chip.
  1. Check the coil ID 1-wire pins on the coil to make sure they are not bent.
  2. Try plugging in a different coil to the same port to check if the problem is internal to the coil. Or, use the Coil Datapath Diagnostic to troubleshoot the failure.
  3. Check the coil ID 1-wire line in the cabling between the coil port and the RFCB.
  4. If every item checks out successfully, try replacing the RFCB.
Body transmit enable mismatch; coil invalidThe body transmit enable state detected by the RFCB from the coil is different than expected. All coils except proton transmit coils are expected to have the body transmit enable pins shorted.
  1. Check the body transmit enable pins on the coil to make sure that they are in the expected state, either opened or shorted.
  2. Check the body transmit enable lines in the cabling between the coil connector and the RFCB.
  3. If necessary, use the Coil Datapath Diagnostic to troubleshoot the body transmit enable failures.
  4. If every item checks out successfully, try replacing the RFCB.
Coil invalid failureThere is a problem with the information in the coil ID chip or coil database.Check that the coil is installed in the coil database.
No coils detected with coils connectedThe RF Hub is not reporting that a coil is connected. This means that the coil present lines are broken between the coil and the RFCB.
  1. Check the coil present pins on the coil to make sure they are shorted, or plug in a different coil to the same port. Use the Coil Datapath Diagnostic to troubleshoot the failure.
  2. Check the coil present lines in the cabling between the coil connector and the RFCB.
  3. If every item checks out successfully, try replacing the RFCB.
