ICN RRX to VRF Data Path Diagnostic

1  Diagnostic Link

Diagnostics → System Function → Recon → VRF Communication Diagnostics

Diagnostics → Hardware Location → PGR Cabinet → VRF Communication Diagnostics

Illustration 1:  VRF Communication Diagnostics

2  Purpose

The purpose of the ICN RRX to VRF data path diagnostic is to test the data path between the VRF and the RRX.

3  Components Tested

The data path between the VRF and RRX.

4  Requirements

No special requirements.

5  Block Diagram

Illustration 2:  RRX to VRF Data Path for 4100 ICNs

NOTE:The bold arrow lines indicate which data path is being tested.

Illustration 3:  RRX to VRF Data Path for 4170 ICNs

6  Test Sequence

NOTE: (For 32-channel 4100 systems) Use the ICN Identification tool from the Common Service Desktop (Utilities → Toolbox → VRE → ICN Identification) to help distinguish ICN1 from ICN2.

(For 32-channel 4170 systems) Use the HART log to identify VRF1 and VRF2. From the Common Service Desktop, Error Logs → HART Log → Current Status, look for the item "vrf" in the BoardType column. Check the Board Location for this board. The slot number indicates the physical location of the VRF. Slot 19 is located to the side of the ICN. Slot 13 is located at the center of the ICN.

  1. Select the ICN RRX to VRF data path diagnostic from the VRF Communication Diagnostics screen.

  2. Click [Run].

  3. Ensure that the data path passes the diagnostic by reviewing the status in the Test Results table.

7  Expected Results

This diagnostic has either a passed or failed status. If the diagnostic has failed, review the error log and corresponding extended error messages for subsequent actions. Additional responses to the diagnostic's failed results are outlined in the table below.

Table 1:  Diagnostic Results

ResultDescriptionGE Field Action
PassedData path passed the diagnostic.No further action required.
FailedData path failed the diagnostic.
  1. Check the VRF and RRX clock input.
  2. Check the fiber data cable between the VRF and RRX.
  3. Execute the VRF Hardware Diagnostics, ICN VRF Manual Loopback Diagnostics, and RRX Board Level Diagnostics.
