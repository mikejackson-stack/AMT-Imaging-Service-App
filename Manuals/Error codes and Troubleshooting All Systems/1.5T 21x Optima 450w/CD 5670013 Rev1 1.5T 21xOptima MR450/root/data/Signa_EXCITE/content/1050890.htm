2  Overview

The Configuration File Manager is a graphical interface where you can change the contents of the MR Configuration File, Gradient Configuration File and the SAR Configuration File. The hardware is configured through “Guided Install”, rather than configuration file manager. No changes should be needed for the MRconfig or GradientConfig. The Config File Manager can be used to view the mentioned files. Changes for coils must be done using the MRconfig file as described in this document, as it contains pre-configured parameters for all GE coils, so adding a coil is as simple as [Click To Add].

NOTE:The MRconfig File Manager should not be needed to configure the system. All system changes should be made through the Guided Install option.

3  Procedure

3.1  Starting Configuration File Manager

  1. From the Service Desktop, open the Common Service Desktop, and go to the Configuration tab.

    Illustration 1:  Common Services Desktop

  1. From the left navigation pane, select Config File Manager.

  1. Click on Click here to start this tool.

    The Configuration File Manager main screen will open.

    Illustration 2:  MRconfig Screen

    A detailed view of MRconfig entries can be found in Site Configuration Options.

  1. Edit the values as needed for each of the Config files in the left navigation list as shown in Illustrations 3 through 5.

    NOTE:Gray fields are fixed values and cannot be modified. The fields which have black text can be edited.

    Illustration 3:  Gradient Config

    Illustration 4:  Scan

    Illustration 5:  Pure

3.2  Exiting The Config File Manager

  1. When you have finished editing values, Click [Save Changes] to save any changes you have made. If you do not want to save the scan changes, click [Discard Changes] .
