Low Contrast Detectability (LCD)

Last Revised:18 January 2007

1  Procedure

  1. Start [Image Analysis] from the Image Quality tab of the Common Service Desktop.

  2. Move the Image Analysis window to the left-hand monitor for access to the Sort Window (Image List-Select Browser) on the right-hand monitor Service Desktop screen.

  3. Using the Sort Window (Image List-Select Browser), highlight ONLY the water images from the first series (images 9-17).

  4. From the Image Analysis window, select the Manual radio button at the top instead of Auto 1X and select [LCD] under the Manual Tools menu. Click [Accept] to begin the analysis. See example Image Analysis Tool, below.

  5. A dialog box will open requesting, “Input hole diameter (mm)”. Enter 3 and click [OK] . A report will be displayed showing the results. See example LCD Report, below.

  6. On the QA Data Form, record the “Avg %Cnst @ 95%CL” value from the LCD report. The expected contrast value for a 3mm object is less than 5.000 HU.

2  LCD Failure Recovery

2.1  Specifications

Avg %Cnst @95%CL < 5.000 HU

2.2  Recommended Recovery

This is basically a noise measurement. Suspect operator error as the first failure mode. Incorrect protocol, DFOV, and phantom centering are the most likely causes.

  1. Verify all protocol values are correct and the phantom is centered.

  2. Rescan and then repeat the test to verify Image Performance.

  3. Perform Detailed Calibrations if necessary.
