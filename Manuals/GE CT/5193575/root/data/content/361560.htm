4  Procedure

4.1  Special Tools overview

  1. Illustration 1 shows the special tools shipped with the new module with the exception of the handle. The handle is part of the DAS/Detector service kit sent with each system. The Controlled Seating Tool is the absolute minimum required tool for proper replacement of the module.

    Illustration 1:  Special Tools

    • The Handle is attached to the heat sink of the module to aid in removal and installation. The heat sink and digital screws can be used to lift the module out if the handle is not available. Newer modules may come with built in handles on the heatsink.

    • The Controlled Seating Tool is used while installing a module to make sure the alignment pins on the module are centered on the detector collimator to avoid any damage to the detector collimator plates during module insertion.

    • The Bias tool is attached via magnet to the detector rail after seating the new module. The Bias tool pushes the module against the back detector rail for proper alignment while the module screws are being torqued.

    • The Multi-tool is used to aid in clamping the wedge lock after insertion using the notch on one end and for removing light seal clips using the magnetized pin on the other end.

4.2  Preparing the System

  1. If replacing a center module (slots 27-31) perform the following steps, otherwise go to step 2.

    1. From a C-shell type enableBISfeature . If this has already been done in the past, the message will indicate that this function is already enabled.

    1. If running 06MW29.7 software, need to check the FRDM wizard config file to update the test spec and enable a check using the following steps from a C-shell. Use 32 instead of 64 for 32 slice systems in the name of the config file.

      {ctuser}[1]  cd   /usr/g/config
{ctuser}[2]  cp  FRDMtool64.cfg     FRDMtool64.cfg.lfc   (makes a backup copy)
{ctuser}[3]  nedit  FRDMtool64.cfg
Edit the following line:
ENABLE_BIS_CHECKS = ON   (change from OFF to ON)
BIS_MATLAB_TEST_THRESHOLD_ARGV = 1.24e-6 (change from 1.5 to 1.24)
Save the change and exit the editor.

    1. Reboot the Console to put the changes in effect.

  1. At the console start the [FRDM Wizard] from the Common Service Desktop Replacement tab. Illustration 2 shows the main screen.

    Illustration 2:  Process Tool

  1. Select [Replace Module] tab and then [Start Process] . This will set up the system software to prepare for a detector module replacement. The physical module replacement can now be performed.

  1. Move the table full back out of the gantry and move it full down to allow you to completely move the front cover away from the gantry.

  1. Remove the right side gantry cover and disable Axial Drive and HVDC from the service switch panel.

  1. Position the detector at 12 o'clock and lock gantry rotation.

  1. Shut down all gantry power from the service switch panel.

  1. Remove the side, top and front gantry covers. The rear cover needs to be released and moved back slightly to allow easy access to the back detector rail.

  1. Reconnect the front cover display and keypad and turn power on to the gantry to allow the table to be moved to full up position to use as a work table. Then power down the gantry again.

  1. Cover the Tube Collimator port to protect it against dropped tools or screws. (Cloth or any other available item)

4.3  Air Plenum Removal

  1. Remove the Detector Air Plenum as shown in Detector Air Plenum Removal/Installation.

    NOTE:Reminder that using the mouse right button on the above document link and selecting “Open in new Window” will keep this document open at the same time for ease in use. Can leave the Air Plenum instructions open for later use when reinstalling the plenum.

4.4  FRDM Removal

  1. Make sure ESD strap is in use prior to continuing. (Use a smock if available)

    NOTE:Order of the following steps is critical to success. Do NOT change the order. Read each step and cautions completely prior to performing that step.

  1. Remove cover band end screws (not captive) and loosen 4 middle screws, then slide off the screw cover bands. See Illustration 3. Remove the middle screws if needed, the cover bands are slotted in the middle.

    NOTE:If any of the cover band screws are right next to the screw holes for the module being replaced, those screws will need to be removed so they don't interfere with the module seating tool used during module installation.

    Illustration 3:  Screw Cover Bands

  1. Remove 8 torx screws (not captive) on the light seal plate with the supplied bit, then lift off the light seal plate. See Illustration 4.

    NOTE:If the detector does not have torx screws on the light seal plate, the use a hex wrench to remove the screws. Replace with torx screws supplied with the replacement module during reassembly. Early detectors had hex head screws that will deform with usage.

    Illustration 4:  Light seal plate

  1. Put on gloves (supplied with system) before continuing to avoid introducing any contaminates on the detector module or around the detector collimator.

  1. Remove module screws on either side of carbon window for the module being replaced. See Illustration 5.

    Illustration 5:  Module Screws

  1. Completely loosen the digital cable thumb screws until they pull back freely from the backplane. Do NOT release the wedge clamp yet. See Illustration 6.

    Illustration 6:  Digital screws and Wedge Clamp

  1. Pull both cable screws away from the backplane approximately 3/8” (8mm) to release the cable edge card connector from the backplane.

  1. Remove the light seal clip on each side of the module. Use the Multi-Tool supplied as shown in Illustration 7.

    NOTE:Early detectors did not have light seal clips so this step can be skipped if the clips are not installed.

    • Insert the MultiTool pin into the Light Seal clip hole, tilt the tool up to pull clip out then pull straight out to finish removing clip.

    • Tool has a magnet to keep clip from falling into gantry during removal.

    Illustration 7:  Light Seal clip removal

  1. Release and remove the wedge clamp.

    NOTE:Releasing the wedge clamp prior to disconnecting the digital cable from the backplane can damage the digital cable screws or the backplane connector.

  1. Attach the handle to the heat sink, (HDAS64 has built in handles on modules) then lift the module up until the Light seal collar completely clears the brackets it is resting between then slide it out. See Illustration 8 and Illustration 9. (Hold onto the digital cable screws if a handle is not available.)

    • Module alignment notches on the Light seal collar and the pins at the other end of the board must clear the alignment slots to allow the module to slide out of the detector.

    • A digital cable screw can be held with the other hand to aid in guiding the module up and out if needed.

    • If the module does not seem to move up, check the digital cable. Make sure it is released from the backplane.

    • If the module seems to be stuck to the rail such that the flex connections are pulling up when the entire assembly is lifted up, STOP. Completely insert the Controlled Seating Tool (seen in Illustration 12) into the detector rails for that module. This will keep the module from hitting the detector collimator plates while you gently push up with a finger on the detector module front edge to release it from the detector rails. Remove the seating tool and continue to remove the module from the detector.

    Illustration 8:  Module removal

    Illustration 9:  Module Alignment pins

    NOTE:After removing the module avoid touching the flex connection or detector module face. Hold the module by the heat sink or metal bracket on the opposite end of the of the assembly.

  1. After removing the module visually inspect the detector rails to see if any Thermal Mount pads from the detector module were left (Some early modules had this problem). The module front end can also be inspected to see if both side pads are still in place. See Illustration 10. The pads are seen as thin white squares on the plates that the mounting screws go through. Carefully remove any pads left on the rails without touching the detector collimator plates. Any damage to the collimator plates will require full detector replacement. Procedure VCT Detector Thermal pad Removal must be used to remove any thermal pads.

    Illustration 10:  Detector module front end

  1. If the initial problem was an Open Pixel, first check the torque on the module flex screws before installing a new module using the following steps. These steps require a Torx T10 size driver bit and the torque driver. Loose flex screws are typically the problem for any open pixel issue. Resolution will be known before any calibrations are run.

    1. Torque the 3 flex connection screws to 4 lb-in (0.5 N-m or 4.6 kg-cm) starting with the center screw.

      Illustration 11:  Flex connection screws

    1. Install Module as shown in the next sections and run maratio’s test from DASTools to see if problem has been resolved.

    1. If the problem was not resolved, install new module

4.5  FRDM Installation

  1. Attach the handle to the heatsink of the new module. (If handle is not available use the heat sink for initial insertion and digital cable screws as a handle to lower the module onto the seating tool)

    NOTE:Do not touch the detector module face or flex connections. Handle the module by the heat sink or metal bracket on the opposite end of the assembly.

    NOTE:The order of the following steps is critical to success. Do NOT change the order. Read each step and cautions completely prior to performing that step.

  1. Install the new module using the following order of steps. (See Illustration 12 for illustrated process with numbered references)

    1. With one hand, insert the Controlled Seating Tool part way (1) so pins do not extend above detector rails to avoid scratching the detector module during insertion. Putting your thumb between the tool and the detector can help control the tool insertion while you insert the module.

    1. With the other hand, insert the Module in (2) toward backplane using the handle or holding onto the digital screws.

      The Detector light seal brackets must be between the module flex connection plates and module light seal plate as shown in Illustration 9 to allow module to slide into detector.

    1. Push the Controlled Seating Tool completely up into detector rails (3a) then lower module down (3b) on top of the seating tool so that the module screw holes engage the seating tool. This will ensure that the module alignment pins do not hit the collimator plates during module insertion.

    Notes:

    • The module must be seated on the detector rail. DO NOT force it into position. The module will seat on the rail when the module alignment pins are properly aligned.

    • You may have to push the top of the board toward the backplane to engage the top alignment pins if the digital cable is pushing the board away from the backplane.

    • If the Controlled Seating Tool is not used, detector collimator damage may result.

    Illustration 12:  Module insertion

  1. Remove the seating tool only after the module is seated on the detector rails. Leave the handle in place to avoid unseating the module from the detector collimator before the module is screwed down.

  1. Attach the bias tool to the detector rail to push the module against the back detector rail with a known force. See Illustration 13. Gloves can be removed at this point.

    NOTE:If the bias tool does not hold to the rail, you will have to hold it in place with one hand while torquing the rear module screw with the other. Original bias tools had this issue, a stronger bias tool is being deployed to resolve this issue.

    Illustration 13:  Bias Tool

  1. Insert both module screws on either side of the carbon window and torque to the value shown in Table 1. Torque the back screw first.

    NOTE:Do NOT push up on the module screws. Pushing up may unseat the module and damage the detector collimator plates.

    Table 1:  Detector Module Screw torque

    1.1 N-m0.8 lb-ft10 lb-in11.5 Kg-cm

  1. Remove the handle and bias tool from the module.

  1. Insert the wedge clamp and lock it. (Orientation: Plate of the wedge clamp against the board)

    Illustration 14:  Wedge clamp insertion

  1. After locking the wedge clamp, carefully install and finger tighten both digital cable thumb screws using the process below to help avoid cross threading. The screws will go in easy when properly aligned.

    1. Pull the digital cable screws away from the backplane initially and then in toward backplane to help initial connector alignment. Use a flashlight if necessary to see if the connector is aligned to the backplane socket. A “click” can be heard when you set down the screws indicating the screws have hit the backplane threaded socket.

    1. Rotate the screws counter clockwise to hear a clicking sound made by the threads of the screw and threads of the socket. This will insure that the screws are lined up to the connector prior to threading them in.

    1. Start both screws into the sockets. Thread both screws in together so the cable edge connector is pulled into the backplane straight. Stop and back out the screws if any squeak is heard as this indicates cross threading. Try rotating the screws counter clockwise until you hear a second “click”. This can help if the screw was previously cross threaded to avoid the crossed threads.

    1. May need to carefully pull the digital cable screws to one side to help alignment if needed while performing steps a-c above.

    1. Torque the screws per Table 2.

    Table 2:  Digital cable screw torque

    0.4 N-m0.3 lb-ft3.5 lb-in4 kg-cm

  1. Look across the modules from the side to make sure the digital cable screws are seated to the same height as the rest of the modules. This will indicate proper connection. See Illustration 15 for example side view. Note a top screw may not be fully seated in this view. Bottom screws all appear at same height.

    Illustration 15:  Module Screws side view

  1. If light seal clips were previously removed, Insert the 2 light seal clips on either side of the module. See Illustration 16.

    Illustration 16:  Light Seal Clip insertion

  1. Strongly suggested but not Mandatory: Use the Deionizing fan to remove any static buildup during the replacement process. Hold the fan within 2 feet of the replaced module for 60 seconds.

  1. Visually inspect the light seal plate for any hair or other debris. Wipe clean prior to installation to avoid getting debris inside detector.

  1. Install the light seal cover being careful around thermistor wires, using torx head screws (supplied with module if detector did not have them). Torque screws to the value shown in Table 3.

    Table 3:  Light seal screw torque

    2.5 N-m1.8 lb-ft22 lb-in25.5 Kg-cm

  1. Install the screw cover bands (both bands are identical) and torque the screws to the value shown in Table 4.

    NOTE:The end screws on the screw cover band next to the rotating base frame can not be reached with the torque driver. Just snug them carefully with an offset hex wrench. Do not overtighten.

    Table 4:  Screw cover band torque

    0.8 N-m 0.6 lb-ft 7 lb-in 8.1 Kg-cm

4.6  Plenum Installation

  1. Install the air plenum as shown in Detector Air Plenum Removal/Installation.

  1. Install the gantry rear cover.

  1. Connect the front cover cabling but do not install the front cover until after checking module alignments and DAStools tests. The display is required to be connected for the test scans.

  1. Turn on the gantry power from the service switch panel leaving HVDC and Axial drive disabled.

    Note the current time. It will take the detector approximately 45 minutes to warm up to operating temperature from the time power is turned on. The alignment and DAStools tests can be run during the warm-up time but calibration must not be started until the detector is up to temperature.

  1. Release the gantry rotational lock and make sure gantry is ready for rotation.

  1. Enable axial drive and HVDC from the service switch panel.

4.7  Detector testing

  1. From the FRDM Process Tool currently open at the console select [Minicheck] and acknowledge the pop up window if the gantry is ready to rotate.

    NOTE:The Wizard will first read the HART data from all detector modules. This will take less than 60 seconds. If this process takes longer, then the communication path to the detector has locked up. Abort the FRDM Wizard, reset the gantry power or perform a scan hardware reset, then restart the Wizard and try again.

    The alignment check will start after the scan button is pressed when prompted. (Non-rotating scan)

    The alignment check can also be run from a Unix Shell. Open a Unix shell and type the following command: zalignmentWizard

  1. The alignment check will run 2 scans and show plots as shown in Illustration 17. Processing will take approximately 2 minutes after the scans are run.

    Illustration 17:  Alignment check display

    Table 5:  

    ModulesSpecificationsNotes
    (Outer Modules)1-26, 32-57+/- 75Only look at modules you replaced. Do NOT move other modules. Some factory modules may not be within this specification.
    (Center Modules) 27 and 31 ONLY+/- 48If the module alignment using the bias tool does not position the module within specification, Use the special “Module adjust tool” instructions to make adjustments.
    (Center Modules) 28, 29, 30+/- 32If the module alignment using the bias tool does not position the module within specification, Use the special “Module adjust tool” instructions to make adjustments.

  1. Check the bottom graph to make sure the module is within specifications defined by Table 5. Use the following guidelines for looking at the plots.

    1. The plots autoscale to fit the data. First look at the Y-scale of the bottom plot. If the upper and lower values are at or less than the specification, then all points in the plot are within specification.

    1. Module 1 and 57 are plotted on the very edge of the plots. In the example of Illustration 17 Module 1 can be found at +5 just above the zero mark. Module 57 can be found at -8 on the right side edge of the plot.

    1. For any questionable plot point, select [Data Cursor] from the top tool bar and then use the mouse cursor to select the module “+” on the bottom graph. A small window will appear showing the module number and plot value. For example module 30 in Illustration 17 is shown to be at -19.

    1. If more than two side by side modules are replaced at once an out of alignment condition can occur if none of the modules were aligned with the bias tool. This signature is different than any single module. See Illustration 18.

      All 5 modules are out of alignment with the rest of the detector as seen on the top graph, yet modules 26, 27, 31, and 32 show out of alignment. This is further explained in the alignment wizard user instructions. Note this potential condition and see that it is the center 5 modules that all need to be repositioned as shown in the top graph. Modules 26 and 32 are effected due to the common edge with modules 27 and 31 and will show better results after the center set is repositioned.

      Illustration 18:  Center module offset example

      See zalignmentWizard User Instructions for more details if needed.

  1. If the module alignment check does not pass; perform the following:

    1. Reopen the Detector following all previous cautions and steps in Air Plenum Removal and FRDM Removal loosening module screws without actually removing them to allow module realignment.

      NOTE:If you are working with one of the center 5 modules (27-31), try to reposition the module using the bias tool once. If the module does not align properly follow the special instructions in the Center Module Alignment Procedure to perform special manual alignment.

    1. Always use the bias tool to push the module toward the back rail. After the bias tool is installed, torque the module screws to the value shown in Table 1.

    1. Re-assemble the system per Plenum Installation.

    1. Exit the plot from the previous alignment scan using the File menu (do not minimize the window), Dismiss the DASTools GUI that shows up and select [MiniCheck] again to rerun the alignment wizard test. Rerun the module alignment check to verify proper alignment, perform this step again if alignment is still not passing.

  1. After the alignment plot is closed (not minimized, must exit the window) the DASTools GUI will automatically show up. From the DASTools interface run the following rotating tests.

    1. Select and Run [mA Ratio Test] (creates/updates the bad channel map)

    1. Select and Run the [Auto Test] from DASTools.

  1. If all the checks pass continue with the next step. If anything fails, troubleshoot per the failed test.

  1. Perform any desired quick checks if problem was not a digital issue that was already verified by the mini check tests.

4.8  Gantry Reassembly

  1. Install all gantry covers remembering to enable Axial Drive just before installing gantry right side cover.

    NOTE:Gantry covers MUST be in place and detector up to proper temperature prior to running full calibration.

4.9  System Calibration

  1. Check the Common Service Desktop, Detector Temperature to see if the detector temperature is at 38 degrees C +/- 1.5. You may have to wait for up to 45 minutes to allow detector to warm up prior to starting the calibration process (from time of Detector power on). Calibrations are not allowed to start until the detector reaches proper temperature.

  1. From the FRDM Process Tool currently open at the console select [Prep for Calibrations] .

    • For 06MW03.4 software: The Scanner Utilities screen will open.

    • For software releases after 06MW03.4: A test will be run prior to calibrations that will check for center artifacts. This test is specific for center module (27-31) replacements but will always be run to make sure no center module artifacts have been introduced due to accidental movement of a center module. Acknowledge that the system is ready for gantry rotation and then press the [Start Scan] hard key when indicated to run the test.

      The Center module test will report a Pass or Fail. If the center check fails, the center module just inserted is not compatible with the other center modules and needs to be replaced. A failure will not be a common occurrence since the system has been updated with a new calibration vector to account for center module variations. Only significant module issues should cause a failure. Potential IQ issues for a failing module include all center related artifacts including center spot and smudge. If the test passes, continue with calibrations.

      The Scanner Utilities window will open.

  1. Perform a [Collimator Cal] .

  1. Perform a full [Detailed Cal] .

  1. After Detailed calibration a [Fastcal] must also be run from [Daily Prep] to complete the updates to the calibrations. (This is new with the VCT system)

4.10  Image Quality testing

Below is an overview of the Image Quality tests to be performed.

  • QA phantom Image Series

  • 35cm Poly Phantom Image Series

  1. See Table 6 for a test analysis overview and table that can be used as a guide to keep track of Exam and Series identifiers per test.

    Table 6:  Test Analysis Overview

    Test (# series generated)ExamSeriesAnalysis
    ImgSer 20cmQA VDAS64 (8 series)  Image Analysis 20cm QA (All series in order as listed in image analysis. For series with Recon as the start of the series description use the same analysis run for the prior series.)
    ImgSer 35cmQA VDAS64 (Series 1,2,3)  Image Analysis 35cm Poly (First 3 series in order as listed in image analysis.)

  1. Perform the following Image Quality verification checks for all module replacements.

    1. Position the QA phantom and level it. Landmark on the line provided and perform phantom centering using the [Scanner Utilities] [Phantom-centering] .

    1. Run the ImgSer 20cmQA VDAS64 series (protocol 45.7) scans by selecting them from the [Service] [Manufacturing] list of protocols. Run all series.

    1. Position the 35cm Poly phantom and level it. Landmark on the center of the phantom and perform phantom centering using the [Scanner Utilities] [Phantom-centering] .

    1. Run the ImgSer 35cm VDAS64 image series (protocol 45.8) scans by selecting them from the [Service] [Manufacturing] list of protocols. Run the first 3 series.

    1. Using the [Image Analysis] tool, analyze each scan using Table 6 as a reference for scans run and analysis instructions. When using the [Image Analysis] tool, run the analysis in order of the series scanned from the image analysis menu for the phantom used.

      In the Image select interface on the [Service Desktop] remember to select the top image and drag down to the bottom of the image window holding the left mouse button to select the entire series of images for analysis. This enables the report to show the average values that are compared to specifications and shown with a pass/fail result.

5  Finalization

  1. From the FRDM Process Tool currently open at the console select [Update Detector Configuration] when the system is ready for customer operation. This will read and update the new detector configuration and perform any background cleanup of temporary software files created by the tool during the replacement process.

  1. Fill out the VCT Digital Module Return Form included with the module or online. This information is important for root cause analysis of failed parts to improve quality of processes and future parts. This also helps clarify any issue reported that would not have been found by normal retests that could result in a No Defect Found.

  1. Return all tools and equipment sent with module along with the replaced module(s).
