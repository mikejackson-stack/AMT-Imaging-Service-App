maRatios Test

The maRatio test runs 2 scans for a 64 slice system and up to 6 scans for a 32 slice system. The purpose of the maRatios test is to detect nonlinear and unresponsive detector channels. To do this each detector element and each DAS channel is tested. The data is analyzed and compared against specifications to determine if a detector cell fall outside the range of expected operation. Once a cell is determined to be bad, it is mapped out of the detector and its data is no longer used. This information is logged in the DAStools log.
