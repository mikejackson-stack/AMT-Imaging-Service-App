VCT Configurations

  • LS VCT: 1 VIG Node or 3 VIG Nodes
  • LS VCT XT: 3 VIG Nodes
    NOTE:LS VCT XT is a Premium LS VCT configuration.

Standard VCT Options

  1. Smart Prep
  2. AutomA
  3. 3000 Image Series (also called Large Image Series)
  4. Connect Pro (required for Exam Split)
  5. Exam Split (before installing engineer needs to determine if HES or VES)
    NOTE:Hard ExamSplit or Virtual ExamSplit. VES requires PPS (Performed Procedure Step), which is installed as a part of the Connect Pro install.

  6. Direct-3D
  7. Direct-MPR
    NOTE:Direct-MPR requires 4 GB of Host Main memory as shown in hinv; otherwise, with 2 GB the maximum images is set to 1200. The vrac_flash_update process must be successful for DMPR to work properly.

  8. Data Export
  9. CopyComposer (also called CD/DVD, Interchange)
