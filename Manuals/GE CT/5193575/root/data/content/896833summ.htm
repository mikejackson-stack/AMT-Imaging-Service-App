VCT VDAS to HDAS Replacement

(Click Here to Return to Detailed Procedure)

1  Safety

Follow ALL required safety and PPE procedures customary for your organization, when working on this product.
 
 

2  Required Conditions

ConditionReferenceEff

Only trained service personnel should service the GE CT Scanner.

-

-

Ensure that the software revision 06MW29.7 or later software revision is on site in order to support an HDAS DAStype. If system has software older than the 06MW29.7 (July 2006), then software revision 06MW29.7 or later must be loaded to support this detector change.

-

-

If you do not already have the 2006 style plenum then you will need to replace the entire plenum assembly with the plenum upgrade kit part # 5169770.

3  Procedure

3.1   Preliminary Steps

  1. Perform a DAStools Auto test and note any failures prior to performing upgrade. If the same failures are seen after the upgrade this will help with troubleshooting since all DAS/Detector electronics are being replaced with this procedure. The software LFC will wipe out results so take appropriate steps to note down results or transfer results file off the system for reference later.

  1. Make sure a current Save State data set exists. Create one if necessary.

  1. Remove all power from the system using standard LOTO procedures.

  1. The plenum will be replaced in this procedure unless you already have the new 2006 style plenum. See Illustration 1 to identify the plenum required with a HALO detector. The visual difference identifying the new style plenum is the grey sub-D cabling. The older plenum has white plastic (molex) connectors.

    (Step Details)

  1. Remove all gantry covers.

    (Step Details)

3.2   Tube weight removal

The tube is being removed to have access to a 4kg fixed weight behind the tube. This weight was used to counter balance the Sherlock detector but is no longer needed with the lighter HALO detector.

  1. Using the Tube Replacement - Lightspeed VCT, remove the tube per section 4.1 “Remove old tube”. Note: the tube will be reinstalled after removing the 4kg weight.

  1. Remove the 4kg fixed weight from the rotating frame behind the tube. See Illustration 2 and Illustration 3. Discard the 2 screws and weight. This balance weight is not needed with a HALO detector.

    (Step Details)

  1. Mechanically reinstall the tube using the Tube replacement instructions from step 1 above, section 4.2 “Install new tube”. ONLY perform mechanical installation at this time. Tube alignments will be performed after all hardware has been changed.

  1. Power on the system and perform a DDC stationary air scan to ensure basic functionality prior to continuing. This will aid in troubleshooting any issues later after replacing the DAS/Detector hardware to know that the tube was functional. Suggest reviewing the scan data with Scan analysis MSD plots to make sure there are no beam blockages.

  1. Remove all power from the system using standard LOTO procedures before continuing to replace the DAS/Detector subsystem.

      (Step Details)

    1. Remove the 29 DIFB boards and put them in the supplied anti-static bags. Set them aside to return with the old detector.

    1. Remove the DCB and place in an anti-static bag. This board will be re-installed in the system.

    1. Remove the DIFB bottom card guides from both DIFB chassis by removing the three screws in each. Be careful to catch the screws and washers during removal. If dropped, they must be found and removed from the DIFB plenum during detector and backplane replacement. See Illustration 5 for screw locations. Card guides are replaced due to air flow design change required for HALO components.

      (Step Details)

    1. Carefully install the Card guide ESD clips on the bottom side of the card guides. See Illustration 6 for reference. There are 8 clips per chassis card guide (16 total). When fully installed the ESD clip is locked in place and will not slide back out.

  1. Install the new HALO detector as shown in VCT Detector Replacement Procedure using section 4.6 (Digital Detector Installation).

  1. Install the gantry balance weights in the same order as removed. Torque in two steps to the values below:

3.8   Gantry Power on

  1. Perform a visual inspection of the gantry to make sure all cabling is secure and connected.

  1. Verify Gantry service switches are in off position and console switch is in the off position.

  1. Enable power to the system per LOTO procedures and turn on the gantry power leaving Axial Drive and HVDC disabled from the service switch panel.

  1. Rotate the gantry by hand for another visual inspection to make sure all cabling is secure and connected.

  1. Power off the gantry from the service switch panel prior to starting LFC. This is to avoid any software conflicts due to changed gantry hardware prior to performing LFC.

  1. Power on the console and stop applications load.

  1. Perform a software LFC using the software load from cold instructions in the service documentation for the software revision you will be loading. Power on the Gantry after LFC is started.

    (Step Details)

  1. Perform a flash download to make sure the DCB and DIFB's have the correct firmware.

  1. Perform the following tube alignment procedures per Tube Replacement - Lightspeed VCT. Section 5

    (Step Details)

  1. From the DASTools interface select and Run [mA Ratio Test] (creates the bad channel map)

  1. From the DASTools interface select and Run the [Auto Test] . If all the checks pass continue. If anything fails, troubleshoot per the appropriately failed test.

  1. Disable power to the gantry and install all gantry covers.

  1. Turn on all power to the Gantry and wait for the detector to warm up. At this point the detector should be close to temperature, System will make sure detector has been at temperature for at least 15 minutes to make sure the detector temperature is stable prior to calibrations.

4  Finalization

  1. Wait for the detector to come up to operating temperature then perform the following steps. The system software will let you know if the detector has not been at operating temperature long enough for calibrations to be run.

    1. Tube Warmup

    1. Collimator Calibration

    1. Detailed Calibration

    1. Fastcal

  1. Perform the following Image Quality verification checks

    1. Position the QA phantom and level it. Landmark on the line provided on the phantom and perform phantom centering using the [Scanner Utilities] [Phantom-centering] .

    1. Run the ImgSer 20cmQA VDAS64 series (protocol 45.7) scans by selecting them from the [Service] [Manufacturing] list of protocols. Run all series. (This protocol is labeled as VDAS but is the same for HDAS)

    1. Position the 35cm Poly phantom and level it. Landmark on the center of the phantom and perform phantom centering using the [Scanner Utilities] [Phantom-centering] .

    1. Run the ImgSer 35cm VDAS64 image series (protocol 45.8) scans by selecting them from the [Service] [Manufacturing] list of protocols. Run the first 3 series.

    1. Using the [Image Analysis] tool, analyze each scan. When using the [Image Analysis] tool, run the analysis in order of the series scanned from the image analysis menu for the 20cm QA or 35cm Poly analysis menu selection as applicable to the phantom scanned.

      (Step Details)

  1. Open a Unix shell and type createMasterDCF from a ctuser prompt. This will initialize the detector configuration in the software for the HALO detector.

  1. Perform a SaveState for the new system configuration and calibrations.

  1. Repackage all removed hardware and return per standard procedures.
