VDARC BIOS Telnet Process

Last Revised on:March 9, 2005

If the SCSI BIOS "extended int 13 support for drives > 1GB" setting is disabled on either host controller, then gre-raid will fail to create/start the scan disk array (by design).

SCSI CONTROLLER SETTINGS for A and B “Sync Transfer Rate should all be at 320 (not 160).

Description:

Ideally, this one-time procedure on the VDARC Node is done before the LFC. Use Serial Over LAN (SOL) to reboot VCT DARC Node and access the DARC SCSI setup.

  1. With Application Software DOWN:

    1. Open a Unix Shell.

    2. telnet localhost 623 (cli service may need to be restarted if this fails)

    3. Server: darc

    4. Username: (press the <Enter>/<Return> key)

    5. Password: (press the <Enter>/<Return> key)

    6. At the dpccli prompt: reset -f -c

      Press [OK] .

  2. Press <Ctrl+A> (when message appears) to configure the SCSI BIOS (appears shortly after system BIOS display)

  3. AIC-7902 A at slot ## xx:xx:xx

    1. Press <Enter> to select AIC-7902 A at slot ##.

    2. Press <Enter> to go to the Configure/View SCSI Controller Settings screen.

    3. Use down-arrow key to select SCSI Device Configuration.

    4. Verify the Sync Transfer Rate (MB/Sec) for all is set at 320.

      If not:

      1. Arrow to the value in need of change and press <Enter>.

      2. Use up arrow key to 320 and press <Enter> then arrow over and select <Enter> for next change.

      3. Verify all (0 through 15) are set to 320.

      4. Press <Esc> key to leave the Configuration screen for AIC-7902 A.

      5. Press <Esc> Key to leave this screen and return to AIC-7902 A at slot ## Screen.

    5. Use down-arrow key to select Advanced Configuration and press <Enter>.

    6. Use down-arrow key to select Extended Int 13 Translation for DOS Drives > 1 GByte.

    7. If setting is disabled, press <Enter> and select/enter Enabled.

    8. Press <ESC> key twice to go up two levels: (AIC-7902A Configuration screen then Save Changes Made?).

    9. Select [Yes] to save changes.

    10. Press <Esc> key to get out of the options screen: Configure/View SCSI Controller Settings.

  4. AIC-7902 B at slot ## xx:xx:xx

    1. Press <Enter> to select AIC-7902 B at slot ##.

    2. Press <Enter> to go to the Configure/View SCSI Controller Settings.

    3. Use down-arrow key to select SCSI Device Configuration.

    4. Verify the Sync Transfer Rate (MB/Sec) for all is set at 320.

      If not:

      1. Arrow to the value in need of change and press <Enter>.

      2. Use up arrow key to 320 and press <Enter> then arrow over and select <Enter> for next change.

      3. Verify all (0 through 15) are set to 320.

      4. Press <Esc> key to leave the Configuration screen for AIC-7902 B.

      5. Press <Esc> key to leave this screen and return to AIC-7902 B at slot ## Screen.

    5. Use down-arrow key to select Advanced Configuration and press <Enter>.

    6. Use down-arrow key to select Extended Int 13 Translation for DOS Drives > 1 GByte.

    7. If setting is disabled, press <Enter> and select/enter Enabled.

    8. Press [ESC] key twice to go up two levels. It displays - (AIC-7902A Configuration screen then Save Changes Made?)

    9. Select [Yes] to save changes.

    10. Press <Esc> key to get out of the options screen: Configure/View SCSI Controller Settings.

  5. Press <Esc> key to leave this screen and return to AIC A/B Selection Screen.

  6. Press <Esc> key to leave the EXIT UTILITY. Use Arrow Key to select [Yes] and press <Enter> key.
