4  Procedure

4.1  Replace Whole Disk Array (JBOD)

4.1.1  Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, select the Shut Down icon and then select [Shutdown] .

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.x) have corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      {ctuser@hostname}  halt

  1. The Operator Console monitor will display a System halted message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch. (Refer to Illustration 1.)

    Illustration 1:  Power Switch

4.1.2  Remove the Old Scan Data Disk Array (JBOD)

  1. Remove the front and rear Operator Console cover.

  1. Remove all rear cable connection to the Disk Array (JBOD). Verify each cable is present and clearly marked, if necessary add a label for clarity.

  1. Remove the front cover of the Disk Array (JBOD)

    Turn the two (2) knobs on the front cover to the horizontal position, then remove the Disk Array front cover.

    Illustration 2:  Disk Array Front Cover

  1. Remove and retain the four (4) front mounting screws.

Failure to return the disks to their proper location will result in potential lost patient raw data.
 
 

  1. Remove each disk from the JBOD assembly individually, and clearly mark them so that they can be returned to the same slot location in the new replacement JBOD.

    1. Remove each disk or empty sled as shown in Illustration 3.

    1. Label each disk as shown in Illustration 4.

      Illustration 3:  Remove Individual Drives

      Illustration 4:  Disk Numbering

  1. Slide out the Disk Array Chassis (JBOD).

4.1.3  Install the New Disk Array (JBOD)

Install the replacement Disk Array (JBOD) in the Operator Console.

  1. Slide the Disk Array (JBOD) into the Operator Console.

Failure to return the disks to their proper location will result in potential lost patient raw data.
 
 

  1. Return each Disk or empty sled to its proper position inside the Disk Array (JBOD) chassis.

  1. Replace the four (4) front mounting screws on the front of the Disk Array (JBOD).

  1. Replace the front cover screen to the Disk Array (JBOD) assembly.

    See Illustration 2.

All cable connector screw-locks must be finger-tightened, only. Do NOT use any tool to tighten cable screw-locks.

Verify that the SCSI Cable is on straight.

 
 

  1. Replace all rear cable connections to the Disk Array (JBOD).

4.1.4  Test the Disk Array RAID

  1. Perform all Disk Array RAID Tests per Disk Array RAID Testing.

  1. Continue with replacements, as necessary.

4.2  Replace the Scan Data Disk Drive (with sled)

4.2.1  Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, select the Shut Down icon and then select [Shutdown] .

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.x) have corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      {ctuser@hostname}  halt

  1. The Operator Console monitor will display a System halted message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch. (Refer to Illustration 1.)

4.2.2  Remove the Old Scan Data Disk Drive which will be replaced

  1. Remove the front Operator Console cover.

  1. Remove the front cover of the Disk Array (JBOD):

    Turn two knobs on the front cover to horizontal position, then take off the front cover from the Disk Array.

    Illustration 5:  Front Cover of Disk Array Assembly

  1. Pull the Scan Disk Drive (with sled) out the Disk Array (JBOD).

    Illustration 6:  Remove Disk Drive (with Sled)

4.2.3  Install the New Scan Data Disk Drive (with sled)

  1. Insert new Scan Disk Driver (with sled) in the Disk Array (JBOD) at the original position of the old disk drive.

  1. Replace the four (4) front mounting screws on the front of the Disk Array (JBOD).

  1. Replace the front cover screen to the Disk Array (JBOD) assembly.

4.2.4  Power ON the Console

  1. Power ON the Operator Console at the front switch.

  1. At the VDARC Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3-10 seconds) to apply power to the VDARC Node.

  1. At the VIG Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3-10 seconds) to apply power to the VIG Node.

  1. At the Disk Array (JBOD) verify two green LEDs at rear panel is on. If not, press the two power switches at rear panel to apply power to the Disk Array (JBOD).

  1. Stop Applications from auto-starting at the 5 second PINK Box.

4.2.5  Test the Disk Array RAID

  1. Perform the Create, Assemble and Query Disk Array RAID Tests per Disk Array RAID Testing

  1. Continue with replacements, as necessary.

4.3  Replace SAF-TE Controller

4.3.1  Power-Off (Shut Down) the Console

Select one of the following methods to Power OFF the Operator Console:

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, select the Shut Down icon and then select [Shutdown] .

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.x) have corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      {ctuser@hostname}  halt

  1. The Operator Console monitor will display a System halted message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch. (Refer to Illustration 1.)

4.3.2  Remove the Old SAF-TE Controller

  1. Remove the rear Operator Console cover.

  1. Remove the SCSI cables on the SAF-TE Controller at the rear of Disk Array (JBOD). Verify each cable is present and clearly marked, if necessary add a label for clarity.

  1. Remove and retain two (2) screws and slide out the SAF-TE Controller.

    Illustration 7:  SAF-TE Controller

    (Sheet 1 of 3)

    (Sheet 2 of 3)

    (Sheet 3 of 3)

    NOTE:Never touch the PCB surface of the SAF-TE Controller. Hold it with the handle.

4.3.3  Install New SAF-TE Controller

  1. Insert new SAF-TE Controller at the rear of Disk Array (JBOD).

Installing the cables in the wrong position will result in patient raw data storage issues that could lead to potential patient misdiagnosis.
 
 

  1. Replace all cable connections on the SAF-TE controller. Ensure that SCSI cable 1 and 2 are connected to their proper connectors.

4.3.4  Test the Disk Array RAID

Do NOT perform the Create command or all data will be lost.
 
 

  1. Perform the Assemble and Query Disk Array RAID Tests per Disk Array RAID Testing

  1. Continue with replacements, as necessary.

4.4  Replace Fan Module

4.4.1  Power-Off (Shut Down) the Console

Select one of the following methods to Power OFF the Operator Console:

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, select the Shut Down icon and then select [Shutdown] .

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.x) have corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      {ctuser@hostname}  halt

  1. The Operator Console monitor will display a System halted message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch. (Refer to Illustration 1.)

4.4.2  Remove the Old Fan Module

  1. Remove the rear Operator Console cover.

  1. Remove the Fan Module by sliding the release lever to the left, and then pulling firmly straight out.

    Illustration 8:  Fan Module

    (Sheet 1 of 2)

    (Sheet 2 of 2)

4.4.3  Replace the New Fan Module and Power-On the Console

  1. Replace the Fan Module by sliding it into its enclosure until it snaps into place.

  1. Power ON the Operator Console at the front switch.

  1. At the VDARC Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3 to 10 seconds) to apply power to the VDARC Node.

  1. At the IG Node verify the front panel Power LED is ON. If not, press the front panel power switch (hold 3 to 10 seconds) to apply power to the VIG Node.

  1. At the Disk Array (JBOD) verify two green LEDs at rear panel is on. If not, press the two power switches at rear panel to apply power to the Disk Array (JBOD).

4.4.4  Test the Disk Array RAID

Do NOT perform the Create command or all data will be lost.
 
 

  1. Perform the Assemble and Query Disk Array RAID Tests per Disk Array RAID Testing

  1. Continue with replacements, as necessary.

  1. Turn OFF the Power Supply switch.

  1. Remove the power cord from the power supply

  1. Remove the defective Power Supply Module by sliding the release lever to the left, and pulling firmly straight out.

4.5.3  Insert the New Power Supply Module

  1. Replace the Power Supply Module by sliding it into its enclosure until it snaps into place.

  1. Replace the power cord to the power supply Module, and latch into place using the power cable clasp.

  1. Turn ON the Power Supply Power switch, insuring that the green light is illuminated.

4.5.4  Test the Disk Array RAID

  1. Continue with replacements, as necessary.

4.6.2  Create/Repartition the Scan Data Disk Array

NOTE:A special create command (sudo gre-raid -c –z) is available for sites that experience issues with the individual disk drive (a good drive the system has tagged as bad). This command still destroys all data by repartitioning or creating the Disk Array. Additionally, it erases the Disk drive serial numbers for the Disk Array (JBOD) allowing reuse of a Disk Drive. Do not use this command on intermittent or faulty Disk Drives. Replace bad Disk Drives. Do Not perform this command if Patient data is not fully backed up. Application Software must be down to perform the create command for the Disk Array.

For remote troubleshooting, verify that you are at the ctuser@darc prompt, not the insite prompt.

  1. Open a Unix Shell and type the following:

    NOTE:The create command (sudo gre-raid -c) destroys all data by repartitioning or creating the Disk Array. Do Not perform this command if Patient data is not fully backed up. Application Software must be down to perform the create command for the Disk Array.

    {ctuser@darc}  sudo gre-raid -c

4.7  Start Applications

  1. {ctuser@hostname}  st

  1. If Application software fails with a halt due tot the Disk Array:

    1. Turn Off power at the front switch on the Operator Console.

    1. Wait one minute for the Disk Array to settle.

    1. Turn On power at the front switch on the Operator Console.

    1. Do Not allow CT Application Software to start-up.

    1. View the gesyslog. Locate the startup time of Application software that just halted. Look for a message related to gre-raid. If the Disk Array is the problem, a message will be present identifying a failure with the gre-raid (Disk Array).

4.8  Retro Recon Test

The Reconstruction (not Scan) portion of the system can be tested at this point.

  1. Click on the [RETRO RECON] selection on the left monitor.

  1. Click on [RAT GOLD] series.

  1. Click on [SELECT SERIES] .

  1. Click on [CONFIRM] .

    Verify the image(s) reconstruct and are displayed.

  1. Click on [QUIT] .

5  Finalization

  1. Take some scans (e.g., scout, axial and helical).

    Verify the image(s) reconstruct and are displayed.

  1. Install the cover of Disk Array (JBOD), if removed.

  1. Install the front and rear Operator Console covers.
