5115335SCH - GOC5 Interconnect

Last Revised:20 September 2006
NOTE:

  • There are two sheets for the GOC5 Interconnect that relate specifically to the VDARC Node Hardware. Sheet 1 applies the original “Westville” VDARC hardware. Sheet 2 applies to the newer “Jarrell” VDARC hardware.

    Please be certain to refer to the Interconnect that applies to your Operator Console variation.

  • The VCT Image Generator (IG) Node hardware is not specifically identified as either Westville or Jarrell. However, whenever a Jarrell type VIG Node is used, it MUST be placed in the bottom standard slot 1 position. The Ethernet cable identifying the bottom IG #1 must be correctly connected between the VDARC Node and the VIG Node. If two Jarrell VIG Nodes are present, the second Jarrell VIG Node must be placed in slot 2 (middle).
