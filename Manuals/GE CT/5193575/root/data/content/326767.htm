Leakage Test

The Leakage Test found in DASTOOLS is a Detector Engineering sanity test. It verifies that the individual components of the detector are operating correctly and free from defects. If this test fails it does not mean that the detector is faulty. This test is meant to be run under strictly controlled environmental conditions. There are no Service Actions in the event of a failure. This test is planned to be removed from the Service screens as it serves no practical purpose for Service personnel.
