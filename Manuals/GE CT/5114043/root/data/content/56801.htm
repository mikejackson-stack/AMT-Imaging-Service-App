System ID Module Replacement

(Click here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1

2  Overview

Remove the system identification module only when replacing the frontplane module.

3  Procedure

  1. Remove the system identification module.

    1. Lift up on the metal retaining clip.

    1. Slide the system identification module to the side and out.

    Illustration 1:  Removing the System ID Module

  1. Place the system identification module on the new frontplane.

    1. Lift up on the retaining clip.

    1. Slide the system identification module under the clip.

      NOTE:The System ID Module contains the host Ethernet Address number. If you replace this item, all of your Software Options (which are fingerprinted to this number) will be unavailable. You will have to order a new Options MOD(s) to restore option software, in this case.

4  Finalization

No finalization required.
