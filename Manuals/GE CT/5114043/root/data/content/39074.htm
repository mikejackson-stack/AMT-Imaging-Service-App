kV Diagnostic

[SERVICE DESKTOP] -> [DIAGNOSTICS] -> [X-RAY GENERATION] -> [KV LOOP] -> [HV MANUAL]

Illustration 1:  kV Diagnostic Screen

1  Diagnostic Description

This diagnostic operating the KV inverters without mA and at low input voltages. This test does NOT require the connection of the x-ray tube. However, if the tube is disconnected, the HV cables should be connected to a bleeder or disconnected at the HV tanks.

2  When (to use)

  1. This test should be run with the HVDC set to test mode (~75VDC) when the following errors are detected:

    • Over currents

    • Shoot-through

    • mA over currents.

  2. Run test when a shorted x-ray tube or HV cables are suspected.

3  What (to look for)

  1. Look for where the current stops with the HVDC set to the test mode:

    1. Inverter currents should be less than 1 to 2 amps of current

    2. mA should be less than 2mA

  2. High pot the tube (use bleeder) to remove the tube from the circuit and rerun the test.

4  Notes

  1. Use HVDC test mode (~75VDC) to check for shorts. KV will NOT reach the prescribed value in this mode.

  2. Normal rail voltage should only be used to test for dielectric breakdowns. Turn on one side (cathode/anode) at a time, since the bang-bang circuit was not designed for accurate KV loop control.

  3. High potting the tube is very dangerous if not done correctly, even with the HVDC bus set to test mode.
