Service Laptop Setup

1  Windows 2000

1.1  Minimum Requirements

Windows 2000

1.2  Hardware Setup

Connect the Ethernet patch cable between the console’s front service port (see Illustration 1) and the laptop.

NOTE:A cross-over network cable will NOT work.

Illustration 1:  Global Console Service Ethernet Port

1.3  Laptop Network Settings

  1. On the laptop desktop, open [MY NETWORK PLACES] .

  2. Right click in the white area and select [PROPERTIES] .

  3. Select [LOCAL AREA CONNECTION] .

  4. Select [PROPERTIES] .

  5. Right click on [INTERNET PROTOCOL [TCP/IP]] .

  6. Select [PROPERTIES] .

    NOTE:Write down all current laptop IP settings displayed on this screen. This settings will be required to return the laptop to “normal”.

  7. Select [USE THE FOLLOWING IP ADDRESS] .

  8. Type 192.9.220.220 [ENTER] .

    The laptop’s IP address is now 192.9.220.220. The laptop is on the same subnet as the OC computer.

  9. Enter Subnet: 255.255.255.0

  10. Click [OK] .

  11. Click [OK] .

1.4  Using the Connection

1.4.1  Method 1: cmd Command

  1. On the laptop, select [RUN] from the [START] menu.

  2. Type: cmd

  3. Click [OK]

  4. Type: 192.9.220.1

    NOTE:This is the OC computer’s IP address

  5. Login as root or ctuser, and use Unix/application commands as appropriate.

1.4.2  Method 2: telnet Command

  1. On the laptop, select [RUN] from the [START] menu.

  2. Type: telnet

  3. Click [OK]

  4. Type: open 192.9.220.1

    NOTE:This is the OC computer’s IP address

  5. Login as root or ctuser, and use Unix/application commands as appropriate.

    NOTE:For a list of commands, type: help

1.5  CT Login

  1. At the root prompt, type: su - [ENTER]

  2. At the password prompt, type: #bigguy [ENTER] .

  3. Type viewlogs [ENTER] .

2  Service Laptop Setup - Windows 98

2.1  Hardware Set Up

Plug the Ethernet cable into the front service port of the Global console.

2.2  Laptop Set Up - Windows 98

  1. Select:

    1. [START]

    2. [SETTINGS]

    3. [CONTROL PANEL]

    4. [CONTROL PANEL] (double click to select)

  2. Select:

    1. [INTERNET PROTOCOL [TCP/IP]]

      NOTE:Record your current network settings.

    2. [PROPERTIES]

  3. Select: [SPECIFY AN IP ADDRESS]

  4. Type 192.9.220.220 [ENTER] .

    1. Click [OK] .

    2. Click [OK] .

  5. Close all Windows applications then select:

    1. [SHUT DOWN]

    2. [RESTART MY COMPUTER]

  6. When restart is completed, select:

    1. [START]

    2. [RUN]

  7. Type Telnet [ENTER] .

  8. At the Telnet prompt, type:

    1. 192.9.220.1 [ENTER] .

    2. net mask 255.255.255.0 [ENTER]

2.3  CT Login

  1. At the root prompt, type: root [ENTER]

  2. At the password prompt, type: #bigguy [ENTER] .

  3. Type viewlogs [ENTER] .
