Data Acq: Detector Heater

1  Theory - Detector Heater Operation

In order for the DAS to obtain consistent and accurate detector diode signals, the X-ray detector modules must be kept at a constant temperature. This tight temperature control is accomplished by hardware circuits located on the DHCB (Detector Heater Control Board). The power applied to the Detector Heaters is drawn from an external 24V DC power supply.

The DHCB has the ability to sense up to three thermistors located on the Detector Assembly and can operate up to three Detector Heaters (this capability is for multi-zone Detector Temperature Control). Precision analog circuitry on the DHCB convert the thermistor resistance to an equivalent digital code to be read by an on-board micro-controller program. This program then operates on-board Power MOSFET switches to apply power to Detector Heaters. Temperature control is accomplished by simple on-off control - i.e. if the temperature is below the Heater ON set-point, the Detector Heaters are turned on, and if the temperature is above the Heater OFF set-point, the Detector Heaters are turned off.

The DHCB incorporates circuitry to:

  • Accomplish three-zone Detector Heater control, if necessary.

  • Communicate with a Detector Memory Board to store Detector-specific operational data.

  • Apply bipolar output voltages for future Peltier-device cooling of the Detector assembly.

The DHCB expands on the functionality previously provided by part of the DCB. In addition, it allows Detector temperature control development to be independent of DCB hardware road-maps. It also eliminates bulky external relays previously used to operate Detector Heaters.

5.1  Display Message: “Failure to Communicate with DHCB”

5.1.1  Possible Reasons for Error

  1. DCB does not sense DHCB

  2. DHCB is not powered

5.1.2  Troubleshooting Summary

  1. Check Cable Connections

  2. Check Power Supply Voltages

  3. Check DHCB.

  4. Escalate to next level.

5.1.3  Troubleshooting Details

  1. Check Cable connections

    • Check the Error Log to see if the DHCB is detected. If detected, go to section 'Check Power Supply Voltages'.

    • If DHCB is not detected, unplug the DHCB-DCB RS232 cable (2288183) from J16 on the DAS Right Backplane, and check resistance between pins 4&8 on the cable to be 2Kohms. If the 2K ohm is present, the fault is in the DCB - follow relevant procedures for its test, and retry - End of Procedure.

    • If the 2Kohm resistance is not present, unplug the DHCB-DCB RS232 cable from J2 on the DHCB, and check the resistance between pins 4&8 on J2 on the DHCB. If the 2Kohm is present, the fault is with the cable - replace it and retry - End of Procedure.

    • If the 2Kohm resistance is not present, the fault is with the DHCB - replace it and retry - End of Procedure.

  2. Check Power Supply Voltages

    • Check 24VDC output voltage of the +24VDC Power Supply. If not present, the fault lies either in the Power Supply or its loads (Both the Xray Collimator and the DHCB draw power from the +24VDC Power Supply). Check the fuse at the input of the +24VDC Power Supply. If it is blown, replace it and retry - End of Procedure.

    • If the fuse is not blown, and the 24VDC is not present the fault could be with the +24VDC Power Supply. Follow relevant procedures or replace the Power Supply and retry - End of Procedure.

    • If the 24VDC output of the Power Supply is present, go to section 'Check DHCB'.

  3. Check DHCB.

    • Disconnect 2288184 cable from the DHCB, and check if 24VDC is being supplied to the DHCB on the Mate-N-Lok (DHCB-J3) Pins 5 and 9. If not present, the fault is with the cable - replace it and retry - End of Job Card.

    • If the 24VDC is present, on the cable, the fault is with the DHCB - replace it and retry - End of Job Card.

  4. End Level 1, On-site troubleshooting. Escalate Problem.

5.2  Display Message: “Low Detector Temperature”

5.2.1  Possible Reasons for Error

(This Procedure assumes that the DHCB has not displayed a Thermistor Error / Heater Error / Control Table Error. If any of these errors are displayed, look at corresponding Procedures)

  1. Detector Thermistor is faulty.

  2. DHCB Analog circuitry / Master Control / MOSFET module has a fault.

5.2.2  Troubleshooting Summary

  1. Check Detector Thermistor.

  2. Check DHCB.

  3. Escalate to next level.

5.2.3  Troubleshooting Details

  1. Check Detector Thermistor

    • Read the Detector temperature (on the Service Desktop). If it is greater than 33º C, there is DCB - DHCB Communication Error. Escalate to next level. End of Procedure.

    • If the DHCB reads a temperature <15.2º C, there is a possible Thermistor open or loose connection. Check the Thermistor cable connections on 2288184 Cable Harness (DHCB J1) - pins 2&10. The resistance should be identical to that between pins 4&5 on “Detector Right” Mate-N-Lok Connector which is the heater connector at the other end of the harness. If the two resistances are not identical, there is cable harness fault. Replace 2288184 Cable Harness. Refer to the DHCB functional diagram in System Diagrams for further pinouts. End of Procedure.

    • If the resistance is about 10K ohms, the temperature of the Detector Assembly is about 25º C. Check the connections of 2288184 between the DHCB and the Detector Assembly, plug the connector back and reset the DHCB. Check Error status and read Detector temperature. If all is okay (there was a loose connection), end procedure.

  2. Check DHCB

    • There can be three reasons why the DHCB is reading a low temperature:

      1. The Master Heater Power switch on the DHCB is off.

      2. There is a failure of the Heater Control Power MOSFET and they have failed open.

      3. There is a fault in the DHCB analog circuitry and the ADC is reading wrong voltages.

    • If the error log indicates a DHCB A/D error, replace the DHCB. End of Procedure.

    • With the DHCB powered on, check the voltage between pins 1&4 on DHCB-J3 of 2288184 from the back of the Mate-N-Lok Connector (Do not remove the connector for measuring the voltage). These pins supply power to the Detector Heater, and during a low-temperature, they should be ON. If the voltage is NOT 24V, but about 0-3V, then there is a MOSFET switch error on the DHCB. Replace the DHCB. End of Procedure.

  3. End Level 1, On-site troubleshooting. Escalate Problem.

5.3  Display Message: “High Detector Temperature”

5.3.1  Possible Reasons for Error

(This procedure assumes that the DHCB has not displayed a Thermistor Error / Heater Error / Control Table Error. If any of these errors are displayed, look at corresponding procedures)

  1. Detector Thermistor has an error.

  2. DHCB Analog circuitry / Power MOSFETs have an error.

5.3.2  Troubleshooting Summary

  1. Check Detector Thermistor.

  2. Check DHCB.

  3. Escalate to next level.

5.3.3  Troubleshooting Details

  1. Check Detector Thermistor

    • Read Temperature from DHCB. If it is less than 38.5º C, there is DCB - DHCB Communication Error. Escalate to next level. End of Procedure.

    • If the DHCB reads a temperature >55º C, there is a possible Thermistor short or faulty connection. Check the Thermistor cable connections on 2288184 Cable Harness (DHCB J1) - pins 2&10. The resistance should be identical to that between pins 7&8 on “Detector Right” Mate-N-Lok Connector. If it is not identical, there is cable harness fault. Replace the Cable Harness. End of Procedure.

    • Plug the 2288284 harness back and reset the DHCB. Check Error status and read Detector temperature. If all is okay (there was a faulty connection), end procedure.

  2. Check DHCB

    • There can be two reasons why the DHCB is reading a high temperature:

      1. There is a failure of the Heater Power Switches and they have failed short; i.e. the Detector is indeed over-heating

      2. There is a fault in the DHCB analog circuitry and the ADC is reading wrong voltages.

    • With the DHCB powered on, check the voltage between pins 1&4 on DHCB-J3 of 2288184 from the back of the Mate-N-Lock Connector (Do not remove the connector to measure the voltages). These pins supply power to the Detector Heater, and during a low-temperature, they should be OFF. If the voltage is 24V, and NOT between 0-3V, then there is a MOSFET switch error on the DHCB. Replace the DHCB. End of Procedure.

    • If the error log indicates a DHCB A/D error, replace the DHCB. End of Procedure.

  3. End Level 1, On-site troubleshooting. Escalate Problem.

5.4  Display Message: “Detector Thermistor Fault”

5.4.1  Possible Reasons for Error

  1. Detector Thermistors can be open / short.

  2. Cable can have loose connection.

  3. DHCB Analog circuitry has an error.

5.4.2  Troubleshooting Summary

  1. Check Detector Thermistor.

  2. Check DHCB.

  3. Escalate to next level.

5.4.3  Troubleshooting Details

  1. Check Detector Thermistor

    • Read the Detector temperature (on the Service Desktop). If it is <15.2º C, there is a possible Thermistor open or loose connection. If the temperature is >55º C, there is a possible Thermistor short or faulty connection. Check the Thermistor cable connections on 2288184 Cable Harness (DHCB J1) - pins 2&10. The resistance should be identical to that between pins 4&5 on “Detector Right” Mate-N-Lok Plug of the Detector. If the two resistances are not identical, there is a cable harness fault. Replace 2288184 Cable Harness. End of Procedure.

    • If the thermistor resistance between pins 4&5 on “Detector Right” Mate-N-Lok Plug of the Detector Harness shows an open (or a resistance greater than 15.0K ohm), or a short (or a resistance less than 3.25K ohm), then there is a thermistor fault. Follow procedures to replace the Detector Assembly. End of Procedure.

    • If the thermistor resistances lie between 15 and 3.25K ohm, check the connections of 2288184 between the DHCB and the Detector Assembly, plug the connector back and reset the DHCB. Check Error status and read Detector temperature. If all is okay (there was a loose connection), end procedure.

  2. Check DHCB

    If the resistances and the cable connections are correct, the only reason the DHCB can read a thermistor open or short is due to a fault in the DHCB analog circuitry - with the ADC reading wrong voltages. If the error log indicates a DHCB A/D error, replace the DHCB. End of Procedure.

  3. End Level 1, On-site troubleshooting. Escalate Problem.

5.5  Display Message: “Detector Heater Fault”

5.5.1  Possible Reasons for Error

  1. The Detector Heaters have an error (open or short)

  2. Loose cable connections

  3. DHCB has an error / malfunction.

5.5.2  Troubleshooting Summary

  1. Check Detector Heater.

  2. Check DHCB.

  3. Escalate to next level.

5.5.3  Troubleshooting Details

  1. Check Detector Heater

    • Power down the DHCB and disconnect “DHCB-J3” of 2288184. Measure the resistance between pins 1&4 of the Mate-N-Lok Plug. This resistance reading should be identical to that read between pins 1&2 of the Detector Plug mating with the “Detector Right” Mate-N-Lok on 2288184 Harness. If the two readings are different, there is cable harness fault. Replace 2288184. End of Procedure.

    • A regular heater should have a resistance of about 9.6 ohms. If the resistance between pins 1&2 of the Detector Plug mating to the 2288184 Cable Harness reads either an open or a short, then there is a heater error. Follow procedures to replace the Detector Assembly. End of Procedure.

    • If all resistances are normal, plug back the complete assembly and power up the DHCB. Check the error status of the DHCB. If all reads okay (i.e. there was a loose connection), end procedure.

  2. Check DHCB

    The DHCB can show an incorrect Heater Fault state if the Power MOSFETs on its board were to have failed, and were malfunctioning. In this case, replace the DHCB and retry. If all is okay, end Procedure.

  3. End Level 1, On-site troubleshooting. Escalate Problem.

5.6  Display Message: “Control Table Fault”

5.6.1  Possible Reasons for Error

  1. DMB EEPROM has incorrect information.

  2. There is a DHCB EEPROM / I2C error.

5.6.2  Troubleshooting Details

  1. If the error log shows “Control Table Fault“, replace the DHCB. If the system still faults, go to the next step.

  2. End Level 1, On-site troubleshooting. Escalate Problem.
