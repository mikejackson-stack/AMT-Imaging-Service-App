2  Overview

There is a tty vendor diagnostic available to test the SDC portion of the PEG-IG board called rundmc. The executable is located on the SBC in /usr/g/bin. Invoking the diagnostic will reboot vxWorks to a diagnostics mode on the Motorola (RIP) Board. Exiting the diagnostic does not reboot vxWorks back to Applications. Restarting Applications, ‘st’ will reboot vxWorks to the applications recon state.

3  Procedure

NOTE:Because vxWorks is rebooted upon execution of this diagnostic, Applications must be shutdown before running diagnostics on the SDC portion of the PEG-IG board.

  1. From the Service Desktop select [UTILITIES] .

  1. Select [APPLICATION SHUTDOWN] .

  1. Open a UNIX Shell and enter the following commands:

    > cd /usr/g/bin

    > rundmc

  1. Menu Option [2] displays the main menu. Execute tests in verbose mode. Select <ENTER>.

  1. Enter your desired loop count; the default is [1] then select <ENTER>.

  1. vxWorks re-booting messages appear on the screen and the board level tests will appear as they are run. The tests for a single pass complete within a few minutes.

  1. When tests are complete, results with number of passes and failures is displayed.

  1. <ENTER> returns you to the Main Menu.

  1. If desired, select 4 to view the log.

  1. If desired, select 5 to view the help menu.

  1. Select 6 to Exit.

  1. Return to the OC prompt and startup Applications by entering “st”. Applications startup will re-initialize vxWorks.

No finalization required.
