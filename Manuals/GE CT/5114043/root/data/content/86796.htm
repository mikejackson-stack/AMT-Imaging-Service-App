Hard Artifact Troubleshooting

1  Error

None available

2  Theory

What causes a “hard” or “gross” ring, band or center spot artifact:

  • Definition of a “hard” or “gross” artifact is a ring, band, or center artifact that will not “cal out”. If the artifact can be “cal'ed out”, the problem can involve a drift problem, which involves a different troubleshooting process and different FRUs than a “hard” artifact. Refer to Troubleshooting Job Card “IMAGE DRIFT”

  • Loss of data on a channel or very non-linear data. The difference between a ring, band or center spot is the location of the channel position. The width of the artifact is determined by the number of consecutive bad channels. Refer to Troubleshooting Job Card “RING ARTIFACT”

The most likely FRUs to cause this type of artifact:

  • Cals

  • DAS

  • Elastomer

  • Detector

  • Tube (not probable because the artifact will cal out)

  • Collimator (not probable because the artifact will cal out)

  • Beam obstruction (not probable because the artifact will cal out)

3  Troubleshooting Summary

  1. Verify that the artifact is true by re-scanning using same technique.

  2. Fast Cal, then rescan

  3. Full set of cals, then re-scan. (In the interest of time, cal the one technique where artifact is most conspicuous.)

  4. DAS Troubleshooting

  5. Detector Troubleshooting.

  6. End level 1, on site troubleshooting - Escalate

  8. Zone Support

4  Troubleshooting Details

  1. Artifact verification

    Verify that the artifact is true by re-scanning, using the same scenario (i.e. same technique, FOV, protocol etc.).

    PASS: Images are good, artifact not repeatable. Problem most likely is a “soft” artifact. Reference the troubleshooting job card for “IMAGE DRIFT”

    FAIL: Artifact is repeatable and “hard”. PROCEED to the next step.

  2. Analyze the Scan Data

    Using Scan Analysis, plot the scan data using MSD, convolved and look for spikes. Refer to “RING ARTIFACT” troubleshooting Job Card for detailed procedure. If Scan analysis doesn't show any spikes, then PROCEED to the next step.

  3. Fast Cal

    • See if the artifact can be cal'ed out using “Fast Cal”. Run the full set of fast cals. Objective of this step is to verify if it is a cal problem or a hardware problem.

    • After fast cals are done, verify artifact is still present re-scanning using the same scenario (i.e. same technique, FOV, protocol, etc.).

      PASS: Images are good, artifact has been “fast cal'ed” out. Problem can be drift. Reference the procedural job card for “IMAGE DRIFT”

      FAIL: Artifact is repeatable and “hard”. PROCEED to the next step.

  4. Full Set of Cals

    • See if the artifact can be cal'ed out. Re-cal the whole system. Objective of this step is to verify if it is a cal problem or a hardware problem.

    • Full cals can take a long time, therefore in the interest of time, it is ok to cal just the technique of which the artifact is happening.

    • After cals are done, verify artifact is still present re-scanning using the same scenario (i.e. same technique, FOV, protocol etc.).

      PASS: Images are good, artifact has been “cal'ed” out. Problem can be drift. Reference the procedural job card for “IMAGE DRIFT”

      FAIL: Artifact is repeatable and “hard”. PROCEED to the next step.

  5. DAS/Detector Troubleshooting

    • At this point of the job card, the assumption is that cals or drift caused by particles or non uniformity are not the problem.

    • Assumption that there is a hardware problem in the DAS or Detector.

    • Refer to DAS Troubleshooting Procedures (Offset & Noise, X-Ray Verification, Ring in Image, DAS Backplane Continuity).

      PASS:

      FAIL: Proceed to the next step.

  6. END LEVEL 1, ON SITE TROUBLESHOOTING

    • Collect all data gathered during the above procedures.

    • Escalate problem.
