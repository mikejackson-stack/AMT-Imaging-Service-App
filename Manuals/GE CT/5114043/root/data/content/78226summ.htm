1.3   Low Contrast Detectability

1.3.1  Image Performance Verification

  1. Select the third 20cm QA Phantom image series (QA#2 Holes) from the exam acquired in the previous section.

    1. From the Global Control Palette, click on the [IMAGE WORKS] Desktop.

    1. From the Image Works Desktop, select the [IMAGE WORKS BROWSER] window.

    1. Select the exam and the third series acquired in the previous section.

    1. Select the [VIEWER] button on the Image Works Browser window. Set up the viewer window for four-image viewing.

  1. Build a 10 mm x 100 mm reference ROI Box using the Image Works Viewer tools.

    1. Click on the grid button to place a grid on the first image.

    1. Click on the [MEASURE] button and select the box ROI icon.

    1. Adjust the size of the ROI box to be a rectangle of approximately 10 mm x 50 mm (500 mm2) box.

      (Step Details)

  1. Collect Mean values for two reference ROI Box positions on four (1st, 3rd, 5th, and 7th) of the eight 20cm QA#2 Phantom images.

    (Step Details)

  1. View the 1st, 3rd, 5th, and 7th images of the QA#2 Holes Series, record the number of visible holes in Table 2, and verify each image meets specifications.

    1. While viewing the 1st, 3rd, 5th, and 7th images, indicate in Table 2 the number of holes that can be visually distinguished. See Illustration 2.

    1. Verify Visible Hole visual check meets specifications listed in Table 3 for the calculated Contrast Factor and record in the HHS Record Tables.

    (Step Details)

1.4   QA#3 Phantom Brightness Uniformity and CT#

1.4.1  Performance Verification

  1. Select the fourth 20cm QA#3 Phantom exam acquired in the previous section.

    1. From the Global Control Palette, click on the [IMAGE WORKS] Desktop.

    1. From the Image Works Desktop, select the [IMAGE WORKS BROWSER] window.

    1. Select the exam and fourth (QA#3) series acquired in the previous section.

    1. Select the [VIEWER] button on the Image Works Browser window. Set up the viewer window for four-image viewing.

  1. Build a 31 x 31 pixel reference ROI Box using the Image Works Viewer tools.

    1. Click on the grid button to place a grid on the first image.

    1. Click on the [MEASURE] button and select the box ROI icon.

    1. Adjust the size of the ROI box to be a square 15 mm x 15 mm (225 mm2) box. Tolerance: 15 mm ± 1 mm (196 mm2 to 256 mm2).

      (Step Details)

  1. Collect Mean values for five reference ROI Box positions on the eight 20cm QA#3 Phantom images.

    (Step Details)

  1. Calculate the Brightness Uniformity and CT# values for each image in the series, record values in Table 5, and compare to specifications.

    1. Calculate and record the average means values (AvXo) for the four outside Boxes (Boxes 2 through 5) for each of the images and record in Table 4.

    1. Calculate and record the average center box (Box 1) means values (AvXc) for each row (2A1A: Images 1, 3, 5, and 7; 1B2B: Images 2, 4, 6, 8) in Table 5.

    1. Calculate and record the average outside boxes (Box 2 through 5) means values (AvXo) for each row (2A1A: Images 1, 3, 5, and 7; 1B2B: Images 2, 4, 6, 8) in Table 5.

    1. Calculate the Brightness Uniformity (AvXo - AvXc) value for each row and record in Table 5.

    1. Verify Brightness Uniformity (AvXo - AvXc) value and the average CT# value (AvXc) for each row meets specifications listed in Table 5.

    1. Record the 20cm QA#3 Phantom Brightness Uniformity (AvXo - AvXc) value and average CT# value (AvXc) for each row in the HHS Record Tables.

    (Step Details)

1.5   QA#3 Phantom Noise

1.5.1  Performance Verification

  1. Select the fourth 20cm QA#3 Phantom exam acquired in the previous section.

    1. From the Global Control Palette, click on the [IMAGE WORKS] Desktop.

    1. From the Image Works Desktop, select the [IMAGE WORKS BROWSER] window.

    1. Select the exam and fourth (QA#3) series acquired in the previous section.

    1. Select the [VIEWER] button on the Image Works Browser window. Set up the viewer window for four-image viewing.

  1. Build a 51 x 51 pixel reference ROI Box using the Image Works Viewer tools.

    1. Click on the grid button to place a grid on the first image.

    1. Click on the [MEASURE] button and select the box ROI icon.

    1. Adjust the size of the ROI box to be a square 25 mm x 25 mm (625 mm2) box. Tolerance: 25 mm ± 1 mm (576 mm2 to 676 mm2).

      (Step Details)

  1. Collect Standard Deviation values for the single reference ROI Box position on the eight 20cm QA#3 Phantom images.

    (Step Details)

  1. Calculate the average Noise values for each image in the series, record values in Table 6, and compare to specifications.

    1. Calculate and record the average Noise values (AvSDc) for the inside Boxes for each of the two rows (2A1A and 1B2B) and record in Table 6.

    1. Verify Noise (AvSDc) values for each row meets specifications listed in Table 6.

    1. Record the 20cm QA#3 Phantom Noise (AvSDc) for each row in the HHS Record Tables.

    (Step Details)
