2  Theory

2.1  Why You Got It

  • The RCIB FAULT LINE is a 12vdc signal originating on the HEMRC Control Board. This signal goes to the Collimator Control Board (CCB), DAS Control Board (DCB), and through the CAN bus terminator.

  • The RCIB FAULT LINE wiring is included inside the CAN bus cabling. The purpose being to create a fault whenever this cable is not installed, or not installed properly, this includes the CAN bus terminator missing or installed incorrectly.

  • The 12vdc signal first just pass through each board, then again enters each board to be used as a fault line. This fault line being asserted will generate the above error messages.

  • The RCIB FAULT LINE is an indication that the CAN bus has become disconnected somewhere, or was not installed properly.

  • The above error is a primary error, do not focus on other error log messages until this error has been cleared.
