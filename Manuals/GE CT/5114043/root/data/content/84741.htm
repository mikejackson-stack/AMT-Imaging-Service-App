2  Theory

2.1  Why You Got It

KV is regulated by the KV board which monitors the KV from the feedback sensed by the voltage dividers in each HV Tank. KV is maintained by adjusting the operating frequency and duty cycle of each Inverter. If the KV is not within 3% of each other, a error will be posted to the operator but scanning can continue. When the KV is different by 5% or more the scan will abort (diagnostics will not abort).

NOTE:KV reported to the screen does not necessarily indicate what the actual kv is due to potential kv gain calibration. KV imbalance is usually due to the result of a component being “opened”.

3  Troubleshooting Summary

  1. Verify that this is the primary error.

  2. Determine which KV board is installed in system.

  3. Run KV LOOP test and use result screens to determine FRU - This is the diagnostics you want to fail because the tube can be verified/eliminated as the problem.

  4. IF KV LOOP does NOT fail, run KV & mA test and use result screens to determine FRU.

  5. Scope KVp.

4  Troubleshooting Details

  1. Verify that this is the primary error

    • This is necessary because different KV bd's regulate KV in a different manner.

    • Examine error log and determine if this is the primary error. If associated with overcurrents or Shoot-Throughs, troubleshoot those errors first.

  2. Determine which KV board is installed in your system.

    • The easiest way to do this is to look at the result screen of either KV Loop or KV & mA Test. The two newest boards will have two additional lines: Cathode/Anode Inverter Duty Cycle. The old KV Bd will NOT have any 'Duty Cycle' displayed.

    • Oldest KV Control Bd 46-321064

    • Middle generation KV Control Bd 46-321198

    • Newest KV Control Bd 2143147

  3. Use KV Loop Test and Result Screens

    • This is the diagnostics where the system can be high potted. The x-ray tube and/or HV cables can be replaced by a High Voltage Bleeder, thus eliminating (or confirming) the x-ray tube and/or HV cables as a cause.

    • Use Job Card “RESULTS SCREEN FOR PERFORMIX KV LOOP”

      FAIL: RESULTS SCREEN FOR PERFORMIX

      • Repair / Replace as needed.

      • Verify System Operation.

      • YOU ARE DONE.

      PASS: RESULTS SCREEN FOR PERFORMIX KV LOOP ok, then proceed to Step 4.

  4. Use KV & mA Test and Results screens. See “Explanation of kV/mA Results Screen,” in kV Troubleshooting Theory.

    FAIL: RESULTS SCREEN FOR PERFORMIX

    • Repair / Replace as needed.

    • Verify System Operation.

    • YOU ARE DONE.

    PASS: RESULTS SCREEN FOR PERFORMIX KV &mA ok, then proceed to Step 5.

  5. Scope the KVp waveform

    • Scope TP-1 to TP-18 on the measurement board of each HV Tank. This is a 10,000/1 divider, so 2VDC Vertical and 50msec/div Horizontal are good starting points.

    • Scope the KVp waveform using the HV Bleeder. See kV Troubleshooting Theory.

      FAIL: “KVp Waveform”

      • Repair / Replace as needed.

      • Verify System Operation.

      • YOU ARE DONE.

      PASS: KVp Waveform OK.
