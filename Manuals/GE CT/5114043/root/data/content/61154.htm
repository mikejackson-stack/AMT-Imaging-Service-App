Octane Graphics Subsystem Troubleshooting

1  SI (Solid Impact) or SE (Solid Impact Enhanced)

The Octane graphics board that controls the primary “head,” (the monitor normally on the right) is in slot A. It is called SI (or SE) with Texture Memory or IMPACTSR with 4 TRAMs.

You can troubleshoot these boards by trying the secondary board in the primary slot, but at least one of the two must be installed in the primary slot and working to boot the system. The SI (or SE) with Texture Memory must be in Slot A to run the scanner applications.

(For Octane 1 only) Refer to Octane XIO Module Replacement for replacement procedure.
