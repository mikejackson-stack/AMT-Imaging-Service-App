2  Overview

Image Drift Test Theory:

Objective of the Image Drift Test:
  • An Image Drift Test will isolate a more subtle ring, band or center artifact that occurs over time relative to time of last Fast Cal or Detail (Phantom) Cal.
  • The difference between a ring, band or center spot is the location of the channel position. The width of the artifact is determined by the number of consecutive bad channels.
  • An image drift test will isolate a problem between the tube, detector or collimator.
FRUs Involved:
  • Particle in the x-ray beam
  • Tube (particle in the beam)
  • Collimator (particle in the beam, or non-uniform bowtie filter)
  • Gain difference in the Detector
  • Cals
  • Detector Heater/Control

3  Procedure

3.1  Troubleshooting Summary

  1. FULL SET of FAST CALS to re-establish a clean cal baseline.

    System should now be “warm”.

  1. ON A “WARM” SYSTEM, CREATE BASE LINE IMAGES and check for the artifact.

    • This step also assumes that the detector has been spinning and therefore detector temperature is uniform across the detector.

    • “Warm” DDC air scans will be used for later troubleshooting. Save and remember these scans for later use.

    NOTE:Artifacts should not exist. If artifact does exist, it would be considered a “hard” artifact.

  1. CHECK DETECTOR HEATER

  1. CREATE a “Cold” system by waiting 45 minutes (with gantry parked), then repeat baseline image scans.

  1. NORMALIZE DETECTOR TEMPERATURE by spinning the gantry for 20min. Then repeat baseline image scans.

  1. ANALYZE MS DD FILES, then reference matrix.

  1. END LEVEL 1, on site troubleshooting

    • Check system message log for detector temperature messages.

    • Detector Heater P.S. output check.

    FAIL: Detector is not heating. Repair Detector Heater Function. Re-verify images.

    PASS: PROCEED to the next step

  1. CREATE a “Cold” system by waiting 45 minutes, then repeat scans using baseline image scan parameters.

    IMPORTANT: The gantry should not be spun during 45 minute wait, as one of the objectives of this test is to get a temperature gradient across the detector. The detector must be parked and stationary for two hours to achieve this gradient. (A properly operating detector is not sensitive to temperature gradients of this type.)

    If the artifact does not repeat when cold, then the problem was most likely a cal problem of some type that either doing a fast cal or phantom cals corrected.
