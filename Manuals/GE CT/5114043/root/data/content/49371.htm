LightSpeed 3.X Service Methods (Advanced)

Axial and Helical Scan Times

1  Axial Scans

Use normal applications (new patient) to acquire Axial Scans with the following parameters:

  1. Use <120KV> and <40MA.>

  2. Use scan time and FOV in Table 1.

Table 1:  Axial Scan Times and FOVs

SELECTED TIMEFOV
0.6 secsmall FOV
0.6 seclarge FOV
1.0 seclarge FOV
2.0 seclarge FOV
3.0 seclarge FOV
4.0 seclarge FOV

2  Helical Scans

Use normal applications ( [NEW PATIENT] ) to acquire Helical Scans with the following parameters:

  1. Use <120KV> and <40MA.>

  2. Use <10MM> Scan Thickness.

  3. Use scan time and location in Table 2.

  4. When you complete the scan time tests, switch back to the [SERVICE DESKTOP] to display the Diagnostic Data Collection screen, and toggle the [MONITOR ENABLE] OFF. Otherwise, the message log fills with kV, mA and scan statistics.
