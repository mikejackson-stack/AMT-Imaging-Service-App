LightSpeed 3.X Service Methods (Advanced)

Host Computer - Octane/Octane2 Troubleshooting

The following modules provide information useful for troubleshooting the Octane1 and Octane2 computers:

  • Overview - Diagnosing Octane Hardware Problems - brief overviews of Power-On Tests and Hardware Inventory (hinv).

  • Power-On Tests - Octane and Octane2 - includes information on:

    • Power-Up Sequence (Overview)

    • Light Bar LEDs

    • CPOP Connector LEDs

    • Computer Panics

  • Host Hardware Inventory (hinv) - Octane and Octane2 - includes an example hinv command.

  • Confidence Tests - Octane and Octane2 - test descriptions include:

    • Audio Test

    • CD-ROM Test

    • Keyboard Test

    • Monitor Test

    • Mouse Test

  • PCI Device Checks - Octane and Octane2 - includes descriptions (where applicable) of “Device Recognition”, “Software Driver” and “Operating System Mapping” for:

    • Fast Ethernet (100Base-TX) Adapter - SGI

    • SCSI PCI Card - SGI

    • Serial Expansion PCI Card - Digi ClassicBoard

  • DIMM Memory - Octane and Octane2 - includes information on:

    • Checking for Faults

    • Memory Identification

  • Octane2 Graphics Subsystem Troubleshooting - troubleshooting information for Octane2, including:

    • Common Problems

    • Operating System Hardware Recognition

    • Operating System Compatibility

    • Hardware Compatibility

  • Octane Graphics Subsystem Troubleshooting - troubleshooting information for Octane (original), including:

    • SI (Solid Impact) or SE (Solid Impact Enhanced)

    • Octane Graphics System Hardware

  • SCSI (Integral) Interface Checks - includes descriptions of:

    • Device Recognition

    • Software Driver

    • Operating System Mapping
