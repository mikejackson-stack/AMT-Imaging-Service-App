GOC6 Load From Cold

1  Required Conditions

ConditionReferenceEff

All hardware components of the System must be functional.

-

-

The Operator Console Front Cover will need to be removed to gain access to the Host Computer DVD Drive.

-

-

A valid and current System Save State on DVD-RAM Media. System should already been configured for site specific configuration and preferences. If System State disk is missing or not current, some or all of the following must be performed: (1.) A manual configuration using information contained on the System Configuration Data Sheet completed at installation time. (2.) Software Options Licences will need to be manually reloaded. (3.) System Calibrations will need to be performed.

-

-

Only trained service personnel should service the GE CT Scanner.

-

-

2  Procedure

2.1   Software Deliverable

2.1.1  VCT

VCTC Collector for GOC6 Console

  1. CTT Operating System, Version 5.2.13

  1. VCT Applications Software

  1. GOC6 Class C Software DVD

  1. GOC6 Class M Software DVD

2.2   Pre-LFC Checks and Information Gathering

  1. Confirm that a current System State DVD-RAM Disk is on site. If unsure of status of the System State, execute System State Save Restore found in the Software Chapter of this manual.

  1. As a backup to the System State Disk, confirm that a GOC6 Console Information Sheet is available and is completely filled out with site-specific configuration and preference settings.

2.3   Operating Software (OS) Load

  1. Unplug the Hospital Network (HSP - J26) cable from rear Console bulkhead.

  1. Label the cable as HSP - J26 (if necessary) and set it aside during LFC.

  1. Remove the Operator Console front cover per the prescribed procedure Console Cover Removal and Installation.

  1. Insert the OS DVD into the tray on the Host Computer DVD-ROM Drive ( Illustration 1).

    (Step Details)

  1. Shutdown and Power Cycle Operator Console:

    1. Using the toolchest, open a Terminal Window.

      1. Type: {ctuser@hostname}halt

      1. Wait for System Halted message to appear on the monitors.

        (Step Details)

    1. Cycle Operator Console power. Wait 30 seconds for the Operator console to settle down before re-powering the console.

  1. As the Host Computer restarts, the boot process messages appear. After the booting process completes the boot: prompt appears.

  1. At the “boot:” prompt, type the following:

    (Step Details)

  1. After the OS is loaded on the Host Computer, Complete Window appears.

    (Step Details)

  1. Remove the OS DVD from the Host Computer DVD-ROM drive when it ejects and close the tray. Press [Enter] to Reboot.

  1. The Host Computer begins to reboot.

    (Step Details)

2.4   Applications Software (APPS) Load

  1. Open the tray on the Host Computer DVD-ROM Drive.

  1. Insert the Applications DVD into the DVD-ROM Drive and close the tray.

    (Step Details)

  1. Select [Run Command] in the Warning box.

    (Step Details)

  1. Select [Load] in the CT Software Installation window.

    (Step Details)

  1. System State decision for the Install INFO decision box will appear.

    (Step Details)

  1. Insert the System State DVD-RAM into the Peripheral Tower.

    (Step Details)

  1. The Install INFO on the System State disk will be read and if a valid System State Disk has been inserted, an Accept window will appear.

    (Step Details)

  1. The Install INFO on the System State disk will be displayed and a confirmation window will appear.

    (Step Details)

  1. System Install INFO will be now used to create the CT Application load routine. A message will appear briefly stating: “Please make sure the CT application media is in the drive - the system will be rebooted”.

  1. Do not remove the APPS disk at this time. The Operator Console will reboot automatically. A shell window will open and the CT Application software will be loaded.

  1. When completed the Operator Console will display a window requesting that the console be rebooted. Select [YES] .

    (Step Details)

  1. After the Operator Console has rebooted, a window will be displayed stating that the CT Application cannot autostart.

    (Step Details)

2.5   DIG Software Load

  1. Open a Terminal Window, and log on at root:

    1. Type: {ctuser@hostname} su – [ENTER] .

    1. Type the root password and press [ENTER] .

  1. In the Terminal Window Type: [root@hostname] load_darc_subsystem [ENTER] .

    (Step Details)

  1. When finished the Shell window will display “DIG load has successfully completed”. Close Shell window.

    (Step Details)

2.6   Check System Date and Time

  1. In the remaining open Terminal Window:

    (Step Details)

  1. Set the appropriate date and time values as needed. Follow instructions on screen for setting date and time.

2.7   Service Software Load (Proprietary SW)

NOTE:Service software (Class C) applies only to GE Healthcare personnel and customers with an Advance Service Limited License agreement. If loading Class M software see instructions included with the CD.

NOTE:The Class C software version must match the Application software version loaded.

  1. Insert Class C Service Software CD into the Host Computer DVD drive.

  1. In Terminal Window

    (Step Details)

  1. Close Shell Windows after Class C software has successfully loaded.

    (Step Details)

  1. Remove Class C service software from the Host Computer DVD drive.

  1. (For GE Healthcare personnel only) Install the Class M software per the instructions included with the CD.

  1. Close the Shell Window once Service Software install is complete. Leave Terminal Window open.

2.8   Restore System State

  1. In the Terminal Window, Type: [root@hostname] reboot [ENTER] .

  1. Allow the System to come up fully into application Mode. If the CT Applications fail to start automatically, open a Terminal Window.

    (Step Details)

  1. Insert the System State DVD-RAM Disk into the Peripheral Tower DVD-RAM drive.

  1. Wait until the DVD-RAM drive is ready (i.e., front panel DVD drive LED is no longer lit).

  1. Select: [Service] to access the Common Service Desktop (CSD).

    (Step Details)

  1. Select: [Utilities Tab] .

    (Step Details)

  1. Select: [System State] . The System State Save/Restore screen appears.

    (Step Details)

  1. Select [All] .

  1. Select [Restore] . The Restore System State box appears.

  1. Select [Yes] .

    (Step Details)

  1. Verify that the "Restore" of System State was successful. A message at the end of the System State Message Log Window should state: “Save/Restore System State: Completed Successfully.”

    (Step Details)

  1. When completed, select [Cancel] , then [Dismiss] .

  1. Select Shutdown icon on the Desktop and restart the system.

2.9   Software Options

NOTE: If performing a Load From Cold (LFC) for the first time and Software Option Licenses plus site-specific configuration has not been saved to System State, Software Options will need to be loaded manually.

  • See Install Software Options to load manually.

    OR

  • Software Options licenses will be loaded during Restore System State. Proceed to next section.

2.10   Flash Download

  1. On the Common Service Desktop – Utilities Tab, select [Flash Download] .

    (Step Details)

  1. When the Flash Download Window opens,

    (Step Details)

  1. Once the Gantry Hardware Flash Downloads successfully, select [Dismiss] .

  1. Close the Common Service Desktop.

  1. Reconnect the Hospital Network cable at the rear of the Operator Console (J26) disconnected at the beginning of the LFC.

  1. Select Shutdown icon on the Desktop and restart the system.

2.11   Final Save System State

  1. Insert the System State DVD-RAM Disk into the Peripheral Tower DVD-RAM drive.

  1. Wait until the DVD-RAM drive is ready (i.e., front panel DVD drive LED is no longer lit).

  1. Select the Service icon to access the Common Service Desktop (CSD).

  1. Select: [Utilities] tab.

  1. Select: [System State] . The System State Save/Restore screen appears.

  1. Select [All] .

  1. Select [Save] . The Save System State box appears.

  1. Select [Yes] .

  1. Verify that Save System State was successful. A message at the end of the System State Message Log Window should state: “Save/Restore System State: Completed Successfully.”

  1. When complete, select [Cancel] , then [Dismiss] .

  1. After completing Save System State, store the DVD-RAM Disk in a safe place.

3  Finalization

  1. After completing Save System State, store the DVD-RAM Disk in a safe place.

  1. Go to the Functional Checks Chapter > System Scanning Test document to confirm proper operation.

  1. Reinstall Console Front Cover.
