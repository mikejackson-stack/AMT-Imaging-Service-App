2  Overview

This module explains how to run the “HHS Scans” procedure, which runs an automated scan sequence and measures the kV and mA at times during the scan to ensure that the system is properly calibrated.

Last Revised:November, 2004

3  Procedure

  1. Launch the [GENERATOR TOOL] from the Service Desktop.

  1. Launch the [HHS SCANS] tool.

  1. Run the sequence.

  1. The tool will let you know if it passes. The scan data will be stored on the system and can be viewed using the “HHS Reports” tool.

No finalization required.
