3.3  Safety

CRASH HAZARD !
THE TABLE MUST BE SUPPORTED USING THE SUPPORT TOOL AS DESCRIBED BELOW WHEN CHANGING THE SHUT OFF VALVE.

4  Procedure

  1. Raise the Table to maximum height.

  1. Perform this step if applicable:

    (For Global PET/CT Table, with fixed position IMS) Move the Cradle to OUT limit position.

    (For Global PET/CT Table) Move the Cradle and IMS to OUT limit position.

    (For GT1700 and GT2000 Table) Move the Cradle and IMS to OUT limit position.

  1. Remove power from Table by turning off 120VAC, Axial Drive and HVDC switches on Service Switch Panel.

  1. Remove the following Table covers:

    • IMS Rear Cover

    • IMS Side Cover (Left)

    • Front/Rear Side Plate (Left)

    • Front Leg Plate (Left)

    Illustration 1:  Table Covers

  1. Remove 2 upper support brackets of the side plates (left) by unscrewing its 2 (x2) screws, and open the side plates.

    Illustration 2:  IMS Cover (Left) and Side Plates (Left) Removal

  1. Attach the Table Support Tool as follows:

    1. Perform this step if applicable:

      (For GT1700 and GT2000 Table) Skip this step.

      (For Global PET/CT Table and Global PET/CT table, with fixed postion IMS) Release Transporter and manually push up against the rear Hard Stop.

      Illustration 3:  Table Pushed Against Hard Stop (Global PET/CT Table)

    CRASH HAZARD!
    THE TABLE IS VERY HEAVY AND CAN MOVE IF THE GLOBAL PET/CT TABLE TRANSPORTER IS NOT SECURED!
    The transporter must be secured from moving before attaching the table support tool.

    1. Perform this step if applicable:

      (For GT1700 and GT2000 Table) Skip this step.

      (For Global PET/CT Table and Global PET/CT table, with fixed postion IMS) Attach one of the “L” shaped alignment blocks to the front linear rail (The alignment blocks and hardware came with the Table and should have been stored away during install). Tighten bolt as shown in order to secure the Transporter.

      Illustration 4:  Tighten Alignment Block (Global PET/CT Table)

    1. The adjuster of the support tool A should be partially extended, about 3 cm, before supporting the Table.

      Illustration 5:  Table Support Tool

    1. Attach the support tool A to the left top frame, and turn the set screw to CCW to fix the support tool A.

      Illustration 6:  Support Tool 'A' Attachment (GT1700, GT2000 and Global PET/CT Table)

      Illustration 7:  Support Tool 'A' Attachment (Global PET/CT table, with fixed position IMS)

    1. Attach the other support tool A to the right top frame, and turn the set (hexagon) screw to CCW to fix the support tool A.

    1. Attach the support tool B to the support tool A using 4 screws.

    1. Extend the adjusters by turning them so that the adjusters touch the floor, and lower the Table onto the support.

      Illustration 8:  Table Support Tool Attachment (GT1700 and GT2000 Table)

      Illustration 9:  Table Support Tool Attachment (Global PET/CT Table and Global PET/CT table, with fixed position IMS)

  1. Remove power from Table by turning off 120VAC, Axial Drive and HVDC switches on Service Switch Panel.

  1. Cut any tie-wraps holding the valve cable to the Table frame.

  1. Disconnect the valve cable connector.

  1. Put the oil pan under the shut off valve, and unscrew 4 screws, then remove the shut off valve from the cylinder assy.

    Illustration 10:  Shut Off Valve Removal (GT1700, GT2000 and Global PET/CT Table)

    Illustration 11:  Shut Off Valve Removal (Global PET/CT table, with fixed position IMS)

  1. Transfer the O-ring from the removed shut valve to a new shut valve, and install the new valve into place.

Properly position the O-ring on the new shut valve. If not, a oil can be leaked out from the joint.
 
 

  1. Tighten the 4 screws.

  1. Route the valve cable just like the old cable, and connect the valve cable connector, then fix the cable to the Table frame with tie-wraps.

    Illustration 12:  Valve Cable Routing

  1. Carefully remove the Table support tool.

5  Finalization

  1. Power up the Table from the Service Switch Panel.

  1. Raise and lower the Table repeatedly to verify that the cables do not catch or pull excessively.

  1. Turn off all 3 switches (Axial Drive, HVDC, 120VAC), and re-install the Table covers:
