3  Procedure

3.1   Console FE Service Port Setup

  1. Open a Terminal window and log on as root:

    (Step Details)

  1. At the prompt type: enableFEport. Ouput similar to the following example is returned:

    (Step Details)

3.2   Laptop Setup to Static IP 10.44.22.50

  1. To configure a laptop for a static IP address, on the Desktop right click on My Network Places.

  1. Select [Properties] .

  1. Select Local Area Connection.

  1. Select [Properties] .

  1. Select Internet Protocol (TCP/IP). See Illustration 1.

    (Step Details)

  1. Select [Properties] . The Internet Protocol (TCP/IP) Properties window opens.

  1. Select Use the following IP address and enter 10.44.22.50,Subnet Mask 255.0.0.0. See Illustration 2.

    (Step Details)

  1. Click [OK] to close the Internet Protocol (TCP/IP) Properties window.

  1. Click [Close] to exit the Local Area Connection Properties window.

  1. Disable wireless and all other networks on laptop.

3.3   Testing the Laptop to Network Connection

3.3.1  TELNET Session

  1. Connect the Cat 5 cable from the laptop to the FE service port at the front of the console.

  1. On the laptop, select [Start] > [Run] .

  1. Enter cmd and click [OK] . A DOS shell opens.

  1. At the “>” prompt enter telnet>10.44.22.20.

  1. Logon as follows:

    (Step Details)

  1. The laptop to network connection is established.

    (Step Details)

3.3.2  FTP (Hummingbird) Session

  1. In Hummingbird Application select New FTP Profile.

  1. Set Host Address to: 10.44.22.20.

  1. Set User Name to: ctuser

  1. Set password to: 4$apps

  1. Select [OK]

  1. Select the new created FTP profile and then 'drag-n-drop' the files to your desktop.

3.4   Setting Up the Console Service Screens

  1. On the console service desktop select the [Utilities] button from the top menu bar.

  1. Now select Utilities from the left navigation menu.

  1. Select Change Display IP.

  1. Write down the address the display is currently set to.

  1. In the blank boxes onscreen, enter 10.44.22.50 and click [Submit] . The following message appears onscreen:

    (Step Details)

3.5   Launching Exceed

  1. Launch Exceed via [Start] > All Programs > Hummingbird Connectivity > Exceed > Xstart. The Xstart Client Startup Application window opens ( Illustration 3).

    (Step Details)

  1. Complete the cells in the Xstart Client Startup Application window as follows ( Illustration 4):

    (Step Details)

  1. Save as Desktop > Laptop to Console 10.44.22.20

  1. Open file on Desktop. An xterm window opens.

  1. Enter service_browser. The service desktop is now accessible.

Potential Injury
Accessing the service desktop from the laptop involves using InSite tools that cause motion or X-ray.
Make sure that no one is near the gantry, table, or PDU.

  1. When you are finished using the service tool, reconfigure the Change Display screen to the original address you wrote down in Section 4-4, Step 4.
