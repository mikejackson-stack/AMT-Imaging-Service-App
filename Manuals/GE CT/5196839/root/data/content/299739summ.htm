1.1   Monitor Connections and Powering Up

  1. Connect the 15-pin Sub-D connector cable(s) between the Operator Console’s HOST and each monitor’s blue connector INPUT 2 D-SUB. See Illustration 1.

    (Step Details)

  1. Connect the AC in line cord from the Operator Console to each monitor's rear side using the GE supplied console power cord. See Illustration 2.

    (Step Details)

  1. Apply power to each monitor by setting the Main Power Switch on the left side of the monitor to the ON position. See Illustration 3.

    (Step Details)

  1. Press the front panel far right button to apply power to each monitor. Verify the blue LED is illuminated. See Illustration 4.

    (Step Details)

1.2   Host LCD Monitor Setup and Calibration

The operator workspace monitor must be properly adjusted for the filmed image to accurately represent the console monitor displayed image. This procedure describes how to adjust the monitor to match the camera. Once the monitor is re-calibrated, it is essential to re-calibrate the camera before the system is used for filming. (Note that this procedure is only for the LCD color monitor and not for the CRT monitor.)

1.2.1  Installing the SMPTE Test Pattern

The Society of Motion Picture and Television Engineers (SMPTE) test pattern is used to provide a standard image for calibrating the Contrast, Brightness, Window, and Level of the display for a scanner. See Illustration 5.

Illustration 5:  Sample Test Pattern

  1. Access the Common Service Desktop (CSD).

  1. From the CSD select the Image Quality tab.

  1. From the menu select Install SMPTE pattern image. An Installation Window will appear.

  1. Allow the SMPTE pattern to load. A "Successful Copy" message will appear when the load is complete.

    (Step Details)

  1. Press <Enter> to leave the Installation Window.

  1. Click the [Image Works] icon, and select the Image Browser

  1. Use the scroll bar, as required, to select the SMPTE test image from the Exam list.

  1. Click Full Viewer. If necessary, use the FORMAT option to select Full Screen mode.

  1. Leave the SMPTE test pattern on the monitor and proceed to Section 4.2.2, NEC1990 SXi On-Screen Manager (OSM) setup.

1.2.2  NEC1990 SXi On-Screen Manager (OSM) Setup

  1. Access OSM on monitor display by pressing Exit, Left, Right, Up or Down control buttons on monitor.

    (Step Details)

  1. Due to the fact that OSM can be accessed by anyone, custom setting can be altered. To assure correct baseline settings, first reset to monitor back to factory presets by navigating to Menu Tools > Factory Presets and pressing SELECT.

    (Step Details)

  1. Find and select AUTO CONTRAST setting.

  1. Find and select Option 2 for AUTO BRIGHTNESS.

  1. Find and set AccuColor Controls and select Option 1. Option 1 sets color temperature to 9300K.

  1. Press [Exit] control button to turn off OSM on the monitor display.

1.2.3  Window and Level Setting

  1. Press [Exit] control button to turn off OSM on the monitor display.

  1. Set the default Window and Level Setting to 100.

  1. With the cursor inside the image displayed in Illustration 7, hold down the middle mouse button and move the mouse in the horizontal plane. View the window control value at the base of the image and set the window control value to 100.

    (Step Details)

  1. With the cursor inside the displayed image, hold down the middle mouse button and move the mouse in the vertical plane. View the level control value at the base of the image and set level control value to 1024.

  1. Remove the SMPTE Pattern by selecting a different Exam from the browser, or by selecting <ESC> on the keyboard.

    (Step Details)

1.3   Monitor Positioning

1.3.1  Raise and Lower Monitor Screen

  1. Place your hands on the side of the monitor.

  1. Lift or lower the monitor to the desired height. See Illustration 8.

    (Step Details)

1.3.2  Tilt and Swivel

  1. Grasp both sides of the monitor screen with your hands.

  1. Adjust the monitor tilt and swivel as desired. See Illustration 9.

    (Step Details)
