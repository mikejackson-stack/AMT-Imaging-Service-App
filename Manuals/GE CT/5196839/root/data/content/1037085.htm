2  Overview

This troubleshooting procedure and associated Service Tool is designed to be used on systems using the interposer design. This includes all MDAS 16-slice and GDAS 16-slice systems. It is intended to be used to troubleshoot rings ( Illustration 1) and isolate problems between the rings and the DAS or Detector.

4  Procedure

NOTE:The tool will not work on a DAS that uses elastomers. (4 and 8 slice scanners).

  1. Use DASTools to locate the bad/noisy channel. (See Illustration 3.)

    Illustration 3:  DASTools Display of Typical Noise Spike

  1. Physically remove the flex from the bad/noisy channel.

  1. Physically remove the flex from an adjacent good channel.

  1. Install one side of the Channel Crossover Tool to the Detector.

  1. Install the other side of the Channel Crossover Tool to the DAS. (See Illustration 4 and Illustration 5.)

    Illustration 4:  Channel Crossover Tool Installed

    Illustration 5:  Channels Crossed Using the Crossover Tool

  1. Use DASTools to see if bad channel moved, or stayed the same.

  1. If the bad channel indication moved 16 channels, the problem is with the Detector

  1. If the bad channel did not move, a DAS issue is indicated. Isolate the DAS issue. See Illustration 6 and Illustration 7.
