Search
Searching requires that dtSearch be installed on your hard drive. If you do not have dtSearch installed, you will not be able to use this feature. You may install dtSearch from the latest Service Release CD-ROM (Red disk).
Launch dtSearch from default install location
(Answer Run Now, then Yes to the dialog boxes that appear.)
Note: This will produce an error if dtSearch is not installed or if it is installed in a different location.
If you have dtSearch, here are instructions on performing a search.
  1. Select Search.
  2. Enter your search term(s) in the "Search Request" field.
  3. In the Search dialog box, select the "More Search Options" tab.
  4. Select "Unindexed search only."
  5. Click "Select directories" and choose "E:\Signa Methods\content" from the directory tree.
  6. Click OK.
  7. Click Search. The search will run and return search your results.
