DVD-ROM 2360027-300 is a single disk equivalent of the formerly multi-disk
CD-ROM set, 2360027-200. The CD-ROM set is no longer available.

2152913 contains service information for legacy systems, including the HiSpeed
CT/i and previous CT Scanners.

2360027-300 contains service information for the LightSpeed Family of CT
Scanners (i.e., LightSpeed 1.X, 2.X, 3.X, 4.X, 5.X, 7.x, BrightSpeed,
and HiSpeed QX/i) and the Discovery CT750 Scanner. Revision 10 and later also
includes Pre-LightSpeed manuals that have been updated since the last release 
of 2152913.

Individual HTML publications are indexed with dtSearch. Select "Help - dtSearch
(Version 6.4)", located in the "Readme" tab of each HTML publication, to view 
directions for using dtSearch.

PDF directories (e.g., "ls_1.x") have been individually indexed, for Advanced 
PDF Search capabilities.

This revision includes an ePST for LightSpeed 1.X-4.X scanners. For an overview
of ePSTs, please follow the "What is an ePST?" link in the left navigation 
pane, under "ePSTs" Please read the "ePST Install Note" file, prior to
loading the ePST onto your computer, to ensure full functionality.

*******************************************************************************
  
Some of the Publications on this DVD-ROM are still available for order in paper
format by following the normal ordering method for technical publications. 
Printed copies may be ordered on-line through SSP (formerly GEMS-Buy).
Use the direction number on the document’s title page as the identifier. 
Please note that there may be a considerable delay, in some cases, of 1 or 2 
weeks to fill a request.

Exception 1: Any doucment without a Direction number and a Revision number may
not be ordered.

Exception 2: Any document with a "-800" extension is NOT available in paper.
This extension indicates that the document is an "e-pub" only. The user
may, however, make print-outs of such documents, if they so require. Any such
prints are subject to all applicable proprietary information restrictions.

Exception 3: A "-200" extension indicates that the part is a CD-ROM. CD-ROMs
are available for order from Coakley-Tech, via GEMS-Buy.

Please refer to "ctse_cd-roms.pdf", located in the "xtras" directory, for
information on which CD-ROM contains which e-pub.

//////////////////////    Troubleshooting/Issues     //////////////////////////
*******************************************************************************

** Class A document cannot be found on DVD-ROM or CTSE Techpubs website. Class A
manuals have been removed, where a Class C equivalent is available. All Class A
CTSE-AM manuals are available on the Common Documentation Library (CDL): 
http://olcweb.olc.med.ge.com:8020/servlet/ClientServletProp?REQ=Enter+
Documentation+Library

** Xtra's documents not available in paper. The ’xtras’ directory includes 
documents from multiple sources and contributors. Either because these 
documents do not have GE Healthcare part numbers or the accuracy of the document 
cannot be completely verified, they are provided "as is". Xtra documents are not 
necessarily under GE Healthcare internal revision control, but may be under 
revision control by the author. They are provided as a service to you and should 
be used with some caution. Problems or defects with "xtra" documents should be 
reported using GE Healthcare iTrack process and to their associated authors. If 
problems are serious enough, the document(s) will be modified or removed from 
future releases as warranted until fixed. New contributions can be submitted to 
CTSE-AM for consideration and inclusion in future releases of this DVD-ROM. 

** Document revision numbers do not match GPCP/ePDM. Always check PCICS/ePDM 
to ensure that you are using the most current revision of a publication.

** Document revision numbers do not match those found on the MI&CTSE web site
or CDL. The Common Documentation Library (CDL) and the MI&CTSE web site will 
always contain the most up-to-date publications. 2360027-300 is issued three 
times a year, and contains the most current manuals at the time of release of 
the DVD.
