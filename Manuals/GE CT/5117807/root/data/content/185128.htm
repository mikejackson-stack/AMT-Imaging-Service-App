2  Overview

This module describes how to verify that communication has been established with the DARC Node or it has been “pinged.” After verifying the communication line exists between the HP Host PC and the DARC Node, a remote shell will be invoked to determine if the DARC Node is up.

4  Procedure

  1. Open a Unix Shell.

  1. At the {ctuser@hostname} prompt, type su - < Enter>

  1. At the Password: prompt, type #bigguy < Enter>

  1. At the [root@hostname] prompt, type # ping darc < Enter>

    PING darc (172.16.0.2) from 172.16.0.1 : 56(84) bytes of data.

    64 bytes from darc (172.16.0.2): icmp_seq=1 ttl=64 time=0.157 ms

    64 bytes from darc (172.16.0.2): icmp_seq=2 ttl=64 time=0.209 ms

    64 bytes from darc (172.16.0.2): icmp_seq=3 ttl=64 time=0.175 ms

    64 bytes from darc (172.16.0.2): icmp_seq=4 ttl=64 time=0.134 ms

  1. Select < Control-C> to stop the ping.

    --- darc ping statistics ---

    4 packets transmitted, 4 received, 0% loss, time 3000ms

    rtt min/avg/max/mdev = 0.134/0.168/0.209/0.031 ms

  1. At the [root@hostname] prompt, type # rsh darc < Enter>

    Last login: Thu Oct 9 11:17:35 on ttyS1

    You have new mail.

  1. At the [root@darc ~] prompt, type # exit < Enter>

    logout

    rlogin: connection closed.

  1. [root@hostname]#
