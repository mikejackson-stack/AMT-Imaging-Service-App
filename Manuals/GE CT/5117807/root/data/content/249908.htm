2  Overview

New Tube prepares the system to store tube usage statistics, for trend analysis, and tube warranty purposes.

Last Revised:March 2003

4  Procedure

  1. Select [REPLACEMENT].

  1. Select [TUBECHANGE].

  1. Select [CHANGETUBE].

  1. Refer to the list in Table 1, and type/enter the failure code for the defective tube in the “Tube Unit Failure Code” field on the screen.

    failcode < ENTER>

    Table 1:  Tube Failure Codes

    Failure CodeFailure Code
    AI: Image Artifact OH: Other-Housing Related
    BG: Broken Glass OL: Generator Overload
    CA: Casing Arcing OR: Other-Rotor Related
    CB: Casing Bubbles/Particles Seen PF: Overheat/Pump Failure
    CL: Casing Oil Leak PT: Pulled Tube (No Failure)
    GS: Grid Short RF: Frozen Rotor
    OC: Other-Cathode Related RN: Noisy Rotor
    OE: Tube Loss Due to Failure Elsewhere SD: Shipping Damage/Error
    OF: Open Filament SS: Stator Open/Stator Short
    OG: ArcingXL: Low X-Ray Output

  1. Refer to the Tube Housing; type/enter the new Tube’s Insert Serial Number in the appropriate field on the screen.

    Insert Serial Number

  1. Refer to the Tube Housing; type/enter the new Tube’s Housing Serial Number in the appropriate field on the screen.

    Housing Serial Number

  1. Click OK to accept these changes (see Illustration 1).

    Illustration 1:  Change Tube Screen
