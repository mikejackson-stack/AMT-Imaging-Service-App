2  Overview

Normally, the table cradle can travel up to 1700 mm from the home position. The Short Footprint function can limit this distance to a value between 1300 and 1700 mm (in 1 mm increments).

NOTE:Some notes about the short footprint function follow:

  • If you moved the cradle out the set maximum distance, and when the table is lowered, then the cradle will move outward so that the cradle distance from the gantry remains unchanged. In this case also, the maximum cradle travel is limited to 1700 mm. And this control is executed only when the Positioning Lights are turned on.

  • If you moved the cradle out the set maximum distance while the table is not at the highest position, then the system will inhibit the table upward operation.

  • During the table characterization procedure, or while operating the cradle with the service switches on the MTCB board, the cradle is enabled to move up to 1700 mm, regardless of the short footprint set distance.

4  Procedure

  1. Attach the cradle extender on the cradle.

  1. Launch the [Mechanical Characterization ] tool from the Service Desktop, Utilities tab.

  1. Select [Short Foot Print].

  1. Click [OK] in response to the “Clear the previous record to move cradle?" message.

    This will erase the previously set distance of the maximum cradle movement. The maximum distance will be set to 1700 mm. See Illustration 1.

    Illustration 1:  Initial Screen

  1. Follow the on screen instructions.

    You can set the desired cradle travel distance with any table height. After clicking [Accept], the distance will be stored on the console computer.

  1. After the setting, verify that you can not move the cradle inward further from the set position, with the following conditions:

    • The table is at the highest position.

    • The table is at a lowest position where scanning is possible.
