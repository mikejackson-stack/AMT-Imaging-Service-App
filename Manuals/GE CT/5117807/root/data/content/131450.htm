4  Procedure

  1. Remove the Mylar Scan Window.

  1. Launch Diagnostic Data collection, DDC from the Service Desktop.

    1. Select DIAGNOSTICS.

    1. Select DIAGNOSTIC DATA COLLECTION.

    1. Select POSITION TUBE.

    1. Enter 180 and execute.

    1. Select STATIC X-RAY OFF.

      1. Filter AIR.

      1. Slice Collimation Largest Aperture, 4 x 5.00 for example.

    1. Select ACCEPT RX.

  1. Using the flashlight, inspect the primary copper filter by looking down into the collimator output port. See Illustration 1.

    Illustration 1:  Collimator Output Port

    NOTE:The copper filter should be clean, dent and scratch free. Discoloration is acceptable. Illustration 2 shows an extremely contaminated copper filter.

    Illustration 2:  Extremely Contaminated Copper Filter

  1. If contamination is visible proceed to the cleaning process.
