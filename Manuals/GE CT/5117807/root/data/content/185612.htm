2.2  Host - scsistat

2.2.1  Procedure

  1. Open a shell window.

  2. Type: scsistat < Enter>

    An example output is shown in Section 2.2.2: Example Output.

  3. Shutdown the system and after the prompt, turn OFF the console power switch.

  4. Turn OFF the SCSI tower power switch at the front of the unit.

  5. Turn ON the console power switch. Stop the boot-up process at the Linux level by selecting [OK] when prompted to do so.

  6. Repeat the scsistat commands. Note the changes to the list.

  7. Stop here and insure that you understand what these lists are showing you as well as how the list was detected.

  8. Shut down; power OFF console.

  9. Turn ON the SCSI tower power switch and perform the commands again.

    NOTE:These devices will not be usable by the system until the system is rebooted and recognized during the boot-up process.

3.3  DARC - sens-v

3.3.1  Procedure

When software is not booted, the Host talks to the DARC and the DARC talks to the IG via a serial over LAN connections. Use the same connection to check the status of the DARC (or IG - sens-v). Use to check voltage, temperature, and fan speed.

  1. Open a Linux shell as root.

  2. Type: telnet localhost 623 < Enter>

    NOTE:If the message “connection refused” appears, perform the following actions:

    • Type: ps -aef | grep dpcproxy < Enter>

      (Notice that dpcproxy is not running, only grep for dpcproxy.)

    • Type: service cliservice start < Enter>

      The following message appears:

      starting dpcproxy.

    • Type: ps -aef | grep dpcproxy < Enter>

      (Notice that both dpcproxy and grep are running now.)

    • Type: telnet localhost 623 < Enter>

  3. Enter server name as darc.

  4. Leave the Username and Password fields empty.

  5. Press < Enter> .

    Login successful and a dpccli> prompt appear.

  6. Type: sens -v < Enter>

3.4  DARC - DipDiag

NOTE:Before running this test, ensure that the CT Applications are NOT running.

  1. Open a UNIX shell.

  2. Type: rsh darc < Enter>

  3. Type: cd/user/g/bin < Enter>

  4. Type: DipDiag < Enter>

  5. When prompted to continue, type y.

    +---------------------------+

    | DIP Diagnostics Main Menu |

    +---------------------------+

      1. X-ray Enable Relay

      2. Test FEC Bit

      3. Test EDDR Bit

      4. Test Magic Number Register

      5. Memory Test

      6. Interrupt Test

      7. External LoopBack Test

      8. DMA Test

      0. Exit

  6. Select your test by typing its number. (See Test numbers, above.)

    NOTE:Tests 7 and 8 WILL FAIL, if a Loopback Cable is not used.

    You may select more than one test.

3.5  DARC - Messages

Messages files took the place of SYSLOG.

  1. Open a Linux shell.

  2. Type: rsh darc < Enter>

  3. Type: cd/var/log < Enter>

  4. Type: more messages < Enter>

For more information, see GOC3 Message Logs (adv).

3.6  DARC - Clear the RECON Queue

The command “cleanq” will remove all entries. Do not use this without verification that all prospective scans have been processed or deemed unnecessary. Do not run this command when applications are running.
 
 

  1. Open a shell window.

  2. Type: rsh darc < Enter>

  3. Type: cd/usr/g/bin < Enter>

  4. Type: RECON_STOP < Enter>

  5. Type: cleanq < Enter>

  6. Type: RECON_START < Enter>

3.7  DARC - reset -c

3.7.1  Procedure

Used on the DARC (or IG) for troubleshooting only. Invoking this command is the equivalent of pushing the Reset button on the front of either the DARC or IG. The unit will reboot and the -c switch causes the bootup script to be echoed to the terminal from which the command was issued (remote or shell on system).

NOTE:After using this command, you must reboot the entire system prior to scanning to insure all devices are synced.

  1. Open a Linux shell.

  2. Type: telnet localhost 623 < Enter>

  3. Enter the server as darc.

  4. Username : < Enter>

  5. Password: < Enter>

  6. Type: reset -c < Enter> .

  7. A boot up script appears (see Example Output, below).

  8. Type: exit < Enter> .

4.4  IG - RAC Test

4.4.1  Procedure

Run the RAC (Recon Accelerator Card) test on the IG if you experience:

  • No recon

  • Slow recon

  • Artifacts

Prior to running this test, ensure that CT Applications are NOT running.
 
 

  1. Open a Linux shell.

  2. Type: rsh darc.

  3. Type: cd /usr/g/bin < Enter>

  4. At the ctuser prompt, type: racdiags < Enter> .

These tests are pass/fail. If any of the tests fail, replace the IG.

4.5  IG - reset -c

4.5.1  Procedure

Used on the IG (or DARC) for troubleshooting only. Invoking this command is the equivalent of pushing the Reset button on the front of either the DARC or IG. The unit will reboot and the -c switch causes the bootup script to be echoed to the terminal from which the command was issued (remote or shell on system).

NOTE:After using this command, you must reboot the entire system prior to scanning to insure all devices are synced.

  1. Open a shell as root.

  2. Type: rsh darc < Enter>

  3. Type: telnet localhost 623 < Enter>

  4. Enter the server as ig1.

  5. Type: reset -c < Enter> .

  6. A boot up script appears (see Example Output, below).

  7. Exit.
