2  General Instructions

  1. Make certain that the HIPAA Component EA3, Enterprise Authentication Questionnaire has been completed.

  2. Use the flowchart above to determine your system configuration.

  3. Select the appropriate link from the bar above (e.g., “4 or 8-Slice with HP8000”).

  4. Choose the appropriate upgrade package from the list that appears. Upgrade Packages include:

    • FX Workflow Package

    • Xtream II Workflow Package

    • Xtream FX Workflow Package (contains both of the above)

  5. Follow the links on the flowchart to complete the Upgrade.

  6. If HIPAA EA3 installation is required, do this now.
