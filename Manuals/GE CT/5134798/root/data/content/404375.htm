Appendix A - Hardware Parameters Selection

1  Introduction

This Appendix applies only to systems using the - "LFC Procedure - Version 05MW14.5" software load procedure.

2  Procedure

This procedure explains how to correct the hardware configuration if the DAS Type, Tube Type, PDU Type, or Gantry Type information on Hardware screen is not correct.

  1. On Hardware screen, click the [HARDWARE PARAMETERS SELECTION] button. This displays the hardware selection popup. Refer to Illustration 1.

  2. Select the correct system configuration from the displayed list (this closes the hardware selection popup).
