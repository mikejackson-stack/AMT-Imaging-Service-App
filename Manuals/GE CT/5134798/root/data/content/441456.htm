Manual Commands for gettubeusagedata

Last Revised:31 May, 2005

If the command gettubeusagedata fails to execute, then run the script manually.

In the Unix shell, execute the following commands as ctuser:

  1. mountMOD -I2L <Enter>

  2. mv /usr/g/service/.bb /usr/g/service/bb.lfc <Enter>

  3. mkdir /usr/g/service/.bb <Enter>

  4. rm -rf /tmp/*bb <Enter>

  5. cp /MOD/service_mod_data/system_state/*bb /usr/g/service/.bb/ <Enter>

  6. /usr/g/bin/SwapTubeData <Enter>

  7. /bin/cp -f /tmp/*bb /usr/g/service/.bb/ <Enter>
