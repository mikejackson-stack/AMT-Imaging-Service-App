2  GOC3 Upgrade Checklist

2.1  Before you Begin

  • Save System State.

    (Be sure to save any customer reformat files that might exist.)

  • Verify and record specific system hardware configuration (see below).

    Open a shell and type: cat /usr/g/config/INFO<ENTER>

  • Save all network configuration files information.

  • Locate all REQUIRED software for your GOC3 system installation.

  • Locate option DVDs and confirm all ordered options are present.

  • Locate the GOC3 documentation CD ROM -2384451-200.

  • Review pre-install for new GOC3 console cooling requirements

    (Refer to “Cooling Requirement” section in Environmental Conditions)

  • Review the console power requirement (GOC3 =120vac) (non GOC=240vac)

  • Determine filming if DASM II Digital - save your DASM II and cable.

  • For all other DASM configurations order a new digital DASM II Kit.

  • Network communication BB or dial up.

    If dial up save your modem and cable.

  • If remote monitors connections are required, order required B-cats on back page.

3  Mechanical Upgrade Installation

3.1  Before you Begin

  • Review FE skills required: GOC3 Training required for this upgrade.

  • Review tools required.

  • Confirm that cooling and power requirements are met.

  • Complete GOC3 Upgrade Checklist ( Step ) and Power down system, and then LOTO.

3.2  GOC3 Mechanical Installation

  • Inventory all components to be removed.

  • Carefully disconnect all system cables from console.

  • Remove and pack: trackball, mouse, keyboard, SCIM, Cables and monitors.

  • Disassemble console table top assembly and pack on top of console.

  • Remove console from room and clean (remove) dust from area.

  • Remove the console from skid in the room. Unpack and assemble new console.

  • Use the boxes to pack and return removed components.

  • Follow the installation procedure to assemble and connect the console.

    (Refer to Unpacking and Installing the GOC3 Console and Console Connections, for details.)

  • Refer to the 14 x 17 wiring drawing located in the back of the console.

  • Install any existing options and cables. Some may require new cables.

  • Pack console on GOC3 shipping skid for return to MKE.

  • Complete the mechanical upgrade check list.

4  Electrical Integration and Calibration

4.1  Before You Begin

  • Review completed forms or data sheets (from Step - Before you Begin)

  • Follow the Software Installation Procedures (Dir 2378261-100), if your console is loaded with software different than that for Ultra 8/4 MDAS.

    Reload your software to the latest version 3.1 (dec -03) LFC disk in the B78xxGT box.

4.2  GOC3 Electrical Install Setup and Calibrations

  • Computer Integration:

    1. Restore System State.

    2. Install Customer Options.

    3. Reconfig the OC.

  • Monitor and Camera setup.

  • Intercom Adjustment.

  • Tube Warm up and Fast Cal.

  • N Number Calibration.

  • Image Quality Verification.

  • System Functional Verification.

  • Save System State.

  • Reinstall Any Customer DICOM Devices.

  • Reinstall Any Remoter Monitors.

  • Options Functional Verification.

  • Complete All Forms As Required (see Forms and Checklists.)

4.3  Installation Completion

  • Complete HHS documentation (USA Only) 4879 & 2579.

  • Complete console return paperwork and ship.

  • Update online product locator.

  • Install all console covers.

  • Store documents, data forms and software in GE cabinet.

  • Complete any other electrical installation checkouts as required.

  • Complete GOC3 Upgrade Completion Form.
