3  LightSpeed 1.X GOC3 Upgrade Checklist - Before You Begin

  • Save System State.

    (Be sure to save any customer reformat files that might exist.)

  • Verify and record specific system hardware configuration (see below).

    Open a shell and type: cat /usr/g/config/INFO<ENTER>

    Save Contents.

  • Save State NOW! Note network configuration files information.

  • Locate all REQUIRED software and options for your GOC3 system installation.

    NOTE:If this console is installed on a LightSpeed 1.X or 2.X S-DAS system, note that it is software-loaded and configured for LightSpeed 1.X. If the console is installed on a Lightspeed 2.X system, you must reload the software. For all other system types, software reload is not necessary.

    Refer to the PDF file below for the GOC3 LFC procedure.

  • Locate option DVDs and confirm all ordered options are present.

    (See GOC3 Standard Software Features - LightSpeed 1.X)

  • Locate the GOC3 service documentation CD-ROM in software box.

    (Refer to GOC3 SDAS Service Docs, for a complete listing of service documentation found in the software box.)

  • Review pre-install for new GOC3 console cooling requirements.

    (Refer to “Cooling Requirement” section in Environmental Conditions.)

  • Review the console power requirement (GOC3 = 120VAC) (non-GOC = 240VAC)

    You can make a power cord adapter or swap the console power plug.

  • Determine filming, if DASM II Digital.

    (Save your DASM II and cable.)

  • For all other DASM configurations, order a new digital DASM II Kit.

    (Refer to Section 7.2, for part numbers.)

  • Network communication Broad-Band (BB) or dial-up.

    If dial-up, save your modem and cable.

  • If remote monitor connections are required, order required Linux B-cats on back page.

    (Refer to Section 7.1, for part numbers.)

  • Remove all customer information and files (reconfig)

  • Remove all patient information and image files.

  • Review the console return documents and ship to location.

    (Refer to Discarded Material Return Process (GOC3) for details.)

4  Mechanical Upgrade Installation

4.1  Before you Begin

  • Review FE skills required.

    GOC3 Training required for this upgrade.

  • Review tools required.

  • Confirm that cooling and power requirements are met.

  • Complete LightSpeed 1.X GOC3 Upgrade Checklist ( Step ), Power-down system, and Lock-Out/Tag-Out.

4.2  GOC3 Mechanical Installation

  • Inventory all components to be installed.

    (Refer to GOC3 Standard Software Features - LightSpeed 1.X, for “B-Cat” information, and Section 8.2.2, for Missing in Shipment information.)

  • Carefully disconnect all system cables from console.

    Note location & label.

  • Remove trackball, mouse, keyboard, cables and monitors.

  • Disassemble console table top assembly and pack on top of console.

  • Remove console from room and clean (remove) dust from area. Refer to:

    • H1.x QX/I Console (Section 8.3).

    • GOC3 QX/i Console Upgrade

  • Remove the console from skid in the room. Unpack and assemble GOC3 console.

    (Refer to Unpacking and Installing the GOC3 Console)

  • Use the boxes to pack and return removed components and console.

  • Follow the mechanical installation procedure to assemble and connect the console.

    (Refer to Console Connections, for details.)

  • Remove the remote tilt button from the SCIM and install the appropriate label

  • Refer to the 14 x 17 wiring drawing located in the back of the console.

    (Click on the PDF icon, , to view a scalable PDF version of this drawing.)

  • Install any existing options and cables. Some may require new cables.

  • Pack H1 console on GOC3 shipping skid for return to MKE.

  • Complete the mechanical upgrade check list (GOC3_Upgrade_Completion_Checklist.doc).

5  Electrical Integration and Calibration

5.1  Before You Begin

  • Review completed forms or data sheets (from Section 3)

  • Follow the Software Installation Procedures (Direction 2378261-100, available on this CD-ROM), if your console is loaded with software different than that for QX/I 4 S-DAS.

  • Find and have available the latest GOC3 service CD ROM for QXI 4 S_DAS

5.2  GOC3 Electrical Install Setup and Calibrations

  • Computer Integration LS QX/I S-DAS

    1. Turn ON console power and observe boot process

    2. Confirm that the software for GOC3 S-DAS 4 slice

    3. Reload software, if different

    4. Convert Octane to Linux save state and Restore System State

    5. Install customer images, if required

    6. Install Customer Options using desktop DVD

    7. Reconfig the OC, based on your system type

    8. Set date & time, if required

  • Monitor setup (new monitor are required)

  • Intercom SCIM volume setup and check labels

  • Note: Complete a full set of cals, if older than 6 months

  • Tube Warm up and Fast Cal.

  • N Number Calibration

  • DAS Gain Cal

  • Collimator Gain Cal

  • H1 QX/I Image Quality Verification (service protocol 10.8) IQ scan

  • System Functional Verification (service protocol 10.4 48cm scan)

  • System Table Gantry Functional Verification

  • Check that the remote tilt key is removed from the SCIM with correct label installed

  • Reinstall and Verify Any Additional Customer DICOM Devices and Camera

  • Reinstall Any Remote Monitors (Linux Kit - see Section 7.1).

  • Options Functional Verification (remote monitors, video equip, injector, etc.)

  • Save System Save State using supplied DVD

  • Complete All Forms As Required (see Forms and Checklists.)

5.3  Installation Completion

  • Complete HHS documentation (USA Only) 4879 & 2579.

  • Update online product locator.

  • Install all console covers.

  • Store documents, data forms and software in GE cabinet.

  • Complete any other electrical installation checkouts as required.

  • Complete GOC3 Upgrade Completion Form.

8.3  QX/I 1.X Upgrade Console Mechanical Differences Overview

  1. Follow the GOC3 QX/i Console Upgrade procedure. New rev 3 Artesyn boards in the gantry & table and a new table ETC board will be replaced.

    Static protection is required.

  2. Additional schematics can be found in the on site service manuals for your system

    Console Upgrade Overview

  3. Disconnect & Remove all monitors, keyboard, trackball and cables. Place all removed components out side of the scan room. These items will be repacked in the new component boxes and returned to Gold Seal.

  4. Remove keyboard desktop (tools required) and support arms. Carefully remove the console out of the room. Save and return all hardware.

  5. A new power cable is required for the GOC3 upgrade. If a cable is required remove covers, to gain access to duct or conduit. Locate the new power cable and install now. Optional: You can re-terminate the console ends on your existing power cable.

  6. If your system has optional monitors, or video devices, a Linux video upgrade option is required. Install this upgrade now. GOC3 support a digital DASM only. If required pull in new cables as required.

  7. New Monitors are required for this upgrade. Locate the monitors to be installed. A new SCIM / keyboard assembly will replace the one piece keyboard assembly. Remove the remote tilt key and replace with the NO TILT overlay.

  8. Go to step 7 on the upgrade check list to view additional parts.
