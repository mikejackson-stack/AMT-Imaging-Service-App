2  GOC3 Upgrade Checklist

2.1  Before You Begin

  • Save System State.

    (Be sure to save any customer reformat files that might exist.)

  • Verify and record specific system hardware configuration (see below).

    Open a shell and type: cat /usr/g/config/INFO<ENTER>

  • Save all network configuration files information. (work sheets)

  • Locate all REQUIRED software and options for your GOC3 system installation.

  • Locate option DVDs and confirm all ordered options are present.

    (See GOC3 Standard Software Features - LightSpeed 2.X)

  • Locate the GOC3 service documentation CD-ROM (2384451-200).

  • Review pre-install for new GOC3 console cooling requirements.

    (Refer to “Cooling Requirement” section in Environmental Conditions.)

  • Review the console power requirement (GOC3 = 120VAC) (non-GOC = 240VAC)

  • Determine filming, if DASM II Digital.

    (Save your DASM II and cable.)

  • For all other DASM configurations, order a new digital DASM II Kit.

    (Refer to Step , for part numbers.)

  • Network communication BB or dial-up.

    If dial-up, save your modem and cable.

  • If remote monitor connections are required, order required Linux B-cats on back page.

    (Refer to Step , for part numbers.)

  • Remove all customer information and files

  • Remove all patient information and files.

  • Review the console return documents and ship to location.

    (Refer to Discarded Material Return Process (GOC3) for details.)

  • Check order for presence of: Monitors, SCIM kit & Video Options

2.2  H2 Upgrades

New monitor and SCIM/keyboard may be required if you have older style monitors with BNC connectors, and the one piece keyboard assembly. Refer to Section 6 for a list of optional parts

3  Mechanical Upgrade Installation

3.1  Before you Begin

  • Review FE skills required.

    GOC3 Training required for this upgrade.

  • Review tools required.

  • Confirm that cooling and power requirements are met.

  • Complete GOC3 Upgrade Checklist ( Step ), Power-down system, and Lock-Out/Tag-Out.

3.2  GOC3 Mechanical Installation

  • Inventory all component to be removed.

    (Refer to GOC3 Standard Software Features - LightSpeed 2.X, for “B-Cat” information, and Step , for Missing in Shipment information.)

  • Carefully disconnect all system cables from console.

  • Remove trackball, mouse, keyboard, SCIM, cables and monitors.

  • Disassemble console table top assembly and pack on top of console.

  • Remove console from room and clean (remove) dust from area.

  • Remove the console from skid in the room. Unpack and assemble new console.

  • Use the boxes to pack and return removed components.

  • Follow the mechanical installation procedure to assemble and connect the console.

    (Refer to Unpacking and Installing the GOC3 Console and Console Connections, for details.)

  • Refer to the 14 x 17 wiring drawing located in the back of the console.

  • Install any existing options and cables. Some may require new cables.

  • Pack console on GOC3 shipping skid for return to MKE.

  • Complete the mechanical upgrade check list (GOC3_Upgrade_Completion_Checklist.doc).

4  Electrical Integration and Calibration

4.1  Before You Begin

  • Review completed forms or data sheets (from Step )

  • Follow the Software Installation Procedures (Direction 2378261-100, available on this CD-ROM), if your console is loaded with software different than that for QX/I 4 S-DAS.

  • Find and have available the latest GOC3 service CD-ROM

4.2  GOC3 Electrical Install Setup and Calibrations

  • Computer Integration LS QX/I S-DAS

    1. Turn on console power and observe boot process

    2. Confirm that the software for GOC3 S-DAS 4 slice

    3. Reload software, if different

    4. Convert Octane to Linux save state and Restore System State

    5. Install customer images, if required

    6. Install Customer Options using desktop DVD

    7. Reconfig the OC, based on your system type

    8. Set date & time, if required

  • Monitor setup (new monitor only)

  • Intercom SCIM volume setup and check labels

  • Tube Warm up and Fast Cal.

  • N Number Calibration

  • DAS Gain Cal

  • Collimator Gain Cal

  • H2 LS Plus Image Quality Verification (service protocol 10.8) IQ scan

  • System Imaging Functional Verification (service protocol 10.4 48cm scan)

  • System Table Gantry Functional Verification

  • Reinstall Any Additional Customer DICOM Devices and Camera

  • Reinstall Any Remoter Monitors (Linux Kit - see Step ).

  • Options Functional Verification (remote monitors, video equip, injector, etc.)

  • Save System Save State using supplied DVD

  • Complete All Forms As Required (see Forms and Checklists.)

4.3  Installation Completion

  • Complete HHS documentation (USA Only) 4879 & 2579.

  • Complete console return paperwork and ship.

  • Update online product locator.

  • Install all console covers.

  • Store documents, data forms and software in GE cabinet.

  • Complete any other electrical installation checkouts as required.

  • Complete GOC3 Upgrade Completion Form (GOC3_Upgrade_Completion_Checklist.doc).
