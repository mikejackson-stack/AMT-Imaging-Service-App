GOC3 Service Methods (Adv)

GOC3/GOC4 Telnet T/S Note

If the telnet connection fails:

  • Load the SOL CD, if available, for current version of Software into the DARC Node and press the DARC Node reset switch (or re-power DARC Node if necessary). SOL CD will auto-eject when completed.

  • Verify the DARC Node is running on the Host Computer using the ifconfig command.

  • Verify the Ethernet cabling between the Host Computer (port C) and DARC Node.
