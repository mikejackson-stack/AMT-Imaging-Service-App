1.2   Configure Network Settings

This screen provides the ability to declare the CT system on a hospital network. Key information such as Host Name, IP Address, Net Mask (for CT systems on a subnet) must be obtained from the hospital network administrator.

  1. Select the [Network] button to display the Network Settings screen as shown in Illustration 3.

    (Step Details)

  1. Enter the Suite Name.

    (Step Details)

  1. Enter the hospital provided Host Name.

    (Step Details)

  1. Enter the hospital provided IP Address.

  1. Enter the hospital provided Net Mask (if the CT system is on a subnet).

  1. Enter the Broadcast Address.

    (Step Details)

  1. Enter the hospital provided Default Gateway IP Address in the Default Gateway field (if applicable). If the site network does not use a default gateway, leave the field blank.

  1. Select [NIS] (Yellow Pages database) Advanced Option only if requested by the hospital network administrator as follows:

    1. Select [Advanced Options] button on the Network Settings screen.

    1. Select [Use NIS?] button.

    1. Enter the hospital provided Domain Name.

  1. Record all the CT Network parameters in the Software Installation Procedures Document

1.3   Initiate System Reconfiguration

  1. Select [Accept] on the System Configuration Screen.

    (Step Details)

  1. When the loading process and configuration changes are complete, the system displays a prompt to reboot. Click on [YES] .

  1. The system will automatically login as ctuser after the reboot. Select [OK] on the Autostart Disabled popup message.

  1. To startup Applications, in the console shell window, type startup <Enter>.
