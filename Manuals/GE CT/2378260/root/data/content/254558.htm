GRE QX/i Console Upgrade

Last Revised:30 May 2007

1  Overview

1.1  Effectivity

The GRE Console Upgrade is for systems that contain an Octane computer within the console only. This upgrade is not compatible with systems that contain an Indigo computer within the console.

This upgrade is applicable to LightSpeed (QX/i) SDAS Systems.

1.2  Before You Begin

  • Use the GRE Console SDAS Upgrade checklist.

  • Refer to the latest software installation procedure located in the “Software” folder of this publication.

POTENTIAL FOR SHOCK
VOLTAGE MAY BE PRESENT.
Use proper lockout/tagout procedures before replacing components. See safety menu of Service Document gui for appropriate procedures.

1.3  Referenced Documentation

The following referenced documents should be available during installation of the upgrade:

  • QX/i Installation Manual, 2152926-100

  • LFC Procedure

1.4  Upgrade Summary

This upgrade requires changes to the table and gantry as well as the removal of the existing console.

Static Protection is Required When Replacing Circuit Boards.
 
 

  1. Follow the Console, Table and Gantry upgrade sections in this manual. New Rev 3 Artesyn CPU Boards for the gantry and table, and a new table ETC Board will be installed during the upgrade. Use the H1.X QXI check list as your steering guide thought this upgrade.

  2. Additional schematics can be found if required, in the on-site service manuals for your system. GRE and LFC information is located on the service CD-ROM shipped with your system. Use the H1.X QXI check list as your steering guide through this upgrade.

2  Upgrading the Console

POTENTIAL FOR SHOCK
VOLTAGE MAY BE PRESENT.
Use proper lockout/tagout procedures before performing console upgrade. See safety menu of Service Document gui for appropriate procedures.

  1. Shutdown the existing console computer.

  2. LOTO console power.

  3. Disconnect & remove all monitors, keyboard, trackball, and cables. Place all removed components out side of the scan room. These items will be repacked in the new component boxes and returned to GoldSeal.

    NOTE:Label cables when you remove them, if needed.

  4. Remove keyboard desktop (tools required) and support arms. Carefully remove the console out of the room. Save and return all hardware.

  5. Install the new GRE Console. Refer to the GRE CD-ROM shipped with your system for console, monitor, DASM and Modem installation instructions, in the mechanical upgrade section, using the H1,X QXI upgrade checklist as an installation guide.

  6. A new 120 VAC power cable is required for the GRE upgrade. If a new cable is required remove covers, to gain access to duct or conduit. Locate the new power cable on the console and install now.

    Optional: You can re-terminate the console ends on your existing power cable.

  7. If your system has optional remote monitors or video devices, a Linux video upgrade kit option is required. Complete this upgrade now.

    • GRE supports a digital DASM only.

    • Pull in new cables, if required.

  8. New Monitors are required for this upgrade. Locate the monitors to be installed. A new SCIM / keyboard assembly replaces the one piece keyboard assembly.

  9. Go to step 7 on the H1,X QXI upgrade check list to view additional parts.
