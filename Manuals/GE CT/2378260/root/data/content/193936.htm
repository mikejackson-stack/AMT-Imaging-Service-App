2  BIOS Boot

When the system is Powered ON, the BIOS Boot process occurs. The following events occur:

  1. System is Powered ON.

  2. At approximately 10 seconds, the HP Invent screen appears.

  3. At approximately 20 seconds, text appears on the screen.

  4. At approximately 30 seconds, the SCSI inventory begins followed by low level tests.

  5. At approximately the 1 minute mark, the GEMs Linux screen appears. Refer to Illustration 1.

Illustration 1:  GEMs Linux Screen

The Linux load begins and retests start.

2.1  BIOS Boot Diagnostics

At this stage, no diagnostics can be performed from the Online Center.

2.2  BIOS Boot Troubleshooting

If problems occur, an FE on-site can perform the following troubleshooting actions:

  1. Listen for beeps.

  2. Check the LEDs on the HP.

  3. Look for the SCSI devices in the inventory.

  4. If a new install, check the cables on the HP.

  5. Attempt a Load from Cold (LFC).

  6. If the LFC fails, replace the HP.

3  Linux Load

Once the Bios Boot completes and the Linux Load begins, the following events occur:

  1. At approximately 1 minute mark (after Power ON), the GEMs Linux screen appears. The Linux load begins and retests start.

  2. At approximately 1 min 45 seconds, the extended tests begin.

    OK should appear after all tests.

    NOTE:A FAILED message is not necessarily a hardware problem. It can be due to incorrect configuration or facility network issues.

  3. At approximately 2 min 40 seconds, the extended tests finish and the following message appears: Starting Darc Power.

3.1  Linux Load Diagnostics

At this stage, no diagnostics can be performed from the Online Center.

3.2  Linux Load Troubleshooting

If problems occur, an FE on-site can perform the following troubleshooting actions:

  1. Listen for beeps.

  2. Check the LEDs on the HP. (For more information see HP Host Diagnostics.)

  3. Look for the SCSI devices in the inventory.

  4. If a new install, check all the cables on the HP.

  5. Reboot to repeat the extended tests. Closely monitor the tests to ensure that nothing fails.

  6. Attempt a Load from Cold (LFC).

  7. If the LFC fails, replace the HP.

4  Application Boot

  1. At approximately 3 min 10 seconds (after Power ON), a pink message box appears on the left-hand monitor. The message indicates you have 10 seconds to abort boot up.

  2. At approximately 3 min 20 seconds, the message in the pink box changes to OC initializing.

  3. Recon initializes. On the right-hand monitor, check Recon status messages: Resetting (1-2 min), Complete, Idle. Refer to Illustration 2.

  4. At approximately 5 minutes 45 seconds, the startup process completes.

Illustration 2:  Recon screen

4.1  Application Boot Diagnostics

At approximately 3 minutes (after power up), command line diagnostics can be performed from the Online Center. For more information see GOC3/GOC4 Command Line Diagnostic Tests (adv).

4.2  Application Boot Troubleshooting

If problems occur, an FE on-site can perform command line diagnostics as needed. For more information see GOC3/GOC4 Command Line Diagnostic Tests (adv).
