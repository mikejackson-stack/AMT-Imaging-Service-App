2  Overview

This procedure describes how to load a valid Service Information CD or DVD on the scanner's local Hard Drive. You can then access all service documentation for the product from the Common Service Desktop.

4  Procedure

  1. (For customers with an Advanced Service Limited License agreement) Insert applicable CT Service Information CD into appropriate DVD Drive:

    • M3 product software - Host computer DVD Drive

    • M4 product software - SCSI Tower DVD Drive or Host computer DVD Drive

  1. (For GE Healthcare personnel) Insert applicable CT Service Information CD or DVD into appropriate DVD Drive.

    • M3 product software - Host computer DVD Drive

    • M4 product software - SCSI Tower DVD Drive or Host computer DVD Drive

NOTE:Install time from CD or DVD media is ~8 minutes (either DVD Drive).

NOTE:The install software checks a “Revision” file on the Service Information CD/DVD to make sure it matches the particular system and, if previously installed, that it is not an earlier revision. If the check passes, all service documentation for the system is installed. If the check fails, no documentation is installed. This feature prevents you from installing the wrong service documentation on a system.

  1. On the CT Common Service Desktop, select the [Replacement] tab.

  1. Select [Service Documentation] .

  1. Select [Service Documentation Manager] .

  1. A menu displays the following selections:

    • [Install Service Documentation]

    • [Update Service Documentation]

    • [Remove Service Documentation]

    • [Download Service Documentation] - (Future feature; not available yet.)

  1. Make your selection as follows:

    (For first time install from CD/DVD) Select [Install Service Documentation] and click [OK] . This installs the service documentation from the CD/DVD and records the Revision information on the system. At the end of the install, the status bar displays: Successfully completed service docs installation.

    (For new revision CD/DVD) Select [Update Service Documentation] and click [OK] . If the Revision file on the CD/DVD is newer, it installs the service documentation from the CD/DVD and updates the Revision information on the system. At the end of the install, the status bar displays: Successfully completed service docs installation.

  1. Select [View Service Documentation] to browse through all available documentation.
