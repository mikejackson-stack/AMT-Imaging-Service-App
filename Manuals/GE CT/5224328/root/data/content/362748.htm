2  Overview

Objective

  • The purpose of this test is to verify that the HV power inverter and HV tank are working properly. This test is used when the X-Ray Generation subsystem becomes difficult to diagnose because this test allows for the separation of the HV tank and X-Ray tube. The No Load kV test is a pass / fail test.

    This test also allows for the separation of the HV Tank and x-ray tube by running it with or without HV cables plugged on the HV tank ( see Notice) This test requires manual operation.

    The exposure is taken similar to application mode, except that no filament drive nor anode rotation is applied. The JEDI inverter verifies that the inverter currents are correctly set and that kV regulation is operating properly. Since no filament drive is applied, no x-rays are generated.

    Summary

  • Run the test via software with HV Candlestick connected. If test passes, the test will not fail when HV cable is disconnected, thus the test is finished.

  • Remove HV Candlesticks from tank receptacles

  • Fill tank receptacles with oil

  • Run diagnostic

  • Clean up

4  Procedure

NOTE:First execute the test with the HV cables connected.

  1. Launch the [GENERATOR TOOL] .

  1. Launch the [NO LOAD KV DIAGNOSTIC] tool.

  1. Run the diagnostic. The test is intended to be run with HV cable disconnected from tank, however, doing a preliminary check with HV candlestick connected to tank can save time if there is not a problem that this test can diagnose. Verify:

    • No error is reported on the console

    • inverter gate_cmd board Leds DS101, DS 102, DS201, DS202 are lit: IGBTs gate drive supply is working properly.

      If this test fails, then execute the test with the HV cables disconnected.

POTENTIAL FOR SHOCK.
VOLTAGE MAY BE PRESENT.
Use proper lockout/tagout procedures before replacing components.

  1. If needed, remove gantry side and front covers

  1. Remove HV cable candlesticks from tank receptacles.

Equipment damage possible. You must fill the receptacles with oil to avoid arcing.
 
 

  1. Fill tank receptacle with oil.

  1. Power on the generator using 120VAC Enable and HVDC Enable switches on the service switch panel. Also press [ESTOP DRIVES RESET] .

  1. Launch the [GENERATOR TOOL] .

  1. Launch the [NO LOAD KV DIAGNOSTIC] tool.

  1. Run the diagnostic. Verify:

    • No error is reported on the console

    • inverter gate_cmd board Leds DS101, DS 102, DS201, DS202 are lit : IGBTs gate drive supply is working properly

5  Finalization

  1. It may be necessary to combine the results of the No Load kV test with the two other major JEDI tests (Shorted Inverter / Gate Command tests). This is because the Inverter and Auxiliary Box control the HV tank and Tube and problems in either the Inverter or Aux Box could cause the No Load kV test to fail. However, on its own, the No Load kV test can indicate:

    1. No Load kV test FAILS (with Candlestick disconnected) - likely HV Tank problem

    1. No Load kV test first FAILS (with Candlestick connected) then PASSES (with Candlestick disconnected) - likely X-Ray tube problem.
