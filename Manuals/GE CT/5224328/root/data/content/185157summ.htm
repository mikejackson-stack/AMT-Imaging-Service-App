3.1   Additional Software Supporting the DARC Node

3.2   Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, click on the [Shut Down] button and select [Shutdown] .

      (Step Details)

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. SW release 06MW29.7 has corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell. Type: halt.

      (Step Details)

  1. Power OFF the console at the front panel switch.

3.3   Remove the Old DARC

  1. Remove the front and rear Operator Console covers.

  1. Visually verify proper labeling of each cable and disconnect all rear DARC Node cables. If necessary add a label for clarity.

NOTE:Refer to the schematic located on the rear console cover for cable connection details.

NOTE:For a scalable PDF version of the GOC3 schematic diagram, click on the following PDF icon:

  1. Remove and retain the four (4) front mounting screws and slide out the DARC Node.

3.4   Install the New DARC

  1. Verify the replacement DARC Node is correct for the Site DAS Type.

    (Step Details)

  1. Slide the replacement DARC Node into the Operator Console.

  1. Replace the four (4) front mounting screws on the front of the DARC Node.

  1. Verify the power switch located at the rear of the DARC Node is in the ON position.

All cable connector screw-locks must be finger-tightened, only. Do NOT use any tool to tighten cable screw-locks.
 
 

  1. Replace all rear cable connections to the DARC Node.

    (Step Details)

3.5   Power-On the Console

  1. Power ON the Operator Console at the front switch.

  1. At the DARC Node verify the front panel green LED labeled POWER is on. If not press the front panel power switch (far-left switch) to apply power (hold 3-10 seconds) to the DARC Node.

  1. At the IG Node verify the front panel green LED labeled PWR is on. If not press the front panel power switch (hold 3-10 seconds) to apply power to the IG Node.

  1. At the SDDA verify the front panel green LED labeled I/O is on. If not press the front panel power switch to apply power to the SDDA.

  1. Stop Applications from auto-starting at the 5 second PINK Box.

3.8   Load Software from Host onto DARC Node

The DARC Node must be loaded with the OS and Application software from the Host Computer to the DARC Node. Set up the DARC Node Boot Order BIOS (if applicable) to allow the software to load from the Host Computer. Perform the DARC Node OS (Operating System) load as described in the LFC (load From Cold) procedure for the software set being used. Perform the DARC Node Application software load as described in the LFC (Load From Cold) procedure for the software set being used. Return the DARC Node Boot Order BIOS (if applicable) to avoid problems with the DARC Node Motherboard bootup. Refer to the appropriate LFC procedure and follow the sub-sections after reading the DARC Subnet information outlined below:

NOTE:The OS (Operating System) and Application software version loaded onto the DARC Node must match the OS and Application software versions loaded on the Host Computer.

  1. Perform the DARC Node OS (Operating System) load as described in the LFC (Load From Cold) procedure for the software set being used.

    (Step Details)

  1. Perform the DARC Node Application load as described in the LFC (Load From Cold) procedure for the software set being used.

    (Step Details)

  1. Perform the DARC Node Boot Order BIOS (if applicable) as described in the LFC (Load From Cold) procedure for the software set being used.

    (Step Details)

3.9   Verify Replacement DARC Node

With Application Software Down, the DARC Node must be checked to verify communication between the Host Computer and the DARC Node. Perform ping and rsh commands on the DARC Node, as follows:

NOTE:For a Ethernet cabling connection issues, use the ethtool command (ethtool –p eth# where # represents the Ethernet address) as root on the Host Computer, DARC Node or IG Node to determine if the Ethernet cable is correctly connected. The port will blink or flash when activated and <Ctrl+C> will stop the test. This command must be performed as root.

Open a Unix Shell and type the following

  • Host Computer (xw8000 or xw8200) example Ethernet cable check:

    [root@hostname]  ethtool –p eth2

    (<Ctrl+C> to stop flashing xw8000 Ethernet port C LED)

    [root@hostname]  ethtool –p eth0

    (<Ctrl+C> to stop flashing xw8200 Ethernet port C LED)

  • Remote Shell to the DARC Node:

    [root@hostname]  rsh darc

  • DARC Node example Ethernet cable check:

    [root@darc]  ethtool –p eth2

    (<Ctrl+C> to stop flashing DARC Node Ethernet port LED)

  1. At the Toolchest, with Application software down, open a Unix Shell.

NOTE:If the DARC login prompt [root@darc] is not present, then the Application software load has not been successful. If the DARC login prompt [root@localhost root] is present, then reloading the DARC Node OS again per the procedure. If ping darc command fails perform an ifconfig on the Host and verify the DARC is RUNNING and the address is correct. Check the Ethernet cable. Re-power the Operator Console, after a halt, as required to troubleshoot.

3.10   Re-Power the IG Node(s)

Remove the power for each IG Node, then re-power each IG Node with the DARC Node up and able to Remote Shell (rsh darc).

  1. At each IG Node, verify the power is OFF. If power is On for any IG Node, then press the front panel power switch (hold 3-10 seconds) to remove power to each IG Node present in the Operator Console.

  1. Wait 20 seconds.

  1. At each IG Node, press the front panel power switch (hold 3-10 seconds) to apply power to the IG Node(s).

  1. Wait 2 minutes for each IG Node present in the Operator Console to boot up.

    (<Ctrl+C> to stop flashing Ethernet port LED)

    [root@darc]  ethtool –p eth3

    (<Ctrl+C> to stop flashing Ethernet port LED)

    [root@ig3]  ethtool –p eth0

    (<Ctrl+C> to stop flashing Ethernet port LED)

3.17   Re-save Reconfig Info File on System State

After the DARC Node software load (OS and Apps), the Reconfig Info file must be re-saved on the System State DVD-RAM.

  1. Insert the System State DVD-RAM into the SCSI Tower DVD RAM drive.

  1. Wait until the DVD drive is ready (i.e., until the front panel green LED is no longer lit).

  1. Select: Service icon to access the CSD (Common Service Desktop).

  1. Select: [Utilities] .

  1. Select: [System State] .

    (Step Details)

  1. Select [Reconfig Info] .

  1. Select [Save] .

  1. If applicable, select [Yes] when the following message appears: System State Media Status: Please insert a DVD into the drive and press Save again.

    (Step Details)

  1. When completed, select [CANCEL] .

Do NOT select [DISMISS] more than once. Doing so will result in the GUI becoming hung, and the System State will be unusable. Should this occur, Re-Save the System State again.
 
 

  1. When completed, select [Dismiss] .

  1. Close the Service Desktop window at the upper left corner of the screen
