NOTE:Install time from CD or DVD media is ~8 minutes (either DVD Drive).

NOTE:The install software checks a “Revision” file on the Service Information CD/DVD to make sure it matches the particular system and, if previously installed, that it is not an earlier revision. If the check passes, all service documentation for the system is installed. If the check fails, no documentation is installed. This feature prevents you from installing the wrong service documentation on a system.
