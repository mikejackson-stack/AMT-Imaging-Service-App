Operating Documentation
Direction  5224328-800,  Rev#  5

SDDA Replacement

(Click Here to Return to Detailed Procedure)

  Safety

All cable connector screw-locks must be finger-tightened, only. Do NOT use any tool to tighten cable screw-locks.
 
 

1  Procedure

1.1   Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, click on the [Shut Down] button and select [Shutdown] .

      (Step Details)

    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. Future SW releases (e.g., 06MW29.7) have corrected this issue.
     
     

    1. If Applications are down, open a Unix Shell. Type: halt.

      (Step Details)

  1. Power OFF the console at the front panel switch.

1.2   Remove the Old SDDA Node

  1. Remove the front and rear Operator Console covers.

  1. Remove all rear cable connections to the SDDA. Verify each cable label is present and clearly marked, if necessary add a label for clarity.

    (Step Details)

  1. Remove and retain the four (4) front mounting screws and slide out the SDDA.

1.3   Install the New SDDA

Install the replacement SDDA in the Operator Console.

  1. Slide the SDDA into the Operator Console.

  1. Replace the four (4) front mounting screws on the front of the SDDA.

All cable connector screw-locks must be finger-tightened, only. Do NOT use any tool to tighten cable screw-locks.

Verify that the SCSI Cable is on straight.

 
 

  1. Replace all rear cable connections to the SDDA.

    (Step Details)

1.4   Power-On the Console

  1. Power ON the Operator Console at the front switch.

  1. At the DARC Node verify the front panel green LED labeled POWER is on. If not press the front panel power switch (far-left switch) to apply power to the DARC Node.

  1. At the IG Node verify the front panel green LED labeled PWR is on. If not press the front panel power switch (top-most switch) to apply power to the IG Node.

  1. At the SDDA verify the front panel green LED labeled I/O is on. If not press the front panel power switch to apply power to the SDDA.

  1. Stop Applications from auto-starting at the 5 second PINK Box.

1.5   Verify DARC Node is Up

The DARC Node must be up to check the SDDA or IG Node. Retry the rsh command if it times out. Perform ping and rsh commands as follows:

  1. Open a Shell and become root:

    1. Type: su -

    1. Type in the root password: #bigguy

  1. Type: ping darc

    (Step Details)

  1. Type: rsh darc

    (Step Details)

1.6   Testing for Systems with “Old” Software

For systems with software older than 06MW03.4, perform the following

The following procedures are used ONLY for software versions PRIOR to 06MW03.4. Do NOT perform, if your software is 06MW03.4 or greater. Running the reconfigScanDisk script with 06MW03.4 SW WILL cause partitioning problems/failures with the Disk Array, which may result in the inability to perform a LFC.
 
 

  1. reconfigScanDisk

  1. testHighSpeed

1.7   Testing for Systems with “New” Software

NOTICE: Running the reconfigScanDisk script with 06MW03.4 SW WILL cause partitioning problems/failures with the Disk Array, which may result in the inability to perform a LFC.     For systems with 06MW03.4 or newer software, perform the tests in gre-raid Disk Array Tests - GOC3/GOC4.

1.8   Start Applications

At the ctuser prompt type: st

1.9   Retro Recon Test

The Reconstruction (not Scan) portion of the system can be tested at this point.

  1. Click on the [RETRO RECON] selection on the left monitor.

  1. Click on [RAT GOLD] series.

  1. Click on [SELECT SERIES] .

  1. Click on [CONFIRM] .

    (Step Details)

  1. Click on [QUIT] .

2  Finalization

  1. Take some scans (e.g., scout, axial & helical).

    (Step Details)

  1. Install the front and rear Operator Console covers.
