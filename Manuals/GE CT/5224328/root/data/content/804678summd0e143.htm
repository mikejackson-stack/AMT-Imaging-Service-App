(For first time install from CD/DVD) Select [Install Service Documentation] and click [OK] . This installs the service documentation from the CD/DVD and records the Revision information on the system. At the end of the install, the status bar displays: Successfully completed service docs installation.

(For new revision CD/DVD) Select [Update Service Documentation] and click [OK] . If the Revision file on the CD/DVD is newer, it installs the service documentation from the CD/DVD and updates the Revision information on the system. At the end of the install, the status bar displays: Successfully completed service docs installation.
