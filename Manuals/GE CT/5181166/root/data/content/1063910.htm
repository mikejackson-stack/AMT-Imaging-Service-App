GRE Message Logs (adv) (All-In-One Console)

Last Revised:16 May 2008

1  Overview

All-In-One Console message logs contain the LINUX operating system messages. This would be the equivalent of the SYSLOG on an IRIX system.

Use on Host and IG.

To access the logs, perform the following actions:

  1. Open a shell window.

  2. Type: cd/var/log<Enter>.

  3. Type: more messages<Enter>.

The /var/log/messages file can get very long and pose a barrier to performance. So whenever the file size exceeds a certain limit (or by number of days expired), the Linux OS saves the current messages file into a file called messages.1, messages.2 etc and writes fresh on the messages file.
