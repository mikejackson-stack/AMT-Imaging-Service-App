2  Overview

This module explains how to run the “Collimator Functional” tests, which exercise the cams and filter motions and encoder responses.

Last Revised:August 1, 2008

3  Procedure

3.1  Test Selection

  1. On the console select the [DIAGNOSTICS] tab in the Common Service Desktop.

  1. Launch the [COLLIMATOR FUNCTIONAL] tool. Refer to Illustration 1 for the layout of the tool interface.

  1. 3. Select the functional test desired in the Test Selection drop-down box indicated in Illustration 1. The different tools are described in the following sections.

    Illustration 1:  Collimator Functional Application Position Test GUI

3.2  Collimator Application Position Test

This test positions the Cams and filter to the selected positions for the entered test duration. Refer to Illustration 1for the layout of the tool interface.

3.2.1  When (to use)

  1. The test runs in continuous modes which help detect intermittent operating conditions.

  1. The test provides a means to visually validate the aperture and filter positions

  1. This test can be used to confirm the functional operation of the collimator.

3.2.2  What (to look for)

  1. Look for highlighted fields that indicate the cam or filter did not make it to position.

  1. Check the log for additional information when this occurs.

3.2.3  Notes

  1. Watch for finger pinch hazards.

  1. Attempt to move the filter and/or cams, when test is complete, and verify motor has holding torque.

3.3  Collimator Continuous Filter Position Test

This test moves the filter from one extreme to another for the entered test duration. Refer to Illustration 2 for the layout of the tool interface.

Illustration 2:  Collimator Functional Continuous Filter Position Test GUI

3.3.1  When (to use)

  1. This test will verify that no mechanical binding is present.

  1. The manual mode can be used for signal tracing.

  1. You check for motion when errors indicate no motion sensed.

3.3.2  What (to look for)

If the display does not indicate changes in the encoder count, visually check the filter for motion:

  1. If filter is moving, failure is in the encode circuit

  1. If filter is not moving, failure is in the drive circuit.

3.3.3  Notes

  1. Watch for finger pinch hazards.

  1. The filter drive can be divided into two functions as shown in Illustration 3

    • Motor Drive (Positioning driver)

    • Encoder (Position feedback)

    Illustration 3:  Collimator Filter Position

3.4  Collimator Encoder Test

This test reads and displays the CAM and filter encoder counts while the devices are positioned by hand. Refer to Illustration 4 for the layout of the tool interface.

  1. When (to use)

    This test can confirm an encoder problem.

  1. What (to look for)

    Verify encoder reading changes once the cams or filters are moved.

  1. Notes

    • Watch for finger pinch hazards.

    • The test reduces the cam holding torque to allow the cams to be rotated by hand.

    • Cams are 2000 counts per rotation.

    • Filter is 1000 counts per rotation.

    • If the cam encoder fails the whole collimator assembly should be replaced.

    Illustration 4:  Collimator Functional Encoder Test GUI

3.5  Collimator Continuous CAM Rotation Test

This test moves the selected CAM for the entered test duration. Refer to Illustration 5 for the layout of the tool interface.

Illustration 5:  Collimator Functional Continuous CAM Rotation GUI

3.5.1  When (to use)

  1. This test can verify that no mechanical binding is present.

  1. The manual mode can be used for signal tracing.

3.5.2  What (to look for)

  1. If the display does not indicate changes in the encoder count, visually check the CAM for motion.

  1. Listen for mechanical vibration or binding.

3.5.3  Notes

  1. Watch for finger pinch hazards.

  1. CAM A and B circuitry is the same.

  1. CAM operation can be divided into two functions as shown in Illustration 6:

    • Motor and drive

    • Encoder

    Illustration 6:  Collimator CAM Rotation
