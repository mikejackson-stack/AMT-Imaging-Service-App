HHS Scans (Adv)

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. On the console select the [DIAGNOSTICS] tab in the Common Service Desktop.

  1. Launch the [GENERATOR TOOL] . When the tool appears select the [HHS SCANS] button. Refer to Illustration 1 for the layout of the generator tool interface.

    (Step Details)

  1. The Start Scan button on the SCIM will be flashing. Press the [START SCAN] button to begin running the HHS scans.

  1. The tool will let you know if it passes.

  1. The scan data will be stored on the system and can be viewed using the [HHS REPORT] button.

    (Step Details)

  1. If the system does not pass, then you can isolate the root cause of the problem by running the following procedures in the order shown below. Failures found during these procedures will indicate the appropriate corrective action.

    1. Meter Verification

    1. High Voltage Tank Feedback Resistor Verification

    1. Focal Spot Transfer Function

    1. Filament Calibration

2  Finalization
