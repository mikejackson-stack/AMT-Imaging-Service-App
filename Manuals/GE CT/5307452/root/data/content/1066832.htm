Dicom Network Host Information

With Applications up, record the DICOM network host information:

  1. Go to Image Works desktop.

  2. Select Network Tab → Remote Host.

  3. Select Update for each Remote Host listed.

  4. Record the information for each Remote host, then select [CANCEL] . Continue selecting remote hosts until all information has been recorded.

  5. When all the information has been recorded, select [CANCEL] to close the Remote Host selection window.
