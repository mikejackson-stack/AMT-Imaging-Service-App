Save Restore Generator Runtime Parameters

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Save Generator Runtime Parameters

  1. Select [DIAGNOSTICS] tab from Service Desktop.

  1. Select [GENERATOR TOOL – JEDI] or [X-RAY GENERATION] folder, then [GENERATOR TOOL – JEDI] .

  1. Select [SAVE RUNTIME PARAMETERS] from [GENERATOR TOOL – JEDI] window.

  1. Click [OK] from Attention pop-up window. A [SAVE RUNTIME PARAMETERS] window is displayed and file is downloaded from generator to console.

  1. Click [OK] from [SAVE RUNTIME PARAMETERS] when process is completed.

  1. Click [DISMISS] from [GENERATOR TOOL – JEDI] .

  1. Save System State. (SeeSystem State Save Restore).

1.2   Restore Generator Runtime Parameters

  1. Select [DIAGNOSTICS] tab from Service Desktop.

  1. Select [GENERATOR TOOL – JEDI] or [X-RAY GENERATION] folder, then [GENERATOR TOOL – JEDI] .

  1. Select [RESTORE RUNTIME PARAMETERS] from [GENERATOR TOOL – JEDI] window.

  1. Click [OK] from Attention pop-up window. A [RESTORE RUNTIME PARAMETERS] window is displayed and file is downloaded from console to generator .

  1. Click [OK] from [RESTORE RUNTIME PARAMETERS] when process is completed.

  1. Click [DISMISS] from [GENERATOR TOOL – JEDI] .
