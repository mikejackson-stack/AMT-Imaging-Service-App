JEDI PPC Board Replacement

(Click here for Summary Version)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Timing Not Applicable30 mins 2 hours

2  Overview

To replace JEDI PPC board:

  • Save JEDI runtime parameters, if possible

  • Replace PPC board

  • Restore JEDI runtime parameters, if previously saved

  • Check functionality of systems

  • Recalibrate

4  Procedure

4.1  PPC Board Removal

  1. If possible, save JEDI runtime parameters by clicking the [SAVE RUNTIME PARAMETERS] button of the [GENERATOR TOOL] found in the [DIAGNOSTICS] tab of the Common Service Desktop. Refer to Illustration 1 for the tool interface.

    Illustration 1:  Generator Tool

POTENTIAL FOR SHOCK.
VOLTAGE MAY BE PRESENT.
Use proper lockout/tagout procedures before replacing components.

  1. Remove power to the gantry using proper Lockout / Tagout procedures.

  1. Remove gantry right side cover.

  1. Turn OFF all the three switches (AXIAL DRIVE ENABLE, HVDC ENABLE, 120 VAC) on the Service Switch Panel.

  1. Position the inverter assembly at 2 o'clock.

Do not drop screws into inverter. If you do, they must be removed or damage to the inverter will occur.
 
 

  1. Remove largest inverter cover.

  1. Attach a protective ESD wrist strap.

  1. Disconnect wires and remove the PPC board.

4.2  PPC Board Installation

  1. Continue using the ESD wrist strap.

  1. Insert new PPC board and re-connect all wires.

  1. Replace the hex screws.

  1. Replace inverter cover.

5  Finalization

  1. Ensure that proper torque specifications (see Torque Wrench Information) are followed for all fasteners.

  1. Run Flash Download Tool to synchronize PPC firmware with Console software.

  1. Restore JEDI Runtime Parameters, if you saved JEDI Runtime Parameters prior to replacing the PPC board. (See Illustration 1)

  1. Run Meter Verification.

  1. Perform HV Tank Feedback Resistor Verification (bleeder test)

  1. Run Filament Calibration.
