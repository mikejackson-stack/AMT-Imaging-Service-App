3  Procedure

3.1   Non-GE Service Personnel

  1. Visually record the x-ray tube insert model number on the x-ray tube rating plate.

  1. Select [CONFIGURATION] tab from Service Desktop.

  1. Select [TUBE INSTALL CERTIFICATION] . A screen, as depicted in Illustration 1, is displayed.

    (Step Details)

  1. If the x-ray tube insert model number on the x-ray tube rating plate is 5195900, select [GE MEDICAL SYSTEMS TUBE] from the Tube Install Certification Tool Change Tube Identity pane.

    (Step Details)

  1. Select [CONFIRM] on the Tube Install Certification Tool. A Confirmation screen, as depicted in Illustration 2 or Illustration 3, is displayed.

    (Step Details)

  1. Select [ACCEPT] on the Tube Install Certification Confirmation screen. The top pane of the Tube Install Certification Tool is updated as depicted in Illustration 4 or Illustration 5.

    (Step Details)

  1. Select [DISMISS] on the Tube Install Certification Tool.

  1. If the Tube Install Certification is configured for a GE Medical Systems Tube and the Trial Period has not expired, contact the GE Call Center and create a dispatch for a Field Service Engineer to finalize on-site the Tube Installed Certification.

3.2   GE Service Personnel

Perform the following steps when originally setting Tube Install Certification or verifying a GE Medical Systems Tube installation, within the trial period, without an active GE Class M service USB key.

  1. Insert and activate the Class M Service key.

  1. Visually record the x-ray tube insert model number on the x-ray tube rating plate.

  1. Select [CONFIGURATION] tab from Service Desktop.

  1. Select [TUBE INSTALL CERTIFICATION] . A screen, as depicted in Illustration 6 or Illustration 7, is displayed.

    (Step Details)

  1. If the x-ray tube insert model number on the x-ray tube rating plate is 5195900, select [GE MEDICAL SYSTEMS TUBE] from the Tube Install Certification Tool Change Tube Identity pane.

    (Step Details)

  1. Select [CONFIRM] on the Tube Install Certification Tool. A Confirmation screen, as depicted in Illustration 8 or Illustration 9, is displayed.

    (Step Details)

  1. Select [ACCEPT] on the Tube Install Certification Confirmation screen. The top pane of the Tube Install Certification Tool is updated as depicted in Illustration 10 or Illustration 11.

    (Step Details)
