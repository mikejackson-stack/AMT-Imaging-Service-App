This procedure is for replacement of the PPC Board Battery.

4  Procedure

4.1  Disassembly

  1. If the battery is still working, save the JEDI runtime parameters by clicking the [SAVE RUNTIME PARAMETERS] button of the [GENERATOR TOOL] found in the [DIAGNOSTICS] tab of the Common Service Desktop. Refer to Illustration 1 for the tool interface.

    Illustration 1:  Generator Tool

  1. Dismount the PPC board.

  1. Use an electrostatic Discharge (ESD) protection bracelet and follow all ESD procedures.

  1. Gently grasp the NV Ram battery on the PPC board (see Illustration 2) between your thumb and forefinger. Pull it directly away from its support on the board.

    Illustration 2:  NV RAM Battery on PPC Board

    NOTE:This NV RAM contains a lithium carbon monoflouride (LiCFx) battery, used to provide the battery backup for the static ram and the time device. Return the former component to your local GEMS representative for recycling.

4.2  Reassembly

  1. Install the new battery on the PPC board in the same location from which it was removed. Ensure that it is properly installed.

Ensure that the cables are correctly connected. Ensure that marks on the cables match the marks on the board.
 
 

  1. Reinstall the PPC board in the inverter and reconnect all the cables.

5  Finalization

  1. Reapply the power.

  1. If the battery was working before the replacement, restore the JEDI runtime parameters that were saved prior to removing the PPC board battery (See Illustration 1). Otherwise, initialize the JEDI database and run Filament Calibration.

  1. Start some exposures in different modes.

  1. Verify that the system works correctly.
