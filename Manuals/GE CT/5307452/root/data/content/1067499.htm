Discovery CT750 HD Service Methods - Adv

Certified Component Replacement Retest Matrix

Last Revised: 08 August 2008

1  Introduction

These procedures apply to all CT 750HD, VCT 64, VCT, Brightspeed, and RT products.

This document defines the minimum retest requirements when a certified component is replaced or swapped on a Lightspeed System. The primary function of this document is to ensure that the replaced certified component functions correctly as designed in the system.

The tests described in this document can be found in the Service Installation Manual and in the service replacement procedures. Use Certified Component Verification Form e4879 as a checklist when performing these retest activities.

1.1  Component Removal

Follow the De-Installation Manual 5272259-1EN for the CT family to de-install these components:

  • Gantry

  • Table

  • Console

Follow the instructions in the replacement procedures to remove these components:

  • X-Ray Tube

  • Collimator

  • High Voltage Tank

1.2  Certified Components

Certified components as defined by the FDA & GE Healthcare:

  • Collimator Assembly

  • X-Ray Tube

  • High Voltage Tank

  • Gantry (replacement)

  • Console Master Control (replacement)

  • Table (replacement)

2  CT Gantry Replacement

Applies to all CT 750HD, VCT 64, VCT, Brightspeed, and RT gantries.

NOTE:Gantry replacement requires two people to complete, which can be accomplished in one day.

Before you start:

  1. Locate the De-Installation Manual 5272259-1EN for Lightspeed Family. Follow the Gantry Removal section to de-install this component.

  2. Record all required information and data from the system prior to powering down.

    NOTE:Do not cut or damage cables when removing.

  3. Complete a system save state.

  4. Follow the delivery procedures in the installation manual shipped with your system.

Review/complete only these sections in the installation manual shipped with your system.

  • Install Gantry Alignment Laser and Bracket or Install Alignment Bars

  • Gantry Tilt Zero Alignment Check

  • Cradle/Table Parallel Check

  • Tighten the Lock Rings

  • Drill the Table Anchor Holes

  • Gantry & Table Alternate Anchor Holes

  • Install the Anchors

  • Remove Gantry Tilt Bracket

Gantry Cable Connections

  • Computer Integration and Configuration: Restore System State

HD, VCT, 5.x, RT4, Brightspeed, RT16 Systems:

  • Tube Warm Up and Fast Cal

  • Center Phantom

  • Tomographic Plane Indication

2.x - 4.x Systems:

  • Table/Gantry Alignment Procedure

  • Tube Warm Up and Fast Cal

  • CT N# Adjustments

  • Tomographic Plane Indication

  • Image Series

2.2.3  Finalization:

  • System Functional Test

  • Save System State

  • Cleanup and Return:

    1. Reassemble the removed gantry including replacing covers.

    2. Using the shipped packaging, return all unused parts.

    3. Arrange for transportation to pick up the gantry and any additional parts.

2.2.4  Leakage Test:

  • Patient Touch Leakage Test (all systems)

  • CT Power and Ground Audit (all systems)

  • CT System Chassis Leakage Test (as required in your area)

2.2.5  Forms:

  1. Complete GE e4879 for certified components replacement. Download from the service CD ROM in the replacement section.

  2. Complete FDA e2579. Download from the HHS web.

  3. Verify gantry has GE rating plate and matching ICD cards.

  4. Update GIB.

  5. Email all forms to the HHS administrator.
