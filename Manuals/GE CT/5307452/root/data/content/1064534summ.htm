Inverter Gate Command Test

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Remove gantry right side cover.

  1. Disable HVDC using service switch panel HVDC Enable switch.

  1. Launch the [GENERATOR TOOL] from the [DIAGNOSTICS] tab of the Common Service Desktop.

  1. Click the [KV DIAGNOSTICS] button, then select the [GATE COMMAND TEST] tool.

  1. Run the diagnostic. No X-Ray will actually be generated.

2  Finalization

  1. If this test fails, your system has an inverter problem.

  1. If the test passes, the sequence normally dictates that you will move to the Shorted Inverter Test.
