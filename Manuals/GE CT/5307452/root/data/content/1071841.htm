2  Overview

The following procedure describes and illustrates the GOC6 HD System Configuration procedure commonly referred to as the “reconfig” script. It is important to follow the steps listed in the order presented.

On the following screens, you should make the changes necessary, pressing the corresponding button at the top of the screen to move from screen to screen. When you are done, you can either press the [ACCEPT] button to start the reconfiguration process, or press the [QUIT] button to exit without changing the system configuration.

While the reconfiguration is going on, messages are displayed in a Shell Window that closes when reconfiguration is complete. Should you later want to review the reconfiguration output, it is logged to the following file: /var/adm/install.log.YYYYMMDDWWWHHMMSS, where YYYYMMDDWWWHHMMSS is the Date/Time that the reconfiguration was started.

To view the file, type: more /var/adm/install.log.YYYYMMDDWWWHHMMSS

It is possible to abort the reconfiguration while entering information on the reconfiguration screens. Simply press the [QUIT] button at the top of the screen. There is NO safe way to abort the reconfiguration after pressing the [ACCEPT] button. If the entries made in the screens were incorrect, DO NOT try to stop the reconfiguration. Instead, wait for it to complete and rerun “reconfig” entering the correct parameters.

4  Procedure

  1. Shut down Applications from the Common Service Desktop, Utilities Tab.

  1. Open a Terminal Window, and log on as root:

    1. Type: {ctuser@hostname} su – [ENTER]

    1. Type the root password and press [ENTER]

  1. Launch the Configuration utility:

    Type: [root@hostname] reconfig [ENTER]

  1. The CT Software Install Utility Window will appear.

    Illustration 1:  CT Software Install Utility Window

    NOTE:The following shows the screens that are used to change the configuration of the system. These screens are the same as those used for the Software Configuration during Load From Cold. The actual screens will vary depending on the current configuration of your system.

  1. Click [CONFIG] .

    Illustration 2:  System Configuration Window

  1. Configure System Settings

    1. Hospital Name (Illustration 2, item a) - Configures the name that will show up on images produced by this scanner. Example: ST MARY'S HOSPITAL

    1. Service ID (Illustration 2, item b) - Issued by the Service organization. Example: 262785CT2 (no spaces, 14 character limitation)

    1. Select the Time Zone for the site.

    1. Next Patient Exam Number - Customer selected. At initial system installation, Type: 1.

    1. Next Diagnostic Exam # - Configures the next Exam number the scan user interface will use. Customer Selected. At initial system installation, Type: 1.

    1. Mobile System - Select to tell the software if this CT is in a mobile environment or not.

    1. Regenerate Scan Database - Determines whether the Scan Database will be regenerated during reconfiguration. Select [YES] if this is an installation with no customer data present. Destructive ! Will destroy any Scan Data present.

    1. Recreate Scan Disk Array – Determines whether the Scan Array will be recreated during reconfiguration. Used only after HSDA Assembly replacement or multiple Hard Disk Drive failures. Destructive ! Recreates logical array.

      NOTE:Not needed for system installation!

    1. Rebuild Scan Disk Array (not normally displayed) – Used only if replacing a single Hard Disk Drive in the High Speed Disk Array (HSDA) of GOC 6 consoles. When a new hard drive is installed in HSDA and the reconfig utility is executed, a new set of buttons will appear to allow the inclusion of the new Hard Disk Drive into the array.

      NOTE:Not needed for system installation!

      NOTE:Will not destroy Scan (raw) Data, but system cannot be used to acquire scan (raw) data while Array is rebuilding!

      NOTE:Will not be displayed under normal operation condition. This selection only appears after a new HDD has been installed in the HSDA and ample time (2 minutes) has been given for the HSDA to recognize the drive.

  1. Click [PREFERENCES] to display the Preferences Configuration window. (See Illustration 3.)

    Illustration 3:  HD Preferences Configuration Window

  1. Configure Preferences Settings.

    1. Doctors Title - Enter the title for the Doctor (e.g., radiologist.)

    1. Units for Patient Weight - Tells the software whether pounds or kilograms are being used.

    1. Language - Configures the language to be displayed on the Application screens.

    1. AutoVoice Language - Configures the language heard in the scan room.

    1. Keyboard Selection – Configures the language specific keyboard character set.

    1. Date Format - Configures the format in which the date will be displayed on the images.

    1. Time Format - Configures the format in which the time will be displayed on the images.

    1. Modified In Room Start - Be sure "Off" is selected, unless the site is in Japan, in which case, this feature should be "On".

    1. HIPAA Present - Be sure “Off” is selected unless told differently.

    1. Select the site preferred Dose Information Display option for the site to use in monitoring calculated Patient Dose. Use the default selection unless told differently.

      • Select ON (full CTDiw Display)

      • Select ON WITHOUT TOTAL DLP (no Dose Length Product Display), or

      • Select OFF (no CTDiw Display)

    1. Dose Record – Configures support for DICOM Dose SR Record option for saving dose information with study. Default is “OFF”. The dose information is saved in a DICOM structured report. The DICOM standard defines a new DICOM X-Ray Radiation SR SOP class which the other systems must support. The Dose SR feature saves an exam's dose information in this format.

      • Select ON - Saves the dose information in a DICOM Enhanced SR SOP Class

      • Select OFF - Turns off option

      • Select FULL - Saves the dose information in a DICOM X-Ray Radiation Dose SR SOP Class

      NOTE:This preference shall not be enabled unless specifically requested by the Customer and the Evaluation of Dose SR Compatibility procedure has been executed and indicates that the other hospital systems support the Dose Report SOP classes.

    1. Preferred Fast Cal KV - Configures the preferred kV that the Fast Cal Routine will calibrate (80, 100, 120, 140 in the Selected Preferred Fast Cal KV field). The default selections are 80, 100, 120, and 140. All defaulted ON for VCT systems. All defaulted On for HD systems.

    1. Target Noise Index Table - Be sure Table 2 is selected.

    1. Gantry Layout - Configures the preference for Patient loading. Choose correct orientation depending on site specific Gantry layout.

    1. Flip and Rotate - Configures the preference for allowing the Flip and Rotate feature to be turn on in the User Interface on the (Left) SCAN Monitor. This preference allows the Customer to apply custom orientation changes based on Exam Type and Reconstruction methods on DICOM images that will be transferred to PACS and related systems.

      NOTE:This preference shall not be enabled unless specifically requested by the Customer and the Evaluation of Image Flip and Rotate Compatibility procedure has been executed and all DICOM test images pass orientation check

  1. Click [HARDWARE] to display the HD Hardware Settings Screen. (See Illustration 4.)

    Illustration 4:  HD Hardware Configuration Window

  1. Configure Hardware Settings.

    1. Gantry Type - Indicates the type of Gantry that is installed.

    1. Tube Type - Indicates the type of X-Ray Tube that is installed.

    1. DAS Type - Indicates the type of DAS that is installed.

    1. Detector Type – Select the detector type: Colorado64 for HD.

    1. Table Type - Select the table type: VT2000 or VT1700. The type of table shipped can be determined by reviewing the order information.

    1. PDU Type - Indicates the type of PDU that is installed.

    1. Scan Recon Hardware – Indicates console type.

    1. Number of VeRBs - Indicates the number of VeRBs installed.

  1. Click [NETWORK] to display the Network Settings Screen. (See Illustration 5.)

    Illustration 5:  HD Network Configuration Window

    NOTE:This screen provides the ability to declare the CT system on a hospital network. Key information such as Host Name, IP Address, Net Mask (for CT systems on a subnet) must be obtained from the hospital network administrator.

  1. Configure Network Settings.

    1. Enter the Suite Name. The Suite name must start with a letter, followed by three (3) alpha-numeric characters. Total must be four characters long. The name of the OC interface will be <Suite Name> _OC, within the scanner subnet. Typically, you should use su01 or ct01 (“su” and “ct” must be lowercase), unless the customer prefers a different suite name.

    1. Enter the hospital provided Station Name.

      • MUST NOT exceed 16 characters.

      • MUST only contain the following characters: a through z, and 0 through 9.

      The Host Name is typically stmary or ct01.

    1. Enter the hospital provided Host Name. The Host Name identifies the network hostname and AE Title of the CT system to the hospital’s network. The Host Name:

      • MUST NOT exceed 16 characters

      • MUST only contain the following characters: a through z, and 0 through 9.

      The Host Name is typically stmary or ct01.

    1. Enter the hospital provided IP Address for the system

    1. Enter the hospital provided Net Mask Address for the system.

    1. Enter the hospital provided Broadcast Address for the system.

    1. Enter the hospital provided Default Gateway Address for the system.

    1. Enable TCP Segmentation Offload – Default YES. If network transfers to certain PACS systems are slow, this can be set to No and may increase the transfer speed.

    1. Enable AW DirectConnect if option provided with system. Reviewing the order information to see if option is included.

      NOTE:Items j – l are visible only when Advanced Options is selected.

    1. Enter the hospital provided NIS Domain Name and IP Address for the system, if NIS is utilized on site.

    1. Enable Network Time Protocol, if so instructed by hospital. Hospital must have an NTP Server available and the scanner should be synchronized with the Hospital’s time.

    1. Enable Change DARC Subnet, if so instructed by hospital.

      NOTE:Only enable this feature if there is an IP conflict between the system local network and the hospital local network. The GOC 6 console utilizes a DHCP Server to configure the Console local network address for communications between Host, Gantry/Table and Reconstruction Engine Computers. Default local addresses in the GOC 6 console use the following local Octets: 172.016.xxx.xxx

  1. Review all screens to be sure the information entered is correct before proceeding to the next step.

  1. Click [ACCEPT] to accept the changes made. (See Illustration 6.)

    Illustration 6:  HD Accept Configuration Window

    After clicking [ACCEPT] the system configures the system. While the configuration is going on, the results are displayed in a Shell window that closes when the loading process is complete. (See Illustration 7.)

    Illustration 7:  HD Shell Configuration Window

  1. When the configuration changes are complete, the system displays a prompt to reboot.

  1. Click [YES] . (See Illustration 8.)

    Illustration 8:  Configuration Complete Window

  1. The system will automatically log in as ctuser after the reboot. Select [OK] on the Autostart Disabled popup message.

  1. Open a Terminal Window. Type: {ctuser@hostname} st [ENTER]

  1. Remember, if necessary, perform System State Save Restorewhenever the “reconfig” script is executed.

5  Finalization

Refer to System Scanning Test to confirm proper operation.
