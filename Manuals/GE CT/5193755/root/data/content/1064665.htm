Peripheral Tower Functional Test

Last Revised:6 October 2008

1  DVD Peripheral Tower - DVD-RAM

1.1  Mount and Un-mount Process

  1. Insert old System State DVD-RAM Disk into the DVD Peripheral Tower DVD-RAM drive.

  2. Open up a Linux Terminal Window and type:

    mountDVD [ENTER]

  3. To view the contents of the DVD-RAM:

    Type: ls(space)-l(space)/DVD [ENTER]

  4. To test DVD-RAM writing capability, perform a Save System State using the Utilities under the CSD.

    NOTE:Do not write to the site's System State Disk until certain the DVD Peripheral Tower is working properly. See “Initializing DVD-RAM Media” if using a new blank DVD-RAM disk.

  5. To remove the DVD-RAM disk from the drive, first un-mount it by typing:

    unmountDVD [ENTER]

1.2  Initializing DVD-RAM Media

  1. Insert a new, blank DVD-RAM Disk into the DVD Peripheral Tower DVD-RAM drive.

  2. Open up a Linux terminal window and type:

    su(space)- [ENTER]

  3. Enter the root password: <password> [ENTER]

  4. Type: mountDVD [ENTER] .

  5. Type: mkfsDVD [ENTER]

  6. Answer Y for “YES” and close the Linux Terminal Window.

2  DVD Peripheral Tower - DVD-R/RW

Mount and Un-mount Process

  1. Insert a DVD-R disk (OS or Apps DVDs) into the Peripheral Tower DVD-R/RW drive.

  2. Open up a Linux terminal window and type:

    mount(space)/dev/dvd1(space)/mnt [ENTER]

  3. To view the contents of the DVD-R, type:

    ls(space)-l(space)/mnt [ENTER]

  4. Read a file from the OS or Apps DVDs.

  5. To remove the DVD-R from the drive, first un-mount it by typing:

    umount(space)/mnt [ENTER]

3  MOD Peripheral Tower

3.1  Mount and Un-mount Process

  1. Insert an old, no longer needed MOD disk into the MOD Peripheral Tower drive.

  2. Open up a Linux terminal window and type:

    mountMOD [ENTER]

    NOTE:If MOD disk was previously used for DICOM Image Archive, the mount command will not recognize the media. See Initializing MOD Media.

  3. To view the contents of the MOD, type:

    ls(space)-l(space)/MOD [ENTER]

  4. Save and read an image series.

  5. To remove the MOD from the drive, first un-mount it by typing:

    unmountMOD [ENTER]

    NOTE:If the MOD cannot be unmounted, use Image Works Browser>Archive>Detach

3.2  Initializing MOD Media

NOTE:For MOD media disks that contain old DICOM Archive data, perform the following to erase the old file system first before attempting steps 1-6.

  • Make sure you are at “root” user.

  • Type: zapmod(space)-f(space)DMOD(space)-do(space)-r

  1. Insert a new blank MOD disk into the MOD Peripheral Tower drive.

  2. Open up a Linux Terminal Window and type: su(space)- [ENTER]

  3. Enter the root password: <password>

  4. Type: mountMOD [ENTER]

  5. Type: mkfsMOD [ENTER]

  6. Answer Y for “YES” and close the Linux Terminal Window.
