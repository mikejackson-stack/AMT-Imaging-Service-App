Table 5:  Output Signals to Elevation

SignalDescription
Elevation EnableThis is a firmware controlled signal originating in the FPGA code. This signal controls a solid state relay on the MTCB that sends out 24Vdc to the Elevation Drive when the relay is closed. This signal is used to enable the elevation drive motion in either the upward or downward direction. The following conditions must be met in order for the elevation drive to be enabled.
  • The watchdog circuit must be active.
  • The Tape Switch signal must be present indicating the tape switch circuitry is connected and ready for elevation down only.
  • The Table Drives Enable Signal from MSUB must be present (or the service switch is in service mode which activates the table drives enable signal).
  • A firmware command to enable the cradle drive must be present.
Elevation Drive InhibitsElevation Upward Motion Inhibit:
This signal controls a solid state relay on the MTCB that sends out 24Vdc to the elevation drive when the relay is closed. This signal is used to inhibit the motion in the upward direction. In order for this signal not to be inhibiting the upward table motion the elevation up limit switch must not be activated. This signal can be forced active by firmware.
Elevation Downward Motion Inhibit:
This signal controls a solid state relay on the MTCB that sends out 24Vdc to the elevation drive when the relay is closed. This signal is used to inhibit the motion in the downward direction for the table. In order for this signal not to be inhibiting the downward table motion the elevation down limit switch must not be activated. This signal can be forced active by firmware.
Elevation Upward / Downward Motion ControlThis functionality is controlled by firmware only. The enable signals and inhibit signals need to be in the correct state in order for firmware motion control.
Elevation Drive Fault ResetThis signal controls a solid state relay on the MTCB that sends out 24Vdc to the elevation drive when the relay is closed. This signal is used to reset the drive by through a hard line instead of through the serial port interface.
Elevation Spare OutputThe MTCB does not have a spare output for the elevation functionality.
