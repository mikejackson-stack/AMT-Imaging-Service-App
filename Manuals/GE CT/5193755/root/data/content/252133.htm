BrightSpeed (Ltd. Access) Service Methods - Adv

CT Interface (LS16, Ultra, Plus)

The interface between the generator and the ORP consists of:

  • An isolated CAN communication line to the ORP

  • Three isolated lines:

    • Exposure command

    • X-ray on

    • Reset
