GOC1 IRIX Systems Upgrading to Linux - Save System State Twice

GOC1 (IRIX) Operator Consoles consist of: Octane with O2 or Octane without O2.

Perform the following steps on the GOC1 IRIX Operator Console before powering down and installing the Linux based GRE/Xtream Operator Console.

NOTE:Two “Save System State” MOD procedures must be performed:

  • You must save the System State onto your Original System State MOD, label it appropriately, and keep it in a secure place. The “Original IRIX Conversion Release System State” MOD will be used only if the customer wants to revert back to the original IRIX-based software.
  • You must then save a second System State onto a new MOD. This MOD will be used for the software LFC.

  1. Save System State (twice) to an MOD on the GOC1 IRIX Operator Console before installing the new Linux based GRE/Xtream Operator Console.
    1. Insert the MOD into the SCSI Tower MOD drive.
    2. Select: [Service Desktop] .
    3. If reloading software, select: [Utilities] . If upgrading from earlier version software, select: [PM] .
    4. Select: [System State] .
    5. Select [All] to save all data.
    6. Select [Save] .
    7. If applicable, select [OK] when the following message appears: System State Media Status: Please insert a DVD or MOD into the drive and press Save again.
    8. When completed select [Dismiss] .
    9. For the original MOD, label the MOD as “Original IRIX Conversion Release System State” and set this aside.
    10. Repeat Steps a-j, for the second “Save System State”, using a new MOD, and label with the release version that is found on the Application software label to be loaded.
  2. Modify System State MOD as follows:
    1. Insert System State MOD into the drive.
    2. Open a Unix Shell and type the following:
      1. {ctuser@hostname}  su  –
      2. Password: <password>
      3. [root@hostname]  mountMOD
      4. [root@hostname]  cd  /MOD/service_mod_data/system_state
      5. [root@hostname]  chmod 666 *bb .epdlog(this changes permissions on tube usage and edit patient data files)
      6. [root@hostname]  rm  -f  *.stats(this removes runtime stats on non-HPOWER systems)
      7. [root@hostname]  rm  -f  iipBackupGen2.tar.Z(this removes IIP “tar ball” files not used by the new IIP)
      8. [root@hostname]  rm  -f  Voxtool.prefs(this removes Voxtool preferences ⇒ new Voxtool application uses new set of preferences)
      9. [root@hostname]  rm  -f  smartscore.tar.gz(this removes SmartScore files ⇒ SmartScore (SmartScore may not be supported by this software)
      10. [root@hostname]  rm  -f  vxtlBackup.tar(this removes VoxTool files ⇒ new Voxtool application uses a new set of files)
      11. Remove VoxtoolPrefs/* and CT_PerfusionPrefs/* files
      12. [root@hostname]  rm  -f  movierx* (this removes Direct 3D preferences that the customer cannot edit)
      13. [root@hostname]  rm  -f  *.flm
      14. [root@hostname]  rm  -f  *.pro
      15. [root@hostname]  rm  -f  *.vrp
      16. [root@hostname]  rm  -f  *.adv
      17. [root@hostname]  rm  -f  *.adv.research
      18. [root@hostname]  rm  -f  *.disp
      19. [root@hostname]  rm  -f  *.disp.research
      20. [root@hostname]  cd /
      21. [root@hostname]  unmountMOD
    3. Close the Unix Shell.
  3. Proceed to next applicable section.
