2  Overview

The Limited Access Patch is supported on 06MW29.7 software with the following hardware configurations:

  • VCT Halo 64

  • VCT Sherlock 64

  • VCT Select/Pro 32

  • GRE HP 100

  • BrightSpeed 4, 8, 16

  • RT 4

The Patch is not supported on H1/H2/H3/H4 systems or systems without a TGPU..

Last revised:January 29, 2007

3  Procedure

3.1  Installing the Patch on a Supported System

  1. Procedure

    1. Shut the applications down.

    1. Put the CD in the Host computer's DVD drive.

    1. As root, enter patch_install -c.

  1. Output

    1. If this patch was NOT already installed:

      These patches from cdrom will be installed:
Limited_Access_patch
======================================================================

Limited_Access_patch has been installed successfully.

3.2  Uninstalling the Patch

  1. Procedure

    1. Shut the applications down.

    1. As root, enter patch_install -u.

  1. Output

    1. If this patch was NOT already uninstalled:

      There are following pathes installed:
Limited_Access_patch
===========================================================================

y     [ENTER y TO INSTALL, n TO QUIT]

Limited_Access_patch has been uninstalled successfully.
===========================================================================

    1. If this patch was already uninstalled:

      There are no patches need to be uninstalled

4  Finalization

Once the patch has been installed (or uninstalled, as the case may be), reboot the system.
