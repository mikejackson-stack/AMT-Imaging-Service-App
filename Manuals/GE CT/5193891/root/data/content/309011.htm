1  Introduction – Diagnostics and Error Management

The purpose of this document is to give some root causes and recommended actions for the inverter troubleshooting. Any inverter malfunction is stored in the inverter error log and reported to the system through a protocol that transports error code. These errors found can only be reported if the inverter is powered on and live.

This HP Inverter diagnostics section consists on the following information:

  • Power-On diagnostics LED indication.

  • List all the potential error codes that can be issued by the HP Inverter.

  • Provide error code explanation and potential cause.

1.1  Application Self Tests

Under application mode the generator continuously monitors the correct operation of its functions. Faults are reported through an error code and associated message. Some are straightforward and convey the root cause.

1.2  Simplified Error Code Definition

1.2.1  Error Class Definition

There are five classes of errors that correspond to different levels of impact to the system. The class of errors corresponds to the seriousness of the error and the system software will manage operations.

Table 2:  Error Class Definitions

ClassDescription
1Errors which have no impact on the system operation. Errors detected in background diagnostics during application. They are referred as "Warning" errors, to monitor drifts and used for engineering tracking. The inverter phase remains unchanged. Errors are stored in the inverter event log.
2Errors which are detected by HP Inverter and that are recoverable automatically without noticeable effect on the system, such as error related to recovered tube spits. The inverter phase remains unchanged. Errors which usually occur during exposure.
3Errors detected by HP Inverter during exposure. They stop the exposure and revert the inverter into a safe state. Error will be reset on Exposure Command release. It will require another Exposure Command to restart the sequence. The inverter phase is set to "error" until the error is cleared.
4Errors which are related to any hardware failures, software application or communication errors. HP Inverter will revert to a safe state. If preparation is in progress, it is stopped. Errors are cleared either by a reset error action from the system (for system having a reset error mechanism) or by a prep release or by a new prep command. The inverter phase is set to "error" until the error is cleared. Application cannot work if errors are persistent.
5These codes may appear when the inverter or tube temperature limits are reached. The application waits until the thermal information disappears. The error information is temporary. The inverter phase is set to "error" until the error is cleared.

1.2.2  Error Code Definition

Each error code comprises two fields (which cannot be generated and used separately):

  • the first field describes the inverter function which is faulty (referred to as the function code)

  • the second field describes the error detected.

Example: error code 0307 means:

  • 03: high voltage generation function;

  • 07: no kV feedback on cathode (see Section 3).

The field data associated with the error code shows detailed information over the state of the inverter when the error occurred. Examples: rotation high speed acceleration state, small focus preheat.

4  Error Reporting

The inverter error is logged in the system event log file and displayed on the operator console (or workstation), the inverter event log upload functionality is available to get more detailed information about the error. This function must be performed from the operator console (or workstation).

5  Detailed Error Description and Troubleshooting

POTENTIAL FOR SHOCK.
VOLTAGE MAY BE PRESENT.
Before any manual intervention, ensure the main power is off. Apply lock out-tag out procedure for your own safety when manipulating inside the equipment.

For each error code this manual shows an associated message and additional explanation related to the error occurrence.

Codes are sorted by ascending order both for simplified code and error code. Refer to the theory of operation for error code structure. Information about associated data structure is located at the end of each error code subset whenever it applies.

The generator sends only one message of error for all the spits (0324H) at the end of the exposure. During the same exposure we may have different kinds of spits.
