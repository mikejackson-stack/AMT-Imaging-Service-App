2  Overview

This section describes the calibration check of system internal kV metering circuits.

3  Procedure

  1. Select [READ METERING] .

    Illustration 1:  Proprietary Read Metering Screen

  1. Select [RUN] to start the test. During the test, the firmware reads the metering circuits in the OFF state, then reads the metering circuits in the ON state, and finally reports the readings to the display.

  1. Compare the data in the “Delta” column on the Read Meter screen to the data in the “Limit” column.

    NOTE:“Delta” = DVM - A/D

    Table 1:  Generator Characterization Test Specifications

    CIRCUIT “OFF”CIRCUIT “ON”
    Anode kV = 0 ± 0.5Anode kV = 50 ± 7.5
    Cathode kV = 0 ± 0.5Cathode kV = 50 ± 7.5
    Total kV = 0 ± 0.5Total kV = 100 ± 15.0
