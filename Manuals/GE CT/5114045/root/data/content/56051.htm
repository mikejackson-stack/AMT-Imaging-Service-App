2  Preliminary Requirements

2.1  Safety

Electronic devices are extremely sensitive to ESD damage. Always do the following:

  • Wear a grounded ESD wrist strap.

  • Place parts on antistatic surfaces.

  • Transport parts in antistatic bags.

 
 

Do not use excessive force to install any component. Excessive force can result in component failure. Be patient and use only gentle but firm pressure.
 
 

3  Procedure

3.1  ID Module

  1. Remove the system module from the replacement computer.

    1. Loosen the captive screw in each sliding handle.

    1. Pull both handles at the same time until they are fully extended.

    1. Pull out the system module.

    1. Place the system module on an antistatic surface component side up.

  1. Install ID Module into replacement computer

    1. With one hand, reach inside the replacement computer and use your fingers to insert the ID module.

    1. Visually inspect the ID module and make sure it is securely in place.

3.2  Memory

  1. Install Memory Modules

    1. Insert the DIMMs into their sockets on the new system module. You’ll hear a click when they are latched. Notice how the latch on the end of the socket moves up when they’re seated properly. DIMMs are notched on the bottom so that they cannot be inserted incorrectly. See Illustration 1.

      Illustration 1:  Inserting Memory Modules

    1. Verify that both sockets in a bank are populated. DIMMs must be installed in pairs. See Illustration 2.

      Illustration 2:  DIMM Socket and Bank Identifications

  1. Install System Module back into replacement computer

    1. Grasp the module and push inwards, without allowing the delicate connectors on its back edge to touch anything.

    1. With the module inserted, push both handles in at the same time until they are fully seated.

      Illustration 3:  System Module

    1. Tighten the captive screw in each sliding handle.

3.3  PCI MODULE

  1. Slide the PCI module in the replacement computer. Do not to allow the compression connector to touch anything (be sure to remove compression cap before inserting).

  1. Push the release lever in to close (latch). (See Illustration 4 for location of lever.)

    Illustration 4:  PCI Module Installation

  1. Tighten the two captive screws ( Illustration 4).

3.4  DISK DRIVES

  1. Remove the replacement computer front bezel (cover). Press both bezel release buttons simultaneously to release the cover.

  1. Tilt the bezel toward you and lift up to remove.

  1. Grasp a drive handle and lift it to a horizontal position.

  1. Applying gentle and steady pressure, push the drives into place.

  1. Rotate the drive handle to the vertical position to lock the drive in place.

  1. Re-install the front bezel.

4  Finalization

No finalization required.
