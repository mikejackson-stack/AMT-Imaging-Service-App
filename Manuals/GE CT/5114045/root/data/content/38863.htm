RCIB Functional Diagnostics

These diagnostics are accessed by launching Diagnostics from the Service Desktop.

1  Fault Line Diagnostic

[SERVICE DESKTOP] -> [DIAGNOSTICS] -> [SYSTEM CONTROL] -> [RCIB DIAGNOSTICS] -> [FAULT LINE]

Illustration 1:  Fault Line Screen

1.1  Diagnostic Description

The Fault Line Diagnostic validates the parallel and serial fault line between the OBC, DCB, and CCB. Test consists of opening and closing the fault relays on each node and validating that all nodes see the fault.

1.2  When (to use)

  1. Run test to detect intermittent fault line failures.

  2. Run after fixing fault line problem to validate fix.

1.3  What (to look for)

  1. Look for any failures in the "Failures" column.

  2. Look for cable swap issues.

1.4  Notes

  1. Test can be run in the applications and diagnostic download.

  2. OBC must be downloaded for test to run.

  3. Test runs with diagnostic or application firmware downloads.

2  RCIB Ping Diagnostic

[SERVICE DESKTOP] -> [DIAGNOSTICS] -> [SYSTEM CONTROL] -> [RCIB DIAGNOSTICS] -> [PING]

Illustration 3:  PING Screen

2.1  Diagnostic Description

The RCIB Ping Diagnostic sends small CAN packets to the selected nodes and verifies the correct response is received. This test works much the same way as a UNIX ping command.

2.2  When (to use)

  1. Run test to detect intermittent CAN serial line problems failures.

  2. Run after fixing CAN problem to validate fix.

  3. Test can be run to determine the status of the node.

2.3  What (to look for)

Look for any failures in the “Failures” column. Check error log for more information, if a problem is detected.

2.4  Notes

  1. OBC must be downloaded for test to run.

  2. Test can be run in the applications and diagnostic download.

  3. Test makes extensive use of slip-ring and ethernet communication lines.
