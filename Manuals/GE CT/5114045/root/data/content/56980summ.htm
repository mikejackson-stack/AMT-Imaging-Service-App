Octane Frontplane Module Replacement

(Click Here to Return to Detailed Procedure)

1  Procedure

1.1   Accessing the Frontplane Module

  1. Shutdown system and remove power.

  1. Remove the console's front cover. Pull out platform upon which the computer rests. Release its tie-down strap if present.

Wear a grounded ESD wrist strap. Place removed electronic parts on an antistatic surface.
 
 

  1. Remove the System Module. Refer to Octane System Module Replacement.

  1. Remove the XIO Module. Refer to Octane XIO Module Replacement.

  1. Remove the PCI Module. Refer to Octane PCI Card Module Replacement.

  1. Remove the Octane Power Supply. Refer to Octane Power Supply Replacement.

  1. Squeeze both buttons on upper front sides of Octane computer, then tilt forward and lift to remove its front cover.

  1. Remove all Octane Disk Drives. Refer to Octane Internal Hard Drive Replacement.

  1. Remove the Light Module. Squeeze both top and bottom wings of the light together at both ends, gently and evenly pull straight out.

  1. Loosen the six (6) captive screws that hold the frontplane module to the chassis. Refer to Illustration 1, below.

    (Step Details)

  1. Place your hand inside the drive bay and lift the module from the base.

  1. Place it face down on an antistatic surface. Avoid touching any components.

    (Step Details)

1.2   Power Supply Fan

  1. Use a flat headed screwdriver to separate the four tabs holding the fan module to the back of the drive bay.

    (Step Details)

  1. Disconnect the power connector under the fan

1.3   System ID Module

The System ID Module holds the pre-programmed Ethernet address for the Octane computer. It is a small circular disk held by a metal retaining clip next to the drive bay. If the System ID module is changed, all software options (MODs) will have to be re-ordered, as the Options MOD(s) is fingerprinted to the Host Ethernet address at first installation. To replace the System ID Module, please refer to System ID Module Replacement.
