GOC4 Upgrade Installation & Service Information

GOC4 Upgrade Proc Guide and Checklist (LS 3.X or LS 4.X)

This module is ONLY A GUIDE. It contains checklists as an aid to the GOC4 (also called GRE) Stand-alone Operator Console Upgrade Procedure. This module does not contain the procedures themselves. Please refer to the appropriate procedures for detailed installation information.
 
 

Last revised:07 November 2007

1  Upgrade Information For:

1.1  LightSpeed 4.X Systems (16-Slice)

Ultra 16 GOC2 Operator Console with Linux based HP Host and Pegasus/daughter Board will upgrade to a GOC4 Stand-alone Operator Console (the DARC2 Node houses a specific 16-slice DIP Board).

1.2  LightSpeed 3.X Systems (8/4-Slice MDAS)

  • Ultra 8 global console with IRIX based Octane II will upgrade to a GOC4 Stand-alone Operator Console (the DARC2 Node houses a specific 8/4-slice DIP Board).

  • Ultra 8 GOC1 with IRIX based Octane II and Pegasus Board will upgrade to a GOC4 Stand-alone Operator Console (the DARC2 Node houses a specific 8/4-slice DIP Board).

  • Ultra 8 GOC2 with Linux based HP Host and Pegasus Board will upgrade to a GOC4 Stand-alone Operator Console (the DARC2 Node houses a specific 8/4-slice DIP Board).

2  GOC4 Upgrade Checklist (Before You Begin)

  1. Save System State on current console installed at site. Be sure to save any customer reformat files that might exist.

    NOTE:Do not shutdown or disconnect console after system save state! If upgrading from Irix System to Linux, review the software install procedures to convert Irix system state MOD. Certain files must be removed before Irix system state will restore on Linux system. MOD modification scripts must be performed on original console.

  2. Locate the Software Installation Procedure within the “Software” folder of this publication. The LFC procedure may have multiple “Information Gathering” sections. Record system information, as applicable, on the “GRE/Xtream Operator Console Information Sheets.”

    Some information may be viewed from a Unix Shell using the command/path:{ctuser@hostname}cat /usr/g/config/INFO.

  3. Save all network configuration files information.

  4. Locate all REQUIRED software for GOC4 system installation.

  5. Locate Option DVDs and confirm that all ordered options are present.

  6. Locate the latest GOC4 documentation CD-ROM.

  7. Review pre-install for new GOC4 Operator Console cooling requirements

    (Refer to “Cooling Requirement” section in Environmental Conditions)

  8. Review the GOC4 Operator Console power requirement (GOC4 =120vac) (non GOC=240vac)

  9. Determine filming:

    • If DASM II Digital, save your DASM II and cable.

    • For all other DASM configurations, order a new digital DASM II Kit.

  10. Determine whether network connection is Broadband or Dial-up. If Dial-up, save modem and cable.

  11. If remote monitor connections are required, order required B-Cats. (See Section 5.1.).

3  Mechanical Upgrade Installation

3.1  Before you Begin

  1. Review FE skills required: GOC4 Training required for this upgrade.

  2. Review tools required.

  3. Confirm that cooling and power requirements are met.

  4. Complete GOC4 Upgrade Checklist.

  5. Power-down system and perform LOTO (Lock-out, Tag-out).

3.2  Mechanical De-Installation / Installation

  1. Inventory all components to be removed.

  2. Carefully disconnect all system cables from old Operator Console.

  3. Remove and pack: trackball, mouse, keyboard, SCIM, and cables (and monitors if required).

  4. Disassemble Operator Console table top assembly and pack on top of old Operator Console.

  5. Remove old Operator Console from room and clean (remove) dust from area.

  6. Remove the GOC4 Operator Console from skid in the room. Unpack and assemble new Operator Console as required.

  7. Use the boxes to pack and return removed components.

  8. Follow the installation procedure to assemble and connect the GOC4 Operator Console.

    (Refer to Unpacking and Installing a GRE Console and Console Connections, for details.)

  9. Install any existing Options and cables. Some may require new cables.

  10. Pack removed Operator Console on GOC4 shipping skid for return to MKE.

  11. Complete the mechanical upgrade check list.

4  Console Integration

4.1  Before You Begin

  1. Unplug the Hospital Network (HSP) cable from rear Console bulkhead. Label the cable as HSP and set it aside during LFC.

    NOTE:If the Operator Console is powered on and the HSP cable is connected before full Operator Console integration is complete, the DARC Node may interrupt hospital network communications in some cases.

  2. Review completed forms or data sheets (from Section 2)

4.2  GOC4 Software Setup

Console Integration is performed per the applicable Software Installation Procedure within the “Software” folder of this publication.

A reconfig is required unless a newer version of software is available in the B78xxGT box. If a newer software version is available, reload software to the latest release. (Refer to the latest software installation procedure located in the “Software” folder of this publication.)

NOTE:LS 3.X and LS 4.X systems use GOC4 Operator Consoles that have software specifically loaded for MDAS4/MDAS8 and MDAS16 respectively. The Select hardware configuration screen may list the Gantry type as H2.

  1. If applicable, Restore System State with Application Software up.

  2. Install Options in specific order with Application Software up.

  3. Open a Unix Shell and shut Application Software down: {ctuser@hostname}  cleanMon

  4. When Application Software is fully down, perform a reconfig as root in a Unix Shell:

    1. {ctuser@hostname}  su  -

    2. Password: <password>

      NOTE:If the password has not been modified by the site and is not known, the correct course of action is to contact Local GE Service.

    3. To reconfig:

      {root@hostname}  reconfig

    4. Select the [Config] button on the CT Software Installation window.

    5. Modify the content information (site name, time zone, etc.) for each screen as required.

    6. When the information input is complete, select [Accept] . The system will reboot.

  5. Perform the following per the Software Installation Procedure:

    1. Load Service Software per instructions on the media, if applicable.

    2. Start Application Software.

    3. If not already completed, install Options in specific order.

    4. Perform initial load of this software - Retro Recon / Customize Large Font (Screen and Film).

    5. Perform Flash Download

    6. Install Features (HIPPA, PNF, AW Direct Connect).

    7. Connect HSP Ethernet Cable.

    8. Perform Tube Install Certification.

    9. Perform Flash Download after TIC.

    10. Restart Operator Console.

    11. Save System State.

    12. Perform system sanity scanning.

    13. Perform Finalization actions.

    14. Load Patches (if applicable).

4.3  Remaining Setup and Calibration

  1. Set up Monitor and Camera.

  2. Adjust Intercom.

  3. Perform Tube Warm up and Fast Cal.

  4. Perform N Number calibration.

  5. Verify Image Quality.

  6. Perform System Functional Verification.

  7. Save System State.

  8. Reinstall any customer DICOM devices.

  9. Reinstall any remote monitors.

  10. Perform Options Functional Verification.

  11. Complete all Forms as required (see Forms and Checklists.)

4.4  Installation Completion

  1. Complete HHS e2579 form downloaded from the HHS website and complete a GE e4879 Install Completion form downloaded from the Service CD-ROM

  2. Complete console return paperwork and ship.

  3. Update online product locator.

  4. Install all Operator Console covers. If present, ensure that the DARC/IG Troubleshooting Video Cable is not connected to the Scan or Display Monitors.

  5. Store documents, data forms, and software in GE cabinet.

  6. Complete any other electrical installation checks as required.

  7. Complete GOC4 Upgrade Completion Form.
