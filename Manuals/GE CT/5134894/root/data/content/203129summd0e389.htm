NOTE:If [Yes] is selected, then all scan data will be deleted on the Scan Data Disk. To avoid accidental regen, [No] is selected by default each time reconfig is run. Regenerating the Scan Database destroys all the scan and calibration files on the Scan Data Disk. Make sure that all images have been reconstructed before regenerating the Scan Database.

This procedure is normally only needed when a Scan Data Disk is replaced or reformatted. Refer to the Software Installation Procedures manual, if you require more information regarding Scan Database Regeneration.
