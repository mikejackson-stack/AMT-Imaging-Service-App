2  Procedure

2.1   Shut Down Application

2.1.1  Standard Level

If Applications is currently running, you must shut down system applications.

  1. Click on the [Service Desktop] icon.

  1. On the desktop tool-bar select [Utilities] icon.

  1. Select [Applications Shutdown] (to bring down applications only).

2.1.2  Super-User Level

  1. Open a Shell window.

  1. Type: su - <ENTER> at the prompt.

  1. Type the root (super user) password: #bigguy

2.2   Check/Set Date and Time

If the time and date is already correct, skip this procedure. Otherwise, you must set the date and time on the Host Computer. With Application Software down, enter the time and date if needed.

  1. If Applications are up, select the [Service Desktop] icon, [Utilities] , then [Application Shutdown] .

  1. Open a Unix shell.

    (Step Details)

  1. Type: setdate mmddhhmmyyyy (e.g.: setdate 050409002003) and press <Enter>.

    (Step Details)

  1. The setdate program will set and display the time and date for on the Host Computer. Verify the date and time on the Host Computer is correct.

  1. To exit the root session, Type: exit <Enter>.

  1. Slide the computer tray back into position, properly secure it, and replace the console’s front cover.

2.3   Reconfig the OC

2.3.1  Overview

  1. On the following screens, make the necessary changes, pressing the corresponding button at the top of the screen to move from screen to screen. When done, either press the [Accept] button to start the reconfiguration process, or press [Quit] , to exit without changing the system configuration.

  1. While the reconfiguration is in process, messages are displayed in a shell window, which closes when reconfiguration is complete. The reconfiguration output is logged to the following file:

    (Step Details)

  1. It is possible to abort the reconfiguration while entering information on the reconfiguration screens. Simply press the [Quit] button at the top of the screen. There is NO safe way to abort the reconfiguration AFTER pressing the [Accept] button. If the entries made in the screens were incorrect, DO NOT try to stop the reconfiguration, instead wait for it to complete, and rerun reconfig, entering the correct parameters.

2.3.2  Procedure

  1. Change directory to scripts:

    (Step Details)

  1. Launch the Install utility:

    (Step Details)

  1. Click on the [Config] button.

    (Step Details)

  1. Configure System Settings:

    1. Hospital Name ( Illustration 2, item a) configures the name that will show up on images produced by this scanner.

      (Step Details)

    1. Service ID ( Illustration 2, item b) is issued by the Service organization.

      (Step Details)

    1. Select the Time Zone for the site.

      (Step Details)

    1. Next MOD # Not Currently Implemented.

    1. Next Patient Exam # configures the next Exam number the scan user interface will use. At initial system installation, type: 1

    1. Next Diagnostic Exam # Not Currently Implemented.

    1. Regenerate Database determines whether the Scan Database will be regenerated during reconfiguration. Select [NO] .

      (Step Details)

    1. Mobile System Select to tell the software if this CT is in a mobile environment or not.

  1. Select the [Preferences] button to display the Preference Settings screen ( Illustration 3).

    (Step Details)

  1. Configure Preferences Settings (Refer to Illustration 3):

    1. Doctors Title - Enter the title for the Doctor. (e.g. radiologist)

    1. Units for Patient Weight - Tells the software whether pounds or kilograms are being used.

    1. Language configures the language to be displayed on the Application screens ( [ENGLISH] , [GERMAN] , [PORTUGESE] , [FRENCH] , [ITALIAN] , [SPANISH] , [JAPANESE] ).

    1. Preferred Fast Cal KV configures the preferred kV that the Fast Cal Routine will calibrate (80, 100, 120, 140 in the Selected Preferred Fast Cal KV field). The default selections are 120 and 140.

      (Step Details)

    1. Date Format configures the format in which the date will be displayed on the images.

    1. Time Format configures the format in which the time will be displayed on the images

    1. Default Archive Device is [DICOM] .

    1. HIPAA Present - Consult with the customer. Unless they specify that they want to use this feature, this field should be set to [OFF] .

    1. Select the site preferred Dose Information Display option for the site to use in monitoring calculated Patient Dose:

      (Step Details)

  1. Select the hardware button to display the Hardware Settings Screen ( Illustration 4).

    (Step Details)

  1. Configure Hardware Settings (Refer to Illustration 4):

    1. DAS Type configures which DAS the software should expect.

    1. Tube Type configures which X-Ray Tube the software should expect.

    1. PDU Type configures which PDU the software should expect.

    1. Collimator/Filter Type configures which Collimator/Filter the software should expect. Presently, LightSpeed 4.X systems only support [Helios G1] .

    1. Select Network Image Printer ONLY IF the site plans to use a network connected postscript printer (such as Codonics printers) with this system.

      (Step Details)

    1. Camera Setup

      (Step Details)

    1. Scan Recon Hardware Configuration selects whether the 02 is present.

    1. Gantry Type selects the type of Gantry connected to this console.

  1. Select the [Network] button to display the Network Settings Screen as shown in Illustration 5.

    (Step Details)

  1. Configure Network Settings (Refer to Illustration 5):

    1. Select the Suite Name: add your name here (Example: CT55).

      (Step Details)

    1. Select the Host Name: add your host name here (Example: BAY55).

      (Step Details)

    1. Set the IP Address: add your address here (Example: 3.57.255.55).

    1. Set the Netmask: add your address here (Example: 255.255.252.0).

    1. Set the Broadcast Address: add your address here (Example: 3.57.255.255).

    1. Set the Default Gateway: add your address here (Example: 3.57.252.254).

    1. Ensure the [Advanced Options] and [Use NIS] boxes are checked.

  1. If there is an Internal Option - Internal Subnet setting, do not change the default settings.

  1. Enter Domain Name: add your name here (Example: CTSYSTEMS.)

  1. Enter the IP Address of Internal Server: add your address here (Example: 3.70.56.18).

  1. Click the [Accept] button at the right corner of the User Interface. The following message appears: Please make sure the CT Application SW is in the drive - the system will be rebooted. Ignore this message.

    (Step Details)

  1. As the system reboots, the following Winterm window message appears: Starting LFW procedure (~13 minutes to load). A shell Installation screen appears and the application software starts loading.

  1. When the system prompts you to reboot (after approximately 13 minutes), answer [Yes] . The system is going down for reboot NOW.

  1. After approximately three (3) minutes, a pink pop up window appears, stating CT Software Auto-Start Disabled. In this box select: [OK] .

  1. Press the button on the DVD-ROM drive to remove the LightSpeed Apps SW CD-ROM from the HP Host Computer.

2.4   Applications Start-Up

  1. Open the Console shell window and type: st <Enter>.

  1. The applications desktop appears on the monitor.
