3  LightSpeed 1.X GOC4 Upgrade Checklist - Before You Begin

  1. Save System State on current console installed at site. Be sure to save any customer reformat files that might exist.

    NOTE:Do not shutdown or disconnect console after system save state! If upgrading from Irix System to Linux, review the software install procedures to convert Irix system state MOD. Certain files must be removed before Irix system state will restore on Linux system. MOD modification scripts must be performed on original console.

  2. Locate the Software Installation Procedure within the “Software” folder of this publication. The LFC procedure may have multiple “Information Gathering” sections. Record system information, as applicable, on the “GRE/Xtream Operator Console Information Sheets.”

    Some information may be viewed from a Unix Shell using the command/path:{ctuser@hostname}cat /usr/g/config/INFO.

  3. Save all network configuration files information.

  4. Locate all REQUIRED software and options for your GOC4 system installation.

    NOTE:If this console is installed on a LightSpeed 1.X or 2.X SDAS system, note that it is software-loaded and configured for LightSpeed 1.X. If the console is installed on a LightSpeed 2.X system, you must reload the latest version of the software. (Refer to the latest software installation procedure located in the “Software” folder of this publication.) For all other system types, software reload is not necessary.

  5. Locate option DVDs and confirm that all ordered options are present.

  6. Locate the latest GOC4 documentation CD-ROM.

  7. Review pre-install for new GOC4 console cooling requirements.

    (Refer to “Cooling Requirement” section in Environmental Conditions.)

  8. Review the console power requirement (GOC4 = 120VAC) (non-GOC = 240VAC)

  9. Determine filming:

    • If DASM II Digital, save your DASM II and cable.

    • For all other DASM configurations, order a new digital DASM II Kit.

    (Refer to Section 6.2, for part numbers.)

  10. Determine whether network connection is Broadband or Dial-up. If Dial-up, save modem and cable.

  11. If remote monitor connections are required, order required Linux B-Cats. (See Section 6.1.).

4  Mechanical Upgrade Installation

4.1  Before you Begin

  1. Review FE skills required. GOC4 Training required for this upgrade.

  2. Review tools required.

  3. Confirm that cooling and power requirements are met.

  4. Complete LightSpeed 1.X GOC4 Upgrade Checklist (Section 3), Power-down system, and perform LOTO (Lock-out, Tag-out).

4.2  GOC4 Mechanical De-Installation / Installation

  1. Inventory all components to be installed.

    (Refer to Section 7.1.2, for Missing in Shipment information.)

  2. Carefully disconnect all system cables from old Operator Console.

  3. Remove trackball, mouse, keyboard, cables, and monitors.

  4. Disassemble Operator Console table top assembly and pack on top of old Operator Console.

  5. Remove old Operator Console from room and clean (remove) dust from area. Refer to:

  6. Remove the GOC4 Operator Console from skid in the room. Unpack and assemble new Operator Console as required.

  7. Use the boxes to pack and return removed components.

  8. Follow the mechanical installation procedure to assemble and connect the GOC4 Operator Console.

    (Refer to Unpacking and Installing a GRE Console)

    (Refer to Console Connections, for details.)

  9. Remove the remote tilt button from the SCIM and install the appropriate label

    Refer to the 14 x 17 wiring drawing located in the back of the console.

    (Click on the PDF icon, , to view a scalable PDF version of this drawing.)

  10. Install any existing options and cables. Some may require new cables.

  11. Pack H1 the removed Operator Console on GOC4 shipping skid for return to MKE.

  12. Complete the mechanical upgrade check list (GRE_Upgrade_Completion_Checklist.doc).

5  Console Integration

5.1  Before You Begin

  1. Unplug the Hospital Network (HSP) cable from rear Console bulkhead. Label the cable as HSP and set it aside during LFC.

    NOTE:If the Operator Console is powered on and the HSP cable is connected before full Operator Console integration is complete, the DARC Node may interrupt hospital network communications in some cases.

  2. Review completed forms or data sheets (from Section 3)

  3. Follow the latest software installation procedure located in the “Software” folder of this publication if your console is loaded with software different than that for QX/I 4 SDAS.

  4. Find and have available the latest GOC4 service CD-ROM for QXI 4 SDAS.

5.2  GOC4 Software Setup

Console Integration is performed per the applicable Software Installation Procedure within the “Software” folder of this publication.

A reconfig is required unless a newer version of software is available in the B78xxGT box. If a newer software version is available, reload software to the latest release. (Refer to the latest software installation procedure located in the “Software” folder of this publication.)

  1. If applicable, Restore System State with Application Software up.

  2. Install Options in specific order with Application Software up.

  3. Open a Unix Shell and shut Application Software down: {ctuser@hostname}  cleanMon

  4. When Application Software is fully down, perform a reconfig as root in a Unix Shell:

    1. {ctuser@hostname}  su  -

    2. Password: <password>

      NOTE:If the password has not been modified by the site and is not known, the correct course of action is to contact Local GE Service.

    3. To reconfig:

      {root@hostname}  reconfig

    4. Select the [Config] button on the CT Software Installation window.

    5. Modify the content information (site name, time zone, etc.) for each screen as required.

    6. When the information input is complete, select [Accept] . The system will reboot.

  5. Perform the following per the Software Installation Procedure:

    1. Load Service Software per instructions on the media, if applicable.

    2. Start Application Software.

    3. If not already completed, install Options in specific order.

    4. Perform initial load of this software - Retro Recon / Customize Large Font (Screen and Film).

    5. Perform Flash Download

    6. Install Features (HIPPA, PNF, AW Direct Connect).

    7. Connect HSP Ethernet Cable.

    8. Perform Tube Install Certification.

    9. Perform Flash Download after TIC.

    10. Restart Operator Console.

    11. Save System State.

    12. Perform system sanity scanning.

    13. Perform Finalization actions.

    14. Load Patches (if applicable).

5.3  Remaining Setup and Calibration

  1. Set up Monitor (new monitor is required).

  2. Set up Intercom SCIM volume and check labels. If older than 6 months, complete a full set of cals.

  3. Perform Tube Warm up and Fast Cal.

  4. Perform N Number Calibration

  5. Perform DAS Gain Cal

  6. Perform Collimator Gain Cal

  7. Verify H1 QX/I Image Quality (service protocol 10.8) IQ scan

  8. Perform System Functional Verification (service protocol 10.4 48cm scan)

  9. Perform System Table Gantry Functional Verification

  10. Check that the remote tilt key is removed from the SCIM with correct label installed.

  11. Reinstall and verify any additional customer DICOM devices and camera

  12. Reinstall any remote monitors (Linux Kit - see Section 6.1).

  13. Perform Options Functional Verification (remote monitors, video equip, injector, etc.).

  14. Save System Save State using supplied DVD.

  15. Complete all Forms as required (see Forms and Checklists.)

5.4  Installation Completion

  1. Complete HHS documentation (USA Only) 4879 & 2579.

  2. Complete console return paperwork and ship to GoldSeal.

  3. Update online product locator.

  4. Install all console covers.

  5. Store documents, data forms and software in GE cabinet.

  6. Complete any other electrical installation checkouts as required.

  7. Complete GRE Upgrade Completion Form.

7.2  QX/I 1.X Upgrade Console Mechanical Differences Overview

  1. Follow the GRE QX/i Console Upgrade procedure. New rev 3 Artesyn boards in the gantry & table and a new table ETC board will be replaced.

    NOTE:Static protection is required.

  2. Additional schematics can be found in the on-site service manuals for your system

  3. Disconnect & Remove all monitors, keyboard, trackball and cables. Place all removed components out side of the scan room. These items will be repacked in the new component boxes and returned to Gold Seal.

  4. Remove keyboard desktop (tools required) and support arms. Carefully remove the console out of the room. Save and return all hardware.

  5. A new power cable is required for the GOC4 upgrade. If a cable is required remove covers, to gain access to duct or conduit. Locate the new power cable and install now. Optional: You can re-terminate the console ends on your existing power cable.

  6. If your system has optional monitors, or video devices, a Linux video upgrade option is required. Install this upgrade now. GOC4 support a digital DASM only. If required pull in new cables as required.

  7. New Monitors are required for this upgrade. Locate the monitors to be installed. A new SCIM / keyboard assembly will replace the one piece keyboard assembly. Remove the remote tilt key and replace with the NO TILT overlay.

  8. Go to Step 7 on the upgrade check list to view additional parts.
