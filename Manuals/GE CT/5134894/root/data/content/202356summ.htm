Loading ConnectPro Software Option

(Click Here to Return to Detailed Procedure)

1  Required Conditions

ConditionReferenceEff

Most hospital HIS/RIS systems are not DICOM compatible and require a DICOM HIS/RIS Worklist Interface to provide patient scheduling information to the CT system. Contact your local HNS support engineer to determine exactly what DICOM HIS/RIS Interface is appropriate for the customer.

-

-

The CT system must have the ConnectPRO software option installed to utilize the DICOM Protocol Worklist capability.

-

-

2  Procedure

  1. If you are not on the Service Desktop, click on the [Service Desktop] icon.

  1. Click on the [Utilities] icon.

  1. Click on [Install] .

  1. Select [INSTALL OPTIONS] and click [START] . The console displays the Software Options window. (Refer to the appropriate Software Installation Procedures manual, for screen details.)

  1. Insert the ConnectPRO Options disk (DVD) into the drive.

  1. Click on [OK] to continue.

  1. On the Software Option window, select [ConnectPRO] in the Available Options pane.

  1. Click on the [Install] button.

    (Step Details)

  1. Enter the hospital provided HIS Server IP Address.

  1. Enter the HIS Server AE Title from the DICOM HIS/RIS Interface device DICOM Conformance Statement document.

  1. Enter the HIS Server AE Port # from the DICOM HIS/RIS Interface device DICOM Conformance Statement document.

  1. Record all the LightSpeed ConnectPRO HIS/RIS Network parameters in the appropriate Software Installation Procedures document.

    (Step Details)

  1. Click on the [Accept] button. The system will check valid setup entries, execute a perl script that makes changes to the configuration files for HIS/RIS, and return to the Software Option window.

  1. Click on the [Quit] button and the subsequent [OK] button in the message window.

  1. Remove the options disk from the drive, and if using an MOD, write protect the side containing the ConnectPRO option.
