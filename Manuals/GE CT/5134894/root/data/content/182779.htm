Computer Integration Procedure is as follows:

    • LFC Procedure - Version 05MW14.5 (Software Installation Procedures)

    • Restoring MOD System State - Field Site Upgrading To Linux Only

    • Save/Restore CSA Protocols

    • Install Customer Options - Software

  • (For Systems NOT Requiring a LFC, i.e. 1.X (QX/i)) Reconfiguration

4  Procedure

4.1  Before You Begin

Before you begin this procedure, do the following:

  1. Locate all information forms and sheets.

  1. Locate all software and Software Load Procedures for your upgrade.

  1. Check all cable connections in Console and PDU.

  1. Power-ON systems. Your system should boot to applications.

  1. Check software version loaded.

  1. Record any errors.

  1. Proceed to Restoring MOD System State - Field Site Upgrading To Linux Only.

  1. If your system fails to boot, follow the appropriate Troubleshooting procedure.

4.2  Configuration

Note: Type the text shown in boldface, and press the <Enter> on the keyboard.

4.2.1  Restoring MOD System State - Field Site Upgrading To Linux Only

NOTE:For sites that have System State Information ONLY on a MOD (not a DVD).

  1. Open a Unix shell and type the following:

    From browser, type: cat /usr/g/config/INFO<Enter>

    (For QX/i (1.X) Upgrade) Continue with this procedure.

    (For Plus (2.X) Upgrade) Proceed to LFC Procedure - Version 05MW14.5.

    whoami<Enter>

    ctuser

    cd /usr/g/bin<Enter>

    sysstategui -MOD -IRX2LNX<Enter>

  1. When the system state GUI comes up, Select [ALL] and then select [RESTORE] .

NOTE:The Irix to Linux conversion takes around 40 minutes. The command lines scroll very quickly during the conversion. When the scrolling stops, the system state has completed its conversion.

  1. (For All Non-Linux Upgrades Only) With the system state MOD still in the drive, open a new shell type the following commands as ctuser:

    mountMOD -I2L<Enter>

    mv /usr/g/service/.bb /usr/g/service/bb.lfc<Enter>

    mkdir /usr/g/service/.bb<Enter>

    rm -rf /tmp/*bb<Enter>

    cp /MOD/service_mod_data/system_state/*bb /usr/g/service/.bb<Enter>

    /usr/g/bin/SwapTubeData<Enter>

    cp -f /tmp/*bb /usr/g/service/.bb<Enter>

  1. Remove the MOD from the drive.

  1. Insert the DVD into the Peripheral Tower DVD RAM tower drive.

  1. Select: [SERVICE DESKTOP] .

  1. Select: [UTILITIES] .

  1. Select: [SYSTEM STATE] .

  1. Click [ALL] to select all the cals, characterizations, etc.

  1. Click [SAVE] .

  1. If applicable, click [OK] when the following message appears: System State Media Status: Please insert a DVD or MOD into the drive and press Save again.

  1. When completed select [DISMISS] .

  1. Close the window in the upper left corner of the screen.

4.2.2  Restore System State

Use the system state disk DVD that you just created for the installed system. The system state disk you created should contain:

  • Collimator Characterization

  • Phantom Calibrations

  • Gen Cal

  • Other Data

    The installation process uses all the system state files. At this time, use the system state DVD to restore all files.

    If the system state DVD was not created, you must recalibrate your system.

  1. Insert the System State DVD you just created into the DVD drive in the SCSI Tower.

  1. If you are not on the Service Desktop, click on the [SERVICE DESKTOP] icon .

  1. Click on the [PM] icon .

  1. Select [SYSTEM STATE] .

  1. Select [CHARACT] .

  1. Select [CALS] .

  1. Select [RESTORE ALL] to restore the system characterization and phantom calibration files to the system.

NOTE:Restore All State can take as long as ten minutes, although typical times average about three minutes. When Restore State completes, dismiss the tool, and proceed to the next section.

If any error should occur during the restore process, see the Software Installation Procedures manual (Load From Cold) for information regarding possible error messages and their recovery.

  1. Click [NO] for Reset Scan Hardware popup message.

  1. Select [DISMISS] .

  1. Check all restored items against your data sheets. Fix any failed items.

4.2.3  Save/Restore CSA Protocols

Use this procedure when upgrading from the Linux GOC II Console to the GRE Console.

NOTE:This is not applicable for an Octane Console to GRE Console upgrade.

  1. Save State via the System State UI.

  1. Do not remove the system state media (DVD) from the drive after the save operation.

  1. Open a shell and type the following:

    tar Pcvf /data/vxtlBackup.tar /usr/g/ctuser/Prefs/VoxtoolPrefs/* mountDVD

    \cp -f /data/vxtlBackup.tar /DVD/service_mod_data/system_state unmountDVD

  1. Close the shell and continue with the software load.

  1. Restore State via the System State UI.

  1. Verify that the CSA Protocols (Reformat, Volume Viewer, etc.) are restored correctly.

4.2.4  Install Customer Options - Software

NOTE:Your system may have media containing customer purchased options. If your system has an options disk, install it at this time - otherwise skip this section.

(Click on the PDF icon below for a listing of standard options.)

Ensure that the options disk (DVD) is NOT write protected at this time. The initial install requires that the DVD be write enabled; subsequent installs can be done with the DVD write protected.

  1. Insert the Options DVD in the Peripheral Tower DVD RAM drive.

  1. If you are not on the Service Desktop, click on the [SERVICE DESKTOP] icon, .

  1. Click on the [UTILITIES] icon, .

  1. Select [INSTALL] .

  1. Select [INSTALL OPTIONS] . A blank Software Options screen ( Illustration 1) appears.

    Illustration 1:  Install Options Screen

  1. Click [INSTALL] . A Select Mechanism ( Illustration 2) window opens. Select the mechanism through which you want to install Option Keys.

    Illustration 2:  Select Mechanism window

  1. Click [PERMANENT] . A Select Device ( Illustration 3) window opens. Select the mechanism through which you want to install the Permanent Option Keys.

    Illustration 3:  Select Device Window

  1. Click the [MEDIA] button and insert the Options DVD or MOD.

  1. Click [OK] . Available options appear on the Software Options screen ( Illustration 4).

    Illustration 4:  Software Options Screen

  1. Pick options one at a time from the Available Options list and click on [INSTALL] to update each selection and place it on the Installed Options List.

  1. When the process is complete, click [QUIT] to close the window.

4.3  Reconfiguration

Reconfiguration procedures are system-specific. Please select the appropriate system from the following list:

  • GRE Reconfiguration - LightSpeed 4.X

  • GRE Reconfiguration - LightSpeed 3.X

  • GRE Reconfiguration - LightSpeed 2.X

  • GRE Reconfiguration - LightSpeed 1.X

NOTE:The following three tasks must be done for ALL systems.

  1. Install all camera, network, and DICOM devices.

  1. Complete all network transfers for each device.

  1. Complete all film transfers for each device.
