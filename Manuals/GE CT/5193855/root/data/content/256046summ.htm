JEDI Noise Test (Pro16, RT)

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Set up test scans.

    1. Remove gantry right side cover.

    1. Turn off the axial drive enable switch on the Service Switch Panel.

    1. Remove the mylar scan window.

    1. Rotate the gantry so that the tube is at the 6 o'clock position (tube at the bottom with the window facing up).

    1. Engage rotational lock. Check that the gantry is securely locked by attempting to rotate the gantry by hand.

    1. Fold a lead apron so that it is an inch or more thick. Cover the window of the tube with this lead apron so that x-rays cannot escape the tube.

    1. Launch the [DIAGNOSTIC DATA COLLECTION] tool.

    1. Select [STATIC SCAN - X-RAYS ON] . Prescribe a scan with the parameter values described below. Leave everything to default and make the following changes:

      (Step Details)

  1. Perform the scan.

  1. Select [STATIONARY SCAN - X-RAYS OFF] . Prescribe a scan with the parameters described below. Leave everything to default and make the following changes:

    (Step Details)

  1. Perform the scan.

  1. Analyze the data:

    1. Open the Common Service Desktop and press the [IMAGE QUALITY] button.

    1. RUN [SCAN ANALYSIS] tool.

    1. Find the scan you just performed and select [Create MSD DD File] .

    1. Create an MSD DD file for each scan. Wait for message indicating file(s) created.

    1. Select the [DD] tab, then select [Update]

    1. Find the two MSD files you just created

    1. Select the MSD file for scan 1 (the X-Ray on scan) and press the [File 1] button. For the X-Ray off scan, select [File 2] .

    1. Under [Math Operations] make sure the plot button is selected and press the file subtraction button (-). The second scan will be subtracted from the first and a plot of the difference will be displayed.

    1. Scroll through each of the Vector 2 plots for each set. Compare the values to the specifications table.

  1. Scroll through each of the standard deviation plots. Record the maximum values found in each range of channels in the middle two rows of Table 1.

    (Step Details)

  1. 5.) The test fails if any of the observed maximum values are greater than the spec. A likely cause is the positioning and securing of the high voltage cables between the tank and inverter. See Inverter/Tank AC Wire Routing for more details. This test must pass for the system to be used.
