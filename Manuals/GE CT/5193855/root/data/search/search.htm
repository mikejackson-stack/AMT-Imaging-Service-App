dtSearch
The search tool that is included on this CD-ROM is dtSearch. It allows the user to search both HTML and PDF files by keyword.

IMPORTANT! Read the instructions below, before launching dtSearch.

  1. When you click the "Launch dtSearch" button (bottom of this page), this window will close and you will see the following dialog:
  2. Select "Run this program from its current location," then click "OK." A second dialog, shown below, will appear.
  3. Click "Yes." The dtSearch form will open in a new browser window. You may now search all of the HTML and PDF files on this CD-ROM.
