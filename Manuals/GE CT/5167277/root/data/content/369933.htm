5167277-800 - FX/Xtream SW & Upgrade Procedures

Power-off (Shut down) Console Procedure

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, click on the [Shut Down] button and select [Shutdown] .

      The Operator Console monitor will display a 'Power Down' message when it is acceptable to power OFF the Operator Console.

    2. If Applications are down, open a Unix Shell. Type: halt.

      The Operator Console monitor will display a 'Power Down' message when it is acceptable to power OFF the Operator Console.

  2. Power OFF the console at the front panel switch.

  3. Turn off the power at the Outlet Box.

  4. Unplug the Power at the Back of the Console.
