5167277-800 - FX/Xtream SW & Upgrade Procedures

Memory Installation (HP xw8x00 PC)

Last Revised:31 August 2005

1  Open the Host Computer

  1. Unscrew the four (4) screws from the HP xw8000/8200 Host computer.

  2. Unplug and label each cable from the back of the Host.

ELECTRICAL HAZARD.
POTENTIAL FOR SHOCK.
Always turn the system off and unplug the power cord from the outlet or Power Protection Device before you remove the covers. Always replace the cover(s) before you turn on the workstation.

3. If necessary, unlock the cover on the side of the workstation.

4. Pull out on the latch to release the cover.

5. Tilt the cover open and lift it off.

2  Install Additional 2GB Memory Modules

NOTE:DDR DRAM must be added as matched pairs. For example, if you place a memory module of 1GB in one slot of memory module pair 1, you must also insert a 1GB module in the second slot of the pair.

  1. Refer to Illustration 1, Illustration 2

  2. Hold the memory module by its left and right edges and insert the module into the slot.

    NOTE:The memory modules are keyed and can only be inserted in one direction. Be careful to align the notch on the module with the key on the connector.

    NOTE:When the module is correctly seated, the retainer clips return to their fully upright position.

  3. Snap the clips firmly into place to ensure that the DIMMs are seated properly.

  4. Replace the system covers, reconnect all cables, and turn on the system.

  5. Start the workstation. Press <Esc> when prompted to check the Summary Screen, and verify the new 4GB memory configuration.

4  Replacing a Host that has the 2Gbyte Memory Upgrade

  1. Remove the addition 2Gbytes of memory from the Old Host computer.

    (Reverse the steps in Section 2.)

    NOTE:Only remove 2Gbytes of the memory. (i.e. 2 DIMMs)

  2. Remove sticker plate from Old Host and swap it with the new Host faceplate:

    1. Detach the three (3) Green tabs that hold the front cover in place by pulling up slightly.

    2. Swing front cover out.

    3. Remove front plate from the old Host. From the backside of the Host front cover, grasp the plate that contains the 2Gbyte sticker, and pull firmly.

  3. Remove the same plate from the new Host computer and swap the two plates.

  4. Replace the front and side covers of both Host computers.

    (Side cover replacement is described in Section 5.)

5  Replace the Side Cover

  1. Lower the cover onto the chassis (aligning the guide rail on the bottom inside edge of the cover with the bottom edge of the workstation chassis).

  2. Close the cover.

  3. If desired, lock the chassis with the supplied key.

  4. Return the Host module to the Console and screw in place with the 4 screws removed earlier.
