5167277-800 - FX/Xtream SW & Upgrade Procedures

VIG Node Reset

Last Revised:18 September 2006

1  VIG Node Process Overview

Use this procedure when replacing a VIG Node, replacing a VDARC Node, or performing a LFC.

VIG Node power off / on is performed with the VDARC communicating (rsh is succesful). If present, use ipmitool command to verify that the ipmi is communicating between the VDARC and the IG Nodes. If a password is required for the VIG Node, select the <Enter> key, but -P should prevent that field from popping up. Then the vrac_flash_update command is performed. If the vrac_flash_update fails, troubleshoot as needed by verifying ping, rsh, and telnet process as required. Then reset each VIG Node. If a command fails to work become root and retry it.

2  Process

  1. If VIG Node is powered ON, turn power OFF at the front panel of each VIG Node.

  2. Open a Unix Shell as ctuser on the HOST:

    Perform a rsh darc command:

    {ctuser@hostname} rsh  darc

    Last login: Day Month Day Time from oc

    [ctuser@darc]$

  3. After verifying the DARC Node is up, apply power at the front panel of each VIG Node.

    Wait approximately 1.5 minutes to 2 minutes for the VIG Nodes to boot up.

  5. Exit the VDARC Node and get back to HOST

    [ctuser@darc ~]$ exit

  6. Perform the VIG Node vrac flashing process from the HOST

    {ctuser@hostname} vrac_flash_update

  7. Verify the vrac flashing process was successful.

  8. Select the front panel reset button () on each VIG Node.

  9. Verify each VIG Node is successfully able to rsh:

    {ctuser@hostname}rsh  darc

    Last login: Day Month Day Time from oc

    [ctuser@darc]$ lhinv  |  grep  Main

                  (verify Main memory = 6 GB)

    [ctuser@darc]$ rsh  ig1

    [ctuser@ig1]$ lhinv  |  grep  Main

                  (verify Main memory = 6 GB)

    [ctuser@ig1]$ exit

    [ctuser@darc]$ rsh  ig2

    [ctuser@ig2]$ lhinv  |  grep  Main

                  (verify Main memory = 6 GB)

    [ctuser@ig2]$ exit

    [ctuser@darc]$ rsh  ig3

    [ctuser@ig3]$ lhinv  |  grep  Main

                  (verify Main memory = 6 GB)

    [ctuser@ig3]$ exit

  10. Perform vrac_diags as follows:

    [ctuser@darc]$ su  -

    Password #bigguy

    [root@darc]$ vrac_menu  -a  (See Note)

NOTE:Depending on the software version, Cone Beam and Thin Slice diagnostics may not be available from the -a command (above). In this case, perform the following commands with Applications Software down:

vrac_menu  -cb  –a

vrac_menu  –ts  –a
