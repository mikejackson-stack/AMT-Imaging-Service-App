5167277-800 - FX/Xtream SW & Upgrade Procedures

DARC Replacement Guide

Choose the Scenario below that is appropriate for your situation:

Scenario1: Perform the following instructions for DARC replacement, when current DARC is up and running and is accessible via network:

  1. Delete SCSI Partitions, using the instructions in LFC Procedure - Version 06MW3.5.

  2. Perform the DARC Replacement Procedure that is appropriate for your system:

    • DARC-2 Replacement

    • DARC Replacement

Scenario 2: Perform the following instructions for DARC replacement, when current DARC is down or not accessible via network:

  1. Power-off SDDA if the SDDA is external

  2. Load the DARC OS, using the “LFC - OS Installation on DARC” provided in LFC Procedure - Version 06MW3.5

  3. Power-on the SDDA.

  4. Wait until the DARC OS is up and accessible via network

  5. Delete SCSI Partitions, using the instructions in LFC Procedure - Version 06MW3.5.

  6. Perform the DARC Replacement Procedure that is appropriate for your system:

    • DARC-2 Replacement

    • DARC Replacement

NOTE:In Scenario 2, if SDDA is internal, please escalate to engineering/OLC team.

All KERNEL PANICS DURING ABOVE PROCEDURE WILL NEED HELP FROM THE ENGINEERING TEAM.
