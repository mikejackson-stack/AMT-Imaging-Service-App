5167277-800 - FX/Xtream SW & Upgrade Procedures

Additional Software Options

There are three additional options that may be installed with this upgrade. Please note that the order of installation is critical to proper operation. When loading any of the following software options, make certain to install them in the order listed below:

  1. CardIQ

  2. CardEP

  3. Hard Exam Split

For software option installation instructions, please refer to: Option Installation.
