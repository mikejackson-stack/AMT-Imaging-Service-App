5167277-800 - FX/Xtream SW & Upgrade Procedures

HIPAA Component EA3, Enterprise Authentication

The following questions should be answered by the Site IT specialist, to configure HIPAA EA3:

  • Does your network have a central user database?

    (Example: Microsoft Active Directory)

    If no, then STOP. Otherwise, continue with the following questions.

  • What is the user database?

    (Example: Microsoft, Novell, Sun)

  • What is the IP of the user database?

  • What is the full name of the user database?

    (Example: server.domain.com)
