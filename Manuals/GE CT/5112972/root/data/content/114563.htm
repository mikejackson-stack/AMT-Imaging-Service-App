3  Procedure

3.1  STATE$REP.TM File

  1. STATE$REP.TM is a file which contains a history of any computer or disk related errors. It can be accessed from “R" level. It will report on disk 0 or 1 if the system has two drives.

    Use <Control S> to stop screen from scrolling.

    Use <Control Q> to start screen scrolling again. See Illustration 1.

    The STATESREP.TM file is located in Directory DZ0 at R level. This file tracks “ON-LINE" disk drive STATUS and ECC errors. It is useful for finding the following:

    1. New Bad Blocks.

    2. Intermittent Disk Drive Errors.

    This file is updated every time DOWN is typed.

    To access STATE$REP.TM, from R level of Directory DZ0 type: STATE$REP.TM <CR>.

3.2  Decoding Information

  1. ERCC ERROR COUNT = 0.

    The number of ERCC errors. Any count (other than 0) indicated ERCC errors have occurred during system operation. This means there is a problem with the CPU Memory.

  1. `DIB' DATA = 000000K, `DIA' DATA = 000000K.

    The DIB and DIA data are analyzed to determine the last actual memory bit to fail.

  1. `DZ0' ERROR COUNT = 6, (DZ = Zebra, DA = Argus, 0 or 1 = Drive Unit Number)

    The total number of Disk Drive errors. (DZ = Zebra Disk, DA = Argus Disk)

  1. DATA LATES = 0, (Zebra Only)

    The number of Data Late Errors. This comes from DIA Status bit 14.
