NOTE:These exposures are most easily performed from Gencal program in CTDS.

  1. Enter CTDS.

  2. Select GC (CR).

  3. Perform Function 7 (reset TGGC and download).

  4. Perform Function 2 (verify/adjust).

  5. Select Corxtab table and manual mode by editing.

  6. Select new technique - change time to 4 seconds.

  7. Select return to retain previous values when finished.

  8. Select “R" to retry scan if required.

  9. Select the “Cancel" key to exit.

NOTE:Use MGTEST FETCH FAULT STATUS (option 22) and verify a 20F2 fault is reported. If Gantry is left in service mode (for error display), just verify that the display shows 242 error on left side of display.
