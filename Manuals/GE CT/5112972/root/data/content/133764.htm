3  Procedure

NOTE:Run this program when you replace the X-Ray tube, or the system requires re-calibration.

  1. Select [Auto mA Cal] .

    NOTE:The software automatically warms up the tube.

  1. Press Start Scan when it flashes, to automatically run the program and update the display:

    • Ductility warm-up

    • Auto mA Cal

  1. The system displays the final filament currents on the screen.
