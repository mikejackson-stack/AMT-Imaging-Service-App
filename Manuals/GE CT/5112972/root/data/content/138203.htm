CTPM-1605 (Monitor System Error Logs)

1  Personnel Requirements

Required PersonsPreliminary ReqsProcedureFinalization
1Timing Not Applicable20 mins Timing Not Applicable

2  Overview

 Procedure Effectivity:

Assembly:SYSTEM
Subassembly:Console
Purpose:Monitor System Error Logs
Last Revised:February 1998

3  Procedure

3.1  HiSpeed CT/i

  1. Review System Error Messages.

  1. On the display monitor, select the [Service Desktop] Icon, and then select [Log Viewing] .

3.2  HSA and HSA RP

  1. Review System Error Messages.

  1. Sample Error Message.

    Date    Time

    Suite:Suitename    Host:Hostname         Proc:Processname    Error:Error Number

    File:Filename    Method:Methodname     Line#:Location ID

    Function:Minor Function

    Scan/Image Type:Scan/image Type      Scan:Scan Specifics       Image:Image

    Exception Level:level/flag    Ticks:ticks (This line, firmware only)     Log Series:#####

    Service lines: Specific and detailed information concerning the error including (but not limited to): - Additional problem description and cause information. Information indicating what was supposed to happen, what did happen, and how it was detected (for example, expected value vs. actual value, name of file attempted to open, etc). This includes any information concerning abnormal conditions related to the error. Network input/output information

3.3  HSA Systems

Review the System Error Log for any errors pertaining to the SRU and run the appropriate diagnostics.

3.4  HSA RP Systems

  1. Review Error Log for RP related errors such as:

    • LSD Errors

    • HSD Errors

    • Boot Problems

    • Self-Test Errors

4  Finalization

No finalization required.
