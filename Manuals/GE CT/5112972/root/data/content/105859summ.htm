CTPM-0203 (Adjust Vertical, Horizontal Sizing)

(Click Here to Return to Detailed Procedure)

1  Procedure

  1. Display an image on the screen using the W/L trackball. Set the level in a negative direction until the background is bright. This should give you a lightened display with the image and the corner text still visible.

  1. Measure the lightened display area using a ruler or tape measure. The lightened display area excluding the gray scale should measure 7.51 x 7.51. (Refer to Illustration 1).

  1. Verify that the lightened area including the gray scale is not tilted left or right and that it is centered within the plastic console bezel opening.
