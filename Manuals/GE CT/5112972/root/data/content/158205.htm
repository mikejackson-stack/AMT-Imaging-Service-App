4  Procedure

NOTE:To save time on future tube change, create a kV Test Baseline on the freshly calibrated system.

  1. Display the Generator Installation and Verification menu.

  1. Select [kV Test] .

  1. Select [Tube at Top] .

  1. Turn OFF the axial drive switch.

  1. Remove the mylar window from the gantry.

  1. Select [Create Baseline] . The system acquires four air scans.

  1. Place the kVp Evaluation Tool on the detector window, with the print side up. Position the tool over the center of the detector, ±1/2 inch. Align the cross-hair on the tool with the center detector Hex Screw (5th from either visible side). See Illustration 1 for a guide to Evaluation Tool placement.

    Illustration 1:  kVp Evaluation Tool Placement

  1. Select [Continue] . The system acquires four kV scans.

  1. Remove the KVp Evaluation tool from the gantry.

5  Finalization

  1. Perform a Save System State upon completion. The system saves the kV Baseline with the system characterization values on the system state MOD.
